Templates

A starting point for every kind of docs page, and how to write one.

Cheatsheet Template Template for an API reference: one card per feature, grouped into sections, filterable by text. templates/cheatsheet.html Commands Page Template Template for a commands page: operations by family, which CLI / skill / yarn command does each, drawn from a JSON file. templates/commands.html Epic UI and App UI Components Page Template Template for a components page or components guide of a component set (Epic UI, App UI): Spell UI's page shape, the set's side column, live examples from its pack. templates/component-set-docs.html Details Page Template Template for a details page: a question Claude explains, answered on the page. templates/details.html Guide Template Template for a guide (design notes, research, references): prose sections, tables, code, callouts, asides. templates/durable.html Sagas Home Template Sagas home template (parked): a project's saga sets, one card each; copied to `goals/index.html` by `spell dev goals index` when there is none. templates/goals/index.html Saga Set Template Saga set template (parked): a set's contents page, copied by `spell dev goals new-set <set>`; its saga cards are written by `spell dev goals index`. templates/goals/set/index.html Saga Page Template Saga page template (parked): copied by `spell dev goals new <set>/<topic>`, kept current by /goals dialogs. templates/goals/set/topic/topic.html Review Page Template Template for a review page: the calls of a finished run, one question each: keep, change or talk over templates/review.html Spell UI Components Page Template Template for a Spell UI components page (or components guide): Fomantic's docs layout in ui-* widgets -- nav, masthead, Examples / Usage / API / Theming tabs, an On this page rail. templates/spell-ui-docs.html Choice Page Template Template for a choice page: names Claude recommends, one row per use site, each one Owen's call. templates/syntax-choices.html
