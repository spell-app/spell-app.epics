Docs Templates

Templates

A starting point for every kind of docs page, and how to write one.

Cheat Sheet Template Template for an API reference: one card per feature, grouped into sections, filterable by text. templates/cheatsheet.html Commands Template Template for a command reference: operations by family, which CLI / skill / yarn command does each, drawn from a JSON file. templates/commands.html Details Page Template Template for a details page: a question Claude explains, answered on the page. templates/details.html Durable Doc Template Template for design notes, research and references: prose sections, tables, code, callouts, asides. templates/durable.html Goals Home Template Goals home template: a project's goal sets, one card each; copied to `goals/index.html` by `spell dev goals index` when there is none. templates/goals/index.html Goal Set Template Goal set template: a set's contents page, copied by `spell dev goals new-set <set>`; its topic cards are written by `spell dev goals index`. templates/goals/set/index.html Goal Topic Template Goal topic template: copied by `spell dev goals new <set>/<topic>`, kept current by /goals dialogs. templates/goals/set/topic/topic.html Review Review: the calls of a finished run, one question each: keep, change or talk over templates/review.html Spell UI Docs Page Template Template for a Spell UI docs page: Fomantic's docs layout in ui-* widgets -- nav, masthead, Examples / Usage / API / Theming tabs, an On this page rail. templates/spell-ui-docs.html Syntax Choices Template Template for a syntax-choices page: names Claude recommends, one row per use site, each one Owen's call. templates/syntax-choices.html
  • Start from a template: spell dev docs new durable <topic>/<topic>.html --title "Title".
  • A plan doc: run /epic <name> in Claude Code. Never copy the plan template by hand.
