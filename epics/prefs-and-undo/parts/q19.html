  • Its pref store: the same shape P1 built: one name per app, the browser's storage or a per-request stand-in on a server, quick and waited-on forms, keys as folders.
    • It kept rich values (dates) through its own serializer; P1 keeps text people can read instead, as Owen chose.
    • Its comments record the bug Overview 1.1 warns about: two apps once shared one pool because the name and the store were passed the wrong way round. P1's store takes one name, so that can't happen.
  • Its database store: one IndexedDB database per app, on a small library (idb-keyval); a quick read throws, a quick write is fire-and-forget, "read, change, save" runs inside the database's own transaction.
    • Three bugs in it: its waited-on read never waits (so its default never applies), its "has" compares a full key against short ones, and its key listing filters by a prefix its keys never get.
    • So P2 builds its own, tested: see the question on the library.
  • Its undo stack: Overview 1.2's design exactly: titled records, two stacks, folding by title and target (only when a target is given), a limit, cleared on a context switch; undo and redo run a moment after the stacks change. P5 builds this, generic.
  • Its action manager: an action is a described command: an id that never changes (tours and analytics key off it), a title, an icon, a tooltip, enabled-when and selected-when, shortcuts per operating system; one place runs every action (keys, buttons, menus), and listeners hear each run.
    • Shortcuts are off inside a text field and inside a modal, unless the action says otherwise; several actions may share a key, the first enabled one runs.
    • It records no undo itself: undo rides on options passed to each change.
    • That shape is epic elemental-spell's Action (its Q33, Q34), not this epic's. P6 takes only its rules for undo's and redo's keys.
  • Its key library: a copy of tinykeys; Spell UI's keyboard registry already does the same, so nothing to take.
  • Its stylesheet: styles merged by selector for drawn items; outside this epic.
