A remembered value read back is the property's value like any other:

  • It's stored on the thing as it's read, so it's in the thing's JSON: a saved document holds the theme it was saved with.
  • A value given when the thing is made is a change like any other, so it wins: new Settings({ id: "main", zoom: 1 }) sets zoom back to 1 on every run, and remembers 1.
    • A program that wants the remembered value leaves it out, or gives it as the starting value (init), which the remembered one beats.
  • remembered values show in saved JSON
  • a value given at new overrides what was remembered
