Owen's comments on the plan, 2026-10-24: can this be: if it starts with ", { or [ it's JSON, otherwise it is text? and pref value 1 should be JSON as well if only a number.

  • Read: JSON when the saved text starts with ", { or [, or is a number; anything else is text, e.g. dark.
  • Written back the same way: a string is quoted only when it would read back as something else ("1", "{x").
  • So head scripts and people read the keys as they are today: spell-site:scheme holds dark.
  • No per-store format option: the plan had one ("text"), which this replaces.
  • true, false and null read as JSON too: a judgement call, J1. 
set("scheme", "dark")        spell-site:scheme      dark         reads back "dark"
set("width", 240)            spellEditor:width      240          reads back 240
set("tab", "1")              spellEditor:tab        "1"          reads back "1"
set("open", ["a", "b"])      spell-ui-site:open     ["a","b"]    reads back ["a", "b"]
set("on", true)              spell-site:edit        true         reads back true

  • every existing key keeps its value's bytes
