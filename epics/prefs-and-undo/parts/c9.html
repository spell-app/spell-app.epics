A Spell app run in VS Code's Run Project panel forgets its remembered properties each time the panel opens.

  • Its webview gets fresh browser storage each time the panel opens, so whatever it kept there would be gone by the next run.
  • So the VS Code runner hands runCompiled() no project id, and nothing's remembered there at all.
  • The fix: remember through the page server's place (ServerPlace, P2), which keeps them in the person's space, whatever opens the app.
  • the editor and <spell-viewer> remember; the VS Code runner doesn't, yet
