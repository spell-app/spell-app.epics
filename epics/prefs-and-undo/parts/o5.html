Nine phases, about 16-24 hours. First one pref store and the places it keeps values, then every one-off store moved onto it, then an undo stack and its use in the runtime, then typed defaults and remembered properties. The spell syntax (remembered, undone as "Turn Card", a declared default) waits for elemental-spell.

One folder: util's persist

  • The pref store, its backends, defaultFor() and the undo stack live in the kit's util, in a folder of their own (Q11).
  • Generic: nothing Spell-specific, so Spell UI imports the pref store, and Spell's runtime and spell-app build on the undo stack.

The phases

  1. Pref Store: ONE store, with three places to keep values to start.
    • Lasting (per site), per tab, and in memory: for servers and tests, and the fallback when the browser blocks storage.
    • Values readable as they are: JSON only when they look like it (Q12).
    • Declared prefs, with defaults (Q13).
    • A waited-on form of everything, for the next phase's stores.
    • It never throws when storage fails: it logs, and answers the default.
    • The editor moves onto it; the two old stores go.
  2. Database and Server Stores: two waited-on places.
    • The browser's database: big values, and file handles, kept as the browser copies them (Q8).
    • The page server: in the person's space, through spaces (Q9).
  3. Stores Move Over: the kit's, Spell UI's and the editor's stores, keys byte for byte; the editor's static files onto the database.
  4. Epic Pages' Stores: the epic pages' folds, drafts, filters and read marks (Q5).
  5. Undo Stack: the generic stack, with transactions (Q6, Q14).
  6. Undo in the Runtime: Spell's recorder on it.
    • One history per app, cleared on a new run and when the app loads saved state (Q18).
    • An action marked undoable is ONE step, whatever it changes and however long it waits.
    • Some changes and actions opt out (Q10).
    • Every app has undo and redo, live titles, and ⌘Z / ⇧⌘Z while focus is in it (Q16).
  7. Typed Defaults: every spell property defaults by its type (Q13).
  8. Remembered Properties: saved through the app's pref store, under its project's id (Q7, Q17).
  9. Doc Review.

Four places to keep values

Place Lasts Waited on For
quick: lasting, or per tab per site, or until the tab closes no small values: a theme, a panel's width
the browser's database per site yes big values, file handles
memory until the page goes no servers, tests, and when the browser blocks storage
the page server in the person's space yes anything that should follow a person 
const site = new PrefStore("spell-site")                     // keys start "spell-site:"
site.declare("scheme", { oneOf: ["light", "dark", "auto"] })
site.get("scheme")             // "light":  nothing saved, so the first choice
site.set("scheme", "dark")     // writes  spell-site:scheme  =  dark
site.set("width", 240)         // writes  spell-site:width   =  240

const files = new PrefStore("spell-static", { place: "database" })
await files.save("@owen/solitaire/cards.png", blob)    // waited on:  kept as the browser copies it

Undo as transactions

  • An undoable action opens a transaction, which stays open until its work finishes, waits included.
  • Undoable work that starts meanwhile joins it: a person sees ONE step.
  • Undo and redo put back what was recorded, at once: redoing a deal doesn't animate it again.
static { this.declareAction("deal", { undoneAs: "Deal" }) }

async deal() {
  for (const card of this.deck) await this.moveCard(card, this.tableau)   // moveCard is undoable too:  it joins
}

app.undoTitle   // "Undo Deal"
app.undo()      // every card back in the deck, at once
app.redo()      // dealt again, at once:  no waiting

Typed defaults

A property that's Reads, when unset, today After Typed Defaults
a number nothing 0
a choice (yes / no) nothing false
text nothing empty text
one of a list nothing its first value
a list a new list a new list
a thing nothing nothing
  • A declared default, or a starting value, wins.
