The plan put PrefStore in Spell UI's util barrel, which everything in Spell UI's core bundle re-exports.

  • Measured with yarn measure: core grew from 38.12 kB to 39.98 kB, so a page with one button went from 73.78 kB to 75.64 kB.
  • Only a few files keep preferences (the docs site's theme and nav, the theme editor), so every other page would pay for it.
  • So it stays out of the barrel, and those files import it by file (spell/util/persist/PrefStore) in Stores Move Over, as the house style allows for an import that saves bundle bytes.
  • The barrel's docstring says so, with the numbers.
  • no page grows for the pref store until it uses one
  • Spell UI's stores import spell/util/persist/PrefStore directly (P3)
