A Spell app's property forgets its value on reload.

A property declared remembered reads and saves through the app's PrefStore, named by the project's id (Q7), which whoever runs the app hands the runtime.

  • declareProp("theme", { remembered: true }): read the first time (its typed default when nothing's saved), saved on every change.
  • Keys:
    • on the app: @owen/solitaire:theme
    • on a thing whose id the program chose: @owen/solitaire:<its id>.<property>
    • on a thing with no chosen id: an error at its declaration, saying how to fix it
  • The host can hand the runtime another store, e.g. the server store; a waited-on store is loaded before the app starts.
  • The editor's runner and a published page both set the project's id before the app starts.
