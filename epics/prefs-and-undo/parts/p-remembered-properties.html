A Spell app's property forgets its value on reload.

A property declared remembered reads and saves through the app's PrefStore, named by the project's id (Q7), which whoever runs the app hands the runtime.

  • declareProp("theme", { remembered: true }): read the first time (its typed default when nothing's saved), saved on every change.
  • Keys:
    • on the app: @owen/solitaire:theme
    • on a thing whose id the program chose: @owen/solitaire:<its id>.<property>
    • on a thing with no chosen id: an error at its declaration, saying how to fix it
  • The host can hand the runtime another store, e.g. the server store; a waited-on store is loaded before the app starts.
  • The editor's runner and a published page both set the project's id before the app starts.
  • What changes: a property declared remembered: true keeps its value from one run to the next, in the person's preferences.
    • declareProp("theme", { oneOf: ["light", "dark"], remembered: true })
    • Read the first time it's asked for: what the last run set, else its starting value, else its typed default (P7).
    • Kept again every time it's set.
  • Where they're kept: a pref store named for the project's id (Q7).
    • on the app, by name: @owen/solitaire:theme
    • on any other thing, under the id the program chose: @owen/solitaire:main.zoom
    • a thing whose id was made up (new each run) isn't remembered: a warning once, naming the fix, not an error (J5)
  • Who says which project: whoever runs the program, with core.remember(projectId), before the program loads.
    • The editor and <spell-viewer> (a published page) both do: their runs carry the project's id.
    • Tests never remember; nor does the VS Code runner yet (C9), nor spell run (C11).
  • Any place works, the page server's too: everything kept is read in one go before the program starts, so the program never waits for it.
  • Only text, numbers and yes / no are kept; a thing or a list in a remembered property isn't, said once. A remembered value the property no longer allows (a choice the program dropped) is passed over, said once.
  • Built:
    • the kit: the remembered flag a property declares
    • the core: RememberedValues, core.remember(), and Thing reading and keeping them
    • spell-app: runCompiled() takes the project's id
    • Python's core lists remember as not ported yet: a Python program keeps none
  • Checked: 10 new tests (two runs of one project remember; two projects don't share; a thing's id; a made-up id; a waited-on place read before start).
    • kit 828 passed
    • spell-parser 3851, and Python's 397
    • spell-app 1131 passed / 75 skipped
  • Merged into main in the kit, spell-parser and spell-app.
