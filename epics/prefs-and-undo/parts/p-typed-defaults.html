An unset spell property reads as nothing, whatever its type: a new counter's count isn't 0.

Every declared property defaults by its type when it names none; a declared default wins; the same defaultFor() as declared prefs.

  • By type:
    • a number: 0
    • a choice (yes / no): false
    • text: empty, ""
    • one of a list: its first value
    • a list: a new, empty one (as now)
    • a thing: nothing (as now)
  • A declared default, or a starting value, wins.
  • The default isn't saved: saved programs' JSON doesn't change.
  • Python's runtime gets the same defaults, or they're listed as not ported yet.
  • Every compiled example and guide re-run; a snapshot that changes is looked at, then re-blessed.
