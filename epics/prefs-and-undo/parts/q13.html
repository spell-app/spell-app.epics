Owen's comment on the plan, 2026-10-24:

need a way to set default, e.g. if dark is light, dark, auto, need a way to specify the default. One possibility is that first value named is the default if no default provided.

I want this for regular spell properties as well. So e.g. all numbers should default to 0, all booleans to false, all text to empty string, all enums to first value in list, etc. With a way to specify explicit default.

  • Declared prefs: store.declare("scheme", { oneOf: ["light", "dark", "auto"] }) reads light when nothing's saved; a declared default wins; a default passed to get() wins over both.
  • Spell properties, by type, when they declare none: a number 0, a choice false, text "", one of a list its first value; a list is a new one, a thing nothing (as now).
  • Both from ONE helper, defaultFor(), in util's persist folder.
  • A new phase for the properties, P7 · Typed Defaults, before remembered properties, which read their default through it.
  • The default isn't saved, so saved programs' JSON doesn't change.
  • P1 · Pref Store: declared prefs and defaultFor()
  • P7 · Typed Defaults: every spell property
  • a caveat: programs see a new value where they saw nothing
