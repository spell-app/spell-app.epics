spell-element, P8 · Disabled And Visible: disabled and visible (and now loading, readonly, inert) on every element.you answered the bedtime page: P8.4 said "sidebar / dimmer / popup: visible makes sense for those too; we should have hidden too, the browser's is close enough", and P8.5 picked a transition for visible="false".how P8 builds visible / hidden, and how far the three extra states go.

What's there today:

  • visible is an attribute on <ui-sidebar> and <ui-dimmer>: they start hidden and animate in.
  • <ui-popup>, <ui-modal> and <ui-flyout> say open instead (it emits Fomantic's visible class). Open means more than shown: focus moves in, Escape closes, ui-open / ui-close can veto.
  • The platform's hidden works on any element, BUT a ui-* element's own :host { display: ... } beats the browser's [hidden] { display: none }, so today <ui-segment hidden> may still show. Whatever we pick, P8 fixes that.

hidden: the platform's, INSTANT, works before scripts load and in the static render. visible="false": ANIMATED hide on any element (a ui-transition animation), visible (or ="true") animates it back in. Both set: hidden wins. The sidebar and dimmer keep starting hidden.

No new attribute: we animate the platform's hidden when a script toggles it (instant on first paint). visible stays only on sidebar / dimmer.

One word of ours; hidden left to the platform (fixed so it works, never animated).

open stays "opened" (focus, Escape, events); visible="false" hides the whole element as on any other, even while open. No breaking change.

A popup is only shown / hidden, so visible and open mean the same there; modal and flyout keep open alone.

Breaking: every <ui-popup open> changes.

A short fade by default; a family picks its own in ElementSetup (the sidebar keeps its transition attribute, the dimmer its fade). Nothing new on every vocabulary.

Any element: <ui-segment visible="false" transition="slide down">. Every vocabulary grows one attribute.

Plain elements hide at once, like hidden; only sidebar / dimmer / popup animate.

You picked all three "the same way" as disabled. 17 vocabularies have loading today, 6 readonly; inert is the platform's.

loading: every element, a setting per family in ElementSetup as disabled (default: a loader over it, busy for screen readers). readonly: every FORM control (FormComponent). inert: the platform's, already works: we style it (dimmed) and document it.

One rule for all; readonly on a card does what inert does.
