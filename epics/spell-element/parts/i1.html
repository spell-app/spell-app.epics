A component’s render() ran again, rebuilding its whole view, whenever its body (outside its JSX) read an attribute. The docs say render() runs once. The new DOMElement tests found it; it is older than Fold Into Elements (P2).

  • why: onMount() passed render() as <Show>’s children, and Solid evaluates those in a tracked computation
  • so a reactive read in the body, like const size = this.attrs.size before the return, subscribed to that attribute, and a change re-ran render()
  • the fix, in UIComponent.tsx: 
    <Show when={…}>{untrack(() => this.render())}</Show>
  • the test now passes, and all 5,081 browser tests still do
  • render() runs once per mount, as documented
  • a read in its body no longer updates the view; reads that should update go inside the JSX
