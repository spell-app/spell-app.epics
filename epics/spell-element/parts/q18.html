Owen, 2026-10-08, answering his own plan comment, "I'd expect DOMElement to have the UNCONVERTED values": the values on DOMElement are converted. This settles a detail of the one attribute store (Q5, from analysis Q5).

  • the raw text is already on the element, as the attribute itself (getAttribute("disabled")), so DOMElement keeps no copy of it
  • DOMElement keeps one converted value per attribute, from either:
    • the attribute's text: disabled="" becomes true
    • a property write: select.options = [...], kept as given, even before the component exists
  • the component reads the value from there

Net effect:

  • one converted value per attribute on DOMElement; no raw copy
  • a property set before the component is made needs no separate "early" store
