chose JSON for the whole array over JSON per item, comma-joined, because {"a":1},{"b":2} isn't JSON anyone can parse back.

  • options: whole array as JSON when any item isn't a primitive (picked); every array as JSON (would change a,b for multiple-style values); each item text()-ed, then joined (the aside in T6's details)
  • the property keeps the array itself; only the attribute text changes
  • el.items = [{ a: 1 }] on a string attribute reflects as items='[{"a":1}]'
