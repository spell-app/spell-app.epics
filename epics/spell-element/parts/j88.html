An array holding anything but strings, numbers and booleans reflects to its attribute as ONE JSON array; an array of plain values stays comma-joined.

  • Why not JSON per item, comma-joined: {"a":1},{"b":2} isn't JSON anyone can parse back.
  • The options:
    • the whole array as JSON, when any item isn't a plain value (picked)
    • every array as JSON: would change a,b, for multiple-style values
    • each item turned to text (text()), then joined: the aside in T6's details
  • The property keeps the array itself; only the attribute's text changes.
  • el.items = [{ a: 1 }] on a string attribute reflects as items='[{"a":1}]'
