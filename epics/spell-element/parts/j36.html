  • Before: most were added on the server too (harmless on linkedom), and never removed (UIList and UIMenu removed theirs on release by hand).
  • UITable's click / keydown listeners now start in the constructor, not onMount(): both run on first connect, before any event.
  • Stayed explicit: UIForm's listeners (added while connected, by an effect), listeners on inner or parent elements (UIDimmer's show-on parent, UIPopup's target, UITabs' bar, docs components' boxes), EpicFold's inner section.
