Four epic elements now watch things outside themselves only while they're in the page: @E.whileConnected, in place of onSettled().

  • The four watchers:
    • EpicFold's hashchange listener
    • EpicVersion's watch of its parent
    • EpicChoices / EpicOption's watch of their question
    • EpicOption's review-inbox subscription
  • onSettled() set each up once, after the first draw, and kept it until the element was thrown away.
  • Why: ui's rules (AGENTS.md) name that decorator for a listener or observer outside the element.
  • Options: @E.whileConnected (chosen); keep onSettled(), with a comment.
  • A moved element now watches its NEW parent or item, where the old code kept watching the old one.
  • EpicFold follows the address's own #hash only the first time it connects (a flag), as before.
    • So a fold moved by a live update doesn't scroll the page to itself again.
  • The MutationObservers stay hand-written, inside those methods.
    • They watch a parent or ancestors, which @E.fromContent (its own light DOM only) can't.
  • Nothing visible on a page that doesn't move elements
  • no listener left running on a removed element
