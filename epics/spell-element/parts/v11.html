Load <spell-app> two ways: alone on a page, and on a docs page. Alone, it should never download the editor; on a docs page, it should load only one Solid.

Alone on a page:

  1. Build the elements: yarn build:element, in the app package.
  2. Start the servers (/spell-serve), then open /demo/spell-app.html on the editor's.
  3. Open the browser's Network tab, and reload.
  • Every app on the page runs its project, with its toolbar.
  • The Network tab never shows spell-editor.js, nor Monaco: nothing on the page asks for an editor.
  • Each app draws at once, as before, not behind a grey skeleton (J97), and fetches only the Spell UI widgets it draws.
  • Root attributes work on it: in dev tools, give one app theme="dark" or size="large", and only that app changes (J99).

On a docs page:

  1. Save the page below as spell-app-docs.html, in the shared scratch folder for details pages.
  2. Open it from this branch's page server: epic pages open pages/details/spell-app-docs.html.
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <link rel="stylesheet" href="../../spell-epic/src/tools/_assets/spell-doc.css" />
    <script type="module" src="/element/spell-app.js"></script>
  </head>
  <body class="spell-doc-page">
    <ui-root><spell-app project="@examples/Solitaire" toolbar></spell-app></ui-root>
    <script src="../../spell-epic/src/tools/_assets/spell-ui.js"></script>
  </body>
</html>
  • The app runs its project.
  • One Solid: the Network tab never shows spell-solid.js (T3, J101).
  • Known, not a failure: the toolbar's Restart icon is blank, and the console warns that the Fomantic icon pack didn't load (I11). Icons the page's own set has, like Debug's bug, still show.
  • No other warning or error in the console.
  • Delete the scratch page afterwards.
