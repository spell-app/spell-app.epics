A new speed check times how long the page takes to make 1,000 buttons, so each phase can show it didn’t slow elements down. The plan asked for it (Q13).

  • the test: UIButton.perf.test.tsx, in ui’s browser tests
  • what it does:
    1. puts 1,000 <ui-button primary>s in the page at once
    2. waits until every one of them is ready
    3. does that once to warm up, then 9 more times, timed
    4. reports the median of the 9
  • it writes build-perf.json, beside yarn measure’s results
  • the numbers move a few milliseconds from run to run (75.1 and 78.3 ms before P1, on the same code), so only a change bigger than that means something
  • every later phase reports “1,000 buttons” next to yarn measure’s sizes
  • before P1: 75.1 / 78.3 ms; after P1: 76.1 / 75.9 ms
