A required slider in a form: it should block the form's submit until someone moves it, though it shows a value from the start.

  • On Spell UI's form page (/ui/components/ui-form.html, from this branch's page server), in dev tools, put a <ui-slider name="volume" required> inside a live form.

What should happen:

  • Submit the form untouched: the slider is flagged as missing, and the form doesn't send.
  • Move the thumb, even back to where it started, and submit again: the form sends.
  • The same slider with a value written in its markup passes at once: something set it (J87).
  • Brand's colour picker with required behaves the same; brand's composer with required fails while its text is blank.
  • readonly on brand's composer or colour picker: the value shows, changes are refused; the composer still casts and the picker still copies (J96).
