Two small additions to the element decorators, so about 20 leftover places in ui could move to decorators instead of being excused.

  • @E.untracked now takes a GETTER.
    • 16 getters were one untrack(() => ...) each.
    • Where:
      • the DOM elements' script API, in ui
      • epics' DOMEpicFoldElement.contentsEntry; brand's DOMBrandFieldElement.errors
      • UIShape / UITransition settings
      • DialogComponent.closedBy, UINag.dismissalStore
      • UITabs.canTransition, UIDocsNav.favoriteTags
      • UISearch.startingQuery
  • @E.onChange(..., { defer: true }): not called at the start.
    • Used by UIProgress's ui-change, and CheckControl's checked alias.
  • Tests added in Reactive.test.tsx.
  • two more decorator options to know, documented in ui's rules (AGENTS.md) and the decorators' file (Reactive.ts)
