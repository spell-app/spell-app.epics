UIComponent.mount() and the static render build each component inside untrack(), and onMount() calls render() inside untrack(), so 19 untrack()s there were no-ops (CheckControl, UIRadio, UINag, UICalendar, UIProgress, UIDropdown, UISelect, UISearch, UIShape x2, UITransition x2, UIEmoji, UIDocsThemes x2, epics' EpicSection x2; UIAccordion's server-only index()). Chose plain reads over keeping them, and said so in AGENTS.md ("Solid authoring") and the @untracked doc.

  • a component built some other way (outside mount() / the static render) would need its own untrack(); none exists
