19 untrack() calls were dropped from constructors, field initializers and render() bodies: they did nothing.

  • Every component is already built inside untrack(), and its render() already runs inside one.
    • UIComponent.mount() and the static render build each component inside it.
    • onMount() calls render() inside it.
  • Where they were:
    • CheckControl, UIRadio, UINag, UICalendar, UIProgress
    • UIDropdown, UISelect, UISearch, UIEmoji
    • UIShape and UITransition (two each), UIDocsThemes (two)
    • epics' EpicSection (two)
    • UIAccordion's server-only index()
  • Chose plain reads over keeping them.
  • Said so in ui's rules ("Solid authoring"), and in the @untracked doc.
  • a component built some other way (outside mount() or the static render) would need its own untrack(); none exists
