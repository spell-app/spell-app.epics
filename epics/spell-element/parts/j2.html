The four components that used solid-element’s hooks (the radio, rating, calendar and slider) now get them from E, ui’s core, instead of importing the copied folder directly.

  • the hooks: E.onConnect, E.onDisconnect, E.onFormAssociated and E.onFormStateRestore, which core.ts re-exports for now
  • why: ui’s rule is that a component imports only through spell-ui/core
    • a file imported by a component family AND by the core gets split into a third, hashed chunk of its own: one more file for every page to load
  • for now only: Fold Into Elements (P2) turns the hooks into methods on the component (Q1), and the re-exports go
  • UIRadio, UIRating, UICalendar and UISlider call E.onConnect(...) and the rest
  • core.ts exports the four hooks until P2
  • no new chunk in the build
