brand's components import Spell UI by namespace now, as a ui family does, instead of by name.

  • That's all of brand's components folder (components): components, vocabularies, fallbacks.
  • Why: P10 asks for brand's elements to be written exactly as a ui family, and ui's "Imports" rule is part of that (WWOD §4 › "ONE namespace per sub-system").
  • The change: 
    import { proto, Cell, UIComponent } from "spell-ui/core"   // before
import { E, UI, UIT } from "spell-ui/core"                   // after
import { F } from "spell-ui/forms"

The options:

  • A, chosen: namespaces, as in ui: @E.state, E.UIComponent, F.FormComponent, satisfies Partial<E.ElementSetup>.
  • B: keep the named imports.
    • A smaller diff, but brand would read unlike ui.
    • And ui's rules (AGENTS.md) carried an exception for it: "(brand: Partial<ElementSetup>)".
  • 26 files touched; 12 of them only for the import line.
  • brand's rules (AGENTS.md, "Imports") and ui's (AGENTS.md, "Classes") say so; the exception is gone.
  • Tests keep their named imports.
