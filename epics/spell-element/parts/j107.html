Motion off beats an element's own animation.

  • The order an element's animation is picked in:
    1. the off switch: the element's own none, none from around it, or reduced motion
    2. the element's own animation
    3. its family's default (elementSetup.animation)
    4. fade
  • Why: the overlays call's (J59) list put the element's own value first, but its reply also says an element can't override a page-wide none, or reduced motion. Both can't hold, so the off switch wins.
  • The other way: <ui-modal animation="scale"> would animate under <ui-root animation="none">.
  • an element's own value beats its family's default, never the off switch
