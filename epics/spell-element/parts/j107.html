Chose: the off switch first (the element's own none, none from around it, reduced motion), then the element's own animation, then elementSetup.animation, then fade.

  • J59's list put the element's own value first, but its reply also says an element can't override a page-wide none or reduced motion; both can't hold, so the off switch wins
  • the other way: <ui-modal animation="scale"> would animate under <ui-root animation="none">
  • an element's own value beats its family's default, never the off switch
