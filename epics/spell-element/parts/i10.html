A form both disabled and loading, that loses disabled first, is left with its loading veil out of reach.

  • Since T9, <ui-form>'s disabled is the base class's ("unusable").
  • When the shared inert state ends, UIComponent.onSharedStatesChanged() takes inert off EVERY top-level shadow box.
    • So the form's root is un-inerted.
    • Its own veil still shows: its inert={this.disabled || this.loading} keeps the same value, so Solid never rewrites it.
  • No other family sets inert for its own loading.
  • Fix: the base class remembers which boxes it made inert, and clears only those. Or a family names the box its loading veils.
