A small hook lets the tab's pane say segment as its class noun, where every other tab says tab.

  • The hook, in two places:
    • classNoun on the base component, beside extraClass
    • a noun option on the class builder (ClassBuildOptions)
  • Why not the alternatives:
    • The tab vocabulary's noun is tab everywhere else: the part context, the docs site, .ui.tab in the CSS.
    • rootClass's class input is private to the base component, so the tab can't override it cleanly.
  • The options:
    • the classNoun hook and the builder's noun (picked): 3 small edits in the element core
    • the vocabulary's noun as segment: renames the tab in every listing
    • string surgery on super.rootClass
  • <ui-tab>'s pane: ui active bottom attached tab segment, Fomantic's own order
  • extras still always before the noun
  • no CSS change; 621 visual tests pass unchanged
