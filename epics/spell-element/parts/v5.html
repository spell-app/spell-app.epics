Edit a Spell UI family while its demo page stays open: it should update in place.

  1. In the ui package (ui), run yarn dev.
  2. Open a family's demo: the buttons, say.
  3. Edit that family, with the page still open.
  • Edit its sheet (UIButton.css): the buttons restyle in place, with no page reload.
  • Edit its component (UIButton.tsx), a class word in render() say: live buttons redraw in place; internal state resets.
  • Edit a vocabulary text (UIButton.en.ts): live buttons update.
  • Edit a file of the shared element code (elements): the page reloads.
