The family sheets lose their own hiding rule; ONE rule, in the shared reset sheet, hides every element, and keeps it shown while it animates out.

  • Dropped from 53 family sheets: the layered :host([hidden]) { display: none }. The loader's went with P12's overlay work.
  • The one rule, in reset.css, is unlayered.
    • It hides every element with hidden, except:
      • hidden="until-found", the browser's
      • while the element animates out (:state(hiding))
    • A layered display: inline fallback keeps an element on screen while it animates out, when it has no :host { display } of its own.
  • Kept, the family rules would hide an element the moment hidden is written.
    • So no hide could animate.
    • And they'd break hidden="until-found".
  • a family that wants a hidden look of its own uses :state(hidden), never :host([hidden])
