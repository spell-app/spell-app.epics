Chose to let @E.untracked wrap an arrow-function field (@E.untracked private readonly onKeyDown = (event) => { ... }) as well as a method, over turning every JSX / addEventListener handler into a method.

  • Options: methods only (the brief), then each handler passed to JSX or addEventListener becomes a method plus an arrow at the call site (onClick={(event) => this.onX(event)}); or methods AND fields (chosen); or leave those handlers' untrack()s alone.
  • WWOD §3 keeps arrow fields for callbacks passed around, so the field form keeps that shape.
  • About 35 handler fields (UIDropdown, UISlider, UICalendar, UISearch, UIForm, UIDimmer, TextControl, UIRating, brand, epics) lose their untrack(() => this.x)s and stay arrow fields.
