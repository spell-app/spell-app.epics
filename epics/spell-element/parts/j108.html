Two rules for when visible and hidden are written:

  • Removing visible hands the choice back to the family, when no hidden is written.
    • Neither name is written, so the family decides again: a transition or modal hides, a message stays shown.
    • So a framework that drops the attribute for false (<ui-modal visible={open()}>) closes the modal.
  • Every attribute written before the first connect counts as markup, so hidden wins.
    • A property write (el.visible = true) is the latest write, at any time.

The other way:

  • removing visible leaves the fact as it was
  • the markup rule only for parsed markup: but that can't be told apart from a script's writes before connect
  • a script's element, before it's in the page, keeps markup's rule: hidden wins
    1. document.createElement()
    2. el.hidden = true, then el.setAttribute("visible", "")
    3. appended to the page: hidden
