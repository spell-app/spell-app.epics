Chose:

  • removeAttribute("visible") with no hidden written: neither name is written, so the family decides again (a transition or modal hides, a message stays shown). A framework that drops the attribute for false (<ui-modal visible={open()}>) closes the modal.
  • every attribute written before the first connect counts as markup (hidden wins); a property write (el.visible = true) is the latest write, at any time

Other way: removing visible leaves the fact as it was; the markup rule only for parsed markup (can't be told apart from a script's writes before connect).
