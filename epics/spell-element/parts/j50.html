chose a timer (E.every(0.1), started and stopped by an @E.onChange("isConnected", "for", "all")) over observers and callbacks, because custom states have no change event at all, and a property can change with no attribute; a read that finds nothing new writes nothing, so the view only redraws on a real change.

  • A: poll at 10 Hz (chosen)
  • B: a MutationObserver for attributes + addPropertyChangedCallback() for properties, states read after events (misses a state a timer sets)
  • up to 100 ms between a click and the inspector's update
  • a changed row flashes once (none under prefers-reduced-motion); unchanged rows keep their DOM
  • properties shown: only set ones (not undefined / null / false) by default; all shows every vocabulary property
