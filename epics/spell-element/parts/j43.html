Chose to clear isTouched in the DOM element's reset callback over each control's onFormReset() doing it (three did) or every override calling super.onFormReset().

  • Per control: the five "at once" controls would never clear it after an invalid event.
  • super.onFormReset(): forgetting it is silent, and the hook is abstract ("every control has one").
  • Chosen: DOMFormControl<C extends F.FormComponent> (was E.UIComponent) writes component.isTouched = false, then calls the hook.
  • The DOM element writes one component member; a test calling component.onFormReset() directly no longer clears isTouched (none does).
