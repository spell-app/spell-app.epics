Chose to look the shared names up by the dictionary's lang (between the dictionary's own attributes and English) over making each dictionary spread SharedVocabulary.es.ts into itself, because a page that writes its own Spanish dictionary would otherwise get English disabled until it knew to spread it.

  • the dictionary (or components[tag]) still wins, so a language can name them its own way
  • the same word names a tag's own disabled / loading (<ui-button>, <ui-dropdown> declare them), so <ie-boton desactivado> is disabled, as the item asked
  • packages/ui/src/vocabulary/SharedVocabulary.es.ts: { disabled: "desactivado", loading: "cargando", visible: "visible" }; SharedVocabulary.translated(lang, name)
  • Vocabulary.resolve() walks SharedVocabulary.attributesFor(), so canonicalize() / localize() know the shared ones too (English tags included)
  • tests: the translated-tag test re-pinned to ["etiqueta", "desactivado", "cargando", "visible"]; <ie-boton desactivado> is disabled
