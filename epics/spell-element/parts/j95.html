Every dictionary of a language reads that language's names for the shared attributes, automatically.

  • The shared attributes, then: disabled, loading and visible. P12 added animation.
  • They're looked up by the dictionary's lang, between the dictionary's own attributes and English.
  • The other option: each dictionary spreads the shared file (SharedVocabulary.es.ts) into itself.
    • A page writing its own Spanish dictionary would get English disabled until it knew to spread it.
  • The dictionary (or its components[tag]) still wins, so a language can name them its own way.
  • The same word also names a tag's OWN disabled or loading, as the button and the dropdown declare them.
    • So <ie-boton desactivado> is disabled, as the item asked.
  • the Spanish shared names: { disabled: "desactivado", loading: "cargando", visible: "visible" }; looked up with SharedVocabulary.translated(lang, name)
  • a vocabulary's lookups know the shared attributes too, English tags included
    • Vocabulary.resolve() walks SharedVocabulary.attributesFor()
    • so canonicalize() and localize() find them
