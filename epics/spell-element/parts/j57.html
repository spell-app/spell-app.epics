Q28 is still open: took the recommended option of its question 1.

  • hidden: now beats a family's own :host { display }: an UNLAYERED :host([hidden]) in reset.css (every shadow root adopts it); a page's own rules still win. Works before scripts load (the browser's own rule) and in the static render (StaticStylesheet's unlayered HIDDEN)
  • <ui-divider hidden> keeps Fomantic's meaning (the spacing without the line): its own unlayered rule, adopted after, wins
  • visible="false": animates out, then :state(hidden) (display: none); visible / ="true" animates back; at once before the element first draws; static render: data-state="hidden", hidden by the same rule
  • el.visible = false reflects as visible="false": a boolean whose default is true now reflects off as "false" (was: removed, which brought the default back); <ui-nag closable>, <ui-accordion exclusive> ... too
  • <ui-sidebar>, <ui-transition> keep their own visible (start hidden); <ui-reveal visible> (no clipping) too
  • <ui-segment hidden> is hidden (it could show before); <ui-message visible="false"> fades away
