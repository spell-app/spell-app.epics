• UIForm: its change / input / ui-change / focusout listeners are now @E.on (the element's whole life) instead of only while connected: only an event dispatched on a DISCONNECTED form differs (it now validates)
  • UICode: the document's new-languages listener is added in the constructor (this.on(..., { target: document }), removed on release) instead of in onSettled(): it starts a little earlier
  • UIMenu: the roving refresh onSettled() queued in the constructor is now @E.onChange("isReady")
  • UISection's sticky watch (was a createEffect made in render()) is @E.onChange("isReady", "isConnected", "sticky", "stickTop"), returning early until drawn, as UIShape / UISidebar
  • also moved, same timing: UIEmoji, UIMarkdown, UISlider, UIDocsTokens (@E.onChange), UIProgress, CheckControl ({ defer: true })
