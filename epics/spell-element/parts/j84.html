Four ui components' listeners moved onto decorators, and start or stop at slightly different times.

  • UIForm: its listeners are now @E.on, for the element's whole life, not only while connected.
    • The events: change, input, ui-change, focusout.
    • Only an event dispatched on a DISCONNECTED form differs: it now validates.
  • UICode: the document's new-languages listener is added in the constructor, not in onSettled().
    • It's added with this.on(..., { target: document }), and removed on release.
    • It starts a little earlier.
  • UIMenu: the arrow-key (roving) refresh, which the constructor queued with onSettled(), is now @E.onChange("isReady").
  • UISection's sticky watch was a createEffect made in render().
    • It's now @E.onChange("isReady", "isConnected", "sticky", "stickTop").
    • It returns early until drawn, as UIShape and UISidebar do.
  • Also moved, at the same timing:
    • UIEmoji, UIMarkdown, UISlider, UIDocsTokens: to @E.onChange
    • UIProgress, CheckControl: to @E.onChange with { defer: true }
  • all ui tests pass (ssr 296, browser 5073)
  • worth a look by eye: a form's validation, a menu's arrow keys, a sticky section's title
