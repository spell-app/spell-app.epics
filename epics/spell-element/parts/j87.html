A required slider or colour picker counts as EMPTY while no value has been set yet: its controlled value is still undefined.

  • Why: Owen's reply asks for it, in case the slider was set up with undefined.
  • The options:
    • empty while unset (picked)
    • always met
    • empty while the thumb sits at min: a real choice of min would fail
    • a range empty until BOTH thumbs were set: moving one thumb wouldn't count
  • The override is validationValue, so what a submit sends (formValue) doesn't change.
  • brand's composer takes required too: blank text fails.
    • So every form vocabulary now has one.
    • FormAttributes.required lost its "undefined at run time" note.
  • No aria-required on the thumbs: ARIA's slider role doesn't support it.
    • The native fallbacks (a range or colour <input>) ignore required, as the browser does.
  • An invalid state is added to the three vocabularies, as the other form controls list it.
    • No error look: Fomantic's slider has none.
  • <ui-slider required> with no value blocks its form's submit until the thumb moves
