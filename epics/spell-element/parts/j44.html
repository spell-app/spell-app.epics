Chose an interface merge on FormComponent (as CheckControl / TextControl do for their common attributes) so the base can read this.disabled, this.name, this.required, over casts or E.Reactive.attributeValue() calls.

  • required?: boolean: TypeScript refuses it (a subclass's vocabulary getter must have the identical type, TS2320).
  • Chosen: required: boolean, with a NOTE that it's undefined (never required) where the vocabulary has none.
  • UISlider / brand's controls type-check this.required though it's always undefined there.
