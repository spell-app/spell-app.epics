Every attribute is still a property (`app.project = ...`), `run()`, `restart()`, `pushed`, `compile()`, `save()`, `compiled`, `COMPILE_DELAY` and the `spell-open` / `spell-compiled` events are as before. What differs:

  1. `assets` is now a vocabulary attribute, so `el.assets` is its TEXT (or `undefined`), not the absolute URL the old getter worked out; nothing outside the element read it.
  2. `debug` is an enum (`explorer`, `things`, `console`): an unknown value now warns in development (`did you mean ...?`) where it was ignored silently.
  3. Both set `delegatesFocus: false`: clicking a program's text mustn't move focus to its first button; Monaco takes focus where clicked.
  4. The texts "Give <spell-app> a project or src to run.", "Waiting for its editor, {editor}, to compile…", "Give <spell-editor> a project to edit." and "Nothing compiled" are vocabulary texts (translatable); the editor shows the English one while the runtime is still loading.

Also: `dropsPushedCode()` became `pushedKey()` + `PUSHED_FOR` (an `@onChange` on those attributes drops pushed code whose key no longer matches), and `DEBUG_PANES` is gone (the vocabulary lists the panes).
