Both elements keep their API: four small differences.

  • as before:
    • every attribute is still a property (app.project = ...)
    • run(), restart(), pushed, compile(), save(), compiled, COMPILE_DELAY
    • the spell-open / spell-compiled events

What differs:

  1. assets is now a vocabulary attribute, so el.assets is its TEXT (or undefined), not the absolute URL the old getter worked out; nothing outside the element read it.
  2. debug is an enum (explorer, things, console): an unknown value now warns in development (did you mean ...?), where it was ignored silently.
  3. Both set delegatesFocus: false:
    • clicking a program's text mustn't move focus to its first button
    • Monaco takes focus where clicked
  4. The status messages are vocabulary texts (translatable):
    • "Give <spell-app> a project or src to run."
    • "Waiting for its editor, {editor}, to compile…"
    • "Give <spell-editor> a project to edit."
    • "Nothing compiled"
    • the editor shows the English one while the runtime is still loading

Also, inside the elements:

  • dropsPushedCode() became pushedKey() + PUSHED_FOR: an @onChange on those attributes drops pushed code whose key no longer matches
  • DEBUG_PANES is gone: the vocabulary lists the panes
  • pages and scripts that worked keep working; el.assets reads differently
