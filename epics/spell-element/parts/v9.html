Show and hide each overlay by its visible attribute, on Spell UI's pages from this branch's page server: the modal, popup, flyout, dimmer and loader.

  • The pages: each family's own page on Spell UI's site, under /ui/components/ (ui-modal.html ...).
  • Edit the attributes in the browser's dev tools, on a live example.

What should happen, on each of the five:

  • The page's own buttons still open and close it, with the same look as on main.
    • Each keeps its own sheet's transition as its default (J103).
  • Add visible: it shows, animating. Remove it: it hides again, since these five start hidden.
  • Add hidden instead: it hides with the same animation, not at once.
  • In the console, set the property: $0.visible = true shows it, $0.hidden = true hides it.
  • The old names do nothing now: open on a modal, popup or flyout, active on a dimmer or loader.
  • Set another animation on one, animation="fly down" on a modal say: it comes in that way, and goes out the same way.
  • Closed by Escape or its close button, a modal sends two events, each carrying { visible: false }:
    • ui-close, before it hides
    • ui-hide, once the animation is done
    • Watch them with monitorEvents($0, ["ui-close", "ui-hide"]) in Chrome's console.
  • The themes picker in the docs header still opens and closes, and its tooltip mutes as before (J105).
  • Nothing in the console.
