Chose to move every family whose disabled was only Fomantic's look, and keep "its own" on the rest, over moving all of them, because inert hides content from screen readers and find-in-page (J55, Q12).

  • Moved to "unusable": form, fields, field, tab, items, comments, comment, feed, event, segments, segment, section (and panel), labels, label, images, image; brand's field
  • Kept, a native control of their own: form controls, <ui-button>, <ui-step>, <ui-item> (an option in menus, dropdowns, selects: inert would drop a disabled option from the accessibility tree; <ui-items>, the group, did move)
  • Kept, something else: <ui-loader> (hidden), <ui-dimmer> (never shows), <ui-transition> (pauses), <ui-reveal> (never reveals)
  • Kept, only a look on text or a glyph, as J60 did for the epic text classes: <ui-header>, <ui-text>, <ui-icon> / <ui-icons>, <ui-emoji>, <ui-progress>
  • a disabled segment, label, comment, section ... can't be clicked, focused or read by a screen reader inside; aria-disabled on the element
  • their own isDisabled / :state(disabled) / aria-disabled code is gone (the base class does it); a link label or image still drops its href
  • field, fields, form and brand's field still write inert on their root themselves, so the static render stays inert
  • visual tests: no diff
