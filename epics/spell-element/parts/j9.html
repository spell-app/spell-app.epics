An app hands its ui-* elements a value by setting the appContext property of a <ui-root> around them; a component reads it as UIComponent.appContext (the context decision, Q9).

  • UIComponent.appContext is the appContext of the nearest <ui-root> (found under its translated alias too), looking out through shadow roots
  • it is a plain property, so a value set before the tag is defined survives the upgrade
  • the Solid host page, tools/frameworks/solid/app.tsx, now wraps its dropdown like this: 
    <ui-root prop:appContext={APP_CONTEXT_VALUE}>
  <ui-dropdown … />
</ui-root>
  • UIComponent.AppContext, the Solid context, is gone: it could not reach inside an element once each element has its own Solid root
  • an app’s value reaches a component only through a <ui-root> around it
  • yarn smoke’s Solid page still reports contextReachesComponent true, through <ui-root>
