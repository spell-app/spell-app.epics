The new names in P12:

  • <ui-divider spacer> is Fomantic's hidden divider; <ui-reveal unclipped> its visible reveal.
    • Both were J57's examples.
    • The class words inside stay hidden / visible.
  • In Spanish, animation is animacion, in the Spanish shared names.
  • :state(still): the element's own animation="none".
    • So the reset sheet (reset.css) stills a translated tag too: it sets --ui-motion: none by the state.
    • An attribute selector only knows English.
  • :state(hiding): a hide animating out. :state(hidden): hidden, and done.
  • The shared visible spec has no default of its own: the docs say it's the family's.
  • two new shared states in every tag's docs data
