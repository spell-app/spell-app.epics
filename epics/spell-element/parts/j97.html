Chose display default immediately for <spell-app> over the root's skeleton, because that's how it drew before (its inner <ui-root display="immediately">), and a program drawing into a hidden box (display: none while skeletons show) could measure itself wrong.

  • immediately (chosen): the runner draws as its widgets arrive, as today
  • skeleton / when-ready: no flash of undefined widgets, but the app waits up to the timeout
  • a page can still ask for display="when-ready" on a <spell-app>
