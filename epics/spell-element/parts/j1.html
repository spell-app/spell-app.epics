Bring It In (P1) COPIES solid-element’s source into ui; it doesn’t move it. The package solid-element stays whole until Package Goes (P5) deletes it.

  • the copy is in solid-element, file for file, unchanged
  • its Vite plugin (hot reload for elements) is copied to HotElements.ts
  • nothing imports the package any more, but it still builds and passes its own tests
  • why not delete it now:
    • every phase ends green (Q14); a copy keeps P1 small and easy to check
    • deleting the package, its scripts and its docs is P5’s whole job, planned with everything that names it
  • cost: until P5 the same code is in the repository twice, and a fix made in one copy isn’t in the other
  • ui, app, brand and docs run on ui’s copy
  • solid-element is still there, unused, until P5
  • a change to the element layer before P5 goes into ui’s copy only
