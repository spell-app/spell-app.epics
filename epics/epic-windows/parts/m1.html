1. Have ready: PowerShell, Developer Mode on (Settings, System, For developers), Git for Windows, Node 24, VS Code with its code command, and GitHub's gh, logged in (gh auth login). 2. Clone Spell and install it: ``` git clone https://github.com/spell-app/spell.git cd spell corepack enable yarn install ``` 3. Install the epic plugin and the VS Code extension: ``` node epic/bin/epic plugin install ``` 4. Restart VS Code.- Both commands finish with no error. - In VS Code, the Extensions view lists the epic extension. - A new terminal finds epic: epic --help prints its commands.

Paste everything the failing command printed, and a screenshot of any error in VS Code.
