A generated editor can’t be saved, tweaked by hand, or kept in step with its schema.

<ui-property-editor source="ProjectSettings.editor.html"> loads a plain-markup page, which the spell editor writes from a schema.

A check-and-fix tool keeps the page in step as the schema changes.

  • The page is plain markup (Q6): groups, order, which control, hints, presets.
  • The spell editor’s “make property editor” writes a default one.
  • The check-and-fix tool:
    • flags a property the page names that the schema dropped, or removes it with a fix
    • adds a new property to an “Other” group
    • flags a control that no longer fits
  • Its command’s home and name proposed first (C8).

The spell editor has no running program to read a type from, so a type's schema comes from the running class when there is one, else the project's compiled declarations (Q18); and the check grows spell check (Q17). The server had to list .editor.html files for the editor to show a written page.

  • Where to see it:
    • Spell UI's Property Editor page, Pages: From a page (a layout loaded with source)
    • the editor's file menu, New Property Editor...
    • spell lint on a project with an *.editor.html
  • <ui-property-editor source> loads a saved page's layout.
    • Same-origin only: the spell editor hands it a /spaces/ URL.
    • select takes part of it, and a group's select its own part.
    • Events: ui-loading, then ui-loaded.
  • PropertyEditorPages: write a type's default page, check a page (dropped, missing, a misfit control), fix it (an Other group, each group on lines of its own).
  • SPACES.TypeSchemas: a type's properties from its project's declarations (they can't tell worked-out properties apart: a page lists them too).
  • New Property Editor... (the app): pick a type; writes <Type>.editor.html (never over one: Card2); the running class when the editor ran this project, else the declarations. Checked with a real write in a temporary project.
  • spell lint lists each page's problems by file, line and column (path:line:col). --fix fixes them.
  • The server lists editor pages, .editor.html files, so the editor can show one it wrote.
