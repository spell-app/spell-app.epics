A generated editor can’t be saved, tweaked by hand, or kept in step with its schema.

<ui-property-editor source="ProjectSettings.editor.html"> loads a plain-markup page, which the spell editor writes from a schema.

A check-and-fix tool keeps the page in step as the schema changes.

  • The page is plain markup (Q6): groups, order, which control, hints, presets.
  • The spell editor’s “make property editor” writes a default one.
  • The check-and-fix tool:
    • flags a property the page names that the schema dropped, or removes it with a fix
    • adds a new property to an “Other” group
    • flags a control that no longer fits
  • Its command’s home and name proposed first (T2).
  • ui: the page loader
  • packages/app: the editor’s “make property editor”
  • packages/cli: the check command
  • commands.json5
  • a round trip on Project Settings: generate, hand-edit, change the schema, check, fix
