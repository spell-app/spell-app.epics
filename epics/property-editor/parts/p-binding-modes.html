<ui-form>’s binding has no debounce, no “on leave”, no Save / Cancel, and no “mixed” value for many things.

FIELD properties on <ui-field>: debounce, on leave, mixed. A FORM property: <ui-form apply="immediately | on save">.

The binding carries both, edits many things at once, and runs the vocabulary’s validation and “on change” rules.

  • On each field (and so on each <ui-property>):
    • debounce: a text field waits for a short pause before it writes
    • on leave: writes only when the cursor leaves the field (an id, say)
    • mixed: a blank “mixed” state when the things edited disagree
  • On the form: apply="immediately" (the default) or apply="on save", which holds every change until Save; Cancel drops them.
  • No commit-mode list on the form.
  • Many things: a field shows the value they agree on, or mixed; a write sets it on all of them.
  • Validation comes from the vocabulary; a value that fails is not written.
  • “On change” rules run after a write (setting A changes B, or B’s choices).
  • FormBinding.ts, FormFields.ts
  • UIField.tsx, UIForm.tsx and their vocabularies
  • a mixed state on input, select, slider and menu
  • ui-form’s existing tests, unchanged
  • new tests for each field mode and each apply
  • three things with one differing value: mixed shows, a write sets all three
