What shape is the ONE description of a property that the editor reads?

  • Today's sources are unrelated shapes: spell's property info, a component's vocabulary, JSON Schema.
  • None has labels, limits, patterns, groups or "on change" rules (see 1.3).
  • a PropertySpec type in Spell UI, with an adapter per source
  • the sources themselves don't change shape; each may grow the fields it can fill (a spell class's limits, later)
  • says exactly what the editor needs, typed
  • one more shape to keep in step with the sources
  • a standard; tools read it
  • clumsy for options from a function, ordered scales, commit modes; most of it would be x- keywords anyway
  • already live at run time (describe())
  • it describes attributes (text), not values of any type; spell classes would have to fake being components
