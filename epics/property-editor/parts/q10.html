Approved on the vocabulary review page, 2.2.

  • schema: what it edits.
    • a spell class (Theme), a tag (ui-button) or a registered JSON schema
  • value: the thing it edits, or a list of things, edited at once.
  • source: the layout page (was layout).
    • a spell path inside the spell editor (the review page’s Q12)
    • anywhere else, a full URL
  • select: a CSS selector; only its first match in the layout page is used.
  • As the field’s:
    • readonly
    • output
    • error
  • Events:
    • ui-change: a property was written ({ name, value, things })
    • ui-loading, then ui-loaded: the layout page
  • Methods, as ui-form’s:
    • save()
    • cancel()
    • validate()
  • Its editor part is its outer box.
    • As ui-form’s is form, and ui-section’s section.
  • Texts: “Save”, “Cancel”, and “Other”, the group for properties the layout doesn’t place.
