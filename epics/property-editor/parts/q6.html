What IS a saved Theme.editor.html, and what does "compiled" make of it?

No web component is written as an .html file today: every one is a folder of TypeScript.

  • the page is plain markup (1.2's example), that a <ui-property-editor src="Theme.editor.html"> loads as it is
  • compiled: one TypeScript module defining <theme-editor>, its rules inlined, for use without spell or the loader
  • runs with no build; easy to tweak and to check
  • a loader and a compile step to write
  • rules and layout in one spell file
  • needs spell syntax for every layout choice; needs the parser to run
