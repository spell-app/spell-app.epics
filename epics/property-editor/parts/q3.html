Where does what the FORM needs live: in the schema, or in the .editor.html page?

For example, for "Text size": its label, its tooltip, that it's in the Type group, that it shows as a slider, its hint, its Reset preset.

  • the schema carries what's true of the property anywhere: type, choices, default, label, tooltip, validation, on-change rules
  • the page carries how this one form shows it: groups, order, which control, hints, presets
  • a page with nothing in it still works: every property, in schema order, default controls
  • a second form on the same class gets the labels and rules for free
  • two places to look
  • the page can be generated every time
  • spell classes need a lot of new syntax for layout
  • everything in one file
  • every form repeats every label and rule; translation keys scatter
