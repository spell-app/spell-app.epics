Nothing turns a vocabulary into fields.

Three new elements: <ui-property-editor> on <ui-form>, <ui-property-group> on <ui-panel>, and <ui-property>, a grown <ui-field> that picks its control.

  • <ui-property> picks its control by type, or by as=:
    • input, select, checkbox, colour
    • a slider with named steps, for an ordered scale
    • a segmented menu as a button group
  • Presets as action buttons; a property whose value is a thing nests a whole editor.
  • An empty editor shows every property, in vocabulary order, with default controls.
  • Works in a side bar, a modal (apply="on save") and a popup.
  • packages/ui/components/ui-property-editor/ (new)
  • their docs pages, in packages/ui/docs/
  • the docs pages show each control kind, many things, a modal with Save, nesting
