--fix writes each page back, then lists each fix as path:line:col fixed: <problem> -- <what it did>, where the problem WAS on the page.

  • Exit 0 when every problem was fixed; what it can't fix (no editor, a schema naming no type) still counts, exit 1.
  • With --json, stdout stays the JSON of what's left, so the fix lines go to stderr.
  • Editor pages are checked only for a whole project, not for a lone .spell file argument.
  • Pages: every *.editor.html in the project's folder and below, skipping hidden folders and node_modules.
  • A test project's page (spell-lang/tests/spaces/@spell/test/) is never written: its problems stay, plus one saying so, as spell format refuses.
