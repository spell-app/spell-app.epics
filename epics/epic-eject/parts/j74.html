spell-epic's config sets windowsFolder to workspaces, where its window file already is.

  • Both repos name ../spell-app.epics as their content folder, so the default would put spell-epic's windows in spell-app's windows/.
  • Then epic window init and epic stock in either repo would treat the other repo's worktree windows as their own (refresh them, or list them as dead).
  • Nothing of spell-epic's moves, and its window needs no reopening.
