Problem: a content-folder file names no checkout, and the doc preview calls SRV.mainServerUrl(file) with no from. Options: (1) every caller passes from, which needs a change in spell-epic that won't compile against main until the cutover; (2) look beside the content repo for the checkout whose page server's pid file names it (contentServerOf()). Picked (2), with from still used first when a caller gives one. The page server writes its pid file after the route modules load, so the file carries contentFolder. The URL path itself comes from the live /api/server. Downside: if no main server is running, or it started before P12 (no contentFolder), you get the old fallback, the content repo's own server.
