Every template is spell-epic's own templates/. Both page servers serve it at /templates/ (the epic server at /r/<repo>/templates/ too; spell-app's at /worktrees/<w>/templates/ too), not under /_epic/, because every page links the Templates tab as ../templates/index.html. So a content folder can't hold a templates/ of its own. The tools still call a template's path templates/..., wherever spell-epic is (pagePath()). Skills reach plan-doc.md through ${CLAUDE_PLUGIN_ROOT}/templates/, and epic pages template <name> prints any template's path. spell-epic's copies were already newer than the shared ones (the shared ones differed only by formatter wrapping and the old packages/epics paths), so they were kept as they are. The page editor no longer writes templates, since templates are now code, edited in spell-epic.
