Each repo's epic settings live in one file, .epic/config.json5, read the way every other tooling data file is read (DataFile).

  • Main's rule since epic-workflow: every tooling data file is .json5, so it can carry comments.
  • The reader is the one the rest of the epic code already uses, so there's nothing new to learn.
  • EpicConfig (P4) reads .epic/config.json5, not .json.
  • epic init (P9) writes that file.
