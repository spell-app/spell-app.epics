The new optional key repoTemplates in .epic/config.json5 names a folder from each checkout's root. Its default is "", meaning none, and epic init writes that. epic pages new and epic pages template look a name up there first, so a repo can replace one of the engine's templates. Its templates get their own list page, <repoTemplates>/index.html, and stay off the engine's Templates page, so that page is the same for every repo. epic pages index rewrites the engine's page only when its templates changed (sameList()), so the reindex that runs on every epic write leaves spell-epic's tree clean.
