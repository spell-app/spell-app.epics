Chose today's layout for a new repo's settings, over spell-app's off-by-default values:

  • worktreeOnly: true
  • linkSessionFolders: true
  • installOnCreate on, only when there is an install command
  • Why: a new repo has no old worktrees to keep working, and these are what the morning's runbook (T19) sets for spell-app anyway.
  • The install command comes from the lock file: yarn.lock, pnpm-lock.yaml, package-lock.json ...
    • With none it is "", which now means "nothing to install": the hook and the skills skip it.
  • worktrees beside the repo, each in a window of its own
  • every window lists every session
  • worktrees inside the repo, the old window layout
  • epic config installCommand may print an empty line: /isolate and /epic skip the install then
