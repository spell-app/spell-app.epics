• contentFolderOf(root) (the assembler's contentFolder.ts, opt-in by path, plain-node loadable): SPELL_SHARED_DIR, else contentFolder in the MAIN checkout's .epic/config.json5 (main found as the repo's common folder's parent); undefined without one, and callers fall back to the checkout (an old link). The assembler still imports no package.
  • Linker takes content (default contentFolderOf(root)): each content folder the checkout has no real folder of (none, or an old link) is a served folder, root/epics = content/epics. Hrefs and targets are the same as through the links (checked on three real pages: same problem counts, link() leaves them unchanged). link() / check() take a page's folder either way (they call servedDir() themselves). A missing link into the content folder is checked against the content repo's ignore rules, not the checkout's (which still ignores the old link names).
  • CLI: spell commands finds its checkout by tsconfig.base.json and reads commands.json5 from the content folder; pack new writes it there; the WWOD check reads goals/AGENTS.md and guides/solid/solid-2.md there (agents/wwod stays through the link).
  • spell server url on a content file: its path in the content folder, on main's server if it runs (mainServerUrl(file, from)), else this checkout's (contentPathOf()).
