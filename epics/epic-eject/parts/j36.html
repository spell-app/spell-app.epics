Chose a key in the epic settings (.epic/config.json5) for the shared folders a checkout links, over a "shared" block in package.json.

  • Why: a repo that isn't a node repo has no package.json.
  • spell-app's package.json block still wins, so its branches keep their own lists (the reorg changed them).
  • epic init writes epics, sagas, guides, pages.
    • Not spell-app's brand, ui, goals, agents.
    • Nor templates, which are spell-epic's (Q8).
  • sharedFolders; its default is the old eight, so nothing changes for spell-app
  • a repo without node can't say which folders it links
  • epic shared link, the window files and the docs tools read the list from the config when no package.json names one
