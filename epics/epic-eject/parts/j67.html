pagePath(): a file in the content folder (named there, or through any older checkout's link: real paths compared) is epics/..., guides/...; the engine's templates templates/...; anything else from the checkout's root (packages/brand/x.html), which the page server still serves at / first. pageAt() turns one back: the content folder when the file is there or its top folder is one of the content folder's and NOT a real folder of the checkout (so packages/... stays the checkout's, though the content repo has a packages/docs/content of old-path links). throughLink() is gone; inContent() maps the other way, a link path to the content folder's.
