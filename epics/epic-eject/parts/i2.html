  • One beside the repo can't: the Vitest extension, TypeScript and the tools find nothing until yarn install runs there (about 4s).

Fix in P8: the WorktreeCreate hook runs the repo's install command BEFORE the window opens, so nothing starts without it.

Built in spell-epic (P8, not live until the switch): the worktree hook runs installCommand in a NEW worktree before it answers, so before EnterWorktree returns and before any window opens.

  • On with "installOnCreate": true in .epic/config.json5 (off by default: the skills still run it after entering, as today); installTimeout bounds it (600 seconds), and the hook's own limit is 900 seconds (hooks/hooks.json).
  • A failed or timed-out install fails the hook (J27): the worktree is kept, and the message says to run the install there by hand, then EnterWorktree with its path.
  • Tested on a throwaway repo (tests/epics/src/command/WorktreeHook.test.ts): runs in the new worktree, fails on a bad exit and on the timeout.
