Seen in P2's test window (2026-10-10): three "Vitest not found in epics / server / try-layout" warnings at startup. A worktree nested inside main (today's .claude/worktrees/) borrows main's node_modules, since node looks up the folder tree. One beside the repo can't, so the Vitest extension, TypeScript and the tools find nothing until yarn install runs there (about 4s).

Fix in P6: the WorktreeCreate hook runs the repo's install command (EpicConfig) BEFORE the window opens, so nothing starts without it.
