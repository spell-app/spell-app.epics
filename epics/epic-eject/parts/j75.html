When the old folder is there and the new one isn't, windowsFolder means the old folder.

  • Why: spell-epic is live the moment it's committed, and other sessions run epic window while the move waits.
  • So the move itself is the switch: the first file it writes makes the new folder, and from then on every tool uses it.
  • Windows still open from an old file are recognised too (packageOf(), the prompt gate's worktree check).
