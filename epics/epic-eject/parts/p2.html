The new layout rests on two untested guesses about Claude Code.
  • A throwaway worktree beside the repo, its session folder linked to main's.
  • Opened in a window that holds only the worktree and the shared content.
  • Owen tries the layout by hand, in the order it would happen:
    1. Make a worktree beside the repo: git worktree add ../spell-app.worktrees/try-layout.
    2. Link its saved-session folder (under ~/.claude/projects/) to main's.
    3. Open a window with only ⎇ try-layout and spell-app-dev in it.
    4. Start a session there, then find it from main's window and from another worktree's window.
    5. Resume it from the other window, then hand it off to a new window.
  • What Claude Code does is written down:
    • to the linked session folder: kept, replaced, or renamed aside (.superseded-*)
    • whether auto mode refuses anything
    • whether entering that worktree from the main checkout works
  • The outcome is a decision: link the session folders, or fall back to a Sessions view in spell-epic's extension (Q4).
