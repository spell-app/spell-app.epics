Chose to hide the old spellings of the moved verbs from spell dev --help, as plan-doc already is, over keeping them listed.

  • The verbs: spell dev window, worktree, park, session, stock and shared.
  • Each runs the same class or tool epic does, with its arguments as typed: no new refusals for old callers.
  • spell dev --help says where they went, and that the old spellings still work.
  • Their flags are now read by the classes themselves: --json, --all, --limit 3 ... as before.
    • The one difference: a global flag typed BEFORE dev no longer reaches the verb; after it, it does.
    • e.g. spell --all dev session list
  • One place lists them: epic --help
