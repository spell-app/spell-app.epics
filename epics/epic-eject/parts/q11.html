A shared page opened from a worktree now loads from main's server, so it looks the same everywhere.

  • Shared pages: epics, guides ... : one file in every checkout.
  • Before: it loaded through that worktree's server, so it drew with the worktree's old page code.
  • Now a link or the side bar sends it to main's server:
    • SRV.mainServerUrl() serves shared content from main's root
    • a link made from the shared repo's real path goes through the checkout's link to it (throughLink() in pages.js)
  • Why: the epic page is the same file everywhere, so it should look the same everywhere.
