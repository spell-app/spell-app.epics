A shared page (epics, guides ... : one file in every checkout) opened from a worktree used to load through that worktree's server, so it drew with the worktree's old page code. Now a link or the side bar sends it to main's server: SRV.mainServerUrl() serves shared content from main's root, and a link made from the shared repo's real path goes through the checkout's link to it (throughLink() in pages.js). Why: the plan doc is the same file everywhere, so it should look the same everywhere.
