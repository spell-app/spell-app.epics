Chose to have both servers serve both kinds of path, over making the migration and the switch happen together, because then neither has to wait for the other.

  • The epic server serves the OLD asset paths from the engine: an overlay, legacyEnginePath().
  • spell-app's page server serves /_epic/ from its own epics package (engineRoutePath()).
  • Migrate before or after the switch
  • Old-path pages on the epic server load spell-epic's engine, not spell-app's copy
  • Migration and switch in one step
  • The migration can run any time after epic-eject merges into main
