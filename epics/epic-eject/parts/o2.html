Move the epic tooling out of spell-app into its own repo, the Epic Kit: ONE copy per machine, that every repo and every window runs.

  • A new repo beside spell-app, with its own git history. Working name epic-kit; the command name is Q6.
  • It is NOT a worktree per spell branch: spell-app's worktrees don't carry any epic code.

It ships as a Claude Code plugin

A plugin is Claude Code's package of skills, hooks and commands, switched on per machine. The kit is loaded in place: from a local-path marketplace, a folder on this laptop that Claude Code reads the plugin from directly, so an edit there is the plugin, with no copy and no install step in between (plugin docs, "in-place and copied plugins").

What the plugin holds:

  • The skills:
    • planning: epic, epics, details, comment, docs-check
    • worktrees and sessions: isolate, park, unpark, wait-for, worktrees, session, title, wtf
    • background and offline: bg, bedtime, airplane
  • The hooks: making and removing a worktree, the prompt gate, and the end-of-turn hooks. Their paths start at the plugin's own folder (${CLAUDE_PLUGIN_ROOT}), not at spell-app.
  • The epic command-line tool: today's spell dev plan-doc, window, worktree, shared, agents, details, session, park and stock commands. It is on every session's path while the plugin is on.

Around the plugin

  • Its own VS Code extension: the Review tab, a Sessions view (O3), the window bridge. Split out of the spell language extension.
  • Its own page server, built on spell's server package: one per machine, serving every repo's epics.
  • Per repo, ONE config file (.epic/config.json, say), naming:
    • the shared-content folder
    • the base branch
    • the install command
    • where worktrees go
    • which folders are linked from the shared content
  • spell-app becomes the kit's first user. spell dev plan-doc stays, as an alias for the kit's command.
  • The kit depends on spell's UI, server and assembler packages; how is Q5.
  • Staying in spell-app, since they're about spell itself: WWOD, fussbudget, design, solid-2, goals, spell-docs, spell-serve.

What changes for Owen

In order, the next time he improves the epic tools:

  1. He edits a skill or a tool in the kit's folder (~/www/epic-kit). A small change needs no worktree.

  3. The skill's new TEXT reaches a running session after /reload-plugins, or in any new session.
