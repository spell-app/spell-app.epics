What should happen, with an epic's window already open and its session running there:

  • From another session, run epic window launch <name> --prompt "/epic request <name> rN".
  • The epic's window keeps its colours.
    • Its window file, workspaces/ongoing/<name>.code-workspace, is unchanged: same bytes, same modified time.
  • No second session starts: the prompt is typed into the epic's running session, and launch prints "... is running: ... typed into it, in its window (nothing opened or recoloured)".
  • Close that session (window still open) and launch again: ONE new session in the window, prompt typed in, colours still unchanged.
