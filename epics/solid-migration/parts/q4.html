Compiled spell's React output inside the Solid runner is a React island, and with P5 gone that one stays. The question is which way the app's own UI converts.

Recommend A: one adapter, which we need anyway, and no throw-away code. Phase ids stay; only the order changes.

  • ONE adapter (Solid hosts React), the same one spell output needs anyway
