The Type and Thing explorers (ported in P6d, part of P6) use ui-* tags but don't load them. Whoever mounts one in a runner must import ./loadUI first, or the tags never draw.

  • The files: TypeExplorer.tsx and ThingExplorer.tsx.
  • They import their peers directly, not the $/app/solid barrel. The barrel would pull $/app/editor into the runners' bundles, through Actions.
  • They don't import ./loadUI either: it throws under node, where their tests render.
