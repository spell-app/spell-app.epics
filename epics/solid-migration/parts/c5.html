The app's own UI is Solid now, but a compiled spell program still draws with React, so a page showing one runs both. This is the case since the Core + JSX Emit phase (P5) was dropped.

  • Where: <spell-app> and the runner mount the program's React tree inside UI that Solid draws.
  • The Web Components + Runner phase (P7) had to keep React's root mount (App.start()) working inside a Solid host and a shadow DOM.
  • Done since (noted in the Doc Review phase, P10; built in P7 and P8): the program draws with React, from its own spell-runtime.js.
    • into <AppRoot>'s element, through editor.setAppRoot()
    • or into <spell-app>'s shadow root
  • What stays: two renderers per page, React only in spell-runtime.js. Tracked in CODE-DEBT.md, "app", "React for spell programs, beside the app's Solid".
