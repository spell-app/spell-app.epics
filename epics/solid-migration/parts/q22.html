<spell-app> / <spell-editor> are customElement()s (@spell-app/solid-element) with BaseElement holding their methods (run(), restart(), compile(), save(), assets). Every attribute is now a property too. Code an editor pushed is the property-only prop pushed, dropped by an addPropertyChangedCallback when project / src / scopes / name / editor change. The editor keeps its state in ownedWrite signals the component draws. Leaving the page disposes a microtask later, so a same-tick move keeps the app. <spell-app> wraps its shadow root in <ui-root icons=fomantic display=immediately>; the VS Code webview HTML wraps #runner-root the same way.
