The Solid console view (src/solid/ConsoleLines.tsx) is also used by the VS Code runner, which must not load the editor. So it imports ./tracked directly, never the $/app/solid barrel.

  • Why: the barrel pulls in Actions, and through it $/app/editor.
  • The runner's RunnerConsole (P7) imports ConsoleLines.tsx directly, as React's version did.
  • ConsoleLines' lines is a plain value, not a signal:
    • the caller tracks the top level: tracked(() => console.lines)
    • each group tracks its own lines and collapsed
