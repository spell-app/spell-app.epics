Decided before the pause; the why and measurements are in guides/solid/solid-2.html.

  • Taken with Owen: @spell-app/ui from SOURCE; CLEAN BREAK in spell JSX (no SUI.*, raw <ui-*> tags, class=); INCREMENTAL phases, each green, stop for review after each.
  • Solid 2 facts that force the design (measured):
    1. writes are staged: read right after write returns OLD value until microtask / flush(). Spell is imperative (set then print must be exact), so spell state can't be Solid signals
    2. write feeding pending async is HELD with its whole batch (entanglement): even flush-per-write can read stale
    3. no writes in owned scope (dev throws; untrack doesn't exempt); no mutable store
    4. one Solid per page; one uncaught error halts the page's whole scheduler
  • Spell cells -- BUILT (P11, D25-D29): each instance keeps a Map record, the ONLY truth, read and written synchronously. Small sync core (cells + memoized derived values, equality cutoff); one enableExternalSource bridge tells Solid, installed by the HOST (bridgeSolid(), packages/app/src/solid/cellsBridge.ts); spellCore.flush() = pending derived checks, then Solid's. Prototype: experiments/spell-cells.core.ts.
  • Accessors for Things, Proxy only for class-less data (editor's nested plain data, JSON): a Proxy costs ~2.5-6x on every access. Accessors BUILT; the Proxy NOT (no proxies at all: a value changed in place notifies nobody, C17).
  • Decorators for hand-written classes -- BUILT (P1, P11): @prop({ type, default }) accessor, @derived, @thing (runs create() after all field initializers, D8). Used by EditorStore, SpellConsole, FormStore. Prototype: experiments/decorators.ts.
  • Compiled output: no decorators (runs from a blob: URL); accessor pairs + class schema -- BUILT (declareProp(), D27). JSX THUNKS and element() on @solidjs/h -- NOT built: compiled spell draws with React (D9, T2).
  • Bundles -- BUILT (P7, D21): Solid + @spell-app/ui in ONE shared spell-solid.js (+ spell-ui.js) across element / runner / editor builds, never in spell-runtime.js. The import-map <spell-app> variant for host pages already running Solid: NOT shipped (T5).
  • Added while building: Solid by default, React files marked (D11); the app UI loads $/ui once, Fomantic icon names via <ui-root icons="fomantic"> (D15); @solidjs/router@next (D23); AST views as framework-free P.Markup (D24).
