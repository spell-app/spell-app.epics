The app's promptForNumber() needs a number field, but ui's prompt dialog only takes text options. So the app patches the dialog's input after ui builds it.

  • It needs type=number, with a min, max, step and placeholder.
  • ui's ModalOptions has only:
    • title
    • message
    • okText
    • cancelText
    • value
  • The HACK: fitInput(), in dialogs.ts.
    • it sets them on the input of the dialog that ui just appended to the body
    • and it vetoes ui-approve while the input is invalid
  • The fix: an input option (type plus attributes) on ui's ModalOptions, then drop the hack.
  • Still so on 2026-10-04: ModalOptions has no input option.
  • ModalOptions gains an input option
  • fitInput() goes away
