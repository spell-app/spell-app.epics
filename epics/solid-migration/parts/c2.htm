Solid 2 is still a release candidate, so behaviour can change between bumps. The experiments that back our Solid rules must be re-run on each one.

  • The experiments: guides/solid/experiments/*.
  • SOLID_NODE_MODULES=<dir> picks the Solid version they run against; without it, the repo root's.
  • Diff the output against the last run.
  • Update solid-2.md with anything that changed.
