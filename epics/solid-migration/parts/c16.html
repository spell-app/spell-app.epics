The runners import spell-app/app/solid/loadUI, which calls UI.icons.use('fomantic') for the whole page. On a host page that uses @spell-app/ui itself, loading <spell-app> switches the host's clashing icon names (27, e.g. x, warning) to Fomantic's. The runner's own icons don't need it: its shadow root has a <ui-root icons=fomantic>. Fix: a loadUI variant without the page-wide use() for the element bundle.
