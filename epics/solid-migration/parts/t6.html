Every compiled derived property is a plain getter today, re-computed on every read. The plan is for the parser to memoize the pure, costly ones.

  • The plan: solid-2.md and solid-2.html, §5.
  • A "pure / worth-it" analysis would pick derived properties that loop over or aggregate lists, and the parser would emit this.derive(name, fn) for them: memoized, with an equality cutoff.
  • Cells already support it: Derived and derive(), from the Spell Cells phase (P11).
  • But the parser emits no derive() yet.
  • It belongs with the Core + JSX thread (T2).
