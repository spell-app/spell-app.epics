  • Taken with Owen:
    • ui from SOURCE
    • a CLEAN BREAK in spell JSX: no SUI.*, but raw <ui-*> tags
    • and class=
    • INCREMENTAL phases, each green, with a stop for review after each
  • Solid 2 facts that force the design (measured):
    1. writes are staged: read right after write returns OLD value until microtask / flush(). Spell is imperative (set then print must be exact), so spell state can't be Solid signals
    2. write feeding pending async is HELD with its whole batch (entanglement): even flush-per-write can read stale
    3. no writes in owned scope (dev throws; untrack doesn't exempt); no mutable store
    4. one Solid per page; one uncaught error halts the page's whole scheduler
  • Spell cells, BUILT (P11, D25-D29): each instance keeps a Map record, the ONLY truth, read and written synchronously.
    • a small sync core: cells, and memoized derived values with an equality cutoff
    • one bridge tells Solid (enableExternalSource), installed by the HOST. That's bridgeSolid(), in cellsBridge.ts
    • spellCore.flush() runs the pending derived checks, then Solid's
    • the prototype: spell-cells.core.ts
  • Accessors for Things, Proxy only for class-less data (editor's nested plain data, JSON): a Proxy costs ~2.5-6x on every access. Accessors BUILT; the Proxy NOT (no proxies at all: a value changed in place notifies nobody, C17).
  • Decorators for hand-written classes, BUILT (P1, P11):
    • @prop({ type, default }) accessor and @derived
    • @thing: runs create() after all field initializers (D8)
    • used by the editor store, the spell console and the form store
    • the prototype: decorators.ts
  • Compiled output: no decorators (runs from a blob: URL); accessor pairs + class schema -- BUILT (declareProp(), D27). JSX THUNKS and element() on @solidjs/h -- NOT built: compiled spell draws with React (D9, T2).
  • Bundles, BUILT (P7, D21):
    • Solid and Spell UI in ONE shared spell-solid.js, plus the docs' spell-ui.js
    • shared across the element, runner and editor builds; never in spell-runtime.js
    • NOT shipped (T5): the import-map <spell-app> variant, for host pages already running Solid
