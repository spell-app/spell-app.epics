The first is a hang. The agent splitting run-on items into paragraphs ran epic lint on language, epic-engine and editor. Later on the 15th, epic agents done and epic add failed with "epic-engine.plan.html.lock held for 20s: stuck?" while other agents were editing the page. The second is a miscount. T74's check flags an item with a paragraph of 5 or more sentences (DENSE: in epic lint). It counts each item of a numbered list written inside a sentence ("1. Example, 2. Markup, 3. ...") as a sentence of its own. So epic-engine's M12 is flagged by mistake.

Fixing the hang means finding what holds the page lock that long: an edit that is slow while it holds the lock, a migration running on every edit, or a lock that is never freed. While a command waits, it should also say who holds the lock.
