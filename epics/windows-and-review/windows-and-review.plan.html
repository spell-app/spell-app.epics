Owen's requests of 2026-10-06, one epic, phased (windows first, then the review page):

WINDOWS / SESSIONS
1. `/epic <name> -<color>` (e.g. `/epic new-thing -purple`) colours the epic's window; `/epic color purple` switches the colour in the current window.
2. Session names: once a session is completed (e.g. `/isolate done`), rename it to start with a green circle check emoji (✅) so Owen knows it's complete; if the epic re-opens, remove it.
3. Staying in a window on `/epic x` / `/isolate x`: retitle and tint the window live as `⎇ x` (workspace settings `window.title` + `workbench.colorCustomizations`, no reload), restored at `/isolate done`. Owen picked this over reloading the window (2026-10-06). The confusing case: the window title still named the old workspace (docs-sidebar) after the session moved to another worktree.

REVIEW PAGE (plan doc review mode, packages/docs/tools/_assets/spell-doc-runtime.js + plan-doc.css)
4. A "Review Now" button in the page toolbar; can alternate with the `send` button for an epic in review mode.
5. Replace the single `...` button on each item with 4 icon buttons (same icons as the current menu): each starts as a dark grey outline; when chosen, coloured as today. Menu item text goes in each button's tooltip. Rename tooltips: `Add Details` => `Add Details Now`, `Revisit` => `Revisit Now`, `Add to todo` => `Make Todo`. Reconsider the colours chosen for the options (they don't feel right). Toggling an active choice (e.g. approved) turns it off (back to no action).
6. The Details and Revisit buttons switch to a loading spinner while active.
7. `Make Todo` shows the note field where Owen can explain. That field (in all modes) grows as he types.
8. When a response is sent, it's put in the bottom fixed pane, which makes the review window useless if he mentioned a lot of things: show responses somewhere that scales (in the page, by the item).

Related: review-review T1 (Review tab start page) and T4 (`/epic review this`, light plan doc for /isolate sessions) are NOT in scope unless Owen says so.
