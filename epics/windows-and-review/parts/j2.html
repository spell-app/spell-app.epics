A change to a phase's plan (plan-doc updated) is a fenced, dated line under its Symptom / Changes. How long it shows.

  • chose: the fenced block stays for good (it records how the plan moved), unlike the orange UPDATE labels, which go when the phase is done
  • the Plan changes box at the top of the Phases section lists each change while its phase is still to do (todo or active), then drops it
  • why: you see at a glance what moved in the work ahead; finished phases keep their record without crowding the top

Net effect:

  • open a done phase to see what changed in it
  • the top box only ever lists changes to work not yet done
