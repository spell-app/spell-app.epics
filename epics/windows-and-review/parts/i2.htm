Owen, 2026-10-06: Cmd+C, Cmd+V, Cmd+A do nothing in the Spell Docs and Review side bar pages.

  • likely cause: the page is a cross-origin frame inside VS Code's own webview frame; VS Code takes the edit keys and applies them to ITS frame, not the page
  • fix (P2): the page's live client (packages/server/src/liveClient.ts, in every served page), when framed, handles Cmd/Ctrl + C, X, V, A, Z itself: copy, cut, select all, undo / redo through the browser; paste through the clipboard permission the frame already has (allow="clipboard-read")

Net effect:

  • the usual edit keys work in every side bar page
