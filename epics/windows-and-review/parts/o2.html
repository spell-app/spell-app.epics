Before P1, a note typed in a Revisit box was kept only in the browser storage of the page it was on, until you pressed soon or now. 

localStorage, key spell-revisit:<page path>
  • That storage belongs to one exact address, port included: 127.0.0.1:4747 and 127.0.0.1:58173 each have their own.
  • So a note went missing whenever the page came back from another address: a worktree's page server restarted on a new port, or the side bar showing the doc from the main server instead of the worktree's.
  • The page never said whether a note was kept anywhere.

The fix (1.1): the note is saved to the epic's review inbox on the server, which every address reads.

  • the inbox file sits beside the doc: <name>.inbox.json, <name>.inbox.json5 today
  • a note survives reloads, restarts and either server
  • you see "Saved" once it's stored
