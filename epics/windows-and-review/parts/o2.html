A note you type in a Revisit box is kept only in the browser storage of the page you're on, until you press soon or now. 

localStorage, key spell-revisit:<page path>
  • That storage belongs to one exact address, port included: 127.0.0.1:4747 and 127.0.0.1:58173 each have their own.
  • So a note goes missing whenever the page comes back from another address: a worktree's page server restarted on a new port, or the side bar showing the doc from the main server instead of the worktree's.
  • The page never tells you whether a note is kept anywhere.

The fix (1.1): the note goes to the epic's review inbox on the server, which every address reads.

  • the inbox file sits beside the doc: <name>.inbox.json
  • a note survives reloads, restarts and either server
  • you see "Saved" once it's stored
