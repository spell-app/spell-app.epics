The template (templates/epics/plan.html) is shared content: every checkout reads the one file, and older checkouts' scripts look for the notice as a ui-message.

  • chose: the template keeps its ui-message; plan-doc new folds it into an aside as it creates the doc (and migrate folds an older doc's)
  • over: changing the template, which would leave the notice up for good on docs made from main until this branch merges (main's add-phase wouldn't find it to remove)

Net effect:

  • new docs show the notice folded, from any checkout with this branch's code
