An item's line is the <summary part="title"> inside <ui-accordion>'s shadow root, around the slotted <ui-title>. So ui-accordion.plan-item::part(title) can make it sticky from the page's CSS: no ui fix, no runtime style.

  • it sticks at the site header plus its section's --spell-stack, the bottom of the stuck section titles that the runtime already writes for anchors
  • made opaque (the row band over the page's background), like the section titles
  • the runtime counts an open item's stuck line in stuckBottom(), so Page Down and the reading position used by live updates keep clear of it. A link to an id inside an open item lands below the line too (offsetFor())
  • folding an item while you're inside it, from its line or the button, scrolls first so the line stays where it was stuck (keepItemPut(), like the sections' keepTitlePut())
  • no ui-package change. spell-doc-runtime.js, plan-doc.css, and the chevron-up icon in bundle-spell-ui.js
