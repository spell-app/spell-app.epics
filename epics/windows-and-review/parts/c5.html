A window starting up draws the theme colours VS Code cached from the last window that had them; it reads its own colour settings only when they CHANGE (found in P5: a probe opened green came up in an older probe's purple).

  • so epic window open writes the window file without its colours, opens the window, waits until it's up (its registry entry, then 1.5s), and writes the colours then: a live change, which applies
  • you may see the old colours for a second or two while it opens
  • window not up within 60s: the colours are written anyway; any later change to them applies them
  • a window opened with a look shows it within a couple of seconds (orange checked by Owen)
