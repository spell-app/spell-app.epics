What add-phase writes when it's given only --goal (older callers, other epics' sessions).

  • chose: the old shape, Goal / Files / Verify, with no TBD Symptom or Changes
  • with either flag: Symptom, Changes, then the details; the goal optional
  • why: nothing written by an older caller gains empty fields; /epic (SKILL.md, step 4) now passes both
  • new epics' phases read Symptom / Changes / details
