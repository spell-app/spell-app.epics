A window's colours and title are settings in its .code-workspace file. VS Code applies a settings change at once, with no reload.

  • the settings: workbench.colorCustomizations, window.title
  • The tool writes those settings into the window's file itself (epic window stay, epic window color); no extension change and no reload, as Q11's check showed.
  • The one unknown was whether changing a window's file restarts its extensions, the Claude panel included.
    • folder changes have (PAPERCUTS, 2026-10-01 and 2026-10-04)
    • settings-only changes were never checked
    • this window's extensions DID restart sometime between 07:30 and 07:50 that day, while its file was being edited
    • P5 checked it on a throwaway window, before anything relied on it: no restart (Q11, C1)
