The test that fails while a real library's committed files are out of date moves from P3 to P7. P3's goal promised it; P3 doesn't deliver it.

  • There is no real library until P7, which writes Person and Org.
  • Spell's rule is that tests read only the test projects, never live projects. A staleness test has to read a live one, so it's an exception to that rule.
  • So the check comes with the first library, in P7, where that exception is decided.
  • What P3 has instead:
    • a fixture snapshot test: People's library and its types, compiled and compared with People.lib.snapshot.js and its .d.ts
    • the merge rules: libraries are marked generated in .gitattributes, and merge-main's list of generators recompiles a library on a conflict
  • P3 ships with no staleness test
  • P7's goal gains it, as the first test that reads a live project
