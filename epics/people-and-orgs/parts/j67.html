Chose to drop both copies in the cards (fullDate() and readEpicDate()) for PlanDates.formatDate() and PlanDates.read(), over keeping the reader's copy. Two edge cases change: an impossible date (Feb 30) reads as nothing instead of rolling over, and a space before a time zone (14:34 -0400, a form git doesn't write) no longer reads. PlanDates.ts imports its types by file name, so plain node (the docs index) loads it. The running epics also find plan docs by pages.js planDocIn(), which accepts an old-named doc with <epic-page> too, as the docs index does.
