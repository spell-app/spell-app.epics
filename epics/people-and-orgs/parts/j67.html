Chose to drop both date copies in the cards for PlanDates' own, over keeping the reader's copy.

  • fullDate() becomes PlanDates.formatDate()
  • readEpicDate() becomes PlanDates.read()
  • Two edge cases change:
    • an impossible date (Feb 30) reads as nothing instead of rolling over
    • a space before a time zone (14:34 -0400, a form git doesn't write) no longer reads
  • PlanDates.ts imports its types by file name, so plain node (the docs index) loads it.
  • The running epics also find plan docs by planDocIn(), which accepts an old-named doc with <epic-page> too, as the docs index does.
  • one date rule for every Epics card and epic page
