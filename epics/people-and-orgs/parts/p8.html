JSONC edits keep comments, and each folder gets an index rebuilt on change. The root folder is set when the server starts.

  • Another folder at server start: --spaces <dir>, or the setting SPELL_SPACES_DIR
  • Each folder's index file stays up to date by itself
  • S3 or Git can replace the disk later, behind the same adapter (J4)
