How far the __ names reach (Q33). I read Owen's note as names on disk, and so the URLs and addresses that name a file; not the keys inside a saved file.

  • The keys stay: "$schema", "$version", "$type", "$id", "$ref", "$items" (Owen's call in J3, built in One Address Scheme's first half, P4).
  • Why: a key is never typed in a shell, so Owen's reason doesn't reach it; "$schema" is the name VS Code looks for, and can't change; renaming the others would redo committed work and every snapshot for nothing.
  • The other way: every key but "$schema" to __ too ("__type", "__id" ...): one mark everywhere, at the cost of renaming P4's keys a second time.
  • no change to the keys, the snapshots or the writers
