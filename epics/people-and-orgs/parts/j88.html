can we use `@here` instead of `@workspace`? Or is `@workspace` a shell thing

Yes, we can. @workspace isn't a shell thing: it's the spell command's own word for "the project in the folder I'm in", one constant in its code. Neither zsh nor bash gives @ any meaning at the start of a word, so @here types just as well.

  • You may be thinking of VS Code: Copilot Chat has an @workspace too. It's unrelated; the spell command's word just happens to match.
  • It means exactly what . already means. spell compile @workspace and spell compile . do the same thing, and so do @workspace/Card.spell and ./Card.spell. With no project named at all, the command also takes the project you're in.
  • Inside the command, it's also the value it uses for "the project here" when you name none (defaultProject()). 
/** Stands for the current folder:  `@workspace` ~== `.` */
export const WORKSPACE_ARG = "@workspace"

export async function resolveProject(arg: string, cwd = process.cwd()): Promise<CLI.CliProject> {
  if (arg === WORKSPACE_ARG) return resolveDiskPath(arg, cwd)
  if (arg.startsWith(`${WORKSPACE_ARG}/`))
    return resolveDiskPath(arg, resolve(cwd, arg.slice(WORKSPACE_ARG.length + 1)))
  if (SP.SpellLocation.isAddress(arg)) return resolveSpellPath(arg)
  return resolveDiskPath(arg, resolve(cwd, arg))
}

Could @here ever clash with an address? Only if an org were named here.

  • An org's space is written @org, so an org named here would be @here.
  • The command checks its own word before it reads an address, so that org's projects could never be named on the command line.
  • @workspace has the same gap today, with an org named workspace.
  • A person named here is fine: their space is here@spell, which doesn't start with @.
  • Nothing reserves org names yet. When orgs get names (Person And Org, P7), the word should be on a short list of names no org may take, with local (the @local/<folder> groups).
  • A small one: in GitHub or Slack prose, @here outside a code span reads as a mention, and in Slack it pings the channel. Every address starting with @ already has that in GitHub (@spell).
