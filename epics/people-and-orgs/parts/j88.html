The short names went with the old addresses (Q15): @examples, @library, @user, @system name nothing now.

  • spell compile @spell/library: a group; @spell: every group in that space; owen@spell/errors: a project; @spell/test/solitaire//Card.spell: a file.
  • @workspace is still the command line's own word for the current folder, @workspace/Foo.spell a file in it: it isn't an address, and none starts that way. A folder opened outside the groups is the group @local/<folder>.
  • spell projects lists each group by its address; the page server's startup compile is @spell/examples @spell/library.
