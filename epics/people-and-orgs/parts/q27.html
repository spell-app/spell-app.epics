What spell names the files and folders that belong to a place itself, never a project or a source file.

Owen's round-7 notes on the spaces page (2026-10-13):

  • "Person file $me.json5": in place of person.json5.
  • "project.json5 to $project.json5": a project's file.
  • "Move the pack folder inside components as $pack": a set's built pack in components/$pack/.
  • A $ at the start of a name means "this place's own", as the $ keys inside saved files and a space's $settings/ do.
  • the people store (P9) reads and writes $me.json5
  • JSON5 Everywhere (P12) renames a project's file to $project.json5
  • every pack is built into components/$pack/, in repo-layout
  • a shell needs single quotes around these names
