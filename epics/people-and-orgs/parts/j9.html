Chose a small file beside Thing.ts, ids.ts, over a new name on spellCore. It holds:

  • newThingId(thing)
  • ID_PROP, the description both kinds of thing (things and lists) declare their id with: { type: "text", init }
  • Why: nothing compiled calls it, so it needn't be on spellCore.
    • a new name there would also mean regenerating spellCore.declarations.json
    • and porting it, or listing it in Python's not_ported_yet.json
  • Kind: lodash's kebabCase() of the class name; Python splits the name into the same words.
    • DatedEvent => dated-event
    • Player2 => player-2
  • Random: 8 characters from crypto.getRandomValues(); Python uses secrets.choice().
    • bytes of 252 or more are skipped, so each character is equally likely
