Chose a small file beside Thing.ts, packages/core/src/classes/ids.ts, holding newThingId(thing) and ID_PROP (the { type: "text", init } both Thing and List declare id with), over a new spellCore name.

  • Why: nothing compiled calls it, so it needn't be on spellCore; a new name there would also mean regenerating spellCore.declarations.json and porting it or listing it in Python's not_ported_yet.json.
  • Kind: lodash's kebabCase() of the class name (DatedEvent => dated-event, Player2 => player-2); Python splits the name into the same words.
  • Random: 8 characters from crypto.getRandomValues() (bytes of 252 or more skipped, so each character is equally likely); Python uses secrets.choice().
