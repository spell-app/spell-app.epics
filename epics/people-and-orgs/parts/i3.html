The first time the library step asked tsc for a library's types, it wrote 99 stray .d.ts files into the repo.

  • One landed beside every core, util and app source file tsc read.
  • Why: TypeScript 7 roots its output at the folder of its project file. A file outside that folder climbs out of the output folder, into the repo.
  • Found and removed at once. All were untracked; none was committed.
  • Fixed by passing --rootDir /, so every file tsc writes stays under its own output folder.
  • A trap worth a line in the papercuts log.
  • making a library's types writes nothing outside its own output folder
