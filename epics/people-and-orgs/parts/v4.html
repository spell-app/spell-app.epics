Every thing has an id built in, so the editor refuses a second one, and explains the built-in one on hover.

  • The extension was rebuilt from this branch, so this works in any .spell file.
  • Type the first two lines below: the second line is underlined.
  • Its message says a person can't add "id": every thing has one, built in.
  • Then type the third line, and hover id in it.
  • Its docs say three things:
    • it's made up the first time it's read
    • it can be set
    • saving uses it
a person is a thing
a person has an id as text        // underlined
print the id of the person        // hover "id"
