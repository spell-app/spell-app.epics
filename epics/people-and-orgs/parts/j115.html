The javascript target puts a /*! SPELL: DECLARES {...} */ comment on each declaring statement's code. The spell comment is part of that code, so it goes under it: 

/*! SPELL: DECLARES { property: "rank", ... } */
// cards have a rank as one of ace or king
static Ranks = ["ace", "king"]
  • So a declaration's codeLines entry, where the Type Explorer starts showing its code, is the spell comment's line.
  • The Type Explorer shows each property with its spell above it.
