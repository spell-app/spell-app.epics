A compiled library loads its core by the core package's name, @spell-app/core/model, not by the repo's short alias $/core/model.

  • Chose: the package name. The core's package file now has one export, ./model.
  • Over: the repo alias, which every other import in the repo uses.
  • Why:
    • The repo's aliases only work for files that some TypeScript project file includes.
    • A library lives with its spell project, in spell's projects folder, and no TypeScript project includes that.
    • Node, Vite and tsx all read a package's exports, so the package name works from anywhere.
"exports": {
  "./model": "./src/model.ts"
}
