VS Code's JSON support resolves a "$schema" only as a URL or a path beside the file, so a bare address, @spell/library/people/Person, names nothing it can fetch. So spell compile writes each library type's schema into the library's build folder (schemas/Person.schema.json), and the repo's .vscode/settings.json maps a file name to it (json.schemas: __me.json5 to Person's, added with the people library in P7).

Works today, nothing to install; a file the mapping doesn't name isn't checked in VS Code (the app still checks it).
