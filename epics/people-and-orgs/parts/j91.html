VS Code's JSON support resolves a "$schema" only as a URL or a path beside the file, so a bare address, @spell/library/people/Person, names nothing it can fetch. So VS Code finds a schema by the file's name.

  • spell compile writes each library type's schema into the library's build folder, e.g. Person.schema.json
  • the repo's VS Code settings, settings.json, map a file name to it, in json.schemas
  • __me.json5 maps to Person's, added with the people library in P7
