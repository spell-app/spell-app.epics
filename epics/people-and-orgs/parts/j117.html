Compiled code imports core by name, so a spell variable of that name would hide it. It steps aside as Python's builtins do:

  • javascript and TypeScript: core_ (Naming.JAVASCRIPT_CLASHES)
  • Python: core_ too (Naming.PYTHON_CLASHES), which it never did before: a variable called core hid spell_core's
  • A program can name a variable core and still run.
