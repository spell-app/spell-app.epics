When a project is renamed, duplicated or deleted in the app, what spell built for it is deleted, not moved or copied; the next compile writes fresh files under the new name.

  • Rename: the old build folder is deleted, and so are the files named for the old name beside the source, e.g. Old.declarations.json, Old.en.js
  • Duplicate: the copy gets none of the original's built or generated files
  • Delete: its build folder goes too
  • Kept: Old.lib.ts and Old.app.py, which others may import or Owen may have edited
