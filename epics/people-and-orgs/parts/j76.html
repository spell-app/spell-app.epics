  • the widgets: the <ui-docs-*> elements the docs site is built from, in docs-components/

    • never in ComponentDefinitions.all
    • never in dist/
  • Every other set's components/ holds only its own elements, so this keeps the one layout true.
  • Spell UI's components/:
    • every ui-* family
    • ComponentDefinitions.ts
    • components.types.ts
  • docs-components/ unchanged; the lint guard covers both (PATTERN_FOLDERS.ui)
