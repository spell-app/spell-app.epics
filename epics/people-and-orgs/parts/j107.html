A file spell owns is read by its old name until something writes the new one.

  • A project file: __project.json5, else project.json (projectFileIn()). Saving writes __project.json5 and removes the old one, so Owen's projects in spell-spaces move as he works on them.
  • Any .json5 file the server or the disk reader is asked for that isn't there yet: its .json name (fileOrOldName()), e.g. an older compile's errors.declarations.json.
  • The core reference page, a shared page: it still names spellCore.declarations.json, so main's checkout keeps working; this branch's script tries the .json5 name first. The page's own links move at the merge.
  • nothing needs renaming by hand in spell-spaces
