Chose id = ThingIdProp() on SpellObject (what Thing and List share) over prop(type="text", init=...).

  • Why: Python's init is called with nothing (init=Deck, init=list), and an id needs its thing: it starts with the thing's kind. JavaScript's init is called with this, so it can.
  • Calling every init with the thing instead would break init=Deck: Deck(thing) reads its first argument as the items.
  • How: Prop.__get__() now asks first_value(instance) (init()'s value by default); ThingIdProp overrides it with new_thing_id(instance). Still a Prop, type text, so setting one is checked, and state.py's isinstance(found, Prop) still sees it.
