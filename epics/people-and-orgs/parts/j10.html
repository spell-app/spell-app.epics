Chose id = ThingIdProp() on Python's shared base class, over prop(type="text", init=...).

  • the base class: SpellObject, which things and lists share
  • Why: an id needs its thing, since it starts with the thing's kind.
    • Python's init is called with nothing.
      • e.g. init=Deck, init=list
    • JavaScript's init is called with this, so it can.
  • Calling every init with the thing instead would break init=Deck. Deck(thing) reads its first argument as the items.
  • How:
    • Prop.__get__() now asks first_value(instance)
    • that's init()'s value by default
    • ThingIdProp overrides it with new_thing_id(instance)
    • Still a Prop, of type text, so setting one is checked.
    • state.py's isinstance(found, Prop) still sees it.
