Compiled to Python, a call to a method with named arguments hands the method a dict, but the method reads each argument as an attribute of it, so running the program throws.

  • The spell: to create a new task (with title as text, completed as a choice), called as create a new task with title = "Create todos app", completed = yes
  • The call it writes: create_a_new_task({"title": ..., "completed": True})
  • Inside the method: title = props.title, which throws AttributeError: 'dict' object has no attribute 'title'
  • Seen running the new fixture TodosFormBased (a copy of the example Todos - Form Based) under Python in the core contract test, so that fixture is left out of the Python run for now (PYTHON_FIXTURES)
  • Logged in the suspected-bugs log (SUSPECTED-BUGS.md), under py
