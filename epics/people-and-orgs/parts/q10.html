Where the people/ and orgs/ folders live on disk. Today every project, the user's own included, is a folder inside the source code, tracked in git.

  • A person file holds emails, birthdays and friends' notes: things that shouldn't land in the repo's history.
  • Tests need their own copy, made fresh in a temporary folder.
  • One folder per machine, shared by main and every worktree; never committed.
  • A setting (SPELL_SPACES_DIR) points it elsewhere, as SPELL_PROJECTS_DIR does today.
  • The first run writes a starter people/owen/person.jsonc from git's name and email.
  • Next to projects/system and projects/user, so it's easy to find.
  • Each worktree gets its own copy, empty until made.
  • Shared by every checkout, and committed after every turn like the plan docs.
  • Personal data in a git history, even a local one.
  • ~/.spell/spaces/people/owen/person.jsonc is where Owen looks for himself
  • tests and the api tests use a temporary folder through the same setting
