Things have no lasting id, so a card in two piles comes back from a saved file as two cards.Every thing gets a built-in id, made up unless set, and no program may declare its own. A property or list typed as a kind holds references to things saved in their own files. One sentence inlines a kind instead, and drawable kinds refuse it.
  • Any spell program can ask a thing for its id, with nothing declared (Q9)
  • Declaring a property called id is an error, underlined in the editor
  • A list of people holds references to people, each in its own file
  • a dated-event is saved inline. keeps dated events inside their person (J1)
  • Saying that of a drawable kind, a card say, is an error that says why
  • The JavaScript, TypeScript and Python writers all know which properties are references

  • a person has an id as text is refused, saying every thing has one built in.
