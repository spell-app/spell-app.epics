In this worktree's editor, open one of your own projects in spell-spaces (still with a project.json), add a file, and save.

  • The project's folder now has __project.json5, and no project.json.
  • Add a comment to __project.json5 by hand, then add another file in the editor: the comment is still there.
  • Rename a project to My Project!: the menus show that title, and its file has "title": "My Project!".
  • VS Code opens the file as JSON with comments, with no squiggles.
