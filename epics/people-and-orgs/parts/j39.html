Before it compiles a project, spell compile compiles what the project imports, if needed; it now always looks at an import's own imports first, even when the import itself needs nothing.

  • Before: an import that already had a compiled file was skipped whole, and what IT imports with it
  • Now, with --stale: an import rebuilt further down makes the ones above it out of date too, so they're rebuilt in order
  • Now, without --stale: an import further down with no compiled file is compiled too, where before it was missed
  • Cost: each import's own imports are loaded once per run, even when nothing needs compiling
  • The code: compileImports()
  • a project compiles on a fresh checkout however deep its imports go
