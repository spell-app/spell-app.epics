The code that makes a custom element on Solid lives inside Spell UI, so every other set's elements have to import Spell UI to exist.

Moved the code that makes custom elements out of Spell UI into a package of its own, spell-kit/element, namespace E.

  • It imports only util's helpers and Solid; Spell UI hands it what it needs as it loads
  • Spell UI's core re-exports it, so Spell UI's files are unchanged
  • One copy per page: packs read it from Spell UI's core
  • A new package, spell-kit/element, namespace E: out of Spell UI, with their MIT notices, came
    • the element and component bases

    • shadow events, hot reloading, cells
    • the part / slot / owner contexts
    • the timing helpers and the vocabulary's types
    • their tests, in tests/spell-solid/
  • Imports only util's helpers and Solid: what it needs of Spell UI's runtime (words, styles, focus, animations, the vocabulary layer) Spell UI hands it as it loads (SpellUISettings); a tag defined before that waits for it (J71, J75).
