A Python entry writes a thing's props, then its plain fields, as a page's state does in state.py, over props alone.

  • plain fields: what it was made with and doesn't declare, as in Foundation(symbol=...)
  • Why: JavaScript's keysOf() lists such a value with the props, so both cores write the same entry.
