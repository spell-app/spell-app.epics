A library keeps the project's top-level functions, but drops its other top-level steps.

  • Kept:
    • its classes
    • what the project adds to classes
    • its comments
    • its top-level functions, as exports, since a library's helpers are useful to whoever imports it
  • Dropped, the top-level STEPS:
    • headings
    • tests
    • print
    • the things the project makes when it runs
  • Over: dropping the functions too, leaving only the classes.
  • The catch: a function that uses a top-level variable the library dropped fails when it's CALLED, not when the library is imported.
  • a project's helper functions can be imported from its library
  • a helper leaning on a dropped variable breaks only when called
