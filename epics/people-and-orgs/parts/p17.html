The code that makes a custom element on Solid lives inside Spell UI, so every other set's elements have to import Spell UI to exist.A new package, $/spell-solid, takes the element and component bases, the decorators, shadow events and hot reloading out of Spell UI. Every set's elements import it, and a page still has one copy.
