Chose to put the list of bundle folders in the root package.json, over moving the build specs there too, because how a bundle is built isn't a page-server setting.

  • the list: "pageServer": { "bundles": [...] }
  • read by BundleBuild, and by the assembler's new Bundle.specs()
    • Bundle.specs() picks its BUNDLES entries by that list
  • the build specs, which stay in the assembler: entries, commands, sources
  • The test comparing two lists is gone; a test checks each listed folder has exactly one build spec.
  • a new bundle needs three things:
    • a BUNDLES entry
    • its folder in pageServer.bundles
    • .gitignore
