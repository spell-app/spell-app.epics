A component pack leaves $/spell-solid out of its script, as it leaves Solid and $/ui/core (PACK_MODULES), and reads it from the page's SpellUI.packModules. There, it IS Spell UI's core module: "$/spell-solid": uiCore, in the docs bundle (spell-ui.entry.js) and the component sets' site build (SitePacks.ts). The app's spell-solid-shared.js likewise.

  • one copy by construction: Spell UI's core carries spell-solid, and its E holds every name a pack reads
  • no new entry in Spell UI's build
  • a new lib entry (@spell-app/ui/spell-solid) Spell UI's core imports, so it stays one copy
  • the docs bundle, the sets' site, the epics pack and the app's shared file all name $/spell-solid
  • the brand's design bundle resolves it to Spell UI's dist/core.js
