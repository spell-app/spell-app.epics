Chose: spell's project groups start empty, and spaces registers the five groups when it loads, over keeping the specs in spell, because Q20 moves the groups to spaces and spell must never import it.

  • spell's list: SpellSetup.projectRoots, empty to start with
  • spaces' registration: projectGroups.ts, a side effect of loading it
  • Every entry loads it:
    • the editor and spaces' routes, through spell-app/spaces
    • the language server and the spell command, through spaces' disk reader
    • <spell-app>, through spell-app/spaces/models/projectGroups alone (no barrel, small bundle)
  • A test per node entry checks it: projectGroups.test.ts.
  • spell's own tests that read paths import it too.
  • a new program that reads spell paths must load spaces' groups first, or every path is 'invalid'
