How spell writes an id, a reference, and a value per member. These words go into every spell program, not only Person, so they're worth picking on purpose.

  • Id: a property no two things of a kind share (a person's owen).
  • Reference: a property that points at a thing instead of holding a copy of it.
  • Per member: one value for each item of a list (a note for each person in a friend list).

  • Each word says exactly what it does; "unique" also works for any property, an email say.
  • "per" is short, and reads well for roles: a role per member as one of admin or viewer.
  • The friendliest to read aloud.
  • "link" will clash with web links once addresses arrive; "known by" names only the one id.
  • An id is its own datatype; "by reference" is programmer's English.
  • Three new property specifiers in the grammar: unique, references to, per
