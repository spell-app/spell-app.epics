A library's .d.ts (its types, for editors and TypeScript) is written by tsc, then formatted the way the repo formats its files.

  • Chose:
    • the repo's TypeScript 7 tsc, which the TypeScript target's check already runs, writes the declarations from the library's TypeScript
    • then oxfmt, through the assembler's formatHTML(), gives them the repo's 2-space style
    • it takes about 70ms
  • Over:
    • a hand-written declarations writer: more code to keep in step with the TypeScript writer
    • TypeScript 6's JavaScript API: a new dependency
  • each library's .lib.d.ts is what tsc writes, in the repo's style
  • no new dependency
