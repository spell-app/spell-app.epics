Spell's date had no Python type yet: chose datetime.datetime over datetime.date, because spell's date is a day AND a time of day, as JavaScript's Date.

  • Saved as toISOString() writes it, 1970-01-01T00:00:00.000Z (spell_core.saving.iso_text()).
  • A datetime with no time zone is read as UTC, and so is ISO text with none: over the machine's local time, because JavaScript reads ISO text with none as UTC, so both cores load a file the same.
  • Read back only from ISO text (datetime.fromisoformat()): JavaScript's new Date() reads more shapes; anything else stays text.
