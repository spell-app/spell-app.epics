Short version: your package works, with no cycle, if two things stay where they are.

  • Person's spell source stays in the spell package's built-in projects.
  • The storage adapter stays in the spell package too, because spell's own project saves will need it.
  • Packages import each other in ONE direction only: the root AGENTS.md's diagram.
  • A cycle is a loop: package X imports Y, and Y imports X, directly or round several packages. The rule forbids it.
  • The page server package is a leaf: it imports no other package, and any package may import it.
  • The page server still runs the app's server code, without importing it:
    • The root package.json lists route modules: files that add routes to the page server.
    • The page server loads each one by its file path when it starts.
    • So moving the app's server code needs only that list changed, and adds no import to the page server.
