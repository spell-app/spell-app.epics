<ui-brand-color-picker>'s Lightness × Colourfulness plane needs a keyboard and a screen-reader story. Chose two visually hidden native <input type=range>s inside the plane ("Lightness", spoken as a percentage; "Colourfulness"), both aria-roledescription="2D slider", over one role=slider div, because ARIA has no 2D slider: a role=slider carries ONE aria-valuenow, so one axis would be invisible to assistive tech. Two real sliders each read and step on their own (an assistive technology's increment arrives as their input event), which is the approach React Aria's ColorArea takes.

Only Lightness is a tab stop (Colourfulness is tabindex=-1, still reachable by a screen reader's browse mode); on either, Up / Down move L, Left / Right move C, Shift 10x, PageUp / PageDown L by 10%, Home grey, End the most colourful that fits. The focus ring is drawn on the marker (.plane:has(> .axis:focus-visible) > .marker).

  • a keyboard user tabs once into the plane and moves in 2D with the arrows
  • a screen reader hears two named sliders with readable values, not one opaque widget
  • each key is ui-input then ui-change, as <ui-slider>'s keys are
