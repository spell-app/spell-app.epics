A colour grid or range makes its chips fill their cells through a PRIVATE size token, so the public one stays the page's.

  • The owners: a set with columns (a grid), and a <ui-brand-color-range>.
  • Each sets the private --_ui-brand-color-fit: 100% on its chips.
  • The chip's size reads the public token first, then the fit, then 3em:
    • --_ui-brand-color-size: var(--ui-brand-color-size, var(--_ui-brand-color-fit, 3em))
  • Why not set the public --ui-brand-color-size: a sheet never declares another family's public component token (ui's theming guide, "Component tokens").
  • A set WITHOUT columns keeps each chip at its own size, in one row.
    • "Sized to fit" read as: they shrink alike when the row is too narrow.
    • How: tracks of minmax(0, max-content), and the chip's max-width: 100%.
    • So the Chooser's 28px presets stay 28px.
  • A page's --ui-brand-color-size still beats the owner's fill (e.g. fixed 28px chips in a grid).
  • size scales the chip's font, so the box, its label and the AA mark scale together; default 3em (48px).
