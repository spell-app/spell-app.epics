A <ui-brand-color-set columns> grid and <ui-brand-color-range> make their chips fill their cells by setting the PRIVATE --_ui-brand-color-fit: 100% on each chip host; the chip reads --_ui-brand-color-size: var(--ui-brand-color-size, var(--_ui-brand-color-fit, 3em)). Setting the public --ui-brand-color-size from another family's sheet would break the rule that a sheet never declares a public component token (docs/theming.md, "Component tokens").

A set WITHOUT columns keeps each chip at its own size in one row ("sized to fit" read as: shrinking alike when the row is too narrow, tracks minmax(0, max-content) and the chip's max-width: 100%), so the Chooser's 28px presets stay 28px.

Net effect:

  • A page's --ui-brand-color-size still beats the owner's fill (e.g. fixed 28px chips in a grid).
  • Sizes: size scales the chip's font, so the box, its label and the AA mark scale together; default 3em (48px).
