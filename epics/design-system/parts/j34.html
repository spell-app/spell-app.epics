<ui-brand-composer> (the Build box / Try a spell box) casts on its round button, Cmd/Ctrl+Enter, or the host's cast() method: it dispatches ui-cast { value }, never with blank text, while casting or disabled. ui-cast is CANCELABLE: unless a handler calls preventDefault(), a composer inside a <form> then submits it (requestSubmit()), so the form's submit handler sees name = the text, as the originals' <form onSubmit> did. Both Cmd+Enter and Ctrl+Enter cast on every platform; plain Enter types a newline. cast() is there for the hero's idea chips, which fill the box and cast at once (el.value = idea; el.cast()).

Net effect:

  • pages without a form just listen for ui-cast
  • pages with a form get a normal submit, which ui-cast's preventDefault() stops
  • a page listening to both ui-cast and submit sees one cast twice
