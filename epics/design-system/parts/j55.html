I8 / I15. <ui-section fold-icon="end"> (values start, the default, and end) renders the fold chevron OUTSIDE the fold button, after the badge and actions, at the far end of the title bar, as the original inspector draws it. The button (the heading) stays the control: the chevron is aria-hidden, and a click on it folds as the button does. It turns the same way as the start one (down open, right folded). A subclass moves the default with @proto static defaultFoldIcon: <ui-brand-panel> sets end, so its bands keep the look they had, now with any actions before the chevron. Kept the turn (down / right) rather than the original up / down, so no existing panel changes.

  • New attribute fold-icon on <ui-section> (and every panel); the panel defaults to end.
  • Color Set Chooser drops its ::part(heading) / ::part(toggle) / ::part(fold-icon) order rules for fold-icon="end"; its strip and copy button now sit BEFORE the chevron, as the original.
