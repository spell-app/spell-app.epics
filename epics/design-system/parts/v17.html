On the Spell UI site (/ui/), in the default Spell theme, nothing should have moved; then each new token or attribute should work.

  • ui-menu: vertical, secondary and text menus look as before (their looks now read --ui-menu-vertical-* / -secondary-* / -text-*); a link item fills a vertical menu's width
  • ui-markdown: the skip-title example drops the first heading; on Design Guide's copy, a contents link (or a #id in the address) scrolls to its heading (reveal(id))
  • ui-list (bulleted, link), ui-message (an icon message), ui-header (a card's sub header): unchanged at default tokens
  • ui-toast: UI.toast({ class }) keeps the page's class; Enter in a <ui-input> submits a form whose submit is a <ui-button> (Spell App's "New habit" field)
  • ui-tabs: the tab strip sits flush on its pane (--ui-tabs-menu-margin, 0)
  • the site header's sun / moon follows a page that sets ui-dark / ui-light itself (Spell App's Light / Dark pill)
