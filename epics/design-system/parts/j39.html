The build card's list is a checklist whose step attribute says how far the build has got.

  • With <ui-brand-checklist step="2">:
    • checks before index 2 are done: filled accent, a white check
    • index 2 is active: soft accent, pulsing
      • The pulse is the original's 1.4-second one (sp-pulse), only when the reader allows motion.
    • the rest are pending: an empty ring, subtle text
  • step at or past the end marks them all done.
  • Without step, each check's own state="done|active|pending" decides, or its selected state.
  • The list announces politely:
    • "Planning structure done" as step moves past a check
    • "All done" at the end
    • never on first render, or going back
  • Done and active lines carry a hidden "done" / "in progress"; the active one is aria-current=step.
  • Text: two fonts.
    • font="sans", the default: 14px, 20px marks, a 12px gap (the build card)
    • font="serif": 15px, 19px marks, a 10px gap (the habits)
  • Not a size: the brand's three lists aren't one ratio (14 / 15 / 13px, marks 20 / 19 / 16px).
    • So other sizes are tokens:
      • --ui-brand-checklist-font-size
      • --ui-brand-checklist-marker-size
      • --ui-brand-checklist-gap
      • --ui-brand-checklist-spacing
  • The page's 850ms timer sets one attribute, step, from 0 to 4.
  • Spell Marketing's smaller card sets those four tokens to 13px, 16px, 9px and 10px: style="--ui-brand-checklist-font-size: 13px; --ui-brand-checklist-marker-size: 16px; --ui-brand-checklist-gap: 9px; --ui-brand-checklist-spacing: 10px"
  • The card's title ("Building your app…" / "Your app is ready") stays page markup, outside the element.
