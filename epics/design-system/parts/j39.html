The build card's list is <ui-brand-checklist step="2">: checks before index 2 done (filled accent, white check), index 2 active (soft accent, pulsing sp-pulse's 1.4s, only with prefers-reduced-motion: no-preference), the rest pending (an empty ring, subtle text); step at or past the end marks all done. Without step, each check's own state="done|active|pending" (or selected) decides. The list announces politely: "Planning structure done" as step moves past a check, "All done" at the end; never on first render or going back. Done / active lines carry a hidden "done" / "in progress", and the active one is aria-current=step. Text: font="sans" (default: 14px, 20px marks, 12px gap, the build card) or font="serif" (15px, 19px marks, 10px gap, the habits). Not a size: the brand's three lists (14 / 15 / 13px, marks 20 / 19 / 16px) aren't one ratio, so other sizes are tokens: --ui-brand-checklist-font-size, -marker-size, -gap, -spacing.

  • Spell Marketing's smaller card: style="--ui-brand-checklist-font-size: 13px; --ui-brand-checklist-marker-size: 16px; --ui-brand-checklist-gap: 9px; --ui-brand-checklist-spacing: 10px"
  • The card's title ("Building your app…" / "Your app is ready") stays page markup, outside the element
