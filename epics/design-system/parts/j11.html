A colour chip's copy attribute says what a click copies: the hex by default, or one of three other forms.

  • Bare copy: the hex, #8E96B5, as the Color Palette page does.
  • oklch: oklch(67.7% 0.047 274), in the palette's own format (Palette.format).
  • token: var(--brand-500).
  • css, which the brief left open: a custom-property DECLARATION, --brand-500: #8E96B5;.
    • That's one line of the Chooser's CSS panel.
  • token and css without a name fall back to the hex.
  • It's a "key, or value and key" attribute (keyOrValueAndKey).

What a copy does:

  • writes the clipboard (navigator.clipboard)
  • sends a ui-copy event, with { value, originalEvent }
  • shows a check in the chip for 1.4 seconds (:state(copied))
  • announces "Copied …" in a status line
  • a refused write (no permission) does nothing
  • no page-wide toast, as the Color Palette page has: that's the page's, not the chip's
  • copy="css" pastes straight into a stylesheet.
  • No toast: a page that wants one listens for ui-copy (e.g. UI.toasts).
