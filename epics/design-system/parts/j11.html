<ui-brand-color copy> is a keyOrValueAndKey attribute: bare copy copies the hex (#8E96B5), the Color Palette page's default; oklch copies oklch(67.7% 0.047 274) (Palette.format); token copies var(--brand-500); css, which the brief left open, copies a custom-property DECLARATION, --brand-500: #8E96B5;, one line of the Chooser's CSS panel. token and css without a name fall back to the hex.

The copy writes navigator.clipboard, then dispatches ui-copy { value, originalEvent }, shows a check in the chip for 1.4s (:state(copied)) and announces "Copied …" in a status line. A refused write (no permission) does nothing. The Color Palette page's page-wide toast isn't reproduced: that's the page's, not the chip's.

Net effect:

  • copy="css" pastes straight into a stylesheet.
  • No toast: a page that wants one listens for ui-copy (e.g. UI.toasts).
