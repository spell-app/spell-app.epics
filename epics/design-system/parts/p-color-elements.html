Four colour elements and the brand's colour math, each with a docs page.

  • Where to see it: the Brand index, "1. Components". Four new pages, Brand Color, Color Set, Color Range and Color Picker, each in Spell UI's docs format, with live examples, the API and a token playground.
  • Palette: the brand's colour math, in TypeScript.
    • OKLCH, contrast, 17-step ladders, and parsing what people type
    • it rebuilds the 20 sets in the brand's palette.json exactly
  • <ui-brand-color>: a square chip.
    • label: hex, OKLCH, name or step
    • contrast: AA
    • copy: hex, OKLCH, token or css, with a check mark and an announcement
    • selected: a ring; details: a tip
  • <ui-brand-color-set>: chips laid out in columns. With selectable it's a radio group: arrows, Home / End, and a change event.
  • <ui-brand-color-range>: 17 chips from one colour, the anchor ringed.
    • attributes: anchor, vibrancy, hue-shift, name
    • strip: the folded row of dots
    • members: scale, anchorStep, css()
  • <ui-brand-color-picker>:
    • the lightness × chroma canvas, out-of-gamut hatched
    • a rainbow hue slider; hex / RGB and OKLCH inputs
    • keyboard on the plane, through two hidden sliders
    • form-associated
    • header and actions slots, to make the original popover
  • Built by two agents in parallel, integrated here.
    • 64 brand tests pass; every page loads with no errors
    • 13 judgement calls to review (J7-J13 this phase)
  • Rough: the picker's family chips on its docs page are plain buttons. They could become a <ui-brand-color-set> (C5).
