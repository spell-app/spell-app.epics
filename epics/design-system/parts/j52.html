Decided: YES by default. The numeric-field rule (right-aligned against the unit, tabular figures) is Spell UI's standing rule, so the element should follow it without page CSS: type="number" and a text field with inputmode="decimal" / "numeric" (the brand's L / C / H fields use inputmode to avoid the spinner) get text-align: end + tabular-nums. inputmode is now a <ui-input> attribute forwarded to the native input (it did nothing on the host before). A new token, --ui-input-numeric-align (default end), sets them back to start. Text fields (a hex, a name) stay start-aligned. No new attribute (no numeric): inputmode already says it.
