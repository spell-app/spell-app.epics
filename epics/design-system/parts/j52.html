Decided: numeric input fields right-align in tabular figures by default, with no page CSS.

  • Why: the numeric-field rule (right-aligned against the unit, tabular figures) is Spell UI's standing rule.
  • Which fields:
    • type="number"
    • a text field with inputmode="decimal" or "numeric"
    • the brand's L / C / H fields use inputmode, to avoid the spinner
  • They get text-align: end and tabular-nums.
  • inputmode is now an input attribute, forwarded to the native input.
    • It did nothing on the host before.
  • A new token, --ui-input-numeric-align (default end), sets them back to start.
  • Text fields (a hex, a name) stay start-aligned.
  • No new attribute (no numeric): inputmode already says it.
  • It changes the one Fomantic example with a number field: Input › Native types › Quantity.
    • Its placeholder now sits at the end; baselines updated.
  • <ui-input type="number"> and <ui-input inputmode="decimal"> right-align, in tabular figures.
  • Color Set Chooser can drop its rule for number fields (.format > ui-input.number::part(control)).
