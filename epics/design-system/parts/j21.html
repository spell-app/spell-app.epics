The Chooser's CSS sheet keeps the original's format and choices, and changes only what isn't real, or wouldn't work, on today's Spell UI under the brand theme (spell-brand).

  • Kept:
    • the format, @layer ui.theme { :root { ... } }
    • the mapping of each set to a hue (LIB)
    • the steps: bases 600 / 300; neutrals 25-150 in light, 950-850 in dark

Changed:

  • The heading font: --ui-header-font-family (invented) -> --ui-font-family-heading.
  • The dark shadow: one --ui-shadow-raised list, with light-dark() colours per layer.
    • That's how the brand theme writes shadows.
    • The original's dark-only rule (.ui-dark, :root:has(> body.ui-dark)) misses the OS's dark mode.
    • Plus --ui-card-shadow: var(--ui-shadow-raised).
  • Primary: restates every primary token from the set's ladder.
    • The suffixes: hover, focus, active, down, text, header, border, background.
    • Plus --ui-link and --ui-focus-color.
    • Why: the brand theme pins all of these to violet steps, so a new primary would otherwise keep violet hovers and tints.
  • Added the "on" colours of primary and secondary (--ui-primary-on, --ui-secondary-on): the theme pins them to violet / grey.
  • Added the text and border tokens the original's PREVIEW used but never wrote:
    • --ui-text-color, and its muted and dark versions
    • --ui-border-color
  • Corners: --ui-radius alone changes little under the brand theme (pill buttons, 16px cards).
    • So the sheet also sets the button, input, select and message radii to it.
    • And the card radius to 1.4 × it, capped at 1.5em: the original's pill card became a stadium.
  • Primary and secondary on ONE hue (violet + indigo -> violet).
    • The original wrote that hue twice, and primary lost.
    • Now secondary gets its own colours directly.
  • The sheet is longer than the original's, and every name in it is a real token.
  • Loaded after the brand theme, it re-themes everything the preview shows.
