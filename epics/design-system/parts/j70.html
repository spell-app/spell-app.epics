The panel gets the section's source attribute for free, the day it lands; it isn't built here.

  • Owen asked for a source option "like for <ui-section>".
  • The section's source is being built right now, in epic claude-design.
    • Its P2, "Section Sources", in its own worktree.
  • So NOT built into the section here: two branches would edit the same code.
    • Nor a panel-only copy, which would fork the behaviour.
  • Instead the panel takes every section attribute by construction.
    • It subclasses the section, and its vocabulary maps the section's attributes.
    • So the day source lands in the section's vocabulary and class, the panel has it.
    • A test pins that the panel's attribute, slot, part, event and state names equal the section's.
  • <ui-panel source> does nothing until claude-design merges
  • The panel's docs page (Usage, "Loading a band from a file"), its vocabulary and its class comments say so.
  • A follow-up todo: a test and a docs example for the panel's source.
