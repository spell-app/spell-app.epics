The checklist's tokens now show their real defaults in the docs, and a new token aligns the mark with the first line (I41, I34).

  • I41: the sheets read each public token where it paints, with its SANS default.
    • E.g. var(--ui-brand-checklist-font-size, 14px).
    • So the docs data records 12px / 14px / 20px / 12px, not the private aliases.
  • Serif is a class word on the check (check serif).
    • It comes from the check's own font, else its list's, asked through checkState().
    • It reads the same tokens, with the serif defaults.
    • The list's spacing switches on :host([font=serif]).
  • The old inheritance through private tokens (--_ui-brand-checklist-*) is gone.
  • I34: --ui-brand-checklist-align, centre (the default, as before) or start.
    • start puts the mark beside the FIRST line's middle.
    • How: align-items: start, plus a style query on the alias that moves the mark by (1lh - mark) / 2.
    • Without style queries (Firefox, today), it sits at the top edge.
  • The checklist page's Theming table shows real defaults, after yarn site:data in the brand package (brand).
  • Spell Docs drops its marker rule (::part(marker) { align-self: flex-start; margin-top: 1px }), for --ui-brand-checklist-align: start.
    • The mark lands 0.55px higher than the original's 1px-down, centred on the first line.
