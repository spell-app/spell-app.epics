Even though the elements start in packages/brand, the theme goes in packages/ui/src/styles/themes/. Why: that folder is the theme registry (it's read by a glob), so ThemeSheets.apply("spell-brand") and the Spell UI site's theme switcher work with no extra code.

Net effect:

  • one new file in ui; no registry change
  • the Spell UI docs site can show every component in the brand theme
