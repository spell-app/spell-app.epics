--ui-message-icon-align (default center): the icon box's align-self in an icon message, so start puts the icon at the top beside the first line. A token, not an icon-align attribute: Fomantic has no class word for it, and it's a look a theme may want for every message.

Net effect:

  • Spell Docs' ::part(icon) { align-self: flex-start } HACK becomes --ui-message-icon-align: start
  • every existing message unchanged
