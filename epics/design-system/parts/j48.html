A new message token, --ui-message-icon-align, places an icon message's icon: start puts it at the top, beside the first line.

  • The default is center.
  • It's the icon box's align-self.
  • A token, not an icon-align attribute:
    • Fomantic has no class word for it
    • it's a look a theme may want for every message
  • Spell Docs' HACK (::part(icon) { align-self: flex-start }) becomes --ui-message-icon-align: start.
  • Every existing message is unchanged.
