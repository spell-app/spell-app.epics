The Chooser's sheet writes the accent role to the brand theme's own accent hue, not to whatever hue the set maps to.

  • The original wrote it to the set's mapped hue (LIB): accent -> the brown background and text.
  • The brand theme now has a real accent hue: --ui-accent-*, color="accent".
  • So the sheet writes there:
    • the base (600 / 400, as the theme)
    • "on", background, text, header and border
  • The mapping still sets primary and secondary.
  • An accent never collides with primary / secondary (a sky accent and a blue primary both landed on blue).
  • color="accent" elements follow the theme; color="brown" keeps its own colours.
  • Under a theme without the accent hue, those lines do nothing.
