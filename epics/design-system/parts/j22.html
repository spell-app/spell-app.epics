The original wrote the accent role to whatever hue LIB maps its set to (accent -> --ui-brown-background / -text). The spell-brand theme now has a real accent hue (--ui-accent-*, color="accent"), so the sheet writes there instead: base (600 / 400, as the theme), -on, -background, -text, -header, -border. LIB still maps primary and secondary.

Net effect:

  • an accent never collides with primary / secondary (sky accent + blue primary both landed on blue)
  • color="accent" elements follow the theme; color="brown" keeps its own colours
  • under a theme without the accent hue, those lines do nothing
