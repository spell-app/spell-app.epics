The Chooser's six presets are a selectable colour set, so the loaded preset wears the selected ring.

  • The original's presets are plain buttons, with no chosen state.
  • Why:
    • a selectable set gives the arrow-key radio group for free
    • the ring says which preset the set came from
  • The ring shows only while the set is still that preset (its name AND its colour); editing either clears it.
  • The families grid in the popup rings the family whose seed is the current colour, the same way.
