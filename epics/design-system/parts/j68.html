Every public panel token was renamed after the new tag (--ui-panel-*), not kept under the old brand names.

  • The tokens:
    • background, border colour
    • header background, header colour
    • sub-head background, sub-head colour
    • radius, padding, gap, band space, shadow
  • Why: Spell UI's token rule names a family's tokens after its tag.
    • Its test (component-tokens.test.ts) classifies them by tag.
    • The docs' Theming tab lists them by that prefix.
  • The one brand page setting one is renamed: Theme Creator's .inspector ui-panel { --ui-panel-gap: 16px }.
  • The clip margin now reads the private alias (--_ui-panel-padding, already px), not the public token, as the token test requires; still 16px.
  • An old --ui-brand-panel-* token set anywhere else would now do nothing; none are left in the repo.
