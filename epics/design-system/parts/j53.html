dashed (keyOnly, ours: Fomantic has no dashed card): a placeholder. The border is a box-shadow, which can't dash, so a dashed card swaps its ring for a dashed outline in --ui-card-border-color (outside the box, where the ring was) and drops its drop shadow unless raised; a focused link card keeps its focus outline.

none on a shadow token: the card draws one box-shadow list (ring, coloured edge, drop shadow), and a none item voided the whole list, ring included. Now a style query turns --ui-card-shadow / -hover-shadow / -raised-shadow / -raised-hover-shadow / -border-shadow: none into an empty layer, so the rest stays. Limit: the query reads the card's PARENT, so set it on the card or above, not through ::part(card).

A link card's hover ring now reads --ui-card-hover-border-color (it kept --ui-card-border-color). Default look changes on hover only: the ring darkens to --ui-border-color-selected (Fomantic keeps the plain border there); the alias rules forbid "the public value if set, else the border colour", and the token's name says hover border. spell-brand sets it to --ui-border-color.

Net effect:

  • Logo Explorations: <ui-card dashed> + --ui-card-border-color: var(--spell-border-strong) replaces the ::part(card) border.
  • Spell Docs: --ui-card-shadow: none and --ui-card-hover-border-color: var(--spell-border-accent) replace 0 0 transparent and the ring-as-hover-shadow.
