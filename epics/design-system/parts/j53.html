Three card changes: a dashed placeholder card, shadow tokens that accept none, and a hover border token for link cards.

  • dashed, a key-only attribute, ours (Fomantic has no dashed card): a placeholder.
    • The card's border is a box shadow, which can't dash.
    • So a dashed card swaps its ring for a dashed outline, in the card's border colour, outside the box where the ring was.
    • It drops its drop shadow, unless raised.
    • A focused link card keeps its focus outline.
  • none on a shadow token now drops only that layer.
    • The card draws one box-shadow list: ring, coloured edge, drop shadow.
    • A none item voided the whole list, ring included.
    • Now a style query turns any of the card's shadow tokens set to none into an empty layer, so the rest stays.
    • The tokens: --ui-card-shadow, and its hover, raised, raised-hover and border versions.
    • Limit: the query reads the card's PARENT, so set it on the card or above, not through ::part(card).
  • A link card's hover ring now reads --ui-card-hover-border-color; it kept the plain border colour before.
    • The default look changes on hover only: the ring darkens to the selected border colour.
    • Fomantic keeps the plain border there.
    • Why: the alias rules forbid "the public value if set, else the border colour", and the token's name says hover border.
    • The brand theme sets it to the plain border colour.
  • Logo Explorations: <ui-card dashed>, with --ui-card-border-color: var(--spell-border-strong), replaces the border it set through the card's part.
  • Spell Docs: --ui-card-shadow: none replaces 0 0 transparent.
  • Spell Docs: --ui-card-hover-border-color: var(--spell-border-accent) replaces its ring-as-hover-shadow.
