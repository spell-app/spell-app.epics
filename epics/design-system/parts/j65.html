A section's fold chevron can now turn the brand's way (UP while open, DOWN while folded), through two new tokens the brand theme sets.

  • The brand's foldable sections (Theme Creator, Color Set Chooser) point the chevron up while open, down while folded.
  • The section element drew it down, turned toward the text, with no way to change it.
  • Two new tokens:
    • --ui-section-fold-icon-rotate: open, default 0deg
    • --ui-section-fold-icon-folded-rotate: folded, default -90deg
    • Named after the existing fold-icon size token, and the fold-icon part they turn.
    • Both the start and the end chevron read them.
    • Right to left, each turn is negated, so the default still mirrors to 90deg.
  • Set in the brand THEME (180deg / 0deg), not on the page.
    • Every original with folding sections does it.
    • So every section and panel under that theme follows.
    • The Spell theme and the Fomantic themes keep down / sideways.
  • Docs: a "Chevron turn" example, and the Theming snippet, on the section's page (ui-section.html).
  • Tests: in ui-section.css.test.ts.
