The brand's foldable sections (Theme Creator, Color Set Chooser) show a chevron pointing UP while open and DOWN while folded; <ui-section> drew down / turned toward the text, with no way to change it.

  • New tokens --ui-section-fold-icon-rotate (open, default 0deg) and --ui-section-fold-icon-folded-rotate (folded, default -90deg): named after the existing --ui-section-fold-icon-size and the fold-icon part they turn; both the start and end chevron read them; right to left each turn is negated (so the default still mirrors to 90deg).
  • Set in the spell-brand THEME (180deg / 0deg), not on the page: every original with folding sections does it, so every <ui-section> / <ui-brand-panel> under that theme follows. spell and the Fomantic themes keep down / sideways.
  • Docs: a "Chevron turn" example and the Theming snippet on ui-section.html; tests in ui-section.css.test.ts.
