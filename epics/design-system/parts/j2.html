The Brand index says "not yet" for a Spell copy that doesn't exist, and a flag in its page list tells it which.

  • Each page in the list (brand-pages.js) has built: true|false.
  • Chosen over asking the server (a HEAD request):
    • a missing file logs a console error, and page checks fail on those
    • a page opened from file:// can't ask at all
  • Each phase that adds a copy flips its flag in the same change.
