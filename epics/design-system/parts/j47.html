The list element's tokens now reach every list, and three new ones size its spacing and markers.

  • The root's font size now reads --ui-list-font-size.
    • It was documented, but only horizontal items read it.
  • --ui-list-margin (1em): above and below the list.
    • Still none before the first child or after the last, the shape of the message's margin.
  • The link, selection and bulleted looks set their defaults THROUGH the public tokens.
    • E.g. var(--ui-list-link-color, var(--ui-text-unselected)).
    • So a page's link colour, item colour, padding, radius, backgrounds, bullet glyph and hang now reach them.
    • The structural variations (horizontal, relaxed, divided, celled) still win over a page value.
  • --ui-list-marker-size (1em): the marker's font size.
    • Its hang (--ui-list-marker-margin) is in the marker's own em.
    • It stays on the line while the item's line height is a length (1.3em, not 1.3).
  • --ui-list-marker-active-color: a selected item's bullet or number; unset, the marker colour, as before.
    • Named after the sheet's other active tokens (--ui-list-link-active-color ...).
    • NOT the issue's --ui-list-item-selected-marker-color.
  • Not done here: the menu's group.
    • I28's --ui-menu-shadow.
    • The secondary menu's private item look.
  • A link or selection list on a page that sets the list's link or item tokens now changes (it ignored them before).
  • No theme sets them, and every list example looks the same.
  • Spell Docs' bullet HACK (::part(item)::before) and the Design Guide's 16px top gap can go.
