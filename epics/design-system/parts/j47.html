• The root's font-size now reads --ui-list-font-size (it was documented, but only horizontal items read it).
  • --ui-list-margin (1em): above and below the list, still none before the first child / after the last (the shape of --ui-message-margin).
  • link, selection and bulleted's marker set their defaults THROUGH the public tokens (var(--ui-list-link-color, var(--ui-text-unselected))): a page's link colour, item colour, padding, radius, backgrounds, bullet glyph and hang now reach them. The structural variations (horizontal, relaxed, divided, celled) still win over a page value.
  • --ui-list-marker-size (1em): the marker's font size. Its hang (--ui-list-marker-margin) is in the marker's own em, and it stays on the line while the item's line-height is a length (1.3em, not 1.3).
  • --ui-list-marker-active-color: a selected item's bullet / number; unset, the marker colour as before. Named after the sheet's --ui-list-link-active-color / -item-active-*, NOT the issue's --ui-list-item-selected-marker-color.
  • Not done here: I28's --ui-menu-shadow and <ui-menu secondary>'s private item look (the menu's group).

Net effect:

  • a link or selection list on a page that sets --ui-list-link-color / --ui-list-item-* now changes (it ignored them before); no theme sets them, and every list example looks the same
  • Spell Docs' bullet ::part(item)::before HACK and the Design Guide's 16px top gap can go
