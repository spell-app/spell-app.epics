Four new elements, from the Color Palette and Color Set Chooser pages, in components for now (D2):

  • <ui-brand-color value="#6550CA">: a square chip. Optional label (hex, OKLCH, or a name), "AA" when text on it passes contrast, click to copy, a popover with its values.
  • <ui-brand-color-set>: a row or grid of chips that you pick one from (the Chooser's presets, Theme Creator's set pickers), or a whole 17-step ladder (the Palette's rows).
  • <ui-brand-color-picker>: the Chooser's popover: an HSL square for the hue, a rainbow hue slider, and HSL, RGB and OKLCH rows, each with a copy button (Q14).
  • <ui-brand-color-range>: a ladder made from one base color (the Chooser's "variants"). It uses the brand's generateScale() math from palette.mjs, ported to TypeScript.
  • Each has a docs page in Spell UI's format, with live examples, the API and a token playground (Q11).
  • Since then the brand's tags drop the ui-: <brand-color>, <brand-composer> ...

"OKLCH" is a way to write a color as Lightness, Chroma (colourfulness) and Hue that matches what eyes see: two colors with the same L look equally light. The brand generates every ladder in it.
