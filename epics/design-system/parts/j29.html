The flourish and blob docs pages put every example in a shared .stage box, since both elements fill or hang off a positioned, clipping parent.

  • The box: a page style in each docs page.
    • position: relative; overflow: hidden
    • a hairline, a 16px radius
  • The Usage tab shows that CSS.
  • A shared class, not inline styles, so the code panes stay readable.
  • The flourish page's sections:
    • one per variant, with the brand's use for it
    • Seed; Size (redraws on resize); Colours; Weight
  • The blob page's sections:
    • the hero blob; Corner
    • Shape: both shapes in each corner, so the mound's flip shows
    • Tone; on coloured surfaces; Size tokens
  • The blob's Theming playground box sets no blob tokens of its own, so edited values reach the blobs (checked).
  • Two new pages, the flourish's and the blob's (ui-brand-flourish.html, ui-brand-blob.html): no console errors, light and dark.
  • The flourish's Theming tab is a hand-written token table plus a live example (an issue: its tokens aren't in the docs data).
