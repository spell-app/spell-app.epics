Both elements fill or hang off a positioned, clipping parent, so every example puts them in a .stage box (a page <style> in each docs page: position: relative; overflow: hidden, a hairline, 16px radius), and the Usage tab shows that CSS. Chose a shared class over inline styles so the code panes stay readable. Flourish: one section per variant (with the brand's use for it), Seed, Size (redraws on resize), Colours, Weight. Blob: the hero blob, Corner, Shape (both shapes in each corner, so the mound's flip shows), Tone, on coloured surfaces, Size tokens. The blob's Theming playground box sets no blob tokens of its own, so edited values reach the blobs (checked).
