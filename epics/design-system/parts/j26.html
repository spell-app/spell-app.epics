The logo pages' download links are tiny circular Spell UI buttons, with a page script that makes a click download the file.

  • The original's are soft pills, plain links with download.
  • The copy's: <ui-button size="tiny" circular icon="download" href="assets/logo/…svg">.
    • The soft accent look: the button's background and colour tokens set to the brand's soft accent and accent text.
  • The page script is needed because <ui-button> has no download (an issue).
  • Icon-only mark buttons are named "Download SVG" (an aria-label).
  • Clicking downloads the file (checked: spell-lockup-tagline-aubergine.svg), and the page stays put.
  • Without the script, a click opens the SVG instead.
