<ui-brand-phone> (the Spell App Build screen's preview) takes three attributes: time (the status bar clock, default 9:41), dimmed (the original's fade to 0.45 while the app builds; animated over 0.4s, not animated under reduced motion) and label (the region's name, default App preview). dimmed, not loading / busy: Fomantic's loading draws a spinner, which the original doesn't; dimmed is Fomantic's word for a faded state. It also sets aria-busy on the region, since it means the app is being rebuilt. No size / device variant: the pages need one phone; the width is a token, --ui-brand-phone-width (300px).

  • The page writes <ui-brand-phone dimmed> while building, removes dimmed when ready.
  • A screen reader hears a region "App preview"; the status bar is hidden from it.
  • Another device shape later is a new attribute, not a rename.
