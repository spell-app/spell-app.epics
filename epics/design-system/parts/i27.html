Two things the guide's page script does by hand:

  • The title: the original drops the readme's own # Spell Design System (the page has its own headline). <ui-markdown> renders every heading, so the script strips the first # line on ui-load and sets content (which marks it dirty). Ask: an attribute, e.g. skip-title (drop a leading h1).
  • Scrolling to a heading: the table of contents sits outside the element, and the page's own #id navigation can't see ids in a shadow root. The script finds the heading in shadowRoot and scrolls it (HACK), and does the same for a #id in the address on load. Ask: a method, reveal(id), and the element honouring location.hash after its first render.
