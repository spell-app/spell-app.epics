Brand Montage, the app panels' side nav (<ui-menu vertical secondary>).

What: .ui.vertical.menu and .ui.secondary.menu set their item look as PRIVATE tokens directly (--_ui-menu-item-radius, --_ui-menu-active-background, --_ui-menu-icon-float: right ...), so --ui-menu-item-radius, --ui-menu-active-background / -color, --ui-menu-icon-float / -margin set on the page never reach a vertical or secondary menu. The original's nav (icon first, the chosen item tinted lavender / filled purple in dark) can't be had by tokens.

Fix: in ui-menu.css, each variation's value becomes the FALLBACK of the public token (--_ui-menu-icon-float: var(--ui-menu-icon-float, right)), as the base block does. Then the page's ::part(item) / ::part(icon) rules (marked HACK) go.
