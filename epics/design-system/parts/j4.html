The Spell copies load the brand script as an ES module split into lazy chunks, not as ONE classic script as the plan said.

  • The plan (the brand script decision, D7) said the .spell.html pages would load one classic script, like the docs.
  • Built that way, it would have to inline several megabytes on every page:
    • every theme sheet (27)
    • both code engines
    • every emoji chunk
    • spell's highlighter
  • So brand-ui.js is built the way Spell UI's own site bundle is.
  • Gain: an 84 KB entry (28 KB gzipped); themes and engines load only when used.
  • Gain: icons come from Spell UI's own packs on disk (a symlink), not jsDelivr.
    • So they draw offline, and every Font Awesome 7 icon works.
  • Cost: the copies open only from the page server, not from file://.
    • The originals already need it (four fetch local files), and so does Compare.
  • A copy loads the module script and its stylesheet: <script type="module" src="../_assets/ui/brand-ui.js"> and brand-ui.css.
  • The icons caveat (C2) no longer needs the internet.
