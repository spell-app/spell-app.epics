The plan (D7) said the .spell.html pages would load ONE classic script, like the docs. Built that way, it would have to inline every theme sheet (27), both code engines, every emoji chunk and spell's highlighter: several megabytes on every page. So brand-ui.js is an ES module, split into lazy chunks, built the way Spell UI's own site bundle is.

  • Gain: an 84 KB entry (28 KB gzipped); themes and engines load only when used.
  • Gain: icons come from Spell UI's own packs on disk (a symlink), not jsDelivr, so they draw offline and every Font Awesome 7 icon works.
  • Cost: the copies open only from the page server, not from file://. The originals already need it (four fetch local files), and so does Compare.

Net effect:

  • a copy loads <script type="module" src="../_assets/ui/brand-ui.js"> and brand-ui.css
  • caveat C2 no longer needs the internet for icons
