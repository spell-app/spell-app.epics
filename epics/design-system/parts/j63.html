I29: inside a tab set the tab list kept the menu's 1em block margins. A flex column doesn't collapse margins, so the menu's bottom 1em plus the pane's top 1em (--ui-tabs-pane-margin) made a 2em gap, where Fomantic's markup (menu, then segment) collapses to 1em; a text tab list also kept 1em above it. Now the set owns the list's block margin: --ui-tabs-menu-margin, default 0, so the pane margin alone spaces them.

  • every unattached horizontal tab set (plain, pointing secondary, text) is 1em tighter between tabs and pane; attached and vertical sets are unchanged (visual baselines updated for ui-tab)
  • the list's height and its labels' font come from --ui-menu-min-height, --ui-menu-font-family, --ui-menu-item-transform / -letter-spacing set on the tab set
