A tab set's tab list no longer adds its own margin, so tabs and pane are 1em apart, as in Fomantic (I29).

  • The problem: inside a tab set, the tab list kept the menu's 1em block margins.
    • A flex column doesn't collapse margins.
    • So the menu's bottom 1em, plus the pane's top 1em (--ui-tabs-pane-margin), made a 2em gap.
    • Fomantic's markup (a menu, then a segment) collapses to 1em.
    • A text tab list also kept 1em above it.
  • Now the set owns the list's block margin: --ui-tabs-menu-margin, default 0.
    • So the pane's margin alone spaces them.
  • Every unattached horizontal tab set (plain, pointing secondary, text) is 1em tighter between tabs and pane.
  • Attached and vertical sets are unchanged; the tab's visual baselines are updated.
  • The list's height, and its labels' font, come from the menu's tokens set on the tab set.
    • --ui-menu-min-height
    • --ui-menu-font-family
    • --ui-menu-item-transform, --ui-menu-item-letter-spacing
