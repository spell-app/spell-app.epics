The sub header rule now reads var(--_ui-header-sub-color, var(--ui-header-sub-color, var(--ui-text-muted))) (and the same for -font-size): the alias when a STANDALONE header declared it, else the public token. An owned header (a card's) declares none, so its lede now takes the public tokens. New --ui-header-sub-margin (0), e.g. 8px 0 0 for the gap below the headline.

Net effect:

  • under the spell / spell-brand themes (which set --ui-header-sub-color, violet-800), a CARD's sub header turns from the muted grey to that violet, like a standalone header's already was; under bookish (--ui-header-sub-font-size) it takes the smaller size. The default theme: unchanged (visual tests pass)
  • Flourishes can drop its --ui-text-muted remap and host font size for --ui-header-sub-color / -font-size / -margin: 8px 0 0
