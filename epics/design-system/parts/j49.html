A card's sub header now takes the header's public tokens, as a standalone header already did, and a new token sets its margin.

  • The sub header's colour now reads the private alias, then the public token, then the muted text colour.
    • var(--_ui-header-sub-color, var(--ui-header-sub-color, var(--ui-text-muted)))
    • The same for its font size.
  • The alias is set only when a STANDALONE header declared it.
  • An owned header (a card's) declares none, so its lede now takes the public tokens.
  • New: --ui-header-sub-margin (0), e.g. 8px 0 0 for the gap below the headline.
  • Under the Spell and Spell Brand themes, a CARD's sub header turns from muted grey to violet-800, like a standalone header's already was.
    • Those themes set --ui-header-sub-color.
  • Under the Bookish theme, which sets the sub header's font size, it takes the smaller size.
  • The default theme: unchanged (visual tests pass).
  • Flourishes can drop its remap of the muted text colour and its host font size, for the sub header's colour, font size and 8px 0 0 margin.
