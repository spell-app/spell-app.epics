Chose to keep the panel's brand fallbacks (var(--spell-*, var(--ui-*))) and its default hue primary, over stripping the brand roles out, because the look on the brand pages must not change and every role already falls back to a plain token.

The vocabulary's color keeps the section's value set (hues) rather than listing accent as the brand panel did: Spell UI ships no accent hue; the brand bundle adds it at runtime (packages/brand/src/hues.ts) and spell-brand colours it, so color="accent" works where both are, as on every element with a color. The sheet's hue lists still name .accent (the one theme hue so far).

Net effect:

  • under any theme (Spell UI's site, no brand): the header band is --ui-primary-background, the box a 35% mix of it with --ui-surface, the sub-head bands a 65% mix, the shadow --ui-shadow-raised (pinned by a test)
  • on the brand pages: unchanged, ivory with color="accent"
  • the Spell UI docs page shows no accent example (it isn't a hue there); it says where it works
