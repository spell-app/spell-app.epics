The panel keeps its brand fallbacks and its default hue, primary, so the brand pages look the same.

  • The fallbacks: each colour reads the brand role first, then a plain token (var(--spell-*, var(--ui-*))).
  • Chosen over stripping the brand roles out: the look on the brand pages must not change, and every role already falls back to a plain token.
  • The vocabulary's color keeps the section's set of values (its hues), rather than listing accent as the brand panel did.
    • Spell UI ships no accent hue.
    • The brand bundle adds it at runtime (hues.ts), and the brand theme colours it.
    • So color="accent" works where both are, as on every element with a color.
  • The sheet's hue lists still name .accent: the one theme hue so far.
  • Under any theme with no brand (Spell UI's site), pinned by a test:
    • the header band is the primary background
    • the box, a 35% mix of it with the surface; the sub-head bands, a 65% mix
    • the shadow, the raised shadow
  • On the brand pages: unchanged, ivory with color="accent".
  • The Spell UI docs page shows no accent example (it isn't a hue there); it says where it works.
