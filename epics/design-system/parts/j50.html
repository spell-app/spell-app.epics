A button's icon can now sit after its text, with a new attribute, icon-position="right".

  • Fomantic writes a trailing icon after the text, as <i class="right arrow icon">.
    • Our sheet already spaced a right icon that way; the element just had no way to put its icon box there.
  • The attribute is named like the input's (<ui-input icon-position>): left, the default, or right.
  • It adds no class to the button: a right icon root class would read as icon-only.
    • The icon box itself gets right icon.
  • A labeled icon block still takes its side from labeled.
  • Fixed on the way: the element example "Icon and text › Next" drew its arrow BEFORE the text.
    • Unlike the class-grammar example.
    • It now says icon-position="right"; the button's content baselines are updated.
  • <ui-button icon="arrow right" icon-position="right">Open app</ui-button> draws "Open app →", spaced by the button's icon spacing token.
  • Spell Marketing can drop its slotted icon after the text.
