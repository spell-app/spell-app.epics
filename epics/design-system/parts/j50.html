Fomantic writes a trailing icon as <i class="right arrow icon"> after the text, and our sheet already spaced a .right.icon that way; the element just had no way to put its icon box there. So a new attribute, named like <ui-input icon-position>: icon-position="left" (default) or "right". It adds no class to the button (a right icon root class would read as icon-only); the icon box itself gets right icon. A labeled icon block still takes its side from labeled.

Also fixed on the way: the element example "Icon and text › Next" drew its arrow BEFORE the text, unlike the class-grammar example; it now says icon-position="right" (visual baselines for ui-button/content updated).

  • <ui-button icon="arrow right" icon-position="right">Open app</ui-button> draws "Open app →", spaced by --ui-button-icon-spacing.
