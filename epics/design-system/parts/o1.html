spell-design-system/ is Claude Design's output: 13 pages, a token set, and logo assets. The pages are NOT plain HTML.

  • Each *.dc.html page is a template (<x-dc>). Claude Design's own runtime compiles it into React at load time: support.js, 69 KB, generated.
    • Templating: values, conditions, loops, and hover styles. 
      {{ value }}   <sc-if>   <sc-for>   style-hover="..."
    • State and handlers live in a <script type="text/x-dc"> class.
    • React and Font Awesome come from CDNs, so the pages need the internet.
    • Four pages also fetch local files, so they need a server: they don't work from file://. The files: palette.mjs and readme.md.
  • Nearly everything is inline style="...".
    • the sp-* classes, in components.css, are used only by the small specimen cards, never by the 13 pages
    • so are the 28 thin React wrappers over them, one folder each beside it
  • The tokens, one sheet per kind in its tokens folder:
    • 17-step OKLCH color ladders for 20 color sets
    • semantic light and dark tokens, e.g. --surface-card, --text-strong
    • type, a 4px spacing grid, radii, shadows and motion
