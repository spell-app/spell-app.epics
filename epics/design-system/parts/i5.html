Found building Brand Palette's Build nav item (P5). .ui.secondary.menu writes --_ui-menu-active-background straight (oklch(from var(--ui-ink) l c h / 0.05)), and .ui.vertical.menu writes --_ui-menu-icon-float: right / --_ui-menu-icon-margin, so an inline --ui-menu-active-background / -color on the menu does nothing there, and the icon can't move back before the text. The spell-brand theme's own --ui-menu-active-background doesn't reach secondary menus either. Also no token reaches: the menu's 1em margin when the host has siblings (--_menu-margin-top/-bottom), its min-height; and a single active item takes --ui-menu-active-last-radius, not --ui-menu-active-radius. Workaround in the page: a plain one-item menu (no box), wrapped in its own <div>, with --ui-menu-active-first-radius / -last-radius. Fix: variations default the public token (var(--ui-menu-active-background, ...)) instead of writing the alias.
