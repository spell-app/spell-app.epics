The Color Set Chooser's hover popover has a copy button per row (RGB, OKLCH). <ui-brand-color details>'s tip is a CSS tooltip (anchor-positioned, flipping at the window's edges) with the same facts (name, hex, OKLCH, contrast on white and ink, the "good for" note) but no buttons: a tip that vanishes when the pointer leaves the chip can't hold controls, and buttons inside a copy <button> chip would be nested interactive content. Copying is the chip's own click, in the format copy picks.
