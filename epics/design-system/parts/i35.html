Spell Marketing, the top nav and footer links (<ui-menu text> of <ui-item href>s).

What: .ui.text.menu sets --_ui-menu-item-padding and --_ui-menu-item-color as PRIVATE tokens, so --ui-menu-item-padding / --ui-menu-item-color set on the page never reach it (the same mechanism as I21's vertical / secondary menus). The menu box also keeps a trailing gap after its last item, so a gap on ::part(menu) pushes the links off the right edge.

Workaround: ui-item::part(item) for padding / colour, and ui-item:not(:first-child)::part(item) margins for the spacing (HACK comment in the page).

Fix: in ui-menu.css, read the public token in front of each variation's private value (var(--ui-menu-item-padding, 0.35714em 0.5em)), as I21 asks.
