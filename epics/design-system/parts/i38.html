What: UI.toast({ class }) sorts class words into type / hue / inverted and drops the rest, and the toast lives in a container in <body>: a page can't scope --ui-toast-* to one toast. inverted doesn't fit either: it forces the dark scheme, so the brand's --spell-surface-inverse (aubergine light, pale lilac dark) resolves wrong in light mode.

Where: Spell App's "Your app is ready." toast. Workaround: --ui-toast-background / -color / -radius / -shadow / -width / -padding set on body (every toast on the page). Also no font-size token: the toast's text is 16px, the original's 14px.

Fix it needs: keep unknown class words on the <ui-toast> host (or a style / tokens option); a --ui-toast-font-size token.
