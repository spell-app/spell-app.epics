I16's 30px controls (14px, weight 500, 6px corners) are set by <ui-brand-field>'s sheet on a DIRECTLY slotted <ui-input> / <ui-select> / <ui-dropdown>, through their public tokens (--ui-input-padding-block ..., --ui-scale: var(--ui-size-small), --ui-font-weight-normal: 500), as a page would (ui-search's precedent).

  • Why the field: it is the thing that means "inspector field"; a panel's ::slotted() reaches only its direct children, so it would miss every field's control anyway.
  • Not nested controls (a row of inputs in a slotted div): Color Set Chooser's RGB / OKLCH row is 34px, 13px in the original, so the page sizes those.
  • The bare name input (Theme Creator, Color Set Chooser) now sits in a label-less <ui-brand-field> (no label row renders).
  • A value set on the control itself still wins (outer tree); its own size resets the scale.
