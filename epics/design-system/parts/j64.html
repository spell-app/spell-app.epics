The brand field's sheet sizes the inspector's controls to 30px (I16): 14px text, weight 500, 6px corners.

  • It sets them on a DIRECTLY slotted input, select or dropdown, through their public tokens, as a page would.
    • E.g. --ui-input-padding-block ..., --ui-scale: var(--ui-size-small).
    • And --ui-font-weight-normal: 500.
    • The search element set the precedent.
  • Why the field: it is the thing that means "inspector field".
    • A panel's ::slotted() reaches only its direct children, so it would miss every field's control anyway.
  • Not nested controls, such as a row of inputs in a slotted box.
    • Color Set Chooser's RGB / OKLCH row is 34px and 13px in the original, so the page sizes those.
  • The bare name input (Theme Creator, Color Set Chooser) now sits in a brand field with no label; no label row renders.
  • A value set on the control itself still wins (the outer tree); its own size resets the scale.
