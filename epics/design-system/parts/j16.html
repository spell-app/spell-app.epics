P5's Color Palette copy (Color Palette.spell.html) draws each palette set as a colour range element, not 17 hand-fed chips.

  • Each of the 20 sets in the palette data becomes one range, its seed, anchor and name from the set.
    • The page script fetches the data (palette.json).
    • The markup: <ui-brand-color-range value=seed anchor=anchor name=set>.
    • The ranges rebuild every step exactly: all 340 hexes equal the data's (checked in the browser).
    • The seed's ring comes from the element.
  • The step numbers show once, in a header row, as in the original.
    • Each range's own numbers are hidden with ::part(number); an issue asks for an attribute.
  • Chips are the elements' SQUARE chips (~62px at 1400px), not the original's 54px-tall ones.
    • The brand readme says chips are always square.
  • Copy: the hex while hexes show, else the token, as in the original.
  • The toast on ui-copy is Spell UI's (UI.toast): inverted, bottom centre, 1.4 seconds.
  • The format switch is a segmented menu (<ui-menu appearance=segmented>).
  • The light / dark pill flips ui-dark / ui-light on the page's root element.
  • Rows are ~8px taller than the original's (square chips).
  • No copy of the palette data in the page: the data file and the element's math are the only sources.
