The Spell App copy's controls: each is a Spell UI element where one fits, and page markup only for layout and decoration.

  • The template category pills: tiny circular basic buttons, not labels.
    • The chosen one is active, with aria-pressed.
    • They're controls, and a label isn't one.
  • The status badges (Live / Draft / Needs data) and the composer's English chip ARE labels.
    • Tinted with the label's background and colour tokens.
  • The nav: a vertical secondary link menu (<ui-menu vertical secondary link>).
    • Its look set through the menu's item, icon and menu parts, as on Brand Montage (I21).
  • The Light / Dark pill: a segmented menu, retinted through its surface and colour tokens.
    • No inset thumb, a hairline between (I6, I14).
  • App and template cards: cards with page markup inside.
    • No card part token exists for an italic serif description.
    • An app card is href="#build", so it's a real link, its click handled.
  • "Your spell": a plain numbered list with CSS counters, not an ordered Spell UI list.
    • The list has no marker font token, for the mono numbers.
  • The streak's 7 dots: plain spans, an image named "5 of 7 days" (role=img).
    • Not a rating: it isn't one.
  • The avatar: a plain span; Spell UI's avatar is image-only.
  • The switches: toggle checkboxes (<ui-checkbox type="toggle" fitted>), each named by an aria-label.
    • Retinted with the checkbox's tokens: a white knob in dark too.
  • The language: a small select.
  • The toast: UI.toast().
  • Every control of the original works, keyboard included; only layout and decoration are page markup.
  • The pill and nav still lean on ::part() and generic tokens, until I21 and I14 are fixed.
