What the brand pages need to open: the internet for the originals, and the page server for most of them.

  • Internet: the originals load React from unpkg, and Font Awesome from jsDelivr.
  • Page server: these don't work from file://:
    • the Compare view
    • four originals that fetch local files: Color Palette, Color Set Chooser, Theme Creator, Design Guide
  • Page server: every Spell copy (.spell.html) too, since its bundle is an ES module (J4).
    • Its icons come from disk, so it needs no internet.
