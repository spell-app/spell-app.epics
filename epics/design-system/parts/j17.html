P5, Brand Palette.spell.html. No ladder is the point on this page (5-chip palettes and specimens), so no <ui-brand-color-range>: the page script does the original's arithmetic on L / C / H (Aubergine L 27%, C x 0.65 capped at 0.11, same hue; Lilac, Lavender, soft, dark background, the House of Owen tints ...) and makes each colour hex with window.Palette.oklchToHex() (gamut-mapped as the original: out-of-sRGB colours lose chroma), so every hex equals the original's. Updated (was: oklch() text, before the bundle put Palette on window, I7). The chips show those hexes, and the specimens take them as inline --ui-* tokens on real elements: a one-item <ui-menu> (the Build nav item), <ui-checkbox selected>, a circular <ui-button>, <ui-header>, <ui-label> for the id pill. Each specimen pane forces its scheme (ui-light / ui-dark) with the candidate's colour as its --ui-background, so the theme's tokens read right in it on a light or dark page.

  • the contrast figures (white 5.9 / 5.5 / 8.9 / 6.5:1 AA) and every hex printed under a chip or a column name come from Palette at load, as the original's
  • Turn 2's per-row tint is three small stacked chips, not a 3-band gradient; the original House of Owen beside each id is a 12px square chip, not a 12px-tall bar (chips are always square)
  • the sections sit on --spell-surface-tint (the original's #F2F2FE lavender wash), the page on --ui-background, not Claude Design's canvas chrome
  • the pill reads + Add habit as a plus icon and Add habit

Net effect:

  • every colour, chip and specimen, and every printed hex and contrast figure matches the original's exactly (checked in the browser)
  • the page works in dark mode; the original is light only
