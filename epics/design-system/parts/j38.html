The composer's casting attribute is the page's "it's building" switch; the element never sets it itself.

  • The page sets it on ui-cast, and clears it when the build is done.
  • While it's on:
    • the Cast button shows a spinning circle (still, with reduced motion)
    • the card is aria-busy
    • "Casting your spell…" is announced, in a status region
    • casting again is ignored
    • the text stays editable

The text box grows with its text, from rows lines (default 3) up to 12 lines, then scrolls.

  • The 12 lines are a token, --ui-brand-composer-max-height.
  • It uses CSS field-sizing: content.
    • Chrome and Safari grow.
    • Firefox doesn't have it yet, so there the box stays rows tall and scrolls.
  • The page's "Building…" steps pair with composer.casting = true / false.
  • A long spell makes the card taller, instead of scrolling inside 3 lines.
