casting (boolean attribute) is the page's "it's building" switch: the page sets it on ui-cast and clears it when the build is done; the element never sets it itself. While it's on, the Cast button shows a spinning circle (still, with reduced motion), the card is aria-busy, "Casting your spell…" is announced (a role=status region), and casting again is ignored; the text stays editable.

The text box grows with its text from rows lines (default 3) up to 12 lines (--ui-brand-composer-max-height), then scrolls. It uses CSS field-sizing: content: Chrome and Safari grow; Firefox doesn't have it yet, so there it stays rows tall and scrolls.

  • the page's "Building…" steps pair with composer.casting = true / false
  • a long spell makes the card taller instead of scrolling inside 3 lines
