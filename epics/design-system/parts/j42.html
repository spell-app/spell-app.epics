Nav: chose <ui-menu vertical secondary fluid> over <ui-list link>: it has group headers (<ui-item type="header">), an icon per item, a selected fill and ui-select, where the list has none of the headers and keeps its link colours private (I28). Its item look still needs the item / icon parts (I21, as Brand Montage), plus width: 100% (I33). Steps: NOT <ui-step> (Fomantic's steps are a progress bar of stages, not numbered instructions): an <ol> for layout, each number a <ui-label circular> on --spell-accent-soft, serif digits via --ui-font-family. Previous / Next: <ui-card link fluid>. "What you'll need": <ui-brand-checklist> of done checks. "On this page" stays static, as the original's.

Net effect:

  • every control is a Spell UI element; three parts hacks (nav items, TOC bullets, tip / check marks) are each an issue
  • the six nav items with no page do nothing, as in the original
