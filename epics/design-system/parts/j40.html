The checklist (<ui-brand-checklist>) is a new element, built on Spell UI's machinery, since no existing one draws a round to-do mark.

  • Looked first:
    • the checkbox is Fomantic's box: a native input under a label, with its own sheet, form-associated
    • the steps element is a horizontal wizard, whose steps each say their own state
    • restyling either would fight its sheet
  • The list owns its checks, as the tabs element owns its panes.
    • Through PartContext, with ownsParts: check.
    • Each check asks the list how to show, so one step moves them all.
  • selected is auto-controlled (Controlled), so a change handler that re-sets it wins.
  • The checked alias copies the checkbox's (CheckHost).
  • The hidden "done" copies the step's hidden "Completed".
  • One more family for the later move into Spell UI (D2): a generic checklist, brand-coloured only through the --spell-* roles (plain Spell UI tokens without the theme).
