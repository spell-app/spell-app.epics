Three things the colour range (<ui-brand-color-range>) does that may surprise:

  • It sends ui-change when its INPUTS change the ladder, as briefed.
    • That is, on attribute and property writes.
    • Every other change event in Spell UI fires on a user action.
  • anchor="auto" puts House of Owen (#8E96B5, L 0.677) on step 400, not 500.
    • 400's target lightness (0.72) is nearer than 500's (0.63).
    • The brand's own set pins it at 500 (buildPalette()), so the docs examples say anchor="500".
  • Chip labels clip on narrow chips, as the Color Palette page's do at small widths.
    • E.g. label="oklch" on a 48px chip.
    • Or any label across a 17-step range in a narrow column.
