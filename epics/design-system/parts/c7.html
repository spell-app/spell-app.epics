• <ui-brand-color-range> dispatches ui-change when its INPUTS change the ladder (as briefed), i.e. on attribute / property writes, not on a user action as every other ui-change in Spell UI.
  • anchor="auto" puts House of Owen (#8E96B5, L 0.677) on 400, not 500: 400's target lightness (0.72) is nearer than 500's (0.63). The brand's own set pins it at 500 (buildPalette()), so the docs examples say anchor="500".
  • Chip labels clip on narrow chips (label="oklch" on a 48px chip, any label across a 17-step range in a narrow column), as the Color Palette page's do at small widths.
