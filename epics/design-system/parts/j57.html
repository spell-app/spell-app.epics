Three brand field fixes (I3, I12, I13): a rich info tip, a steady row height, and full-width segmented menus.

  • slot="info": the rich version of info.
    • The attribute stays the short form.
    • The icon shows when either is there.
  • The actions box is the row's height, 1.25em.
    • A taller pill (a mini circular button) overhangs it evenly.
    • So Reset appearing never moves the slider.
  • A slotted menu gets a block host, which the row stretches.
    • The rule: ::slotted(ui-menu:not([hidden])) { display: block }.
    • An outer-tree rule beats the menu's own :host { display: contents }.
    • A segmented menu with alignment="fluid" then fills the row.
    • Done in the field, not in the menu: no menu change, and a menu elsewhere keeps contents.
  • Color Set Chooser: rich tips, through slot="info"; no row jump.
  • Theme Creator: drop the <div class="seg"> wrappers and their CSS.
