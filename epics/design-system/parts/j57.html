  • slot="info": the rich version of info (the attribute stays the short form); the icon shows when either is there.
  • The actions box is the row's height (1.25em): a taller pill (a mini circular <ui-button>) overhangs it evenly, so Reset appearing never moves the slider.

Done in the field, not in ui-menu: no menu change, and a menu elsewhere keeps contents.

  • Color Set Chooser: rich tips through slot="info"; no row jump.
