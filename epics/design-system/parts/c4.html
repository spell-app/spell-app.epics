<ui-brand-color-picker value="#abc"> (or oklch(...), 142 150 181) READS as #AABBCC: the readout, the fields, the form value and every event's detail.value are upper-case #RRGGBB. But the host's value property and attribute keep the text as it was set, until the user edits the colour (then they're the #RRGGBB the edit made). Rewriting the host on our own would be an event-less write the page didn't ask for, and would fight a framework that controls value. Read the colour from ui-change, or the form, when it must be normalised.
