A property panel, like the Color Set Chooser's left column: a tinted box with a full-width header band, collapsible sub-heads, and tight 16px padding.

  • <ui-section> already has about 80% of it: a header, a subhead, collapsing with animation, actions, a badge, nesting.
  • So the panel is a thin element on the same machinery (D9): the outer panel is the box and header band, and each nested panel is a sub-head band. Uncoloured it is primary; color="accent" is the ivory (Q13).
  • It began in the brand's components, like every new element (D2), and moved into Spell UI on 2026-10-05 as <ui-panel>, its tokens --ui-panel-*. 
<ui-brand-panel header="Color Set" collapsible>
  <ui-input placeholder="Name, e.g. brand"></ui-input>
  <ui-brand-panel header="Tweak" collapsible>
    <ui-brand-field label="Vibrancy" value="100%">...</ui-brand-field>
  </ui-brand-panel>
  <ui-brand-panel header="Presets" collapsible collapsed>
    <ui-brand-color-set>...</ui-brand-color-set>
  </ui-brand-panel>
</ui-brand-panel>
