New public tokens, each read through a private alias in ui-markdown.css, defaults = GitHub's look as before:

  • --ui-markdown-heading-font-family (the article's), -heading-weight (600), -heading-line-height (1.25), -heading-margin (1.5em 1em, a margin-block)
  • -heading-rule (the border under h1 / h2, 1px solid the rule colour; none drops it) and -heading-rule-gap (0.3em: without it a dropped rule would still leave the padding)
  • -h1-size / -h2-size / -h3-size (2 / 1.5 / 1.25em); h4-h6 stay fixed
  • -hr-height (0.25em), -strong-color, -code-color (the text's)
  • -heading-scroll-margin (0): added beyond the issue, so reveal() / #id land below a sticky header

spell-brand.css sets them to the Design Guide's look: serif bold, no rule, ## calc(28em / 15), ### calc(19em / 15), margin 1.1em 0.43em, 1px hr, strong / code in --spell-text-strong, plus heading colour, rule colour and code background (which the guide page set itself). Not taken: the guide's -0.012em heading tracking (no token). editable's preview draws <ui-header>s, which these tokens don't reach.

Net effect:

  • every <ui-markdown> under the Spell Brand theme reads like the Design Guide; other themes unchanged
  • the Design Guide page can drop its --ui-markdown-* colour block (the theme has it)
