Carries over J7 / J9 (closed) to the HSL picker, with what the rows added:

  • The colour being edited is HSL (working), apart from value (#RRGGBB): a grey keeps its hue, and black or white keep hue AND saturation, so the square and the hue slider don't jump as the colour passes through them. Palette gained rgbToHsl, hslToRgb, hexToHsl, hslToHex, formatHsl, format(hex, "hsl"), and parse() reads hsl(...); every 8-bit colour on a grid round-trips (tested).
  • The square's keyboard / screen-reader story is J7's: two visually hidden native ranges, now "Saturation" (the one tab stop) and "Lightness", aria-roledescription="2D slider"; arrows 1%, Shift 10%, Home / End saturation 0 / 100%.
  • Rows: a mono label, the inputs JOINED in one box (hairlines between; units ° / % inside), and a copy button. HSL: H°, S%, L%. RGB: the hex field (anything Palette.parse() reads). OKLCH: L%, C, H; a colour a screen can't show is gamut-mapped (Palette.oklchToHex()).
  • Copy buttons are native <button>s drawn as circular basic icon buttons by the sheet (a hairline ring, no fill), not <ui-button>s: the element's shadow root would depend on the ui-button family being defined, and component files import only $/ui/core. Icon copy outline (the original's fa-regular fa-copy), a check in the success colour for 1.4 s (as <ui-brand-color>), "Copied ..." announced, :state(copied), and ui-copy { value, format, originalEvent } with format hsl / hex / oklch (hex, not rgb: <ui-brand-color>'s word for the same text).
  • HSL copies the row AS SHOWN (formatHsl(working): a grey copies with the hue it shows); whole degrees and percentages, so it may land one step off value in 8-bit.
  • Head-row header / actions slots and thumbs without a white ring: as J9. The "hatched area" hint line is gone.
  • three formats to type in and copy, in the brand's look
  • a grey, black or white never loses the hue / saturation the picker shows
