The HSL picker keeps the old picker's choices (the closed J7 and J9), plus what its rows added.

  • The colour being edited is kept as HSL, in working; only value is a hex.
    • A grey keeps its hue; black or white keep hue AND saturation.
    • So the square and the hue slider don't jump as the colour passes through them.
    • Palette gained the HSL conversions, and its parser reads hsl(...).
      • rgbToHsl, hslToRgb
      • hexToHsl, hslToHex
      • formatHsl, format(hex, "hsl")
    • Every 8-bit colour on a grid round-trips (tested).
  • The square's keyboard and screen-reader story is J7's: two visually hidden native ranges.
    • Now "Saturation" (the one tab stop) and "Lightness".
    • Announced as aria-roledescription="2D slider".
    • Arrows move 1%, Shift 10%; Home / End set saturation to 0 / 100%.
  • Each row: a mono label, the inputs JOINED in one box, and a copy button.
    • Hairlines between the inputs; the units (° and %) inside.
    • HSL: H°, S%, L%.
    • RGB: the hex field, which takes anything Palette.parse() reads.
    • OKLCH: L%, C, H; a colour a screen can't show is gamut-mapped (Palette.oklchToHex()).
  • Copy buttons are native buttons, drawn by the sheet as circular basic icon buttons (a hairline ring, no fill).
    • Not <ui-button>s: the element's shadow root would then depend on the button family being defined, and component files import only spell-ui/core.
    • Icon copy outline, the original's fa-regular fa-copy.
    • As the colour chip does: a check in the success colour for 1.4 seconds, "Copied ..." announced, :state(copied).
    • A ui-copy event, with { value, format, originalEvent }.
    • Its format names the row copied:
      • hsl
      • hex, not rgb: the colour chip's word for the same text
      • oklch
  • HSL copies the row AS SHOWN (formatHsl(working)), so a grey copies with the hue it shows.
    • Whole degrees and percentages, so it may land one step off value in 8-bit.
  • As J9: header and actions slots in the head row, and thumbs without a white ring.
  • The "hatched area" hint line is gone.
  • Three formats to type in and copy, in the brand's look.
  • A grey, black or white never loses the hue / saturation the picker shows.
