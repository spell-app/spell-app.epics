packages/brand/spell-design-system/ is Claude Design's output: 13 pages, a token set, and logo assets. The pages are NOT plain HTML.

  • Each *.dc.html page is a <x-dc> template that Claude Design's own runtime (support.js, 69 KB, generated) compiles into React at load time.
    • Templating: {{ value }}, <sc-if>, <sc-for>, and style-hover="..." for hover styles.
    • State and handlers live in a <script type="text/x-dc"> class.
    • React and Font Awesome come from CDNs, so the pages need the internet.
    • Four pages also fetch local files (lib/palette.mjs, readme.md), so they need a server: they don't work from file://.
  • Nearly everything is inline style="...". The sp-* classes in components/components.css (and the 28 thin React wrappers over them in components/*/) are used only by the small specimen cards, never by the 13 pages.
  • The tokens (tokens/*.css): 17-step OKLCH color ladders for 20 color sets, semantic light and dark tokens (--surface-card, --text-strong, --accent), type, a 4px spacing grid, radii, shadows and motion.

1.5 <ui-field> and <ui-brand-field>

You asked for an analysis. Today's <ui-field> is Fomantic's .field: a block with a label above a control, that <ui-form> finds and puts error messages into.

  • It renders <div class="field"><slot></slot> plus an error "prompt" label that appears when <ui-form> calls showErrors().
  • Attributes: state (error, info, success, warning), inline, required (an asterisk), disabled, width.
  • No label attribute: you write the <label> yourself.
  • No place for help text, buttons, a value readout or an info tooltip.

What the brand's inspector field (the Color Set Chooser's "Vibrancy" row) needs:

Four new elements, from the Color Palette and Color Set Chooser pages, in packages/brand/components for now (D2):

  • <ui-brand-color value="#6550CA">: a square chip. Optional label (hex, OKLCH, or a name), "AA" when text on it passes contrast, click to copy, a popover with its values.
  • <ui-brand-color-set>: a row or grid of chips that you pick one from (the Chooser's presets, Theme Creator's set pickers), or a whole 17-step ladder (the Palette's rows).
  • <ui-brand-color-picker>: the Chooser's popover: a lightness × colourfulness square drawn on a canvas, a hue slider whose track is a rainbow, and hex / OKLCH inputs.
  • <ui-brand-color-range>: a ladder made from one base color (the Chooser's "variants"), using the brand's generateScale() math from lib/palette.mjs, ported to TypeScript.

"OKLCH" is a way to write a color as Lightness, Chroma (colourfulness) and Hue that matches what eyes see: two colors with the same L look equally light. The brand generates every ladder in it.
