How a drawing writes a table (gap 1), and what its parts are called.

  • Today ui-table only dresses a native <table> written inside it: its whole look is about 515 rules on the native row and cell tags. A drawing has no native table, so it has nothing to dress.
  • It also has a list mode today: give it rows (a list) and column-defs, and it draws the table itself, sorted. But its cells are plain text only, and the columns are written as JSON.
  • ui-row and ui-column are the grid's, so the table's parts take the family's prefix, as ui-breadcrumb-section and ui-placeholder-line do.
  • elemental-spell plans a for each in drawings: with it, a table "filled from a list" is just rows written once and repeated.
  • <table-row> and <table-cell>; header on a row makes the header row, on a cell a row's header cell; footer on a row; caption on the table.
  • One way to write any table: typed out, or repeated over a list.
  • A cell holds anything: a button, an image, a label.
  • Sorting, striping, celled and the phone layout keep working: the look is ported to the new tags.
  • Cost: about 8h; no row spanning (cells can span columns, not rows).
<table celled sortable caption="Scores">
  <table-row header>
    <table-cell>Player</table-cell><table-cell>Score</table-cell>
  </table-row>
  <table-row><table-cell>Ann</table-cell><table-cell>12</table-cell></table-row>
</table>
  • <table rows="..."> with <table-column key="player" header="Player"> children, the markup form of column-defs.
  • Keeps the native table inside, so the whole look works as it is.
  • Cost: about 4-6h; a table typed out by hand has to be written as a list; a cell that's more than text needs a cell template, which means Spell UI copying a drawing's holes, elemental-spell's job. 
<table celled sortable rows="{scores}">
  <table-column key="player" header="Player"/>
  <table-column key="points" header="Score"/>
</table>
  • A's rows and cells, and B's column tags for a quick table from a list.
  • Cost: about 12-14h; two ways to write the same table.
  • New: ui-table-row, ui-table-cell; caption on ui-table.
  • In a drawing: <table-row>, <table-cell>.
  • Today's native-table dressing and list mode stay, for plain HTML pages.
  • A table from a list waits on elemental-spell's for each.
