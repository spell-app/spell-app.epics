The first proposal, as Owen commented on it

About fifteen new tags and a handful of new attributes on existing ones. The names below are the proposal: the open questions (Q1 to Q4) settle the ones worth Owen's say.

  • In a drawing, a tag is written by its SHORT name, its Spell UI name without the ui-: ui-table-row is <table-row>.
  • Each also gets a Spanish name, ASCII as every Spell UI tag's is (ui-text is es-texto).

Owen's comments M1-M9 changed most of this table. It stays as he commented on it; each group's question holds its answer, and the decided names are now in the table at the top of this section.

  • Tables: <row> and <cell> (Q2 decided, Q5).
  • Layout box: one <stack>, after Web Awesome (Q3).
  • Paragraph: <text paragraph>, no ui-paragraph (Q6).
  • Links: a global link=, no ui-link (Q7).
  • Letter styles: a global font=, several values (Q8).
  • Quotes: <quote> (Q9); key caps: <keys> (Q10).
  • Page frame (Q11), video and audio (Q12), term list (Q13), figure (Q14).
  • Drawing surface: later, caveat C2 (work for later).
  • Request r1 (Owen's attribute renames, from debut) joins the epic: its words (color, direction, spacing, align, link, label ...) replace the ones above, and its open points are Q15 to Q27.
