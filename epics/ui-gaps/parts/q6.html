How a drawing writes a paragraph: a block of text with holes for its values.

  • Owen's comment on 1.2's table: <text paragraph>.
  • Today ui-text is inline: a <span>, a size, a colour, a status colour, and a line height of 1, which squeezes lines that wrap.
  • paragraph would make it a block: a <p> inside (so screen readers hear a paragraph), a line height for reading (about 1.5), and room after it before the next one.
  • Markdown (ui-markdown) already draws paragraphs, but it can't hold a drawing's values.
  • Owen's words.
  • Everything text takes works on it too: size, color, font, align.
  • Cost: one attribute changes text from inline to a block; about 1h.
<text paragraph>
  You have {score} points.
  Press Deal to play again.
</text>
  • <paragraph>: a block is its own tag, text stays inline.
  • Cost: one more tag to learn and translate; about 2h.
<paragraph>
  You have {score} points.
</paragraph>
  • ui-text gains paragraph: a <p>, a reading line height, room after.
  • No new tag.
