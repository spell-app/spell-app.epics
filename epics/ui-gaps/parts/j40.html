TitleFit writes each stage's look on the menu (whole, then icons only), reads the sizes, and writes back the stage showing, all before the browser paints: nothing flashes, and a page's own CSS for :state(icons-only) counts (the docs make each button 34px square there).

The plan's sketch worked the icons-only widths out from the whole look; that missed exactly such page CSS. The answer is then the same from either side of a width, so it never flips.
