How a drawing writes a quotation.

  • Owen's comment on 1.2's table: "<quote> is good".
  • Today only markdown draws a quote: a block with a bar down its start and muted text.
  • HTML has two: <blockquote> (a block, set apart) and <q> (a few words inside a sentence, its quotation marks drawn by the browser in the page's language).
  • <quote> is a block quote; <quote inline> a quotation inside a sentence.
  • Optional by for who said it, drawn under a block quote.
  • Cost: about 1-2h.
<quote by="Ada">
  Imagination is the discovering faculty.
</quote>
She said <quote inline>go</quote>.
  • <quote> for the block; font="quote" on text for the inline one.
  • Cost: a quotation isn't a way letters look, so it sits oddly in font.
  • New: ui-quote; in a drawing <quote>.
  • inline for a quotation in a sentence; by for who said it.
