  1. <text paragraph> (Q6): ui-text draws a <p>, as a block, with a real line height and the space between paragraphs; font and link from P3 work inside it.
  2. A new ui-quote (Q9): a block quote, its look from the markdown pages'; inline draws a quotation inside a sentence, with the language's own marks.
  3. A new ui-link (Q7): the same link P3 gives every tag, as a tag of its own, for a sentence's link; focus ring, target, disabled drops the link.
  4. A new ui-keys (Q10): shortcut="meta+S" read by the runtime's Chord, drawn as key caps: ⌘S on a Mac, Ctrl+S elsewhere, caps 1px apart as the docs search draws them; repeats for a second shortcut.
  5. Note: in Chord, Meta means the Meta key itself, while spellx's meta means ⌘ or Ctrl (elemental-spell Q31), Chord's Mod; ui-keys reads meta as Mod, and says so in its docs.
  6. One key-cap look as tokens, shared with the docs search.
