--markup-only skipped tag renames altogether, so the content folder's drawn examples would have stayed old (and drawn nothing). Now it renames a tag where a browser draws it: never escaped markup, a tag quoted in an attribute, a Markdown code span or fence, a selector or token (the record). It also reads style sheets (a renamed tag is a selector there), and leaves a request sent to an epic (requests/r<n>/request.md, someone's words verbatim) whatever it says.
