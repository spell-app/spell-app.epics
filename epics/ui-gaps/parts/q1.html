How a drawing writes a sentence: paragraphs, links, bold and italic, inline code, key caps and highlights (gaps 3, 4 and 5, and the minor quotes and sub- and superscript).

  • Today ui-text is the one inline text tag: a size, a colour, a status colour. It draws a <span>.
  • Spell UI's own rule is "one word, one element": a look is a word on the one noun (<ui-button primary>), not a second tag.
  • Key caps are different: they read an action's shortcut="meta+S" (elemental-spell's Q38) and show it as ⌘S on a Mac, Ctrl+S elsewhere. That's behaviour, so they're a tag of their own in every option.
  • New tags: <paragraph>, <link>, <keys>.
  • On <text>: bold, italic, code, highlighted, quote, subscript, superscript.
  • Each style still draws the right HTML inside (bold a <strong>), so screen readers hear it.
  • A link is its own tag because it's something you click and tab to, not a look.
  • Cost: 3 new tags, 7 attributes; about 6-8h with docs and Spanish.
<paragraph>
  Press <keys shortcut="meta+S"/> to save,
  or read <link href="help.html">the help</link>.
  It's <text bold>free</text>.
</paragraph>
  • <paragraph>, <link>, <keys>, plus <bold>, <italic>, <highlight>, <quote>, <sub>, <sup>.
  • Shortest to type, and closest to an HTML habit.
  • Cost: 9 new tags, each with its Spanish name and docs page; inline code needs another name, since ui-code is the code block; breaks "one word, one element". 
<paragraph>
  Press <keys shortcut="meta+S"/> to save,
  or read <link href="help.html">the help</link>.
  It's <bold>free</bold>.
</paragraph>
  • Only <keys> is new. <text paragraph>, <text href>, <text bold>.
  • Fewest tags, and cheapest: about 4-5h.
  • Cost: a paragraph is a block and text is inline, so one tag changes its whole shape by an attribute; a link hidden as "text" doesn't say it's clickable. 
<text paragraph>
  Press <keys shortcut="meta+S"/> to save,
  or read <text href="help.html">the help</text>.
  It's <text bold>free</text>.
</text>
  • New: ui-paragraph, ui-link, ui-keys; in a drawing <paragraph>, <link>, <keys>.
  • ui-text gains bold, italic, code, highlighted, quote, subscript, superscript.
  • ui-paragraph quote draws a block quote.
  • Built in two phases: paragraphs and links, then the inline styles and key caps.
