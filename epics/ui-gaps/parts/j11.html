Fomantic's classes are the same, but where they sit in an element's class string moved for the renamed attributes: a table attached at the top's scroller is top attached resizable short scrolling scroller, was resizable top attached ....

  • Why: the class builder writes each kind of attribute in a fixed order, and the renames changed some attributes' kind (an on / off switch became a value).
  • The CSS keys on the classes and on adjacent phrases (top attached), never on the order between phrases, so nothing looks different. The visual tests will say for sure.
  • Tests that pinned a whole class string were brought up to date (table, progress, slider).
  • One case can't be written any more: a table's compact="very" padded (contradictory) is now one padding, the last old name wins.
  • class strings read in a different order; the look is the same
