The header heading-text shorthand is now heading (old name header) on card, modal, step, message, popup, toast and flyout.

  • Left as they are: ui-header, placeholder-header, calendar, dropdown and section name a PART or a SLOT header, not an attribute; those names are a CSS contract (::part(header)). The seven tags' own header part keeps its name too.
  • The docs widgets (ui-docs-toc, -tokens, -nav, -example, -api) keep their own header attribute: internal. The docs nav's <ui-message header> stays on the old name until the JSX types are regenerated.
  • The dialog's own member heading (the slotted <ui-header> that names it) became slottedHeading, so the attribute could take the name.
  • Spanish: heading is encabezado, as header was; header's entry stays, for the docs widgets.
  • <ui-card heading="Hearts">; header= still works, with a console note
