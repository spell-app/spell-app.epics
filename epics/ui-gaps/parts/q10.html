How a drawing shows a keyboard shortcut as key caps: ⌘S on a Mac, Ctrl+S elsewhere.

  • elemental-spell's actions write their shortcuts as shortcut="meta+S" (): meta is ⌘ on a Mac and Ctrl elsewhere; shift, option and control by name.
  • Menus, toolbars and hints show them; nothing in Spell UI draws key caps today.
  • What's there to build on:
    • Spell UI's shortcut parser, Chord, reads Mod+Shift+K
    • the runtime knows a Mac from the rest (UI.browser.isApple)
    • the docs' search box draws its own key caps, a chord's caps 1px apart so they read as one
  • That's behaviour, not a look, so it's a tag of its own.
  • <keys shortcut="meta+S"/>: the action's own word, so a shortcut copies straight from it.
  • Several shortcuts, as an action may have: shortcut="meta+S F2".
  • Cost: about 2h.
