r1: "select -> part", one of Owen's other renames. What select does today, and why part is the browser's word already.

  • Today select is a CSS selector that picks ONE piece of a page: include only the release notes from a page, not the whole page.
  • Three families take it:
    • ui-include: "include only the first element of source it matches"
    • ui-property-editor and its ui-property-group: only that piece of the layout page is used
  • (ui-select also has a part named select, its native box: not this.)
  • part is HTML's attribute for styling inside a component from outside (::part(header)), on every element. In code, element.part is the browser's list of them.
  • So part="#notes" works only while the element isn't inside another component, where it would become that component's part; and the browser splits part="main > section" into three words. 
<ui-include source="examples/release-notes.html" select="#notes"></ui-include>   <!-- today -->
<ui-include source="examples/release-notes.html" only="#notes"></ui-include>     <!-- A -->
<ui-include source="examples/release-notes.html" part="#notes"></ui-include>     <!-- C, r1 -->
  • Reads as English: "include release-notes.html, only #notes".
