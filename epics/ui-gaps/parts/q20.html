r1: "labeled and structured: no name yet, ask Owen". What each does today, and names in r1's style: each word says one thing.

labeled: four meanings in six families

Family Today What it draws
button, buttons, dropdown labeled, labeled="right" the icon in a box of its own, at the start or the end
button labeled="left" with label which side the joined label box goes (r1 renames that box badge)
input labeled="right | corner | left corner" with label="°" where the joined label box sits: before, after, or folded into a corner
menu labeled a large icon above each item's text
slider labeled labels along the track, at the steps
  • The input's joined box is the same idea as the button's (a unit, "°" or "%", joined to the field). And r1 turns aria-label into label, so the input's label="°" needs a new name anyway: the proposal makes it badge too. 
<ui-input type="number" value="250" labeled="right" label="°" aria-label="Hue">   <!-- today -->
<ui-input type="number" value="250" badge="°" badge-side="end" label="Hue">      <!-- A -->

Choices

A · A plain word per meaning (recommended)

  • icon-box="start | end": button, buttons, dropdown.
  • badge-side="start | end | corner | start-corner": button, input (with badge).
  • icon-above: menu.
  • step-labels: slider.
  • Cost: four words where there was one, each to learn and translate.

B · Keep labeled, as Fomantic has it

  • One word, described tag by tag; Fomantic's examples still read across.
  • Cost: "labeled" means four things, and none of them is a label once r1 is done.
  • labeled becomes icon-box, badge-side, icon-above or step-labels, by family; labeled an old name.
  • The input's joined box becomes badge, as the button's does.

structured: the table only

  • ui-table's structured: "collapsed borders, for rowspan / colspan headers". Fomantic's word, for a header row whose cells span several columns or rows.
  • The rows and cells this epic adds can span columns, not rows.
<ui-table spanning celled>
  <ui-row header><ui-cell span="2">Player</ui-cell><ui-cell>Score</ui-cell></ui-row>
  ...
</ui-table>

Choices

A · spanning (recommended)

  • Says when you need it: header cells that span.
  • Cost: a word Fomantic doesn't use.

B · An appearance word

  • appearance="structured", beside striped and celled (or whatever word the style question picks).
  • Cost: it's a border rule, not a look you'd pick for its own sake.

C · Keep structured

  • Fomantic's; nothing to rename.
  • Cost: says nothing about what it does.
  • structured becomes spanning on ui-table; structured an old name.
