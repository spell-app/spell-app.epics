The shared link on an element whose family draws no link of its own (a segment, a card later) goes there when it's clicked, as the plan says.

  • It isn't a real link: no Tab stop, no Enter, no middle-click for a new tab, no link role for screen readers.
  • Why: turning any element into a focusable link would put a tab stop on every box, and a box can hold buttons of its own.
  • A real link is <text link> (built here) or <link> (P9); families that draw an <a> (button, image, label ...) stay real links.
