link was a hover look on item, list, items, menu, toolbar and step ("looks clickable"), and is now where a click goes (r1 #12). Both names are link, so the element tells them apart by what's written:

  • <ui-item link>, bare: the old look, read as appearance="link"
  • <ui-item link="help.html">: the new link
  • removed: both let go

It's in the kit's DOM element and in the static render, so card, cards, icon and emoji's link look work the same way.

  • old pages with a bare link keep their look; new ones write appearance="link"
