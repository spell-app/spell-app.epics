r1: "<ui-breadcrumb> -> <ui-breadcrumbs>; <ui-breadcrumb-section> -> <ui-breadcrumb>". The old container's name becomes the new child's, so the two can't both work at once.

  • During an alias period, <ui-breadcrumb> would have to be the old trail and the new step at the same time.
  • So this rename has none: every page, docs page and component that writes a breadcrumb changes in the same phase as the rename, by the sweep's script.
  • A page outside the repos with the old tags draws a trail of one step until it's rewritten.
<ui-breadcrumb><ui-breadcrumb-section link="/">Home</ui-breadcrumb-section></ui-breadcrumb>   <!-- before -->
<ui-breadcrumbs><ui-breadcrumb link="/">Home</ui-breadcrumb></ui-breadcrumbs>                <!-- after -->
  • The breadcrumb rename lands with its sweep, in one commit per repo; no alias for either tag.
