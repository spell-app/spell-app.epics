Before, <ui-menu appearance="pointing" secondary> merged the two (its docs said so). Now appearance takes several words, and the old switches are its old names, so as everywhere the new name wins when both are written: that menu is pointing only.

  • Every docs page and example was rewritten to appearance="pointing secondary".
  • Tabs the same: appearance="segmented" basic is now appearance="segmented basic".
  • a page mixing both spellings loses its old switch's look until it's rewritten (P6's sweep does)
