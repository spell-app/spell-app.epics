  • a README writes an example as an html example block; the tool draws it in a <ui-example> with the page server's Spell UI, light and dark, into images/readme/<page>.<n>.png beside the page, and writes a <picture> and the markup's fingerprint under the block
  • spell readme check fails a picture older than its markup (rule picture)
