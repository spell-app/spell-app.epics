  1. Read the commands guide first: there's no ui noun yet, so Spell UI adds one through its package.json's commands, spell ui rename [--write] <folder>, with a row in the commands page (commands.json5, then spell commands check).
  2. The script reads the old names from the vocabularies themselves (what P2's renames declare), so it never keeps its own list.
  3. Without --write it lists each file and the renames it would make; with it, it rewrites them in place, attribute by attribute (primary becomes color="primary"), and the two breadcrumb tags together.
  4. It reads HTML pages, Markdown and the JSX in .tsx files; spell files later, once spellx has drawings.
  5. Its own tests: a before / after page per kind of rename.
  6. Run it over each repo, lowest first (the kit, spell-ui, spell-brand, spell-epic, spell-app), then the content repo's ~2400 pages; each repo's diff its own commit.
  7. Then the old names go (Q16): P2's alias table emptied, the console note gone; a page still using one shows it unstyled, which yarn test and epic lint --all catch.
  8. Checked: the script's tests; yarn test over every repo; epic lint --all; a dry run printing nothing left.
  9. Left out: pages outside the repos; elemental-spell's own drafts, which it rewrites with the same script.
