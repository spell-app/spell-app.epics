What the global font attribute holds: how a tag's letters look.

  • Owen's comment on 1.2's table: a global attribute, font="bold | italic | underline | strikethrough | etc", with several values at once.
  • So <text font="bold italic">, and the same on a button or a header.
  • Inside text, each value draws its HTML element too, so screen readers hear it:
    • bold: <strong>; italic: <em>
    • code: <code>; highlight: <mark>
    • subscript, superscript: <sub>, <sup>
    • underline, strikethrough: the look only (<s> for strikethrough)
  • On any other tag: the look only.
  • Inline code has three slightly different looks today (markdown's, the typography class's, the native-HTML styles'): one token for it, and one for highlights, settles them.
  • bold, italic, underline, strikethrough, code, highlight, subscript, superscript.
  • One place to look, and they combine: font="bold code".
  • Cost: code and highlight are more than a font (a background, a box); about 3h.
It's <text font="bold">free</text>:
run <text font="code">spell</text>.
  • font: bold, italic, underline, strikethrough, subscript, superscript.
  • code and highlight as words on text: <text code>, <text highlight>.
  • Cost: two places for "how it looks"; about 3h.
It's <text font="bold">free</text>:
run <text code>spell</text>.
  • font on every tag, several values: bold, italic, underline, strikethrough, code, highlight, subscript, superscript.
  • Inside text, each draws its HTML element; elsewhere, the look.
  • One inline-code look and one highlight look, as tokens.
