What Web Awesome does

  • Its layout is CSS CLASSES on a plain <div>, not elements:
    • wa-stack: a column, room between
    • wa-cluster: a row that wraps, for buttons, tags, metadata
    • wa-flank: two items, one at its own size, the other filling the rest
    • wa-split: items pushed to the two ends
    • wa-grid: as many columns as fit, each at least --min-column-size (20 characters by default): no breakpoints
    • wa-frame: a box of a fixed shape (square, landscape) for an image or video
  • Room between: wa-gap-0, then 3xs to 5xl on its space scale. Alignment: wa-align-items-start | center | end | stretch.
  • Spell UI already copied them as utility classes: .ui-stack, .ui-cluster, .ui-split, .ui-flank, .ui-frame, .ui-grid, on its own space ladder.
  • The catch: a drawing has no <div> to put a class on. So it needs an ELEMENT, which Web Awesome never needed. 
<div class="wa-cluster wa-gap-s">
  <wa-button>New game</wa-button>
  <wa-button>Undo</wa-button>
</div>
  • <stack> is a column; direction="horizontal" makes it a row, wrap lets it wrap (Web Awesome's cluster).
  • r1's words: spacing for the room between (none, xs, sm, md, lg), align for where children sit.
  • The two layouts drawings need nine times in ten, in one tag.
  • Flank, split and frame stay classes for plain HTML; the auto-column grid can be a later mode, columns="auto".
  • Cost: about 2-3h.
<stack direction="horizontal"
       wrap spacing="sm">
  <button>New game</button>
</stack>
  • <stack>, <cluster>, <flank>, <split>, <frame>, and an auto-column grid.
  • Each does one thing, exactly as Web Awesome's classes do.
  • Cost: six tags to learn and translate; "flank" and "split" are designers' words, not a novice's; about 6-8h; grid is taken by Fomantic's grid, so the auto grid needs another name.
  • <layout type="stack | cluster | flank | split | grid | frame">.
  • One tag, every Web Awesome layout.
  • Cost: the attributes each type takes differ (a flank has a flank size, a grid a column size), so one tag carries six sets; about 5-6h. 
<layout type="cluster" spacing="sm">
  • New: ui-stack; in a drawing <stack>.
  • Attributes: direction, wrap, spacing, align, fluid.
  • The .ui-* layout classes stay, for plain HTML.
  • A todo for Web Awesome's other layouts as elements, if drawings need them.

examine web-awesome first

What the plain layout box is called, and how it says its spacing (gap 2).

  • It lays its children out in a column or a row, with a gap between them, alignment and wrapping, and no look of its own: what a <div style="display: flex"> does in HTML.
  • The examples need it most: Solitaire, the task list and the calculator all lay themselves out with native <div>s today.
  • Spell UI already has utility classes for it, .ui-stack and .ui-cluster, and a spacing ladder of tokens (--ui-space-3xs to --ui-space-3xl), but no tag.
  • The attributes come from words Spell UI already uses: horizontal (lists, labels, statistics), alignment (menus), vertical-align (grids), wrapping (code).

Choices

A · stack (recommended)

  • SwiftUI's, Chakra's and Material UI's word, and the utility class's already.
  • A column by default; horizontal makes it a row.
  • gap takes the spacing words: none tiny small medium large huge.
<stack horizontal gap="small" alignment="center">
  <button>New game</button>
  <button>Undo</button>
</stack>

B · box

  • The plainest word: "a box".
  • Cost: says nothing about laying things out; needs row or column to say which, and those are the grid's words. 
<box direction="row" gap="small">

C · Two tags: stack and cluster

  • <stack> for a column, <cluster> for a row that wraps, as the utility classes split them.
  • Cost: two tags to learn and translate for one idea.
  • New: ui-stack; in a drawing <stack>.
  • Attributes: horizontal, gap, alignment, vertical-align, wrapping, fluid.
  • The .ui-stack utility class stays, for plain HTML.
