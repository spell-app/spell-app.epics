Typing |> inside a tag now writes /> (merged, 2301301). The bubbly look draws /> as a bar and a point, |⟩, so the editor now takes what you see as what you meant:

  • in a Spell drawing's tags and in HTML files (the property editor page)
  • between a tag's attributes, or right after its name or a value: <divider |> becomes <divider />, the caret after it
  • left alone in a quoted value, a {…} code value, an unquoted HTML value, a tag's text, and Spell code
  • one undo puts back the |> you typed

Before: | typed where the /> was. After: > typed.
