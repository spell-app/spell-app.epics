owenoak: “Doesn't get bubbles! (screenshot: Solitaire's Card.editor.spell in the code pane, its # heading, prose and <property-editor "card"> with <ui-property-group> / <ui-property> markup all drawn as plain black text: no bands, no colours)”

Fixed. A property editors file (Card.editor.spell) is now drawn like your other Spell files.

  • With the bubbly look on, it gets bubbles: the heading, the prose, and the <property-editor "card"> tag with its markup inside.
  • With the look off, it gets colour: the heading is bold and coloured, and the quoted values are coloured.
  • The tags inside are still plain text with the look off. Card.spell's tags look the same way.

Why it was plain:

  • The editor treats a property editors file as plain text, because the Inspector reads it but it's never compiled.
  • The code pane only drew Spell files, which get parsed, and HTML files. This file was neither, so it got no look at all.
  • Now the code pane draws it from its text alone, the way it draws Spell (FileStates.extensionsFor()). It also gets bold headings, and in tags the typing help that turns a typed |> into />.
  • The Spanish one, Carta.editor.es.spell, is drawn the same way.
