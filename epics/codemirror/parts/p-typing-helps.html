  • All nine typing helps work on the test page as they do in the app now:
    • the caret snaps into the body a blank line is drawn in, and the indent goes again if the line's left untyped; Backspace takes it out a level
    • a letter on a blank line takes the next line's indent
    • group , its , a open a name's quotes
    • a space after a tag's name writes the rest of the tag
    • a paste takes the indent where it lands, Cmd+V and the menu's Paste alike
    • Shift+Tab, or Backspace at a line's indent, takes the lines under it out a level too
    • Enter between a tag's attributes lines the rest up under the first attribute
    • Enter before a comment after code puts the comment on its own line
    • Enter leaves no spaces at the end of the line it splits
  • Typing { in color="blue" makes it color={blue}, and " after a code value's { makes it text again.
  • Each is one undo step, and none fires on an edit the editor writes itself.
  • Two editors on one file (the code pane and a slice) both follow, and only the one you type in helps.
