I20 colours a CSS file (styles.css). CSS written inside other files is still plain text:

  • a Spell type's <css> block (checked live: SpellEditor.spell's, its lines plain, bubbly look on)
  • a <style> in an HTML file (the HTML look draws tags, not what's inside them)

Colouring them means parsing each block's text with CodeMirror's CSS language and laying its colours over the Spell look: a new piece in both looks, not a few lines. Left for a later item.
