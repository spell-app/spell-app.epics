The move is many phases. Either the app keeps running on Monaco until CodeMirror has every feature, then swaps in one go, or a setting picks the editor while the move goes on.

  • View › Code Editor: Monaco or CodeMirror (default Monaco), so you can try each phase in the real app as it lands, and compare.
  • Main stays usable all along; each phase can merge.
  • The last phases flip the default, then remove Monaco and the setting together.
  • CodeMirror only on the test page until the switch phase.
  • No two-editor code paths for a while; but nothing to try in the real app until late.
  • From the first phase you can switch the real app's code pane to CodeMirror and try it; Monaco disappears in the last build phase.
