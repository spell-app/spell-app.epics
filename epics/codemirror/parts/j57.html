  • marks the place in a soft yellow
  • takes the keyboard as it opens: ↑ ↓ through the uses, Enter goes, Esc closes it, the caret back in the code; Esc in the code closes it too

You asked: Make this match the editor style

The peek box is now drawn with the code pane's own surfaces, not as a purple dialog:

  • No border and no focus ring. The box is the code's paper, lifted off the code around it by the pane's own shadow, with 8px corners.
  • Its head and the list of uses are the file tabs' bar colour, with the bar's line, a shadow under the head.
  • The picked use is a white pill, like the file tab that's showing. The other rows hover the way the code menu's rows do.
  • The ✕ and the kind ("17 uses", "Definition") are muted, like the bar's own.
  • Every colour is an editor or Spell UI token, with Spell UI's own as the fallback, so <spell-editor> draws it the same. Light and dark come from those tokens.
  • Spacing is on the 4px grid: 4px around the list, 4 x 8px rows, a 28px head.
