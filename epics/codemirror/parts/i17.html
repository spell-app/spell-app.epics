You asked: uhh... what are these components?

Leftovers. FileDropdown and ProjectDropdown were the Solid copies of the old React editor's two dropdowns, the file picker and the project picker at the top. Their jobs moved elsewhere, so nothing in the editor drew either of them any more. Only their App UI pages, their tests and a few comments still pointed at them.

What took their place:

  • The file list is now the code pane's tab row (<FileTabs>), with the button at its end that lists every file:
  • The project list is now the Spell menu, the first menu in the top bar (<ProjectsMenu>, inside the menu bar's code). Your screenshot on C1 shows this one:

What was removed, as you chose:

  • Both components and their CSS, plus ProjectMenu, the same project list drawn as a menu of links.
  • Their two App UI pages and pictures, and their links from App UI's home page.
  • The four file actions grouped for the dropdown's foot (New, Duplicate, Rename, Delete File). Nothing else used that group, though each action is still there.
  • Two helpers they had were still in use, so they moved rather than went: the project's file list now lives with the tab row, and the group's project list in a small file of its own, which the Spell menu, the editor and the landing page read.
  • The house style's examples that pointed at FileDropdown now point at live code.

Added: App UI pages for what replaced them, FileTabs and MenuBar, each with the picture above.

The editor's own Spell keeps its ProjectMenu name: it names the open project's menu, under its name in the top bar, not the removed component.
