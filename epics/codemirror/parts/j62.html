When a new layout (the pause's, or a parse's) changes the heights of lines above the caret, the scroll is set so the caret's line stays where it was on screen.

  • How: CodeMirror's scroll snapshot (view.scrollSnapshot()), which it applies once the new heights are measured, before anything is painted; its target's fields moved onto the caret's line (a HACK: they're CodeMirror's internals, plain fields).
  • Only while the code has the keyboard and the caret is on screen: otherwise CodeMirror keeps the top line still, as before.
  • Rejected: scrollIntoView(..., { y: "start", yMargin }), CodeMirror's public way: it measures from the drawn caret and adds the pinned lines' margins, so it lands a few px off, and it scrolls the page's other scrollers too.
