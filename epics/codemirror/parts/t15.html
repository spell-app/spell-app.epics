Four clicks now select a block, in every code editor (merged, 573ca19):

  • on a head line (to draw solitaire): the head and its whole body, through </context-menu>
  • on a body line: the innermost block it's in
  • each click after the fourth: the block around it (five clicks there: all of solitaire is an app)
  • a line in no block: the line, as three clicks
  • three clicks still select the line; a press inside a selection still starts a new one (I9)

The block is the one the fold arrow folds, so the two always agree.
