Every place the editor app shows code moved to CodeMirror 6, and Monaco left the repo.

Where you see it:

  • The code pane: each file you open, drawn bubbly or plain, with every typing help Monaco had; one view shows each file in turn, keeping its undo, folds and scroll.
  • The Inspector's Code card: the slice of code under a thing you picked (<CodeSlice>).
  • The compiled code: the read-only JavaScript, TypeScript and Python pane, following the line you're on.
  • Publish's diff: their side and yours, each change taken by its arrow.
  • Notebook cells, and <spell-editor>, the editor pane as a web component.
  • The fallback editor shown after an error, and the older output pane.

Why move (from editor P30's write-up):

  • A sixth of Monaco's size: 206 KB gzipped, against 1,241 KB.
  • Solitaire drawn bubbly in 226 ms after the parse, against 686 ms; typing a little faster (10.3 ms a key, against 14.1).
  • The bubbly look becomes marks in the lines themselves: no layer behind the text to keep lined up.
  • Every word CodeMirror shows can be Spanish; Monaco's stay English.

The compiled TypeScript, JavaScript and Python views moved too: Monaco gave them only colouring, which CodeMirror's language packages give for 45 KB.

Not carried over:

  • <spell-editor>'s right-click menu and Find All References: the app's menu can't load on a page with only that element (I4, dropped).

Built after the swap, from what Owen found in the app:

  • A peek view under the code, Peek Definition (⌥F12) and Peek References (⇧⌥F12), drawn as the code pane's own surfaces (I5).
  • A compact find bar like VS Code's, its Replace row showing until folded (I8); selections don't drag (I9); four clicks select a block (T15).
  • Every line 25px, a block's feet drawn in the blank line under it, a description too wide for its band cut short with … (P7).
  • The bubbly marks made only for the lines on screen: a keystroke in Table's 2,668-line examples 68 ms, was 157 (P7).
  • A file drawn from its text alone, before its project's parse is in, with the same blocks and bands as the parse gives (I23, I26, I28).
  • Typing in Solitaire.spell about 6 times faster, the caret's line held still (I21); the popups that show by themselves wait for typing to pause (I22).
  • CSS files and property editors files coloured (I20, I18); a comment's -- one step for the caret (I25).
