Every place the editor app shows code moves to CodeMirror 6, and Monaco leaves the repo.

Where you'll see it:

  • The code pane: each file you open, drawn bubbly or plain, with every typing help it has today.
  • The Inspector's Code card: the slice of code under a thing you picked (<CodeSlice>).
  • The compiled code: the read-only JavaScript, TypeScript and Python pane, following the line you're on.
  • Publish's diff: their side and yours, each change taken by its arrow.
  • Notebook cells, and <spell-editor>, the editor pane as a web component.
  • The fallback editor shown after an error, and the older output pane.

Why move (from editor P30's write-up):

  • A sixth of Monaco's size: 206 KB gzipped, against 1,241 KB.
  • Solitaire drawn bubbly in 226 ms after the parse, against 686 ms; typing a little faster (10.3 ms a key, against 14.1).
  • The bubbly look becomes marks in the lines themselves: no layer behind the text to keep lined up.
  • Every word CodeMirror shows can be Spanish; Monaco's stay English.

The compiled TypeScript, JavaScript and Python views move too: Monaco gives them only colouring today, which CodeMirror's language packages give for 45 KB.
