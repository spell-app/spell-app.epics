Each file's state (its parse wait, its save wait, which project it's in, the outside-edit path) is worked out the same way for either editor. So that half of SpellModels is lifted into one class that both editors' file states extend (P2 · File States):

  • use() / disposeProject()
  • saveAfterEdit()
  • applyEdits() and EditWay
  • reading the existing PARSE_WAIT / SAVE_WAIT
  • Why: epic editor is still changing SpellModels; with one shared base its changes land once, not once per editor.
  • The other option: copy it into FileStates now, keep the two in step by hand until the swap, and delete SpellModels at P6 · The Swap. Less to move now, but every change epic editor makes meanwhile would have to be made twice.
