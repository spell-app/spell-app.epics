Typing in Solitaire.spell: the scroll jumps around

Taken up at once: agent codemirror-typing-scroll is on it.

Typing in Solitaire.spell no longer moves the code, and each key is about 6x faster. The scroll jumps came from the pause after each key: it redrew the file from its own text alone, with the block ends' feet 13-25px shorter, and the project's parse 50ms later drew them back. Keys more than 150ms apart (a loaded machine) moved the caret's line twice a key, by up to 101px. Now the pause waits for the parse, and the caret's line stays where it is on screen through any new layout. Each key also no longer makes the browser lay the whole pane out 3 extra times. Key to drawn frame: 54-63ms => 8-11ms (CPU 4x slower: 243-267ms => 16-19ms). Caret's line moves: 2-12 per 100 keys, worst 152px => 0. At 300ms a key: 33 moves in 20 keys => 0.
