Two sentences: what this plan does, and why.

Make Spell UI's components speakable in the spell language. The name of each property and value is VOCABULARY (Owen, 2026-10-08, in review of epic spell-element): we'll create `is disabled` spell language for a component in English and `está deshabilitada` in Spanish; the same for values: `left` and `right` in English are `izquierda` and `derecha` in Spanish. So each vocabulary attribute needs a spell phrase per language (translated like attribute names already are), the docs show the member and its data type, and spell programs can read and set components in their own words.
