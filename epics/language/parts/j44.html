Chose a hash of the code that decides what a project compiles to (the parser folder, the kit's util, spaces' models, Spell UI's components and vocabularies: compilerCode() in spaces' api.ts) over SPELL_VERSION / the package version, because the compiler changes every day without a version bump, and a stale entry is a wrong program. More than it needs, on purpose: a Spell UI edit empties the cache needlessly, which costs one compile. The page asks the version once and files everything under it; a page still running an older compiler can't file entries under the new one (409). Only the newest 3 versions' folders stay on disk.

a project that hasn't changed isn't compiled again after a reload: its output is kept in ~/.spell/cache/compiles, capped at 200 MB (least recently used first)
