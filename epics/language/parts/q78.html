For P67 · Drag Events. You wrote: "For the file events, we can just support when a? file is? dragged over it? form for now, but put the file events in the request to the other epic." So epic from-jarvis's P9 builds that one line; these are the rest, for your OK on each.

No new grammar: each is Spell's existing drag line (when a card is dropped on it:) with file or folder as the thing. What's new is what they mean: a file dragged in from the desktop. What Spell calls a file waits on from-jarvis Q7. 

- when a file is dragged out of it:
- cuando un archivo se arrastra fuera de ella:

- when a file is dropped on it:
- cuando un archivo se suelta sobre ella:

- while a file is dragged over it:
- mientras un archivo se arrastra sobre ella:

- when a folder is dropped on it:
- cuando una carpeta se suelta sobre ella:

Clashes, and how each is read:

  • A program's own "file" type. A program that says a "file" is a thing has its own files. Then when a file is dropped on it: hears its own files dragged about, not the desktop's: the program's word wins, as it does for any type, and the editor warns that it hides desktop files.
  • something. when something is dropped on it: does NOT hear desktop files, so a pile that takes anything doesn't start taking files.
  • No folder while dragging. A browser can't tell a folder from a file until it's dropped, so there's no when a folder is dragged over it:. The file lines cover folders while dragging.
  • Whether it takes them stays the list's own rule, can take a file if: ..., which also lights its glow. While dragging it only knows how many files and their kinds, never their names.
  • Files and folders reach any view that has one of these lines, the same way cards reach a pile.
  • No dragged out, no while: less to learn, but no hint that clears itself as the files leave.
  • Say which, or the words you'd rather.
  • when a file is dragged out of it:, when a file is dropped on it:, while a file is dragged over it:, when a folder is dropped on it:, and their Spanish
