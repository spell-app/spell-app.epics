Owen's C5 asked for a base Dimension class in TypeScript, with the units in Spell. Built: one Dimension class in each core, and each dimension (Length, a program's DataSize) is one of them, made from its units: core.defineDimension("Length"), then core.defineUnit() for each unit line. Not a class per dimension: nothing differs between dimensions but their units, and a class each would mean a generated class file per dimension in both cores.

  • Same Spell either way; a measure is still a plain number.
