A theme could make buttons look like pills with CSS alone (.ui.button { border-radius: 999px }), or hand each button a real default, so it IS appearance="circular" unless it says otherwise.

  • Defaults: button.appearance reads circular; the Inspector can show it; attributes that change behaviour (a section's folding, a menu's closing) work too; a button that writes appearance="basic" plainly wins.
  • CSS only: no new mechanism, but only looks, the element doesn't know, and a button can't easily opt out.

A: real defaults, through each root's settings (RootSettings, which already gives icons and emoji their packs by nearest root).
