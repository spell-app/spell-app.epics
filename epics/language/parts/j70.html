Plain drawings now take the tag form's shortcuts (Q4 A): <text> is Spell UI's, </> closes, a <for> works inside an element. But a name no pack has, <div>, <p>, <br>, stays the web's in plain Spell, where the tag form calls it an error: the guides and the frozen test projects draw those, and the frozen ones never change.

So a plain drawing's <button> is Spell UI's now (J83 still holds for a tag file's <spell> chunk); nothing built in wrote a bare <button> in plain Spell (checked).
