Owen (2026-11-02), about the reserved-words table: "lose drawable, drawable thing, drawable list dibujable".

They stop being type words and stop being errors naming view / viewable list: ordinary free words a program may use as names.

`drawable`, `drawable thing`, `drawable list` and Spanish's `dibujable`, `cosa dibujable`, `lista dibujable` are no longer type words, nor errors naming `view` / `viewable list`: ordinary words a program may name its own types with (`a drawable is a thing`, `un dibujable es una cosa`). The retired type words' table and the code only it fed are gone; `spell lint --fix` still puts the other retired words right (`parts` => `slots`, `animation` => `to`), its message key now `retired-word`. Docs and two guides that still quoted the old words now say `view` / `vista`, as the examples do.
