An edit re-reads only the files it affects, but every file of the project is written out again (about 100ms of Solitaire's ~350ms)
  • From T92 (and J43): editing a body (its picture) rewrites only that file; renaming a property or making an action wait rewrites exactly the files that use it.
  • Solitaire: an edit's writing drops from about 100ms to the edited file's share; measured before and after.
  • No stale output: a test compares every cached compile with a full one, on every example, across edits.
  • All targets: JavaScript, TypeScript, Python.
  • the writer writes each file's pieces on its own, keyed by file and class; a class is assembled from its pieces in file order
  • the uses record counts what action bodies use, each used thing's outline (name, kind, blanks, waits)
  • a file's pieces are reused while its text and the outlines of what it uses are unchanged
