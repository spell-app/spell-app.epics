From the data epic: its Star Wars cards had to be plain things, because the project's styles.css can't reach inside a view.

  • Each view draws in its own shadow root, which sees only its own styles. Today a stylesheet reaches in only by part: Solitaire writes [layout]::part(placeholder).
  • This isn't about the language: the words don't change. The code is the app runner's (shadowStyles.ts, SpellElement), so it fits the Drawable Spell saga as much as this epic.

.card .title just works, using the one shared sheet the runner already builds per page. A rule meant for the page can now hit a view's insides, and the compiled TypeScript target needs the same.

A guide section, and a warning when a stylesheet's class names only something inside a view. Views stay sealed, but people must learn ::part().
