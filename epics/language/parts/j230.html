Built: a member the program names takes its words joined by - as its id, wherever it's declared: Solitaire's stock, discard-pile, clubs, C1 (case kept, so <column "C1"/> stays C1).

  • An app's members are unique already: a program has one app.
  • A member of a type with many things (a player has "hand" as a new pile) gives every player's hand the id hand: Pile#hand finds the first. Unchanged since 417e06bec, which first named members so; nothing in the examples does this today.
  • Owner-qualifying (<player id>-hand) needs the owner's id while its member is made, which a compiled member's init doesn't have: a core change, for when an example needs it.
  • A type saved in a place still gets none (its rows need ids of their own).
