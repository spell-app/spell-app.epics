alert, warn and confirm can now have a title. It shows as the dialog's heading.

  • alert "You won!" titled "Solitaire" with "New game" compiles to await core.alert("You won!", { title: "Solitaire", okText: "New game" }).
  • In Spanish it's avisar "¡Ganaste!" titulado "Solitario". titulada works too, the same word notificar already uses.
  • If a line only names buttons, it compiles the same as before: alert "Yo!" with "yep" is still core.alert("Yo!", "yep"). The core takes either form, so programs compiled earlier keep working.
  • Python gets the same options, with Python's names ({"title": "Solitaire", "ok_text": "New game"}). spell_core turns them back into JavaScript's names before it asks the page.
  • Tests: a rule test for each phrasing, in English and Spanish. A core test checks what the page is asked for, and pytest checks the options reach the page.
