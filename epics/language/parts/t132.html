What it says on the tin.

an action's `disabled when <condition>`, `enabled when` turned round: the same `<name>IsEnabled` getter, giving back `not` of it (`ActionDetail`'s `disabled` group; `MethodDefinition.describedAction()` wraps it in `P.ASTNotExpression`); an action saying both is refused, naming both (`enabled-and-disabled-when`, `SP.SpellWarnings.refuseIf()`, `ActionDetail.saysBoth()`); Spanish `inactiva cuando`, beside `activa cuando`, which the translator carries both ways; the Inspector's dimmed run button says "Not when ..." for one (`enabledWhenInSource()` says which); three examples' `enabled when ... is no` now `disabled when ... is yes` (the Action guide's deal, the editor's inspect app and clear console) (Owen, editor I61)
