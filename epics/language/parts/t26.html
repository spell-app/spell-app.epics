Owen (2026-11-02): "cards' color is -- can you warn on this, suggest a card's color?"

A declaration with a plural owner and no article, cards' color is red if ..., cards' value is: ..., the curly ’ too: read as a card's color is ... (T24), with a warning saying to write that. Only when the singular is a known type; otherwise as today.

`cards' color is red if ...`, `cards' value is: ...`, `cards' "short name" is ...`, `cards' color is one of red, black:` (the curly ’ too), a plural known type with no article, compile exactly as `a card's color is ...` does, warning `Write "a card's color is ...": a declaration names one card`. A singular with no article (`card's value is`), or a plural no type is called, is still not read. A translation writes it as one: `la cuenta de una carta es ...`.
