Built: to get "..." now compiles exactly like to "...". The get is left out, so the method name, title and undo label are the same.

  • Before, in Solitaire: get became an action of its own, and the quoted part failed. 
    to get "the points for a card on a pile"
	return 1

  return core.asAction({ undoneAs: "Get" }, () => 1)
}

    Card.prototype.thePointsForCardOnPile = function (pile) {

  • Without quotes, nothing changes: to get the next card is still an action named "get the next card" (getTheNextCard()).
  • In Spanish, the word is obtener: para obtener "los puntos de una carta en una pila" gives Carta.prototype.losPuntosDeCartaEnPila.
  • In the editor, get is coloured as a keyword, and the bubbly look draws it as part of the line's opening words ("to get"). The name is only the quoted part.
