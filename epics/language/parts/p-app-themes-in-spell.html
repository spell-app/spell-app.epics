An app has no way to say, in Spell, how its widgets look by default.
  • From Owen, 2026-11-03: I should be able to specify this in a theme for the app.
  • Solitaire can write buttons are pills and sections are raised once, for the whole app, and every button and section follows.
  • A Spanish app says the same in Spanish: los botones son píldoras.
  • A theme file may set defaults for every app that uses it; an app's own beat the theme's, and an element's own attribute beats both.
  • The Inspector says "from the theme" beside a value that came from one.
  • The Root notebook's Theming page and README-spell show it.
  • An app says its widget defaults in Spell, in a <theme> block (spellml) or its theme: lines (code Spell), in English and Spanish.
  • A theme file (pop.theme.json5) may carry defaults too, which the app's own beat.
  • The editor's Inspector shows when a value came from the theme.
  1. In Spell: an app's <ui-defaults> block holds sample tags, one per widget: 
    <ui-defaults>
  <ui-button appearance="pill"/>
  <ui-section appearance="raised"/>
</ui-defaults>
    Each tag's attributes are that widget's defaults; any attribute but content ones (Q37). Spanish pages write the same tags with the vocabulary's Spanish words (<ui-botón apariencia="píldora"/>, as Spell UI's Spanish tags already read). An attribute or value a component doesn't know is an error naming the tag's values.
  2. Exportable: the defaults live in a file of their own, so another project can use them: <ui-defaults source="@org/project/ui-defaults.spell"/> points at one, resolved like an import; an inline <ui-defaults> block is the same file's content written in place.
  3. Compiles to the app's defaults object, handed to the app's root as it draws (parser/src/core/ui.ts, beside core.projectSheet()); Python writes the same data into its page.
  4. Inspector: a value that came from the defaults says so beside it, "from ui-defaults", naming the file.
  5. Docs: the Root notebook's Theming page and README-spell get the example; Solitaire is NOT changed (content stays as it is unless Owen asks).
  6. Checks: rule tests in both languages; a browser test of a compiled app with <ui-button appearance="pill"/> in its defaults, inline and through source= from a second project; spell content compare (JS and Python) changes only projects that use it; speed within Q24's budget; VS Code grammar regenerated.
  7. Left out: sentence wording (buttons are pills); defaults inside a theme's .theme.json5; a UI for editing defaults.
