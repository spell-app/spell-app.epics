A small bug in the code editor's Rename command. Rename changes a name everywhere it's used: right-click a word in the code › Rename Symbol, or press F2, type the new name, press Enter.

Try it in Solitaire's Deck.spell, in the editor (test.spell.app):

for card in the deck -- line A: this line MAKES the name `card` add the short name of the card to card names -- line B: this line USES it
  1. Click on the word card in line B (the card), press F2, type c, Enter: works, line A and line B both change to c.
  2. Click on the word card in line A (for card in), press F2, type c, Enter: nothing happens. That's the bug.
  • "A for loop's variable" just means the name a for line makes up: card above.
  • Found because a test renamed rank in Deck.spell; your with rank and suit (T121) took that line away, so the test moved, and I tried it from the for line.
