oculto joins en (slot) in Spanish's attribute words, so <ui-button oculto> is hidden too. A hidden declaring tag draws nothing: no h(...), and its hidden isn't a starting value of the new view. A non-declaring tag keeps hidden: true.

Clarify

What it's about: Solitaire's <deck "deck" hidden />, the first line of to draw solitaire.

  • The line says "solitaire has a deck", as "deck" is a new deck would, but draws NOTHING for it.
  • Why nothing: drawing the deck would draw every card in it, and a card's element can be in only one place, so the cards would leave their piles.
  • The rest of to draw solitaire (the <segment> and below) draws exactly as if the deck line weren't there.
  • Spanish says it <mazo "mazo" oculto /> (or oculta, for a feminine word).

The call is where else oculto works:

  • A, keep it (what's built): oculto means hidden on ANY tag.
    • e.g. <botón "x" oculto> is a button that's there but not shown, as hidden is in English.
  • B, only on a declaring tag: oculto works only on a line like the deck's; anywhere else, Spanish has to write hidden.
  • A: Spanish hides any tag with its own word; English is unchanged either way.
  • B: one less Spanish word to learn, but a Spanish file mixes oculto and hidden.
