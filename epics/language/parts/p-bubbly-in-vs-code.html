In VS Code, Spell files are coloured text, with none of the bubbly look.

Your words (2026-11-11): “... as much as VSCode done in bubbly style as possible.”

  • Weights, italics and colours from semantic tokens and decoration types.
  • Pills around what you typed: a decoration with a background colour, rounded corners and a border.
  • Spacers beside a pill: before and after attachments, never padding on the text.
  • What VS Code can't do, so it's left out:
    • block shapes across lines (the band, the bracket, the foot)
    • gaps between blocks
    • clean curly quotes: only through a CSS trick in a decoration's text style, which VS Code doesn't support
  • Left for later, not rejected for good: a custom editor, a webview hosting Spell's own Monaco from P48, would draw everything. But a Spell file there loses VS Code's own editor: its find and replace, multiple cursors, other extensions, the diff and git views, and edits from Claude and other agents.
  • The layout comes from the language server, the same layout as P47 and P48.

The Spell extension decorates VS Code's own editor with as much of the bubbly look as it allows: weights, italics, colours and pills. The block shapes, the gaps and clean curly quotes it can't draw.

  1. The language server sends the bubbly layout (a request of its own) and semantic tokens for the weights.
  2. The extension's decoration types: pills, spacers, weights, italics, colours.
  3. A setting to turn it off; yarn vscode; a manual test for you.

Left out: the custom editor (above), block shapes, gaps, curly quotes.

  • app/vscode/src/extension.ts: the decoration types, applied as the layout arrives
  • app/src/lsp (SpellLanguageServer.ts, SpellLanguageService.ts): semantic tokens for the weights; the bubbly layout as a request of its own
  • app/vscode/package.json: the token styles, and a setting to turn it off
  • A Spell file in VS Code shows bold references, italic ability words and pills round what you typed (a manual test, in your window, after yarn vscode).
  • Editing, find and the caret work as before; the setting turns it off.
  • App yarn review.
