A component's vocabulary lists its attributes, in groups (appearance, behaviour, content ...).

  • A: any attribute but the ones that hold a thing's own content (label, value, text): a theme can set a menu to close on click as well as a button's shape.
  • B: only the appearance group: looks, never behaviour.

A: any but content, so "every section folds" is themeable too; a theme naming a content attribute is a warning naming the attribute.
