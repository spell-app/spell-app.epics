A project file has no optional page: a <spell-page> starts by itself, and would make spell run open a browser. So Explainer.spellml is listed with "active": false: off, only the console listens and every run prints as before (checked: identical output, on and off); on, the page fills from the same events. Its code isn't compiled by the snapshots while it's off; checked by hand, compiled and drawn in the editor.
