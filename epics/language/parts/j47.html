T35 waited for spellx to write a measure property, but these are declared in StarWars.api.spell, which is code Spell: its "height" is a length in cm or "unknown", mass in kg, diameter in km, and the craft page's length in m. The facts read value = "[its height]", so each shows in the reader's units, and an unknown one still drops its row. The hand-written measure ... in ... stays for population, a day, a year, X-wings, passengers and credits, which aren't dimensions. StarWars.api.spell is ingest's file, edited by hand, with a comment saying so (as OpenMeteo.api.spell's units are).
