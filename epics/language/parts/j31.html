Chose to refuse, with a warning, the attributes named label, value and text, every attribute in an inspector's Name or Content group (title, icon, description, badge ...) and every rich-data attribute (options), over refusing only the three names, because those groups are what an element shows, not how it looks; a theme saying every button has an icon would be content. The groups are the vocabularies' own group, so a new attribute is sorted the same way.
