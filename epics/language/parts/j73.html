SX.CodeSpellWriter now writes a drawing as written, <text>back</>, since plain Spell reads that. shortcuts: "spelled out" keeps the old <ui-text>...</ui-text> for spell translate, whose way back to tags finds each name by its tag; the writer's own tests ask for it where they check that shape. It also writes a blank line after a <for>'s riders when markup follows, which would otherwise join the last rider's markup.
