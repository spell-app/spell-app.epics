A draw and a getter must answer right away, or the page can't draw.

A getter that waits says "make it an action". A draw shows the current value, warns, and redraws when the slow call changes something. A literal pause in a draw is an error. So is a slow comparison in a sort; where gets a one-by-one version.

Strict and simple, but drawing a loaded value then needs a property and an action.
