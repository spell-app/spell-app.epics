His screenshot: <card-image direction=down /> draws down as a white pill with no quote marks. The file has no quotes there: the old look drew them; since I115's follow-up only a real " gets a curly mark.

Fixed (65c541124). <card-image direction=down /> now draws as “down”. A headless screenshot of it is pixel-for-pixel the same as one of direction="down". Nothing is added to the file.

  • How: a tag's value written without quotes is now marked as bare. The editor draws its curly marks beside the words, along with the same spacing a quoted value gets.
  • Because there's no real " to step over, the caret beside these marks stays at the edge of the words. A letter you type there goes into the value.
  • Worth knowing: I couldn't find a version of the editor that drew these before. The one just before I115 drew direction=down without quotes too (headless screenshot). So this is new rather than something coming back.
