1. In the ⎇ language window's terminal, restart this checkout's page server: 
    spell server stop && spell server start
  2. Open the editor (the site header's Editor), then @spell/examples/Solitaire.
  3. Open Chrome's devtools (Cmd+Opt+I), Console tab, and reload the page (Cmd+R).
  4. Read the [compile-cache] lines; then type 
    SpellProject.compileCache.counts
  5. Edit a line of Card.spellml, let it compile, reload again.
  6. To compare without it: 
    SpellProject.compileCache = undefined
    then Compile and Run (Cmd+Enter).
  • The first open: compile(): Solitaire compiled, 5 files -- so far 1 compiled, 0 from the cache.
  • After the reload: Solitaire from the cache, 0 files compiled -- so far 0 compiled, 1 from the cache; the game draws as before, and the side bar fills a moment later.
  • After the edit and a reload: from the cache again (the edit's compile was kept).
  • A folder per compiler version in ~/.spell/cache/compiles/.
