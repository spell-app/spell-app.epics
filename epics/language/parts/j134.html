A Spanish <acción "deshacer" solo-icono tamano="pequeño"/> compiles to the very same core.drawAction(this, "undo", { "icon-only": true, size: "small" }) as English's. Spell UI's Spanish dictionary reads each name (the Spell UI pack's new readAttribute(), beside its readDefault() for <ui-defaults>); one it doesn't know (class, aria-label) stays as written.

The other way, drawing an <es-boton> in Spanish, would have changed the core's drawAction() in JavaScript AND Python (the button's tag, and the English names the action gives it, its title, icon, disabled), on a Python core another phase is working in. This way the core, the Python core and every compiled snapshot are untouched.
