Every Spell UI vocabulary now says its own partOfSpeech. The 84 tags the old table listed keep their colour; the other 53 were purple (any dashed tag) and are set by the same rule: a layout box blue, a control green, text and what sits in it amber.

  • Blue (structure): breadcrumbs, diagram, diagram-node, feed, event, comments, comment, statistics, message, nag, toast, placeholder, property-group, repeat, reveal, shape, toc, transition, tree, tree-diagram, tree-node, zoom, example, include, extra, terms, content, visibility
  • Green (action): breadcrumb (a link), property-editor, property, theme-editor, theme-menu, theme-token
  • Amber (property): avatar, color-chip, dimension, flag, detail, loader, progress, video, audio, embed, ad, json, author, placeholder-line, placeholder-header, placeholder-paragraph, placeholder-image
  • Grey (plain): divider (it was purple when written <ui-divider>; now grey either way, as Owen asked), components (invisible)
  • HTML's tags keep their table in BubblyMarkup; bare title, meta, link are listed grey there, so the head's tags don't take Spell UI's ui-title / ui-meta / ui-link colours. A bare video, audio, embed now takes Spell UI's amber.
