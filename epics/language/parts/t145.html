owenoak: “how can we set a header on an `alert` and/or change the text size within it (Owen picked all three: a header with `titled`, a size word, Markdown)”

A dialog's message is read as Markdown now. alert "# You won!\nYour score: **{score}**" draws a heading and bold text.

  • Nothing changes in what the line compiles to. The core asks Spell UI's dialog for markdown: true on every alert, warn and confirm.
  • Spell UI uses <ui-markdown sanitized breaks> only when the message actually has Markdown in it: a heading, a list, a quote, bold or italic, code, or a link.
    • A plain message stays the plain paragraph it always was, so it looks exactly as before. A test checks this.
    • 5 * 3 = 15 and snake_case_name don't count as Markdown.
  • It's safe. The message is set as the element's text, never as markup. Then DOMPurify cleans what it draws: no scripts, event handlers or javascript: links. The test puts an <img onerror> in the message, and it comes out without the handler.
  • breaks keeps each \n as a line break, as the plain paragraph did. The Markdown also keeps the paragraph's 16px margins, so the spacing doesn't change.
  • The <ui-markdown> family loads the first time a message needs it. The dialog waits for it to draw (at most 1 second), so it never opens half-drawn.
  • prompt's message stays plain, because it's the label for the input.
