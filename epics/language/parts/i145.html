A quote left open now breaks only its own line. Delete small's closing quote, and only size="small is underlined. The toolbar, its ⟩ and every tag after it draw as before.

  • Three readings let an open " run on to the next quote, lines below:
    • Spell's tokenizer read a quoted text past its line's end. Now a text ends on its line. A tag's attribute value can still run over lines, as I12 allowed (style="color: red; then margin: 0").
    • An attribute it couldn't read, on a line of its own, ended the tag at the line break before it. So the tag had no >, and the rest of the file read as text. Now it skips that attribute and carries on to the tag's own >.
    • The look's own reading of tags let a quoted value cross lines. It now ends on its line too.
  • The error underlines size="small only. Before, it covered the whole tag and everything inside it.
  • Measured in the real editor, light and dark, Solitaire's toolbar laid out as main has it, the quote deleted: before, 3 of 36 tags drawn, no ⟩, the bands torn into 72 pieces. After: all 36, the ⟩, every band, the same as with the quote in place.
  • Plain Spell too: to "restart the game with its quote open no longer breaks its body. The same tokenizer reads every language, Spanish included.
