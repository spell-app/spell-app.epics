deal the cards compiles to core.answered(this.dealTheCards()) when the action gives a value back. Chose to count an inline body (if ... then deal the cards) as a statement too. Not wrapped:

  • an action's last line, which is already that action's value (I47), so it goes where it's written
  • an action that gives back nothing, or whose only yes / no is whether it was cancelled
  • a server's operation, which has no steps of its own
