Chose to keep a root's default in the element's converted values (source default), so its property, its component and its classes all see it, over writing the attribute, because the markup should stay what the page wrote, and an attribute written by a theme would then look like the page's own and win over the next theme change. button.appearance reads pill; button.getAttribute('appearance') stays null.

<ui-root defaults> gives the elements inside attribute values they don't set, by tag ({ "ui-button": { appearance: "pill" } }); an element's own attribute or property wins, nested roots inherit and override, live; content attributes and bad values warn once, naming the root and tag; pill is another word for circular on <ui-button> (píldora)
