<action discard title="Discard your changes" /> answers discard. Told apart from the tag's other bare words by three rules:

  • only on an <action> with no quoted word, so <action "save" icon-only /> is untouched
  • only its FIRST attribute, so <action title="Cut" discard /> isn't one
  • never keep-open / icon-only (mantener-abierto / solo-icono), nor a word Spell UI's button or menu row takes bare (disabled, basic ...), so <action disabled>Cut</action> stays a menu row

Chose this over a new attribute (answer="discard") because it reads the way <action ok /> already does. It just closes the modal, labelled by its title, else Discard; if the program has an action discard, it runs that first, as <action ok /> does. No repo program wrote a bare first word on <action> before (grepped).
