Proposed fix (agent language-autoplay):

  • Why the return goes: since I47, a return whose call gives nothing is written as the call alone, so a body's last line bump it stays -> None in Python. That rule was meant for the end of a body, but it caught every return, even one inside a loop. auto play gives nothing, so return auto play lost its return; move the card to end pile gives an answer, so it kept its.
  • The fix, in the writers (JavaScript, TypeScript, Python): a return you wrote, with more of the action still to run after it, keeps its return, on the line after the call:
    • await this.autoPlay(), then return (Python: await self.auto_play(), then return)
    • At the end of an action (its last line, or the last line of each branch of an if it ends in), the call alone, as now.
    • The action still gives nothing: Python's -> None stays.
  • No new Spell: return auto play just does what it says.
  • Tests beside I47's, English and Spanish: inside a loop, inside an if with more after it, and at the end.
