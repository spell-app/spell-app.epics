The rules

  • An app's id is its own name in lower case, with dashes between its words: solitaire, todos-app.
  • A member the program names takes its words joined by dashes, each word as written: discard-pile, C1.
    • The member and the tag that draws it always agree.
    • discard pile, with a space, still finds it.
  • A thing made while the program runs, with no name, keeps a random id.
  • An id the program sets, or that saved data has, still wins.
    • Data saved with the old random ids still loads, and its references still find their things.
  • An id given by its name counts as chosen, so a named thing's remembered settings are found again after a reload.
    • The app keeps its own under the setting's name alone, theme, as before.
  • The same in Python.
  • A named member inside another thing gets its name alone, never its owner's too: J230 says why.
