  1. Reading. In SpellxTwin.property(), an is= attribute is the line's right side: its {name} is (the existing value shape) followed by the attribute's own Spell tokens. The tag head already turns a quoted value into Spell tokens where it sits in the file (SpellxTokenizer's attribute reading, then SpellxTwin.spellTokens()), as one-of="..." is read today; braces read the same, a } in a string included (findMatchingDelimiter()).
    • Single-quoted text. Spell's tokenizer takes only " as a quote (SpellParser: “Only support double-quotes as quote symbols (so we can do contractions with single quotes)”), and ' is also a possessive and a foot. So a Spell attribute's value is tokenized with one rule more: a ' opens text only where a word could start (the value's start, after a space, (, + or a comma) and closes at the next ' that isn't followed by a letter. Then the card's rank stays a possessive (a letter before the '), 5' stays a foot (a digit before it), and 'Message ' + its name is text then a read. The text token it makes is the same one "Message " makes, so nothing after the tokenizer changes. Text attributes (description=, title=) are untouched.
    • starting-at="0" adds starting at 0 to the line: a new shape, its {name} is {is} starting at {starting-at}, in both packs (words.property; Spanish empezando en). Today's typedValue, its {name} is {a type} {type} starting at, takes its value from the body, so it stays only for reading the old type="number">0</>.
    • is-one-of="red, black" is today's list shape, its {name} is one of {one-of}, its words from the quotes; with a body over several lines, today's listBody.
    • is= beside a body over several lines is an error on the tag, as type= with a block is today (spellx-typed-body): a worked-out value is the body or is=, not both.
    • is= with is-one-of= (or the old one-of=) is an error: both say what the property is. So is starting-at= beside a body.
    • The old forms read as before, each with a warning naming its new form: type="number" as is="a number" (the article from the type's own word, as typed does now), a typed body as starting-at=, one-of="..." as is-one-of="...". Spanish's attribute words are es, empezando-en and es-uno-de; tipo= and uno-de= warn the same way.

Text inside goes in single quotes. A body over several lines is written as today.
    • A value whose text itself holds a single quote ("it's late") can't go in single quotes: the writer keeps braces for it, is={"it's late"}, as braces always read.
