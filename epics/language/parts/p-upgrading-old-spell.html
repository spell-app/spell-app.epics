Spell code written for an older Spell, or an older API, has no way up: an old form is only an error, a place field gone from its server is only a comment.

One list of old forms, each dated, grown from today's retired words. Each shows as a warning with a quick fix in the editor and VS Code, and one step rewrites a whole project, recording the Spell it now matches. T166's same-line comments are its first form.
