Proposed order for a read of the X (Spanish el, la, los, las):

  1. A local, argument, loop variable or alias, innermost first.
  2. A property of the thing the action runs on, inherited ones too.
  3. Every thing of a type, as the cards means today.
  4. Otherwise an error, as today.

What that does to names you already use:

  • its X doesn't change: it follows it, so inside a loop it's the loop's item.
  • the stock of the solitaire stays valid, and is still needed outside the solitaire's own actions.
  • A literal action name wins: with to reset the stock declared, reset the stock calls it.
  • Properties can be declared below the action that reads them.
