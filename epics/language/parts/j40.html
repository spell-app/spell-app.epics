Chose to read a source file's <ui-defaults> from its project's compiled declarations (a new uiDefaults key on its statement), over fetching and parsing the file while compiling, because parsing is synchronous and imports already load declarations before it. So <ui-defaults source="@org/project/ui-defaults.spell"/> needs @org/project in the project file's imports, compiled; the error says so. The importer copies the table into its own core.useDefaults(), naming the source file, so Python and the Inspector see it.
