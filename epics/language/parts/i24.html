A vista reversible's dirección is the core's direction, values up / down (its declarations map them). obtener una nueva carta cuyo ... y dirección es arriba compiles to new Carta({ ..., dirección: "arriba" }), which sets nothing: the card starts face down. English's direction is up works.

  • Solitario's tests turn each card up with voltear ... boca arriba instead.
  • Its property editor (Carta.editor.es.spellml) names the field direction, the class's, and its buttons will show up / down, not arriba / abajo.
