A task's row is a horizontal <ui-stack>: grip, checkbox, title field, priority. Nothing in Spell UI lets the title field fill what's left (no grow on a stack child, ui-space has no slot), and nothing dims a done row. So Task List and Lista de tareas keep a two-rule styles.css: task-list-checklist > *::part(title) { flex: 1 } and the done fade.
