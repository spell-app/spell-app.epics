Typing a space after one word at a line's start, with nothing after it, types a ": Monaco closes the pair, the caret between, and one undo leaves group . Only in code Spell, not page files. Left out: to/para for actions, because para also starts para cada. HACK: before typing the quote it asks Monaco to colour the line, through tokenization.forceTokenization, which isn't in Monaco's types. Monaco closes a pair only on a line it has already coloured, and quick typing gets ahead of the colouring. If the pair still isn't closed, it writes the closing quote itself.

English: a/an at the top level; group/its/it one level in, under a type; it under a property (it "is a (rank)"). Spanish: un/una; grupo/su/sus; Spanish has no word before a choice.

A rule's syntax puts a name after many shapes of words, and the same words start lines with no name after them. Examples: its rank && "of" && its suit as a property's value, and para cada .... So the line's place has to decide too.
