Some tag attributes use other words than the plain Spell line they stand for (template= for is a, address= for at), and a one-line alias keeps its condition in its body.

  • Owen's words (2026-11-10): “what are other forms we might consider changing this way”, then “make this a phase”.
  • The rule: an attribute is the plain line's own words, in quotes. Each of Spell's own attributes always holds the same kind of thing, Spell or text, so its quotes are read that way and nothing is guessed (Owen, 2026-11-10: quotes rather than braces, “a lot easier for a layman to grok”). Braces still read, as they do everywhere: “You should always be able to use {...} for dynamic values.”
  • Owen's picks:
    • Q42 A: template="two sided view" (27) becomes is-a="two sided view", as in a card is a two sided view. Spanish es-un="vista reversible".
    • Q43 A: a place's address= (21) and a site page's address= (409) become at=, as in x is a web server at "..." and it has a home page at "/"; a site already says at=. An address is text.
    • Q44 A: a one-line alias, <alias "is a face card">if its rank is jack, queen or king</> (9), becomes <alias "is a face card" if="its rank is jack, queen or king" />. Spanish si=.
    • Q45 B: enabled-when="..." (5) and selected-when="..." (10) keep their quotes. That's now the rule itself: they always hold Spell, so their quotes read as Spell.
  • Text inside a Spell attribute's value is in single quotes, as P42 adds: if="its name is 'joker'".
  • Left alone, because they don't fit the rule:
    • shortcut="meta+T" (37): text, a key, not Spell.
    • A property's alias="is (color)" (5): a phrase pattern, not Spell to run.
    • One-line action bodies (18), <action "count up">set the count to the count + 1</>: steps stay a body.
    • Handler heads, <on fizz with number as a number>: already the plain line's words.
    • title=, icon=, description=, tab=, tags=: text. aka= already the plain word. for-each={...} takes quotes too, as it always holds Spell; its braces still read.

Each attribute takes the plain line's own words, in quotes, as P42 does for a property's is="...": is-a= for template=, at= for address=, and if= for a one-line alias's body.
