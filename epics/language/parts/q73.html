For P66 · Choose From a List. You wrote: "For JSON object with { [label|name|title]: <value>}` show label and choose value." It reads two ways, and they show different rows.

Reading 1, one record whose keys are the labels. Each key is shown; the value under it is what's picked. 

levels is { "Easy": 1, "Hard": 3 }
choose a level from levels with prompt "How hard?"
// the person sees Easy and Hard;  picking Hard makes it 3

Reading 2, a list of records, each with a label and a value. The label, name or title is shown; its value is picked. 

levels is a list of { label: "Easy", value: 1 } and { label: "Hard", value: 3 }
choose a level from levels
// the person sees Easy and Hard;  picking Hard makes it 3
  • Choosing from a record shows its keys and gives back the value picked.
  • A list of records is a list of things: it shows each one's title, else its name, and gives back the whole record.
  • label joins title and name as what a row shows.
  • A list of records shows each label, name or title, and gives back its value.
  • A record with no value is given back whole.
  • A record: its keys shown, the value picked. A list of records: the label shown, the value picked.
  • Two rules to learn; one sentence each in the guide.
  • choose a level from levels, on a record, shows its keys and makes it the value picked
  • On a list, each row shows its title, label or name; it is the thing picked
