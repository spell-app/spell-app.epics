Every <ui-button> an app wants as a pill has to say appearance="circular" itself: a theme sets colours and fonts, never a widget's attributes.

  • Every <ui-button> inside an app whose defaults say appearance: circular draws as a pill; one that writes appearance="basic" itself keeps that.
  • Any attribute a component's vocabulary lists can have a default, checked against its values.
  • Changing the defaults redraws what uses them; a root inside another inherits the outer one's, and overrides what it sets.
  • pill becomes another word for circular, as Owen wrote it.
  • A root (<ui-root>) can hand its subtree default attribute values per tag, which an element uses when it doesn't set that attribute itself.
  • They change live, and a nested root inherits what it doesn't set.
