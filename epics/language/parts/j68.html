Chose to read a page's plain head, "button api" is a notebook page, as the very token its tag was, through the tag form's tokenizer, over writing a second page reader on plain Spell's tokenizer.

  • Why: the plan keeps a page's body as it is, prose lines, ## headings, <spell> and <html> blocks, its own <view>s, and only that reader understands them; so every page compiles to the same program, byte for byte.
  • What it means for P47 · Spellx Removed: its plan deletes the tag tokenizer outright; the page body's half of it (prose, blocks, page views, a <for> inside an element) has to stay, renamed as the page reader, and only the code tags go.
  • A page's file is still the spellx form inside (SP.formOfText() says so for a plain page head); nothing a person reads says spellx.
