From r5: Owen wants nothing as Spell's one word for a missing value. Today a check for one has five wordings: 

if the title is defined          // title !== undefined
if the title is undefined        // title === undefined
if the title is not defined
if the title exists              // title !== undefined
if the title is nothing          // title === undefined (nothing is a literal)

In the examples: is nothing 6 times, is not nothing once, exists 3 times, is defined twice, is undefined once (a frozen test project).

  • is defined and is undefined retire, rewritten by spell lint --fix to is not nothing / is nothing.
  • exists / does not exist stay: they read well for a thing (if the player exists).
  • Spanish: es nada / no es nada and existe / no existe; está definido retires. Catch: no es nada also means it's nothing in everyday Spanish, so existe is shown first there.
  • As A, plus is something for is not nothing.
  • Reads naturally, but it's a third way to say the same test.
  • exists retires too: one pair for everything.
  • Loses if the player exists, which reads better than is not nothing for a thing.
  • Two pairs: is nothing / is not nothing for any value, exists / does not exist for a thing.
  • undefined, null, is defined, is undefined are errors naming their new words, fixed by spell lint --fix.
