The read is small, because it reuses what its X already does. The work around it:

  • The read: a sibling of the its rule, ranked below locals, with one shared way to find the thing an action runs on.
  • The language server: it works out a property's owner from it, so without a fix hover loses its type, and rename spreads to every type's stock.
  • Completion and colouring: the should offer this type's properties and colour them as properties.
  • Text fill-ins: [stock] in a text means its stock by gluing English; it should use the same lookup.
  • Examples: Solitaire first, and other projects as we choose; the language guides say which to teach.

Not yet tried: static properties, and adding a property while a file is being edited live.
