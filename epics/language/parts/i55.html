T53 made una nueva carta cuyo dirección es arriba write { direction: "up" }: the value is said FOR the property there. Setting it later (poner la dirección de c a abajo) or comparing it (si la dirección de c es arriba) still compiles "abajo" / "arriba", which the class never holds. The property now carries its value pairs (P.ScopeVariable.valueOutputs, from the template's enumerationOutputs): an assignment or comparison whose other side is that property could use them. Spanish files use voltearla boca arriba / está boca arriba meanwhile.
