Card.editor.spell is text the Inspector reads (propertyEditorInSource()), never parsed or compiled: no JS, TS, Python, words or scope pack comes of it, and there's no property editor rule for P55's declaring tags to hook into. So <property-editor "card"> ... </property-editor> (or </>) is read beside "card" is a property editor in the same reader, and tested to give the same markup, byte for byte, for Solitaire's and Solitario's files. No SPELL: DECLARES, hover or scope-explorer entry: nothing is declared. A general top-level <type "name"> in a compiled file is left unbuilt: its children would be markup where a declaration's body is members.
