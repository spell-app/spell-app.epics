P27's cache was to live in ~/.spell/cache (Q33). Owen worried a lot of activity could swamp the disk, and asked about a tmp/ folder that clears itself. A temp folder is only cleared on reboot or after days unused, so it doesn't stop one busy session filling it; a size cap does.

a project that hasn't changed isn't compiled again after a reload: its output is kept in ~/.spell/cache/compiles, capped at 200 MB (least recently used first)
