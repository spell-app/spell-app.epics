• Both sides yes/no: a question, as always. Both values of one kind, outside a condition: or is the first that's there (discardPile.lastItem || stock.firstItem), and both in a list ([stock, discardPile]).
  • In a condition (if, X if C otherwise Y, when enabled, a where), a value is a test of whether it's there, as always: if its page and its page's fits and its page's thumbnail (StarWars, PokeSpell, PublicServers) still reads.
  • "There" is javascript's and Python's own: a 0 or empty text counts as not there.
  • One kind: the same type, one a kind of the other, the nearest kind a program declared (a stock pile and a discard pile: a pile), or lists of one item (a deck and a pile of cards). A pile and a card are two kinds, refused.
  • Refused outside a condition: a question and a value either way; in a condition only a question then a thing in a where, and and red anywhere.
