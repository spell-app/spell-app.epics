`return 0 otherwise` compiles to a plain `return 0`. It's allowed only when the line above it (comment lines aside) is a `return ... if ...` line; anywhere else it's an error saying where it goes, so a stray `otherwise` is never quietly dropped. Only `return` takes it: `print "lost" otherwise` under `print "won" if ...` would need an `else`, and nothing asked for that yet. Spanish: `devolver 0 de lo contrario` (or `sino`), not `si no`, which reads as `if no`, as the value ladder's `otherwise` already does.

Owen's three `return ... if` / `return 0 otherwise` lines compile as he wrote them; `otherwise` on any other line stays an error. `return 0 otherwise` as the last of a run of `return ... if ...` lines (a plain `return 0`; an error anywhere else), and `return` with a ladder of values indented under it (`- 10 if ...` / `- 0 otherwise`, with or without `- `), the same value lines a property's ladder takes; Spanish too (`devolver 0 de lo contrario`)
