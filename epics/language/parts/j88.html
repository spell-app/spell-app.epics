Every page draws its body now: no page has a <draw> of its own, and no members (<property>, <action>, <on> ...).

  • The page reader's own tags are <if> / <otherwise if> / <otherwise>, <for> with its attributes and its <loading>, <empty>, <failed>, an <html> block and a <spell> block.
  • Any other tag in a page is markup: <note>, <stories>, <menu> now draw as the components of those names (no built-in page wrote one at its body's top).
  • A page declares nothing, so a page alone in its file has no properties: a site can't give one an address parameter (/films/:film). A page that takes one is written in plain Spell code (film page is a page:), as Star Wars Site's are.
  • Its flags are only notebook and locked; thumbnail was a tag's attribute and goes.
