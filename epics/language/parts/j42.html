<ui-defaults>
  <ui-button appearance="pill"/>
</ui-defaults>

Select a button in the app, one that doesn't set appearance itself. The Inspector's Appearance row:

The plan said:
  Appearance     [ pill ▾ ]   from ui-defaults · Theme.spell
