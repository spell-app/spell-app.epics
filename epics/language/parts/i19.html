The recipe examples (RecipeBox, CajaDeRecetas, FamilyCookbook) wanted the card for a new recipe and a card per recipe in ONE <cards> group, inside a <container> (the old styles.css did this with a grid). Writing <for> inside any element is a compile error: <for ...> can't sit inside an element yet: write it on a line of its own in the drawing, outside the element.

So the examples use <for ... as="cards"> for the recipes, and the new recipe's card sits above the group on its own; nothing caps the page's width any more.
