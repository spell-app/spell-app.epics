Which buttons close a modal?

Only the <action>s inside <actions> close it, after they run. Elsewhere in the modal they run and it stays open.

Any <action> anywhere in the modal closes it. Simpler, but no way to put a working button in the body.

A program rarely has actions called ok or cancel. What does <action "ok" /> do in <actions>?

With no action of that name it just closes the modal (labelled OK / Cancel, in the page's language). With one, it runs it, then closes. A typo there would close instead of erroring, but only in <actions>.

Every <action> must name a real action; write your own to "cancel".

How does a button in <actions> run without closing the modal?

<action "preview" keep-open />: on the button, where you see it.

Also preview without closing the modal, written in the action's body or a button's onClick={...}. Two ways to say one thing, and a new phrase that means something only inside a modal.

Does the program pause at show "you won" until the modal closes?

Like alert already does: the lines after it run once the modal closes. hide never waits.

The program goes on at once; the buttons do the rest.

After the modal closes, how does the program know which button closed it?

the result is the closing button's action name: "ok", "cancel", "save the example"; Escape or the dimmer gives "cancel". The same word after alert and prompt (both have a TODO for it). A program's own result property would still win where it's named.

the you won modal's answer: read off the modal, never a word that changes meaning after each show. Longer to write.

The buttons' actions do everything; show hands back nothing.
