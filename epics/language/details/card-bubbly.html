Card, Drawn Bubbly

Solitaire in the bubbly look, every line, drawn by Spell's own code as every page that shows Spell now draws it: its card, the game, its piles and its deck, then the card in Spanish; last, two of the app's HTML pages, drawn the same way with their corners cut. Comment on any block with its bullhorn, or select some text and press ⌘ I.

# A playing card

// A card says what its rank, suit and color are: a deck, a pile or the game only reads them.

// It's a two sided view: face up it shows its picture, face down the back every card shares.

// On the page each card is its own element, `<solitaire-card>`: people may drag it (`draggable`), when its pile lets it go.

a "card" is a draggable two sided view

group "Rank"

// Ace is low: ace = 1 ... king = 13

its "rank" is one of ace, 2 ... 10, jack, queen, king

it "is a (rank)"

its "value" is the position of its rank

it "is a face card" if its rank is jack, queen or king

it "is a number card" if it is not a face card

group "Suit"

its "suit" is one of clubs, diamonds, hearts or spades

it "is a (suit)"

its "color" is one of red, black

red if it is a diamond or it is a heart

black otherwise

its "symbol" is

"♣" if it is a club

"♦" if it is a diamond

"♥" if it is a heart

"♠" otherwise

group "Names"

// What a person, test or console calls it

its "name" is its rank && "of" && its suit

it "is the (rank) of (suit)"

its "state" is

// Its short name: Q♠↓ is the queen of spades, face down

letter is 10 if its value is 10 otherwise the first letter of its rank as uppercase

arrow is "↑" if it is face up otherwise "↓"

return letter + its symbol + arrow

if it is a heart

return item column of ["🂡", "🂢", "🂣", "🂤", "🂥", "🂦", "🂧", "🂨", "🂩", "🂪", "🂫", "🂭", "🂮"]

its "lifted" is yes or no

// Over every card and pile around it while the cheat moves it -- styles.css

# Klondike Solitaire

// Deal seven columns, then build four foundations, ace to king, one suit each:

// [wikipedia](https://en.wikipedia.org/wiki/Klondike_(solitaire)) has its rules, and what each pile is called.

// The cards, the deck and the piles are this project's own: `Card`, `Deck` and `Pile`.

solitaire is an app

its "score" is a number

its "moves" is a number

// The cards played this game: a stock card turned over isn't one

its "hint" is text

// Said beside the score: what a drag would add, e.g. (+10), a drop nowhere, a win

when its score changes

// a change to a property is an event: each runs just after the change lands

// every card on a foundation: the game is won

set home to the number of cards in the clubs + the number of cards in the diamonds

set home to home + the number of cards in the hearts + the number of cards in the spades

if home is 52: set the hint to " -- You won!"

when its moves change

// a card played: the last hint goes

clear the hint

"deck" is a new deck

group "Piles"

// One of each, made with the solitaire

"stock" is a new stock pile with name "stock"

"discards" is a new discard pile with name "discards"

"clubs" is a new foundation with name "clubs", suit = clubs

"diamonds" is a new foundation with name "diamonds", suit = diamonds

"hearts" is a new foundation with name "hearts", suit = hearts

"spades" is a new foundation with name "spades", suit = spades

"T1" is a new tableau with name "T1"

"T2" is a new tableau with name "T2"

"T3" is a new tableau with name "T3"

"T4" is a new tableau with name "T4"

"T5" is a new tableau with name "T5"

"T6" is a new tableau with name "T6"

"T7" is a new tableau with name "T7"

when creating it

// Every card of the deck into the stock

for card in the deck

add it to the stock

group "Dealing"

// Each pauses a moment, so a deal animates

to reset the stock

// The discards, turned over, back into the stock

set cards to a copy of list (the discards) as a pile

reverse the cards

for card in the cards

add it to the stock

turn the card face down

to play from the stock

// Turn the stock's next card over, onto the discards: the discards back into the stock when it's empty

if the stock is empty

reset the stock

get the last card of the stock

turn it face up

// as long as its flip takes (styles.css), so it turns over before it moves

pause for 300 msec

add it to the discards

to turn a stock card

// A click on the empty stock: one step to undo, where the deal's own turn isn't

undoable as "Turn Card"

play from the stock

to deal the cards

// Gather every card into the stock, shuffle it, and deal the tableaus: one card more in each, left to right

for card in the deck

set start pile to card's pile

turn the card face down

if start pile is not the stock

add the card to the stock

pause for 50 msec

shuffle the stock

// each row's first card lands face down, then turns up where it lies

for row from 1 to 7

for column from row to 7

add the last card of the stock to item column of the tableaus

if column is row

turn the last card of (item column of the tableaus) face up

pause for 50 msec

play from the stock

group "Game Play"

// Its moves: the toolbar's buttons, its keys, and the board's right click; each says its title once, for all three

to "restart the game" with title "Restart"

shortcut N

undoable

clear the score

clear the moves

clear the hint

deal the cards

to auto play

// Play every card that can go somewhere, until none can

shortcut A

undoable

set anything changed to no

if the discards is not empty

set test card to the last card of the discards

if play test card

set anything changed to yes

pause for 500 msec

// each tableau's last card onto its foundation

for pile in the tableaus

if the pile is empty return

set test card to the last card of the pile

set foundation to the first pile in the foundations where its suit is the suit of test card

if the foundation can take test card

set anything changed to yes

play test card

pause for 100 msec

// each tableau's face-up cards, all together, onto another tableau

for pile in the tableaus

set face up cards to the cards in the pile where the card is face up

if face up cards is empty return

set test card to the first card of face up cards

if test card is a king and test card is the first card of the pile return

if play test card

set anything changed to yes

pause for 500 msec

if anything changed auto play

to cheat

// Turn up a face-down card from a tableau, at random, onto the discards

shortcut C

undoable

set remaining piles to piles in the tableaus where it is not empty and its first card is face down

if remaining piles is empty return

set the pile to a random pile in remaining piles

set the card to a random card in (the cards in the pile where the card is face down)

// over every card around it, then turned face up as it moves onto the discards

set the lifted of the card to yes

turn the card face up

add the card to the discards

pause for 300 msec

set the lifted of the card to no

its "game menu" is a menu of "auto play", "cheat", "restart the game", "undo" and "redo"

## Playing a card

// What a click or a drag does: the card's own moves, and each pile's, as the game plays them.

// the card, and every card on it, onto the first pile that takes it; it says whether it moved

// - the stock's card turns over onto the discards instead

to play a card

undoable as "Play Card"

if card's pile is solitaire's stock

play from the stock

return

set end pile to the first pile in every pile where it can take the card

if there is not an end pile return no

return put the card on end pile

// the card, and every card on it, onto the pile, if the piles' rules let it go and take it; it says whether it moved

// - the pile it left turns its new last card up; the move counts, and scores

to put a card on a pile, undoable as "Move Card"

set start pile to card's pile

if start pile cannot give up the card return no

if pile cannot take the card return no

set points to count the points for the card on pile

for card in (cards in start pile starting with the card)

move it to pile

if the start pile is a tableau and the start pile is not empty

pause for 200 msec

turn the last card of the start pile face up

set solitaire's moves to solitaire's moves + 1

set solitaire's score to solitaire's score + points

return yes

to count the points for a card on a pile

// what the move scores: 10 on a foundation, 5 from the discards, else nothing

if pile is a foundation return 10

if card's pile is solitaire's discards return 5

return 0

a card

// each card's events, and when it may be clicked: the Inspector lists them, as written here

// only a card face up, or the stock's, can be clicked: the others show no pointer

clickable when it is face up or its pile is solitaire's stock

on click

// a click plays it

play it

when dragged

// a drag starting clears the last hint

clear solitaire's hint

on drag cancelled

// dropped where no pile takes it, or Escape pressed: it slides back, and the score says so

set solitaire's hint to " -- Not there"

a pile

while card dragged over

// while a card it would take is over it, the score shows what the move would add -- gone as the card leaves

set points to count the points for the card on it

if it can take the card and points > 0: set solitaire's hint to " (+" + points + ")"

on card dropped

put the card on it

// one card at a time, the last of its pile: its suit, one higher

to draw its placeholder

// A light grey ace of its suit, face up

the column can take the jack should be no

the column can take the queen should be yes

add the queen to the column

the state of the column should be "T1: K♠↑ Q♥↑"

the column can give up the queen should be yes

turn the queen face down

the column can give up the queen should be no

// a foundation takes its suit, ace first, then one higher: each the last card of its pile

set the foundation to a new foundation with name "hearts", suit = hearts

set the two to a new card whose rank is 2, suit is hearts and direction is up
