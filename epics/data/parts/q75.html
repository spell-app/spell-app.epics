For P50 · Server Actions. Owen: "the error should be re-thrown for an error which is not explicitly caught". In his example the "not authorized" branch shows the login dialog with no nevermind. 

if completing a job fails
	if the error is "not found"
		nevermind
	otherwise if the error is "not signed in"
		show the login dialog            <- stopped here, or passed on?
	// an "offline" error matches nothing
  • A: caught means a branch matched. The login branch stops it; "offline" matches nothing and passes on. nevermind is then only for a branch with nothing else to do.
  • B: caught means it said nevermind. The login branch shows the dialog, then passes it on, so the page's step and the error notice see it too.
  • Ambiguity: a failure step with no if at all, just steps: A counts it as matching everything, B passes it on.
