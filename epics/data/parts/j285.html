Schema names carry server-code words: BriefCircuitGroupAssignmentSerializer read as five words, too many for a type name. typeOfSchema() drops a trailing Serializer or Schema, splits a run of capitals (BriefMACAddress => mac address summary), and when the squashed name equals one of the place's own types uses those words (BriefIPSecProposal => ipsec proposal summary, as its list is ipsec proposals).
