For P50 · Server Actions. Owen's order: "collection error handler, page error handler": an error not stopped goes out a level. 

the API file's failure step  ->  the app's file's  ->  the page's  ->  the person
  • A: out a level at a time, then the notice an action's failure shows today, its message in the person's language.
  • B: out a level at a time; an error nobody stops is written to the console only, with no notice.
  • Ambiguity: a mistake in the program's own steps (a before step reading a missing field) isn't the server's error. It goes straight to today's notice, never to a failure step, so a failure step can't hide a bug.
  • Spanish shows the same notice, translated.
