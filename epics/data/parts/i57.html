A list written in braces draws its items, whatever kind of list it is.

  • Reproduced in a real browser, on the real example: every book's card shows "Book can't draw", because the page's drawing library can't draw a Spell list. The page kept answering here, so the hang itself did not come back.
  • The compiler knows when a value in braces is a list, and hands it to a new step in the core, core.listShown().
  • A list of text or numbers shows as words with commas: "Ann Author, Bob Writer".
  • A list of things that draw themselves draws each one.
  • The Public Servers example goes back to {its author name}, showing every author.
