Each tab keeps its own list on this device, and a tab that opens takes over what closed tabs left behind.

  • Each page gets a new tab name when it loads, and holds a browser lock under that name for as long as it lives. The browser lets the lock go when the tab closes, crashes or reloads.
  • A tab's pending changes are kept under the place's key plus the tab's name, so two open tabs can't write over each other.
  • When a place opens, it looks for the same key under other tab names. Any tab whose lock nobody holds is gone: its changes join this tab's list, in the order they were made, and its copy is removed.
  • A list kept before this change, under the old key with no tab name, is gathered the same way, so nothing kept today is lost.
  • Reloading is the same as closing then opening: the new page gathers what the old one left, before it sends anything.
  • Two tabs opening at once take turns, under one more lock, so a closed tab's changes are picked up by only one of them.
  • A page with no browser locks (an address that isn't https or local, or no browser at all) keeps one list for all its tabs, as today.
