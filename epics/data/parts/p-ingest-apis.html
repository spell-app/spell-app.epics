Pointing a program at someone's server means reading its docs by hand and working out its fields.

  • Owen, 2026-10-31: "Spell command to ingest one of our data sources via agent and make an api description doc for it. Do this before StarWars and use it to extract the data for SW."
  • spell place ingest <address> samples the source for real, has an agent read what comes back and any docs, and writes one description: its collections, fields and types, ids, links between things, paging, limits, what it can do.
  • The description includes the Spell to paste: the place's line and details, and a type per collection. The command checks that this Spell compiles, and that a read through it really returns rows.
  • It works for any kind of place, starting with a web server; GraphQL can read its schema, a CSV its header row.
  • Never sends a write; a key is named, and never written into the description.
  • Owen, 2026-10-31: "flag for type, if no flag, attempt to discover by hitting the URL, if you can't figure it out, ask them. We'll want to be able to do this in the editor soon."
  • --kind <kind> names the kind of place. With none, the command works it out by reading the address. If it can't tell, it asks, and with no one to ask, it stops and says which kinds it tried.
  • The work sits in a library the command calls, with the question handed in, so the editor can run the same steps and ask in its own way later.
