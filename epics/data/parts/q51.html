For P49 · OpenAPI Ingest. A large API (about 270 paths, 320 schemas) split by its tags, while it stays one place. Today a type in another file goes by the place's name (it lives in acme); the place's own lines (jobs live at) are all under its one line. 

// Acme.api.spell:  the place and every collection's line
// Acme.jobs.api.spell:  a type per schema tagged jobs, each "it lives in acme"

// or each tag's file says its own collections:
acme also has:
	jobs live at "/api/jobs"
  • The ambiguity: acme also has is a new way into a place from outside its line, and two files could each say the same collection.
  • Recommended: no new words, the collections' lines in one file, the types by tag.
