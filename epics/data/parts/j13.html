You asked for epic pages to move onto chunked files. I planned it so they share the file code, the format and the reads, but the tool keeps editing a whole page and writing it back, rather than each edit being a change to one thing.

  • Why: all of the epic tool works on a whole parsed page under one lock, about 3,800 lines of it. Changing that would be its own large rewrite of the tool every running session uses, and a lock already keeps its writers apart.
  • What you'd miss: epic pages don't test a place's write path, its pending changes or its conflict check. The recipe box still has to.
  • P6 stays about 3-5 hours, and a git revert stays safe.
