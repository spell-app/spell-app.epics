  1. Run the ingest. Point spell place ingest at Open-Meteo's forecast for one place (hourly temperature and rain), and write down every place it stops or guesses wrong.
  2. Hours from lists side by side. The answer holds a list of times and, beside it, a list for each value. The ingest sees lists of the same length under one name and writes them as one list of hours, each with its time and values; the core turns the lists into those things when it reads.
  3. Found by where. A forecast is read for a latitude and a longitude given in the question. The ingest writes them as what a read must say, and a read that leaves them out is refused when the program is compiled, saying what to give.
  4. The units it names. The answer names each value's unit (°C, mm, km/h). The ingest writes each field as a measure in that unit, in the words the language's units already read (P24 · Units the Person Reads, in epic language), so a temperature shows in the reader's own units.
