J12 says Sources stays as it is, and J11 says the Loader's code doesn't change. Both still hold for what they do, but each lost a small part:

  • Sources's private abortable() moved to LoadOnce.abortable(), because places need the same few lines, and a copy would go against WWOD's rule on duplicates.
  • The Loader's load() now calls a new loadEntry(), which leaves undo alone. A reference in a row reads through that, since going through load() would have forgotten undo on every refresh.
