A folder place stands on an object shaped like SpaceStorage, and the app's DiskStorage is above the kit, so the demo and the kit's tests had nothing to stand on. I chose to make ChunkFiles that same shape, over moving DiskStorage down, because the plan says the app's fits as it stands. It hears the disk through LiveReload's watching, so this phase adds no raw watcher.

The shape gained two optional methods, a thing's version and a write only from that version, because it had no way to say a conflict. DiskStorage has both, on the file operations' own check. A storage without them still works, and the last save wins.
