The Public Servers example itself, laid out again so it is less crowded, above all in a full-screen window. Commits d63d658e6 and 8b8b32fac.

  • Every tab sits in a centred column (<container>). Before, everything started 8 pixels from the window edges: at 1920 pixels wide the to-do lines ran about 1900 pixels.
  • Every page has the same header: its title and search, then its chips, then the results, with twice as much room above the results.
  • The try-these chips are a toolbar that scrolls sideways, so on a phone they take one row, not two.
  • GitHub people:
    • a small round avatar beside the login, four to a row (was six full-width square avatars: 24 people took 1271 pixels)
    • stackable, one card a row on a phone, so a login and its GitHub icon always fit on one line (0 of 48 cards overflow or wrap the icon at 390 pixels wide; was 16 and 3)
  • A GitHub person page:
    • titled by the name, else the login (before, a person with no name got just a big icon)
    • Back is an icon on the title row
    • the counts and the bio show only once they are read (before: "public repositories · followers" with no numbers)
  • GitHub rate limit: a quiet orange line saying to try again in a minute, not a big red box (twice).
  • A repository with no language no longer ends in a stray "·".
  • Open-Meteo hours: a table with headings; the day shows only at midnight (it was on all 48 rows); the numbers right-aligned.
  • REST Countries: a table with headings, a bigger flag, the currency code in plain grey, the languages on one line, and the names' language picked in a select on the title row.
  • JSONPlaceholder: the to-do field and Add on one line; every remove button at the right.
  • the Public Servers example reads as one calm column at any window width, its six tabs alike
