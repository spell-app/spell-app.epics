For P49 · OpenAPI Ingest. One place, several servers, each with its own address (a path prefix too) and its own key; picked when running, without editing the file; each read only or safe for writes, so --try-writes and verify refuse production. 

acme is a web server at "https://dev.acme.test/service/v1"
	its production server is at "https://acme.test/service/v1", read only
	its staging server is at "https://staging.acme.test/service/v1"
	its key is the secret "ACME_KEY"     <- ACME_KEY_PRODUCTION on production?

// or no words:  the servers in the project's file
"places": { "acme": { "production": { "at": "...", "key": "ACME_KEY_PRODUCTION", "readOnly": true } } }
  • The ambiguity: server is already the place's kind (a web server), so its production server may read as a second place. And read only on one server sits beside it is read only for the place.
  • Picking one: spell run --server production, or SPELL_SERVER=production; the first named is the default.
  • Recommended: the project's file, no new words, as addresses for each machine aren't the program's to say.
