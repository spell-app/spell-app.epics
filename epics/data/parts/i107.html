tell me exactly what to do to set this up

About 10 minutes. Do it all in one sitting: the demo wipes itself every night at 04:00 UTC (11pm your time).

  1. Make an account. Open demo.netbox.dev/plugins/demo/login/.

    • Leave Username and Password empty, and click Create & Sign In. It makes one for you.
    • You should see: NetBox's home page, signed in as user and a number, top right.
    • Every demo account is an admin, so writes are allowed.

  2. Make a token. Click your user name, top right, then API Tokens, then Add a Token.

    • Leave everything as it is: Version v2, Enabled and Write enabled ticked.
    • Description: spell. Click Create.
    • Copy the whole token it shows: it starts nbt_ and has a dot in the middle. You only see it this once.
    • Spell sends it as Authorization: Bearer nbt_..., which is how NetBox wants a v2 token. Don't pick v1.

  3. Give the token to Spell, in a terminal. Spell reads it from the environment only, and never writes it down. 

    export NETBOX_TOKEN='nbt_paste.it_here'
    • Keep this terminal for every step below: a new one won't have it.

  4. Make the NetBox place, in a folder outside every repo, as its rows are real data:

    mkdir -p ~/netbox-try
cd ~/netbox-try
spell place ingest https://demo.netbox.dev --kind "web server" --spec "https://demo.netbox.dev/api/schema/?format=json" --key-secret NETBOX_TOKEN --name netbox --into NetBox.api.spell --no-examples --no-ai
    • About a minute. You should see Added netbox to NetBox.api.spell., then a list of left-out label lines: that's I106, expected.
    • NetBox.api.spell now says its key is the secret "NETBOX_TOKEN" under its first line.

  5. Check every list reads, still in ~/netbox-try:

    cd ~/netbox-try
spell place verify NetBox.api.spell
    • About a minute (yesterday's run, refused everywhere, took 44 s).
    • You should see What changed: with lines like circuits: failed => verified., and no What failed: list, or a short one.

  6. Try writes. It adds, changes and deletes one row of the first list that read, and says whether NetBox kept it: 

    cd ~/netbox-try
spell place verify NetBox.api.spell --try-writes
    • --try-writes takes no list name: it picks the first list with rows itself. Harmless here: the demo wipes it tonight.

If something doesn't work, tell Claude on this item (I107) the step number and paste the last 20 lines it printed. Common ones:

  • the key named NETBOX_TOKEN isn't in the environment: step 3 was in another terminal.
  • 403: Invalid v2 token: part of the token was cut off, or it was made before 04:00 UTC and wiped.
  • 403: Invalid v1 token: a v1 token; make a v2 one.
  • spell: command not found: run cd ~/www/spell && yarn cli:install once.
