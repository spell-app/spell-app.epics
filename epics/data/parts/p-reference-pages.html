  • Open design questions, for that page:
    • What the source is for each kind of reference, and what a page is made from: the description, the parser's rules, a project's declarations.
    • Where the edited words live: in the source beside what they explain, in a file of their own beside the page, or in the page itself.
    • How an edit is matched back when the source changes: by name, by a stable id, by position; and what happens to an edit whose thing was renamed or removed.
    • Where a person edits: in place on the page, in the editor, or in a file.
    • What is generated and never edited (types, addresses, states) and what's prose a person owns (summaries, notes, examples).
    • What a reference page is: a page in the editor, as the place reference is today, an element any page can hold, or a docs page the page server serves; and how one links to another.
    • How it's checked: a stale page, an edit that no longer matches anything, a missing description.
    • Languages: a Spanish project's reference, and edited words in two languages.
