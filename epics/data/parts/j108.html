The plan said one shared poll on every() passing changes to every browser. Chose answers shared for a window over a server timer for browsers, because of Airtable's monthly caps (found while checking its docs: the free plan's 1,000 a month): a timer keeps spending with no tab open, and a window stops when the tabs do. A browser still asks every N seconds, and many tabs make one request each window, so a change takes up to twice N to show. watch() runs one timer on every(), for a referee. Also kept to 4 a second, not 5: a late request makes six in Airtable's second, which costs 30 seconds of everyone's.
