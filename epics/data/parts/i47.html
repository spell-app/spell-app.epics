A stat's stat is { name: "hp", url: ".../stat/1/" }, of a collection the ingest wasn't asked for. As text it reads https://pokeapi.co/api/v2/stat/1/, not hp. Its version, language and others are the same.

PokéSpell names its six bars by their place in the list instead (PokéAPI always lists them in one order). Better: a small type with a name, held inside, never fetched.

details

PokéAPI points at other things with a small pair, a name and an address: "stat": { "name": "hp", "url": ".../stat/1/" }. The ingest keeps only the address, so the stat of stat reads https://pokeapi.co/api/v2/stat/1/ where a person wants hp.

  • How it gets there, in three steps:
    1. While it looks at the rows, fieldsOf() turns every name-and-address pair into its address (linkIn()), so the field is a "link" (epic data's P27, More REST Servers).
    2. Then findLinks() asks "is that address one of the collections I was asked to read?" PokéSpell's ingest asked for pokemon, species, types, abilities, moves, evolution chains and generations: not stats. So the link points nowhere.
    3. Writing the Spell, typeWordsFor() writes a link that points nowhere as text, and when it's read the runtime does the same swap again (addressesOf()): the address.
  • Where the address IS one of its collections, it works: its "kind" is a type and its "generation" is a generation follow the address and read the real thing.
  • P28 (GitHub REST) didn't touch this; P29 (Open Library) only added links by id, and left this case as it was.
  • It isn't only stat. In PokéSpell's API file, 15 fields at the top of a type say // an address (growth rate, colour, shape, habitat, the move's target ...), and more inside the small types say nothing at all (a stat's stat, a flavour text's language and version, a move's version group).
  • Side find: the lines of a type written for what's INSIDE a row never get the // an address comment (typesInside() never calls commentFor()), which is why its "stat" is text gives no warning.

/** A `{ name, url }`, or a list of them, as its address:  anything else as it is. */
function linkIn(value: unknown): unknown {
  if (Array.isArray(value)) return value.every(isNamedLink) ? value.map((each) => (each as { url: string }).url) : value
  return isNamedLink(value) ? (value as { url: string }).url : value
}

/** Is this a link with its name, PokéAPI's way:  `{ "name": "pikachu", "url": "https://..." }`? */
function isNamedLink(value: unknown): boolean {
  if (!isObject(value)) return false
  const { url, ...rest } = value as Record<string, unknown>
  return typeof url === "string" && IS_LINK.test(url) && Object.keys(rest).every((key) => key === "name")
}
