So a date's day, its hour and how a page shows it all come from the same clock, the reader's.

  • Text with a time and no zone (Open-Meteo's 2026-11-06T14:00) already read that way; only a day alone read as UTC.
  • Both cores now do it: the JavaScript one and the Python one.
  • Text with a zone (...Z) is the same moment as before, shown in the reader's time.
