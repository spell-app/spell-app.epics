Chose one SavedRead per type and query, whose changes cell a memo follows, over a link or a timer: a new answer, a write or a heal runs the memo again, and thingsFrom() runs inside that. Each computation reading it holds it until it's disposed (onCleanup()); the last one letting go calls result.leave(). It stays listed, still hearing rows, so its list stays true: so the map of reads grows by distinct query, for a program's life.
