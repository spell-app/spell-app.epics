The plan's example said its "created at". The ingest writes its "created_at" instead.

Why: a named field is matched exactly, so the words form wouldn't find it.

The ingest will write the words, as the plan's example did: - a recipe's created is its "created at".

  • A name written as plain lowercase words finds the server's field by its words, however the server spells them: created_at, createdAt, Created At. A spelling that matches exactly comes first.
  • A name written any other way, like "created_at", stays exact, so old lines mean what they meant.
  • When one row really has two fields with the same words (both created_at and createdAt), the words can't say which, so the ingest keeps the exact spelling for that one line.
