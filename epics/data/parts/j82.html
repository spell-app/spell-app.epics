Chose plain { id, name, page } over a built-in type. A built-in with a stored name has to be a real property of a runtime class (builtinTypes.test.ts pins it), which is a class and a registry entry for three fields. What it costs: no hover docs on it, and Spanish's el nombre de la persona compiles to .nombre, so a person carries each language's word for its name (WORDS_FOR_NAME in saved.ts): a new language adds its word there. There's no way yet for a program to set the name; the page's server or Guest 1234 says it.
