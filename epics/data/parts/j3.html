No run-time call can say which line declares a value. I first chose to have the compiler write that down in design builds, over shipping it in every app, because only the editor needs it.

The coherence review found no design build exists. So Gathering Reads now has a choice in it, whose recommended option has each saved property's own declaration carry its line, and its plan follows that option.

  • The editor gets the declaring line, with no new way to build a program.
  • Built apps grow by one small value per saved property, unless the other option is picked.
