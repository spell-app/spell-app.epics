Where these collide

  • every recipe: it's a scratch list today, of what the program made. For a saved type it would mean those in the place: a real change of meaning, though no existing program has a saved type. Tried: a line below the type can tell it's saved, and one above it can't, so The Words has to note it with the stubs.
  • when someone else changes it: tried: today it compiles, with no error, to an event of that name, which never comes. So does when a recipe changes:. A higher priority fixes both, and has a test.
  • belongs to one: it refuses an owner that isn't a list today, and will accept one.
  • send: it keeps meaning events. A named operation on a place reads as an action, not as send.
  • source: taken by Spell UI's sources and by source code, so a "data source" would collide.
  • store: taken by several classes and the Solid store, and tienda is a shop.
  • record: taken by the undo history and the reactive engine. Data should be plain things.
  • sync: used all over, mostly for forms and the DOM. Avoid it.
  • find, load, fetch: people name their own actions with these (load the scores), so a program's own always wins. load the recipes and fetch the recipes read, only of a type. Tried: all three stay free, and a program's own to reload the recipes: wins over the proposed word.
  • is saved in: only a place's name may follow, or is saved in its own file reads its own as a property.
  • save the draft: the recipe box has its own draft, a text. save takes only a real draft, and of anything else says there's no save step.
  • (stop|cancel) search: inside a handler, today's cancel <event> takes it, and drops the name.
  • Helpful errors: save, fetch of what isn't a read, query, connect to, database and join should each get a message naming what to write.
  • A bare plural: recipes reads every recipe only if the program has nothing called that: its property, variable or argument wins, and caja de recetas stays one name.
  • "And" for "or": where its cook is "Ana" and its cook is "Bo" can never be true, so Spell should say so, and offer its cook is "Ana" or "Bo", which doesn't work yet: it's always true (I13). its cook is "Ana" or its cook is "Bo" does.
