The Overview names Spell UI's Sources as something to reuse. I chose to reuse its behaviour and its helper, not the class, because util can't import it, and it holds only text from the page's own address.

  • Reads And Cancelling moves its helper, LoadOnce, down, for a shared load.
  • A reader's signal aborting only its own wait is written the same way.
  • Saving with a version check comes from the file operations' check, which it also uses.
  • Sources stays as it is, and places don't depend on it.
