Found building P30's page: a page property its "todos" made add its new todo to the todos add to that property's list, so nothing was saved, and nothing said so. The page calls its property own todos. Worth a warning where a property's words are a saved type's plural.

the todos means every saved todo, unless the thing the action is about has a property of that name: then it means the property. So a page with a property called todos silently changes what add its new todo to the todos does: it adds to the property's list, never to the server.

  • Found building the JSONPlaceholder page (P30), which first had <property "todos">every todo where its user id is 1</property>.
  • What a person sees: the Add button does nothing lasting. The server is never asked, no notice comes, and the next read of the list doesn't have the new todo.
  • Why: the property's value is what a read gave back, a list of its own. Adding to it is adding to that copy.
  • The page now calls the property own todos, so the todos is every todo again, and the add compiles to a save.
