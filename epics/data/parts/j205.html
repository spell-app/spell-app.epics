Built: WebPlace.readBehind() asks with cache: "no-cache", so the browser sends its own If-None-Match from what it holds, and a 304 comes back as the answer it had.

  • Why: swapi's CORS answer doesn't allow an if-none-match header from a page, so a header of ours would fail before it left.
  • And neither swapi nor PokéAPI lets a page read their ETag (no Access-Control-Expose-Headers).
  • A copy that didn't change tells nobody; one that did re-reads that place's reads, from the copy now fresh, so only what really differs redraws.
