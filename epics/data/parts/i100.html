Undo after a draft's Save removed the last-added recipe, not the edit.

  • The guide lists it under Limits.

A draft's Save becomes one Undo step, named "Edit", so Undo after it takes back that edit and nothing older.

  • Why it happened: Undo only hears changes made inside an undoable action, and a Save button's action isn't one. So Save made no step, and Undo took the step before it, the last recipe added.
  • Save now records its changes as one step. Saving with nothing changed makes no step.
  • Inside an undoable action, Save joins that action's step, as adding and removing do.
  • One more thing goes with it: right after Save, Spell makes a fresh draft holding the saved values. It would go on holding them after Undo, so reopening Edit would show the undone text. A draft nobody has typed in is now thrown away when the real thing changes, and the next read makes a new one.
