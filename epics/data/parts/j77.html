Undo of a remove writes the whole row back. A row read with fields left out would come back without them, which is losing someone's data. So any type a program removes, saves again or drafts is read whole, with no note since nothing can change it. That covers the flagship, so its compiled savedIn has no select.

Also: a selection only goes to a place that can leave fields out (GraphQL, memory). A web service asks for everything anyway.
