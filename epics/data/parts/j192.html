Chose no new words over a place line (a forecast's hours are lists side by side): an object whose every field is a list of the same length, given to a property declared as a list of things, can only mean one thing. The core turns it into one row per place in the lists (rowsOfListsSideBySide(), in its places), each named by its type's own stored as. The ingest writes its "hours" is a list of hours, stored as "hourly": hourly reads as hours (daily, weekly ... likewise).
