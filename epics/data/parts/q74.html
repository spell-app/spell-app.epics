  • Spell has no word for this today: cancel calls off an action before it's done, which is something else (below).
  • Ambiguity: ignore it could read as ignoring the job; do nothing reads as a step that's only there to fill a gap. nevermind says the error doesn't matter.
  • How it differs from cancel: cancel is in a before step and stops the call, so nothing is sent. nevermind is in a failure step, after the call failed, and stops the error going any further.
