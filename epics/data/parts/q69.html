to complete a job

		<failure code>
 
to complete a job
	cancel if the job's status is "done"
	call the server
	show "Done"
	if that fails
		show the error's message

para completar un trabajo
	cancelar si el estado del trabajo es "done"
	llamar al servidor
	mostrar "Hecho"
	si eso falla
		mostrar el mensaje del error
  • if that fails already follows a place's read or write in Spell, so it reads the same here. on error would be a second way to say it.
  • Ambiguity: call the server could read as calling any server. Here it means the action's own server call, and it's refused outside an action that has one.
  • A wrapping action has the same words as the server action's line, so it's known as the wrapper by having no is at.
