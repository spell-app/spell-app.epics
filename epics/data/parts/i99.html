Two things are wrong, and both get fixed:

  • The sort tells the place the property by the wrong spelling, created_at. It will say the name compiled code and rows use, createdAt.
  • An atmosphere account never reads lines like - a status's created is its "created at", so its created stays empty and there is nothing to sort by. It will read them the way a web server does, for reads and for writes.

Then Statusphere's list becomes every status sorted by its created, newest first, with no reverse found.
