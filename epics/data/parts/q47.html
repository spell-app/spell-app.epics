For P49 · OpenAPI Ingest. Today every collection that live at is taken as writable, and only it is read only turns writes off, for the whole place. The spec says per path which of POST, PUT, PATCH, DELETE each takes. 

	jobs live at "/api/jobs"
	jobs are read only
	jobs can be added and changed
	- it adds and changes jobs
  • The ambiguity: jobs are read only could read as each job's fields being read only, not the server refusing writes. jobs can be added and changed lists what it does, so a missing word means a refusal, which is easy to miss.
  • Or no words: the writes stay in .api.json5, and the core refuses what the description says isn't there. But the program doesn't carry the description.
