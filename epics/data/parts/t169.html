Owen, 2026-11-18, on the reference pages page: "deprecating the // on the same line, use -- comments on the first line in the thing"; "convert to -- comments on the first line after the thing".

  • Today both // and -- are comments. A declaration's description is the first comment line under it (epic language P48), else the comment lines just above, else the comment at the end of its own line. -- at a line's end also describes a drawing (to draw its placeholder -- a grey ace).
  • Deprecating same-line // everywhere is a language change, every example and guide with it: beyond this epic. P53 only writes and reads -- first-line comments.
