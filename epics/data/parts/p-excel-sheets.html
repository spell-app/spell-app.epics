  • Built: a spreadsheet whose address ends .xlsx reads an Excel workbook; a .csv stays a CSV file. And a new place kind, an excel file at "recipes.xlsx" (Spanish un archivo de excel en "recetas.xlsx"), names a workbook whatever its address ends in. Both go through the same rows a CSV file gives (SheetTable): the id column, rows with no id, the notes.
  • Each sheet of a workbook is a collection, named by its tab (case, spaces and dashes aside); a workbook with one tab answers any name. Numbers come out as numbers; a date reads as text with no time zone, 1977-05-25 or 1977-05-25T10:30, so it shows in the reader's own time. The id column is every sheet's: a sheet without it says so.
  • Writing, behind the place server only: ExcelPlace, beside the CSV one, with its rules: a row's version is a hash of its cells, a change from an old version is refused, no id column means adds only. Each save is read, changed and written under the file's lock, all at once. It keeps the other sheets, columns the program doesn't know, formulas and column widths; a row that moves takes its formulas with it. Cell colours and fonts are lost (the free SheetJS drops styles), and every save's answer says so. A file that isn't a workbook is refused rather than saved over.
  • The library: SheetJS 0.20.3, the newest, from SheetJS's own site (npm's copy is stuck at 0.18.5). Its small build, which reads and writes .xlsx only, loads when a page first reads a workbook: 271 KB (87 KB zipped) in a chunk of its own. The CSV place itself grew by about 1 KB. The full build would have been 503 KB.
  • The ingest: spell place ingest on an .xlsx address looks at the workbook, one collection per sheet, its first row the fields. A read through the Spell now gets a binary answer as bytes, not text.
  • Recipe Box gains recipes.xlsx and two commented lines, a spreadsheet at and an excel file at. The words lists (the coherence words page, the Spanish glossary and words), README-spell's "Where data lives", the CLI's --kind help and the data guide's places table say both lines.
