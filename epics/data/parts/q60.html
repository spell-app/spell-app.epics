For P49 · OpenAPI Ingest. Owen on Q59: "Would be good to have a 'master switch' at the collection level, unindented, which we could use to e.g. turn off delete". Unindented, so outside the web server's lines; it narrows what every job's own enabled operations line can enable. 

enabled job operations are add, change, complete

operaciones activas de los trabajos: añadir, cambiar, completar
 
deleting jobs is disabled

borrar trabajos está desactivado
 
no job can be deleted

ningún trabajo se puede borrar
  • Which wins: in each, the master switch wins. A thing's own line can only narrow it, never turn back on what the switch turned off; a thing that lists delete anyway warns when it compiles.
  • Ambiguity: an unindented line about jobs could read as about the type job, which is the thing level, not the collection. A says the collection by its plural, job operations; C reads like a rule the program checks, not what the server allows.
  • A lists what's on, as the thing's line does; B and C name what's off, which is shorter for one switch.
