Every thing already has a type (its class's name) and an id, so a place's own fields by those names would hide them: TypeScript flagged Wikipedia's type. The ingest writes its "kind" is text, stored as "type" and its "number" is a number, stored as "id". PokéAPI's types entries read the kind of a slot, a little stiff: a pokemon's own id is its Pokédex number, its "number".
