Sheets and Airtable name their columns the way a web server names its fields: one matching, in FieldNames, used both ways.

  • Reading: each column becomes the name the program uses. A line such as a recipe's title is its "Dish Name" wins, and any other column is matched by its words, so Hair Color is read as hairColor and Cuisine as cuisine.
  • Writing: each field goes back under the column it was read from, so a write to hairColor lands in Hair Color instead of being refused. Every place that writes reads the columns first, so it knows them.
  • The id column keeps its own name, as the place's id is read from it.
  • This covers a CSV file or workbook read in the browser (SheetPlace), the same files through a server (CsvPlace, ExcelPlace), Google Sheets, and Airtable, which closes T65 and T84 too.
  • A program's lines reach a server the way Airtable's already do, with each request. Python's sheets send them the same way.
  • A number column read under another name still reads as a number.
