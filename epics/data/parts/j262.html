  • Why NetBox: it's the nearest public twin of a large internal API. An inventory of a company's network, 4 to 5 times the request's API in size, split by tags, paged as {count, next, results}, errors as {"detail": ...}, a token in a header, its spec served without sign-in.
  • Reads and writes need a free demo account, which anyone can make on its sign-in page. Its data is reset every night at 04:00 UTC, so writes there do no harm.
  • SpaceTraders, the runner-up: reads with no sign-in, a free game account, and the most action routes (POST /my/ships/{shipSymbol}/orbit), but a fifth of NetBox's size.
  • Not FastAPI-made: no public FastAPI one of this size was found. NetBox's is made by Django's spec writer, which differs in small ways (3.0, not 3.1).
  • How it differs from P28 · GitHub REST: P28 sampled a few of GitHub's lists. This reads a whole spec, writes included. GitHub's own spec was left out: it can only be written to with a real account, and P28 already reads GitHub.
