linkBySchema() turns a field holding ONE Brief copy of another list's thing into a link (a tenant's group is a tenant group). A LIST of them (a module bay's module_bay_types, a list of BriefModuleBayType) isn't linked, as the list's schemaAt is its path, so I106 gives it a type inside, 'module bay type summary'. Linking those lists too (a list of module bay types, read by address) would need no type inside at all; left for a decision.
