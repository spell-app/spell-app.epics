Today every field's first real value goes into .api.json5 as example. For a spec-sourced ingest none is written: the spec's own example values are used where it has them, as they're not anyone's data.

  • --no-examples turns them off for a sample-row ingest too; that stays on by default, so the public examples don't change.
  • --examples-into ~/fixtures/acme keeps the real rows there, and the description names the folder, never the rows. The site data panel reads live, or from that folder.
