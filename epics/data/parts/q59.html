For P49 · OpenAPI Ingest. Owen: "DO NOT put the enabled at the web server level". The live at lines are indented under the web server's line, so they read as that level too. 

a "job" is a thing
	it lives in netbox
	enabled operations are add, change           <- on the thing

netbox is a web server at "https://demo.netbox.dev"
	jobs live at "/api/jobs"
		enabled operations are add, change       <- under the collection, one step deeper
  • The ambiguity: the second sits inside the web server's block, but belongs to one collection, not the place.
  • On the thing, a type moved to another place carries a line about its old server with it.
