<for its types /> (a list of pokemon type) and <for the pokemon of its picked kind /> (type pokemon) compile in TypeScript to Pokemontype and Typepokemon, which don't exist: PokéSpell's tsc snapshot shows them. JavaScript is right.

A list keeps the words of what it holds apart, so its items get the type's real name.

  • The cause: a list of PokemonType was named in lower case with the words run together, list of pokemontypes, and the name read back from that is Pokemontype.
  • P.listOf() will split a name of several words where a capital starts a word, list of pokemon-types, for every caller.
  • P.listOfType(), which only some callers used for this, goes: there is one way to name a list.
  • PokéSpell's tsc snapshot loses its three wrong-name errors.
