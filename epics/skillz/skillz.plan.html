1. starts ONE background agent (`Agent`, `run_in_background: true`) with the task VERBATIM, plus this session's
context: checkout / worktree, epic and plan doc if any, the agent budget `n`, and the house rules that matter
(WWOD, stage don't commit unless told, edit shared files at their real path, record judgement calls in the plan
doc, plain shell commands in a worktree)
2. replies ONE line, "started: <short name> (<n> agents)", and ENDS THE TURN, so the panel is free at once
3. when the agent's notification arrives: a short report (what changed, where to look, anything that needs Owen),
links per the root rules (side bar + browser; plan docs in the Review tab)
- `/bg list`: the background tasks running, with their names and age; `/bg stop <name>`: stop one (TaskStop).
- Several `/bg` at once are fine; two touching the same files: say so, and run the second after the first.
