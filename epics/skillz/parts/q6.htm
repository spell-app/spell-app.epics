Several helpers may add, update and remove their entries in the same list at the same moment. The question was who writes the file.

The options weighed:

  • A · a new command, spell dev agent add|set|done|list|wait, with a locked write (plan-doc’s file lock): one place that knows the file’s path, prefix and format
  • B · Claude edits the JSON by hand (Read, then Edit): no code, but two helpers writing at once clobber each other’s entries, and every skill must know the path and format

Picked: A (Owen, in a modal, 2026-10-07). It is a repo action, so a spell dev command, as the commands page’s "Layers" says.

Net effect:

  • packages/cli/src/dev/agent.ts is built first (P1), with tests
  • the /bg skill and the standing rule only ever call spell dev agent ...
  • wait and told come in P3, for redirects from the page
