The list command is spell dev agents, not spell dev agent (2026-10-07): the WWOD citation check that had the name moves to spell dev wwod check (Q12).

  • /bg ["name"] [n] <task>: start the task.
    • "name" (optional, a quoted first word) names the helper; the real name gets the epic’s prefix: /bg "aaa" ... here is skillz-aaa. No name: Claude makes one up from the task.
    • n (optional, default 1) is the most agents the task may use IN ALL, the helper itself included. /bg 4 <task>: the helper plus up to 3 of its own.
    • A hard cap: unlike the root rule (up to 5 agents, unasked), the helper never goes over n (C1).
  • /bg ?: the agents still running, from the list (spell dev agents list), each with its name, task, status and age.
  • /bg stop <name>: stop one (TaskStop by its task id), and take it off the list.
