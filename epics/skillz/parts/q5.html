In an epic, the list of running agents lives beside the plan doc, epics/<epic>/agents.json. The question was where it lives when the session has no epic: on main, or in an /isolate worktree without a plan doc.

The options weighed:

  • A · ~/.spell/agents/<checkout>.json: outside the repo, one file per checkout; nothing to ignore, but out of sight, and the file name must encode the checkout path
  • B · only epics keep a list: simplest, but /bg ? and the same-files check would not work outside an epic
  • C · <checkout root>/.spell-agents.json, git-ignored: beside the work, found the same way as the checkout itself

Picked: C (Owen, in a modal, 2026-10-07).

  • spell dev agent writes <checkout root>/.spell-agents.json when the checkout has no epic (P1)
  • .spell-agents.json goes in spell-app’s .gitignore
  • /bg ? and the same-files check work on main too
