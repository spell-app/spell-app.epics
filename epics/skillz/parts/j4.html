The rule “every agent Claude starts is named and listed, and plan-doc work goes to a background agent” had to live somewhere every session reads. It went into “Delegated work” in the root CLAUDE.md, kept short, and points at .claude/skills/bg/SKILL.md for the steps.

Why CLAUDE.md, not AGENTS.md:

  • the rule is Claude-only: it uses Claude Code’s Agent and TaskStop tools
  • AGENTS.md is the cross-model file: Codex reads it too, and has neither tool

Why short there, with the full steps in the skill:

  • the steps (the skill’s “Names” and “When its notice arrives”) are kept in ONE place
  • a rule in two places drifts: the house rule is that a rule lives in exactly one place
  • CLAUDE.md gains a three-bullet “Delegated work” paragraph: add / done around every agent, the bold Agent <full name> came back with: line, plan-doc work in the background
  • .claude/skills/bg/SKILL.md holds how to do each of them; a change to the steps is made there only
  • Codex sessions see none of it
