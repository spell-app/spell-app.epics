As with the name: in a terminal it asks "Which colour should your words be?"; with none (a Claude session running it, a script), it keeps the suggestion, the first colour name nobody has, rather than leaving the person in the shared colour.

  • --color answers it either way; a name someone has is refused, listing the free ones.
  • RepoInit.init() called from code (tests) asks nothing and keeps no colour unless given one.
  • Everyone who runs epic init gets a colour of their own, different from the team's.
