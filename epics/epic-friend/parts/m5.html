1. In a terminal (not inside VS Code), from the kit's checkout, build the extension: 
    cd ~/www/spell.worktrees/epic-friend/epic && yarn vscode:package
  2. Open Cursor (the app), File, Open Folder..., and open ~/www/spell.worktrees/epic-friend.
  3. In Cursor's terminal (View, Terminal), run: 
    node epic/bin/epic plugin install
  4. Run Developer: Reload Window from the Command Palette (Cmd+Shift+P).
  5. Look for the Review view (the checklist icon) in Cursor's right side bar. If it isn't there: Command Palette, View: Open View..., type Review, Enter.
  6. In Cursor's terminal: 
    node epic/bin/epic open epic-friend --review
  • Step 3's last lines say "Cursor: extension spell-app.spell-epic ... installed" (or nothing, if it was there already).
  • The Review view exists in Cursor, in the right side bar or found by View: Open View.
  • Step 6 shows the epic-friend epic page in that view, not in Chrome.
