On main, spell-brand takes most of its settings from the kit ({ top: "../spell" }), but its install keys are its own. Its file leaves installOnCreate out, so main reads Spell's old default, false.

After P6, a left-out key reads as epic init would write it for that repo. spell-brand has a yarn.lock, so it will read true: a new spell-brand worktree will run yarn install before it opens. Its other own keys (base branch main, yarn install, its worktrees beside it, no app) come out the same.

To keep it as it is: add "installOnCreate": false to spell-brand's .epic/config.json5. I left that repo alone (outside this worktree). This branch doesn't have main's peer code yet, so the check was worked out by hand from main's epic config in spell-brand.
