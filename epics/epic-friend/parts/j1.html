Owen asked for "epic rename me bob or some such" (Q10). It became a flag on whoami, in line with Q11.

  • One command for your name: epic whoami shows it, epic whoami Bob keeps a new one, epic whoami --rename Bob also rewrites the old one in every doc.
  • Kept apart on purpose: setting a name for the first time should never rewrite pages; rewriting is a bigger step you ask for by name.
  • Not epic rename me: the commands page has no rename noun, and "me" would be a word nothing else uses.
  • Where it's built: P1 reserves the flag; P2 · Names On Everything does the rewriting, since it touches every writer; P9 · Shared Comments renames the person's comments file.
