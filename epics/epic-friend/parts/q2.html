Where does "who are you" come from, on each person's machine? No login: each person runs their own epic server, which stamps their name.

  • Nothing to set up: every developer already has one (git config user.name prints "Ana Lima").
  • Their content-repo commits already carry the same name as author.
  • Spell's people app reads it the same way, for a starter profile.
  • Downside: a full name, where a page might want "Ana".
  • ~/.spell-epic/person.json5, { name: "Ana" }, set by a command or a "Who are you?" box on the page.
  • A short name, chosen apart from git's.
  • One more thing to set up; falls back to git's name when missing.
  • no new setting: the name on the page is git's user.name
