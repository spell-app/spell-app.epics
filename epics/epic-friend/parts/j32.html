Codex puts its thread's id, CODEX_THREAD_ID, on every shell command it runs. That's from Codex's own code on GitHub (openai/codex, codex-rs/core/src/exec_env.rs: "CODEX_THREAD_ID is injected when a thread id is provided, even when include_only is set"); it also sets CODEX_SESSION_ID.
