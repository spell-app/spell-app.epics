README/npm.md's spell publish fold is a What it printed fold built from the command's own messages (its first line, scratch install, and the dry run's last line, the middle as ...), not a captured run.

  • A dry run rebuilds every folder's declarations (outside dist-packs/) and its scratch install needs the network, so it wasn't run here, with P10 building in the same worktree.
  • The page's one tested example is spell publish --help (an Output fold, passing).
  • The npm whoami fold shows the real account name, owenoak, the public publisher of the packages.
  • Not stated, as unverified: npm's maximum token lifetime, and npm's exact menu path for a granular token.
