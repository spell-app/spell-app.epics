The plan said the repo's editor first, then the window. Built the other way: SPELL_EPIC_EDITOR (this machine), then the window the command runs in (Cursor's marks in the environment), then the repo's editor, then VS Code.

  • Why: a repo saying cursor would make a teammate in VS Code open Cursor windows. The window a command runs in is the surest sign; the repo's setting is for commands run outside any editor (a plain terminal).
  • A team can mix VS Code and Cursor; each person's tools follow their own editor.
