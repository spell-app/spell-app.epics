The plugin acts as if every repo were Spell: its worktree hook breaks Claude Code's worktrees in repos without epic init, and settings left out fall back to Spell's values.

  • In a repo with no epic settings, a Claude Code worktree is made exactly as Claude Code would make it.
  • No default names spell-app, ../spell-app-dev or yarn install; Spell's own config spells those out.
  • The docs and comments name ~/.spell-epic, the folder the code uses (T1).

The worktree hook does Claude Code's own plain worktree in a repo without epic settings. A missing setting falls back to a neutral default, never Spell's. The docs name the real home folder.
