Merging P5 will NOT start pushing spell.epics: the sync runs only when .epic/config.json5 names contentRemote, and the kit's config names none (checked).

  • But spell.epics already has an origin: https://github.com/spell-app/spell-app.epics.git, branch master. Without the config gate, every turn would have pushed it.
  • To turn it on: add "contentRemote": "https://github.com/spell-app/spell-app.epics.git" to the kit's .epic/config.json5 (or run epic init in the kit, which records an existing origin as contentRemote: so running epic init in the kit turns pushing on).
  • Leave it off: commits stay local, as today.
