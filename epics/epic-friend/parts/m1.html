1. In Terminal, make a throwaway repo: 
mkdir -p /tmp/try-epics/app && cd /tmp/try-epics/app && git init -b main && git commit --allow-empty -m first
2. Run 
epic init
and press Enter at 'What should the shared epics repo be called? (app-epics)'.

It prints 'shared repo: made &lt;you&gt;/app-epics on GitHub, private, and pushed', the repo is on github.com with one commit, and .epic/config.json5 has its address as contentRemote. Delete the GitHub repo after.
