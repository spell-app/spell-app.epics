1. In Terminal, make a throwaway repo: 
mkdir -p /tmp/try-epics/app && cd /tmp/try-epics/app && git init -b main && git commit --allow-empty -m first
2. Run 
epic init
and press Enter at 'What should the shared epics repo be called? (app.epics)'.

It asks every question first, then prints a summary and ends with Epics initialized!. The repo is on github.com with one commit, and .epic/config.json5 has its address as contentRemote. Delete the GitHub repo after, and rm -rf /tmp/try-epics to run it again.
