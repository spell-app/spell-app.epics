Calls made in P6:

  • A left-out key reads as epic init writes it, for EVERY key it writes, not only the folders. So linkSessionFolders, windows.worktreeOnly and installOnCreate (when there's an install) now default to on, and sharedFolders to epics, sagas, guides, pages. Before, they were spell-app's: off, and seven folders.
  • windows.contentName and windowsFolder follow a contentFolder the file names. installOnCreate follows a named installCommand.
  • The base branch is read from git's own files, not by running git, because the page server asks often: the remote's default branch, else main, else master, else whatever the main checkout has checked out. epic init now writes the same: before, it skipped main and master and wrote the checked-out branch.
  • A repo counts as set up when it has its own file, OR it's a child repo its multi-repo top names.
  • In a repo that isn't set up, the worktree hook makes the worktree Claude Code makes: .claude/worktrees/<name>, branch worktree-<name>, from origin/HEAD, else HEAD. Removing one is more careful than Claude Code: a worktree with uncommitted changes stays, and so does a branch with commits nothing else has.
