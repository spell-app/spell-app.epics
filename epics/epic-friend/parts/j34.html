The plan said the page turns each colors entry into a theme token. As built, each reply and thread message sets its speaker's token with the settings' colour as its fallback: var(--epic-voice-agent-codex, #0f8b8d) (ThreadFacts.voiceOf()).

  • Same effect: a theme or page can still set --epic-voice-agent-codex and win over the settings.
  • No page-start code needed, so it works on every page that has the pack, docs pages and Epic UI's site included.
  • Someone without a colour: the token is unset and the card falls back to the shared voice, so nothing looks different until colors says so.
