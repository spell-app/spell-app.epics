For (Owen picked Q15 C): how the epic skills run under Codex without a second copy of each.

  • Chose: the SAME skill files for both. Codex's plugin manifest points at the one skills folder Claude's plugin uses, and each step that needs a Claude Code tool has a one-line "In Codex:" way beside it.
  • Over: generating Codex copies from ours when the plugin is installed or published.
  • Because:
    • both agents read the same skill format (a SKILL.md with a name and a description), so nothing needs converting
    • generated copies are 20 more files to keep honest, and a build step between editing a skill and trying it
    • a check (epic skills check) keeps the one copy honest: a Claude-only tool with no Codex line fails it
  • The only generated files: Codex's two custom agents (designer, coherence), written from our agent files at install, since Codex wants its own settings-file format for them.
  • one copy of each skill, read by both agents
  • P12 adds "In Codex:" lines and a skills check, not a Codex folder
