What was built, phase by phase. Each phase's Done list has the details.

  1. Who you are (P1): epic whoami and epic whois; one home for the engine's folder and the person (EpicHome); git's name read one way, on the kit's git runner (Git). Every served page gets the person's name.
  2. Names on everything (P2): every writer stamps the person; an agent's words are marked as an agent's, never told by a name; epic whoami --rename rewrites an old name.
  3. Words for people (P3): "Owen" out of the page text, the help, the messages to Claude and the 20 skills. Epic UI's hand-written pages and code comments are left (T9).
  4. Sharing the content repo (P4, P5): epic init makes or clones the shared repo (contentRemote in the config); every turn's commit fetches, renumbers clashing ids, rebases and pushes. Spell's own content repo syncs too (J18).
  5. Outside-repo rough edges (P6): a repo epic init never set up is left alone by every hook; a left-out setting reads as that repo's own, never Spell's; the docs say ~/.spell-epic.
  6. The READMEs (P7, P8): README-epics.md for teams, and the kit's topic READMEs moved into README/.
  7. Shared comments (P9): one comments file per person beside each page, synced with the plans; marks stay on each machine.
  8. Other agents (P10, P11, P12): below, "Other agents (Codex)".
  9. One-step setup (P13): npx spell@next epic init is the one command, for the first person and every teammate: spell epic runs the epic tool, epic init installs the plugin when it's missing, asks the person's name and colour, and starts the epic server last.
  10. Colour names (P14): colors takes Spell UI's names (green, teal ...), drawn from the theme; VoiceColor is the one check.
  11. Other systems (P15): the process, link and clipboard helpers work on Linux and Windows too, the plugin install puts the extension into the editor, and a Windows CI job reports. Tried by people in the future epics epic-windows and epic-linux.
  12. Cursor (P16): Editor picks code or cursor (the machine, then the window, then the repo's editor setting); the extension installs into Cursor. A live Cursor window is M5 and M6.
  13. Along the way: the two voices' colours as theme tokens (T11); epic init asks private or public, private by default (T19); epic server start registers a freshly set-up repo (I4).
