spell serve [target] [--port n] [--headless] runs the spell server, so the app can save to the local file system.

  • it opens the app in the browser, unless --headless
 the spell app (vite + express /api) on `--port`, opened on the target
  • the cli's serveCommand.ts
  • the app's server (index.ts, express, /api)
  • and its UI, on vite
  • serve in the background, then fetch /api and the page
  • --headless opens nothing
  • by hand: edit a file in the browser, and save it
