spell run on a UI project opens it in your browser, served from localhost until you press Ctrl-C. It serves the project as compiled when the run started.

  • Edit a spell file while it's open, and the page doesn't change.
  • To see the edit: stop the run and start it again.
  • nothing changes: the CLI's README.md says the same ("no live reload")
