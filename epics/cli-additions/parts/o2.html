A scope pack, <Project>.scopes.js, is the Type Explorer's data for a page with no parser, such as <spell-app>.

  • written after a CLEAN compile: compiled, with no file errors
  • three writers, all through SpellDiskWorkspace.writeScopes(), so their output is byte-identical:
    • the language server
    • yarn scopes
    • and now spell compile and spell watch (P1)
  • not with --stdout or --check-only: those write nothing
