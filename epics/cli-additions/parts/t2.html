Bundle the CLI into one file, so you can install spell without cloning the repo. Four things stand in the way:

  • keepNames: rules register by their class name, so the bundler mustn't rename them.
  • The import alias ($/...) must resolve inside the bundle.
  • __PACKAGE_VERSION__ must be filled in.
  • environment.ts must stop finding the projects folder next to spell's src/ folder.
