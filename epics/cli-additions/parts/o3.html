How spell speedtest times the parser, and compares two commits.

  1. One side is a child process running SP.spellParser.speedTest(), which prints JSON.
  2. --against <ref> times that commit too:
    • a temporary git worktree of the ref
    • the root's node_modules linked in
    • the runner COPIED in (D3), and run there
    • then the worktree removed
  3. Each side runs 3 times (--runs). Combined:
    • the mean of the averages, as an integer
    • the lowest min, and the highest max
  4. The table: Previous, Current, Change.
    • bold row headers, no ms, equal columns aligned right
