The plan said posting goes through the kit's request helper. fetch(), which UI.api stands on, can't report how far an upload has got, so each file is posted with XMLHttpRequest, one request per file, as form data in a field named file (its path as its file name).

  • A server's error answer becomes an ApiError, the same error UI.api throws, with the response in its cause.
  • Nothing answering is a plain Error; the row says "Failed: no connection".
