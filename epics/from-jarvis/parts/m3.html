1. Once this is merged into main, rebuild the extension from the main checkout:

cd ~/www/spell && spell app vscode

then reload VS Code (Cmd+Shift+P, Developer: Reload Window).

2. In VS Code, make a folder Clip with these files, copied from the parser's test project (parser/tests/spell/natives/clipboard/): clipboard.ts and Clipboard.spell; add Program.spell holding: 

copy "hello" to the clipboard\nprint shout "hi"

and a project.json:

{ "imports": [{ "path": "/clipboard.ts", "active": true }, { "path": "/Clipboard.spell", "active": true }, { "path": "/Program.spell", "active": true }] }

3. Open Program.spell, then Cmd+Shift+P, Spell: Run Project.

4. In the runner, open its Output tab. Then change shout in clipboard.ts to add + "!", save, and press Restart in the runner.

Output shows HI and copied hello, with no 'which this runner can't load yet' error in the toolbar. After the edit and Restart it shows HI! -- the code file is read afresh each run.
