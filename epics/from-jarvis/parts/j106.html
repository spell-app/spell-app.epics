KeyIsSecret, KeyIfSet, TokenFrom, KeyWritten, KeyGoesInHeader, KeyGoesInAddress keep their class and rule names, so compiled declarations and the syntax tables keep reading them. The old words register as OLD_KEY_IS_SECRET and the like (oldWords), each warning: Say "it is authenticated with the secret "X"": "its key is the secret "X"" stops working in a later release. The new code names say authenticated (AuthenticatedPlaces, authenticationLines).
