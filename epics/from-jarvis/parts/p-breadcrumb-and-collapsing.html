When the open path is deeper than the tree is wide, the first columns scroll out of view, and nothing says where you are.

  • You always see the whole path, and can click back to any column
  • Deep paths keep the last columns readable; the early ones narrow to a strip with the picked row's name

The tree's sticky-path line shows above the columns too, each part a way back to its column, styled like the editor's sticky header; and the columns before the last few narrow to a strip (coherence: narrow, not collapse), widening on hover or focus.

  • The path line becomes a nav a screen reader announces, its parts real buttons you can Tab to, like <ui-breadcrumbs>.
  • The same in the outline, where sticky-path is hidden from screen readers today.
  • It stays a picture of where you are; the columns' own keys are the way back.
  • Less to change in the outline view.
  1. One path line for both appearances: main's sticky-path (its parts path and path-row) is drawn by one private renderPath(rows, onPick), used by the outline and by the columns. (coherence) In columns it sits above them, drawn from path; each part picks that column's row and scrolls it into view.
  2. Its look is the editor's sticky header's, as sticky-path's is; whether it becomes a real navigation is this phase's choice.
  3. Narrow columns: columns before the last N (a setting, default 2) get a narrow state, not collapsed: Spell's word list keeps open / close for rows, so a column that shrinks gets its own word (coherence). A narrow column is a strip showing the picked row's name or icon; hover, focus, or a click on its part of the path widens it again. A CSS width transition, none under reduced motion.
  4. Vocabulary: the attribute (named after narrow) and parts in UITree.en.ts, Spanish in UITree.es.ts; a token for the strip's width; the property editor layout places them.
  5. Docs: the tree's page gets a deep example.
  6. Checked by: unit tests for which columns narrow, and for the path's clicks; a headless check of a 6-deep path at 600px and 1400px wide, light and dark.
  7. Left out: sizing (Column Sizing).
