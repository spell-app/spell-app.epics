Found building P6's docs example. A <ui-json> that's still pending (defined early by the root, its family not attached yet) takes el.value = x as a plain own property, which then shadows DOMJsonElement's value accessor for good: every later write lands on it, content stays empty and it shows No data. The example waits for json.ready before writing. Likely any family DOM class's accessor has this, unless the early element holds and replays property writes.

`item` shows a thing's data with no page code; a property set before its family loads reaches its setter
