P13 builds spell-runtime.js self-contained only for what a runtime keeps per copy (PER_COPY: core and the runner), the same rule dev's runtimeCopyInDev() uses, named once in the app's Vite config. Solid, Spell UI, spell/util and the places stay in the shared chunks, so every copy draws on the page's one Solid.

  • How: runtimeOwnCoreInBuild() gives the runtime's imports into PER_COPY modules of their own (?spell-runtime), so they bundle into the runtime alone; their lazy imports of each other (core's placeSamples) are made static.
  • A fully self-contained runtime (the paste's option 1 taken literally) would have given each copy its own Solid: rejected (coherence finding).
  • spell-runtime.js: 195,775 bytes before, 279,580 after (+84 KB: core that was in a chunk the editor shared, placeSamples, the runner's element code). The editor itself loads no core: none of its chunks hold any now.
