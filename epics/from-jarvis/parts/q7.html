This is for File Upload In Spell, the phase that lets a Spell page take a file someone picks or drops, like the Netlist Viewer's .json. Found by the coherence review, while the phase's plan was written.

Whichever way the phase's words go, a picked file becomes a Spell value with a type: a name, a size and its text. That type needs a name in Spell, and new words need your OK.

The catch: "file" already means something in Spell. It's a kind of place, where a project keeps its data (a place kept in a file). So a netlist file is a file would mean two things. 

A   a netlist viewer has a netlist file, a picked file.
    show the text of the netlist file.

B   a netlist viewer has a netlist file, an upload.
    show the text of the netlist file.

C   a netlist viewer has a netlist file, a file.
    (the place kind "file" told apart by where it's used)
