How should Jarvis tokens get renewed: Spell's own "its token comes from" line with a HallPass service principal's secret, or a script that swaps the secret for a token before Spell starts?

Hand-made HallPass tokens expire after hours; every read then answers 401 until a new one is saved and Spell restarted.

Since 0.8.9, Spell can renew a token itself (epic data's P49): a place line names where tokens are made and which secret makes them, and Spell asks for a new one as each runs out.
