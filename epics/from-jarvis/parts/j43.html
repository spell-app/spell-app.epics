Designer finding (phone width): the selected column was off-screen. Rather than min(width, (100% - strips) / 2) in CSS, which would also shrink columns that fit, the tree works out fullColumnMostPx: a column narrower than its share keeps its width, the rest share what's left. The box snaps (scroll-snap-type: x mandatory, each column start); a path change scrolls to the first column start that shows the selected column's end. The title band now runs on past the last column (a filler), and the last column's resize line sits inside the box, so it no longer makes the box scroll 3px.
