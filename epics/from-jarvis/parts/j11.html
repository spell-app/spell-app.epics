• string: <ui-input>, kept a string (no longer read as JSON, as the handoff did)
  • number: <ui-input type="number">
  • an ISO date (2026-11-18) or date and time (2026-11-18T10:00:00Z): type="date" / "datetime-local", written back in the same form (its Z or offset kept)
  • true / false: <ui-checkbox>
  • a key, or null: a text field, read as JSON else as a string, as the handoff did
  • JSON has no enums, so a pick list needs its choices from the page: editors, a script property by key name, e.g. { direction: ["in", "out"], when: "date" }; a list makes a <ui-select>, a word names the control outright.
  • Alternative: editable itself taking that object. Rejected: one attribute both a yes/no and an object is hard to type and to show in the property editor.
