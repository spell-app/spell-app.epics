Spell UI has no element for a graph of nodes and wires with nested parts: the handoff's <ui-graph> lives outside the kit.

  • <ui-graph> is a Spell UI tag, with its docs page in the components site
  • It shares the kit's text measuring with the diagrams, rather than its own copy
  • Unit tests for its layout and for opening a nested graph

<ui-graph> comes into Spell UI from the handoff, at its newest version: nodes with ports, wires between them, nested graphs opened in place, in a modal or by drilling in, with pan, zoom and fit. It's registered, documented and tested like every other tag.
