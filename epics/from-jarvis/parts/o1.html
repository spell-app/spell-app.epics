The editor fills the console with a line for every file it reads, and it asks the server again and again whether the open file changed.

  • The chatter is one leftover console.warn in the server's serverPath getter: it runs for every file request.
  • The repeated asking is the editor's open-file watch, editor.watchOpenFile(). It re-reads the open file every 2 seconds, not 5 (FILE_POLL), and it was 2 in 0.8.9 too. Each re-read is a request, so each one also prints the chatter line.
  • Spell has no web worker at all: nothing calls new Worker or SharedWorker. What can push is the page server's live channel, a websocket that already tells open pages which file changed (LiveReload, liveClient()).
