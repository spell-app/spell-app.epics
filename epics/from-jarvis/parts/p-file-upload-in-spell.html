A Spell page can show a file input, but no Spell words read the file someone picks or drops.

  • A Spell page lets you pick or drop a .json file and use its text
  • In English and Spanish

Spell words for picking or dropping a file and reading its text, so a page can hand an uploaded file to its own code.

  • <input type="file" name="netlist file"> binds to a property, as form controls do; dropping a file on the drop area sets the same property.
  • Then the text of the netlist file, a built-in member of a file.
  • No new statements, only a built-in type with members.
  • when a file is dropped: / when a file is picked:, with the file in hand.
  • Two new handler rules.
  1. Look first at what exists: <ui-input type="file"> already picks files, and Spell has drag and drop for its own things; the gap is reading a picked or dropped file.
  2. The words are this phase's choice below. Whichever: a file someone gives becomes a Spell value with its name, size and text (read once, as text), so read netlist from the file's text works.
  3. Rules in parser/src/spell/rules/, English and Spanish, with their tests; the core reads the file in the browser (and refuses in spell run, saying why).
  4. yarn spell:gen:syntax after the rules; the syntax guide picks them up.
  5. Checked by: rule tests; a tiny example run in the editor, picking a file and dropping one.
  6. Left out: binary files and uploads to a server.
