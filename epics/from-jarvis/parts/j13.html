The editor's page is vite's, so the page server never put its live client on it. The kit's new joinLiveChannel() (beside the live client) sets window.SPELL_SERVER and loads /api/server/live.js through the proxy, which already passes /api websockets on.

  • No write token and no run: a page server restart never reloads the editor (I329 stays true).
  • Every changed-script offer is taken, so the live client never reloads the editor for new code: vite does that.
  • Not in a frame: the live client would hand a frame's keys and right-clicks to VS Code; a framed editor keeps the slow poll.
