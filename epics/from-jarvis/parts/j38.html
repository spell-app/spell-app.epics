As the Finder: Option-drag (Alt) sets one width for every column, deeper ones too, kept as every, and clears each column's own. A column's own drag still wins over it. Option-double-click fits every column on screen to its own rows; Option with the arrow keys resizes every column.

A double-click now fits instead of putting the column back, so no gesture goes back to size: only forgetting the kept widths does.
