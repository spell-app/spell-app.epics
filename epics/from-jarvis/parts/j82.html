• ui tree view is a type called UiTreeView, added to the project's scope the first time a line names it, with a property for each of the element's attributes.
  • Compiled, a type built on it extends View and names its element: static uiElement = "ui-tree". core.uiElementOf() reads it.
  • The element's hooks and attributes come from the component pack (viewBaseFor()), from a new generated table, hooks.generated.ts, which yarn site:data writes.
