The handoff's demo set its nested graphs from a script, with ALU's children loaded lazily after 400 ms. On the docs page and in examples/elements/ui-graph.html the flat and nested graphs are JSON in the graph attribute; ALU's children are given, not lazy (a function can't be JSON). Lazy children are shown in the Usage tab's code instead. The 150-node graph is a 22 kB attribute in the examples file (axe and the visual tests read it), and made by a short script at the end of the docs page.
