Only the base element's attributes show on <jarvis-netlist-column>. A property the type declares itself, beyond those, isn't an attribute of the element, as a plain view's is.

The element of a type built on a Spell UI element gets an attribute for each property the type declares itself, as a plain view's element does.

  • Its vocabulary is the Spell UI element's, then one attribute per own property, from the same list a plain view's element reads (typePropertiesOf()).
  • Kept the same both ways: the page sets the attribute and the thing follows; the thing changes and the attribute follows.
  • A value the page wrote on a tag with no thing of its own goes to the thing the element makes.
  • Left out for now: a property holding another thing, or the list holding it (shown as references on a plain view), and a property an edit adds while the program runs.
