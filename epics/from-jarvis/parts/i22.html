spell run --target py of a program that draws serves it on Quart (serveApp() in runTarget.ts), which writes the program and its imports into its folder but not clipboard.py. A program that doesn't draw runs.

The web app's folder gets the program's .py code files, as spell compile --target py already writes them.

  • One helper copies a project's code files in a language into a folder: spell compile's copy moves into it, and spell run --target py's web app calls it too.
  • So from clipboard import copy_text finds clipboard.py beside the program on Quart.
