The plan said the uploader holds a <ui-input type="file">. It holds an invisible native <input type="file"> instead, which nobody sees: its only job is opening the browser's file dialog.

  • <ui-input type="file"> can't open its dialog from script (its native input is in its own shadow root, and it has no showPicker()), and can't pick folders (webkitdirectory).
  • Everything people see is Spell UI: <ui-button>, <ui-input> (the input look), <ui-segment>, <ui-progress>, <ui-popup>, <ui-icon>.
  • Other way: give <ui-input> a showPicker() and a folder mode, then hold one of those.
