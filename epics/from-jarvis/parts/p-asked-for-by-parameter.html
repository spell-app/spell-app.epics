A list that needs a query parameter it has no field for, like Jarvis's layer stacks, can't be described in Spell.

  • layer stacks are asked for by their system compiles and reads (Q4)
  • spell place ingest --spec writes it

A list may be asked for by a parameter that isn't a field, given in a read the same way; the OpenAPI reader writes it from a spec.
