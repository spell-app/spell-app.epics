<ui-json> holds JSON but draws nothing, so a page can't show JSON as a foldable outline; the handoff's viewer that does lives outside the kit.

  • A page shows JSON as an outline that opens and closes, from Spell UI itself
  • Copy, the quotes toggle and editing work as they did in the handoff's demo
  • Spanish names, a docs section, and unit tests

The handoff's JSON viewer comes into Spell UI: a foldable outline of any JSON value, with Copy, a quotes toggle, a click event on keys and values, and editing in place. Where it lives, inside <ui-json> or as its own tag beside it, is this phase's choice.

  • As the handoff's own words have it: "we'll eventually fold this into <ui-json> itself".
  • <ui-json appearance="outline"> draws the outline; without it, <ui-json> draws nothing, as today.
  • The viewer's members become <ui-json>'s: one tag, one vocabulary.
  • The subclass comes in as it is, UIJsonViewer.tsx beside UIJson.tsx, defined by the family's barrel.
  • Less to change now; a second tag to learn, and folding it in later is a rename for every page using it.

Nothing in the kit does this already: <ui-code language="json"> shows JSON as coloured text, with no folding; <ui-tree> is an outline of rows, not of a JSON value's members.

    • UIJsonViewer.tsx (about 600 lines): its drawing into UIJson.tsx, shown with appearance="outline"
    • UIJsonViewer.en.ts: its attributes (depth, quotes, no-header, editable), parts, texts and the ui-json-navigate event into UIJson.en.ts; Spanish into UIJson.es.ts (none came)
    • UIJsonViewer.css: into UIJson.css, or a second sheet UIJson.outline.css loaded only for the outline
    • index.ts: its exports (JSON_NAVIGATE, JsonNavigateDetail) into the family's barrel
    • ui-json-viewer.html and .demo.ts: become docs examples and examples/elements/ pages, their sample data made up
  2. Copy uses the kit's E.ClipboardCopy, as <ui-code>'s copy button does, instead of its own clipboard call and timer (coherence).
  3. Its colours stay on the theme's --ui-code-* tokens, with --ui-json-* overrides.
  4. The handoff's first rough edge fixed: with editable, a double-click's first click no longer sends a ui-json-navigate.
  5. The property editor layout, ui-json.editor.html, places the new attributes; yarn site:data (and yarn gen:root for option B).
  6. The docs page, ui/docs/ui-json.html: an outline section, from the demo (opened one level, three levels and editable, all closed, a 387-member object).
