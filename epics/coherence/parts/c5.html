The first question to the code map after a commit waits about 40 seconds, while the stale map rebuilds.

  • A map older than the newest commit is rebuilt before it's asked.
  • graphify's update re-reads every file, not just the changed ones, so a rebuild costs the same as the first build.
  • The docs map, ours, rebuilds in under a second.
  • Later questions, until the next commit, answer at once.
