Spell UI's docs code names the person reading a docs page three ways: "viewer" 51 times, "reader" 18, "person" 10. The word list has no entry for it yet.

  • WWOD says "people" for the ones using an app, never "users": that settles UI text, not this.
  • WWOD's writing rules (its §6) already call the person reading a docs page "the reader".
  • It's mostly in comments and names in Spell UI's docs components and site, not in text people see.
