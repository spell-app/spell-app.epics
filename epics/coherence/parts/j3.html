spell map looks a name up exactly itself before asking graphify, so a question about a class lands on that class.

  • graphify's own lookup also matches longer names: Tokenizer hits MarkdownTokenizer too.
  • With more than one match it refuses to answer.
  • spell map finds the exact name first; when several things share it, the one in a file named for it wins.
  • No exact match: it lists the candidates with their ids, to ask again by id.
  • spell map explain Tokenizer explains Tokenizer, not a refusal
  • an unclear name lists its candidates instead of failing
