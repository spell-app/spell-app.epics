WWOD §5: x ?? die("message") for a required value. Ours: die() (src/util/spell/die.ts) RETURNS an Error after a console.warn; only getDier()'s die throws. So WWOD's idiom silently does nothing here. 

const file = files.get(path) ?? die("no file")   // file is an Error, nothing thrown
const file = files.get(path) ?? die("no file")   // WWOD:  throws, file is never undefined

Adopt the idiom; debt entry: die() becomes never-returning (its callers checked). Until then the rule says ?? getDier(...)(...) or a plain throw.

Keep die() as is; required values use an explicit if (!x) throw or an OrDie method.
