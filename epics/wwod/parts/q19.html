Two rules answer "don't pass a bare true" differently: §9 "String sentinels" (forget("skip notification")) and §7 "any boolean param, take a params object". §9's own examples use booleans (overwrite: boolean | "check", { optional: true }).

A positional boolean is never OK. One mode switch: a sentinel string. Several options: a params object, where named booleans are fine ({ optional: true }).

No booleans at all, even named ones.
