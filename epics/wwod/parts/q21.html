§12 says behaviour switches are ALL-CAPS statics at the top (Match.DEBUG_MATCH_INITIALIZATION), and also "prefer @proto static for any per-class constant behaviour switch" (@proto static inlineInitialType = false).

ALL-CAPS static: a developer / debug switch, set by hand for the whole class tree. @proto static: a behaviour a subclass or instance overrides.

Drop the ALL-CAPS switch form.
