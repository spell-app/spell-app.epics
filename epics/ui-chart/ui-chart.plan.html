A <ui-chart> element that takes a chart as data and draws it with Observable Plot by default, with Plotly's figures and a d3 module of your own as other engines. It uses the shared server drawing (Mermaid, coloured code) to put the chart in the page as SVG before any script runs, so a chart costs a few KB instead of a library.

I'm going to want a `<ui-chart>` very soon, which should work both with Plotly (possibly drawn on the server) and d3 (same).
