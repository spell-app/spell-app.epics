Page notes show their bubbles only on a page server running this branch's code.

  • The bubbles appear only when GET /api/notes answers. The main checkout's page server (the one the side bar uses) gets that route once P3 is merged and the server restarts (server ensure restarts one older than its code).
  • Until then pages show no bubbles, never a broken one.

Three more limits of page notes:

  • Notes on scratch details pages (pages/details/) are written, but the shared repo ignores that folder: they are never committed
  • A page that wasn't oxfmt-clean gets the note pre-indented, not reformatted (J3)
  • Claude editing a page with the Edit tool takes no page lock, so a note saved in that moment could be overwritten (once C4); epic notes does take the lock
