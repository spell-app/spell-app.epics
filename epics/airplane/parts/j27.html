Cmd-K's jump dialog is a plain Spell UI modal, built by hand, because the ready-made prompt can't stay open on a miss.

  • Spell UI has no <ui-prompt> element.
  • Its prompt helper, UI.modals.prompt(), closes on any answer: so it couldn't stay open on an unknown id.
  • So the dialog is a <ui-modal>, built the way that helper builds its own.
    • On a miss, it cancels the modal's approve event (ui-approve).
  • It takes any id (J7, q3, P2, o1), in any case, with or without a leading #.
  • An unknown one says "No J999 on this page.", with the text selected.
  • It lands through the same path as a click on a #j7 link.
  • Not while typing in a field, nor with a dialog open; on plan docs only.
  • A check option on Spell UI's prompt helper would make this Spell UI's own. Not done: it changes a Spell UI API.
