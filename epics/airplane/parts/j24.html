Favourites are one shared file, written through the Epics route module the page server already has.

  • A new route, POST /api/epics/favorite, joins New epic's in epicRoutes.
  • That module is already registered in the page server's routes (pageServer.routes): no new module.
  • It writes the favourites file (favorites.json) under its file lock, atomically.
  • Unstarring the last one leaves an empty list ([]), rather than deleting the file.

The Epics index is shared, so until airplane merges, older code draws it the old way.

  • Older code: main's page server, or another worktree's docs index.
  • Main's page server puts running epics' cards at the start marker, outside the groups.
  • An older docs index rewrites the page as one flat list.
  • Both go away when airplane merges into main.
  • A star clicked in any window shows on every checkout's Epics page, on its next load.
  • Until the merge, main's page server may show the running epics' cards loose above the groups.
