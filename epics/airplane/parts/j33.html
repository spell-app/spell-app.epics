One comment shape, CommentList, for docs pages and plan docs alike.

  • It lives in the epics package's tool folder (tool/).
    • Why: the docs package may import epics, never the reverse.
    • And a plan doc's review inbox holds comments in the same shape.
  • Ids are cm1, cm2 ..., not c1.
    • c1 is already a caveat's id, and plan-doc inbox done takes both.
  • A docs page's comments go in an inbox file beside it (<page>.inbox.json), git-ignored.
    • The ignore rule is in the shared repo's .gitignore, and in the copy epic shared init writes.
    • It covers the inbox files under guides/, pages/ and epics/: 
      guides/**/*.inbox.json*
pages/**/*.inbox.json*
epics/**/*.inbox.json*
  • A comment Claude took stays in its file, marked taken, with which phase took it.
    • So the page keeps showing where it went (status: taken).
    • The file goes only when its last comment is deleted.
  • Comments are per machine until gathered, as review marks are.
