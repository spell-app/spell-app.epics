CommentList lives in packages/epics/src/tool/ because docs may import epics, never the reverse, and a plan doc's review inbox holds comments in the same shape. Ids are cm1 ..., not c1: c1 is a caveat's id, and plan-doc inbox done takes both. A docs page's comments go in <page>.inbox.json beside it, git-ignored (guides/**, pages/**, epics/** *.inbox.json*, in the shared .gitignore and spell dev shared init's copy). A taken comment stays in its file (status: taken, which phase), so the page keeps showing where it went; the file goes only when its last comment is deleted.

  • Comments are per machine until gathered (as review marks are).
