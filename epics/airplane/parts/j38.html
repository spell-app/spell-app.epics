When an agent hands the plan-doc tool a name and the file it lives in, the tool now writes just the name, with the path as its hover tooltip. A click still opens the file.

  • It rewrites a path alone in brackets after a name, whatever the name is.
  • It rewrites a path after a comma only when the name matches the file, or its folder. So buildTsx() with its own file is rewritten; a method with some other file is left alone.
  • The path may be in a code span, plain text, or a link. A link moves onto the name.
  • It leaves folders, a file name with no folder or line, lists of names, and any other wording such as "in".
  • Only new text, on the way in. The converter and existing docs are untouched.
  • The links tool now links a name with a path tooltip to that file, so pages and plan docs keep their click-through.
