The writing checker now flags file paths and crowded code in the docs, but only where Owen reads prose: docs pages and Markdown.

  • Two new kinds: path-in-prose and code-dense (3 or more code spans in one sentence).
  • Code comments are left out: a docstring citing its file is how agents find things.
  • A code span counts as a path only when the whole span is a path. A command that names a file, like running the links tool, is not flagged.
  • Not flagged as paths: folders of two parts or fewer, packages, import aliases, routes, URLs, and a file name with no folder and no line number.
  • No separate no-lead kind: the existing dense kind now says to write a plain lead line, then one fact per bullet.
  • Today it finds about 820 path misses and 1,430 crowded sentences in the guides, and about 3,230 and 5,460 in the epics. Nothing was rewritten: the docs-check and fussbudget passes do that.
