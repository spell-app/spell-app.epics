The docs an epic writes besides its plan doc can drift from what was chosen, and from each other.A doc task, in two steps:
  1. Each doc an epic wrote, other than the plan doc, is checked against what the plan doc decided.
  2. Then those docs are read together, and made consistent with each other.
  • A skill, and its spell dev steps, that Owen runs on an epic or on several. In order:
    1. Find the docs the epic wrote besides its plan doc: its durable doc, guides, AGENTS.md files, skills, READMEs.
    2. Check each against the plan doc's decisions, answered questions and judgement calls, and fix what drifted.
    3. Read them as a group, and make them consistent with each other.
  • Run it before the flight (which epics: asked).
  • /docs-check <epic...>, or alone: then it asks which. It:
    1. checks each doc an epic wrote against what its plan doc decided, and fixes what contradicts it
    2. then reads them together, and makes names, commands, flags and numbers agree
    3. turns what it can't decide into a judgement call
    • It works in place, uncommitted.
    • Run it from the checkout with the epic's code: main for a merged one.
  • The finder, two new plan-doc commands:
    • spell dev plan-doc docs <name>: the docs, sorted into wrote, related, linked and swept
    • spell dev plan-doc decisions <name>: what the plan doc settled, in one call
