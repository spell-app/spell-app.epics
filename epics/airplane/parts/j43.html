VS Code's workbench.action.webview.openDeveloperTools ("Developer: Open Webview Developer Tools", src/vs/workbench/contrib/webview/electron-browser/webviewCommands.ts) takes no arguments: for iframe webviews it just calls nativeHostService.openDevTools(), the window's own tools. No command opens them on the Console tab or in element-pick mode. So both buttons (title bars of both views, $(inspect) and $(debug-console), after Open in Browser) run it, and their titles (the tooltips) say what to do next: Cmd+Shift+C there for the picker; the Console tab and the page (127.0.0.1) in its context menu. $(debug-console) over $(terminal): it's VS Code's own console icon, where a terminal icon promises a shell.

  • Two new icons on the Spell Docs and Review title bars, also palette commands "Spell: Inspect ..." / "Spell: Show Console ...".
  • Desktop VS Code only; elsewhere a warning.
