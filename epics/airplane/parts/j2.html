A page note is plain markup, drawn by the docs pages' own script and stylesheet.

  • The tags: <spell-notes>, <spell-note> and <spell-note-reply>.
  • The script: spell-doc-runtime.js, through a line it adds to the page's head.
  • The stylesheet: spell-doc.css.

Chose it over a real Spell UI element (@spell-app/ui), because it is much smaller:

  • no new component
  • no shadow DOM, which the page's live update can't see into
  • the markup reads as plain HTML to Claude
  • it survives the formatter (oxfmt) and docs update as it is
  • New: PageNotes.js, which makes the edits on the page's source.
  • New: the runtime's Page notes section, and a CSS block.
  • The docs script (spell-ui.js) is rebuilt.
  • Opened from a file (file://), the notes show as cards, folded, without bubbles.
