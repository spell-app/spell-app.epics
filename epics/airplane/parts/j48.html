VS Code adds Cut / Copy / Paste to every webview's menu, but they act only on a FOCUSED webview, or else on the active EDITOR's (overrideCommandForWebview() in src/vs/workbench/contrib/webview/browser/webview.contribution.ts); a menu drawn by VS Code takes focus, and a side-bar view is never an editor, so those items could silently do nothing. They're hidden (preventDefaultContextMenuItems, the documented switch) and ours go to the view the menu was opened in, named in the context VS Code passes each item (webview), through the same path as the Edit keys (DocView.edit()). Ours also show only where they make sense: Cut / Paste in a field, Copy with a selection.

  • Cut, Copy and Paste on the menu always reach the page right-clicked; a headless check (three origins, as in VS Code) pasted and copied with focus moved away
