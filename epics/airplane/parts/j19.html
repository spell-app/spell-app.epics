The docs finder sorts what it finds four ways (wrote, related, linked, swept), and doesn't read the swept ones.

Why there's a "swept":

  • The shared docs (guides, templates, Spell UI's pages, WWOD) aren't in spell-app's git.
  • So besides the durable doc and the epic's commits, the finder also looks at:
    • the shared repo's commits made at the end of the epic's turns (Turn-end: <epic>)
    • pages that name the epic
  • But a turn commits every session's edits, and a tool run over every page changes them all.
    • airplane's docs offline --fix touched 12 unrelated guides.
  • So a page found ONLY that way is "swept": counted, listed with --json, not read.

And a commit found by its subject (P6: Doc Review -- ...) that another epic's plan doc lists is that epic's, and dropped. skillz was picking up airplane's 164dd71.

    • skillz: 19 (7 wrote, 9 related, 3 linked); 0 swept
  • Missed: a page the epic wrote that lands in swept. That's one that:
    • neither names the epic, nor sits in a folder named for it
    • and that the epic only changed through the shared repo
