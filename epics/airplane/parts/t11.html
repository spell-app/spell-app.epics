Pages the docs tools write themselves keep their notes; templates take none.

  • The docs home and the list pages keep their bubbles.
    • When the docs index generator (index.js) rewrites part of a page, it carries every notes group back into the same section.
    • A group whose section is gone is kept at the end of the page.
    • Chose this over turning the bubbles off on those pages.
    • The code: replaceBetween() and PageNotes.carryOver(), on each <spell-notes> group.
  • Notes on templates are refused (403).
    • A note on a template (templates) would be copied into every page made from it.
  • Notes on these pages survive epic pages index and docs update:
    • the docs home (index.html)
    • the epics list (index.html)
    • the guides list (index.html)
  • No notes on:
    • templates
    • plan docs (they have the inbox)
    • goals pages (they have thoughts)
    • details pages with questions, and syntax-choices pages
    • Spell UI docs or brand pages
