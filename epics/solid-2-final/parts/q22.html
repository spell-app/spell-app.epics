Two parts:

  1. In the first speed wave: each shadow root installs only the event kinds it actually uses. This is the half of TLDR item 36 you kept; every element still keeps its shadow root.
  2. In the element-base comparison: one listener per event kind for the whole page, finding the real target inside open shadow roots with event.composedPath(), but only under a <ui-root>. Elements outside any <ui-root> (Spell UI in a React app) keep delegation per root. It rides with reworking ShadowEvents for Solid 2.0.3, compared with @solidjs/element 2.0.1's delegation.
