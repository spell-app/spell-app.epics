The docs used to be generated by a converter, which checked its own output. Now the pages are hand-written .html, so that self-check is gone, and a broken page is caught only by the separate checkers.

  • Three checkers cover most of what the converter checked:
    • doc-links.py --check: every local link resolves (now doc-links.js)
    • check-spell.js: the page renders in a browser, with no console errors
    • plan-doc check: a plan doc's structure and links
  • Not checked: exactly which checks the old converter ran, so what "most" leaves out.
  • nothing changes: an accepted limit
  • run the three checkers after editing a page by hand
