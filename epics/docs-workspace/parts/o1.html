Where everything lives in the docs workspace.

  • packages/docs/, named @spell-app/docs: docs for every package (D1)
  • one folder per doc: its page, named for the folder, and the doc's experiments/
  • templates/: the durable doc, the cheat sheet, and the plan template with its rules (plan.html, plan-doc.md)
  • a plan doc per /plan-doc session, in a folder named for it under plans/
  • the docs index, index.html: its lists written by yarn docs:index
  • _assets/: one classic bundle (Solid, Spell UI and the runtime), and the page and plan CSS
