The house style puts two spaces after a period. In the text of an HTML page, oxfmt squeezes them to one, so a page's source never keeps them.

  • Example, run 2026-10-04: <p>One.  Two  three.</p> comes out of oxfmt as <p>One. Two three.</p>.
  • A browser shows one space either way, so only the source is affected.

Net effect:

  • nothing changes: page text uses single spaces
