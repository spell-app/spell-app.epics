When this plan was written, a skill had no way to rename the Claude Code session or its VS Code tab. The /plan-doc skill had to ask you to type /rename yourself.

  • Claude can't run /rename: it's a command only you can type.
  • So a new planning session kept its first prompt as its title until you renamed it.
  • Looks done or obsolete: the /title skill now queues a title with spell dev session title <title>, and a UserPromptSubmit hook applies it on your next message; the prompt-gate.mjs hook also renames the session on /isolate <name> and /epic <name> (checked 2026-10-04).
  • you no longer need to type /rename after starting an epic
  • the new title shows only on your next message, not at once
