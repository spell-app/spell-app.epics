Spell UI's screenshot tests have reference images ("baselines") for macOS only, because the Linux ones are made in Docker, and Docker Desktop won't start here. You'd notice it in status.md: every family's Visual column says "🚧 local", not ✅.

  • Docker Desktop 4.42.1 crashes at launch on macOS 26.6.
  • So the baselines in baselines/ are local-darwin only, for all three browsers.
  • The fix, once Docker Desktop runs (likely by updating it): yarn test:visual --os linux --update in ui (T1).
  • Still true on 2026-10-04: Docker Desktop is 4.42.1, macOS is 26.6.2, and there's no linux baselines folder.
