D29 · Layout: table stacks by VIEWPORT by default

Fomantic's ui table stacks below 768px of the VIEWPORT (tablet stackable: 992px). The element used the host's own width, so every docs example (~655px column) showed the stacked layout. Now both hosted and static tables use the viewport (@media); an element opts in to its own width with --ui-table-stack-by: container (host, ancestor or page). Open choice for Owen: a vocabulary attribute instead of a token. Removed the docs page's site-note.
