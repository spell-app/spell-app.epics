With display="immediately", an icon inside a <ui-root> can briefly show the page's version of the icon, then redraw with the root's.

  • A root's icon set is made once the runtime loads: it lives in the runtime chunk.
  • An icon that loads first draws from the page's packs, then redraws when the root's set arrives.
  • The modes that hide content until ready don't show it.
  • Emoji names apply at once, so emoji don't flicker.
