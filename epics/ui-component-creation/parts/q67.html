UI.icons.scope(packs, { assets, parent }) makes a root's set; parent is a function asked at each lookup, so an inner root follows the outer root's CURRENT packs. SVG cache and registered icons are shared, one per page. EmojiData keeps loaded names per set (peek / get take a set; setFor(element)), so two roots can use different sets at once. IconGlyph now takes its owner: new IconGlyph(this, () => name).
