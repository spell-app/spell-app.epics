In a list item, a raw <img> slotted in front of <ui-content> sits on its own line, instead of beside the content.

  • Why: the item lays its parts out as table cells, and an image (a "replaced element") can never be a table cell.
  • A slotted <ui-image> now works: the image's owner tokens (--_ui-image-owner-display, -align, -max-width) make its HOST the cell.
  • For a raw image, use the item's image shorthand instead.
in a list item · 3 cases 
<!-- wraps -->
<ui-item><img src="a.png"><ui-content>...</ui-content></ui-item>
<!-- works -->
<ui-item><ui-image src="a.png"></ui-image><ui-content>...</ui-content></ui-item>
<ui-item image="a.png">...</ui-item>
