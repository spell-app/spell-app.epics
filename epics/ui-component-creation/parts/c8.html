A plain label inside a coloured box (a red segment, say) should stay uncoloured, as in Fomantic. That now holds for <ui-label> elements, but not for labels written as class markup (.ui.label).

  • The fix resets the inherited colour on the element's host (:host in ui-label.css).
  • Class markup lives in the page's own DOM, so it has no host to reset on, and still takes the box's colour.
  • Logged in agents/SUSPECTED-BUGS.md.
  • The follow-up todo: T5. The decision behind the fix: D26.
example · 8 lines 
<!-- uncoloured (fixed) -->
<ui-segment color="red">
  <ui-label>Plain</ui-label>
</ui-segment>
<!-- still red -->
<div class="ui red segment">
  <div class="ui label">Plain</div>
</div>
