D60 · Root box: width / height (CSS units or window) and a fixed flag

Owen: width / height take CSS units or window (100dvw / 100dvh); either set, the root is a box that scrolls its own content. fixed pins it to the viewport (position: fixed; inset: 0): a full-page app shell. Mobile: inset: 0 tracks the address bar, overscroll-behavior: contain; iOS's keyboard can cover fields near the bottom (documented).
