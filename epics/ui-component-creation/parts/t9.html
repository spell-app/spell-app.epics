<ui-emoji name> knows English names (and Fomantic's). This todo adds translated names, so a page in Spanish could write perro.

  • The plan: translation.md, "Emoji names".
  • The same generator would write one data folder per language, one JSON file per chunk. An English name keeps working on a translated page.
