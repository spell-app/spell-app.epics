A list marked .ui-list-plain (no bullets, no indent) still gets a 1.5em indent when it sits inside a .ui-prose column. You'd notice a bulleted-looking gap on a list meant to be flush.

  • The prose rule has the same specificity as .ui-list-plain, and comes later in utilities.css, so it wins.
  • The /components/ index worked around it with ui-not-prose.
  • Not fixed in src/styles: another agent owned src/ then.
  • Still there on 2026-10-04.
.ui-list-plain {
  list-style: none;
  margin: 0;
  padding: 0;
}
/* ... later, same specificity, so it wins: */
.ui-prose :where(ul, ol):not(:where(.ui-not-prose, .ui-not-prose *)) {
  padding-inline-start: 1.5em;
}
  • once fixed: .ui-list-plain is flush inside prose, with no ui-not-prose needed
