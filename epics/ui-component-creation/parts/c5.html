A page built with <ui-grid> or <ui-cards> elements spaced some sections differently from the same page written as Fomantic class markup ("static markup"). Measured as the gap from one heading to the next, static versus element:

Example page Difference
grid/types (celled grid) +16px

card/content one section
card/types one section
  • Same family of cause: the element's host is a size container (container: ... / inline-size), so a margin inside it can't collapse with the heading above.
  • But each needs its own fix, on the owner's side: for example the celled grid's margin, or the negative row spacing.
  • Not fixed when written. The plan for it: C21.
  • Looks done or obsolete: SUSPECTED-BUGS.md ("ui") says that on 2026-10-02 (epic seo) the size-container hosts that kept a margin from collapsing were fixed (table, celled grid, steps, statistics); card/content and card/types were disproven (they match class markup); grid/variations' remaining gap is consecutive grids, left out on purpose in ui-grid.css (checked 2026-10-04).
