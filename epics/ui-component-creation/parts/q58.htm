D46 · Browser: loader reads a build-time tag index, not ComponentDefinitions

The site's auto-loader (site/src/scripts/components.ts (gone since P20)) and the component browser read tag => folder / search key from a JSON blob each page carries (#site-component-index, from ComponentIndex.clientIndex(), itself from ComponentDefinitions at build time). Importing ComponentDefinitions client-side would eagerly bundle all 93 vocabularies (~500 KB source) into every page. EXTRA_TAGS and the plural / prefix guessing are gone.
