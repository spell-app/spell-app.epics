D42 · Split: PART_NOUNS / PART_VOCABULARIES live in ui-parts.types.ts; fallback VOCABULARIES are statics

ui-parts has no roll-up vocabulary file (it would match the *.vocabulary.en.ts globs): PART_NOUNS and PART_VOCABULARIES are exported from ui-parts.types.ts. In ui-form and ui-grid the fallback's VOCABULARIES list is a private static of the fallback class, because the types file holds values the vocabularies import (a types-to-vocabulary import would be a runtime cycle).
