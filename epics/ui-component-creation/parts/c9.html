Running the tests in WebKit (Safari's engine) turned up behaviour that differs from Chrome and Firefox. The tests and the code now allow for each one:

Safari does this So now
Tab skips links and buttons (Option+Tab reaches them) the test helper Keys.tab() handles it; Focus.trap no longer ignores Alt+Tab
A mouse click doesn't focus a button the dropdown's trigger focuses itself on a real click
Focusing into a shadow root picks the close icon Focus.enter() always focuses the target in the flat tree
replaceSync() twice, before any cssRules read, appends instead of replacing Styles.register reads a rule first
Adopted style sheets keep stale media-query results if no element using them is alive when the window resizes tests render first, then resize
No anchored container queries a new flag, UI.browser.supports.anchoredQueries

Title, as first written: Browsers: Safari quirks the tests now allow for (keys, focus, sheets)

Safari's Tab skips links/buttons (Option+Tab reaches them): test/keys.ts Keys.tab(); Focus.trap no longer ignores Alt+Tab. A mouse click doesn't focus a button: the dropdown trigger focuses itself on a real click. Focus.enter() always focuses the flat-tree target (WebKit picks the shadow root's close icon). replaceSync twice before any cssRules read appends: Styles.register reads a rule first. Adopted sheets keep stale media results if no element using them is alive at a viewport resize: tests render first, then resize. WebKit has no anchored container queries: new flag UI.browser.supports.anchoredQueries.
