D69 · How D48-D50 were built
  • Table stack-by: an enum attribute that adds a private class to the table (stack-by-container / stack-by-viewport, from the canonical value); the sheet's later, equal-specificity rules undo the token's way and stack the attribute's way. Not a host state: :host(:state()) setting --_table-stack-by, and :state() rules in the page sheet, both left WebKit with stale media / style queries on a LATER table.
  • Breadcrumb, feed: style queries now match only REAL elements, which set private values (--_ui-breadcrumb-divider-*, --_feed-line, --_feed-number*); the ::befores read them through var(), content defaulting to none. Fixes I7.
  • Form: the form host (:state(root), always on) is a block and an UNNAMED inline-size container; the stacking query is unnamed. <ui-fields> / <ui-field> share the sheet, so the rule is scoped by that state. Fixes I8.
