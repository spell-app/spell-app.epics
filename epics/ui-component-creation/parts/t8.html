The grid and card group elements had the same margin gap that item groups had (C5). The plan: fix each on its owner's side, as <ui-items> was.

  • How items did it: the group's outer margin sits on the HOST, because the host is a size container and a margin inside it never collapses with the heading above.
  • Looks done or obsolete: SUSPECTED-BUGS.md ("ui") records the celled grid's margin fixed on 2026-10-02, card/content and card/types disproven, and grid/variations' remaining gap left out on purpose (checked 2026-10-04). 
:host(:state(items)) {
  --_ui-items-margin: var(--ui-items-margin, 1.5em);
  display: block;
  container: ui-items / inline-size;
  /*
   * The group's outer margin sits on the HOST:  a size container is its own formatting context, so a margin on
   * the root inside it never collapses with the heading above, as static markup's does.
   */
  margin-block: var(--_ui-items-margin);
}
