WebKit's container lookup walks shadow-including DOM ancestors, not the flat tree through slots, so a size container that is an element INSIDE a shadow root (ui-form's .ui.form, display: contents host) is invisible to slotted descendants' own shadow trees. Container NAMES are also tree-scoped in WebKit (a name set by :host is not visible from a sibling shadow tree): fixed for grid and items by unnamed queries. ui-form needs its container on a real box host: test 'stacks rows on a narrow form' left failing.
