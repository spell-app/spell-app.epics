<ui-root> draws its content right away, but its own looks arrive a moment later. With display="immediately" you could see the content in the page's colours first, then switch.

  • What arrives later, with UI.load():
    • the root's own style sheet (its states for theme, box and fixed)
    • RootBox
  • The modes that hide content until ready (skeleton, when-ready) don't show the switch.
  • Without a box (display: contents), a theme sets colours but paints no background.

Title, as first written: Root theme / size / box apply once the runtime has loaded

The root renders eagerly, but its own sheet (states for theme / box / fixed) and RootBox arrive with UI.load(). With display="immediately" the content can show a moment in the page's scheme before switching. Hidden modes don't show it. Without a box (display: contents) a theme sets colours but paints no background.
