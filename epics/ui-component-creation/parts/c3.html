In the screenshot tests for <ui-input>'s types page, the empty date field is hidden behind a mask. Without it, the WebKit baseline would change every day.

  • WebKit draws an empty <input type="date">'s placeholder from the SYSTEM clock (e.g. 10/01/2026).
  • Playwright's clock freezes only JavaScript's Date, so it can't reach that.
  • The mask is a hook beside the example: types.visual.ts.
  • 6 baselines were refreshed (3 browsers, light and dark); only the masked area changed.
export default {
  mask: ["ui-input[type=date] input"]
} satisfies VisualHooks
