Switching the emoji names to Unicode's CLDR list made the names data bigger. A page still loads only one small chunk of it.

  • Over all chunks, gzipped: 28.6 kB before, 38.6 kB after.
  • A page still loads one chunk of about 5 kB.
  • It now holds 3,979 CLDR names plus 1,374 Fomantic aliases (3,808 names before).
  • Checked on the way:
    • the 44 hand-written emoji-presentation ranges matched Unicode exactly
    • the old rule "below U+1F000 gets U+FE0F" was too broad: 60 emoji had a U+FE0F they didn't need (e.g. zap, star)
  • The generated JSON is now indented with 2 spaces (Owen's rule). It's bundled as JS, so the shipped size doesn't change.
