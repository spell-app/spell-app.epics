• Icons are SVG files in packs: a folder of SVGs, plus a generated index, pack.js (file, size, aliases).
    • built by yarn icons:pack
    • built in: fa7-free (the default), fa7-brands and fomantic
  • Page-wide: UI.icons, in the runtime. 
    use(), reset(), resolve(), get(), peek(), register()
    • get(), use() and ready never reject (I1, fixed in P2)
    • a missing icon draws nothing; a pack with no usable URL warns once
  • Per subtree: <ui-root icons="fa7-free, /packs/lucide/pack.js" assets="...">: comma list, later wins (D51).
    • a root's packs are a child set, UI.icons.scope(packs, { assets, parent }), over the outer root's or the page's; parent is a function asked at each lookup, so a nested root follows the outer one's CURRENT packs (D52, D67)
    • each icon finds its nearest root through RootSettings (flat tree: slots, shadow hosts) and redraws when a root changes or the icon moves (D66)
    • ONE SVG cache and one set of registered icons per page, shared by every root
  • <ui-icon-set> is gone (P18, D58).
    • HTML uses <ui-root icons>; JS, UI.icons.use()
    • emoji names work the same way: <ui-root emoji>, EmojiData.use()
  • Single-file (IIFE) pages: the docs bundler, bundle-spell-ui.js, registers the icons it bundles, so nothing is fetched (reset(), then register()).
  • Design: icons.md.
