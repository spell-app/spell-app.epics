A sketch of what it would take for Spell to write Rust the way it writes Python today: a readable Rust project that prints the same lines as the JavaScript, starting with programs that draw nothing. Most of the compiler carries over; the hard part is that Spell's things freely point at each other, and Rust's rules on sharing make that its biggest design call.

Rust is all the rage these days. Sketch out what it would take to have Rust as an output target.
