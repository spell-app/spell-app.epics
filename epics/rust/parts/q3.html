Sometimes the compiler doesn't know a value's type: an event passed to a handler, or a parameter it can't trace. Python writes Any, and TypeScript writes any; Rust has no such word, so it needs a choice for those few values. 

def is_a_rank(self, rank: Any) -> bool:
    return self.rank == rank
  • Unknowns become a Value that can hold nothing, a number, text, a thing or a list. This is how Python's "said out loud" rule carries over.
  • Every program still compiles, and the count of Value shows how much the compiler still doesn't know, as Python's count of Any does.
  • Those spots read clumsily, with conversions on both sides.
  • All the Rust that comes out is clean and fully typed.
  • Solitaire and others are refused until the compiler knows more, or their authors write types. That work helps every target, but the wait could be long.
  • The runtime gets a Value type, and compiled programs use it only where the type is truly unknown.
  • The contract test can reach more programs sooner.
