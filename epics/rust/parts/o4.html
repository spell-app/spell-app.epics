Five pieces, in the order they'd come. The first keeps Rust from adding about seven more copies of target facts.

  1. Make room for a third runtime. Python's name is written into the command line, the run command, the compile check and the contract test. Those facts move onto each target's own entry.
  2. Find the tool, or say how to get it. The Python runs call uv with no check, and the one "is it installed?" helper is private to the code map. It becomes shared, for Python and Rust both.
  3. Move the type knowledge out of the TypeScript writer and into the shared base.
  4. The Rust writer, likely 2,000 lines or more, against Python's 1,829. That figure is a guess.
  5. The Rust runtime, grown one feature at a time, as the Wasm plan chose. Python's took 6,164 lines in the end. It would be called spell_core, as Python's is, because Rust already has a crate of its own named core. It holds the store of things, and depends on tokio.
