A program's compiled file ends with one type per event it handles: export type KeyDownEvent = SentEvent & { key: string } in TypeScript, a SpellEvent subclass or alias in Python.

  • The name comes from the event: key down is KeyDownEvent.
  • A name the browser already has gets SpellEvent instead, so drag is DragSpellEvent.
  • The handler carries its event explicitly, so Spanish programs work: PuntuaciónChangeEvent.
  • A handler's name settles what it holds, with no pile of unused declarations.
