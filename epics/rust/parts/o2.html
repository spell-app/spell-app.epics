About half the work is already done: a new target plugs into parts every target shares.

  • The writer's base. ProgramWriter and WriterProject are shared, and each target adds one method per kind of source tree node, about 67 for Python.
  • The list of targets. Rust is one more entry in TARGETS, with its code in a new folder beside Python's.
  • Waiting. The shared pass already says which functions wait, with nothing in the source. Rust writes async fn and .await from its answer, with no pass of its own.
  • The proof. The contract test runs each program with the same seed and compares every printed line with JavaScript's. A list of programs says which ones a target must pass, so Rust can start with one and grow.
  • Keeping the runtime in step. The shared list of runtime functions and its four files of expected results already check Python's runtime against JavaScript's.
  • Clear refusals. A writer already stops with an error naming what it can't write, and a program that draws is already refused on a target that can't draw.
