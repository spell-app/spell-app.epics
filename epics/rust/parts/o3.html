Four things Spell does freely are hard in Rust, the first by far the hardest.

Things that point at each other

  • A card knows its pile, and the pile knows its cards. Compiled programs freely read self.pile == solitaire.stock.
  • Rust wants each value to have one owner, so every other program would be fighting that rule.
  • How to share them is a question: Q2.

Types the compiler doesn't know

  • Python can say "any type" and run anyway. Solitaire's Python mentions Any on 23 of its 1133 lines.
  • Rust needs a type for everything, and some of what the compiler does know is locked inside the TypeScript writer.
  • So that knowledge moves to the shared base, which also helps every other target. What's still unknown is a question: Q3.

Waiting

  • Rust's standard library has no way to run code that waits, unlike Python's. So Python's rule of "standard library only" can't simply carry over: Q4.
  • Holding a shared value open across a wait crashes at run time, so this interacts with Q2.

Build time

  • Python runs at once; every Rust run is a compile first. The contract test allows 60 seconds a program, across 30 programs.
  • A shared build folder and a prebuilt runtime should help, but nobody has measured it. It's the first thing to measure.
