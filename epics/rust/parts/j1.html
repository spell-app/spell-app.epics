Python names one of a list of values as Rank = Literal["ace", 2, ...], written above the class, as TypeScript has export type Rank.

  • Python can't work a Literal out from the tuple, so it says the values twice.
  • A value Literal can't say (a fraction) stays Any.
  • Pyright can check is_a_rank("queen"), and a misspelled rank fails.
