Spell compiles to one language today, JavaScript for Solid; this epic makes the compiler's middle, the spell tree, say what a program MEANS instead of how JavaScript spells it, so a writer per language can turn the same tree into JavaScript, TypeScript, Python and more. Along the way it adds a tree diagrammer, so anyone can see that tree as a picture.
