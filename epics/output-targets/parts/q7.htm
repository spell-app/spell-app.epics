How does a project say which output(s) to compile to?

  • A project's settings live in its project.json today, e.g. packages/spell/projects/test/FizzBuzz/project.json lists its imports.
  • The app and VS Code run what they compile, so they always need js/solid, whatever else is chosen.

Net effect (A):

  • project.json gains an optional outputs list
  • spell compile gains --to <output> (the word follows Q1)
  • the editor and app keep compiling js/solid to run, and also write the others on save
ChoicesA · Both (recommended)
  • project.json: "outputs": ["js/solid", "ts/solid"], default ["js/solid"]
  • spell compile Solitaire --to ts/solid overrides it for one run
  • Files side by side: Solitaire.compiled.js, Solitaire.compiled.ts
B · Per run only
  • spell compile Solitaire --to ts/solid; nothing in project.json
  • Simplest; but a project that only makes sense as Python can't say so
Answer · Both: project.json lists targets (default js/solid), and a per-run flag overrides
