Two loosenings in @spell/core's types (T7), types only, to let compiled TypeScript check:

  • spellCore.drawThing(drawable?: unknown), was Drawable.
    • Its contract already says it returns null for anything that isn't drawable.
    • And compiled spell passes list items typed unknown.
    • Cleared 14 errors.
    • Cost: a caller loses the compile-time 'is this drawable?' check. One line to put back.
  • spellCore.RUNTIME typed SpellRuntimeState, was "| undefined".
    • Every runner calls resetRuntime() before a program runs:
      • the app's runCompiled.ts
      • the CLI's runProject.ts
      • the tests
    • Written undefined as unknown as SpellRuntimeState, with a note that it's unset before then.
    • Cleared 3 errors.
  • Solitaire's tsc errors 35 -> 10, with T7's other, stricter changes (List<T>, callbacks over T)
