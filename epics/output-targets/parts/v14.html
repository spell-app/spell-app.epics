In the editor (spell dev server, then the app), run the example Todos - Form Based. Then tick a task, edit a task's title, type a new task name and press Add Task, and press each button of the Test menu.

  • A violet menu runs across the top: "To Do:" on the left; "Show:", All, Active and Completed on the right, with All highlighted. Clicking Active or Completed moves the highlight. It never filtered the list, and still doesn't.
  • Three task rows, each a checkbox and a title field. "Create todos app" is ticked.
  • Under the form, its debug view shows the app as JSON. Ticking a task, or typing in a title, changes that JSON as you go.
  • Add Task is greyed out while the new task field is empty, and turns on once you type a name.
  • Add Task adds a fourth row, titled as typed, and empties the new task field.
  • The grey Test menu:
    • Add Item adds a row titled "Moar"
    • Remove Item removes the first row
    • Change name renames the first row "New title"
    • Remove Completed removes every ticked row
  • No errors on the program's console, and no "can't draw" stand-ins anywhere.
