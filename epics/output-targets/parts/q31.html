spellCore.element() writes prop:name for a live value or an object on a tag with a dash.

  • For example <ui-form value={the app}>: an attribute could only hold "[object Object]".
  • These stay attributes:
    • text, numbers and choices written as is
    • class, style, id, slot, part
    • handlers, and dashed names (aria-label)
  • Safe before an element is defined: solid-element keeps a property set before upgrade.
