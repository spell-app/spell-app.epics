Chose nested lists for the native fallback (what shows if drawing throws) over drawing the same SVG without Solid, and an always-present <svg class="ui tree diagram empty">, hidden, for "nothing to draw", over rendering no <svg> at all.

  • Lists: if drawing failed, the layout may be what threw, so drawing again could throw again. Lists need no layout, and a screen reader reads the whole tree from them.
  • empty: a real state class (ui tree diagram empty) that a stylesheet can see, and it lets the shared fallback test harness break the element. The host still has no height.
  • The tree's JSON can also go in a tree='{...}' attribute. That comes free with the property (Spell UI's json attribute kind); no extra attribute was added.
