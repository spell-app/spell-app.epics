spellCore.element() moved whole into deprecated.ts, marked @deprecated, with the helpers only it uses (React's spellings, prop: on a ui-* tag, the dotted-tag error).

  • Programs compiled before P20 still run: a browser runner test and a spell run test draw with it.
  • It's no longer part of the core contract (SpellCore leaves deprecated names out of what a new target's core needs), so Python's core won't need it.
  • drawing.ts keeps only the net, drawThing(), drawItems(), @drawn, mountApp() and the h it exports.
  • Old compiled programs keep drawing; new ones never call element()
