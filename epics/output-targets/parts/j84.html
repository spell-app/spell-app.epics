The TypeScript writer already extends the javascript one, so the shared code moved DOWN into JSWriter, rather than into a new base class.

  • JSWriter now holds what both writers say the same way:
    • kindOf(), and the value-kind helpers: givenKind(), definitionsKind(), propertyKind() ...
    • coreCall() / listCall() / typeTest() / eventCall()
    • comparison(), templateText(), loop()
    • nameOf()
    • module()'s imports, forProject()
  • TSWriter keeps only what's TypeScript's: 1970 lines down to about 1380.
    • types, interfaces and declare module
    • decorators
    • JSX and Solid's shapes
    • the type argument of on<{ card: Card }>(...)
    • !, where ?. can't go
    • its tidier parentheses
  • TSProject is renamed WriterProject, file too: both writers read it now.
    • TSGivenValue / TSWhere became GivenValue / ProgramPlace.
    • TSList and TSUndeclared keep their names, as they're TypeScript's.
  • The pure helpers both use are in a new jsShapes.ts, not in the barrel.
    • For example unwrapped(), isCoreCall(), kindFromDatatype() ...
