Spell objects round-trip through JSON, and a repeat takes its list from spell.

  • Every spell object's JSON says its class first, as "@type"; a list's adds its items, under "items".
  • spellCore.fromJSON() rebuilds each object as its class; there's no Thing.fromJSON() (J50).
  • <ui-repeat items={the shownTasks of the app}> takes a spell expression, set live as a property.
  • Todos - Form Based's debug box shows each task, its class's name first.
  • Its All, Active and Completed menu filters the list.
  • One helper, util's typedJSON(), writes the shape; "@type" is never a prop, so the Thing Explorer doesn't list it (J53).
  • An unknown "@type" comes back as a plain object, not an error; no snapshot changed.
