fromJSON() makes each object the way a program does, new Card({ rank, suit }), rather than poking values into a bare object.

  • Props with a setter go to the constructor, so create() sees them, as it does for new.
  • A prop with no setter (set by setProp() alone) is set after: it stays a prop, in keys() and the JSON.
  • A list's items are then SET, list.items = [...], through writeItems():
    • an exclusive list, e.g. a Pile, owns each card it reads back
    • what its create() added is replaced: the JSON is the truth
  • Each thing made is one of the program's, so it shows in the Thing Explorer.
  • The other way: skip the constructor (Object.create()), so create() never runs. Not taken: a hand-written class's fields would never be set.
  • A class whose create() deals cards gets the JSON's cards, not the dealt ones, plus a moment of dealing first.
  • Pile.ownerOf(card) is right for every card read back.
