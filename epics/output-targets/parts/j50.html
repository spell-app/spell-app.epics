JSON is read back through spellCore.fromJSON(json) alone: there is no Thing.fromJSON() or Card.fromJSON().

  • The class rebuilt comes from the JSON's "@type", never from who was asked.
    • Card.fromJSON(pileJSON) would answer a Pile, which reads wrong.
  • A static on Thing is inherited by every class a program declares: one more name on each, for the same job.
  • It takes JSON text, or what JSON.parse() already answered; a string is always read as JSON text.
  • The other way: static fromJSON() on Thing and List, checking the result is one of its class.
    • Easy to add later, if hand-written TypeScript wants it.
const json = JSON.stringify(board)
const copy = spellCore.fromJSON(json) as Board
copy.piles.firstItem!.firstItem!.pile === copy.piles.firstItem   // true:  the pile owns its card
  • spellCore.fromJSON() is the only way to read a spell object back; compiled programs and hand-written TypeScript both reach it through spellCore.
  • No named fromJSON export from @spell/core.
