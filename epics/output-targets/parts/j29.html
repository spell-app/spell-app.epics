A warning is spell's second kind of problem, beside parse errors: something the program should say, which doesn't stop it parsing, compiling or running.

Noting one: a rule notes a warning on its OWN match, while parsing.

  • The call: SP.SpellWarnings.note(match, message, at?).
  • It goes into match.data.warnings.
  • at is the match it shows under; by default, the noting match.

Finding them: NOT rolled up line by line, as parse errors are (data.errors).

  • SP.SpellWarnings.in(file.match) walks the file's matches as they are now: matched, plus the matches rules keep in data.
  • So incremental parsing needs nothing new: a kept line keeps its warnings, and a re-parsed one gets fresh ones.
  • The incremental test now checks warnings too, on every edit: they match a full parse.
  • Only warnings about the file's own tokens are kept.
    • A match parsed from a string (a quoted method signature) sits at the string's offsets.
    • So quoted_method_signature notes its parameters' warnings again, about the quoted text.

Showing them:

  • In editors: SpellLanguageService.diagnostics() returns parse errors, then warnings, marked as warnings (DiagnosticSeverity.Warning). So VS Code and the app's Monaco underline them in yellow.
  • spell compile lists them under its errors, and counts them in its note (8 warnings).
    • Each reads path:line:col warning: message.
    • Never as errors: the exit code, the project's state and the scope pack are as if they weren't there.
  • spell check prints only errors on stdout, as before; its note on stderr counts warnings too.
  • CLI.Problem gained severity?: "warning".
✓ @system:examples:Calculator  8 warnings
    .../Calculator.spell:10:1  warning:  Say what "input" is, e.g. "a calculator has an input as text"
    .../Calculator.spell:41:12  warning:  Say what "digit" is, e.g. "(digit as text)"
  • One generic shape for later warnings: a rule calls SP.SpellWarnings.note(), and editors and spell compile show it, with nothing more.
  • Files:
    • SpellWarnings.ts, new
    • SpellWarning, in spell.types.ts
    • SpellLanguageService.diagnostics(); CliSession.warnings() and report()
    • PARSING.md says how.
