First install the extension from main, after this epic merges: spell dev vscode (J5: it's built but not installed tonight). Then, in a .spell file (e.g. Card.spell/):

  • Right-click a line: "Show Tree for This Line" is in the menu; also in the command palette as "Spell: Show Tree for This Line"
  • The right side bar shows a "Spell Tree" view under Spell Docs, drawing that line's tree, its root box accented
  • Move the cursor to another line: the tree follows, a moment later
  • Type on the line: the tree updates without saving
  • A blank line: "Put the cursor on a line of spell to see its tree."
