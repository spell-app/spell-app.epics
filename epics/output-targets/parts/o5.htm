A first cut of the phases, so the questions have something to hang on. The real phases come after the answers; scope is Q3.

  1. JSWriter, zero diff. Every node's compile() and renderChildren() move into one JSWriter. The fixture snapshots (FizzBuzz, Solitaire) and every rule's tests must not change by a byte.
  2. Meaning, not JavaScript. The rows of 1.3: operators as meanings, plain values, spell names, Self and Nothing, declarations. Snapshots still unchanged: JSWriter now does the spelling.
  3. Tree diagrams. The diagrammer (1.4), drawing the cleaned-up tree.
  4. Outputs. The table of outputs, how a project picks one (Q7), and the "can it draw?" check.
  5. ts/solid. TSWriter extends JSWriter, adding type annotations from the datatypes; tsc is the judge of how good the types are.
  6. The core contract. spellCore's method list as the spec every core implements; test programs run on each output, their printed output compared.
  7. If in scope: py, a PyWriter and spell_core in Python.
  8. Doc Review.
