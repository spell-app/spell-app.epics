Q25 said to declare, for TypeScript only, a member used on a type that doesn't declare it. The rule built:

  • a value given when one is made (a new foundation with symbol = "♣️"):
    • declare symbol: string, on the class shared by every class it's given to
    • for example droppable on Pile, given to each kind of pile
  • a method two or more classes define, which the class they share doesn't: merged in after it.
    • export interface Pile { canPickUpCard(card: Card): ... }
    • A declare property would clash with the sub-classes' methods.
  • the shared class imported from another project: in a declare module block for it, as I1's fix does
    • Klondike gives Cards' Pile a name.
  • a method's return type isn't known there (spell keeps it in scope, not on the tree): a marker
