Owen answered P17's three open typing rules in modals before bed, 2026-10-10, so P17 runs tonight instead of waiting for a sitting:

  • A value whose type the program never says: infer it from what the program gives it (new Stock_Pile({ name: "stock" }) => name!: string); only when nothing says, any /* spell: type unknown */ and spell's warning, as now.
  • A member declared only on subclasses (droppable, canPlayCard() on Pile): still declared on the shared type for TypeScript, but typed from what the subclasses' definitions return: canPlayCard(card: Card): boolean. spell's warning stays.
  • J28's four rules kept: a slot named for a property takes its type; a getter says its type; an event's payload typed; a property over an inherited getter keeps a getter / setter pair.
  • The rest is settled by his sample-review notes: ?. not ! (Q38), === on known types, instanceof / typeof / isOfType(), typed list methods and event payloads.
