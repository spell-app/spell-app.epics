In the editor, run a scratch program that talks to the person:

notify "hi"
alert "hi"
confirm "ok?" with "yep" and "nope"
prompt "name?" with "Owen"
notify "done"
  • notify shows a Spell UI toast.
  • alert, confirm and prompt each show a Spell UI dialog, one after another, with the button labels and the default answer given.
  • The program waits for each answer before going on: the last toast, "done", shows only after the prompt is answered.
