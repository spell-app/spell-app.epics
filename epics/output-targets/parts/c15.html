The JavaScript writer wraps every value in a drawing that MIGHT change as a function, a "live value" (() => this.short_suit), so Solid updates that one node when it does. It can't yet tell a plain local variable from a property, so a local is wrapped too. 

className: () => className
  • Harmless: className is a let set once at the top of draw(); the function just returns it. Solid watches it, finds nothing to watch, and never updates it.
  • What's not wrapped: literals, elements, inline event handlers, and any on* prop.
  • P12 or P13 may skip locals that never change, once the writer knows which they are.
  • a few more small functions than needed in compiled JavaScript; no change in what the page shows
