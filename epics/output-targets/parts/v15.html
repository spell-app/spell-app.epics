Open Spell UI's form docs page, ui/components/ui-form.html (spell dev docs open ui/components/ui-form.html), and unfold Usage › Binding. Try its two live examples.

  • A form bound to an object (<ui-form value>): each named field shows its property, and typing or clicking writes it back. The form's debug view (<ui-form debug>) follows as you go.
  • A repeat (<ui-repeat name>): one row of fields per item of a list. Each row edits its own item.
  • The checkboxes and inputs look like every other Spell UI form, with even spacing between the rows.
