Every old name is kept in one place, so it is easy to see what is deprecated, and easy to delete later.

  • Chose one module of aliases, deprecatedMethods, over an alias beside each method in its own module, or a wrapper calling the new name.
  • Each alias IS the new function, not a copy: spellCore.itemOf === spellCore.positionOf, so the two can never drift apart.
  • They are typed on SpellCore, struck through in an editor as @deprecated, so old hand-written code still type-checks.
  • The core contract says they are not part of it: Python's core, later, needs only the new names.
