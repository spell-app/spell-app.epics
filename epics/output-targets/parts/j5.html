VS Code's line tree shows in a view of its own, "Spell Tree", in the right side bar UNDER "Spell Docs" (the same container), rather than as a page inside the Spell Docs view. Chose that because the tree must come from the language server's live parse (unsaved edits included), and the Spell Docs view only shows pages served by the page server, which can't see the editor's buffer.

  • The command: "Spell: Show Tree for This Line", in the command palette and the editor's right-click menu (Q15). It reveals the view, which then follows the cursor in spell files while it's visible.
  • The tree comes from a new language-server request, spell/lineTree (SpellLanguageService.ts).
  • It's drawn with the docs bundle (spell-ui.js), loaded into the view's webview: TreeView.ts.
  • The extension is BUILT, not installed: an installed extension runs the source of the checkout it was built in, so installing from this worktree would point every VS Code window at this branch. Install it from main after merging (spell dev vscode); the hand check is in To test.
