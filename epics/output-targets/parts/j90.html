How the javascript writer spells an element now (P20), as the before/after page showed it.

  • The tag, and a prop name that is not a plain name, are in double quotes: h("ui-form", { debug: true, "prop:value": () => app }), "aria-label": "Done". Before, such names were single-quoted.
  • Props: class first, then the rest as the program wrote them, as the TypeScript writer orders them.
  • Children: on the call's line when they fit (100 characters) and at most one of several is an element; else one a line.
  • The import: import { spellCore, Thing, List, App, h, positionOf, trigger } from "@spell/core", h first of the added names, only in a module that draws.
Compiled javascript reads like the hand-written after on the hyperscript-drawing page.
