Fix 7 of the untyped gap (1.7): an enumeration's values are written as a plain array, so its property's type is string (or string | number), not its values. 1.6 plans the same change for P10; this item says what it closes. 

// a joker has a color as either red or black
static Colors = ['red', 'black']
get color(): (typeof Joker.Colors)[number] { ... }          // string
// TS2416: Property 'color' in type 'Joker' is not assignable to the same property in base type 'Card'.
//   Type 'string' is not assignable to type '"black" | "red"'.   (a card's color getter returns 'red' or 'black')

static Colors = ['red', 'black'] as const                   // after
get color(): (typeof Joker.Colors)[number] { ... }          // 'red' | 'black'
