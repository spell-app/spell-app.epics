TypeScript compiled before P16 still runs: it calls the list's own method, and imports the helper by name, so both old names stay.

  • The plan named aliases on spellCore only; Q47 said every old name is kept. I took Q47's reading.
  • Compiled TypeScript writes a list's own method: startPile.itemOf(card) before, startPile.positionOf(card) now.
  • It imports the helper by name: import { itemOf } from "@spell/core" before, positionOf now.
  • So List.itemOf() calls positionOf(), marked deprecated.
  • And the barrel exports itemOf, the same function as positionOf.
  • A custom collection's duck-typed method is now positionOf() only: nothing but List had one.
  • List has positionOf(), and a deprecated itemOf()
  • @spell/core exports positionOf, and a deprecated itemOf
