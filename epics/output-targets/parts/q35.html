Owen, 2026-10-09, reviewing the ts/solid samples: which methods core's list gets, what they're called, and the rules they keep. It fills in Q33 (A: list methods, TypeScript only).

  • Each does exactly what its spellCore twin does.
  • Every position counts from 1.
  • A result that is a list owns nothing (scratch), so filtering piles never moves a card.
  • List is iterable: for (const card of pile).
  • The TypeScript writer uses them only where spell knows the value is a list; plain arrays and text keep spellCore.
  • Adding before or after an item that isn't in the list adds at the start (before) or the end (after).
    • In addBefore() / addAfter().
    • And in spell's add x to list before y.
