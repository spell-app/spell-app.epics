A writer finds its method for a node by the node's CLASS NAME: ASTIfStatement(node) writes an ASTIfStatement, and a node with no method of its own uses its nearest base class's (Writer.ts). Chose that over an explicit table or a kind on every node, even though WWOD says names aren't identifiers (§3).

  • Why it's safe enough here: rule names already ARE class names, so every build keeps class names (keepNames, pinned by build.test.ts).
  • A rename fails a test, not a project: JSWriter.test.ts checks every AST class finds a method.
  • Why not a kind per node: 76 classes each grow a @proto static kind = "If", and inheritance (a CoreMethodInvocation written as a ScopedMethodInvocation) needs the chain walk anyway.
  • writer methods are named for AST classes; renaming an AST class means renaming its writer methods too (the test says which)
