A tool that draws a spell program's tree as a picture: spell in, the REAL parsed tree out, as a themed SVG (light and dark). Built in P4.

  • Owen asked for it (2026-10-05), like "The tree for one line" in the sketch.
  • Why it earned a phase here: this epic rewrote the tree, and a picture is the quickest way to check, by eye, that a line's tree says what it means and nothing about JavaScript.
  • Each box is one tree node:
    • its kind: If, Divide
    • its key value: Number 15
    • its labels in spell's words: divided by, Print (J6)
    • its datatype, when known, as a muted second line: Divide · number (Q14)
  • Each line is labelled with the slot it fills, such as:
    • condition
    • body
    • otherwise
  • It comes in two halves (Q5), with plain data in between, because Spell UI may not import spell:
    • spell parse "<spell>" --tree (Q12) parses the spell and prints its tree.
      • --json gives it as plain data.
      • --html gives it as a page.
    • <ui-tree-diagram>, a Spell UI element, draws any such data as an SVG.
  • Where it shows (Q6):
    • docs pages: trees made from real spell, not drawn by hand
    • the app: "Spell Tree", the last pane of the editor's right column, draws the line the cursor is on, and follows it (it replaced the Match inspector, Q13)
    • VS Code: "Spell: Show Tree for This Line" opens a "Spell Tree" view under Spell Docs (Q15, J5)
  • The app's old ASTViewer (the compiled JavaScript as coloured text, the editor's "Javascript Output" pane) went in P1: that pane shows the compiled JavaScript in a read-only Monaco now.
