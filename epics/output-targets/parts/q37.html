Owen, 2026-10-09: the shape of an event in the TypeScript. It fills in Q34 (B: core's on() / trigger(), in JavaScript too).

  • Core exports on(), off(), once() and trigger().
    • Each finds the CURRENT runtime when it's called: a new one is made each time a program starts.
  • TypeScript imports them, like prop.
  • The payload's type is a type argument, and the handler takes it apart in its parameter.
  • JavaScript calls them on spellCore; its snapshots change once.
const click = () => trigger("card-click", { card: this })
on<{ card: Card }>("card-click", ({ card }) => card.play())
  • built in P14
  • the JavaScript reads spellCore.on(...) / spellCore.trigger(...)
