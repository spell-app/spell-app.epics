Block (block), ParseError (parse_error), ArithmeticExpression, If, Else and Await no longer set static ruleName: P.Rule.ruleNameFor() gives the same name. Kept on BlockLine (line), AssignmentStatement (assignment), CompoundExpression (expression), UndefinedLiteral (undefined) and the seven fuller names.

  • A ruleName in the rules now always means "the class name doesn't give it".
