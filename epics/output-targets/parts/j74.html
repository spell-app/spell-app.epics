Six rule classes no longer set static ruleName: P.Rule.ruleNameFor() gives the same name.

  • Block (block), ParseError (parse_error)
  • ArithmeticExpression
  • If, Else, Await

Kept, where the class name doesn't give it:

  • BlockLine (line)
  • AssignmentStatement (assignment)
  • CompoundExpression (expression)
  • UndefinedLiteral (undefined)
  • the seven fuller names (J72)
  • A ruleName in the rules now always means "the class name doesn't give it".
