Owen asked for it (2026-10-05): a tool that draws a spell program's tree as a picture, like "The tree for one line" in the sketch. Spell in, the REAL parsed tree out, drawn as a themed SVG (light and dark).

  • Why it earns a phase here: this epic rewrites the tree, and a picture is the quickest way to check, by eye, that a line's tree says what it means and nothing about JavaScript.
  • Each box is one tree node: its kind (If, Divide), and its key value (Number 15).
  • Each line is labelled with the slot it fills: condition, body, otherwise.
  • Datatypes can show on hover, or as a second line: Divide · number.
  • Its shape (Q5): two halves.
    • spell dev tree "<spell>" parses the spell and gives the tree as plain data (JSON).
    • <ui-tree-diagram>, a Spell UI element, draws any such data as an SVG. It lives in ui, which may not import spell: hence plain data in between.
  • Where it shows (Q6):
    • docs pages: trees made from real spell, not drawn by hand
    • the app: a pane drawing the tree of the line the cursor is on, updating as it moves
    • VS Code: a "Show tree for this line" command, opening it in the side bar
  • The app's old ASTViewer (the compiled JavaScript as coloured text) goes in P1: it was already unused, since the app shows compiled JavaScript in a read-only Monaco.
  • Built in P4, right after the tree stops speaking JavaScript, so it draws the cleaned-up tree.
