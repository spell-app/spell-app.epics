Rebuild and install the extension with spell dev vscode, from a branch level with main. Open Solitaire in VS Code, use "Spell: Run Project", and click a few cards.

  • Solitaire runs, and its cards click.
  • The rebuilt runner's spell-runtime.js exports trigger, on and positionOf, which compiled javascript now imports by name.
  • Before the rebuild, a freshly compiled program would fail to link (C27).
