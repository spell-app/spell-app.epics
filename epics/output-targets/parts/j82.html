• What: the text fill-in helpers now live at the bottom of TextLiteral.ts, after the text rule.
    • FillInParts, parseFillIns(), fillInsAST()
    • They handle fill-ins like "images/[rank].png".
  • Why: inside core, only the text rule uses them, and the layout says what one rule alone uses stays in its file.
  • Over: a core.shared.ts.
    • The JSX rules (jsxAttribute, jsxText) use them too.
    • But they import the module ($/spell/rules/core), so they don't care which file holds them.
  • Easy to move to a shared file later, if a second core rule needs them.
