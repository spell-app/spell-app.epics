Q44 says a method keeps its receiver's type name where dropping it leaves a little word dangling. Which words count was left to me.

  • The list: of, to, from, in, into, on, onto, at, by, for, with, without, before, after, about, under, through, between, within, upon, against, toward, towards.
  • Left out on purpose: a verb's own little words (up, over, out, off, down). to pick up (a card) stays pick_up, so it reads card.pickUp(), not card.pickUpCard().
  • The kept word is the type's plain name, with no dollar sign: update_the_total_of_calculator, append_$digit_to_calculator, set_the_operator_of_calculator_to_$op.
  • No fixture has a method like this, so no fixture's output changed. Only the Calculator example's names change.

The list is DANGLING_WORDS in methods.ts. Add a word there if one reads wrong.
