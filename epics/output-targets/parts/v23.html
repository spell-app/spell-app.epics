Since P19, compiled javascript imports a few helpers by name, so the <spell-app> web component needs its runtime rebuilt before it can run a freshly compiled program (the caveat about rebuilding the runners, C27).

  • In the app package, rebuild the element bundles: yarn build:element.
  • On this checkout's dev server, open the demo page, /demo/spell-app.html.
  • Play a few moves of the program it runs.
  • The program draws and plays; clicks work.
  • No "not exported" or linking error on the console.
  • The Network panel shows ONE Solid: the runtime brings none of its own.
