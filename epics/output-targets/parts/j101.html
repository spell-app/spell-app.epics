• J85 asked for javascript to be formatted as TypeScript is. TypeScript's docstring counts "one class body per type" as part of that, so javascript does it too.
  • Only for a class this project declares. A member added to an imported class stays a patch: Card.prototype.play = ....
  • E.g. a card belongs to one pile set in Pile.spell: pile now sits inside class Card. 
// before:  after the class, in another file
Card.declareProp('pile', { type: 'Pile' })
Object.defineProperty(Card.prototype, 'pile', {...})
// after:  in class Card
static { this.declareProp("pile", { type: "Pile" }) }
get pile() { return this.getProp("pile") }
Each class reads as one block in javascript too.
