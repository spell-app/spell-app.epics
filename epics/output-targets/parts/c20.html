Built Solid TypeScript hears clicks only once its module has finished loading: Solid's compiler puts delegateEvents(["click"]) at the END of the module.

  • A program's own top-level code that clicks something (a test, a "start" that clicks) runs before that line: the click goes unheard.
  • A person's clicks always come later, so a real app is fine.
  • JavaScript output (@solidjs/h) binds handlers on each element, so it never had this.
  • Seen in the CLI's runCommand.test.ts, which clicks inside a setTimeout().
