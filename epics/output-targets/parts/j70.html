PascalCase makes the _if trick unnecessary: class If is legal, and its rule name works out to "if".

  • static ruleName stays only where the class name doesn't give the name:
    • BlockLine is "line"
    • SpellJSXText is "jsxText"
  • Also where the PascalCase name would hide a javascript or DOM name inside its file.
    • The rules number, boolean, text and comment get a fuller class name, keeping their rule names.
    • For example NumberLiteral.
    • Same for keyword, which would read as the parser's own Keyword.
  • _if, _else and _await become If, Else and Await, with no ruleName.
