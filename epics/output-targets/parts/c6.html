A member patched onto a class from ANOTHER project can't be typed the way one from the same project is.

  • export interface Card { pile: Pile } merges only with a Card class in the same file.
  • When Card is imported from another project, TypeScript reports the interface as clashing with the import.
  • The fix is a declare module block naming that project's module.
  • No fixture does this yet, so nothing shows it.
