Built generically in spell-ui's form family (any object, nothing spell-specific):

  • <ui-form value>, a json property, never reflected: each named control shows its property and writes it back, live both ways.
    • FormBinding does it: a Solid effect per control.
    • It writes a microtask after input / change / ui-change, never when the value is === the old one.
  • <ui-repeat name>: its children once per item of scope[name], any iterable.
    • Rows are kept by identity, in the light DOM.
    • The scope is the item of the row around it, else the form's value.
    • Named after the everyday word for Angular / Vue form arrays, a repeater: short, and the tag says what it does.
  • <ui-form debug>: a <pre part=debug> of the bound object as JSON (its toJSON()), else its values.
