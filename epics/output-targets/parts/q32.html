Built generically in packages/ui's form family (any object, nothing spell-specific):

  • <ui-form value> (a json property, never reflected): each named control shows its property and writes it back, live both ways (FormBinding: a Solid effect per control; writes a microtask after input / change / ui-change, never when ===).
  • <ui-repeat name>: its children once per item of scope[name] (any iterable), rows kept by identity, in the light DOM; scope = the item of the row around it, else the form's value. Named after Angular / Vue form arrays' everyday word, a repeater: short, and the tag says what it does.
  • <ui-form debug>: <pre part=debug> of the bound object as JSON (its toJSON()), else values.
