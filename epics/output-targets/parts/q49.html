Owen, 2026-10-10, on I8: a list's JSON holds its own properties as well as its items, and every spell object says its type, so it can be read back as that type.

  • The key is "@type", JSON-LD's spelling: no spell property can be named @..., so it never collides, where "type" would.
  • Others seen: GraphQL __typename, MongoDB _t, kotlinx type; no single standard.
  • spellCore.fromJSON() rebuilds each object from its @type, finding the class by name among the program's. 
{ "@type": "Pile", "name": "stock", "items": [{ "@type": "Card", "rank": "ace", "suit": "clubs", "direction": "down" }] }
