Chose to centre each slot label ON its line, at the line's midpoint, with the line broken where it would run under the text, over the sketch's look (the label beside the line). Why: centred labels can be spaced so that no slot label ever overlaps another label or another line, and the layout tests prove it on random trees; labels beside the line can still collide when siblings are close. The break needs no background colour, so it looks right on any surface.

  • Chosen: centred on the midpoint, line broken under it. Each node keeps twice its label's width clear in its row, so labels never collide. Cost: trees with long slot names get wider.
