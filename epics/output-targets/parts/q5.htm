What shape does the tree diagrammer take (1.4)? It has two halves: turning a parse into tree DATA, and DRAWING that data as an SVG.

  • @spell-app/ui may not import spell (root AGENTS.md): a drawing element in ui has to take plain data, which spell supplies.
  • Docs pages must still open from disk (file://), with no server: a LIVE element there only works on data already in the page.
  • The data, for one node: { kind: "Divide", label: "", datatype: "number", slot: "value", children: [...] }

Net effect (A):

  • a new ui element, <ui-tree-diagram>, with its own Spell UI docs page
  • a new spell dev tree command (commands.json kept true)
  • where it shows: Q6
ChoicesA · An element + a command (recommended)
  • <ui-tree-diagram> in ui: draws any tree from JSON, themed, light and dark.
  • spell dev tree "<spell>": parses, prints the JSON (or writes it into a page).
  • Works in docs pages (JSON in the page), the app and Spell UI's docs.
  • Reusable for other trees (the parse of a rulex rule, a goal set).
B · A command that writes SVG
  • spell dev tree "<spell>" --svg: prints a finished SVG to paste into a page.
  • Simplest; nothing new in ui.
  • Static: no hover, no folding; the app's AST viewer can't use it live.
Answer · A ui element, <ui-tree-diagram>, plus a spell dev tree command
