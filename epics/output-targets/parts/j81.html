Spell's AGENTS.md ("Rule module layout") gives VARIABLE_SYNTAX as its example of a constant at the top of a RULE file. But two rule files read it, so it went into the shared file.

  • The two: Variable.ts and KnownVariable.ts.
  • It's in variables.shared.ts, next to IdentifierMatchData (used by SpellIdentifier and Variable).
  • The other option: keep it in Variable.ts, and have KnownVariable.ts import it from there.
    • That import exists anyway, because Variable is its base class.
  • If you'd rather keep the guide's example true, it's a two-line move.
    • Or the guide's example could switch to a constant only one rule reads, e.g. LOWER_INITIAL_WORD in Property.ts.
