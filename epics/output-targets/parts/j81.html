Spell's AGENTS.md ("Rule module layout") gives VARIABLE_SYNTAX as its example of a constant that sits at the top of a RULE file. But two rule files read it, Variable.ts and KnownVariable.ts, so it went into variables/variables.shared.ts, next to IdentifierMatchData (used by SpellIdentifier and Variable).

  • The other option: keep it in Variable.ts, and have KnownVariable.ts import it from there. That import exists anyway, because Variable is its base class.
  • If you'd rather keep the guide's example true, it's a two-line move. Or the guide's example could switch to a constant only one rule reads, e.g. LOWER_INITIAL_WORD in properties/Property.ts.
