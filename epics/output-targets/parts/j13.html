What the TypeScript writer (P.TSWriter) types, and what it marks as unknown.

What it types:

  • every parameter
  • every reactive property, from its check: 
    { type: 'number' }      =>  number
{ oneOf: Card.Suits }   =>  (typeof Card.Suits)[number]
  • a new variable, when spell knows its datatype: let count: number = 0

Where spell doesn't know:

  • A parameter gets any /* spell: type unknown */ (Q16), since TypeScript needs one.
  • A new variable set from a spellCore call (which returns unknown) gets the marker too, or as Card when spell knows.
  • Any OTHER new variable spell can't type is left bare, so TypeScript works it out: let game = new Game().
    • Writing any there would throw away a type TypeScript already has.
  • Solitaire has 56 markers; FizzBuzz 1.

Lists are any /* spell: list */:

  • @spell/core's List doesn't say what it holds.
  • And spell sets properties on lists (the name of the cards), which a List can't have.

Members added from outside:

  • A member patched onto its class from outside (Card.prototype.pile) gets an interface before it, which TypeScript merges with the class: export interface Card { pile: Pile }.
  • Functions written outside their class take this: Card.
