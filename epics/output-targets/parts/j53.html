Only spell objects, Thing and List and what extends them, write "@type"; Observable.toJSON() stays its props alone.

  • The shape is one helper in $/util's records, typedJSON(target), beside getProps(), with the key as a constant, TYPE_KEY.
  • Why not every Observable: tasks, files and the editor's store are Observables too, and their JSON isn't spell's to change.
  • "@type" is the CLASS's name, even when an instance says another type: the class is what fromJSON() rebuilds.
  • "@type" and "items" are never props: keys(), and so the Thing Explorer, never lists them. 
{
  "@type": "Todos_App",
  "tasks": {
    "@type": "Task_List",
    "items": [{ "@type": "Task", "title": "Create todos app", "completed": true }, ...]
  },
  "filter": "all",
  "newTaskName": ""
}
  • Every spell object's JSON starts with its class's name; every other Observable's JSON is unchanged.
  • The core contract snapshots did NOT change: print shows a thing through node's inspect, never its JSON.
