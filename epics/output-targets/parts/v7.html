In a scratch user project, add "targets": ["js/solid", "ts/solid"] to its project.json. Then run spell compile <project>, or save a file in the app.

  • <Project>.compiled.ts should appear beside the compiled javascript and the declarations file.
  • The app still runs the project: it runs the JS.
