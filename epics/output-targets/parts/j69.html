The layout every module will follow, shown on events (written down in spell's AGENTS.md, "Parser rules").

  • events.parser.ts: the module's parser alone, so each rule file can import it without importing its siblings.
  • Trigger.ts, On.ts: one rule class each, exported, its registration right below it. The class docstring starts with the rule name, so a search for {on} still finds the class.
  • <module>.shared.ts, when a module has any: what several of its rules share. Chose .shared over WWOD's .types because rule helpers build AST nodes, values a types file mustn't import.
  • index.ts: export * from each file, in the old registration order, which is what breaks a tie between rules.
  • events.ts is now the events/ folder; everything that imported it still does.
  • The other 17 modules follow the same recipe.
