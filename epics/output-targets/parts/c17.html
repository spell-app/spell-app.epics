A repeat's rows have no wrapper element, so the form's spacing stays right; a moved row keeps focus only in Chromium.

  • The form's rows of fields drop their bottom margin by being the last child (:host(:last-child), after Fomantic's .field:last-child).
  • A wrapper per row would make every row's last field :last-child, packing the rows tight.

So instead:

  • Each row is its copied nodes, straight in the repeat.
  • Its top-level elements are registered as holding the item (FormBinding.hold()).
  • The template is kept as a <template>, the LAST child, so no row is ever :last-child.
  • Moves use moveBefore() where the browser has it (Chromium does), so a moved row keeps focus. Elsewhere, a moved row's focus is lost.
