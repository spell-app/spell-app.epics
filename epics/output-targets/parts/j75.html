In the classes split, DefinePropertyHas.getLongForm() checks specifier.is(OutlineSpecifierEnum), but outline_specifier_enum registers AFTER define_property_has.

  • Importing ./OutlineSpecifierEnum would load (and register) it first: the _testable_ order in ruleNames.test.ts's snapshot changes.
  • Chose: import { OutlineSpecifierEnum } from "$/spell/rules/classes", the folder's own index.ts. A cycle, but the class is read only when getLongForm() runs, long after the folder loaded; a comment above the import says why.
  • Over: swapping the check to is(TypeSpecifierEnum) (registered earlier, so a plain import): the same for every real input, but not for a nonsense one, e.g. its have a x as one of a, b, so a behaviour change in principle.
  • Breaks only if something imports classes/DefinePropertyHas.ts directly before the folder: nothing does.
