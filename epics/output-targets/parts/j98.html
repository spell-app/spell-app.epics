• In it: every method, getter and stored property of each of the project's types, by the name the javascript writer gives it (nameOf()): Card: { moveToPile: "move (a card) to (a pile)", shortRank: "short rank" }.
  • Left out: top-level functions (deal the cards) and class variables (Ranks): the Thing Explorer shows neither. Adding them later is a new key beside types, e.g. functions.
  • Fallback, no words file or no entry: an action by its split name (move to pile), a property by its name as is (isSetUp), as today.
  • A type's inherited member is found in the type it comes from: a foundation's draw is draw (a foundation), a joker's inherited turnOver is Card's words.
  • One file per project per language, keyed by the code's own names: a Spanish file is the same shape.
