Page layouts

How a site says what stays on screen around its pages (menu, drawer, side bars, footer), so many pages look the same and nothing flashes when you go between them. A proposal for T39; nothing is built yet.

session mockup-layouts, a helper of epic mockup, while writing up your page-layout idea (T39) 2026-11-16
mockup: Spell sites as click-through mockups, and then the real thingYou suggested page layouts, as Svelte has, instead of every page including its own top bar (T39). This page is that idea worked out in Spell.How a layout is written, how a page picks one, what moves into it (the top bar, the tabs), and the new Spell UI elements and attributes.

What a page layout is, in one breath:

  • A view that draws what stays on screen around a site's pages: its menu, its drawer (the side navigation), two side bars and a footer.
  • The site draws it ONCE, and puts the page inside it.
  • Going to another page with the same layout redraws only the page: the menu, the drawer, the side bars and the footer stay as they are, the same elements, so nothing flashes.
  • The site draws one frame by itself: the side navigation, a top bar when its file says it has a top bar, and the page.
  • The frame is drawn once already, and only the page part redraws, so the navigation doesn't flash today.
  • What's missing:
    • a site can't say what goes in the frame, beyond the top bar's end buttons (the top bar view)
    • no side bars or footer, no second frame for some pages (only , no top bar)
    • the tabs moved into the pages yesterday (<site-tabs />), so every page change makes them again
    • T39 as first written put <top-bar /> in every page too: the menu would be made again on every page, the flash you want to avoid

A layout is a view of a new built-in kind, page layout, with five slots, each drawn by its own to draw its ....

  • The slots: page menu, drawer, left sidebar, right sidebar, footer.
  • The page goes in the middle by itself: a layout never says where.
  • A slot it doesn't draw is empty, and takes no room; except the drawer, which holds the site's navigation unless the layout says otherwise.

  • Two pages that share a layout: going between them redraws only the page. The menu, the drawer's open folders, the side bars, the footer, and anything typed in them stay.
  • Two pages with different layouts: the new layout draws, the old one is kept (not thrown away), so going back shows it as you left it.
  • The not found and error pages show in the default layout, so the navigation stays and you can get out.
  • A test pins it: the menu's element is the same object before and after a page change.

A layout draws five regions around the page. Each region can be its own drawing, or the whole layout one drawing with the regions marked in it.

to draw its page menu, to draw its drawer ...: Spell's slots, as a two sided card's.

  • The page can't be left out by mistake: the site puts it in the middle.
  • One layout can build on another and draw one slot again (wide layout is a main layout), which replaces nested layouts.
