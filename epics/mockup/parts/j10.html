Owen's comment on P10 asked for a generic resizable on most Spell UI elements. It's built once on the element base in P10, first used by three components (diagram node, card, segment), rather than per component; other components take it as they need it.

`<ui-diagram>`, boxes in columns and the links between them, the NERD skill's drawing: its script's layout and routing ported whole to a pure `DiagramLayout` (the same numbers as the script on two made-up specs, within 0.2; groups with lanes, coloured headers, solid `contains` / dashed `ref` lines, a legend of the kinds used, brackets, buses, loops, curves, merged arrowheads); the spec is the skill's own JSON, or a flat `{ nodes, edges }` put in at most `columns` columns (3 by default, `DiagramColumns`); drag a box and its lines follow (`Dragging`), `remember` keeps where (`PrefStore`), Put back, `fixed`; `downloadable` / `toSVG()` / `saveSVG()` write the script's file (`DiagramSVG`); `<ui-diagram-node name [resizable]>` fills a box with what it holds, a `<ui-shape>` that flips, the box and its lines following its size; measured in its real font through `TreeMeasure`, now shared (`widthOf()`, `fontOf()`); ink colours on theme tokens; English and Spanish, docs page, examples; the components README regenerated (it was stale since P3)
