A page's jobs are written in one block, named for each form of Spell; the plan said <jobs>.

  • Code Spell: <jobs>, as written.
  • spellx: <spell-jobs> (Spanish <encanto-tareas>), since spellx's notes all carry its prefix. Its twin is Code Spell's block.
  • Both compile to the page's static jobs, a markdown list.
  • In the list, - [x] marks a job done; the lines under it are its checks.
