Owen asked for ticks when the row's menu has them or an item inside can be ticked. An item that's off writes nothing, so nothing says it CAN be ticked; ticking only while one is on would make File ›'s gutter come and go.

So the rule is: an item with selected or active written, true or false (UIItem.saysOnOrOff). The editor's menu rows write selected="false" while off (Action's onOrOff()); Spell UI's JSX types allow "false" only on flags that are on by default, so it's cast there.

  • View › and File › tick in the ☰ menu, their gutter steady
  • A plain fly-out (Edit ›, Run ›) has no gutter
