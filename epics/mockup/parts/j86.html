For P20 · Saved Draft Edits: how the running app shows your draft.

What's there today:

  • The program the editor runs is compiled in the browser, from the files it loaded, and the file route already hands it your drafts. So inside the editor, your draft does run.
  • But that compile then SAVES what it built into the project's one shared build. Everyone opening the app (/apps/...) runs your unpublished draft, until the build is redone from the files on disk, when your draft's program is gone, even for you.
  • The server's own builder, ProjectBuild, compiles only from the files on disk: it never sees a draft.

The call:

  • While you have drafts of a project, what the editor's compile builds is saved as YOUR build, beside your drafts; the file route serves it to you first, and the shared build to everyone else.
  • Publish and Discard drop your build with your last draft; the shared build is redone from the published files.

Rejected: the server compiling a per-person copy (the files with your drafts laid over them, in a temporary folder). It would teach the spell command about drafts and compile every drafted project twice, for a program the editor has already built.

  • A draft runs for you, in the editor and on the app's own page, and for nobody else until you publish.
  • The shared build only ever holds what's published.
