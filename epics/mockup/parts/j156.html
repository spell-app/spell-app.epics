The corner button on every sitemap card (pages, dialogs, sidebars, sections) is a pencil, "Edit {name}" / "Editar {name}", doing what a double click does: the page's own file in Edit, in the same tab, or the site file at its line (a page with no file yet gets one made, as a double click does).

The old new-tab link opened a page's live address when its line had one; that address is still a field of the page's form (Live link), but nothing on the board opens it any more.

To visit a page's real, live page, copy it from the form's Live link field; the card no longer opens it.
