The docs nav's folds don't ease while a search is typed, as before; they ease shut when it's cleared.

  • The old docs nav drew a topic's rows only while open, so a search's folds never eased either way, while a person's click did.
  • The tree's folds ease whenever a row opens or closes, so <ui-docs-nav> sets the durations to 0 while a search is typed.
  • Clearing the search is the moment the state goes away, so the topics it opened ease shut.
  • Telling a person's toggle from a page's change in the tree would add a state just for this.
