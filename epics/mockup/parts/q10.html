Owen wants to edit a collection's rows the way a spreadsheet does, a whole table at once, not one row picked at a time in the Inspector. Nothing in Spell UI does that yet:

  • <ui-table> draws rows as plain text (from a native table, or its rows list); it sorts and selects rows, but has no editing, and draws every row (no scrolling window for long tables)
  • the Inspector edits one value at a time, saved to the place (one undo step per change, ⌘Z works); the table should save the same way

What spreadsheet editing means here:

  • click or arrow to a cell, type to replace it, Enter or Tab to move on, Escape to undo the cell
  • each cell edited by its field's type: text, number, date, yes / no, a LINK as a dropdown of the rows it can point at (an analysis's project)
  • add and delete rows; paste a block of cells from Excel or Google Sheets
  • each change written to the place the table shows (the sample now, the live API later), undoable
  • one table component; editable turns on the cell cursor and editing
  • the table also learns to show a place's collection itself, with columns from its fields, so a page says <ui-table editable> over runs and gets typed editors
  • the keyboard follows the accessible "grid" pattern, so screen readers announce cells
  • a separate spreadsheet component, free to grow formulas and frozen columns later
  • two components that both draw rows and columns, and one more to learn
  • <ui-table> gains editable, typed cell editors, and reading rows from a place
  • the same table edits sample rows in the site editor and, later, live rows on the real site
