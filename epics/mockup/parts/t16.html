In plain Spell (not the tag form), a page's <jobs> block directly followed on the next line by a <markdown> block is read as ONE block, and the line shows "Don't understand". A blank line between them fixes it. 

<jobs>- [ ] see a film's people</jobs>
<markdown>The film page.</markdown>      // error:  read as one block

<jobs>- [ ] see a film's people</jobs>

<markdown>The film page.</markdown>      // fine
  • Only when typing by hand: the site editor puts the blank line in itself.
  • The tag form (.spellml) isn't affected.
  • Why: the reader joins tags on lines next to each other into one piece, and no rule reads two blocks as one piece.

Two raw-text blocks on lines next to each other are read as ONE fragment (the tokenizer joins elements on consecutive lines), which no outline rule takes: Don't understand "<jobs>...". A blank line between them keeps them apart, and the site editor writes the jobs first with the other lines after, so it only bites when written by hand. Spellx is fine: its description is comments.
