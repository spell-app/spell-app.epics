• Hover opens a fly-out at once, as Mac menus and the editor's bar menus do; SubMenuAim keeps it open while the pointer heads for it. The 0.8s page hover delay is for popups and tooltips.
  • Mouse only: a touch taps the row.
  • → opens it (← in a right-to-left page); in a menu whose items run sideways, ↓, as the ARIA menubar pattern says, so → still moves along the bar. The fly-out still opens beside the row.
  • No aria-controls on the row: optional in the pattern, and an id can't reach a named menu across the row's shadow root.
  • Submenus feel like a desktop app's.
