The language can now close a dialog or a sidebar, so saving a review closes its dialog.

  • Before, nothing could: a button inside a view can't reach the dialog around it by id (Spell UI's invoker commands look in the button's own tree).
  • So show_site_part takes close the ... too (cerrar el ... in Spanish).
  • It compiles to core.closeSitePart(), and names only a dialog or a sidebar.
  • Every dialog and sidebar also has its close icon now.
