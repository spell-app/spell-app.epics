Everyone's: the order stays in homeOrder.json, and the words changed (titles, taglines, section headers and lines) go in a new file beside it, homeTexts.json: never into the projects' own files, so an example's name and description stay as written and only the home page shows the change. Whose a change is, the server decides: someone of @spell (signed in, else this machine's person), in Spell's own checkout, changes everyone's; anyone else, or anyone in an app that installs Spell, changes their own, kept in their space's preferences (spell-home), laid over everyone's, with Reset to Default. With no server (the static preview) or one that refuses it (the house-network site, which already refused the old drag), the changes are kept on that device. The order of your own apps is always your own, @spell's people's too: nobody else has them.
