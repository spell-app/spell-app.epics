In Chrome, open test.spell.app (the main editor, which has all of this epic).

  1. From Home, open a project of your own with three or more files (or make one: Home › New Project, then File › New Spell File twice).
  2. Drag the last file tab left, and drop it before the first one.
  3. Reload the page (⌘R).
  1. While you drag, the tabs make room where it will land.
  2. On the drop the tab stays where you put it.
  3. After the reload the tabs are still in the new order.
