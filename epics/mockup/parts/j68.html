• A session is named once with spell place sign-in, and --signed-in uses it on ingest, read-page and site screenshots.
  • Only cookies go on API requests. A site whose API wants a token kept in the page's storage would need more: the sign-in keeps that storage, and takes it out of what is written, but no request sends it.
  • A redirect to another host or a sign-in path counts as the session having ended, so an API that really redirects elsewhere would be misread.
  • A row off a list is its text alone; a table is by its headings.
