The site editor is its own page in the editor app, /site/<project> (View › Site): Pages (a tree, a board of cards in section rows, a form, stories) and Data (the NERD / ERD). Each card shows its page's picture or thumbnail (T12, P13, P16), and a double click opens its page's file, making it first if there's none (P17).

The site editor is where Owen works on the sitemap and its pages.

  • The site view: every page, as a tree (the side navigation's order) and as a board of cards, each with its screenshot or mockup:
    • add, delete, rename a page; drag it to another place
    • edit its address and parameters
    • the NERD / ERD diagram, a tab beside it
  • Diving into a page: its jobs, then its mockup, edited in the Spell editor as any project file is (the Palette, the Inspector, moving parts about)
  • Run shows the site itself, its navigation working, at the page's address

It is its own page in the editor app, like the theme editor: its own address (/site/<project>), so the editor itself is untouched. Opening a page from it goes to that page in Edit; a link back returns to the site view.
