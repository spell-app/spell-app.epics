A MOCKUP theme: wobbly ink borders, a handwriting font, greys.

It's a theme like any other, so switching a mockup to a real theme later changes its look and nothing else.

  1. Start from Pop, the theme with ink outlines, and make mockup.theme.json5: greys, a white page, ink-black lines, one accent grey for selected things.
  2. The font: a free handwriting font with a licence that lets Spell ship it (e.g. Patrick Hand or Architects Daughter, both OFL), as one woff2 file served beside the theme, so it works offline.
  3. The wobble: the theme's own rules sheet draws borders as slightly uneven lines (an SVG filter that roughens edges, kept light so text stays sharp), on cards, buttons, inputs, tables and modals.
  4. Focus rings and selected states stay clear: checked against the contrast rules every theme passes.
  5. It joins the theme list, so every theme menu, the theme bench and the theme editor show it.
  6. Checked by: the themes' tests; the theme bench screenshotted light and dark with /designer.
  7. Left out: a dark mockup that differs from the light one beyond the inverted greys.
