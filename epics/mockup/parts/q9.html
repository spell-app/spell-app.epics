The NERD and ERD need boxes joined by lines in any shape: a run links to its analysis, an analysis to many runs, two collections to each other. <ui-tree-diagram> can only draw a TREE: each box has one parent, and its layout places children under their parent. So the NERD needs a new component. "Graph" is out: it reads as a bar graph.

  • it shares the tree diagram's box measuring and line drawing, so there is one way to draw a box and a line
  • it lays boxes out in columns, and lets people drag them, remembering where
  • any box can be a <ui-shape>, so it flips to show its other side (NERD to ERD)
  • "diagram" is already Spell UI's word for this, through the tree diagram
  • later, the tree diagram can become a layout of it
  • says boxes and lines plainly; a new word
  • the maths word, but people may read it as computer networking
  • a new Spell UI component, <ui-diagram>, with <ui-diagram-node> boxes and links between them by id
  • the NERD and ERD are built on it
