For a spec with no columns (what P11's NERD may hand it), the boxes nothing links to go in the first column, each other box one column right of the furthest box linking to it; links that close a loop don't push a box right; past columns (3 by default) they stack in the last. The NERD skill's own column rules (reusable things left, definitions middle, runs right) need to know what each box IS: that's P11's, which can write columns itself.
