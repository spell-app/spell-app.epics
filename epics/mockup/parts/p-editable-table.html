Rows are edited one value at a time in the Inspector; nothing edits a whole table the way a spreadsheet does.

  • Click or arrow to a cell, type to replace it, Enter or Tab to move on, Escape to put it back.
  • Each cell is edited by its field's type: text, number, date, yes / no, and a link as a dropdown of the rows it can point at (a film's planet).
  • Add and delete rows; paste a block copied from Excel or Google Sheets.
  • Each change goes to the place the table shows (the samples now, the live API later), and ⌘Z undoes it, as the Inspector's edits undo.
  • Screen readers announce cells (the accessible grid pattern).
  • The Star Wars mockup gets an editable table of its sample rows.

<ui-table editable>: a cell cursor, typed cell editors, adding and deleting rows, pasting blocks of cells.

The table reads a place's collection itself, and writes each change through the place, undoable.

  1. The cell cursor: one cell is current; arrows, Tab, Enter, Home / End move it; the table follows the accessible grid pattern, so screen readers announce cells.
  2. Editing: typing starts an editor in the cell, Enter or Tab keeps it and moves on, Escape puts it back. An editor per field type: text, number, date, yes / no, a choice, and a link as a dropdown of the rows it can point at.
  3. Rows: a last empty row adds one; a key and the row's menu delete. Paste: a block of tab-separated cells, as Excel and Google Sheets copy, fills from the current cell, adding rows as needed.
  4. Reading a place: the table takes a place's collection, its columns from the collection's fields and their types, so a page writes one <ui-table editable> over runs and gets typed editors.
  5. Writing: each change goes through the place (the sample now, the live API later), and is ONE undo step, through the same undo the Inspector's edits use (InspectorData), which moves to where both reach it.
  6. Its docs page grows an editable example; the Star Wars mockup gets an editable table.
  7. Checked by: the table's tests (keys, editors, paste, a write, undo); screenshots; a manual paste test for Owen.
  8. Left out: formulas, frozen columns, and drawing only the rows in view for very long tables.
