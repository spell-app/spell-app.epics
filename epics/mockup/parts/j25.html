The drawn look comes from uneven corners and an ink outline, not an SVG filter, so every word stays sharp.

  • The plan said to roughen borders with an SVG filter, kept light so text stays sharp.
  • But a filter on a box roughens everything in it, its text too: it can't be kept off the words.
  • Instead every box's corners are a little uneven:
    • buttons, fields and labels: border-radius: 9px 3px 7px 2px / 3px 8px 2px 7px
    • a bigger wobble on cards, segments, messages, popups and modals
  • And buttons wear a 2px ink outline.
  • They're rules in the theme's own rules sheet, not radius tokens: components read their radius tokens in longhands, min() and calc(), which an 8-value radius would break.
  • A button in a <ui-buttons> group keeps the group's corners through a style query; Firefox has none yet, so there a grouped button wobbles too.
  • A table's own grid stays square, only its outer box wobbles, so <ui-table editable> still reads as a spreadsheet.
