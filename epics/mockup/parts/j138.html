Owen's I20 gave groups icons. A group whose line names none:

  • wide: an icon-wide gap before its label when a group beside it has an icon, so the labels line up, as pages do (J131)
  • collapsed: the thin line T34 drew, not its first letter, so it still reads as a divider between the page icons rather than as one more page
Groups without icons still read as dividers when collapsed; their labels line up with the iconed groups' when wide.
