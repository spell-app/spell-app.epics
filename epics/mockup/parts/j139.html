Owen asked for the page icons to be indented under a group's icon. The step is one icon plus the gap after it, so each page's icon lines up with the group's label, the way nested items line up in the target sidebar. It's set in <ui-site-nav>'s sheet over the tree rows' parts, so <ui-tree> itself, and the docs site's nav, are unchanged. Groups' own icons are drawn at the label's smaller size (0.8125em, pages 0.875em).

Grouped pages read as nested under their group; the docs nav doesn't move.
