The shared movable / resizable (MoveAndResize, in the kit's element folder) loads the kit's Dragging and PrefStore by a dynamic import, the first time an element is movable or remembered, so no page pays for them otherwise. The element folder's barrel test now allows those two of util's files. Resizing is the browser's own corner grip (CSS resize), so plain CSS limits it; sizes and places are kept per element id, under ui-element:<id>. <ui-diagram-node> keeps its own resizable (its host draws nothing), read with the shared one's words.
