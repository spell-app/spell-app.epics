The shared movable and resizable cost a page nothing until an element uses them.

  • They're MoveAndResize, in the kit's element folder.
  • It loads the kit's dragging and its saved preferences by a dynamic import, the first time an element is movable or remembered.
    • the files: Dragging, PrefStore
    • the element folder's barrel test now allows those two of util's files
  • Resizing is the browser's own corner grip (CSS resize), so plain CSS limits it.
  • Sizes and places are kept per element id, under ui-element:<id>.
  • <ui-diagram-node> keeps its own resizable (its host draws nothing), read with the shared one's words.
