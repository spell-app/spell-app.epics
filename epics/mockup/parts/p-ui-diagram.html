Spell UI draws only trees of boxes: nothing draws boxes linked any which way.

  • Write <ui-diagram> with <ui-diagram-node> boxes, each naming the boxes it links to: the boxes lay out in columns, left to right, the lines between them labelled.
  • Drag a box: its lines follow; reload the page and it's still there.
  • Any box can be a <ui-shape>, so it flips to show its other side.
  • One way to measure a box and draw a line: <ui-tree-diagram> uses the same code, and looks exactly as before.
  • It has its own page in Spell UI's docs.
