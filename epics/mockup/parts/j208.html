Artworks from the Met uses core's drawing of long lists as you scroll (drawnWindow), not a scroll loader of its own.

  • Its search asks only for artworks with pictures (hasImages=true, written into the API file by hand); the Met has no filter for public-domain pictures, so some still draw nothing, and are left out.
  • Core change: when the items it drew last took no room (still reading, or drawing nothing) it waits a second before drawing more. Before, it drew every artwork at once: 1,688 reads for cats, and the Met's bot guard then refused the page for minutes.
