T33: after File › Import, every page and its source is your draft until Publish, the first one too.

  • A draft holds text alone (ProjectDrafts saves, reads and publishes text), so a picture, or any other file the server doesn't draft (isDraftable(): .spell, .css, .js, .jsx, an editor page), is written as it is.
  • The project is made of its project file alone, as the archive wrote it, so the project exists and its files' order is the archive's; an archive with none (a hand-made zip) gets an empty one, each file appended as it comes.
  • The project's index is read only once every file is written: read with no file listed, the server makes up a blank file, a real one.
  • The static build (no drafts) is as it was.
  • An imported project shows nothing public but its project file and pictures until you Publish
