Update App Snapshot… takes its picture with the browser's screen capture of this tab, cut to the phone's screen. - Faithful: the pixels as drawn, every shadow root and style sheet; no new dependency. - But the browser asks "share this tab?" each time; Safari has no 'this tab' choice, so it offers a list of windows. - Why not another way: - nothing in the kit draws a page into a picture in the browser (no html-to-image, html2canvas or snapdom), and those miss Spell UI's shadow roots and adopted sheets - the headless screenshot the README's pictures use (yarn examples:readme --thumbnails) runs on the server, which can't see what the person set up in the dialog - If the question annoys: (1) a DOM-to-picture library such as snapdom, a new dependency, less faithful; (2) the server replays the person's clicks headless, complex. - Hidden in the static build, as Versions is. a "..." menu on each of your own projects' home cards, 12px in from the top left: Run App in a New Tab; Rename, Duplicate, Versions, Export as .zip, Update App Snapshot…; Delete
