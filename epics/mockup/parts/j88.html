Reordering changes the project file everyone shares, not your draft, so it takes the same right as renaming a file. AutoSave keeps a file once typing has paused for 0.8 seconds, rather than on every key, and keeps anything still waiting when you leave the page.

  • A designer can't reorder tabs on a project they don't manage.
  • If you turned AutoSave off yourself before, it stays off: File › AutoSave turns it back on.
