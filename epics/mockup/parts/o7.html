After testing with people, the same site grows into the real one. Each step changes one thing:

  1. A real theme: the company's colours and type as a theme file; the mockup theme switched off
  2. Live data: each sample place switched to the live API, no page code changed
  3. Adding and editing rows through the site's own forms
  4. Charts and sheets drawn by Python on the server, shown on a page
  5. Publishing: the site built and served on the company's Node server

What the site's code finally IS (Spell projects run by Spell, or code handed over) is Q5, and which of these steps this epic takes is Q7.
