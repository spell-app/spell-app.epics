After this epic's click-through prototype, the same site grows into the real one. Each step changes one thing:

  1. Running it for testing with people: the mockup served where people can try it, still in the sketchy theme
  2. A real theme: the company's colours and type as a theme file; the mockup theme switched off
  3. Live data: each sample place switched to the live API, no page code changed
  4. Adding and editing rows through the site's own forms
  5. Charts and sheets drawn by Python on the server, shown on a page
  6. Publishing: the site built and served on the company's Node server

What the site's code finally IS (Spell projects run by Spell, or code handed over) is left open until the publishing epic; the mockups are Spell projects meanwhile. None of these steps is this epic's. They become later phases of THIS epic, added when Owen is ready (Owen: "We'll do that here later").
