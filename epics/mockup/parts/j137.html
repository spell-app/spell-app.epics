The drag is the kit's `Dragging`, which covers the page with its own closed-hand cursor while it runs, so a pointer leaving the line still drags it. Hovering the line shows col-resize. Giving `Dragging` a cursor option would change a shared helper; left as is.

Mid-drag the cursor is a grabbing hand. Dragging takes the cursor a drag shows over the whole page (DragOptions.cursor), the closed hand still when none is said; a column tree's line keeps col-resize while it's dragged, as on hover
