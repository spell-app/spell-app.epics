Owen's answer to how P20 · Saved Draft Edits should fix edits that looked lost (r3): Both.

  • In dev (the editor running from a checkout, on this Mac), saving a file of a built-in project (@spell/examples/Solitaire/Solitaire.spell) writes the real file, so git sees it. No draft.
  • Drafts stay for people's own projects and their orgs', for anyone reaching this Mac's editor through the house-network site, and for the live site.
  • Wherever a draft stays, every place that reads the file shows it: the code, the project's list of files, and the running app.
  • The editor says Your draft on a file you've drafted, with Discard beside it.
  • P20's plan is rewritten around both halves: a dev save of a built-in goes to its file, a draft shows everywhere.
  • A draft already sitting beside a built-in (Owen's __draft/Solitaire.owen-2026-11-11.spell in the language worktree) is still offered: Publish writes it to the file.
