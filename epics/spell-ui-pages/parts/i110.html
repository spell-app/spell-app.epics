<ui-header text-align="center"> in a modal stays on the left, while the content beside it centres.

  • Fomantic's example: the modal page, Variations, Center Aligned (center aligned header).
  • Ours (seen in a Playwright screenshot of the open modal):
    • a centred header slotted into a <ui-modal> stays left-aligned
    • while a centred content box beside it centres
    <ui-header text-align="center">   stays left-aligned
<ui-content text-align="center">  centres
  • The likely cause: the in-modal header rule in ui-parts.css (text-align: start) beats the alignment variation.
  • Not fixed then, because another page agent was editing ui-parts.css.
  • The page shows the example with a gap comment, alongside the modal actions issue (I99).
  • once fixed: text-align="center" centres a modal's header
