<ui-search url> only understands Fomantic's own response shape, so it can't search an API such as GitHub's directly.

  • Fomantic's examples:
    • Examples, Using Different Response Fields: fields: { results: 'items', title: 'name', url: 'html_url' }, over GitHub's API
    • Using API Settings: apiSettings.onResponse, regrouping GitHub's answer by language
  • Ours has no field map and no response hook (Fomantic's fields, onResponse, mockResponseAsync). An author must either:
    • proxy the API
    • or set source from a ui-search listener
  • What the page does instead: the same search over a LOCAL source of repository names (the site never calls GitHub), with a GAP comment.

Net effect:

  • once fixed: <ui-search url> can read any response shape
