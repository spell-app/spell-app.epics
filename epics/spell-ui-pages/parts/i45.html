When a stackable grid stacks its columns, Fomantic turns a vertical divider between them horizontal. Ours stays vertical, drawing a line through both stacked columns.

  • Fomantic's example: the divider page, Vertical Divider, second block. A ui placeholder segment > ui two column very relaxed stackable grid, with a login form column, a ui vertical divider "Or", and a Sign Up column.
  • At phone widths, Fomantic's vertical divider becomes a horizontal one between the stacked columns.
  • What the page does: the same markup, in element form. When this was written, our grid stacked by its CONTAINER's width, so in the ~755px demo frame it stacked even on a desktop, and:
    • the divider stayed vertical: a line through both stacked columns, "Or" on top of the form
    • the stacked grid kept its negative gutters, so the form's labels were clipped at the segment's left edge
  • ui-divider.css leaves the swap, and the .ui.grid > .column + .divider rule, to ui-grid.css, which hasn't got them. Nor has it Fomantic's zero margins for a stackable grid in a segment.
  • Partly outdated: since the Stack With phase (P10) the site's root is stack-with="page", so on a desktop this grid shouldn't stack any more. The swap itself is still missing: ui-divider.css still says ui-grid.css "owns those when it lands" (checked 2026-10-04; the page not checked in a browser).

Net effect:

  • once fixed: a stacked grid's vertical divider turns horizontal, and the grid drops its gutters in a segment
