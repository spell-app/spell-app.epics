When a stackable grid stacks its columns, Fomantic turns a vertical divider between them horizontal. Ours stays vertical, drawing a line through both stacked columns.

  • Fomantic's example: the divider page, Vertical Divider, second block.
    • a placeholder segment holds a two-column, very relaxed, stackable grid
    • its columns: a login form, a vertical divider saying "Or", and a Sign Up column
    • at phone widths, the vertical divider becomes a horizontal one between the stacked columns

  > ui two column very relaxed stackable grid

  • What the page does: the same markup, in element form. When this was written, our grid stacked by its CONTAINER's width, so in the ~755px demo frame it stacked even on a desktop, and:
    • the divider stayed vertical: a line through both stacked columns, "Or" on top of the form
    • the stacked grid kept its negative gutters, so the form's labels were clipped at the segment's left edge
  • The divider's sheet leaves the swap to the grid's sheet, which hasn't got it.
    • ui-divider.css leaves the swap, and the rule for a divider after a column, to ui-grid.css
    • the rule: .ui.grid > .column + .divider
    • the grid's sheet also lacks Fomantic's zero margins for a stackable grid in a segment
  • Partly outdated (checked 2026-10-04; the page not checked in a browser):
    • since the Stack With phase (P10) the site's root is stack-with="page", so on a desktop this grid shouldn't stack any more
    • the swap itself is still missing: the divider's sheet still says the grid's "owns those when it lands"
  • once fixed: a stacked grid's vertical divider turns horizontal, and the grid drops its gutters in a segment

Title, as first written: Gap: <ui-divider vertical> in a stackable <ui-grid> doesn't turn horizontal when the grid stacks

Fomantic example: divider page, Vertical Divider, second block (ui placeholder segment > ui two column very relaxed stackable grid with a login form column, ui vertical divider Or, and a Sign Up column). At mobile widths Fomantic's vertical divider becomes a horizontal one between the stacked columns. What the page does: the same markup in element form. Our grid stacks by its CONTAINER's width, so in the ~755px demo frame it stacks even on a desktop; the divider stays vertical (a line through both stacked columns, Or on top of the form), and the stacked grid keeps its negative gutters, so the form's labels are clipped at the segment's left edge. ui-divider.css says the swap and the .ui.grid > .column + .divider coupling were left for ui-grid.css, which hasn't got them (nor Fomantic's zero margins for a stackable grid in a segment).
