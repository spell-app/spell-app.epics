scripts/site-dev.ts: runs yarn site:bundle (clean _assets/, icon-packs link), yarn server ensure, prints the /ui/ URL, then Vite's watch build with vite.site.config.ts. Every src/ / site/_src/ edit rebuilds _assets/ and the page server's live reload reloads open pages. Not watched: site:data / site:index / site:kitchen. A watch rebuild doesn't clear _assets/, so stale hashed chunks can linger: yarn site:build before committing. Why not removed: without it a library change needs a manual rebuild per edit; why not a Vite dev server: the pages load the committed bundle, so watching that same build shows exactly what gets committed. site:preview dropped. Documented in packages/ui/AGENTS.md and site/README.md.
