On a component's API tab, the page's contents list (the toc) is empty, and links to its headings from other tabs don't work. Found in the Template & Shell phase (P3).

  • Why: <ui-docs-api family> draws its tag headers (e.g. #ui-or) in its shadow root, where the toc can't find them.
  • So on the API tab the toc is empty and the rail hides. The content takes the room; the tables would stack at the 720px column anyway.
  • A link to #ui-or from another tab doesn't switch to the API tab, since no light-DOM element has that id. <ui-docs-api> scrolls to it only when it's already shown.
  • The later fix:
    • the toc lists ui-docs-api's ui-render {tags}
    • <ui-docs-api> exposes its header elements
