Fomantic's loading buttons come in three loader styles; ours only has the plain one.

  • Fomantic's example: the button page, States, Loading. Rows 2 and 3 are ui double loading button and ui elastic loading button (plain, basic, primary, secondary).
  • Ours: loading is a boolean, with no value for the loader's style. The page shows only the first row.
  • Suggested: loading="double" and loading="elastic".
    • the attribute's kind: keyOrValueAndKey
    • the loader may already name them
  • once fixed: <ui-button loading="double"> works, and the page shows all three rows
