Fomantic's rtl theme is only fonts; its right-to-left layout is a separate build (RTLCSS), used with <html dir=rtl>. We ported the fonts and the direction, not the build.

  • rtl.css does:
    • the font stack. Droid Arabic Kufi is now called Noto Kufi Arabic; both names are listed.
    • direction: rtl on :root, which inherits into every shadow root
  • NOT ported:
    1. the Google Fonts @import: constructed sheets ignore @import, and themes load no font
    2. the flipped build: see the issue about physical CSS properties (I3)
    3. :dir(rtl) rules (accordion, section): they follow the dir attribute, not the CSS direction
