Fomantic's grid docs outline every row and column, so empty columns show their widths. That look is Fomantic's docs sheet, not grid CSS, and our docs example element has nothing like it.

  • Fomantic's examples, on the grid page:
    • most Overview examples (highlighted example): docs.css outlines every row and column, so EMPTY columns show their widths
    • Colored (colored example): docs.css pads each column 2em, so coloured columns are 76px blocks
  • Neither is grid CSS: it's fomantic-ui.com's own docs sheet. Checked on the live page: #example .colored.example .column { padding: 2em }.
  • What the page does:
    • each empty column holds a <ui-segment>, so it shows in the code too
    • coloured columns stay as tall as their text
  • The fix, if wanted: a highlighted attribute on <ui-docs-example> that outlines grid rows and columns in its demo.

Net effect:

  • once fixed: the grid examples can drop their filler segments
