The Spell UI docs page template needs the colour-scheme script in its head, and the theme pickers in place. What goes where, in the template (spell-ui-docs.html) and its shared parts:

  • In <head>, BEFORE the link to the site's CSS:
    • a <script> holding ThemePreference.HEAD_SCRIPT verbatim. It puts back the light or dark class on <html> before the first paint: 
      try{var s=localStorage.getItem("spell-ui-site:scheme");if(s==="light"||s==="dark")document.documentElement.classList.add("ui-"+s)}catch(e){}
    • also the color-scheme meta, below
  • In the header's dark menu, a theme picker on the right, below.
  • In a component page's masthead (Fomantic's N Themes), the family's theme picker, below.
  • Nothing else: the site's script restores the theme itself (ThemePreference.restore()).
  • Looks done or obsolete (checked 2026-10-04):
    • the template has the color-scheme meta
    • it has the head script before the CSS link: a newer version, which reads spell-site:scheme first
    • it has the masthead's picker
    • the layout part, layout.html, has the header's pickers, though not in the exact <ui-item position="right"> form below 
<!-- in <head>, before the site CSS link -->
<meta name="color-scheme" content="light dark">

<!-- in the header's <ui-menu inverted> -->
<ui-item position="right"><ui-docs-themes inverted size="small"></ui-docs-themes></ui-item>

<!-- in a component page's masthead -->
<ui-docs-themes for="ui-<name>" show="theme">

<!-- the template's masthead, as found -->
<ui-docs-themes for="{{tag}}" show="theme">

The Spell UI docs page template needs the colour-scheme script in its head and the theme pickers in place. For the template (templates/spell-ui-docs.html) and _parts/:

  • In <head>, BEFORE the _assets/site.css link:
    • a <script> holding ThemePreference.HEAD_SCRIPT verbatim. It re-applies ui-light / ui-dark on <html> before the first paint: 
      try{var s=localStorage.getItem("spell-ui-site:scheme");if(s==="light"||s==="dark")document.documentElement.classList.add("ui-"+s)}catch(e){}
    • also <meta name="color-scheme" content="light dark">
  • In the header's <ui-menu inverted>: <ui-item position="right"><ui-docs-themes inverted size="small"></ui-docs-themes></ui-item>.
  • In a component page's masthead (Fomantic's N Themes): <ui-docs-themes for="ui-<name>" show="theme">.
  • Nothing else: site.js restores the theme itself (ThemePreference.restore()).
  • Looks done or obsolete: the template has the color-scheme meta, the head script before the site.css link (a newer version, reading spell-site:scheme first), and the masthead's <ui-docs-themes for="{{tag}}" show="theme">; _parts/layout.html has the header's pickers, though not in the exact <ui-item position="right"> form above (checked 2026-10-04).
