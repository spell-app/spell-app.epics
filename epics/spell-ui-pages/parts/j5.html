Fomantic's .overrides files are CSS written against its class names. Our components draw those same class names INSIDE their shadow roots, where a page stylesheet can't reach.

  • So a new option, UI.styles.register(..., { shadow: true }), adopts a sheet into every shadow root, the way the app stylesheet already is.
  • Example: the instagram theme's hover rule for a link card reaches the card drawn inside the card element's shadow root. The rule is .ui.link.card:hover, in instagram.css.
  • The other option: themes made of tokens only, which would lose most of the overrides.
