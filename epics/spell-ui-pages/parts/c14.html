The Spell UI site's built files are committed, so every rebuild shows up as changed files.

  • _assets/: 143 files, 3.3 MB (960 KB gzipped).
  • Loaded up front: 345 KB (85 KB gzipped), e.g.
    • site.js: 92 KB
    • the UIElement chunk: 109 KB
    • site.css: 120 KB
  • The biggest lazy chunks:
    • the spell highlighter: 458 KB
    • UIRuntime: 171 KB
    • highlight.js: 145 KB
  • Family chunks have stable names; shared chunks are hashed. So a library change renames a few files.
  • The theme sheets' fonts and images land in _assets/ too:
    • karma-*.woff2
    • montserrat.woff2
    • flags.png
  • Rule: rebuild and commit with every phase that changes src.
