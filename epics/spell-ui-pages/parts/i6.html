The API tables on the docs pages show descriptions with backticks in them, and <ui-markdown> can't draw a short inline snippet.

  • <ui-markdown> always draws a block of paragraphs, in an article. It has no inline attribute.
  • One per table cell would also be hundreds of elements per page.
  • What was done instead: a small, safe splitter, InlineCode:
    • CommonMark's code-span rules
    • text nodes only
    • draws <code>
  • A real fix: <ui-markdown inline> (phrasing content only, no wrapper). It would still be too heavy per cell, so the splitter would stay.
  • once fixed: <ui-markdown inline> exists; the API tables keep InlineCode
