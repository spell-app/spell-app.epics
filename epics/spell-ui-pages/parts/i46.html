Fomantic's loading segment can show a double loader, and keep the loader's default colour on a coloured segment. Ours can't do either.

  • Fomantic's example: the segment page, States, Loading, second block: ui brown double loading segment and ui brown usual double loading segment. usual keeps the loader's default colour on a coloured segment.
  • Ours: <ui-segment>'s loading is keyOnly (a plain on / off word), and it has no usual.
  • What the page does: one brown loading segment, with the two words explained in the description.
  • The same shape as the button's loader issue (I22). Suggested: loading="double", plus a keyOnly usual.
