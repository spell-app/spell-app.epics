Fomantic can join a label to a selection dropdown; ours joins only the input's own text field.

  • Fomantic's examples: the Input page, Variations, Labeled:
    • a ui labeled input holding a label and a select.ui.selection.dropdown ("I am a [Developer]")
    • a right-labeled one ("[1-5] Persons")
  • Ours: the label joins the shadow <input> only, and <ui-dropdown> has no joined label.
  • What the page does instead: leaves both out.
