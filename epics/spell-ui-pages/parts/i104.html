Fomantic's image header puts a small avatar on the left with the name beside it. With a <ui-image>, ours drops the text below the picture.

  • Fomantic's example: the table page, Types, third block. An image header holds a mini rounded image, then a content box with a sub header. 
    h4.ui.image.header
  img.ui.mini.rounded.image
  .content
    .sub.header
  • Ours: the parts' sheet, ui-parts.css, sizes and inlines only a slotted plain image (.ui.header ::slotted(img)).
    • a <ui-image size="mini" rounded> is a block at its own size
    • the <ui-content> after it drops below
  • What the page does: shows it so.
  • The fix:
    • treat a slotted ui-image like an img (owner tokens for its display and width)
    • lay out img + .content inline-block, as Fomantic's image header does
  • once fixed: an image header with a <ui-image> puts the text beside the picture
