Fomantic shows three reds, lighter to darker, for inverted red segments in the three emphases. Ours shows one red and two dark greys.

  • Fomantic's example: the segment page, Variations, Emphasis, third block:
    • ui inverted red segment
    • ui secondary inverted red segment
    • ui tertiary inverted red segment
  • Ours: the plain one is red; the secondary and tertiary ones render the uncoloured dark inverted grey.
  • Why: secondary is also a colour alias, mapped after the hues (the header NOTE in ui-segment.css). The same root cause as the secondary menu issue (I5).
  • Also, for comparison: every inverted color segment fills with the hue's dark-scheme shade (a light pastel) under dark text, where Fomantic fills with the full hue under white text.
  • What the page does: renders Fomantic's markup as is.
