<ui-button attached="top"> should span the segment it sits on; ours sits on the segment's corner like a tab.

  • Fomantic's example: the button page, Vertically Attached. A ui top attached button above a segment, a ui bottom attached button below it, both spanning the segment's width.
  • Ours, <ui-button attached="top">Top</ui-button>:
    • the HOST is block-level and full width (:state(fluid), display: flex, 1093px)
    • but the inner <button class="ui top attached button"> stays its content width (76px)
  • fluid does stretch, so the attached top / bottom case just misses the same rule.
  • The page is left as is.

Net effect:

  • once fixed: attached top and bottom buttons span their segment, as in Fomantic
