In Fomantic, a dropdown inside a menu IS a menu item, with an action menu that can nest sub-menus. Ours is a select: it holds a value.

  • Fomantic's examples, on the menu page:
    • Types: the school menu's ui right dropdown item
    • Types: the toolbar's ui dropdown icon item with a wrench, a nested New sub-menu, a divider and a header
    • Content: Dropdown Item, and Sub Menu's More
    • Variations: Pointing vertical, Size
  • In Fomantic, the dropdown takes the item's padding, hover and the menu's border, and its menu is an ACTION menu.
  • Ours: <ui-dropdown> is a select (a listbox, with a value). So the page puts a <ui-dropdown> inside a <ui-item>, which:
    • looks like a control inside an item
    • keeps the chosen text
    • leaves out the toolbar's nested New sub-menu
  • Wanted, e.g.:
    • <ui-dropdown item>: the item look, no value, with action items
    • or a menu-button element with sub-menus
  • once fixed: the menu page's dropdown examples match Fomantic's, nested sub-menu included
