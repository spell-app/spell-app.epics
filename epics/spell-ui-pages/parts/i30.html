Fomantic adds mobile to any ad unit to show it on phones only; ours has only two fixed mobile units.

  • Fomantic's example: Advertisement, Mobile: ui mobile banner test ad.
  • Our unit has only two mobile sizes: "mobile leaderboard" and "large mobile banner".
  • What the page does instead: shows those two.
  • once fixed: <ui-ad> takes a mobile modifier with any unit
