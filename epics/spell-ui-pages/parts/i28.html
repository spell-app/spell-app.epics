Fomantic can mix dividers within one breadcrumb; ours uses the same divider between every section. Minor.

  • Fomantic's example: the breadcrumb page, Content, Divider, second block. A right chevron icon divider, then a right arrow icon divider, in ONE breadcrumb.
  • Ours: each section draws its divider from the breadcrumb's divider / divider-icon tokens, so a trail has one divider.
  • What the page does: two breadcrumbs, one with chevrons, one with arrows.
  • The fix, if wanted: a divider / divider-icon attribute on <ui-breadcrumb-section>, overriding its own divider.
  • once fixed: the page can show Fomantic's mixed-divider example as one breadcrumb
