Fomantic can hide a file input and open its dialog from a styled <label for>. Ours can't.

  • Fomantic's example: the Input page, Types, Invisible File Input (2.9): <input type="file" class="ui invisible file input">, then a <label for> styled as a red icon button or a placeholder segment, which opens the file dialog.
  • Why ours can't:
    • no attribute hides our file control
    • a light-DOM <label for> can't reach the shadow <input>
  • What the page does instead: leaves the example out.
  • once fixed: a hidden <ui-input type="file"> can be opened from a label or button
