Fomantic's image placeholder example is a 150px square; ours can only be sized with tokens or a style=.

  • Fomantic's example: the Placeholder page, Content, Image: <div class="ui placeholder" style="width:150px;height:150px"><div class="image">.
  • Only the --ui-placeholder-* tokens (or style=) size a placeholder; no attribute on <ui-placeholder> or <ui-placeholder-image> does.
  • What the page does instead: a plain <ui-placeholder-image>, at its default fixed height and the placeholder's width.

Net effect:

  • once fixed: the example can be the 150px square Fomantic shows
