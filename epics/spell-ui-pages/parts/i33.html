Fomantic's rail examples don't fit our docs column, and a page can't narrow the rails without CSS.

  • Fomantic's examples: every Rail page example (Rail, Dividing, Attached, Close, Size) puts a left AND a right 300px rail outside one segment.
  • The docs column (~755px at a 1440px window) can't hold both.
  • Only --ui-rail-width narrows a rail, which an example can't set without style= or site CSS.
  • What the page does instead:
    • one rail per example, its segment in a half-width <ui-column> that leaves the rail its room (floated="right" for a left rail)
    • Size stacks seven right-railed segments
  • The fix: a width attribute on <ui-rail> (columns, fractions or px), so the examples can match Fomantic's.
  • once fixed: <ui-rail width> exists, and the rail examples show both rails
