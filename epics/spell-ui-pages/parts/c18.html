On the Spell UI docs pages, a link to an example works only once the contents list (the toc) has run. Found in the Template & Shell phase (P3).

  • Section headers carry their ids in the markup (PAGES.md says so).
  • Examples get theirs (e.g. #labeled-icon) from <ui-docs-toc> as it scans the page.
    • So a deep link works once the toc has run; it scrolls again when the page's <ui-root> is ready.
    • Renaming a heading in a page renames its example's id.
  • The template's sticky offset=64 assumes the 44px spell-site-header.
  • Visual baselines: ui-docs-example.css changed (demo padding, flow-root, scrolling on a phone), but they weren't re-run: that needs Docker, and was left to the lead's visual pass in the Gap Report phase (P8).
