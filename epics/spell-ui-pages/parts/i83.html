A vertical slider fills its host's height, and only an inline style or page CSS can set that height.

  • Fomantic's examples: Variations, Vertical, and Vertical right aligned. Fomantic's own markup uses style="height: 200px" too.
  • No attribute sets a vertical slider's height.
  • What the page does instead: style="height: 200px" on the host, as Fomantic does, with a GAP comment.
  • once fixed: a height attribute (or token) replaces the inline style
