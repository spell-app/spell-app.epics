In Fomantic, a label joined to an input IS the joined box. In ours, a slotted <ui-label> sits inside a grey box of its own.

  • Fomantic's examples, on the Input page, Labeled:
    • a ui right labeled input with a ui basic label ("kg")
    • a right labeled left icon input with a ui tag label ("Add Tag")
  • Ours: the label slot sits inside a grey label box, so:
    • the basic label is a small white box inside a grey one
    • the tag's shape is lost: only its hole shows
  • What the page does instead: shows it as is.
  • A slotted <ui-label> could replace the box, the way a slotted part replaces a card's shorthand.

Net effect:

  • once fixed: a slotted label becomes the joined box, basic and tag shapes included
