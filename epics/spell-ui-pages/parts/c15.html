The tokens table on a component's docs page shows a description only where the CSS has a comment right above that one token. Most families comment GROUPS of tokens instead.

  • FamilyTokens takes a token's description from the sheet comment right above its alias, into components.json.
  • Example: ui-button, none of its 43 tokens has a description.
  • <ui-docs-tokens> drops the Description column when no row has one.
  • The fix: write a comment per token in the sheets, a docs pass per family.
