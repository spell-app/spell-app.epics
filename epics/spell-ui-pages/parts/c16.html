A page with a stored theme may show the default look for a frame before the theme arrives.

  • The light / dark scheme is fine: the inline <head> script re-applies it synchronously.
  • But a THEME is a lazy chunk, plus the runtime.
  • restore() starts the load as site.js evaluates, beside the families' own chunks, so components usually render themed.
  • What may flash: page text (ui-typography, plain markup).
  • The fix would mean blocking the render, or inlining every theme.
