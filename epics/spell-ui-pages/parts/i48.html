Fomantic's emoji page opens on an Emojis tab listing every emoji, with a search box. Our page leaves it out.

  • Fomantic's tab: an emojiSearch search box over a ui emoji container, every Unicode 15.1 emoji in a grid, built by the docs' own script.
  • Why ours can't:
    • no widget lists a name set: EmojiData loads names lazily, per first letter, and has no list or search API
    • a <ui-emoji> per name would be thousands of elements
  • What the page does: leaves it out, with a gap comment.
  • The fix: a docs-only <ui-docs-emoji> (a search <ui-input> + a virtualised grid), on an EmojiData.names(set) API.
  • once fixed: the emoji page gets its Emojis tab
