In Fomantic, a comment's reply form lines up with the comment's text, right of the avatar. Ours starts at the avatar's left edge, full width, below any thread.

  • Fomantic's example: the comment page, Content, Reply Form. The form.ui.reply.form is INSIDE the comment's .content, so it lines up with the text, right of the avatar, above any thread.
  • What the page does: <ui-form slot="reply"> on the <ui-comment>. UIComment renders the reply box after the default slot, so the form:
    • starts at the avatar's left edge
    • is full width
    • comes below the thread, if the comment has one
  • The fix: when the comment has an avatar, indent .comment > .reply by the content margin (--ui-comment-content-margin), and render it before the thread.
  • A workaround an author can use today: put the <ui-form> inside the comment's <ui-content>.

Net effect:

  • once fixed: slot="reply" lines the form up with the text, above the thread
