Where the site, its tools, its elements and its themes live.

The site: plain HTML files, built in Spell UI's package (site/); the pages have since moved, to the shared ui/ folder (epic claude-design P6), then to Spell UI's own docs/, served at /components/ui/ (epic people-and-orgs P18). The page server served it as static files, at /ui/ (D7). Its README.md says how it works. The home page, index.html, and the foundation pages: getting-started, grammar, theming, utilities, icons, kitchen-sink. One page per family (59), ui-<name>.html in its components folder, plus a card index there. The shared header and footer, in _parts/: each page pulls them in with <ui-include> (D8). The bundle's entry and the site's own CSS (layout glue only), in _src/. The bundle built from it, COMMITTED and code-split, in _assets/. The site's data, in _data/: GENERATED: components.json (every tag, family, token, topic and theme) and icons.json kept by hand: pages.json Fomantic's docs images, in images/; files the examples load, in examples/. The site's scripts, in Spell UI's package.json: site:build: the data, the component index, the kitchen sink and the bundle site:dev: a watching build, plus the page server site:new: a new page from the template site:check: Playwright checks for errors, 404s, undefined tags, phone overflow and tabs, with screenshots The page template, spell-ui-docs.html (D1); the authoring guide, PAGES.md, beside this doc. Six docs-only Solid elements, ui-docs-*: example, api, tokens, nav, themes, toc. <ui-root> loads them when a page first uses one. The component list doesn't show them (D2). The themes: one sheet per Fomantic theme, <name>.css in Spell UI's themes folder. ThemeSheets.apply() lays each one on top of the classic theme. Registering a sheet with { shadow: true } carries its class-grammar overrides into the components' shadow roots (UI.styles.register(), D5). The source of the text, the examples and the themes: clones of Fomantic-UI 2.9.4 and Fomantic-UI-Docs, in Spell UI's reference folder (not committed).
