A menu whose items sit inside a <ui-container> (to centre them) shows the items as plain text.

  • Fomantic's example: the container page, Examples, Centered Menu: ui attached stackable menu > ui container > items, a simple dropdown item, and a right item with an input.
  • Fomantic's .ui.menu .ui.container is a flex row, so the items line up as in any menu.
  • Ours, <ui-menu attached stackable><ui-container> around <ui-item>s:
    • the items render as plain inline text: no item padding, no dividers
    • their icon shorthand draws nothing
    • the right sub-menu drops onto its own line
  • The fix: a menu rule for a slotted ui-container (display: flex, items as in the menu), in ui-menu.css / ui-container.css.

Net effect:

  • once fixed: the Centered Menu example looks as Fomantic's does
