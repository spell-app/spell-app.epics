Several kinds of content inside a dropdown's menu don't draw as in Fomantic.

  • Fomantic's examples, on the dropdown page:
    • Content: a .header with an i.tags.icon
    • Content: Description's vertical item
    • Content: Floated Content (right floated icon)
    • Content: Label (a ui empty circular label before the text)
    • Content: Message (a menu holding only a message)
    • Variations: Inverted (an inverted menu on a plain dropdown)
  • Seen:
    • <ui-item type="header" icon="tags"> draws no icon
    • a slotted <ui-label empty circular> is a tiny dot touching the text
    • the header slot has no padding
    • with no items, the menu adds "No results found." under the slotted message
    • no attribute for vertical items, floated content, or an inverted look for the menu alone
  • What the page does instead: shows what it can, with gap comments.

  • once fixed: the dropdown page's Content and Inverted examples match Fomantic's
