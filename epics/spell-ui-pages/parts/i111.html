Fomantic draws a keyboard key as one box, <kbd class="ui label">. Ours draws the page's kbd box around the label's own box.

  • Fomantic's example: the Label page, Types, Label (keyboard shortcuts): <kbd class="ui label">CTRL</kbd>, one box, monospace.
  • A custom element can't BE a <kbd>, so the page writes <kbd><ui-label>CTRL</ui-label></kbd>.
  • The foundation's kbd style then draws its own border and padding around the label (a box in a box), in the label's sans font.
  • What the page does instead: shows it as is.
  • The fix, either:
    • a kbd look on <ui-label>
    • or the foundation leaves a kbd that holds a label bare

Net effect:

  • once fixed: a keyboard key is one box, as in Fomantic
