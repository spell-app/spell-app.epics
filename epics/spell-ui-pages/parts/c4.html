Where a Fomantic variable has no public token, the theme sheets (the T3 batch of themes) write the component's own private plumbing, from the ui.theme layer. If a component renames one of those, the theme breaks silently.

  • The private variables themes write:
    • fixed-width: the modal's width, ratio and header size 
      --_modal-width, --_modal-ratio, --_ui-modal-header-size
    • instagram: --_card-border-shadow (the hover ring)
    • colored: --_checkbox-*
    • bookish: --_ui-icon-owner-align
    • flat: --_flat-form, a style-query flag
  • The safety net is thin: themes.test.ts checks one computed style per theme.
