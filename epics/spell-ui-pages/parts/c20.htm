Two leftovers from moving the ui-root page off Astro, in the Component Pages phase (P4).

  • The Replay demo needs a page script:
    • the old Astro RootDemo.astro held a nested <ui-root> in its loading state, with an element extending UIHost
    • the site bundle exports nothing, so the page can't import UIHost
    • so components/ui-root.html ends its Examples tab with a small <script type="module">: it finds UIHost as the base of <ui-root>'s class, and defines site-root-hold
    • it's the only page script among those pages so far. If pages must stay script-free, the site entry could export a hold element instead.
  • The example files moved:
    • the files the code, markdown, include and root pages load moved from Astro's site/public/examples/ to site/examples/
    • served at /ui/examples/, linked relatively as ../examples/...
    • plus site/examples/icon-pack/: a one-icon pack (spell sparkle) for the root page's icon-scoping examples, since the page's own root already loads every built-in pack
