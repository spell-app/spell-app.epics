The ui-docs-* elements (the widgets the Spell UI docs pages are built from) get their facts about each component from a generated JSON file, not from the component vocabularies themselves.

  • The file: components.json, committed, and rebuilt by yarn site:data.
  • The other option: import the vocabularies directly. Rejected because:
    • ComponentDefinitions is about 325 KB of source
    • <ui-root>'s glob would drag it into the docs' bundle, spell-ui.js, too
  • a vocabulary change shows on the docs pages only after yarn site:data and a commit
  • neither bundle carries the 325 KB of vocabulary source
