Fomantic's horizontal divider header keeps its words' case, in the header font. Ours shows them as the plain divider's uppercase label.

  • Fomantic's examples, on the divider page: Horizontal Divider, second block, and Horizontal Alignment: <h4 class="ui horizontal divider header"> with an icon (Description, Specifications, Left Aligned ...).
  • On fomantic-ui.com the text keeps its case, in the header font (bold, 1.07em).
  • <ui-divider horizontal> has no header word, so the text is the plain divider's UPPERCASE, letter-spaced label.
  • What the page does: <ui-divider horizontal icon>; the words show in uppercase.
  • The fix, either:
    • a header keyOnly on the divider, drawn with the class word "header"
    • or set --ui-divider-text-transform: none per use
  • once fixed: <ui-divider horizontal header> matches Fomantic's divider header
