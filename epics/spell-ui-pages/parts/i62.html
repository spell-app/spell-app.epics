<ui-root size="large"> makes the components inside it larger, but plain text and a bare <ui-icon> stay the same size.

  • Found on the old Astro page's Nested roots example: a bare <ui-icon> and text inside <ui-root size="large">, and neither grew.
  • Why:
    • RootBox sets only --ui-scale on the root's host, which components read
    • plain text ignores it
    • <ui-icon> resets it on its host: it sizes by the surrounding text's em
  • But the vocabulary says size is the size of everything inside.
  • What the page does instead: the example puts <ui-button>s in the roots, which do scale.
  • A fix idea: the root also sets font-size: calc(1em * var(--ui-scale)) on its host, and then components must not scale twice. Not a local fix, so left.
  • once fixed: everything inside a sized root grows, text and icons included
