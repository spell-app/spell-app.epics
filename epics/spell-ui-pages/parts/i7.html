A <ui-table> drawn inside another element's shadow root shows as a bare, unstyled table.

  • Why: <ui-table> styles its light-DOM table with a PAGE sheet. A page sheet only reaches the document's own sheets (document.adoptedStyleSheets). 
    UI.styles.register('table', css, { page: true })
  • What was done instead: <ui-docs-api> lists the table's sheet in its own styles (table: tableCSS). It's the same registry name, so the same sheet object is adopted into its root.
  • The fix: UITable also adopts its sheet into its host's root node, when that's a shadow root.
    • It needs an additive Styles API: today's adoptInto replaces a root's whole list.
  • Until then, every docs element that uses <ui-table> must do the same as ui-docs-api.
  • once fixed: <ui-table> is styled in any shadow root, with no extra styles entry
