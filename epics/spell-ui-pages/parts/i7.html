A <ui-table> drawn inside another element's shadow root shows as a bare, unstyled table.

  • Why: <ui-table> styles its light-DOM <table> with a PAGE sheet (UI.styles.register('table', css, { page: true })), which only reaches document.adoptedStyleSheets.
  • What was done instead: <ui-docs-api> lists table: tableCSS in its own styles. It's the same registry name, so the same sheet object is adopted into its root.
  • The fix: UITable also adopts its sheet into host.getRootNode() when that's a ShadowRoot.
    • It needs an additive Styles API: today's adoptInto replaces a root's whole list.
  • Until then, every docs element that uses <ui-table> must do the same as ui-docs-api.

Net effect:

  • once fixed: <ui-table> is styled in any shadow root, with no extra styles entry
