The light / dark / system buttons on the docs site look right, but a screen reader can't tell which one is chosen.

  • They are one choice of three. Fomantic does it as ui buttons with one active.
  • <ui-button> only sets aria-pressed as a toggle button, and a toggle doesn't fit:
    • it un-presses on a second click
    • it turns the positive colour
  • What was done:
    • active on the chosen button (looks right)
    • role=group + aria-label on the group
    • aria-label + title on each button
  • The native fallback uses aria-pressed buttons.
  • Wanted: e.g. <ui-buttons choice>, giving radio semantics over active:
    • role=radiogroup
    • aria-checked
    • arrow keys
  • once fixed: the scheme buttons announce which one is chosen, and arrow keys move between them
