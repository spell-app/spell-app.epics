In Fomantic, a field in an error, warning, success or info state tints everything in it. Ours tints the label and the input, but not a dropdown or a checkbox.

  • Fomantic's examples: the form page, Field States (Field Error, Warning, Success, Info). Each has a ui selection dropdown and an inline ui checkbox in a coloured field.
    • Fomantic tints the dropdown's box, text and menu, and the checkbox's label, in the state colour.
  • Ours:
    • the field's label and <ui-input> take the state
    • the <ui-dropdown selection> stays neutral
    • the checkbox's label keeps the text colour
  • What the page does: shows them so.
  • The fix: the field's state remap (--ui-color*) reaches the dropdown's and checkbox's own state look, e.g. through an owner token they read, as <ui-input> does.

Net effect:

  • once fixed: a field's state tints every control in it
