Each Fomantic theme only lists what differs from Fomantic's default look. Our copy of that default look is classic.css, so a Fomantic theme is applied as classic plus the theme.

  • In code: ThemeSheets.apply(name) registers classic first, then the named theme.
  • Example: picking material loads classic.css, then material.css over it.
  • The options it was chosen over:
    • copy classic's tokens into each of the 25 theme sheets (the same lines 25 times)
    • apply each theme straight onto our own default look (the wrong base sizes and palette)
  • every Fomantic theme costs two sheets, classic and its own
  • a change to classic.css reaches all 25 themes
