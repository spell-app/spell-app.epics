Every Spell UI docs page's top tabs (and the page template's) are now appearance="segmented" alignment="fluid" equal. The icons page's pack switcher stays a button group.

  • Why for the tabs:
    • the Menu Appearance phase's (P11) Verify line says segmented + fluid
    • it is Fomantic's own docs menu of four equal tabs
    • four equal tabs fit the 390px phone width (site:check: no overflow)
  • The other option: keep the old icons page's hugging switch.
  • Why the pack switcher stays <ui-buttons>: it's a single CHOICE, not navigation or a menubar, so <ui-menu appearance="segmented"> doesn't fit its meaning.
    • It is now equal (hugging, like the old page's segmented switch) instead of width="3".
  • The issues about single-choice button groups (I12, I17) stay open: segmented gives the look, not radio semantics (role=radiogroup, aria-checked).

Net effect:

  • the site's top tabs fill the row in four equal boxes
  • the icons page's pack switcher is <ui-buttons equal>
