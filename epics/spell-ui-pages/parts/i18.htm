Fomantic example: button page, Inverted (<div class="ui inverted segment"> around the buttons) and Vertically Attached (ui attached segment around a wireframe image). Both segments have 1em padding on fomantic-ui.com.

What the page does: <ui-segment inverted> / <ui-segment attached> render with padding 0, buttons touching the dark edge, the image flush with the border. Cause: ui-docs-example.css sets the PUBLIC token --ui-segment-padding: 0 on its closed demo segment to unframe it, and that inherits into every <ui-segment> in the live example. Fix: unpad the demo through a private --_segment-padding (or ::part), never a public token that inherits. Page left as is (GAP comments in site/components/ui-button.html).
