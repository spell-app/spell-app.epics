Fomantic can give a textarea an icon or a corner label; ours has neither.

  • Fomantic's example: the Input page, Variations, Textarea (2.7): a textarea inside each of:
    • ui left corner labeled input
    • ui corner labeled input
    • ui left icon input
    • ui icon input
    • the two combinations
  • <ui-textarea> has no icon, no label and no labeled attribute.
  • What the page does instead: one plain textarea.
  • once fixed: <ui-textarea> takes an icon and a corner label
