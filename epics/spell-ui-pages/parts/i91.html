Found on the embed page (a <ui-label attached="bottom right"> slotted into a <ui-embed>), not fixed: ui-label is another page agent's family. Mechanism: ui-label.css moves a label to the bottom with .ui[class*="bottom attached"].label { top: auto; bottom: ... }, but the corner classes are bottom right attached / bottom left attached, which don't contain the substring bottom attached; the corner rules only set left / right, so the label keeps top: 0. Fix: add .ui[class*="bottom left attached"].label, .ui[class*="bottom right attached"].label to the bottom rule's selector (corner radii still come from the later corner rules). Fomantic's label page (Attached: bottom left / bottom right in a segment) hits the same. The embed page uses attached="top right" instead.
