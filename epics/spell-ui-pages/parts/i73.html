Only buttons can be invokers (the commandfor / command attributes); a menu item can't target a sidebar, modal or shape.

  • Fomantic's example: sidebar, Examples, Using a custom context. A Menu item of a top-attached menu toggles the sidebar (attach events).
  • Ours: only <ui-button> (and native buttons) are invokers.
  • What the page does instead: a compact basic <ui-button> inside the item, with a GAP comment.
  • once fixed: <ui-item commandfor command> works, and the page drops the inner button
