The foundation's look for inline code doesn't reach inside components, so docs elements copy it by hand.

  • The look belongs to ui-typography, a PAGE sheet (typography.css) that is never adopted into shadow roots.
  • No widget draws inline code.
  • The API and example elements' descriptions style code by hand, in their own sheets, copying typography's rule.
  • The fix, either:
    • a .ui-code-like utility in the foundation, adopted everywhere
    • or an inline mode on <ui-code>
  • once fixed: one inline-code rule, and the docs elements drop their copies
