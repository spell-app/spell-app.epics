The docs site's top bar needs a square menu with no margin, as Fomantic's docs have, and ui-menu has no word for that.

  • Fomantic's docs top bar is ui big fixed inverted main menu: square, no margin.
  • Why ours can't:
    • our fixed means position fixed, which isn't wanted under spell-site-header
    • attached=top overhangs 1px on each side (Fomantic's calc(100% + 2px)), which made the 390px page scroll sideways
  • What site.css does: .site-top-menu::part(menu) { margin: 0; border-radius: 0 }.
  • Wanted, either:
    • a flush / page-bar variation
    • or a margin + radius token pair on ui-menu. It has --ui-menu-radius but no margin token.
  • once fixed: the top bar is plain markup, and the ::part(menu) rule in site.css goes
