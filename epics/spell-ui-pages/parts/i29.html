Fomantic's progress bars can show centred text, words, or a name per bar; ours only show a percent or ratio at the bar's end.

  • Fomantic's examples:
    • Content, Centered Progress Text: <div class="centered progress">
    • States, Indeterminate: each bar holds its own text, e.g. Pulsating (default)
    • Content, Multiple Bars with Text: a name per bar, set in the progress's settings (below)
    text: { bars: ['WIP', 'Review' ...] }   // shown as "{bar} {percent}%"
  • Ours: bar-text takes only a percent or a ratio, always at the bar's end. The sheet drops .centered.progress on purpose.
  • What the page does instead:
    • Centered shows the end-aligned percent
    • indeterminate bars carry their words in label, below
    • multiple bars show plain percents
  • Wanted, e.g.:
    • bar-text-align="center"
    • a template for the bar's text, with placeholders ({bar}, {percent} ...)
    • with bar-names
  • once fixed: the three examples can match Fomantic's
