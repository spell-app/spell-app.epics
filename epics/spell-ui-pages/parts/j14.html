The new appearance attribute (Menu Appearance phase, P11) picks a menu's look with one word, and that word IS the CSS class.

  • Declared as kind: "valueOnly", with exactly these values:
    • tabular
    • pointing
    • secondary
    • text
    • segmented
  • Why the value is the class word:
    • the old boolean words stay as aliases, with identical classes
    • the native fallbacks need no code
    • the menu sheet keys on the same words
  • Left out:
    • vertical: an orientation, which every look combines with
    • basic: <ui-tabs basic> already means the panes'
    • combined values such as secondary pointing: write appearance="pointing" secondary instead
  • The other option: an enum the element maps onto the boolean words.

Net effect:

  • <ui-menu appearance="pointing"> ~== <ui-menu pointing>
