D30 · &lt;ui-docs-nav&gt;: API, organization and what it remembers

Built as src/docs-components/ui-docs-nav/. Decisions taken while Owen slept:

  • Shape: ONE <ui-menu vertical inverted fluid> (the nav landmark) in a scroll box (part="nav", the dark fill below a short menu too). Items: header slot, top links in bold (Overview, Getting started, Grammar), a Components item (header + count label + A-Z / Topics <ui-buttons>, then the search <ui-input>), Favourites, the list, Foundation, footer slot.
  • Attributes: current (a tag, or a page file name without .html; default: the page own file name), base (default: the site root above SiteData, so links are absolute), view (az | topics, reflected; default the remembered one), size (medium: our 16px menu is already bigger than Fomantic big on 14px). Host aria-label renames the landmark (two navs on a page).
  • Events: ui-navigate { href, page } (plain left click on a link, cancelable: a flyout closes on it, a router can veto), ui-change { view }, ui-favorite { tag, favorite, favorites }. The inner menu ui-select is stopped at the nav. Names in code are American (favorite, like color), display text British (Favourites).
  • Host API for P3 (flyout / sidebar): focusSearch(), revealCurrent() (scrolls the nearest scroll container up the flat tree, never the page; call after opening a flyout: a hidden nav cannot measure), favorites, listed (promise). / focuses search while the nav is visible. Height: --ui-docs-nav-height (default 100%: fills a sized parent) / --ui-docs-nav-max-height.
  • Remembered (wrapped localStorage, the SAME keys as the Astro ComponentBrowser, so viewers keep theirs): favourites, view, open topics. Topics start CLOSED (as Astro); on load, the current page first topic opens if no open topic holds it (not remembered; closing it sticks). While searching every topic with a match opens; a toggle closes one for that search only.
  • Rows: a link <ui-item> (yellow status <ui-label> for in-progress / planned) plus a toggle tertiary star <ui-button>, in a two-column grid via the sub-menu ::part(menu). Only main tags can be current (as Astro). Docs-only tags never listed.
  • Data: no new fields; added SiteData.root(). Measured on the real data: A-Z ~40 ms to listed (~200 elements), the worst case (Topics, searching e, ~765 elements) ~120 ms.
