Fomantic's clearable search has a trailing remove icon; ours can only be cleared with Escape.

  • Fomantic's example: Types, Clearable. A ui icon input with a trailing remove icon, and a native type=search prompt.
  • Ours:
    • no clearable attribute
    • the prompt is type=text
    • only Escape (with the results closed) clears it
  • What the page does instead: shows the search with a starting value, says Escape clears it, and has a GAP comment.

Net effect:

  • once fixed: <ui-search clearable> draws a remove icon that clears the prompt
