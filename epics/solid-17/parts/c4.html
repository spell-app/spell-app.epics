The fix for elements not yet defined patches the browser's own setAttribute(), for EVERY element, ours or not.

  • It must do nothing unless the tag has a dash AND the value isn't a string: any slip changes third-party code and native elements.
  • Cost: one extra check on every setAttribute() call on the page.
  • It needs its removeAttribute() twin too.
    • Solid removes an attribute for null or false.
    • So the listener or property must be cleared there.
