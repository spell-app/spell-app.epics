Opening a file whose name holds %25 (an encoded %) in the editor may break after the router upgrade.

  • The router next.40 now decodes route parameters itself.
  • spell-app hands the decoded /edit/*address parameter to SpellLocation.addressForUrl() (from followRoute()), which decodes each part again.
  • Decoding twice turns %2541 into %41, then into A: the wrong file.
// spell-app's followRoute.ts:  tail is the router's /edit/*address parameter
path = SP.SpellUrls.withoutPage(SP.SpellLocation.addressForUrl(tail))

// spell-lang's SpellLocation.ts
static addressForUrl(tail: string): string {
  return tail
    .split("/")
    .map((part) => decodeURIComponent(part))
    .join("/")
}
