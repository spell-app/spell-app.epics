Only Spell UI's own catalog is defined early. A pack's tags (epic-*, brand-*, <spell-app>) are defined as before, when the pack's script runs.

  • Most packs define every tag as their script registers, so there's no window to cover.
  • spell-app's pack loads its families first (an async define()): meanwhile the page-wide patch holds a function or object, unless the page is pure.
  • Pack catalogs now carry the attribute names too (rebuilt), so defining them early later is a small step: ComponentPacks.register() would call DOMElement.defineEarly() before define().
