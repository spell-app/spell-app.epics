To drop prop:value and prop:open, a later change to the value or open attribute must set the element's CURRENT state, once it's on the page.

  • Today the attribute is the starting value only, as on a native <input>: a script that sets the attribute after the person has typed would now overwrite what they typed.
  • Form reset reads the starting value: it must stay distinct from the live one.
  • Every element with a live value / open needs checking: dropdown, select, input, accordion, modal, flyout, sidebar, popup ...
