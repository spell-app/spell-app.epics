  • Raised by the intellisense session, 2026-10-22; the same catch Q3 C names.

Planned fix, in P5:

  • When spell-kit/element loads (always before any pack), it patches Element.prototype.setAttribute ONCE: an on-* name given a function, on a dashed tag, goes into a side table (a WeakMap keyed by node) instead of the attribute.
  • The element reads its side table when it upgrades, and adds the listeners then.
