The first test run at rc.17 failed 270 tests in five repos; nearly all from ONE new check.

  • Solid inserts our elements from inside an effect's callback, and the browser runs the element's connectedCallback() right there. It builds the component in a fresh createRoot(), with no owner.
  • rc.17's dev build throws for that: [PRIMITIVE_IN_EFFECT_CALLBACK] Cannot create a memo, effect or root with no owner inside an effect callback (4596 times in the log).

Fix: one owner of our own, ELEMENT_ROOTS in UIComponent.tsx, made once as the file loads; every element's root is made under it. The element still lives until dispose(), and an app's context still doesn't reach inside. The kit's element tests: 154 of 154 pass.
