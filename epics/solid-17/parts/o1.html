Every Solid package moves together, in every repo: the newer plugin and router won't take the old Solid.

  • The core packages, rc.13 → rc.17 (published 2026-10-22, the day this epic started): solid-js, @solidjs/web, @solidjs/signals, @solidjs/compiler, @solidjs/babel-plugin, @solidjs/h
  • The Vite plugin, @solidjs/vite-plugin next.47 → next.51: it needs rc.16 or later
  • The router (spell-app only), @solidjs/router next.35 → next.41: it needs rc.15 or later
  • seroval, pinned to exactly 1.6.7 by rc.17 (we hoist 1.6.8 today)

Where the versions are written:

  • the kit's package.json: dependencies, peers and the resolutions that keep ONE copy
  • each child repo's package.json: spell-lang, spell-ui, spell-brand, spell-epic, spell-app
  • prose that names rc.13: README-element, README-util, README-development, and two code notes (ShadowEvents.ts, Reactive.ts)
  • the agents' Solid 2 guide, guides/solid/solid-2.md in the content folder
