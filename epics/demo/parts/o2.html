Each of the four parts (meetings, links, weather, joke) is built on its own, as a BriefingSource, so one can be added or fixed without touching the others.

Jarvis asks all four at the same time, waits up to 3 seconds, then reads out whatever is ready, in that order. A part that is late is left out. 

if (/good morning/i.test(phrase)) {
  const briefing = await Briefing.forToday(ctx, [meetings, links, weather, joke])
  await ctx.speak(briefing.paragraph)
}
