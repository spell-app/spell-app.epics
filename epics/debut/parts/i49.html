  • Built as Spell UI's docs page theme-bench.html, at /components/ui/theme-bench.html: four REAL pages in frames, each drawn at a desk's width and scaled to its cell, so what's tuned is what ships.
  • The theme menu at the top sets every page, as each page's own menu would. At rest / Stuck scrolls every page so its section titles sit at rest or stick.
  • The tuning column lists every token behind the chrome, in the theme tree's groups: a control each (colour and opacity, a length, text), every theme's value as a chip (a click wears that theme), and which pages read it; a page that sets the token on its own elements is marked, since a tuning on the page's root doesn't reach there.
  • Changes: the theme file's lines (hex colours, #rrggbbaa when see-through) and the editor's own tokens as a rule for its sheet, to copy; kept in the browser per theme until reset.
  • The editor runs on its own port, so it takes the bench's messages in development (EditorTheme); the editor frame opens its full view: Debug, every Inspector card, a card picked.
