On the public site, what happens when a visitor changes an example?

  • There's no server to save to: the site is plain files.
  • Whatever we pick, the examples themselves never change for the next visitor.
  • Edits survive a reload, saved in the browser's own storage.
  • A "Reset example" button puts it back.
  • Making a new project works too, kept the same way.
  • Edits live only while the tab is open.
  • Simplest; a visitor who reloads loses their work.
  • They can read and run the examples, not change them.
  • Safest, but not much to "play with".
  • The browser version of the file hook saves into local storage, over the built examples.
  • Rename and delete work on a visitor's own copies only.

Owen picked A, 2026-10-23.

  • The read-only build (P9) saves edits in the browser's own storage, over the built examples, with a Reset example button.
  • Rename and delete work on a visitor's own copies only.
