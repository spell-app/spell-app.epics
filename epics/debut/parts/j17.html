Owen's sixth look asked for the page header to be rethought, the top bar's rings and dead tools gone, and the top bar's links to scroll with arrows. The calls made building it:

  • The stuck title is a copy of the masthead's, as large, with the bug, original-page and palette buttons on its right. It takes over as the real title reaches the top bar, so the subhead and Send scroll on under it. Its background is the page's colour at 80% with a blur, not fully clear: fully clear, the text sliding under the large title read through it.
  • Send and "who's listening" stay in the masthead, under the buttons, and scroll away with it.
  • The themes button is <ui-docs-themes compact>, a new attribute: an icon-only palette button, its "N themes" its tooltip. Every components page and the page template use it.
  • The top bar's links are the <ui-toolbar>'s own items, so they scroll with ‹ › at every width. A toolbar nested in the centre slot became a plain item and couldn't scroll.
  • Edit and code buttons: gone from the Spell UI site's docked headers (no-tools, a new attribute on <spell-site-header>). The epic pages' and guides' fixed header keeps them: there the pencil edits sections in place and the code button opens the source in VS Code.
  • the old compact 40px stuck bar is gone; --site-page-title-height is now the copy's measured height
  • phones show the masthead's icon buttons too
