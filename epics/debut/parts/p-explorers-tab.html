The Things and Types explorers only show in VS Code and the <spell-app> element, not the web editor.

  • A tabbed pane in the editor's right column: App, Things, Types, JavaScript, Tree.
  • Both explorers refresh after each compile.
  • Run a program and see its things live in the Things tab, with their properties and actions.
  • See every type the program knows in the Types tab, with details.
  • Types come from the language service the editor already runs for the code; things from the running program.
  • The editor's right column is one pane of five tabs: App, Things, Types, JavaScript, Tree. It's the same runner pane VS Code's runner panel and <spell-app> use, and it remembers the tab shown.
  • The App tab keeps the program running behind the others: it's never redrawn. Restart and Publish sit at the tab bar's right, plain icons with tooltips, whatever tab shows.
  • Types: every type the code knows, worked out after each compile by the language service the code editor already runs; click a link to go to its line.
  • Things: what the running program has made, live, its members named in Spell's words from the project's words files.
  • Every runner's tab bar is now a <ui-toolbar>: in a narrow pane the tabs scroll sideways with ‹ › buttons instead of wrapping.
  • Tab names in English and Spanish.
