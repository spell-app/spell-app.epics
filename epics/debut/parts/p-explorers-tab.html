The Things and Types explorers only show in VS Code and the <spell-app> element, not the web editor.

  • A tabbed pane in the editor's right column: App, Things, Types, JavaScript, Tree.
  • Both explorers refresh after each compile.
  • Run a program and see its things live in the Things tab, with their properties and actions.
  • See every type the program knows in the Types tab, with details.
  • Types come from the language service the editor already runs for the code; things from the running program.
