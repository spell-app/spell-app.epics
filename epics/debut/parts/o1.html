Spell's first public outing: a web address where anyone can open the editor, try the example programs, change them and run them, with nothing to install and nothing saved on a server.

  • The editor, prettier: a facelift in the brand's look (lavender, serif headings, pill buttons), a nicer code theme, and the Things and Types explorers from the VS Code extension in a tab beside the running program.
  • Better examples: the Todo List and Calculator tidied, four new ones, and nothing rough or personal on show.
  • Themes: a theme editor built from the property-panel look, and a "fruity" theme in the style of today's macOS, with frosted glass done in CSS alone.
  • Pages to read: guides in the storyteller voice, as projects in the editor's Guides column (Q5).
  • A read-only build: the same editor built as plain files, served locally the way a host would; edits stay in the visitor's own browser. Putting it on a public address comes later (Q6, C4).
