The editor is already three columns wide: the code, then the console, then the running program with its JavaScript and parse tree. A fourth column would leave each too narrow.

Chose a tabbed pane in the right column (App, Things, Types, JavaScript, Tree), the same pane VS Code's runner panel and <spell-app> use, over a new column.
