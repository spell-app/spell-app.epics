New SpellProject.codeFor(target) in spell-parser writes the project for another target from the files as last compiled, read only. Chose that over adding the targets to every compile, which would save build files on each keystroke and stop the whole compile when the Python writer can't write a project. A target that can't write the project shows why, as a comment.
