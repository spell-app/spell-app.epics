To make the docs site's sticky bars glass in fruity, Spell UI gains two tokens a theme may set: --ui-bar-background (what a bar sticking over scrolling content wears) and --ui-bar-filter (what it does to what's behind it). The docs site's top bar, the tab bar's band and the stuck section titles read them, falling back to the page background as before; only fruity sets them. They're read with a fallback, as component tokens are, not declared in the generated token sheet.
