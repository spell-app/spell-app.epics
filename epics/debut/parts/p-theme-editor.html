The Theme Creator is a mockup in the Brand tab, and Spell UI's themes README says "Coming".

  • A real theme editor, in the property panel's look.
  • It edits a theme live, copies its CSS, and can be used in the editor.
  • Inspector panels for Theme, Color, Type and Shape, built from <ui-property-editor> and <ui-panel> in the brand's compact inspector look.
  • A live preview of real components.
  • Copy CSS: the theme as a stylesheet.
  • "Use in the editor": kept in the browser, reached from the editor's theme menu.
  • The Brand tab's Theme Creator mockup is the design, and its script the reference.
  • A new Spell UI element, <ui-theme-editor>: make a theme by changing one of Spell UI's own (fruity where the page has none).
  • Its inspector is a <ui-panel> around a <ui-property-editor>: name and base; Color (rows of round swatches for primary, secondary and background, which also tints fruity's wallpaper); Type (heading and body fonts, each shown in itself, and a text-size slider); Shape (corners, depth and fruity's glass, as segmented choices, each with a Reset).
  • A live preview: a habit-tracker sample of real elements (card, checkboxes, field, buttons, label, toggle, message, progress), side by side in light and dark, or one of them.
  • Copy CSS: the theme as one stylesheet, its changed tokens on :root in @layer ui.app, its first comment naming the base to apply first. The page wears the same sheet while the editor is open, and gets its own theme back when it leaves.
  • Use this theme keeps it in the browser (SavedTheme); the Spell editor wears it over its base while that look is chosen.
  • Its docs page (ui-theme-editor.html), Spanish dictionary, 13 tests; Spell UI's themes README now has recipe 5, Making a theme, in place of the Coming line.
  • Designer pass: swatch rows fitted to one line at any width (they wrapped to two in the 320px inspector); the slider's dark look left as I21.
