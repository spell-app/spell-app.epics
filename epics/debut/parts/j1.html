The guides are projects in spell-app's Guides group (Q5), opened in the editor. It isn't known yet how a guide's prose (the storytelling, between the code) should show there.

  • A spell file that reads as prose, with the code inside it, shown as it is in the editor.
  • Or a page beside the code, drawn next to the editor.

Chose to decide it at the start of P10, after a look at what spell-lang's markdown support can already do, and record it as a decision then.

  • P10 opens with a short check, and a decision written into the epic page before any guide is written.

Settled by Q18 (Owen, bedtime page): a guide is a spell file that reads as prose, with the code inside it.

How it shows, as built in P10, with nothing new in the editor:

  • Each part of a guide starts with a ## heading, which the editor draws bold.
  • The prose is // comment lines under it, which the editor draws in italics; the code between them is plain, and runs.
  • The first line says so: "These lines in italics are for you to read. The plain ones are a working program."
  • Each step ends with a Your move line and a What you'll see line, as the novice voice asks.
  • A guide's checks are ordinary to test lines: Program Output shows a green tick for each.
