  3. Each theme a theme file of its own, <name>.theme.json5, its sheet generated from it (P18), built as Fruity was:
    • its own colours first, then every classic setting it replaces: type, sizes, corners, text, surfaces, borders, shadows, the palette's text-on-colour, focus
    • a rules sheet of its own (rules/<name>.css) for what values can't reach (Pop's outlines and sticker shadow, a shadow on cards), and the shared modern rules; no fixes for one component

    • fonts the computer already has, no font files (J77): the serif and the rounded font become two more of Spell UI's font stacks, beside its mono one (--ui-font-family-serif, -rounded), with the theme editor's Palatino and Rounded; Paper (Iowan Old Style first) and Pop use them, and so does the theme editor
