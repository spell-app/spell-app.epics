For the public preview, Spell has only four looks of its own (Spell, Spell Brand, Fruity, Studio); every other theme in the menu is a port of one of Fomantic's.

  • A handful of new Spell UI themes, each in light and dark, each a different first impression.
  • Listed with Spell's own themes: in the theme menu, on the docs site and in the editor, and in the theme editor's Start from.
  • Owen, 2026-10-25: "Add a phase to make some new themes."
  • Pick one in the palette menu, on a docs page or in the editor, and the whole page changes: colours, type, corners, shadows.
  • Each one in light and dark, its text readable in both (WCAG AA, 4.5:1).
  • Each one a starting point in the theme editor (its /theme page in the editor).
  • Unchanged: the editor's looks (Glass is Fruity, Brand is Spell Brand, Studio) and the code's Purple colours.
  1. The set (see Q21; until you answer, all four):
    • Paper: warm and bookish; cream page, ink-brown text, an oxblood accent, a serif for text; dark is lamplight, deep brown with cream text.
    • Midnight: dark first; a blue-black page, a teal glow accent, softly lit edges; light is a pale dawn blue-grey.
    • Crisp: high contrast; pure white or black, 2px borders, a thick focus ring, text at 7:1, no shadows.
    • Pop: playful; bright flat colours, thick ink outlines, a hard offset shadow, round corners, the rounded system font.
  2. Each theme a sheet of its own beside fruity.css, built as fruity was:
    • its own colours first, then every classic setting it replaces: type, sizes, corners, text, surfaces, borders, shadows, the palette's text-on-colour, focus
    • a few rules for what settings can't reach (an outline, a shadow on cards); no fixes for one component
    • light and dark as pairs, so the page's light / dark switch works as it does today
    • fonts the computer already has, no font files
  3. Listed: each name added to UI.themes.own.
    • The theme editor's Start from already reads that list: nothing to do there.
    • (coherence) The theme menu keeps its own hand-written list of four (ThemeMenu): it reads own instead, each with a one-line description in its texts, so the next theme is one edit.
    • So the editor's palette menu lists them too: it is the docs' menu.
  4. Checked:
    • the themes test: a block per theme, as fruity's (in own, its accent, font, corners, its dark page)
    • contrast: each theme's text, muted text and text-on-colour measured in light and dark, read back from the browser as the contrast test does; AA (4.5:1), Crisp 7:1
    • the designer on the editor and the ui-button docs page in each theme, light and dark, desktop and phone; it fixes what's plain, asks about the rest
    • yarn review in spell-ui and spell-app
  5. Docs: a short section per theme in the theming notes; the Themes class's list of Spell's own themes.
