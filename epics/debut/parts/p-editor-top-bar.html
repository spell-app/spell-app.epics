The editor’s top is three rows of controls (the top bar, each pane’s header, the Inspector’s cards): Spell’s hat, the project menu and the app menus read crowded and disjointed, and the commands live in scattered icons and "..." menus (the top bar details page).

ONE top bar, as Owen designed it on the top bar details page (round 2):

  • The first menu is the project, "Solitaire ▾": New / Duplicate / Rename / Delete / Reset Example, ─, Project Settings, Theme: Fruity (the theme menu as a sub-menu), ─, More Examples (another example), ─, Home. Then File · Edit · View · Run · Help, each item showing its key. The old hat + project menu + app menus row goes; how the left side looks is still open (the page’s Q9).
  • The middle is Run | Edit: no Debug button; its Program panel opens from View › Program Panel.
  • The right end is ONE group of icons, no gaps. Run: Restart, theme, you. Edit: Inspect app, the Inspector menu | Restart, theme, you. No Home (project menu), no gear (Project Settings). Each pane’s own header row goes.
  • Inspect app: pressed while inspecting, a second press or Esc stops, no banner; a small help popup anchored to the button the first time ("Click a part of the app to inspect it. Alt-click for a part inside it. Esc stops."), until the first pick or closed. Run menu: Inspect App, Stop Inspecting (Esc).
  • The inspect ring is the part’s own ::after: the part gets anchor-name: --inspect-hover / --inspect-picked, its ::after is position: fixed with position-anchor and insets from anchor() minus 3px, an accent outline, rounded, pointer-events: none (hover dashed, picked solid). No script moves it; no overflow-hidden parent cuts it. The overlay stays only for parts with no box (display: contents).
  • Edit: every file of the project is a tab over the code, in the theme’s tab look (<ui-toolbar appearance="tabular">), none closes, a dot when unsaved; too many: ‹ › scroll buttons; too narrow for two tabs and a button: one dropdown. Never the C|D|P letters.
  • Phone: Run only, for now (no Edit, no Debug).
  • Keys: today’s only (⌘S, ⌘⇧R, ⌘↵, ⌘N, Esc), the menus and the keys read one list.
