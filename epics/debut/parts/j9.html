The sections toolbar takes a theme's pill-bar look through new --ui-bar-* tokens (track, its padding and radius, keys, hover, the active key's shadow); only fruity sets them, so other themes keep the ivory pills. The top bar is see-through at the top of the page and fills in over the first 32px of scrolling (a CSS scroll-driven animation; where a browser lacks one, it stays filled). The tabs now stick a band's width below the top bar, which sits above them, so they no longer overlap it.
