No theme looks like today's macOS.

  • A new Spell UI theme, fruity, with frosted glass done in CSS alone.
  • Light and dark, pickable in the docs site and the editor.
  • The system font, rounder corners, soft shadows.
  • Translucent cards, menus, popups, panels and dialogs, with a blur behind them for the glass (not gone too far).
  • Listed as one of Spell UI's own themes, not a Fomantic port.
  • A test, beside the other themes'.

Owen looked at fruity on Spell UI's docs (test V1), with a screenshot (v1-owen-1.png): 'Spacing problems. Header bars backgrounds should go all the way to the edges. Merge day/night buttons into the theme picker. Lower opacity slightly in headers and bubbles around the button groups etc to simulate glass.' So P2 reopens for a follow-up: the spacing, edge-to-edge header bars, one theme picker with light / dark in it, and thinner glass on headers and the bubbles around button groups.

  • The theme: the system font, rounded rectangles, Apple's system colours, a violet accent; cards, menus, popups, modals and toasts are translucent and blur a soft wallpaper behind the page; light and dark.
