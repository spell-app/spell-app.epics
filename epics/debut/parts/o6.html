The good news: compiling, the language service and running a program all happen in the browser already. The server only reads files, saves them, and lists projects.

  • Nearly every server call goes through one replaceable hook (LoadableFile.fetch). A browser version of it answers from files written at build time, and keeps edits in the visitor's browser.
  • A few calls skip the hook (project create / rename / delete, the "You" panel): routed through it, or hidden in the public build.
  • The build already works (yarn build in spell-app, checked by a test). What's new: a build flag, a script that writes the project lists and compiled examples beside it, and a command that serves the result the way a host would.
  • The editor's addresses start at /, so it wants a host that serves at a domain's root and sends every unknown path to the page: Cloudflare Pages does both, free.
  • Nothing deploys anywhere today, and this epic adds no deploy: build only for now (Q6); deploying is a todo (T1).
