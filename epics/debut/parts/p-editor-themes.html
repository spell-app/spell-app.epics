The editor ignores Spell UI's themes: its colours are hard-coded, and the code is always Monaco's plain light theme.

  • The editor applies a Spell UI theme at start-up, picked from a menu and remembered in the browser.
  • Its hard-coded colours become theme tokens.
  • The code gets Shades of Purple in dark mode, and a matching light theme.
  • A theme menu in the editor, reusing the docs site's ThemePreference and its theme menu.
  • The editor's own colours (the menu bars, the dark page background, the panels) and the Things and Types explorers' colours all come from --ui-* / --spell-* tokens, so every theme reaches them.
  • Shades of Purple, ported from its VS Code theme file, with rules for Spell's own token names (headings, keywords, types).
  • The code theme follows light and dark with the rest of the page.
