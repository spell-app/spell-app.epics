Owen: "in theme.json5, can you do colors as #rrggbbaa rather than "rgb(255 255 255 / 0.35)"".

  • Every theme and palette file writes its colours as hex, #rrggbb or #rrggbbaa (alpha round(a × 255)), inside longer values too: a shadow's 0 1px 2px #0000004d.
  • The theme writer (ThemeFile) refuses a plain rgb(), naming the hex to write; the theme editor's sheets are hex too.
  • Nothing visible changed: the theme-values test, every value each theme sets as the page computes it, passes unchanged.
