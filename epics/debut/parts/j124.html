rules/modern.css holds the rules Glass and Spell BOTH had: anchors below the header, tabular numbers, link underlines, the image outline, the button press, no animation on a scheme switch, font smoothing. Glass's overflow-wrap: break-word on page typography stays in Glass's own rules sheet: Spell never had it, and moving it would have changed Spell's look.

Merlot names no modern rules either, as it had none: giving it them is a one-word change to its file ("rules": ["modern", "merlot"]), but it would change its look, so it's not done here.
