Spell UI already switches themes at run time (UI.themes.apply()), from one stylesheet per theme, over about 400 --ui-* tokens. Only the docs site offers a picker.

  • The fruity theme is a new sheet beside Spell's own, in the style of macOS today: the system font, rounder corners, soft shadows, translucent cards, menus and panels, with backdrop-filter blur behind them for the glass. Light and dark.
  • The theme editor has a ready-made design: the Theme Creator page in the Brand tab, with inspector panels for Theme, Color, Type and Shape, a live preview and Copy CSS. It's a mockup; the real one is built from Spell UI's property editor and the brand's compact inspector look.
  • The editor then takes a theme: applied at start-up, picked from a menu, remembered in the browser. The Monaco theme follows it (Shades of Purple in dark, a matching light one in light).
  • Shades of Purple isn't in the repo as a Monaco theme: it's ported from its VS Code theme file, with rules added for Spell's own token names.
