A theme made in the theme editor can be kept only once, and never becomes one of Spell's.

  • Use this theme keeps ONE theme per browser (SavedTheme): keeping another replaces it, and it has no name.
  • It shows in no theme menu: only the editor puts it back.
  • Nothing carries it to another browser or computer but Copy CSS.
  • Making it one of Spell's own themes means copying that CSS into a sheet and the theme list by hand.
  • The builder (P21) saves NAMED themes, any number, where SavedTheme keeps one today: save, save as, rename, delete.
  • The builder's Start from lists every theme, Spell's and My themes, each with its tint: starting from one copies it into a new theme, not saved yet.
  • Saved themes show in the theme menu (<ui-theme-menu>, P17) in every place, in a "My themes" group ABOVE Spell's themes, each with its tint; picking one wears it, and it's remembered like any theme.
  • Export a saved theme to a file; import one back, in any browser.
  • "Save into Spell UI" writes the theme as a real theme file in Spell UI's themes folder and adds it to the theme list, so the builder is how Spell's own themes get made. Only a Spell admin sees it, and only while working on Spell (served by the page server).
  • A theme kept before this phase (Use this theme) opens as the first of My themes.
