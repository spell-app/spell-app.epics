Clone Spell, install it, and build the VS Code extension: ``` git clone https://github.com/spell-app/spell.git cd spell corepack enable yarn install cd epic/vscode yarn install yarn package cd ../.. ``` 3. Install the epic plugin, the epic command and the VS Code extension, all at once: ``` node epic/bin/epic plugin install ``` 4. Make sure ~/.local/bin is on your PATH (most systems have it): that's where the epic link goes. 5.
