• one per checkout root: main, and each worktree
  • each root holds its pid file and its log (.spell-server.json, .spell-server.log)
  • port: prefer 4747, else any free; real port in pid file; pages read injected window.SPELL_SERVER
  • what it serves:
    • /: the docs index
    • its own routes, under /_server/: ping, events, live.js, page
    • /ui/: passed to astro dev (D10)
    • dot files: blocked
  • watches named folders only (never the whole root: node_modules, .git, worktrees flood the watcher)
  • route modules, listed in root package.json "pageServer": {"routes": [...]}: goals (P5), app (P7)
  • yarn server serve|start|ensure|stop|status|url <file>
  • no body parsing of its own: each route parses its own (page edits 10mb, goals 64kb, the app's /api as JSON5); a second parser skips a body already read
  • /editor: the app's route module redirects to vite's dev server. spell serve records where that is, in .spell-server.editor.json.
