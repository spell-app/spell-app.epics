When VS Code's doc preview opens a page by its file (?file=) and no page server is running, the page still shows, but parts of it don't work. You'd notice a goals page whose buttons do nothing, or a Spell UI link (/ui/) that fails.

  • Why: the extension's DocPreview then serves the checkout with a server of its own, in-process. It has live reload, but no route modules, so no goals buttons and no /ui/.
  • The fix, for now: run yarn server start, then reopen the page.
  • Why the extension doesn't start the page server itself: C4.
