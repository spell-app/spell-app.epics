In the Docs And Preview phase (P4), VS Code's doc preview (DocPreview) was made to use a page server only when one is already running.

  • It finds a running page server by its pid file.
  • Otherwise it starts its own SRV.WebServer, inside the extension:
    • live reload works
    • no goals buttons
    • no /ui/
  • The scripts that open docs start the page server first, so they get the full one.
  • The other option: have the extension start the page server. But a VS Code opened from the Dock may have no node on its PATH (C4).

Net effect:

  • a doc opened by a script gets the full page server
  • a doc opened some other way, with no page server running, gets the reduced one (C3)
