Running the goals tools under tsx (so they can use the page server's code) adds about 0.13 seconds to every call.

  • Measured: goals.sh help took 0.05s with plain node, and 0.18s under tsx.
  • yarn goals help takes about 0.6s, mostly yarn's own start-up.
  • To run anywhere else, the goals folder now needs this repo's src/server and tsx (C2).
  • The choice to run under tsx is up for review: T17.
