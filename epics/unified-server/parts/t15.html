In the Spell Serve phase (P7), spell app serve was made to leave alone a page server it didn't start. You'd notice it when docs are open elsewhere.

  • Ctrl-C stops Vite.
  • It stops the page server only if spell app serve launched it.
  • A page server that was already running (docs open elsewhere) stays up.
  • Since then (checked 2026-10-04): Vite is the page server's child (serveCommand.ts), so Ctrl-C stops both, or neither when the page server was already running.
  • docs and goals pages open in another window keep working after Ctrl-C
