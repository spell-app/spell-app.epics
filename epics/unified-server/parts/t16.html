Found when goals' buttons hung (Goals Migration and Spell Serve phases, P5 and P7): the page server parses no request bodies itself.

  • Each route does its own, with its own limit:
    • page edits
    • goals: 64kb
    • the app's API: JSON5, 10mb
  • A body can be read only once: a second parser in the same chain (parseBodies) skips a body already read. 
router.use("/api", refuseForeignOrigins, SRV.parseBodies({ limit: 10 * 1024 * 1024, parseJson: JSON5.parse }), api)
  • a new route module brings its own body parser, with its own size limit
