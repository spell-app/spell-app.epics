The package's src/: its barrel uses node built-ins only (D4).

  • server.types.ts: the shared types. 
    Handler, RouteParams, HtmlTransform, FileTransform, Mount, ServerInfo, HttpError
  • mime.ts: ONE TYPES table, the union of the copies in cli, goals and DocPreview.
  • safePath.ts: resolveInside(root, urlPath) gives a file, or a 400 / 403 / 404. A folder gives its index.html.
  • StaticHandler: mounts a URL prefix on a folder, the longest prefix winning.
    • HEAD requests
    • no-store and ETag
    • hooks for HTML, and transform hooks per file extension
  • The Express subset that the app's api.ts uses: Request, Reply, Router and bodies.
  • LiveReload: a server-sent-events hub over fs.watch, with a 250ms debounce. Its client is the page script live.js.
  • Guard: a Host allowlist, a per-run token (x-server-token), and a same-origin check.
  • ports.ts: three port helpers, isFree, freePort and listenPreferred.
  • PidFile: status (a ping, and the root matches), ensure (spawn detached, then poll), and stop.
  • FileLock: a lock file beside the file (<file>.lock), from goals' withLock.
  • open.ts: opens a browser, a new window, a reused Chrome tab, or VS Code.
  • WebServer: node:http plus all of the above.
  • Opt-in, not in the barrel:
    • page/: the page server, the editor, the CLI, the Astro proxy
    • site/: the site header
