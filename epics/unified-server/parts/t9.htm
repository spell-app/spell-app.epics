In the Docs And Preview phase (P4), Spell UI's pages ended up with two theme controls: the site header's and the site's own. They could disagree.

  • The header's light / dark / OS button set color-scheme on <html>.
  • The Astro site kept its own Light / Dark / System toggle.
  • Both were left in: the site's toggle is part of what the site documents.
  • Since then (checked 2026-10-04): the Astro site is gone, but the plain HTML site still has its own theme picker (<ui-docs-themes>, in packages/ui/site/_parts/layout.html) beside the header. The header's button is now one light / dark flip, stored under the same key as Spell UI's ThemePreference (SiteHeader.ts), so the two may no longer disagree. Not checked in a browser.

Net effect:

  • Spell UI pages show two theme controls
