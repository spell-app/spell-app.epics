In the Docs And Preview phase (P4), Astro 7 turned out to move astro dev into the background by itself, then exit, whenever it detects an AI agent in its environment (CLAUDECODE ...).

  • --ignore-lock kept it in the foreground, so the page server owned it and could stop it.
  • The side effect: no Astro lock file, so a yarn site:dev started beside it wouldn't notice it.
  • Looks done or obsolete: the Astro site was retired on 2026-10-03 (commit fc83daab); the page server no longer runs astro dev (checked 2026-10-04).
  • while Astro ran: stopping the page server stopped Astro too
