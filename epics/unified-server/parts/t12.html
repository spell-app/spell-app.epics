In the Spell Serve phase (P7), the page server's /editor was made a redirect to Vite's dev server, where the editor actually runs. You'd notice that the editor has no site header, and the Editor tab leaves the page server's address.

  • Where Vite runs was recorded by spell serve when this was written.
  • The other option: serve a built editor under /editor/. That needs a Vite base and a router basename.
  • Since then (checked 2026-10-04):
    • the page server starts Vite itself, and reads its address from its record: EditorServer, in appRoutes.ts
    • when the editor isn't up yet, /editor answers 503, with a "reload" message
  • the editor has no site header
  • the Editor tab goes to another origin (Vite's port)
