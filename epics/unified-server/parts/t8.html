In the Docs And Preview phase (P4), the header's "Open in VS Code" button was made a plain link, vscode://file/<path>. You'd notice it when several VS Code windows are open.

  • It works from file:// pages too.
  • But it opens the file in the LAST FOCUSED VS Code window, not the window of this session.
  • Opening it in the right window would need the window bridge, which needs a server endpoint.
  • with several windows open, the file may open in the wrong one
  • no server is needed for the button to work
