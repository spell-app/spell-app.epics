The spell extension never runs tsx, so it never starts the page server: a VS Code opened from the Dock or Finder (not from a terminal) may have no node on its PATH.

  • So whatever opens a doc runs yarn server ensure first, which starts the page server if it isn't running.
  • When nothing did, the preview falls back to its own server, without goals buttons or /ui/ (C3).
  • The choice itself is up for review: C20.
