In the Spell Serve phase (P7), the app's yarn start was changed to run spell app serve --headless. You'd notice the API on a different port.

  • The API is now on the page server: port 4747, or a free one. It used to be on 3001.
  • yarn start:server still runs the API alone, on 3001.
  • anything that called the API on 3001 after yarn start must use the page server's port
