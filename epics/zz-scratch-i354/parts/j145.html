The 'This takes effect on restart' message is now one compact row (restart icon, message, primary Restart button, close), 24px above the window's bottom, centred.

  • Why low: it stays until Restart or a close, so up top it would keep covering the file tabs and the running app's own bar; the short-lived notices and errors stay at the top.
  • I163's 500px floor is dropped for this message only (it no longer uses the shared floating style's width); the Published notice is untouched.
  • Closing hides it until the next edit that needs a restart; a run that can't take an edit still starts afresh, as before.
