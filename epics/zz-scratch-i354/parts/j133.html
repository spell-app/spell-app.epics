To select the spacer, I made any tag the drawing writes a part, if it's neither a drawn thing nor a Spell UI element. So it's also a row in Views (Spacer). In the examples only Solitaire's two spacers are such tags. A project that writes plain HTML (a div) would get rows for those too.

The toolbar's spacer is 0px wide. The gap it makes (14px, between Restart and Undo) counts as its box, for pointing at it, its outline and its selection.
