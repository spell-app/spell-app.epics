Two calls in T74's typing help:

  1. A " switches code back to text only when typed right after its { (color={|its color} => color="its color"), and only when its words hold no quote or brace. Anywhere further in, a " starts a string in the code (onClick={say "hi"}), so it's typed as itself. A { typed anywhere inside a quoted value still makes it code, as asked. Undo right after gives back the plain character either way. The right-click menu's Refactor… and the light bulb's "Make it text" work with the caret anywhere in the code.
  2. Only attribute values switch, not the words between tags. <text>its size</text> has no quotes to turn, so a { typed there is typed as itself, and the menu offers nothing there. A tag's quoted word (<action "redo" />) doesn't switch either: it isn't a value.

Also: the menu item is a Refactor (rewrite), not a Quick Fix, so in the code editor it's under the right-click menu's Refactor… and the light bulb; in VS Code the same. Spanish: "Convertir en código" / "Convertir en texto".
