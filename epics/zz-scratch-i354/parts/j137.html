The Code card's Add Action writes to "new action" at the end of the selected thing's type (as Add Event writes its handler), then its code slice takes the cursor; a second one is new action 2, and so on. It's renamed in its signature, as any action is.

  • Only for a thing: a Spell UI element (a button) has no actions, so its Code card shows Add Event alone.
  • Written in English, as Add Event is, even in a Spanish program (the TODO both share).
  • Icons: Add Event the event bolt, Add Action the action's play circle, the ones on the card's rows.
  • Under 300px of card width the header shows their icons alone, their words in the tooltip, so it never wraps.
