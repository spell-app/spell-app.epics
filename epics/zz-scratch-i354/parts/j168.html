Spell UI's <ui-button> put 0.5em between its icon and its words (about 8.5px drawn at the bar's size), so in the draft bar the trash can read as belonging to 'Draft'. It now uses a menu item's distance, 0.35714em (about 5px), so every icon-and-word control in Spell UI spaces the same way. Icon-only and labeled-icon buttons don't change: they set their own margins. The value can be set per page with --ui-button-icon-spacing.
