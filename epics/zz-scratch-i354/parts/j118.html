T68: typing a space after a tag's name follows the same shape table as choosing the tag from the suggestion list.

  • A quoted name's tag: <action "|" />, as you said.
  • One that holds nothing (divider, children, Spell UI's icon, input): the table says it closes itself, so <divider | />, not <divider |></divider>.
  • Any other tag: your <segment |></segment>. The table writes </> under the tag when you choose one; typing writes the closing tag in full, on the same line, as you asked.
  • A tag a quoted name names that also holds things (tab, panel): <tab "|"></tab>, the quotes first, then its closing tag in full.
  • A tag no pack knows (the project's own views, <tableau): counted as holding things, so <tableau |></tableau>.
  • Only in code Spell, not in a page file. It lists the program's actions (for <action) or the tag's attributes (for <icon) at once, the same as choosing it does.
