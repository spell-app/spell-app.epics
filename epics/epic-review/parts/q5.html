Finish Review also: a log line ("Review: 7 items, 3 decisions, 2 deferred"), a reply summary, and for a doc on main, stage + ask before committing.

  • Each answer: written to the doc (decision, close, convert to todo, new phase ...)
  • Actionable ones collect in a list; "Finish Review" shows it, and offers "Start the fixes" (in the epic's worktree), "Add as a phase", or "Leave"
  • Keeps the review fast; fixes run together

Fix each item as it's answered, then the next. Good for 1-line fixes; a long fix stalls the review, and fixes happen wherever the session is (maybe main).
