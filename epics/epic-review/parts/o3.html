The files the review touches, and what each one does.

  • The epic skill (SKILL.md):
    • section 7, "Review", runs when the first word is review (a reserved name)
    • and in "5. Each phase", every session marks the items it talks through
  • The prompt hook (prompt-gate.mjs) lets /epic review ... through untouched: no rename, no block, any window.
  • The plan-doc tool (plan-doc.js) has these commands for it:
    • review, defer
    • queue and unqueue
    • items, and its --spec: the picker page
    • list, backfill
    • every command edits the epic's one shared epic page; the live-doc lookup this epic added went once the pages moved to the content repo
  • review-backfill.js: the one-off walk through past sessions.
  • Details pages (details.js, details.css, and the details script):
    • boxes ticked to start with
    • two-column cards, with a state icon and (?)
    • Select all / none, and Open | All
    • no site header
    • the Send bar pinned as the page's bottom
  • Plan docs and the docs index (spell-doc-runtime.js):
    • Open | All on every item section
    • review labels after an item's id
