The docs index marks an epic "stalled" (a yellow pause) when it has phases left and no update for more than 3 days. For a merged epic, that mark is only as fresh as the last yarn docs:index run.

  • Running epics are judged on every page load, by the page server.
  • Merged ones are judged only when the index is rebuilt.
  • It rarely shows: merged epics are nearly always done.
  • nothing changes: yarn docs:index refreshes the marks
