When a review offers to do waiting work now, saying yes moves you to a new window, and the review stops there. You pick it up again with /epic review <name>.

  • The option was "Do this now" when this was written; the skill now calls it "Start work" ("This review stops until you run /epic review commands again").
  • Why it stops: the move to the new window (the handoff) ends the turn.
  • Nothing is lost: the review marks and the to-do list are already in the plan doc, so the next /epic review resumes from them.
  • after starting work, run /epic review <name> again to finish the review
