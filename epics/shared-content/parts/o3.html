Brought up to what was built: editing at the real path, the commit's shape, search, and the repair commands.

  • A new worktree: the WorktreeCreate hook runs spell dev shared link, so its links are there from the start.
  • Editing: VS Code, the page server and the tools edit through the links.
    • The change lands in the shared repo, and every checkout sees it at once.
    • Claude edits a shared file at its REAL path, inside the shared repo itself: a worktree session's Edit refuses a path through the links (J16).
  • Committing: after every turn, the Stop hook runs spell dev shared commit (Q5).
    • One commit per place the files live: auto: epic <name>, auto: agents ...
    • Its trailers name the checkout whose turn swept the edits up, and the session.
    • Nobody commits these files by hand, or on a branch.
  • Merging a branch: it touches no shared files, so the changelog and the logs can't conflict.
  • Searching: the links are git-ignored, so a search must follow them (C3).
    • grep -R does; grep -r doesn't.
    • rg needs -L --no-ignore-vcs.
  • Checking and repairing:
    • spell dev shared status: each checkout's links, and the shared repo's state
    • spell dev shared link: a checkout's links, put back
    • spell dev shared repair: after merging a branch from before the move
