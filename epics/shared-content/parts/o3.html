• A new worktree: the WorktreeCreate hook runs spell dev shared link, so its three links are there from the start.
  • Editing: Claude, VS Code and the page server all edit through the links; the change lands in ../spell-app-dev and every checkout sees it at once.
  • Committing: after every turn, a Stop hook commits whatever changed in the peer (Q5). Nobody commits docs on a branch any more.
  • Merging a branch: it touches no shared files, so the changelog and logs can't conflict.
  • Checking: spell dev shared status shows each checkout's links and the peer's state.
