Once a plan doc lives in the shared repo, spell-app has no git history of it, so commits --backfill can't follow the doc. For a doc spell-app doesn't track, it reads this checkout's commits since the doc's start date and keeps those that name this epic: <epic> ... (shared-content I3:), or P3: <that phase's exact name>. A bare Fix I3: could be any epic's, so it's left out.

  • item fixes in a shared epic need the epic's name: <epic> I3: ... (the skills say so in P7)
