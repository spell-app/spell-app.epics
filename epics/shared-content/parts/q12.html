A WORKTREE session's Edit / Write refuses a path through a shared link, while the real path works.

  • Its error: "spelled in a form that cannot be safely resolved".
  • The real path is in the shared repo, ../spell-app-dev.
  • The main session doesn't mind.

Owen chose a hook over a rule: shared-path.mjs (since removed: J16).

  • It runs before every Edit / Write / NotebookEdit (a PreToolUse hook).
  • When a folder on the path is a link into the shared repo, it swaps in the real path.
  • So every session edits PAPERCUTS.md as always.
