Every checkout (main and each worktree) gets three links, each a whole folder. The real folders live in ../spell-app-dev, at the same paths (Q9).

Link Holds
packages/docs/content ALL docs content, at the paths it has today under packages/docs: index.html, changelog.html, guide pages, epics/, solid/, dev/, templates/ ...; details/ (scratch, not committed)
goals goal sets, the goals index.html, goals.preferences.json5
agents agents/PAPERCUTS.md, agents/SUSPECTED-BUGS.md, agents/CODE-DEBT.md (moved from the repo root)

The tools stay tracked in spell-app, versioned per branch (Q9).

  • Templates are content (Q10).
