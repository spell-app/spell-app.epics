Every checkout (main and each worktree) has eight folder links at its root. The real folders live in the shared repo, ../spell-app-dev, at the same paths (Q9).

Folder Holds
epics plan docs, with their inboxes and details pages
guides every other docs page, with its Markdown, data and experiments; the changelog is one
pages the docs home, and the scratch details pages (never committed)
templates one starting point per kind of page (Q10)
ui Spell UI's hand-written docs pages; each branch's built bundle and data are laid over them
brand the Brand tab's pages
goals the goal sets
agents the three logs, moved here from the repo root: papercuts, suspected bugs, code debt; and the house style, WWOD

Which folders a checkout links is its own branch's business.

  • The list: the manifest, "shared" in the root package.json.
  • Git ignores the links: a marked block in the root .gitignore.
  • After merging a change to the list: spell dev shared link.

The tools stay tracked in spell-app, versioned per branch (Q9).

  • The docs scripts, their _assets and the goals tooling live in the docs tools folder (tools).
  • Templates are content, not tools (Q10).

How it got here

  • This epic's P2 first put all the docs under ONE link, the docs content folder (content), beside two more: goals and agents.
    • So every docs URL gained /content/ for a day (C6).
  • Epic claude-design P4 (2026-10-05) split that one link into the root folders above.
  • Old paths still work, for checkouts on older code:
    • the shared repo keeps a link per old entry in its old docs content folder (content)
    • the page server redirects /packages/docs/content/<x> to the new URL
    • every auto commit first moves pages older code wrote at old paths (spell dev shared repair)
