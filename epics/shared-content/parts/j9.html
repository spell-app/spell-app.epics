The hook that commits the shared repo is registered already, before the shared repo exists.

  • The hook, shared-commit.mjs, is in the repo's settings (settings.json).
  • It exits at once while the shared repo (../spell-app-dev) doesn't exist.
  • So it costs nothing until P5 creates it, and the cutover then has one less file to change.
  • Once P4 is on main, every session runs one more (instant) Stop hook.
