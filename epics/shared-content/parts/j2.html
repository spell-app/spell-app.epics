DOCS keeps its meaning, "where the pages are", and three new names cover the rest.

  • Nearly every tool used DOCS that way: join(DOCS, "epics"), templates, page paths.
  • So the pages module (pages.js) keeps it, and adds three names:
    • PACKAGE: the docs package's folder
    • TOOLS: its tools folder
    • ASSETS: the page assets, in the tools folder
  • Tools that start yarn run it from PACKAGE.
    • Once content is a link, a process started inside it would be in the shared repo, outside the yarn workspace.
  • One changed constant, instead of a hundred changed call sites.
