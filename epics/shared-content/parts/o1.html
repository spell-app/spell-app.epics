Before this epic, docs content was tracked per branch, which cost twice.

  • A worktree couldn't see another worktree's plan docs or docs edits.
    • Nor main's newer ones: it had the copy it was cut with.
  • The same few files conflicted on most merges:
    • the changelog
    • the docs index
    • the papercuts log
    • 7 of the last 50 commits then were "Merge main into X", with these files the repeat offenders.

Now they live once, in the shared repo: every checkout sees each edit at once, and none of it is ever merged.
