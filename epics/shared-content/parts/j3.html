The goals tools no longer find their goals folder by sitting inside it.

  • They're in the docs tools now (tools/goals).
  • So targets.js reads GOALS_DIR when it's set.
    • Else it uses the checkout's goals folder (goals).
  • spell goals sets GOALS_DIR to the folder it found.
    • That's the nearest folder with a goals.preferences.json5 file.
  • The script behind the /goals skills (goals.sh) no longer searches.
    • It always uses its checkout's goals folder.
  • A goals folder outside the checkout works through spell goals or GOALS_DIR, not through the skills' script.
