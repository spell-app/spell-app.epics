Each checkout links whole folders, and a tool works through a folder link as long as it uses the link's path. So these stay unchanged:

  • Live reload watches each configured folder by its own path, and macOS reports changes inside it (a new test).
    • The folders: the docs content (content) and goals.
  • The file lock (<file>.lock) sits inside the linked folder, so every checkout locks the same real file.
  • Page saves write a temp file beside the page, inside the same real folder, then rename it.
  • The page server checks paths as text, never through realpath.

What did change:

  • git runs in the spell-app checkout, never inside content, where it would see the shared repo
  • shared epics count once, not once per checkout
  • finding pages (findPages) follows a linked folder
  • a shared epic's running card links main's own URL
  • the docs index updates from a worktree, when content is shared
