Reported by review-review: after P3, a plan-doc edit was saved unformatted, and its command failed.

  • findDoc() preferred the epic's worktree path to the shared doc.
  • tidy() made that path relative to main's docs package (docs).
  • The result, ../../.claude/worktrees/..., is a path oxfmt refuses.

Fixed (1f9a6061):

  • epicFile() returns this checkout's own path to the same file.
  • tidy() sends a path leaving the package as an absolute one.
