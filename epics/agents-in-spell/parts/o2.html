• The code word for what does the work is agent, the same word people read: an agent runs on a model; no separate "runner" word.
  • ONE client for every model and agent, in the kit (a new src/agents/, say), so the parser, the epic engine and the app all use it; each provider is one more piece behind it.
  • The editor keeps its Change This flow (select a part, say what should change), but its plumbing is replaced: AG-UI events and MCP tools in place of its own request inbox and Claude Code stream reader.
  • A local model is reached first through the editor's own local server (spell app serve), which finds Ollama or LM Studio: no Electron app needed to start.
  • An Electron app later finds Ollama or LM Studio, and reaches Apple's on-device model through a small Swift helper; it bundles no model runtime of its own.
  • Local agent work is designed for 16 GB Macs as well as 32 GB: the small, fast models on 16 GB, Qwen3.8 27B from 32 GB.
  • A model learns Spell from a Spell reference in its prompt, cached, every edit checked by Spell's checker.
  • The phone does both: a remote for an agent running elsewhere (with voice and review), and small edits on the phone itself.
  • Spell decides local or hosted, within the person's settings: local first, hosted when the check fails twice, asking before it costs money.
  • The browser runs models too, with no install: Chrome's built-in model, and WebLLM or Transformers.js (a 1-5 GB download per site).
