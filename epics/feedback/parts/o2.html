The same way an owned page's comments reach its epic, with the page's Send:

  1. Owen comments on the page (its bullhorns) and presses Send in the page header. Beside it, who hears it:
    • "feedback is listening": a session runs /epic review feedback right now
    • "nobody is listening: Send wakes feedback": no session yet
  2. Nobody listening: Send WAKES this epic, as an owned page's Send wakes its own (ReviewStart.wakeFor()):
    • /epic review feedback typed into the one running session titled for it (🚧 feedback), for Owen to press Enter
    • else a new session in a main window, the command typed in
    • in airplane mode, nothing: the comments wait for the landing
  3. The session's epic inbox wait feedback prints the sent comments, each under its page ("sent from the pages feedback owns").
  4. Comments never sent (written on a plane, or Send never pressed) are swept in by /airplane land, which runs epic comments gather.
