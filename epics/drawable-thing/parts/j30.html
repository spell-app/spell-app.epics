Text the program shows, like a heading or a class attribute, keeps its words exactly as written, even when a language writes its types in another case. It's the program's own text, not a reference to a type.

  • A heading: spellCore.heading("Pile of playing cards") stays as is, though Pile is also a type's name.
  • A class attribute: class: "Pile Foundation stacked" stays as is too.
  • The detective test (naming.test.ts) compiles Solitaire with types in snake_case and looks for any PascalCase type name left over. It skips plain text like these, but still checks the text under type: and instanceType:, which IS a type reference.
  • what the program says on screen doesn't change with the output language
  • "Pile of playing cards" would read "pile of playing cards" in a snake_case language
  • cost: it changes words people read, and can't tell a type's name from an ordinary word
  • headings, labels and class attributes read the same in every output language
  • the detective test checks only text that names a type
