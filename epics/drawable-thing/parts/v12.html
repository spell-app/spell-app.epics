Check, by hand, that an edit skips the program's start, and that the file you edit decides whether the game is kept (P17, Q26, Q27). Only the runner tests have played it so far.

  1. In the editor app, open @examples/Drawable Solitaire and run it.
  2. Play a few moves: deal from the stock, move a card or two.
  3. Clear the console.
  4. Edit Card.spell, e.g. a colour in the card's <css>.
  5. Clear the console again, then edit Solitaire.spell, e.g. a word in its drawing.
  • After the edit to Card.spell:
    • the game in progress stays, drawn the new way: no new deal
    • the console says what was kept, but the card and deck tests print nothing
    • the game's own top-level print still prints (J63)
  • After the edit to Solitaire.spell:
    • a fresh deal, as Restart gives, with the tests printing again
    • the console says why: Started afresh: the program's start changed, in the file that starts its app.
