Q23 made holes live, and P14 also asked that braces reach the page as written. Chose: a {...} in a <markdown> block is always a hole, except in code, over: keeping any {...} that doesn't read as spell as plain text.

  • Code keeps its braces: a fenced code block, or a `code` span, e.g. `{ color: red }`.
  • \{ is a real brace: it's kept as written, and markdown shows it as {.
  • A hole is read as a text fill-in is: {rank} means {its rank} in a card's drawing, and one that doesn't read is tried again with the in front, as a layout's hole is.
  • A hole that still doesn't read is a parse error, reported with its line, as a {...} in JSX is.

  • A typo in a hole is an error you see, not text that quietly shows on the page.
