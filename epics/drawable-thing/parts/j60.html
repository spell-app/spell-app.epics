Chose to count as a test call only a top-level line that calls a method defined to test ..., over any call whose words start with "test".

  • Such a method is named test_... and can only be a statement: the rule that calls it says so (its startsTheProgram()).
  • The same tests spell test finds: every exported function named test....
  • Not marked: a test called inside a method, or inside a top-level if, e.g. if debugging: test card setup. Only the top-level line itself is.
  • A test the program imports from another project counts too, as its call rule keeps those names.
