Owen's example, tableau T1, works as written. A name written bare must start with a capital letter; any other name goes in quotes. I chose that over taking any word as a name.

  • Spell reads words for many things: with any word allowed, turn card over could read as the card named "over".
  • So foundation clubs isn't a reference; foundation "clubs" is.
  • A name starting with a capital can't be mistaken for spell's own words, which are lowercase.
  • Where: thing_name, and named_thing's two forms.
  • As built.
  • Spell would have to know the names while parsing, from with name = ... lines, and a name given as the program runs would never read.
  • tableau T1, pile T2, foundation "hearts" all read.
