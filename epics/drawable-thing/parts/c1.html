Once a type's name can be several words, the parser looks further ahead when it reads a type, and could read too much. 

a card is a drawable thing
set the big card to a new card     -- "big card" must NOT read as a type
a big card is a card               -- ... unless someone declares it, like this
  • The guard: only names someone DECLARED match, the longest first ("bank account" before "account").
  • The built-in two-word types ("drawable thing", "drawable list") are declared by spell itself.
  • Checked in P1: every fixture snapshot unchanged, and the parser speed test run on HEAD and on the diff.
  • a type mention matches a list of known names, not any run of words
  • a new multi-word name can change how an older line reads, if it's declared in the same scope
