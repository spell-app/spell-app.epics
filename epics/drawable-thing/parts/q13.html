Where in the spell does a type's <css> block go? For P4 · CSS In Spell: it decides what the new rule reads, and which type a block belongs to.

  • the block sits under the type's line, with its properties
  • which type it styles is plain: the one it's indented under
  • one place to read what a card is and how it looks
a card is a drawable thing
  - it has a rank as a number
  <css>
    :host { display: inline-block }
    .red { color: crimson }
  </css>
  • the block follows the type's to draw, next to the markup it styles
  • cost: a type with no to draw of its own (it inherits one) has nowhere to put it
to draw (a card):
  return <div class="card {its color}">{its rank}</div>
  <css>
    .card { border: 1px solid }
  </css>
  • both are read; both sheets are adopted, the outline's first
  • cost: two places to look for one type's look
  • P4's rule reads a <css> block inside a type's outline, and only there
  • a block anywhere else is a parse error that says where it goes
