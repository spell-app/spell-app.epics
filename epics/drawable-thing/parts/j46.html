J23 left lists for the phase to settle. A list stays a property only, with no attribute. I chose that over space-separated references, cards="Card#ace-of-spades Card#2-of-hearts".

  • A tableau of 13 cards would be an attribute of 13 references, rewritten on every move.
  • A name with a space needs quoting, and reading a list back gives the same things only when every name is unique.
  • No example has a declared list property on a drawable type.
  • In passing: a list a type makes for itself ({ init: () => new List() }) was a TEXT attribute before, its JSON written out. It's now a property only, as J23 says lists are.

  • About as much work again as single references (J23's estimate).
  • Lists are set from a script, as before.
