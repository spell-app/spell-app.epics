a pile is a drawable list of cards:
	<css>
		/* its cards, stacked:  the last on top */
		::slotted(*) { position: absolute; left: 0; top: 0; width: 100%; }
	</css>

a tableau is a pile:
	<css>
		/* its cards, one below the other */
		::slotted(*) { position: relative; margin-bottom: 8px; }
	</css>

to draw a tableau:
	return <div className="pile tableau"><slot/></div>
