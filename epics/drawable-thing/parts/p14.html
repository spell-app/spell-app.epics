A spell file can hold CSS in a <css> block, but formatted text has nowhere to go: markdown's own symbols would be read as spell.

A <markdown> block is read exactly as written, as a CSS block is. It's drawn with Spell UI's <ui-markdown>, and coloured as markdown in VS Code and the spell editor.

  • Nothing inside the block is read as spell: its stars, hashes, angle brackets and braces reach the page as written, as a CSS block's do.
    • Spell's tokenizer reads markdown as a raw-text tag, beside css.
    • The indent its lines share comes off, so the block can sit indented in a drawing.
  • It's drawn by Spell UI's markdown element, <ui-markdown>, with the markdown as its text.
  • The inside of the block is coloured as markdown in both editors:
    • in VS Code, through spell's grammar, as it already colours a <css> block as CSS
    • in the spell editor in the web app, as its <css> blocks are coloured
