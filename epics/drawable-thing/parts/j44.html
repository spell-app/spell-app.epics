Owen asked for <solitaire-tableau id="T1">, with no drawable- prefix. The word "drawable" (or "drawables") is dropped from the PROJECT's part of the tag. I chose that over dropping it from the whole tag.

  • Drawable Solitaire, Tableau => solitaire-tableau; the fixture DrawableSolitaire too.
  • A class's own name keeps it: DrawableCard in project Games is game-drawable-card.
  • A project named only "Drawable" falls back to spell-, as an empty name already did.
  • Where: elementTagFor().
  • As built.
  • A type named drawable-thing would lose its own word.
  • Every Drawable Solitaire tag is <solitaire-...>: the demos and tests follow.
