A type's property whose name the page or Spell UI already means something by gets no attribute and no element property: a type's title doesn't turn into a tooltip, and its hidden doesn't hide the card.

  • The names left out:
    • the page's own: id, class, style, slot, part, is, lang, dir, title, hidden, inert
    • Spell UI's: disabled, loading, visible, animation
    • the element's own: thing, which holds the thing it draws
  • The thing still has the property: a script sets it on the thing, not the element.
    • <my-page title="Home"> sets the element's tooltip, not the page thing's title.
  • Methods likewise: a method the element already has, like remove() or click(), isn't replaced by the type's.
  • Where: TAKEN_ATTRIBUTES, a list in app's SpellElement, and a check that the method name is free.
  • A type can use any property name; only its element hides the taken ones.
  • A name added to the list later hides that property on every type's element.
