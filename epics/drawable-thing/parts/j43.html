J23's option A said every drawn element would show thing="Card#queen-of-spades". P18's goal didn't list it, and I left it out. I chose that over writing the attribute anyway.

  • Spell UI hears every attribute written on its elements as the page changing it.
  • So writing thing="Card#queen-of-spades" would set the element's thing to that TEXT, in place of the card the program handed it.
  • The text finds the card again only while the card keeps its name. A card's name follows its rank and suit, so card.rank = 2 would leave the element drawing nothing.
  • What works now: thing="Pile#stock" written in markup is read, and a card shows pile="Tableau#T1".
  • Doing it needs Spell UI to write an attribute without hearing it: a small change to its element core (a todo, below).
  • A todo: a way for a component to show an attribute without it being read back.
  • Then every drawn element shows its thing's reference.
  • A new public method on DOMElement to write an attribute unheard.
  • Touches the element core every ui-* tag shares.
  • The inspector shows a card's rank, suit, direction and pile, but not which card it is, by reference.
