A drawable type's tag is the project's name made singular, then the type's class name, all in lowercase words joined by dashes. This is the naming the tag question (Q3) settled, spelled out for every kind of name.

  • Core names it, in elementTagFor(), and keeps it on the class: spellCore.elementTagOf(thing) gives a thing's tag back.
  • The project's name is made singular as a whole, so only its last word changes: games becomes game.
  • A multi-word class name's underscores become dashes: Bank_Account is bank-account.
  • Anything that isn't a letter, a digit or a dash is dropped, and the tag always starts with a letter.
  • A project whose name has no letters at all starts the tag with spell- instead.
    • Every tag has a dash, so it's always a valid custom element name.

  • The Todos - Form Based row is the odd one: "todos" stays plural, because only the name's last word ("based") is made singular.
  • Letting the author name the tag by hand stays a todo (T1).
  • Q3's answer, project name made singular first, holds for every project and library name.
  • A project named only in symbols or digits gets spell- tags.
  • A multi-word project's earlier words keep their plural: <todos-form-based-task>.
