Check, by hand, that the inspector shows each drawable element's thing by its id, and each card's pile as a reference (P18). Only the browser tests and a headless run of the demos have seen it so far.

  1. In app, build the element bundle: yarn build:element.
  2. Open /demo/klondike-layout.html on the page server, and open the browser's inspector.
  3. Look at a tableau's tag, then at a card's tag inside it.
  4. Move that card to another tableau.
  • Each tableau's tag is <solitaire-tableau id="T1"> ... id="T7".
  • Each card's tag has its card's name as its id, e.g. <solitaire-card id="queen-of-spades">.
  • Each card's tag shows the pile holding it, e.g. pile="Tableau#T1".
  • After the move, the card's pile names its new tableau.
  • No tag says drawable-solitaire-... any more.
