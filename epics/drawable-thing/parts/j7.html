A type's name may have up to 4 words; a fifth word ends it.

  • The limit is SpellType.MAX_NAME_WORDS, one number to change.
  • It keeps the look-ahead short: every type mention tries the longest run first, so a longer limit costs time.
  • Four words covers names like "savings account interest rate".
  • a name of five words or more doesn't declare (its fifth word reads as the next part of the line)
  • raising the limit is a one-line change, re-checked by the parser speed test
