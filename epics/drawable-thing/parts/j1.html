The editor finds a file's <css> blocks by reading its text line by line, not from spell's parse, because spell's grammar has no rule for the block yet.

  • A line holding only <css> opens a block.
  • A line holding only </css> closes it.
  • A block never closed runs to the end of the file.
  • The same two line patterns, SpellCSS.OPEN_LINE and CLOSE_LINE, drive both:
    • the language server (completion, hover, errors, folding)
    • the spell editor's colouring
