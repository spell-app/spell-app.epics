A type name is one word, so "a bank account is a thing" can't be said.

A type's name can be several words, with a short name after "aka".

  • "a bank account aka account is a thing" declares the class BankAccount.
  • Afterwards "bank account(s)" and "account(s)" both name it.
  • A spell author can give a type a name of two words or more, and a short name after "aka" (O5).
  • Either name, singular or plural, finds the type afterwards.
  • Only names someone declared match, the longest first: "a big card" stays a card (C1).
  • Every example program parses exactly as before, and the parser is no slower.

set checking to a new account               -- checking = new Bank_Account()

set accounts-list to a new list of accounts -- new List({ instanceType: "Bank_Account" })

a card is a thing

set joker to a new big card                 -- joker = new Big_Card()
a savings account aka card is a thing       -- PARSE ERROR:  "card" already names a type:  card
  • How spell reads a declaration:
    • A new rule, type_words, reads the name: every word up to a reserved word or "aka", at most 4.
    • Both create_type and create_list_type read it, then an optional "aka" and a short name.
    • Both now declare through one shared method, TypeDeclaration.declareType(): the code they each had a copy of is gone.
    • Both refuse a name another type already goes by (J6).
  • How spell reads a mention:
    • Every rule that reads a type first tries the LONGEST run of 2 to 4 words that names a type in scope. 
      type
known_type
singular_type
plural_type
    • Else one word, as before.
    • Only declared names match: "a big card" stays a card unless a "big card" was declared (C1).
  • The short name:
    • a type's scope record keeps it (TypeScope.aka)
    • a scope's type list finds a type by it, after every type's own name in that scope: a new, generic option on the parser's scope lists (aliasProp)
    • a mention by the short name compiles as the type's own name
    • a project's declarations carry it, so a project that imports it knows the short name too
