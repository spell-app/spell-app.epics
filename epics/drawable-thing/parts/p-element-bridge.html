Nothing turned a spell type into a custom element.

Core names each drawable class's tag and hands the class to a hook; the app fills in the hook with a bridge, SpellElement, a Spell UI component that defines the element.

  • The tag is the project's name made singular, then the type's, in dashed words: <solitaire-card>, <game-bank-account> (J12).
  • Each tag is defined once, as a sub-class of SpellElement; it draws its thing in its own shadow root, with the page's theme sheets and the page's own Solid and Spell UI.
  • Core never imports Spell UI; how a tag gets defined changed again in P5 (J16).
  • A project that declares drawable types now ends with one line defining their elements, and each type gets its own tag on the page: "a card is a drawable thing" in Solitaire is <solitaire-card>.
    • The line: spellCore.defineElements("Solitaire", { Card, Joker, Pile }).
    • Sub-types of a drawable type count too; a project with none ends as before, so no fixture changed.
    • Written by SpellProject.elementsFooterFor(), not by the writers (J11).
  • How a tag is named: the project's name made singular, then the class's, in dashed lowercase words (J12).
    • a project called games, and its type Bank_Account, make <game-bank-account>
    • a project called Todos - Form Based, and its type Task, make <todos-form-based-task>
    • A project name with no letters starts the tag with spell-.
  • Core's new elements module names each tag and keeps it on the class (spellCore.elementTagOf()).
    • It hands each class to a hook the page fills in, so core never imports Spell UI.
  • The bridge: app's new SpellElement, a Spell UI component, with its vocabulary beside it.
    • Each runtime copy fills core's hook once, from spellRuntime.
    • Each tag is defined once, as a sub-class of it carrying the tag.
    • It draws its thing through the runtime, in its own shadow root, with the page's theme sheets.
    • One table per page says which runtime draws each tag: the one that defined it last (J13). That's the start of P7's swap on recompile.
