A declaration is refused, with an error on its line, when one of its names already belongs to another type. So a name always means one type, and a mention never has to guess.

  • Its name is already another type's short name: refused.
  • Its short name is already another type's name: refused.
  • The check runs while parsing, against the types in scope at that line: TypeDeclaration.refuseTakenNames().
  • Declaring the SAME type again, as before, is not refused.
a card is a thing
a bank account aka account is a thing

an account is a thing
  -- error:  "account" is already the short name of bank account

a savings account aka card is a thing
  -- error:  "card" already names a type:  card
  • one name, one type, in a scope
  • an author who wants both must rename one of them
  • a type of that name further out, met only later, can still be shadowed: caveat C6
