A layout's spell knows only its own project's types and functions, not those of a project it imports, like a library.

  • The layout reads its own project's declarations file.
  • A type or function from an imported project isn't in it, so a hole naming one shows ⚠.
  • Its things still work if the program itself made them: those come from the running program.
  • The fix, later: read each imported project's declarations too, as the editor does.
  • For now, a layout's spell sticks to its own project's names.
