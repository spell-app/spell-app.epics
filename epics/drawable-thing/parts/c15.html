An attribute hole with a space in it must be in quotes: HTML ends an unquoted attribute value at the first space.

  • action={auto-play} works: no space.
  • action={bump the score} becomes action="{bump", which doesn't read: ⚠.
  • Write action="{bump the score}" instead.
  • The browser does it before spell sees the page, so the layout can't fix it.
  • Found by the browser test.
<button action={auto-play}>           ... fine
<button action={bump the score}>      ... the browser reads action="{bump", and two more attributes
<button action="{bump the score}">    ... fine
  • The demo page's comment says so; Spell's docs on layouts should too.
