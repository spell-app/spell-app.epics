Every edit in the editor ran the program again from the top: Drawable Solitaire dealt a new game, and any program lost what it was doing.

A recompile carries the program's things over to the new classes, matched by name and type: the game in progress stays, drawn the new way.

  • Works for any program: a counter keeps its count; a card held by the deck and a pile stays one card (J37).
  • A property added gets its starting value; one removed is dropped; a thing whose type changed starts afresh, and the console says so.
  • Restart starts afresh on purpose: <spell-app>'s, the editor's and VS Code's.
  • The new run still ran its start until its first pause (J36): P17 fixed that.

  • How: the new program still runs from the top, but stops at its first pause.
    • While it loads, every pause for ... never ends.
