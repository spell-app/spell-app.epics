Spell UI's code block, <ui-code language="spell">, shows a <css> block as plain spell, not as CSS.

  • It uses spell's pre-compiled highlighter (spell's highlighter), which knows nothing of the blocks yet.
  • You'd notice it in docs pages and plan docs that show spell code with a block in it.
  • Only the two editors (VS Code and the spell editor) colour the blocks today.
  • docs examples with a <css> block are coloured wrongly until the highlighter learns them
  • fixing it means teaching the highlighter, then rebuilding Spell UI's bundled copy (yarn gen:spell)
