In the spell editor, a CSS comment spread over several lines is coloured as a comment on its first line only.

  • The spell editor colours each CSS line on its own.
  • Monaco's public way to colour a line (monaco.editor.tokenize) carries nothing from one line to the next, so line two doesn't know a comment is still open.
  • VS Code is not affected: its colouring carries state across lines.
/* a long note,
   this line colours as CSS, not as a comment */
.red { color: red }
  • a long comment looks half-coloured in the spell editor; nothing else changes
  • one-line comments colour correctly
