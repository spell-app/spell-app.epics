A project compiled to TypeScript (or Solid) still draws a drawable child with a plain call, card.draw(), so the child draws inline, not as its own element.

  • Only the JavaScript target's draw the card goes through core's spellCore.drawThing(), which draws the element.
  • The TypeScript and Solid targets' drawing (@drawn) is the TS Solid Elements phase's job (P10).
  • The runners only run the JavaScript target today, so nobody sees the difference yet.
  • Nothing to do now: P10 makes those targets draw drawable things as their elements.
