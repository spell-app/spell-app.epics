Chose to start the whole program afresh, as Restart does, when any of the last run's things can't come over (its type changed, or is gone), over P16's way (J37) of starting just the top-level things holding it afresh and keeping the rest.

  • Why: with the start now skipped, a thing that starts afresh by itself misses what the start does to it. In Drawable Solitaire, a change to the type of a card's rank left every pile with the half-dealt cards of a deal that stopped at its first pause, and the game still running on them.
  • The console says why, in place of the first try's lines, e.g. Started afresh: stock: Card's rank changed its type. Then the program runs from the top: tests, a fresh deal.
  • spellCore.carryOver() itself still starts each such thing afresh by itself: the runner asks first (spellCore.carryProblems()) and doesn't call it then.
