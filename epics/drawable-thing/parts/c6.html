A short name declared in an inner scope finds its own type, even where a type of that very name exists in a scope further out. Rare, and mostly prevented, but possible.

  • The order in which a scope looks a type up:
    1. its own types, by name
    2. its own types, by short name
    3. then the scope around it, the same way
  • So an inner short name hides an outer type's real name.
  • The refusal (J6) stops the common case: a short name equal to a type's name already in scope when it's declared.
  • What's left: an outer type of that name that turns up only after the short name was declared.
const item = this.#items.find((it) => key === this.getKeyFor(it)) ?? this.getByAlias(key)
if (!item && !localOnly) return this.parent?.get(key)
