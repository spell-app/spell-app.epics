Owen (2026-10-10): a map of { kind: case } per output language, e.g. { type: "PascalCase", variable: "snake_case", method: "camelCase" }, or { all: "snake_case" }, which Python will use.

  • Kinds: type, method, variable, property, constant; all for any not named.
  • Type names too, including where a type's name is TEXT in the compiled code (isOfType(x, 'BankAccount')): those get their own tree node, so each writer renames them.
  • JavaScript and TypeScript: types PascalCase (BankAccount), methods and variables camelCase, properties and constants as spell names them.
  • P11 builds the full map (about 3-4h)
  • J4 resolves as BankAccount
