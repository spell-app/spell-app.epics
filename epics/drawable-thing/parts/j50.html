Owen: "be careful, this could get annoying very quickly". The warning shows only where spell names a thing (tableau T1) AND the project gives two things that name in so many words. I chose that over counting every way a name can be set.

  • Counted: set x to a new tableau with name = "T1" and get a new tableau with name = "T1".
  • Not counted: a name worked out as the program runs (name = ("T" + the number)), a later set the name of x to "T1", or a new thing added straight to a list.
  • Two things named the same, and nothing names one: no warning.
  • A super-type sees its sub-types: pile T1 warns for a tableau and a pile both named T1.
  • The whole project is seen, so a reference written above the things it names warns too; it follows edits as they're typed.
  • The message: More than one tableau is named "T1": this finds the first one made.
  • As built.
  • Also set the name of x to "T1": more warnings, some for a thing renamed on purpose.
  • No example warns; the ThingReferences fixture shows one warning, and none for two piles nothing names.
