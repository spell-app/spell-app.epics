A drawable element can't show or take a thing it holds: a card's pile, an element's own thing, a list's items are JavaScript properties only (J23).
  • A thing is named in text by a reference, and an attribute can hold one:
    • by its name, Type#name, e.g. Tableau#T1
    • by its place, Type#1: the first of that type, counting from 1
  • A tag's name drops the word drawable: <solitaire-tableau id="T1">.
  • Owen (picking A on J23): "the web component name would be <solitare-tableau id="T1"> -- no <drawable- prefix"; "Tableau#1 should be the first tableau on the page, using 1-based indexing"; "Pile#T1 should work to find tableaus because Pile is a superclass of Tableau".
  • A reference names one thing: Tableau#T1 by its name, Tableau#1 by its place, counting from 1.
  • A type finds its sub-types' things too: Pile#T1 finds tableau T1. (Pile#2, a place across sub-types, is a todo for later.)
  • A property holding a thing shows as its reference on the element: <solitaire-card pile="Tableau#T1">, and follows the thing (as P13's attributes do); setting the attribute sets the property.
  • A layout's tag can say which thing it draws with one: thing="Pile#stock", beside id="T1". Reworked for J43: the id IS the reference, and the thing attribute goes.
    • Owen (J43): "Seems simpler to not have the 'thing attribute' but use ID instead, e.g. <solitaire-tableau-pile id="T1"> IS the thing reference. Allowing this to drift by assigning a 'thing' explicitly seems likely to have problems."
    • A tag's id names its thing: <solitaire-tableau id="T1"> is Tableau#T1. And <solitaire-pile id="stock"> finds the stock pile, a sub-type's thing.
    • An element the program draws gets its thing's name as its id, so the inspector names it: <solitaire-card id="queen-of-spades">. A thing with no name gets no id.
    • Two things of a name on one page (two decks in a game): the second is queen-of-spades-2, the next -3 (Owen: "Will need to work when e.g. there are two decks in a game. Maybe queen-of-spades-2?").
  • A drawable element's tag drops the word drawable from its project's name: the Drawable Solitaire example's tableau is <solitaire-tableau>.
