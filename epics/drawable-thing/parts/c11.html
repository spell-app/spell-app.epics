A card moved from one pile to another looks moved, but on the page it's a NEW element in the new pile; the old one is removed.

  • Each pile keeps its own cards' elements by identity: within ONE pile, a card keeps its element as other cards come and go.
  • Across piles, nothing carries the element over: the old pile drops it, the new pile makes one for the card.
  • Nothing is lost: the card's state (face up, its suit) is the card thing's, not the element's, so the new element draws the same card.
  • The goal said "moving a card moves its element": true for what you see, not for the element object.
    • It would matter only to code holding on to the old element, or to an animation that follows one element from pile to pile.
