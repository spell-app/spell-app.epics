Owen, 2026-10-25, on J35 (asked with examples in the modal): "Once, written in spell".

  • Two sided view is a spell file in a library of built-in templates (TwoSidedView.spell), compiled ONCE; TwoSidedView in the runtime is that compiled class, holding direction, face up / down, turn it over and its drawing.
  • A card made from it compiles to only its own front and back: class Card extends TwoSidedView { drawFront() ... drawBack() ... }.
  • Replaces P5's copy-in (each template got its own copy of the words, J35); more built-in templates can be added the same way.
