Owen, 2026-10-24, on Q42: "<while mouse is down> for code which should execute while mouse is down, then undo effect when mouse goes up."

  • Like CSS :active, for code: it starts when the condition turns true and is undone when it turns false. 
<spell-view "playing card" template="two sided view">
	<while the mouse is down>
		set its lift to 4
	</>
</>

The card lifts while it is pressed, and drops back when the mouse goes up.
