Owen's test closes with </> (Q21). Where may it close a tag?

Now: what may </> close: Spell's own tags only, every tag, or none?

Shaped by Q46: a drawing holds no native HTML, so its "markup" is pack components with bare names (<text>, <button>). The old line between "Spell's tags" and "markup" is now only which pack a word comes from. 

<phrase "is a face card">if its rank is jack, queen or king</>

<draw section="front">
	<text part="face" color={its color}>{its rank} {its symbol}</>
	<if it is a face card>
		<image part="portrait" src="{its rank}.svg" />
	</>
</draw>

Changed: A's old reason, "</> already means a JSX fragment in markup", went with Q46; so B is now recommended.

  • </text> in a drawing, </> after <phrase>.
  • Costs: a reader has to know which words are Spell's and which a pack's.
  • Owen's own words: "</> could end the relevant tag".
  • A named closer (</draw>) is allowed anywhere, and checked.
  • The editor shows what each </> closes, faintly, after it; it keeps the indent right (Q7).
  • Spellx has no fragments; a drawing may draw several things.
  • Plain JSX; longer, and Owen already writes the short form.
  • </> closes whatever tag is open innermost, components too.
  • A named closer is checked; the editor labels every </>.
 
<spell-test "card setup">
	get a new card whose rank is queen, suit is spades and direction is down
	echo "testing the " + its name
</>

<spell-phrase name="is a face card">if its rank is jack, queen or king</>

Choices

A · Anywhere, for Spell's own tags; never for markup (recommended)

  • It closes the nearest open Spell tag. The editor keeps indentation right (Q7), so what it closes is always plain.
  • In a drawing's markup (<ui-text>), a closing tag is written out, as JSX does: there </> already means a fragment.
  • The writer writes the full closing tag on long members, and may write </> on one-line bodies.

B · Anywhere, markup too

  • Cost: clashes with JSX's fragment, <>...</>.

C · Never: always the full closing tag

  • Plain JSX; longer, and Owen already likes the short form.
  • </> closes the nearest open Spell tag; markup's closing tags are written out.
