Choices

A · Tags in drawings, spell lines in actions (recommended)

  • A drawing is markup, so its choices nest like markup and close with </>; an action reads as steps.
  • A spell if line in a drawing is read too, and spell lint --fix rewrites it as a tag.
  • Both write the same code spell line, if it is a face card.

B · Spell lines everywhere

  • One way to write if; Q14 stands as it is.
  • Cost: in a drawing, only the indent shows where a choice ends.

C · Either, anywhere

  • Nothing to learn twice, but two spellings of one thing in every file, and the writer must pick one.
  • drawings choose with <if …>…</>, <otherwise>, <for each …>
  • actions keep spell lines; both compile to the same code spell
