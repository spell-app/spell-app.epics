For I1 in P2. A View subclass defines its own element as it's declared (<solitaire-card>); an App would get <solitaire-solitaire>, which nothing places.

  • So App extends View (its drawing, parts and css work as any view's), but skips defining an element: it's mounted by <spell-viewer> / core.mountApp(), as today.
  • The other way, an App element <solitaire-app> that the viewer places inside itself, is possible later; it adds a second element per page for no gain now.
