1. In Chrome, open the Counter notebook: 
    http://localhost:3000/run/@spell/notebooks/Counter
  2. Under "Try it", click the counter button a few times.
  3. Under the counter template's example, click its </> button to open its code. There's no Edit button: the opened code is always editable.
  4. In that code, change Clicked to Pressed, and watch the page, and the program pane's header, as you type.
  5. Reload the page (⌘R).
  6. In VS Code, open Source Control (⌃⇧G) and click Counter.spellx in its list.
  7. Back in Chrome, open one counter's code (its </>), click html in its own switch, beside its code, and change a word in it. Then click spell in the same switch, and try to type.
  8. Click the lock icon in the program pane's header, about 40px after the title (the title is a menu of the project's notebooks). Change any text in an example's code, then click the small Reset beside that example's code switch. Change it again, then reload (⌘R).
  9. Click the lock again to unlock it, and change a word in any example's code.
  • Step 2: the button counts its clicks.
  • Step 4: the example redraws as you type; nothing else on the page moves or flashes. The header says "Saved" for 15 seconds, then it fades.
  • Step 5: it says Pressed.
  • Step 6: the diff shows only that one line changed.
  • Step 7: the html view shows <ui-button>; your change redraws the example above it, and the header says "Saved". The spell view is read only: typing does nothing.
  • Step 8: the header says "Locked: changes aren't saved"; your edit draws, Reset puts the code back as the file has it, and after the reload your edit is gone. Source Control shows no new change.
  • Step 9: the edit saves again: the header says "Saved".
