If spellx drops its prefixes (Q45), the word section means two things inside one drawing:

  • Spell's own: a place in a view's drawing that a subclass fills, as the two sided view's front and back (Q15, approved as <spell-section "front"/>).
  • Spell UI's ui-section: a titled block that folds away, one of the components people draw with most.

Both appear inside a drawing, so "context decides" can't tell them apart. One of them needs another word.

Now: Q37 makes the tag that places a view's named part a short word, and Q46 makes <section> Spell UI's folding block (ui-section). Both live inside a drawing, so <section "front"/> can't tell them apart. Which word places a named part? 

<spell-view "two sided view">
	<draw>
		<if it is face up>
			<draw "front" />        <!-- no body:  draw the front here -->
		</>
		<otherwise><draw "back" /></>
	</draw>
</spell-view>

Changed: this was asked "if spellx drops its prefixes"; with Q37 and Q46 it's live either way. Q15's approved <spell-section name="front"/> would have become <section>.

  • <draw "front">…</> defines it; <draw "front" />, with no body, draws it here.
  • No new word, and it reads as what it does. Code spell: - to draw its front: and draw its front.
  • ui-section was renamed only days ago (property-editor P10); every page using it changes again.
  • A slot holds children an outsider puts in; front and back are drawn by the subclass, so it says the wrong thing.
  • A view's named part is <draw "front"> to define, <draw "front" /> to place.
  • <section> is always Spell UI's folding block; Q15's section= attribute becomes the draw's name. 
<view "two sided view">
  <draw>
    <if it is face up>
      <section "front"/>      <!-- Spell's place?  or a folding block? -->
    </>
    <otherwise>
      <section "back"/>
    </>
  </>
</>

Choices

A · <draw "front"/> places a named drawing (recommended)

  • <draw "front">…</> defines the front; <draw "front"/>, with no body, draws it here.
  • No new word: draw is already reserved, and it reads as what it does.
  • <section> stays Spell UI's folding block everywhere.
  • Code spell: - to draw its front: and draw its front, as today.

B · Keep <section>, rename Spell UI's

  • ui-section becomes something else (ui-fold?).
  • Costs: it was renamed only days ago (property-editor P10), and every page that uses it changes again.

C · <children "front"/>, drawable-thing's slot word

  • Reuses today's word for a named slot (<children name="header"/>).
  • Costs: a slot holds light-DOM children an outsider puts in; front and back are drawn by the subclass, so the word says the wrong thing.
  • Q15's <spell-section "front"/> becomes <draw "front"/>.
  • <section> is never a Spell word: it's always Spell UI's folding block.
