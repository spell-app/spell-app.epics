Choices

A · Every tag with a name may use it; the writer always writes name= (recommended)

  • One rule: a bare quoted string first is the name.
  • Files Spell writes (.spell to .spellx) say name=, so they read the same everywhere; a person may type the short form.

B · Every tag, and the writer uses it too

  • Shorter files everywhere.
  • Cost: farthest from JSX; an agent copying HTML habits writes name= anyway, so files mix.

C · Only tests

  • A test's name is a sentence, which reads oddly as an attribute; every other name stays name=.
  • Cost: one more exception to learn.
  • <spell-test "card setup"> and <spell-test name="card setup"> mean the same; so do every other named tag's two forms.
  • Spell's writer writes name=.
