• No attributes: an empty block, so what follows starts on a new line, as <br> did. In a stack or a row it is an item with no size (the stack's own spacing still falls either side of it).
  • height without inline: a block that tall, a blank band between lines.
  • inline: a gap inside the line instead, a space's width (0.25em) unless width says.
  • Not done: making a bare space force a new line inside a WRAPPING row (that needs to know the row's direction).
