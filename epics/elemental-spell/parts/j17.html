Your note: "what kind of classes? Javascript classes or CSS?"

JavaScript classes: Spell's runtime templates, the ones a compiled module can extend or make (Thing, List, App, View, ViewableList, Page, TwoSidedView). Nothing to do with CSS.

  • core (the runtime's helpers) and h (what draws markup) always stay in the import.
  • E.g. a module with only a card: import { core, View, h } from "@spell/core".
