A .spellx file can only be edited as text.

The editor shows it as a notebook: prose drawn, chunks as cells.

A property chunk opens a property editor.

  • prose cells drawn as markdown; each chunk a cell that folds, edits in place and moves (Q60)
  • a <property> chunk opens a property editor: its name, one-of values, aliases and body
  • every edit writes back into the file's text at the chunk's place, from the match tree (Q69)

Q69 A: no span map any more: each chunk's place in the file comes from the match tree, so an edit in a cell or a property editor is written at that chunk's place in the text.
