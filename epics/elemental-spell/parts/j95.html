Solitaire, TaskList, tic-tac-toe, Solitario and ListaDeTareas each have a .spellx twin beside every .spell file, made by spell spellx convert (J54, J55).

  • The project file lists only the .spell files, which the app opens.
  • The pair test reads each twin by name (Card.spell => Card.spellx beside it) and parses the twins as a project of their own.
  • The project's index used to add any new file in its folder as an import, and saved the project file, which declared everything twice. Now a .spellx whose .spell is beside it is never added (isSpellxTwin() in project-utils). It stays in the file list, so the editor shows it. A .spellx with no twin is added as before.
  • The CLI's project picker lists the twins too (since P8): its test now expects them.
