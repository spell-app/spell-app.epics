Q71's library of built-in templates: spell-parser/src/core/templates/TwoSidedView.spell (and TwoSidedView.es.spell), compiled by yarn core:gen:templates.

  • In core, because the class they compile to is core's; the generator in spell, because core never imports spell -- the .spell files are data to it.
  • Output: the class into the JavaScript core (classes/TwoSidedView.ts) and Python's (spell_core/two_sided_view.py), every language's declarations into src/spell/builtInTemplates.generated.ts. A test fails while they're stale.
