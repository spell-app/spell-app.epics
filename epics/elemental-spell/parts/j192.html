It's a LoadableComponent, so source, load, loaded, reload() and save() are <ui-code>'s. It draws nothing and overrides the loader and the error message; since nothing would show a failure, it warns in the console as well as sending ui-error.

A parent that reads it hears of a change through a small untranslated event, as ui-changed's name differs by language (es-cambiado). JsonChild holds the reading, a leaf of the family; only <ui-tree-diagram> reads JSON children today, since no other family took a JSON script child (ui-form doesn't).
