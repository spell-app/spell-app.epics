A .spellx file can be read, but not compiled or loaded in a project.

Each .spellx file is written into .spell text with a span map, then compiled as today.

Projects, the CLI and the page server load .spellx.

  • .spellx → .spell → JS (Q10): exact that way, with a span map back (Q11)
  • errors land on the .spellx line
  • Spanish .es.spellx files too
