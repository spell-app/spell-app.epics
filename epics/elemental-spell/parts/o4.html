A .spellx file never compiles by itself: it is written into code spell first.

  • Our own reader turns the file into a tree of chunks (P3).
  • A writer turns the chunks into .spell text, exactly, with a span map pairing each piece of the two files, then today's compiler takes over (P6; Q10, Q11).
  • The span map is what keeps errors, hover and the notebook's edits on the right .spellx line (P8, P11).
  • The other way, .spell to .spellx, is a one-off converter that lays the file out afresh (P12; Q19).
  • Last, standard source maps in the build folder chain through the span map, so a runtime error names the .spellx line (P14).
