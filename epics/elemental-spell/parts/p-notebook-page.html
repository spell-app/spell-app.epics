A notebook becomes a Spell template, <spell-notebook>, a subclass of page: its body a drawing with markdown prose and live <example>s, edited in place from a toolbar, each cell saved and redrawn on its own. Built first on a small Counter notebook.

  1. The <spell-notebook> template.
    • notebook is a built-in template, a subclass of page, written in Spell like the two sided view (Q71); English <spell-notebook>, Spanish <encanto-cuaderno>
    • it draws the page: the title, the sections from its ## headings, the prose, the examples
    • it holds its own templates (the counter), as an app holds its own
    • <example> is a new chunk tag (Spanish ejemplo), with its code spell twin (an example "one counter":), read and written by P3's reader and P12's converter, so .spell and .spellx stay equal
    • the body is a drawing: drawing tags draw where they sit; loose text is markdown, broken into sections at ##; a tag in the middle of prose ends one block and starts the next
    • an example is always WRITTEN in spellx; its html view is made by the same mapping P6 compiles with (each pack's catalog), an html edit mapped back into spellx before it saves, and markup with no spellx form kept as written and marked
    • Files: spell-parser's Notebook.spell (and its Spanish twin), the example rule in src/spell/ and src/spellx/; then yarn core:gen:templates
  2. Drawing it.
    • a Spell page run by <spell-viewer> at the app's own address, /run/@spell/notebooks/Counter
    • a masthead (the title and first paragraph); each ## section a sticky, folding <ui-section>, in a table of contents on the right
    • each example: its title, its live result (its body compiled as a drawing, mounted on its own, so it re-renders alone), its code in Monaco, read-only until edit mode
    • Files: spell-app's spell-notebook element (masthead, sections, table of contents, example frame), and its App UI docs page
  3. Edit mode: the toolbar and Monaco.
    • a sticky toolbar at the top: Edit (a pencil, toggled); Add (Example, Text, Section, Template, after the selected cell); Delete, Move up, Move down (⌘Z undoes each)
    • Show code as spellx / html: one switch for the whole page; each example's own switch flips the page's and every example's; remembered per notebook across reloads
    • Lock (admins only) and Try as a visitor
    • a click selects a cell: a focus ring, and the toolbar acts on it
    • Monaco is spell-app's own (LazyMonaco), one per open example, with spellx colouring (T50); the html view colours as HTML
    • Files: NotebookToolbar.tsx, NotebookCell.tsx in the spell-notebook element
  4. Saving, cell by cell, with no flash.
    • an edit changes only its cell's span of the file (P11's span-exact edits); re-indenting the edited cell is fine, the rest left byte for byte
    • it saves 600ms after the last keystroke, through the spaces API the editor saves with
    • only the edited cell re-renders: its text compiled ON ITS OWN, SP.SpellProject.compileChunk(text, { into: project }), which reparses just that chunk into the notebook's project; a template edit re-renders the examples using it
    • a broken edit keeps the last good result, marks the code red, and shows the error's line under it
    • a change from outside (another tab, an agent) goes through ONE mechanism with epic-engine's: 's planner over any keyed tree; this phase writes the chunk-tree adapter (cells keyed by place) and a runner that re-renders cells
    • steps 1-3 and the notebook's own edits don't need P40; this step waits for P40 to merge (which needs Owen's Accept on epic-engine's page)
    • no ids written into the file: cells are found by their place in the chunk tree
    • Files: spell-parser's SpellProject (compileChunk()); spell-app's NotebookCells.ts, moved beside the notebook
  5. Locked notebooks.
    • <spell-notebook "..." locked>, saved in the file
    • whoever can write the file saves (today, the page server lets Owen); anyone else edits as a try-out, gone on reload
    • the toolbar says which: "Your changes are saved" / "Trying it out: changes aren't saved"
    • Try as a visitor lets an admin see the locked side; people's roles in spaces can replace this later
  6. The Counter notebook.
    • Counter.spellx, in a new project group, @spell/notebooks: a counter template, "Try it" with one counter, "Two of them" with two in a section
    • the editor app opens it as text too, and spell spellx convert gives its .spell twin
    • the .spell / .spellx pair test covers it
