• A pane, step or section can be written as a flat sibling anywhere on the page, naming its container by id with parent="<id>".
  • It joins that container in page order, as if it were nested there.
  • Nested markup keeps working unchanged.
  • Why: flat files are easier to write and diff, and the notebook (P16) can add, move and delete cells without re-nesting markup.
  • Scope (Owen: "tabs, steps, section for now"):
    • <ui-tab parent> joins a <ui-tabs>
    • <ui-step parent> joins a <ui-steps>
    • <ui-section parent> nests under another <ui-section> (or joins a <ui-sections>)
    • Others (ui-item in a menu, options in a select) are later.
  • The value is a bare id, parent="types", not #types; the container is written <ui-tabs id="types"></ui-tabs> (it can't self-close in HTML).
