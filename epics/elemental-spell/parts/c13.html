Declarations are built now, not committed. In a fresh checkout, VS Code's language server shows "compile it first" for a project that imports one nobody has compiled yet.

  • The page server compiles @spell/examples and @spell/library as it starts, and builds any built file a page asks for.
  • Every spell command compiles a parsed project's never-compiled imports first.
  • So it shows only for an import outside those, before anything compiled it: spell compile <import> fixes it. P7 (editor and language server) can make the server do the same.
