Spell's events are JavaScript's: they bubble by default, input state is only readable inside a handler, and nothing cancels or passes.

Events become Owen's: send, pass and cancel; on, when and while handlers; input state readable anywhere.

The phase starts with a table of every event.

  • the table of every event first (T2): its name, when it's sent, who gets it, whether it can be cancelled, its parameters
  • send you can await (Q28); pass event; cancel event (Q27); an event nobody catches is dropped (Q29)
  • <on …>, <when …> and <while …> (Q42, Q51, Q52)
  • target, the original target, sender and parameters (Q26)
  • the keys and the mouse readable anywhere: the meta key, the three buttons, mouse still down, enter and leave (Q31, Q32); right and center click (Q30)
  • which action gets a shared key: focus for keys, the thing under the mouse for the mouse (Q35)
