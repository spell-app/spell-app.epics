A drawing is markup written in Spell's own words, with no native HTML (Q46).

  • A bare name, <button>, is the app's own template or a component from its packs.
  • Tags branch: <if>, then <otherwise> (Q43, Q53).
  • A self-closing draw tag places a part: <draw "front"/> (Q55).
  • What Spell UI still lacks next to HTML is the sibling epic ui-gaps (Q50); whether a drawing may name a native element after all is J83, open. Built in P7.
