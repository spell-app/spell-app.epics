Q42 settled that <while …> undoes its effect when its condition stops holding. What exactly is undone?

Each property the body set returns to its value from before. The runtime is reactive, so it can record the old values as the body sets them.

It is a reactive <if> for markup: what it shows goes away; properties it set stay set.

An <after> block inside it runs when the condition stops holding, like <otherwise> for time.

A LOOP while the mouse is down is a different thing: <repeat while the mouse is down> (HyperCard's), not <while>.

  • <while> is a temporary state: whatever it changed is put back by itself.
