C28: several drawn lines, loops and ifs in one drawing compile to ONE return [ ... ], in order (DrawnLines.gather()): markup lines one after another spread from their fragment, a loop is its core.map(...), an if among them a cond ? a : b (null when no branch is picked).

  • A line that draws nothing AFTER a drawn one (set its moves to 1 between two markup lines) is moved before the return: the drawing is made once and returned at the end, so nothing could run after it.
  • The other way, an accumulator (const drawing = [], a push per line), handles every shape but reads worse in the compiled code; the list form is what Solid takes anyway.
  • An if ALONE stays an if, each branch returning its own drawing (as before).
