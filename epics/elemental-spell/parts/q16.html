Owen's card uses <spell-view name="playing card" template="two sided view">. Following his new words (Q17), one tag per kind: 

<spell-template name="deck" template="list of cards">          a template that isn't drawn
<spell-view name="playing card" template="two sided view">      a view:  drawn on the page
<spell-page name="scores" template="page" url="/scores">        a page:  a view with an address
<spell-app name="solitaire">                                    an app:  a view you publish

Recorded: template= names the parent, and the tags are yours. Here is the whole model in one table.

Tag What it makes Code spell it becomes
<spell-thing name="deck"> a template with no look of its own, still reactive a "deck" is a thing
<spell-view name="card" template="two sided view"> a view's template a "card" is a two sided view
<game-card>, <ui-button> one card, one button: a thing made from a view, by its own tag (library, then name) a new card; in a drawing, the same tag
<spell-page-template name="score page"> a page template a "score page" is a page
<spell-app-template name="card game"> an app template a "card game" is an app
<spell-page name="scores"> one page, on the default page scores is a page where:
<spell-app name="solitaire"> one app, on the default app solitaire is an app where: (as today)
<spell-page name="high scores" template="score page"> one page, from a page template high scores is a score page where:
  • The one gap you named: a view's template is <spell-view>, a page's and an app's are -template.
    • It has a reason behind it: the short tag goes to what people write most. Views and things are almost always templates; pages and apps are almost always one of a kind.
    • If it ever grates, a one-of-a-kind view could be <spell-view name="board" one>, rather than a fourth long tag. Not needed now.
  • The <spell-viewer> rename touches spell-app's runtime element (its vocabularies, SpellElement, the editor's APP_TAG, the server's project files), every page and README that runs an app, and 6 guides: about 59 files in the repos.
    • The repo's own name, spell-app, stays.
