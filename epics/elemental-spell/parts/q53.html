Owen, 2026-10-24, on Q43: "also will need <otherwise|else> and <otherwise|else if ...>. That should continue the previous <if> if that was not explicitly terminated."

  • Each <otherwise …> starts a new branch and ends the one before.
  • One </> closes the whole chain.
<if the card is red>
	<text color="red" />
<otherwise if it is a face card>
	<image "face" />
<otherwise>
	<text />
</>
