An action is a described command (Q33): it has shortcuts, and says when it's enabled and when it's selected. What are those attributes called, and how is a key written?

Shaped by: Q33 (an action is a described command), Q31 (meta is command or control), Q6 (attributes may repeat), Q37 (inside a template, the short word <action>). 

<spell-app name="solitaire">
	<action name="start a new game" shortcut="meta+N">…</action>
	<action name="undo the last move" shortcut="meta+Z" enabled-when="it has moves">…</action>
	<action name="show the timer" selected-when="its timer is shown">…</action>
</spell-app>

Nothing dropped: Q37's answer only shortened the tag.

  • shortcut= repeats for a second key: shortcut="meta+N" shortcut="F2".
  • The -when values are spell, read as yes or no.
  • Spanish: atajo="meta+N", activa-cuando="tiene jugadas".
  • Reads as words, and translates; longer, and unlike every other app's docs.
  • Room for a long condition; three lines for a one-word shortcut.
  • shortcut="meta+N", repeatable; enabled-when= and selected-when= hold spell.
  • Code spell's form for it (- to start a new game, on meta+N:) is settled in the events phase.
 
<spell-action name="start a new game" shortcut="meta+N">
<spell-action name="undo the last move" shortcut="meta+Z" enabled-when="it has moves">
<spell-action name="show the timer" selected-when="its timer is shown">

Choices

A · shortcut=, enabled-when=, selected-when=; keys as meta+N (recommended)

  • meta is command on a Mac and control elsewhere (Q31); shift, option, control as named.
  • shortcut= may repeat for a second key (Q6): shortcut="meta+N" shortcut="F2".
  • The -when values are spell words, read as yes or no.

B · Spell words for keys: shortcut="meta key and N"

  • Reads as English, and translates.
  • Cost: longer, and a key list nobody can copy from another app's docs.

C · Child tags: <shortcut>meta+N</shortcut>, <enabled-when>...</enabled-when>

  • Room for a long condition on lines of its own.
  • Cost: three lines for every one-word shortcut.
  • shortcut="meta+N", repeatable; enabled-when= and selected-when= hold spell.
  • Code spell needs a form too, e.g. - to start a new game, on meta+N:; settled with the events phase.
