P2 renamed the page element, its class (SpellViewer, DOMSpellViewerElement), folder, vocabularies, docs page, demo page and its script (/element/spell-viewer.js). These kept spell-app, on purpose:

  • SpellAppRunner and its family (SpellAppSource, SpellAppToolbar, the .SpellApp CSS class): it runs a Spell App, the new word, and VS Code's runner uses it too, not only the element.
  • spell-app.css: the element build's ONE sheet, gathered from every element in it, so it's the package's, not the viewer's.
  • #spell-app-root (where an App draws), spell-app:theme (a saved preference: renaming loses it), data-spell-app-fonts, Symbol.for("spell-app:spell-elements"): namespaced by the package.
  • <spell-app> as a placeholder for a checkout's path (README-vscode, spell-epic's AGENTS.md, a demo script's usage line).
  • History: the changelog and epic pages keep <spell-app>; present-tense guides were updated.
