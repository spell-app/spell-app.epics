The editor and VS Code treat a .spellx file as plain text.

Colouring, errors, hover and completion work in .spellx, through the span map.

The editor keeps the indentation, adds Spanish accents and rewrites HTML habits.

  • open Card.spellx: coloured, with errors on the right line, hover and completion
  • indentation kept as you type, or at least on save (Q7); Spanish accents added (Q49)
  • HTML habits (<ui-button>, on-click=) rewritten by spell lint --fix
  • a switch to see the .spell a file becomes

spell-app's language server (lsp/SpellLanguageService.ts, SpellLanguageServer.ts), the editor's Monaco language (SpellMonaco.ts, SpellTokensProvider.ts); the VS Code extension's language contribution and a spellx grammar.
