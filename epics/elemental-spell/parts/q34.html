Owen, 2026-10-24: "Need a JSX-ish way to e.g. embed actions in a menu or toolbar ... the GameMenu can be used to add the entire menu to a toolbar, app-level dropdown menu, context menu, etc".

  • A named menu is a list of actions, built once and reused in a toolbar, the app's menu bar and a context menu: 
    <ui-menu name="GameMenu">
   <ui-action name="foo" target={game}/>
</ui-menu>
  • Today Spell UI has <ui-menu> (a nav menu, or an application menubar of <ui-item>s) and <ui-toolbar> (a <ui-menu> that scrolls sideways); <ui-action>, an item drawn from an action, is new. (<ui-actions>, a modal's row of buttons, is something else.)
