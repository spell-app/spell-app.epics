The significant gaps, most needed first

Ten, by size: S about an hour, M a few hours, L a day or more.

  1. Table rows and cells (M): a table built from components, header row and caption included, ideally filled from a list of things. ui-row and ui-column are the grid's, so the names need care.
  2. A plain layout box (M): lays its children out in a row or a column, with gaps, alignment and wrapping; no look of its own.
  3. A link in running text (S).
  4. A paragraph (S): a block of text with holes for values.
  5. Inline styles (S): bold, italic, inline code, key caps, a highlight; as ui-text attributes or a few small tags.
  6. A page frame (M): header, footer, main and side regions, with the landmarks screen readers use; the never-built <ui-page>, drawn by a Page template.
  7. A drawing surface (L): shapes and a canvas, for games and charts.
  8. Video and audio (M): the app's own files, with controls.
  9. A term and value list (S): "Suit: hearts", a thing's details at a glance.
  10. A figure with a caption (S).

Minor, left for later: quotes, sub- and superscript.

Words both spellx and Spell UI want

Q45's structure words are reserved. Most never meet a component; these do.

  • "Context decides" means the tag's place says which.
  • Inside its owner (a card, a feed), the tag is the component.
  • Everywhere else, it's Spell's word.

Choices

A · Build the gaps as Spell UI components, in a sibling epic (recommended)

  • The ten gaps become components, each with its docs page and its Spanish words, in an epic of their own.
  • Spellx's reader, writer and code-spell work go ahead here; drawings use what Spell UI has.
  • A gap's name is known ahead: using one before it lands says "coming: tables" rather than "unknown tag".
  • Cost: about 5 small, 4 medium and 1 large component; roughly 20-30h.
  • Day one: everything Spell UI has today, about 120 tags.

B · Build them inside this epic

  • One epic owns the language and the components it needs.
  • Cost: this epic roughly doubles, and component work waits on language reviews (or the other way round).
  • Day one: the same as A, later.

C · Start with what Spell UI has; gaps are errors until each lands

  • No plan for the gaps: each is built when someone needs it.
  • Cost: nothing now, but tables and links block real apps on day one.
  • Day one: the same as A, with no end in sight for the gaps.
  • A sibling epic for ten components, tables, a layout box and links first.
  • This epic's drawing reader knows their names and says which are still to come.
  • <section> stays Spell UI's; a view's named part gets another word (Q48).
  • Five shared words (description, comment, event, property, action): context decides, by the tag's owner.
