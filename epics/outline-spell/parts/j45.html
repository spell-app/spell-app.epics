What can be clicked looks clickable by itself: Spell writes an inline style on it, not a stylesheet rule.

  • Anything in Spell's markup with an onClick gets style="cursor:pointer;user-select:none": a pointer, and its text can't be selected.
  • Inline, so it works in every target (JavaScript, TypeScript, Python) and inside every shadow root, where a page's stylesheet doesn't reach.
  • An element that says its own style keeps it: Spell adds nothing.
  • It's written compactly, the way Solid's compiler writes styles, so all three targets draw the same.
  • So the cards' hand-written cursor in Solitaire's styles is gone.
  • Every onClick in a program shows a pointer, with no CSS written.
  • To get a different look, give the element its own style.
