What could make the outline worse than today, and what guards against it.

  • More magic, more guessing. Each left-out word is a guess the parser makes.
    • a wrong guess is a program that reads right and does something else
    The spell goals already name this: risk R1 in the syntax goals (syntax.md), "ambiguity grows with vocabulary".
    • guard: a guess only when exactly ONE answer fits (one property of that kind); two fit → an error saying which two
    • guard: hovering a line shows what it was understood as, in the long form (a card "is a (suit)" for its suits)
  • Error messages. Lauren will see "Don't understand" on a line that looks fine to her (risk R3). The outline makes this worse, since more is left out.
    • guard: outline errors name the rule they nearly matched ("a property needs its: its “rank” is ...")
  • "English-like" has a bad name (AppleScript, COBOL; the programmers goals). An outline reads more like a spec than a novel, which helps.
  • Two styles to keep working, if both stay (Q1): every rule is tested both ways.
  • a phase for the editor's side: "understood as" hovers and outline-aware errors
