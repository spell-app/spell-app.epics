In a type's body a property still needs its quotes or its its.

  • - suit is a suit of its deck is "Don't understand"
  • - x is 1 quietly sets a variable beside the class

Directly in a type's body, any bare name declares the type's own property or getter (T8, point 2, option A).

  • guard: a line starting with a statement's first word stays that statement
  • guard: a getter that never reads it warns
  • A property:
    • - suit is a suit of its deck
    • - score is a number
    • - face is up or down
  • A getter: - state is: with a block under it, or - name is: its rank + ....
  • are as well as is: - foundations are a list of piles.
  • - if x is 1 stays an if: a line starting with if, set, for, return ... is never a name; a property named so keeps its quotes.
  • - score is 0 warns: "score is always 0: did you mean a number?"
  • A kind keeps its quotes: - "suits" as one of clubs, ...; a bare suits as one of ... stays an error.
  • Only directly in a body: inside a getter or method there, total is 0 still sets a local, and outside a body nothing changes.
  • Setting a variable from a body line is set x to 1, written in the outline guide.
