A tableau's layout is fixed by its type, so a page that tries to change it is undone at once.

  • The type says - its layout is vertical, which compiles to a getter (J41): there is nothing to write to.
  • In the browser, setting layout="fanned" on a tableau's element is undone straight away: the element shows the thing's value, vertical, again.
  • Before this phase, the page threw instead; now it just shows the value again.
  • A fix: a starting value instead of a getter, so the line gives the first value and the page may change it. That's a language change, for later.

Net effect (once fixed):

  • a tableau (or any pile whose kind states its layout) could be switched to fanned or horizontal from the page
