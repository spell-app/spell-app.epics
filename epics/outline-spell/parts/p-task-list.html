The Todos example was written in Spell's old style, one long sentence per fact, in one file.

Rewrote it as the Task List, renamed: the outline style, Spell UI's controls, and a property editor.

  • @spell/examples/TaskList: a task, the list and a stylesheet, each its own file; Lista de tareas is its Spanish twin.
  • A task is a drawable thing: a title, notes, a priority and whether it's done; a checklist shows all, to do, or done.
  • A task can be selected: a click selects it, shift a range, command one more; the selection of the tasks is what's selected, which Spell reads on the page.
  • The property editor edits every selected task at once.
