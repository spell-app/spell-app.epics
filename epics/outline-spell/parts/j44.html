The drop event's name comes from a core message in each language, so it reads right in Spanish too.

  • The message is drop-event, in the drawing core's messages.
  • English: card-drop, so the game writes on card drop with a card and a pile.
  • Spanish puts the verb first: soltar-carta, so Solitario writes al soltar-carta con una carta y una pila.
  • Its details name the thing by its type and the list by each of its types, e.g. { card, tableau, pile }, so a handler can ask for a pile, or a tableau.

Since J49, a list's - when a card is dropped on it: takes the place of this event; Solitaire and Solitario use that.

  • One new core message, drop-event, in English and Spanish.
  • A third language adds its own wording there; nothing in the page changes.
