A capital typed by hand changes what a line means, with no warning. Found answering T1 (typographic marks).

  • values already ignore case, but properties, variables and type names do not
  • and reading a name nobody declared is not an error
  • its Rank is 1, on a card with a rank: compiles to this.Rank === 1, always false
  • print the City, after the city is "Paris": compiles to City, which fails when it runs
  • a CARD has a value as a number: adds the property to a class called CARD that does not exist
  • the Rank of a card is 1: declares a SECOND property, Rank, beside rank
  • by contrast, its suit is Clubs finds the value clubs, and a Card finds the type Card
  • fix: a name that matches a declared one except for case is that one (or a warning naming it); a first letter capitalised at the start of a line, as T1 allows, then needs nothing more
