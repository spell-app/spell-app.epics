The fix for stray getter lines (I9) covers both of a getter's line shapes, not only the one the issue named, and its message says where the line belongs.

  • both shapes are refused outside any getter or method, since each compiled to a return with no function around it:
    • red if x is 1 (value_if)
    • black otherwise (value_otherwise)
  • the message: A line of a getter's body: put it under one, e.g. "the color of a card is:"
  • the check walks up from the line looking for a method's scope (refuseOutsideMethod()), so a method's body counts too, not only a getter's
