Does the outline style sit BESIDE today's sentence style, or replace it? "Today's style": one statement per line, each naming its subject (a card has a suit as one of ...).

A · Both, same meaning (recommended)
  • every outline line is shorthand for a long-form line; both compile to the same code
  • hover shows the long form, so the outline teaches the long form
  • existing projects keep working untouched
  • cost: every new rule tested both ways
 B · Outline only
  • one way to say each thing (the spell goals' Q2, "how many ways to say one thing?")
  • cost: every project and example rewritten; method bodies (loops, if) still need sentences
 C · Outline for definitions, sentences for actions
  • types are always outlines; to ... bodies stay sentences
  • cost: the old a card has ... lines become errors; a migration

Net effect (A):

  • no project breaks; Card.spell and the outline cards (1.6) compile to the same code
  • a later epic can retire the long form if the outline wins
