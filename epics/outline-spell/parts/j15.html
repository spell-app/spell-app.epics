The list guards got an it form too, not only a form without a subject. Before P8 they had neither: in a list type's body only the full sentence worked. 

a pile is a list of cards where:
	- it can take a card if: it is empty
	- can give up a card if: the card is its last card
a stock is a list of cards where:
	- it can never let go of a card
	- can never let go of a card
  • Why: the phase's goal says "both styles give the same output"; a guard with only one style would be the exception.
  • Cost: 3 more syntaxes, each rejected early outside a list type's body.
  • The tests compile both against the sentence style: the same JavaScript.
  • - it can take a card if: ..., - it can give up a card if: ... and - it can never let go of a card work in a list type's body
  • and the same three without it
