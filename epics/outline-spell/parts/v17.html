1. In VS Code's main window (the kit's, spell), open the Explorer (⇧⌘E) and open any file in spell-app/spaces/@spell/examples/Solitaire/.
  2. Open the Command Palette (⇧⌘P) and run: 
    Spell: Run Project
  3. Wait for the game to show in the Spell panel.
  4. On a touch screen (an iPad, or a laptop's), or in a browser's device mode (Chrome: ⌥⌘I, then the phone-and-tablet button, ⇧⌘M), with the game open in the page server's run page.
  5. Drag the discards' top card with a finger onto a column that takes it.
  • The card follows the finger; the page doesn't scroll.
  • It lands on the column.
