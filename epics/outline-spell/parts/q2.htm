How text says "put a value in here": "images/(rank)-of-(suit).png" (1.5). Owen wants no curly braces; Lauren is happy with ( ) or [ ].

A · ( ) around a known name (recommended)
  • "(rank)-of-(suit)" fills in; "Draw a card (any card)" stays as written, since any card isn't a name the parser knows
  • matches quoted phrases' slots: "is a (suit)"
  • cost: a name added later can change old text; the editor colours fill-ins, so it shows
 B · [ ] always
  • "images/[rank]-of-[suit].png": no guessing, and brackets are rarer in text
  • cost: a second "fill in" mark beside the phrases' ( ); a literal [ needs an escape
C · ( ) always
  • simple rule: every (...) in text is an expression
  • cost: every literal parenthesis needs an escape; existing strings change meaning

Net effect (A):

  • the text rule builds a template when a ( ) holds a known name, in strings and markup
  • anything bigger than a name still uses markup's {...}
