Found while writing J3's details (2026-10-06). Spell finds every type a project declares BEFORE it parses (so a line can name one declared further down), with a scan, SpellParser.TYPE_DECLARATION. That scan doesn't allow quotes, so a "card" is a thing isn't found ahead.

  • fails: it is a card on a line ABOVE a "card" is a thing: "Don't understand"
  • works: the same with a card is a thing
  • fix: let the scan's pattern take "card" (and 'card'); one regex, plus a test
  • a quoted type name behaves exactly like an unquoted one, wherever it's used
