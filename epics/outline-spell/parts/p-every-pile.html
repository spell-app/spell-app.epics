The Solitaire kept a list of its own, all-piles, and added each pile to it by hand, only to go through every pile.

Added every pile: every pile the program has made, of any kind, in the order made; all-piles went.

  • every pile holds sub-types too, made fresh each time it's read, and typed a list of piles so the editor knows each item.
  • A test's own piles and quiet scratch lists aren't in it.
  • It compiles to core.everyThing(Pile), in Python core.every_thing(cls).
  • Only every pile: no all the piles.
  • Committed with P15, P17 and P18, as 981dda5e.
  • Where to see it: the outline Solitaire's Solitaire.spell has no all-piles list any more. It reads every pile in three places:
    • its state: for each pile in every pile
    • its deal: set cards to merge every pile into a new pile
    • a card's play: the first pile in piles in every pile where its droppable is yes ...
  • every pile is a list of every pile the program has made, in the order made.
    • sub-types too: the stock pile, the discard pile, the foundations and the tableaus
    • made fresh each time it's read, so a pile made later is in the next read
    • it's a scratch list: it takes none of the piles out of the lists that hold them, so the foundations stay in the solitaire's foundations
    • typed a list of piles, so the editor knows each item is a pile
  • Not in it:
    • a pile a to test ... method makes
    • a scratch list made quietly, e.g. the new pile in merge every pile into a new pile
  • How it compiles: every pile is core.everyThing(Pile).
    • the rule, every_thing, reads every and a known type
    • core's everyThing() reads the program's things, as the first tableau does
    • Python the same: core.every_thing(cls)
    • core's method list regenerated, so every project's declarations list it
  • all the piles wasn't added: every pile only (J32).
  • Tests: a new case in outline.test.ts runs a pile and a tableau, then checks what each list holds.
    • every pile: both, in order
    • every tableau: the tableau
    • it runs with its things registered, as a running program's are: a new option of the test helper
    • no case yet for a test's own piles being left out
  • Not tried by hand in the app: the hand test, T9, covers it with P17 and P18.
