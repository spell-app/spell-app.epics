1. In VS Code's main window (the kit's, spell), open the Explorer (⇧⌘E) and open any file in spell-app/spaces/@spell/examples/Solitario/.
  2. Open the Command Palette (⇧⌘P) and run: 
    Spell: Run Project
  3. Wait for the game to show in the Spell panel.
  4. Try the three tests above in it: widen the panel, click the stock, play a card.
  • Solitario draws, glides and shows its placeholders just as Solitaire does.
