A method in a type's body that names no type, like - to reset:, compiles to a loose function with no error or warning, and that function reads this, which is nothing when it runs. Found 2026-10-19, while building P15.

  • e.g. in the solitaire's body: 
    a solitaire:
	- to reset:
		set its score to 0
  • it reads as the solitaire's own method, but it isn't one: reset the solitaire doesn't reach it
  • its score inside it compiles to this.score, in a function with no this
  • the method that works names its type: - to reset a solitaire:
  • likely fix: in a type's body, a method that names no type is that type's (as a property line leaves out its); or, at least, a warning saying to name the type
  • once fixed: - to reset: in a solitaire's body is the solitaire's method, or warns
