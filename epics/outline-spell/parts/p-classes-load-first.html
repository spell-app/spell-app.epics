With the kinds of pile at the end of Solitaire.spell, the table above them made a stock pile before its class existed, so the program stopped as it loaded; and stock pile wasn't read as a type.

The compiler moves a file's classes above its first running code, and a type's name may be several words.

  • A file can declare its types at the end and use them above: each class moves up above the file's first running code, banners and headings staying where they are.
  • A type's name may be several words, a stock pile is a pile, read as one name before is a, is an or aka.
  • A method on such a type, - to draw a stock pile:, compiles inside its class.
  • The test projects' output re-blessed: the same code, classes higher up.
