Open examples / OutlineSolitaire in the app served from this worktree, with the browser's console open. Or run it from the worktree's root: 

spell run @spell/examples/outline-solitaire
  1. watch it load and deal
  2. read the console
  3. edit any spell file of the example (add a blank line) and save, so the running game hot-reloads
  4. read the console again
  5. press Debug
  6. press AutoPlay, then Cheat (both read the tableaus since P23)
  7. play a few moves, then press Restart
  • it deals: the cards come out of the stock into the seven tableaus, and one card turns over onto the discards
  • the console shows the two tests, card setup and deck creation, passing, once each
  • after the hot reload: the game carries on where it was, and the tests do NOT run again
  • Debug prints every pile's state: the stock, the discards, the four foundations and the seven tableaus
  • AutoPlay moves what it can onto the foundations; Cheat turns over a face-down tableau card onto the discards
  • Restart gathers the cards back and deals again, the score back to 0
