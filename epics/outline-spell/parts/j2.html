Chose to compile an outline body FLAT: each line as if it were written at the top level, right after the type's line. Members (properties, getters, phrases) then move into the class as they always do.

  • why: the outline must compile EXACTLY like today's sentences (Q1); a test compares the card outline with the same lines in today's style, character for character
  • so a set x to 1 in a body makes a file-level x, as at the top level
  • the other way: a body as its own block, wrapped in {}: its members would no longer move into the class
  • export class Card extends Thing { ... get color() ... } from either style
