Found answering T1 (typographic marks). A string in quotes may run on past the end of its line, so ONE quote typed without its partner pairs up with the next quote anywhere below it, and every line after it is lost into a single "Don't understand" error.

  • e.g. a card “is low" if its rank is 1, followed by three more ordinary lines: the whole rest of the file is one error, and none of those lines compile
  • no spell file in the repo has a string spanning lines, so ending every string at the end of its line costs nothing today
  • fix: in spell's tokenizer (matchText()), a quote with no partner on its own line is not a string; the error then stays on that one line
  • matters more after T1: curly and straight quotes typed by hand will be mismatched more often
