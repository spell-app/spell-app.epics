The outline Solitaire names its variables, a method and an event with hyphens, start-pile, because a variable or an event's name can't be several words.

Tried 2026-10-20:

  • several words already work for types (a stock pile, P15), properties (its short name) and methods (- to auto play:)
  • they don't for variables and event names: each of these is "Don't understand"
    • set start pile to a new pile
    • if anything changed is no
    • on card click with a card
    • fire event card click

Variables and events take names of several words, as types, properties and methods do; then every hyphenated name in the outline Solitaire becomes words.
