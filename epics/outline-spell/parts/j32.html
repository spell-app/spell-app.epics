P16's plan said all the piles might mean the same as every pile, settled while building. It was left out: only every pile is new.

Why:

  • all the piles reads like a name the program could declare itself, e.g. a list it keeps; taking the words for core could clash with one
  • one way to say it is easier to learn and to complete in the editor
  • adding it later is one more syntax on the same rule, every_thing
  • all the piles is not spell: write every pile
