1. In VS Code's main window (the kit's, spell), open the Explorer (⇧⌘E) and open any file in spell-app/spaces/@spell/examples/Solitaire/.
  2. Open the Command Palette (⇧⌘P) and run: 
    Spell: Run Project
  3. Wait for the game to show in the Spell panel.
  4. Click the stock (top left) a few times.
  5. Play a card: click a face-up card that can go on a foundation or a tableau.
  • Each card slides from where it was to where it lands.
  • No card jumps.
