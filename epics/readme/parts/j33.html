A Mermaid block can't switch its theme by colour scheme: the %%{init}%% directive applies in both modes. So the default theme puts every text on a light box (nodes, edge labels, notes, subgraphs), and draws what sits on the page itself (lines, a sequence diagram's messages) in a mid-tone purple, #7F6FD6, which reads on white and on GitHub's dark background.

  • The dark variant is there, yarn mermaid:pretty --dark, for a page that's only ever shown dark. No page uses it.
  • Rounded nodes come from the classes (rx, ry), and the curved lines from flowchart: { curve: "basis" }.
  • Each node's kind comes from its label: a repo's name, a leading step number, a folder, a file, or a 🌱 or 'coming'.
