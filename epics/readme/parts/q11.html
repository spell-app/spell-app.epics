The spell-lang README opens, as the brief asks, with how spell changes the game for someone who doesn't program and works with an AI. That opening is written as the project's DIRECTION, in plain words, with what's built under it.

  • What's decided in the project: "AI: partner, then teacher" (the motivation goals' one settled line): an AI writes spell; the person reads what it wrote, checks it, changes it, and learns to write their own.
  • What's built: English spell compiles to JavaScript, TypeScript and Python; the parser knows no language; markdown is the second language on it; the editor shows a program running as it's typed.
  • What's not: no AI feature ships in the app; no human language but English parses.
  • So the README says: "Spell is English you can run. Because the source IS English, the person who asked an AI for a program can read what it wrote, change it and learn from it." Then the picture: human languages in (English today, Spanish next), the one spell tree in the middle, targets out (JavaScript, TypeScript, Python today; WebAssembly coming).
  • The Spanish sample from Card.spell-es is shown in the "coming" section, labelled as a hand translation nothing parses yet.
