README-frameworks.md tells React 19 and Svelte 5 readers to import the families up front (import "spell-ui" or spell-ui/ui-dropdown) rather than lean on <ui-root>'s on-demand loading: both decide property or attribute by looking at the element, so an undefined tag would get options as an attribute. This is the frameworks' documented behaviour and what the smoke pages do (they import spell-ui first); the on-demand case wasn't run. The getting-started page's 'define the elements before the framework renders them' says the same.
