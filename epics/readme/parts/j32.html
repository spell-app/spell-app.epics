The checker and the prettifier live in tools/, beside repos.ts. Their tests are in tests/tools/, as the kit lays out tests. To make yarn kit:test run them, tools joined the kit's "spellFolders", with its own tsconfig.json, vite.config.ts and vitest.config.ts. So repos.ts is now type-checked and linted too. It passed both with no change.

The other way was a test that no check runs.
