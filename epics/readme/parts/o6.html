README.md: the brand

  • Lead: Spell's look, as code: a theme for Spell UI (`spell-brand`: Spell Purple, aubergine dark mode, the serif), a pack of `<brand-*>` elements the brand pages need, the brand's assets (logo, font, reference images), and the docs set that shows them.
  • Picture: the three things and who uses them: the theme (every docs page wears it), the pack (the brand pages, the design system), the assets (served at `/_brand/assets/`).
  • The elements: the ten `<brand-*>` tags in a table, their one-line descriptions from the vocabularies; the real markup (with today's pack address, `/_epic/pack/` style, not the stale `/packages/brand/...`); which graduated into Spell UI (`<ui-panel>`, `<ui-field>`).
  • The theme: what `spell-brand.css` adds over `spell.css` (the brand roles); dark mode is aubergine; link to spell-ui's README-themes.
  • The brand pages: Claude Design's originals and their Spell UI copies side by side, `yarn compare`; they're shared content, not in this repo.
  • Palette: the colour math (sRGB ↔ OKLCH, contrast, 17-step ladders), in three lines.
  • Working on it: `yarn pack:build | pack:check`, `yarn site:data`, `yarn compare`, `yarn test`, `yarn review`; it needs spell-ui and the kit.
  • Expands: every element's attributes; the assets list and licence; the generated files.
  • Sources: explore-4 B.1-B.3; spell-brand/README.md (its pack path and bundle path are stale).

README-design.md: designing with Spell UI in Claude Design

  • Lead: a design system on claude.ai generated from the code, so a design made there is plain Spell UI markup, and comes back as a page. Round trips both ways.
  • Picture: the loop: vocabularies and the theme → `yarn design:build` → the design system's files → claude.ai → a board → `/design pull` → a page in the repo; `/design push` the other way.
  • What's in the system: a card per vocabulary, the theme as tokens, the brand rules, the Brand group; the one classic bundle every board loads (`yarn design:bundle`, `yarn design:check`).
  • How to use it: the skill's four verbs (push, pull, new, page), in spell-app; what a design writes (`<ui-button primary icon="check">`), no wrappers.
  • The counts, dated (70 cards, 451 tokens, pushed 2026-10-05).
  • Expands: the export's files; the vendored runtime and the check.
  • Sources: explore-4 B.3; the claude-design and design-system guides; spell-ui's `yarn design:build`.
