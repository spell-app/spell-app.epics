The map: every README this epic wrote, by repo, with what each one is for and what it replaced. A repo's root README is its front page; the README-<folder>.md pages beside it go deep on one folder or one topic.

  • 35 pages in all: five front pages rewritten, and 30 new secondary pages beside them.
  • About 11,900 lines, counted at the doc review, before its text pass. A page's count includes its folded details.
  • Ten old in-folder READMEs were folded into the new pages and deleted (Q5), and every link to them repointed.
  • The kit is the root everyone works in, so the pages about working on Spell as a whole (the command line, development, VS Code, agents) are the kit's, beside its own folders' pages (Q6).
  • The pages describe the layout AFTER repo-split P13 and P14 (Q2): the command line in the kit's cli/, each repo's commands in its own, package names everywhere, the assembler inside the server (Q7). A page that names something not landed yet carries one folded "Until repo-split ... lands" note with today's spelling; P9 removes them.
  • Guides in the content folder are named, not linked (Q3).
