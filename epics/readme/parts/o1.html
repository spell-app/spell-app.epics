The map: every README this epic writes, by repo, with what each one is for. A repo's root README is its front page; the README-<folder>.md pages beside it go deep on one folder or one topic. The outlines (sections, pictures, expands, stubs) are the sub-sections after the writers' brief, one per repo.

  • The kit is the root everyone works in, so the pages about working on Spell as a whole (the command line, development, VS Code, agents) are the kit's, beside its own folders' pages (Q6).
  • The pages describe the layout AFTER repo-split P13 and P14 (Q2): the command line in the kit's cli/, each repo's commands in its own cli/, package names everywhere, the assembler inside the server (Q7); the element framework's page is the kit's (Q8).
  • Existing in-folder READMEs are folded into the new pages and deleted (Q5); every link to them is repointed. Guides in the content folder are named, not linked (Q3).
