The brief drops "Fomantic UI reborn" as Spell UI's lede. Something has to replace it on the front page, the package description and the saga's purpose line, so the outline proposes one, and the page can be marked if a different line is wanted.

  • Proposed: "Accessible, themeable web components that load themselves on demand, from plain HTML or any framework."
  • Why those words: each one is a fact the page then shows (accessibility built in, themes and tokens, `<ui-root>` loading families on first use, the five framework recipes).
  • The lineage stays, as the last section of the page, two lines: the vocabulary and class grammar are Semantic UI's and Fomantic UI's; each family's CSS is a port of Fomantic's, kept inside the shadow root.
  • Alternatives considered: "Fomantic UI's vocabulary as web components" (what the package says today: the lede the brief retires); "Spell's component library" (true, but says nothing to someone who doesn't know Spell).
  • spell-ui's README, its package.json description and the saga's purpose line all say the new line, in the spell-ui phase.

Beautiful, themeable, accessible components that load themselves on demand, for use in plain HTML or any framework
