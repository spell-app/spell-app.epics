Static Pages for SEOspell ssr page.html renders every Spell UI family in node, through Solid 2's server render (renderToString), into plain HTML with no shadow DOM and no element scripts, plus one stylesheet of only the families the page uses; dialogs, click popups, accordions and forms work with JS off. Each element is replaced by the root it renders, marked with its kind (data-ui), each component's sheet is rewritten and fenced in with @scope, and the page's own CSS is rewritten so it still reaches only what it reached before.
