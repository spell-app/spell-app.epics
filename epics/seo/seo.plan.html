Durable doc: guides/seo/seo.html, "Static Pages for SEO": how to use and maintain the static render, as built. This plan stays as the record.

spell static page.html renders every ui-* family in node (Solid 2 renderToString, $/ui/server) into plain light-DOM HTML plus one stylesheet of only the families the page uses: no shadow DOM, no element scripts; dialogs, click popups, accordions and forms work with JS off. Each host is replaced by its rendered root, marked with its kind (data-ui); each component sheet is rewritten for light DOM and fenced in with @scope, and the page's own CSS is rewritten so it still reaches only what it reached before.
