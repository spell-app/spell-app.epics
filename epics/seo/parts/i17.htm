Every family sheet is @scoped to [data-ui=noun] roots, so author markup that uses the class grammar directly -- the native <button class="ui button" commandfor command> triggers in the modal, flyout, dimmer, sidebar and shape examples -- gets UA styles in the static page, while the elements fixture styles them. Most of those examples' remaining parity diff (modal 17-20%, flyout 18-19%, shape 7-16%, dimmer types 7-14%, sidebar ~4%) is these buttons and the 10-16px height they lose. Not a family problem: the static stylesheet (or the fixture) would need an unscoped class-grammar layer for author markup.
