The static HTML keeps every part="..." attribute the components rendered, for example <div class="header in-card" part="header">.

  • Harmless: with no shadow root, there's nothing for them to expose.
  • The plan said: strip them in the second phase (P2) if the stylesheet doesn't need them, since app CSS couldn't reach them with ::part() anyway (C3).
  • Kept, because the page needs them: the page's own CSS is rewritten to match them.
    • a rule H::part(p) becomes H [part~="p"]
    • that's StaticPageStyles, and the decision to rewrite the page's own styles (D22)
  • nothing changes: the attributes stay, and page CSS written with ::part() still works
