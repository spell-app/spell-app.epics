ui-form.css's static-markup rules hide a form's state messages (.ui.form .message:is(.error, …) { display: none }, shown again under .ui.error.form ...). Messages are AUTHOR content (slotted), so the I14 anchor :where(:scope, :not([data-ui-slotted])) now keeps those rules off them: ui-form/states 4% -> 12% light / 29% dark ("Hidden: the form isn't in the error state." shows). As elements, native.css hides them (:where(ui-form) :where(ui-message[state="error"]):not(:where(:state(error)) *)), on tags, the dropped state attribute and :state(). Fix in shared code: the static sheet needs that native.css rule rewritten for flattened output, e.g. :where([data-ui=form]) :where([data-ui=message].error):not(:where([data-state~=error]) *) (also fields / field), or rules a family marks as light-DOM (class grammar) exempt from the anchor.
