UIRuntime's docstring says it can be built outside a browser, for server rendering. It can't: building it in node throws.

  • The line, in UIRuntime.ts: "Constructs outside a browser too (SSR): services touch the DOM only when used." Still there (checked 2026-10-04).
  • Why it's wrong: registerFoundation() calls new CSSStyleSheet(), which node lacks.
  • Worked around: the server uses ServerRuntime instead (the decision on the runtime in node, D11).
