Show hover and focus popups on static pages with the HTML interestfor attribute, once browsers other than Chrome ship it.

  • What it does: it lets an element open a popover when a reader hovers or focuses it, with no script.
  • Today, a static hover popup is a hidden role=tooltip popover: read by screen readers and crawlers, never shown (the caveat on families without JS, C1).
  • Not checked: which browsers ship interestfor today.
