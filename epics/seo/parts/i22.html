StaticRender rewrites the page's own <style>s (StaticPageStyles), not its <link rel=stylesheet>s. The docs' _assets/spell-doc.css styles ui-section (title sizes, padding, ::part(title)), ui-cards.spell-flow (4 columns) and ui-message lists, so on the static solid-2.html cards go 2 per row instead of 4, section titles and spacing change, and the Status message's list turns teal. Rewriting spell-doc.css by hand with StaticPageStyles.rewrite() fixed all three (experiment, not committed). Fix options: spell static writes a rewritten <sheet>.static.css for each LOCAL linked sheet and relinks it (shared assets: written once per run), or the docs page CSS also targets [data-ui=...].
