The static render rewrites a page's own CSS so its ui-* selectors still match. Some of that CSS it can't reach, and those rules then match nothing on the static page.

  • Replaces the caveat on app CSS (C3).
  • Rewritten:
    • the page's <style>s, by StaticRender (the decision to rewrite them, D22)
    • each LOCAL linked sheet the rewrite changes, inlined by spell static (the decision on linked sheets, D59)
  • Left as written, so their ui-* tag, ::part() and :state() selectors match nothing:
    • remote sheets (https:, //)
    • @import inside a sheet
    • sheets that don't parse
    • styles a script sets
  • Also only approximate:
    • H::part(p) becomes H [part~=p], which also reaches parts of components nested in H; the shadow boundary used to stop that
    • page CSS keeps out of components' own markup only through REACH (the decision on component internals, D58)

Net effect:

  • for a static page, put page CSS in <style>s or local sheets
