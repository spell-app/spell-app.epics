D31 · Host-margin groups: the root-zeroing rule skips static roots ([data-ui])

ui-items.css puts the group's outer margin on the HOST and zeroes the root's (:host(:state(items)) > .ui.items { margin: 0 }). Statically root == host, so that rule (components layer) beat the host margin (ui.reset): every items group lost its 1.5em. Now .ui.items:not([data-ui]): never true for a shadow root, so the browser is unchanged; ui-items/types 12% => 0.46%. Same pattern to watch in other groups that carry their margin on the host.
