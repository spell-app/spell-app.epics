Found in P6: spell static on a page with a <ui-dropdown> or <ui-popup> warns css not minified, only stripped: Unexpected token Function("anchored"). ui-popup.anchored.css holds @container anchored(fallback: flip-block), which Lightning CSS 1.30 can't parse (its header says so: that's why it's a separate ?raw sheet). StaticDocument.minify() is strict (D53), so the WHOLE stylesheet falls back to comment / blank-line stripping: probe page (dropdown, sidebar, popup) 248 kB -> 225 kB instead of ~16% smaller again. Nothing is dropped: the output is correct, only bigger. Suggest: minify each family's block on its own and keep the ones that fail as stripped text, or cut the @container anchored() blocks out before minifying and append them after.
