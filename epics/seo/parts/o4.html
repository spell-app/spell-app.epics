Without shadow DOM, CSS leaks two ways:

Component into nested component (D5)

  • .ui.menu .item would reach a nested dropdown's rows; leaky selectors: menu 44, list 34, dropdown 34, form 22, message 21, breadcrumb 14, comment 9
  • fix: each sheet wrapped in @scope from its families' roots ([data-ui=kind], plus class-grammar markup the page wrote) down to, not into, author content and other components (D13, D34)
  • every rewritten subject anchored with :where(:scope, *) (D18): inside @scope a bare .ui.card means a DESCENDANT of the root; shadow-markup subjects also :not([data-ui-slotted]), so they never land on author content (D42)
  • a sheet several families adopt (items take ui-list.css) is scoped to every kind seen adopting it, and sheets keep their adoption order (D19) 
/* in the shadow root */
.ui.cards > .card,
:host(:state(in-cards)) > .ui.card { margin: ...; width: ...; }

/* static */
@layer ui.components.card.types {
  @scope (:is([data-ui="cards"], [data-ui="card"], .ui.cards:not([data-ui]):is(...), .ui.card:not([data-ui]):is(...)))
    to ([data-ui-slotted]:not([data-ui]) > *, :scope [data-ui] > *) {
    .ui.cards > .card:where(:scope, :not([data-ui-slotted])),
    .ui.cards > [data-ui-li] > .card:where(:scope, :not([data-ui-slotted])),
    :scope:where([data-ui]):is([data-state~="in-cards"]):is(.ui.card) { margin: ...; width: ...; }
  }
}

Page into component (D6, D58)

  • page CSS never reached a component's own markup: the shadow boundary kept it out. Statically every page subject gets REACH, :where(:not([data-ui] *), [data-ui], [data-ui-slotted], [data-ui-slotted] *): outside components, roots (were hosts), author content
  • ui-card => [data-ui="card"], ::part(p) => [part~="p"], :state(x) => [data-state~="x"] (D22), in <style>s and local linked sheets (D59)
  • @layer ui-slotted, page, ui; opens the stylesheet (linked first, D52): a page that layers its CSS as page loses to components; unlayered page CSS still wins on roots and author content, as it beat :host / ::slotted() rules in a browser

Rest of the rewrite

  • :host(X) > C => :scope:is(X):is(C): the root replaced the host, so both land on one element; :state(x) => [data-state~="x"]
  • host-only rules (token resets) move to @layer ui.reset, minus display (D15); ::slotted() and slot rules to @layer ui-slotted, before page, as they lost to the page in a shadow root (D42)
  • list groups (cards, list, feed, steps, items): each A > B also matches A > [data-ui-li] > B (D14)
  • foundation sheets keep only page selectors; reset.css scoped to every component (D16); typography / native get REACH; page sheets families register while rendering included (D35)
  • [hidden] { display: none }, unlayered: component display rules beat the browser's
  • inherited properties already crossed shadow boundaries: no change
