Default output <page>.static.html beside the input, its stylesheet <page>.static.css beside that (-o out.html => out.static.css). -o <folder> for several pages (each keeps its name, relative to the folder named); a folder input means every .html under it except *.static.html, node_modules, dot folders. --css <file>: ONE stylesheet for every page; --inline: a <style>; --no-minify.
