On a static page with JavaScript off, some families render but can't be used. A reader sees their first state and nothing happens on a click or a hover.

  • Tabs: only the selected pane shows; the others are in the HTML, hidden.
  • Hover and focus popups: the plan said they'd fall back to title. As built, each is a hidden role=tooltip popover that its target names with aria-describedby:
    • screen readers and crawlers get the text
    • sighted readers without JS don't
  • Dropdowns: the menu opens, but choosing a row needs JS.
  • Calendar: the picker renders, but picking a day needs JS.
  • Search, shape, slider, element dimmer, and a nag's close button: first state only.
  • The full table, family by family: 1.5 No-JS interaction.
  • nothing changes: these need the elements' JS
  • hover popups could show later, through interestfor (the todo, C22)
