Client bundles: server-only (D8)

The server code stays out of what the browser loads.

  • @spell-app/ui/server and solid-element's server helper are separate exports, never in client bundles
    • in it: the runtime shim, the server element, the tree driver, the flattener
  • the static stylesheet is written by spell ssr, not shipped with the components
  • client code gains only isServer guards: a constant false in the browser build
  • the budget: under 1 kB, minified and gzipped
    • yarn measure before and after: NOT run (T32)
  • methods only the server uses (staticControl() and others) stay in client bundles

Static output (P5, measured)

Measured on solid-2.html, a page with 12 families: about 3.3 s, mostly Vite compiling every family.

  • HTML: 128.5 kB before, 174.2 kB after (32.4 kB gzipped)
  • CSS: 337.9 kB before, 284.7 kB after, minified
    • gzipped, 39.5 kB to 38.2 kB (C19)
  • a page with popups isn't minified at all (I25)
  • static against live: 287 of 342 example pairs within 1%, in chromium (yarn test:visual --static)
