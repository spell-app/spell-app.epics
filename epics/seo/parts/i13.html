A component's slot { --ui-color: initial } (e.g. ui-segment.css's .ui.segment > slot) is rewritten to .ui.segment > * in its components layer, so it lands ON a slotted component's root and beats that root's own .ui.primary (ui.tokens): a primary button directly in a segment renders grey (ui-root/types 1.08%, the only diff there). In a shadow root the reset sat on the slot and the button's root re-declared it. Fix in shared code: emit slot-derived resets in @layer ui.reset (like host-only rules, D15). (Agent B)
