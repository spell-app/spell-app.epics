What the output looks like, family by family:

  • Clean, about 40 of 55: the output is the family's class-grammar examples, which its CSS tests already cover.
    • the examples: examples/*.html
    • the tests: ui-*.css.test.ts
  • Kind: every root says which element it was, in data-ui (D41).
    • the tag without its ui-: card, placeholder-image
    • unique per tag
    • the stylesheet's @scope starts there
  • States: every element state goes into data-state="a b" (D13).
    • states from an owner (in-card) are classes too
    • the author's content is marked data-ui-slotted
  • List items (D4, D20):
    • a <div> item root BECOMES the <li>: a list item, a feed event
    • an <article>, link or button root is wrapped in a <li data-ui-li> that's display: contents (D14)
    • a <div> with role=list holding them becomes a <ul> (D12)
  • Phrasing content: where only inline content may go, a <div> becomes a <span> (D43).
    • a <div> root there, and every rendered <div> under a <p>
    • other block roots still split a <p> (C20)
  • The element is the box: popup, a shape's side.
    • the root takes the box and the state classes (D26)
  • Special cases (D36):
    • a breadcrumb's section becomes an <li>
    • sticky drops its sentinels
    • an item with no owner renders a <span> that's display: contents
    • dropdown and select drop their light items, and render rows (D32)
    • accordion pairs its children into <details>
    • form merges the author's <form> into its root (D27)
    • ui-root becomes a plain wrapper (D30)
  • Attributes move to the root:
    • the global ones: id, class, style, title, lang, data-*, aria-*
    • a form control's id and ARIA names go to its native control instead (UIT.STATIC_CONTROL, D55)
    • the family writes its name and value there (D28)
    • the role and ARIA set through internals are written out as attributes

Tags that are never registered would hide the page.

  • native.css hides an undefined ui-root whenever scripting is on, as it is for Googlebot (visibility: hidden)
  • and undefined ui-popup and ui-modal
