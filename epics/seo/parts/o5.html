How the interactions work without the elements (StaticInteractions, D47):

  • custom commands (--show, --close, --toggle) become native ones
  • references between elements become id attributes (D24): a tab's aria-controls, a modal's aria-labelledby
  • the ids come from one allocator for the page, which skips the page's own ids (D48)
  • a fixed id a render repeats is renamed after its first use
  • open popups, modals and flyouts render closed (C11)
