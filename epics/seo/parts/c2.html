The static render runs once, on the server, before any reader opens the page. So it can't use anything that lives only in the reader's browser.

  • A tabs history hash: with history, the selected tab follows the page's address hash (UITabs.tsx).
    • the server never sees the hash, so it renders the default tab
  • A nag's dismissal: a dismissed nag is remembered in the reader's storage (localStorage, by default); the server renders it shown.
  • Measured sizes: anything a family sizes by measuring the page in a browser.
  • nothing changes: the static page shows each family's default state
