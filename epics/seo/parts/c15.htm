Live, a row of <ui-steps> stacks into a column on a narrow screen. On a static page it never does.

  • Live: the stacking queries (under 768px, under 992px) ask the HOST's size, since the host is the size container.
  • Static: the host is gone (in the static markup, the container would be the group's parent). The render put the host's container on the inline-flex root, which then shrank to nothing.
  • So ui-step.css now sets container: none on .ui.steps (a no-op in a browser). With no ui-steps container, the queries never match statically.
  • Grids and statistics keep the container on their (block) root: their columns still respond, but rules on the grid root itself (mobile reversed) don't.
  • Found by Agent A.

Net effect:

  • nothing changes: static steps stay in one row at every width
