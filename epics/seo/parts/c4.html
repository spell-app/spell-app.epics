A static page must not load the ui-* element scripts. If it did, every component would show twice.

  • Why: loading the scripts upgrades each element, and an upgrade would treat the flattened markup inside it as slotted content, then render its own copy too.
  • The fork (packages/solid-element) only clears declarative shadow roots, not flattened markup.
  • spell static drops the element scripts from the page for this reason (D51).
  • nothing changes: a page is either static or live, never both
