A ui-* host is phrasing content, valid in a <p>; its static root (<div>) is not, and the HTML parser closes the open <p> at it (even nested in a <span>). Handled in-family for <ui-popup> (server markup is <span>s, header / content display: block) and <ui-shape text> (shape, sides box and sides as <span>s, as its class grammar). Other families' block roots in running text (e.g. <ui-header> slotted in a popup inside a <p>) still split it.
