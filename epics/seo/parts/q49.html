packages/cli/src/runner/renderStatic.ts (tsx) starts ui/tools/StaticRenderer.ts's SSR-only Vite server (the D17 setup, moved out of visual/StaticPages.ts, which now uses it too) and loads ui/tools/StaticDocument.ts through it. Talks over IPC (CLI.StaticMessage): one job, a reply per page. A child keeps Vite, the server UI runtime on globalThis and Vite's console out of the CLI, whose console.* is silenced. About 3 s per run, mostly Vite compiling every family; several pages share one run.
