StaticFlattener.replace() moves the host's slot attribute to the FIRST element of its render only. An unowned <ui-item> renders just <slot>, so a rich dropdown item <ui-item><b>Bold</b> one</ui-item> (the dropdown assigns it to its row's named slot) lands in the row as <b data-ui="item">Bold</b>: the text " one" falls to the default slot, which a static dropdown doesn't render, and the <b> is taken for the item's root (data-ui, host attributes). Suggest: a host whose render has no single root element (a bare slot) hands its slot to every top-level node (text in a <span style="display: contents">), and gets no data-ui. Pinned in ui-dropdown.ssr.test.tsx (one-element rich item).
