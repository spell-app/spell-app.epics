In ui-items.css, :host(:state(in-items)) > .item > img.image (the item's own image shorthand) and ::slotted(img) both match a slotted <ui-image size=tiny>'s root, img.ui.tiny.image, statically: it gets the 175px item-image width (items/content 39%, states 48%, variations 52%). In a shadow root neither could: the first only sees shadow markup, the second only author <img>s. Fix in StaticSelectors: ::slotted(T) => T:not([data-ui]), and compounds after the root from shadow markup => :not([data-ui-slotted]) (static author content always carries it, shadow markup never). Measured with an equivalent local patch to ui-items.css (not kept): states 0.8-1.3%, content 9%, variations 10%, the rest I9. (Agent B)
