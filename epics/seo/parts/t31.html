Found in P6. The plan (1.5, C1) said a hover / focus popup falls back to a title. The build renders it as a hidden popover="manual" role=tooltip span, its target pointing at it with aria-describedby (D24): screen readers and crawlers get the text, sighted no-JS readers see nothing. Option: on a server, UIPopup.serverBind() also writes the popup's plain text as the target's title when it has none (cost: a tooltip AND a description read twice by some screen readers).
