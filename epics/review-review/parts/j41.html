Every rewrite of an item now moves the text it replaces into a folded "Original Discussion" aside inside the item, after the current text and before the commits (I7).

  • Each version is a div.plan-version. The first has no heading until a second arrives; then it gets "As first written".
  • Each later version sits under <h5>As of 2026-10-04 20:49</h5>: the time it was replaced. Versions are kept oldest first.
  • A version that says the same as one already there (ignoring whitespace) isn't added again.
  • Ids inside become data-original-id, so #why in the new text and the old never clash, and no link lands in history.
  • Over: one flat block with dated headings. The wrapper makes "already there?" and date order simple.

Example: rewriting Q1 twice leaves As first written (the question with its option cards), then As of 2026-10-04 23:50 (the first rewrite), and the second rewrite on top.

  • details --file never drops text.
  • Answering a question again (decide) keeps the old answer card there too; a migrated id="d7" moves to the new card, so #d7 links still land.
