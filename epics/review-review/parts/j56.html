The PR offer is a new step 4 in /isolate's Finish: after the branch has main merged in, before leaving the worktree and before main moves. It runs git fetch origin main, then git rev-list --count origin/main..main; not 0 means GitHub's main is behind, so no offer, just one line saying why (Q16, answer C). Chose skill prose with those exact git commands over a spell dev worktree verb: a verb needs CLI options, tests and a commands page row (held back in shared-pending until merge), more than the two git commands it would wrap.
