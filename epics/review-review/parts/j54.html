A /bedtime run is marked on the doc's page, now that the Overnight section is gone.

  • The Overnight section did two jobs:
    • it was the morning report
    • it was the switch saying a /bedtime run is going on, so every item the night touches stays green until you review it (D2)
  • D5 drops the report, but the switch still has to live somewhere.
  • Chose a mark on the doc's body, data-bedtime="P3-P6", over keeping a hidden Overnight section just as a flag.
  • It's turned on and off by two commands, both logged: 
    spell dev plan-doc bedtime <name> start "P3-P6"
spell dev plan-doc bedtime <name> done "summary"

An example:

  • /bedtime runs bedtime review-review start "P8-P10".
  • A session that loses its memory mid-night reads summary --json, and sees "bedtime": "P8-P10".
  • So it knows it is still running unattended.
  • summary --json has bedtime (the phases, or null) instead of overnight; /epics and /wtf read that.
  • Nothing new shows on the page: the night's judgement calls and issues show red in their own sections.
  • /bedtime records its work in the log instead of the report's Phases and Problems lists.
    • each phase with log and commit --phase
    • a skipped phase in a log line
