The Overnight section did two jobs: it was the morning report, and it was the switch that said a /bedtime run is going on (so every item the night touches stays green until you review it, D2). D5 drops the report, but the switch still has to live somewhere. Chose a mark on the doc's <body>, data-bedtime="P3-P6", turned on by spell dev plan-doc bedtime <name> start "P3-P6" and off by bedtime <name> done "summary", both logged, over keeping a hidden Overnight section just as a flag.

Example: /bedtime runs bedtime review-review start "P8-P10"; a session that loses its memory mid-night reads summary --json, sees "bedtime": "P8-P10", and knows it is still running unattended.

  • summary --json has bedtime (the phases, or null) instead of overnight; /epics and /wtf read that.
  • Nothing new shows on the page: the night's judgement calls and issues show red in their own sections.
  • /bedtime records each phase with log and commit --phase, and a skipped phase in a log line, instead of the report's Phases and Problems lists.
