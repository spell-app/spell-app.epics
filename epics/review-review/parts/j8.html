• Chosen: a changed .js reloads a page only when it's in (or under) the folder of a script the page loads, e.g. _assets/ for the bundle and its lazy chunks.
  • Over: reloading every open page on any .js change, as before. Editing a repo tool such as scripts/plan-doc.js used to reload every doc.
  • A changed stylesheet the page links (or @imports) is swapped in place, no reload.
