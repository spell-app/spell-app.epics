spell dev server passes the page server's OWN verbs through unchanged: serve, start / ensure, stop, status, url. The commands page's target names (start --foreground, status --json, restart) are a later move (R8), and its rows now say so.

  • The one addition: spell dev server start --all runs scripts/serve.mjs (yarn serve), every web server of the checkout.
  • Not built from R2 either: spell dev cli install (yarn cli:install stays the bootstrap).

Net effect

  • yarn server ensure and spell dev server ensure mean the same, so scripts/serve.mjs and skills keep working.
