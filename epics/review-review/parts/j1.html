Three small choices about the new "Review" tab in the right side bar:

  • Its icon is VS Code's own $(pass) codicon (a circle with a check, outline), not an SVG of Font Awesome's regular/circle-check. It is drawn at the same weight and size as VS Code's other side bar icons. Swapping to the Font Awesome one is a two-line change if you prefer it.
  • Opened by hand before anything was shown in it, the Review tab says how to fill it (/epic review <name>, or yarn docs:open <page> --review) instead of showing the docs index, so it never looks like a second copy of the Spell Docs tab.
  • Its title bar has the same buttons as Spell Docs (back, forward, reload, restart the page server, open in the browser). "Docs Index" stays a palette command for the Spell Docs tab only.
