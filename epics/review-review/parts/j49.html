While a pass-through's tool runs, spell ignores Ctrl-C (the terminal sends it to the tool too) and passes on SIGTERM / SIGHUP sent to spell alone.

  • So a foreground server (spell dev server serve, spell dev goals serve) shuts down cleanly and spell exits with ITS code. Checked: SIGINT to the group gave the tool's 0 after its cleanup; SIGTERM to spell reached the tool, which exited 7 as it chose.
  • A tool killed by a signal: exit 128 + n (130 for SIGINT), as a shell reports it. The old spell plan-doc said 1.
  • No orphaned servers after Ctrl-C; the shell prompt comes back after the tool is done, not before.
