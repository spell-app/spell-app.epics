A plain <ui-sections> (no collapsing) changes nothing in its sections: it is a block spaced as one section would be, and the nearest group always decides the default.

  • Spacing: the group takes a section's margin (1.5em, 0 when first / last in its parent), so a group after a paragraph keeps the same gap a lone section would.
  • Nearest wins: a plain group inside a collapsing one turns the default OFF for the sections in it (JS and CSS both read the nearest group).
  • Levels and sticky stacks carry through a group: a section in a group in a section is still nested (h3 under an h2).
  • No other attributes for now (no collapsed to start every section folded, no exclusive "one open at a time"); easy to add if wanted. 
<ui-sections collapsing>
  <ui-section header="A">                    <!-- folds -->
    <ui-sections>
      <ui-section header="B">...</ui-section>  <!-- doesn't:  the plain group is nearer -->
    </ui-sections>
  </ui-section>
</ui-sections>
  • Wrapping sections in a plain group is safe: nothing about them changes.
  • The plain group is how to switch the default off for one subtree.
