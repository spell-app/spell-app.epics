The round filter button on each section title is quiet while it shows everything, and solid in the color of the state it shows.

  • The brief suggested the other way round (old outlined). But "all" is the default, on every section, all the time: a solid grey circle on each title would be the loudest thing there.
  • Steps with no items in that section are skipped, e.g. Judgement calls with only red and blue items goes all, red, blue, all.

  • The commits button in the page header shows only on a doc that has commits; pressed, it is the accent violet (orange would read as "in progress").

Net effect:

  • a resting filter button is an outlined grey circle; red, orange, blue, green or solid grey means a filter is on
  • docs reopen with every item shown, once
