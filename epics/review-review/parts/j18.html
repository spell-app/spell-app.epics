In dark mode the UI red is a light salmon, almost the same as the dark mode orange, so red and orange chips side by side were hard to tell apart.

  • The "needs attention" chip uses the light-mode red (--ui-red-on-light) with near-white text in both modes.
  • Orange, blue, green and grey use the normal dark-mode tokens.

Net effect:

  • in dark mode, red chips are a deep red with white text, clearly not orange
