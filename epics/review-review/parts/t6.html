• After yarn vscode and a window reload, open a plan doc in the side bar, unfold a section, scroll halfway down and start typing in a field (or just leave a code block open).
  • Run yarn plan-doc log <name> "test", then yarn plan-doc add <name> todo "test".
  • Expected: no white flash, no jump; the new log line and todo appear, the counts and contents follow; folds and typed text stay. Remove the test lines afterwards.
  • Then yarn plan-doc phase <name> <N> active: the doc comes forward once, without reloading.
  • Then reload the side bar (or restart VS Code): it opens on the section you were reading.
  • Rerunnable in a headless browser: node scripts/check-live.js in packages/docs.
