Owen, 2026-10-04: a new @spell-app/ui element that holds a run of sections which fold, packed tight.

  • <ui-sections collapsing> around a run of <ui-section>s: every section in it folds, and folded ones stack with no space between them (an accordion's look, with sections' sticky titles).
  • The sections under it, sub-sections included, take collapsing from the parent by default: no collapsible on each one.
  • Built in packages/ui by its own agent during P5; using it in plan docs (e.g. the phases list, or every section) is a follow-up to decide.
  • a page can write <ui-sections collapsing> once instead of collapsible on every section, and folded sections no longer leave gaps
