  • each rewrite shows in every window as soon as it's written
  • spell-app-dev auto-commits every turn (auto: .claude/worktrees/review-review), so the record is many small commits, not a phase commit
  • checking 'nothing lost': compare with the doc before P8, git -C ../spell-app-dev show <sha>:epics/<name>/<name>.plan.html
  • undo: git -C ../spell-app-dev revert of those auto-commits, or restore the file from the pre-P8 sha

Net effect

  • Note the spell-app-dev sha before P8 starts (into the P8 log), so one command restores any doc.
