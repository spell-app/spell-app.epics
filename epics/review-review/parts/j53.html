The new spell dev plan-doc relayout <name> | --all [--dry-run] converts answered questions from the old layout (answer card first) to the new one. Some cases needed a rule.

  • Option cards without letters (4 in markdown: Q1, Q2, Q5, Q6, e.g. "New package (recommended)") become Choices too; the dry run notes they can't be picked by letter.
  • A grid that isn't options (Pros / Cons labels, no letter, no "(recommended)") stays in the question's text. None of the real docs has one.
  • Replies (div.plan-reply) stay after the answer card; everything else after an old card is the question's text.
  • A question born answered (no answer card, e.g. all 14 in shared-content) is skipped and listed.
  • migrate also runs it, so an old doc comes out in the new layout.
  • Dry run 2026-10-04: 70 questions in 13 of 20 docs. Checked on copies: idempotent, and every word, link, code span and list item kept.
