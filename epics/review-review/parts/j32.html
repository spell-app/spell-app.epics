The note is kept as you type (in the browser, per page and item); after a reload, every item with an unsaved note opens its box again with the text.

  • Escape closes the box and keeps the note; the check or send button saves it and forgets the draft; Clear in the menu drops both.
  • Example: start typing on J3, VS Code restarts: J3's box is open again with your text.
  • a half-written question is never lost, and never sent until you press a button
