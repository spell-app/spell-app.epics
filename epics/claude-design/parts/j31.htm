Chose one rule, docsArea() in site.types.ts, over a regex per tab, because the areas nest in names: templates/epics/plan.html holds /epics/, templates/goals/ holds /goals/.

  • the first area folder in the path wins: the plan template lights Templates, a plan doc Epics
  • a worktree's path is read from inside it (/worktrees/<w>/, .claude/worktrees/<w>/), so a worktree named goals isn't Goals
  • older checkouts' packages/docs/content/... and packages/docs/... paths still light the right tab
  • the home and the scratch details pages (pages/) light none; before P5 they lit Docs

Net effect: a table of 33 paths pins it (site.types.test.ts).
