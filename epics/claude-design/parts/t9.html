Check that a split plan doc updates in place, without reloading or jumping.

  1. Show this doc from the claude-design window, so its page server serves it.
    • spell dev plan-doc open claude-design
  2. Unfold Phases and P3, and open an item.
  3. In a terminal, run the two commands below.
spell dev plan-doc log claude-design "flicker test"
spell dev plan-doc close claude-design <some item>

What should happen:

  • The page doesn't reload or jump.
    • The log line appears in the log, if it's unfolded.
    • The item's chip turns grey.
    • P3 stays unfolded, and the open item stays open.
  • Opening a section or item shows its body at once: it loads from the parts folder.
  • A link to an Overview h4 lands on it, loading its sub-section first.
