The design bundle carries every free Font Awesome icon, registered by name when it loads.

  • How: one inlined string, an <svg> holding all 2,159 icons, parsed once.
    • Each icon is registered with UI.icons.register().
  • Not chosen: a new in-memory icon pack API in @spell-app/ui.
  • Why: register() already exists, and costs nothing measurable.
    • The bundle runs in ~65 ms, and draws its first icon at ~105 ms: the same as the docs bundle.
  • The names, in three layers:
    1. Exactly what ui's fa7-free pack gives:
      • its file names
      • their … outline forms
      • Font Awesome's aliases, like cog
    2. Then fa7-brands, only where the free pack has no such name.
      • 4 clashes, all Font Awesome's own logo: font awesome, web awesome.
    3. Then the docs' own icon names on top (ICONS), so widget names work as in the docs.
      • E.g. close and search. Also remove.
      • One difference from plain fa7-free: sign in is right-to-bracket, as in the docs.
  • The licence text is kept ONCE, as a legal comment at the end of the bundle.
    • Each SVG's own Font Awesome licence comment is stripped: they're identical.
    • And <!-- can't be in the bundle.
    • That saves about 480 KB raw, and keeps the CC BY attribution.
  • Fomantic's icon names are not included (not asked for).
  • 2,889 names reach 2,159 icons; icons add about 1.5 MB raw.
  • A prefixed name (fa7-free:bell) draws nothing in a design: registered icons answer plain names only.
