Chose to register every icon with UI.icons.register() from one inlined string (an <svg> holding all 2,159 icons, parsed once) over adding an in-memory icon pack API to @spell-app/ui, because register() already exists and costs nothing measurable: the bundle runs in ~65 ms and draws its first icon at ~105 ms, the same as the docs bundle.

  • names: exactly what ui's fa7-free pack gives (file names, … outline, FA's aliases like cog), then fa7-brands only where fa7-free has no such name (4 clashes, all FA's own logo: font awesome, web awesome), then the docs' ICONS names on top so widget names (close, search, remove) work as in the docs; one difference from plain fa7-free: sign in is right-to-bracket, as in the docs
  • each SVG's Font Awesome licence comment is stripped (they're identical, and <!-- can't be in the bundle) and the text is kept ONCE as a legal comment at the end of the bundle: saves about 480 KB raw, keeps the CC BY attribution
  • Fomantic's names are not included (not asked for)
  • 2,889 names reach 2,159 icons; icons add about 1.5 MB raw
  • a prefix:name (fa7-free:bell) draws nothing in a design: registered icons answer plain names only
