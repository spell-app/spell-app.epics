One rule picks which top-bar tab a page lights, not a regex per tab: the first area folder in its path wins.

  • The rule: docsArea().
  • Why: the areas nest in names.
    • The plan template (plan.html) has /epics/ in its path.
    • The goals templates (goals) have /goals/.
  • The first area folder wins: the plan template lights Templates, a plan doc Epics.
  • A worktree's path is read from inside it, so a worktree named goals isn't Goals.
    • Both forms: the server's worktree URLs, and the worktree folders themselves.
  • Older checkouts' paths, under the old docs folders, still light the right tab.
  • The home and the scratch details pages (in pages) light none.
    • Before P5, they lit Docs.
