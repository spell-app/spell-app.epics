The shared Spell UI page template loads the site's script and styles from the shared ui folder, not from ui's package.

  • The template: spell-ui-docs.html.
  • It points at the site's styles and script in the shared ui folder (the two paths below).
  • Why: the bundle finds the layout beside its own folder.
    • Loaded from ui's package, it would fetch the layout from the package's site folder, where it's gone.
  • site:new rewrites that prefix for the page's depth.
    • That's TEMPLATE_SITE.
chosen      ../ui/_assets/site.css|js
not         ../spell-ui/site/_assets/
            -> would fetch spell-ui/docs/__parts/layout.html, gone
  • The template, opened from the page server, shows in the site's layout, as before.
  • An older checkout's site:new expects the old paths, so it would write wrong ones: see the caveat.
