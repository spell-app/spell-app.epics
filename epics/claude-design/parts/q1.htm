Answer · Claude Code carries them: /design pull and /design push

How a design made in Claude Design becomes a page in spell-app-dev, and how an existing page gets into Claude Design to edit. Claude Design can't read or write files on your laptop, so something has to carry pages across (1.5).

A · Claude Code carries them: /design pull and /design push (recommended)
  • /design pull <design link> guides/pony.html: Claude reads the design and writes it as a page, on our page template, keeping the ui-* markup
  • /design push guides/pony.html: sends a page up as a new design to edit there
  • cost: two skill commands; a design may need tidying into our page shape
 B · By hand
  • download or copy the HTML from Claude Design, paste it into a file
  • cost: nothing to build; every trip is manual, and pages drift from the template
 C · Claude Design for exploring only
  • pages are only ever edited in VS Code; Claude Design makes mock-ups that Claude Code then rebuilds
  • cost: nothing to build; no edits come back

Net effect (A):

  • two new commands in the design skill: /design pull and /design push
  • the pony comes back to spell-app-dev through /design pull
