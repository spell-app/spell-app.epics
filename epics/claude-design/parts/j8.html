P7's design-system generator lives in Spell UI's package, as yarn design:build. spell dev design build passes through to it, and its output goes in ui's build folder.

  • The generator: DesignExport, plus three helpers.
    • DesignTokens
    • DesignComponents
    • DesignColor
  • Not chosen: new code in the CLI (dev).
  • Why:
    • ui owns what it reads: its site data (components.json), the examples and the theme sheets
    • the CLI may import ui, but not the other way round
  • spell dev design build [--out <dir>] runs ui's script (design-build.ts).
    • A pass-through, like spell dev details.
    • push and pull can join the same noun in P9.
  • Its output goes to ui's build folder, git-ignored (design-system/project).
    • Not ui's dist, which yarn build empties.
  • A rerun clears old cards, but keeps the bundle P8 writes into the same folder (bundle.js, and its CSS).
  • The commands page has a new row in commands.json, and its 5.2 Names table a design noun.
