Two small calls about split plan docs.

  1. Each host in the skeleton holds one line saying where its body is, not nothing.
    • "Loads from parts/p3.htm when opened (needs the page server)", as p.plan-part-note.
    • With the loader, it's replaced at once: the panel stays shut while the body is on its way.
    • Without it (a page server on older code, or file://), it says where the body is, instead of an empty section.
  2. plan-doc check now also checks the doc's file links: all of them, parts included.
    • Six finished docs already had broken links from the docs' moves (see the issue).
    • A failing check would have blocked splitting them.
    • So the links print as LINK:, and fail the check only with --links.
  • Split docs read sensibly even where bodies can't load.
  • plan-doc check <name> --links is the strict form.
