Owen saw "This preview could not run" on the spike system's cards, and the spike Design's counter didn't click (2026-10-05). Cause: the one-file bundle finds its lazy scripts with new URL("lazy/", document.currentScript?.src ?? location.href).

  • a design system's preview INLINES the bundle, so currentScript.src is "", which ?? doesn't replace
  • the preview frame's location.href is about:srcdoc, which no relative URL resolves against either
  • so new URL threw before any element was defined: every card fell back to its static preview

Fix: packages/epics/tools/bundle-spell-ui.js now writes a bundleUrl(dir) helper that never throws (||, and null on failure, so a lazy script rejects instead). The spike's copy got the same patch. Reproduced and checked locally with Playwright (scratchpad/repro/repro.mjs):

  • card, old bundle: Failed to construct 'URL': Invalid base URL, nothing defined
  • card, fixed bundle: SpellUI defined, <ui-button> renders, no errors
  • the Design artboard under Claude Design's own runtime (dc-runtime.js) with the fixed bundle: "Clicked 0 times" becomes "Clicked 1 times", the label follows, no errors
