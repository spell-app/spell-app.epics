The docs home is a grid of cards, one per area, in ONE open section ("Areas"), not a folded section per area.

  • Why: a routing page's cards must be on screen when it opens.
  • And the docs runtime and the page checker still want a foldable section to work on (check-spell.js).
  • A · one open "Areas" section, a card each, plus a folded "About these docs" (chosen).
  • B · a folded section per area: seven clicks to see seven links.
  • C · bare cards, no section: no contents entry, and check-spell fails ("no foldable section on the page").
  • Each card shows:
    • an icon
    • a title, linked to the area's list page
    • its count: "3 running · 18 done", "23 guides", "72 component pages", "1 goal set"
    • a one-line description
  • The cards carry ids named for their areas, like epics and guides.
    • So old #epics links to the home land on the right card.
  • The list pages' own sections start OPEN: the list is the page.
  • Their notes (Writing docs, Files) start folded.
  • The home lights no tab; the Spell logo goes there.
