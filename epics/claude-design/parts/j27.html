The home's cards have NEW markers, not the old list markers (index:start / index:end).

  • Why: the home is shared, and every checkout's docs index tool writes it (index.js).
  • An older one (main, and the other worktrees, until this branch merges) would write its three old lists straight back over the routing cards.
  • A · new markers on the home (chosen): an older index tool finds none, and stops.
  • B · keep the old markers: the home flips back to three lists whenever an older checkout runs docs index or a plan-doc command.
  • Until main merges claude-design, older checkouts' plan-doc commands print a warning.
    • "docs index not updated: missing <!-- index:start -->"
    • Harmless: nothing is written.
  • The list pages keep index:start / index:end: older code never knew them.
