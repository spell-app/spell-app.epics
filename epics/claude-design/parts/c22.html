With Spell UI's pages shared, an edit on one branch shows in every checkout before that branch merges.

  • A page edited for an element only one branch has shows that element undefined in other checkouts, until the branch merges.
    • Each checkout serves its own built assets.
  • site:index and site:kitchen write the SHARED index and kitchen sink, from THIS branch's data.
    • A branch with a new family adds its card everywhere.
    • Other checkouts' --check says stale, until it merges.
  • The search index is shared (search.json).
    • After a section edit, SiteDataBuilder.test.ts fails in EVERY checkout.
    • Until someone runs yarn site:data, once (no commit).
  • Pages opened from disk (file://) no longer find their bundle: view them through the page server.
