Page paths given to the docs tools are now from the checkout's root. A path relative to an area, or an old path, still finds the page.

  • Before: every docs tool took page paths relative to the old docs folder (content).
  • Now: from the checkout's root, e.g. the Solid 2 guide's full path, solid-2.html.
  • The page finder (pageFile()) also tries:
    • each area: the Solid 2 guide's path without the guides folder still finds it
    • the home, as just index.html
    • the old path, under the old docs folder
  • epic pages create puts a page in the guides, unless its path starts with the guides or pages folder.
  • The tool's folder constants:
    • EPICS, TEMPLATES
    • GUIDES, PAGES
    • HOME, DETAILS
    • AREAS
    • the old DOCS is gone, so a use that was missed fails loudly
  • The page server ALWAYS redirects /packages/docs/content/<x>, even while the old path resolves.
    • So each page has one address.
  • epic pages open solid/solid-2 still works.
