The brand elements get into the design bundle through a small Vite library build in spell-brand. The design bundle's esbuild can't compile their Solid JSX.

  • The build: vite.design.config.ts, run by bundle-spell-ui.js --design.
  • Not chosen: bundling brand's components straight from source.
  • Why: the elements are Solid JSX, which only the Solid compiler turns into code.
  • Its entry (brand-design.ts) defines the accent hue first, then every element.
    • Spell UI and Solid stay external.
    • The bundle resolves Spell UI's core and forms to its built dist/: the same modules its own elements use.
    • So there's one UIElement, one ValueSets, one Solid.
  • It's imported BEFORE Spell UI's families in the design entry (spell-ui.design.entry.js).
    • So accent is a hue when they define (issue I17).
  • Rejected:
    • an esbuild Babel plugin for Solid JSX: a second compiler setup to keep in step
    • the brand pages' own bundle: brand-ui.js carries its own copy of Spell UI
  • The design bundle: 5.15 MB (gzip 1.49 MB), was 4.8; the cap is 6 MB.
  • yarn design:bundle takes about a second longer.
