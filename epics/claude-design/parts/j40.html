Chose a small Vite library build in packages/brand (vite.design.config.ts, run by bundle-spell-ui.js --design) over bundling components/ straight from source, because the elements are Solid JSX, which only the Solid compiler turns into code, and esbuild (which makes the design bundle) can't.

  • src/brand-design.ts: the accent hue first, then every element; $/ui/* and Solid stay external, and the bundle resolves $/ui/core / $/ui/forms to Spell UI's dist/, the same modules its own elements use: one UIElement, one ValueSets, one Solid
  • imported BEFORE Spell UI's families in spell-ui.design.entry.js, so accent is a hue when they define (issue I17)
  • rejected: an esbuild Babel plugin for Solid JSX (a second compiler setup to keep in step); the brand pages' own bundle (brand-ui.js carries its own copy of Spell UI)
  • the design bundle: 5.15 MB (gzip 1.49 MB), was 4.8; the cap is 6 MB
  • yarn design:bundle takes about a second longer
