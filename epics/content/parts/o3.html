Another epic that finds a content fix (a typo in an example, a notebook that no longer compiles, a guide that tells the old way) sends it here as a REQUEST, rather than fixing it on its own branch.

  • How: /send content <what> from that session; it lands as a request (r1 ...), and this session files it into a phase.
  • Why: that epic's branch stays about its own work, and two branches never edit the same example at once.
  • Not content: a change the example needs BECAUSE that epic changed the language or a component. That stays in the epic that broke it, so its branch passes its own tests (Q2).
  • Today nothing tells another session to do this; WWOD even says the opposite, "fix it in place" (Q5).
  • The word is "request", as /send says: WWOD already uses "driveby" for a fix made in place.
