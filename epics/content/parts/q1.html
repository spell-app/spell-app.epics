The kickoff names examples and notebooks. The same space holds two more kinds of content:

  • the 12 guides (@spell/guides), each a walk through one example, which go stale when the example changes
  • the people library (@spell/library/people), which the people-and-orgs epic built

A guide follows its example, so one change edits both. The library is code the language leans on: it stays with its epic.

One rule, easy to say: if it is under spaces/@spell/ and not test/, it is content.
