A small script counts the page's words once the page has drawn, and writes the chip into the head.

  • Counting: a new function, readingTime(), takes the page's main column and returns its word count and its minutes.
    • Words in prose count at 230 a minute, a typical adult reading speed (Q1).
    • What happens to code blocks is open: Q2.
    • Folded sections count too: they are on the page, just closed (C1).
  • Showing: the chip goes into the one-line head that oneLineHead() already builds, beside the title.
    • Its tooltip gives the exact count: "1,412 words".
    • Where exactly it sits is open: Q3.
    • A live update to the page (an edit saved while it's open) recounts.
/** How long the page takes to read:  its words, and the minutes at 230 a minute (Q1). */
function readingTime(main) {
  const text = proseOf(main)          // the main column's text, code blocks per Q2
  const words = text.split(/\s+/).filter(Boolean).length
  return { words, minutes: Math.max(1, Math.round(words / 230)) }
}
