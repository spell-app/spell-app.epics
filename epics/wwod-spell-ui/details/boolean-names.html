wwod-spell-ui -- the house style (WWOD) applied to Spell UI; P13 decides how true / false names are spelled. P13's proposal asks five questions (Q22-Q26), one per kind of boolean; you wanted each name's context before deciding, so here is every name the recommended options touch. The rename list the later rename phase applies: a row you leave as it is goes in as recommended, a row you retype goes in as you typed it.
  • Each row is one name, where it's declared. File opens it at that line in VS Code; Current is how the code reads today; Recommended is Claude's call, already filled in.
  • Agree: leave the box as it is. Disagree: type what you'd write instead. A changed box is marked; its round button puts the recommendation back.
  • What you type is saved every few seconds (the toolbar says when): a reload or a closed tab keeps it.
  • Do it sends every box and your feedback to Claude. Change anything after and press it again: the new answer replaces the old one.

Q22 (proposal 1.4.1-1.4.3), recommended A: what a class of ours holds or works out (getters, methods, cells, memos, fields) is is / has / can (or was / should / needs), or a verb that already asks the question; never a bare adjective

Q23 (1.4.4), recommended A: options, props and @proto static switches are bare, the platform's way ({ once: true }); a noun keeps is / has; the field a setting is copied into takes its name

Q24 (1.4.5), recommended A: records we define follow the members rule (is / has, or a verb); shapes copied from outside (JSON on disk, LSP, Fomantic, platform, upstream ports) keep their names

Q25 (1.4.6), recommended A: locals and parameters free (a noun takes is); a yes / no function is is / has / can or a verb: sameX(a, b) becomes isSameX(a, b), like node.isSameNode(other)

Q26 (1.4.7), recommended A: in a Solid controller a tracked yes / no read is a call (a method or a memo); an untracked read, and anything outside controllers, is a getter
