One plain record per controller is the only truth, read and written at once; each property has a small signal that tells Solid it changed. So one name reads fresh anywhere, and is tracked inside JSX, a getter or an effect. The decorators are how a member says which kind it is.

Cells and signals become @state accessor x = v: read this.x, write this.x = v, fresh at once and tracked; booleans read as English

A Cell plus a plain field (or wrapper, or setter) kept for a synchronous read merges into ONE @state accessor; every name that disappears has its own row

this.controlled("open", false) and its isOpen() wrapper become @controlled("open") accessor isOpen = false; a user change is this.requestChange("isOpen", next, announce)

createMemo fields become plain get x() (cheap: spell measured memoizing ~2x slower), @derived get x() only for costly ones (loops, parsing, class strings, new DOM); no-arg value methods become getters

The vocabulary gives a getter per attribute, converted: this.attrs.displayTime becomes this.displayTime; typed views (common, dialogAttrs, sourceAttribute()) and attribute-only methods go

new E.HostAttribute({ host, name }) becomes this.attributes["aria-label"]: the raw DOM string (string | null), tracked, internal only

An English name; a getter when it takes no arguments (get isDisabled()), a method when it does (hasContent(name))

A setX(v) that only writes becomes this.x = v; setter closures go; an action that sends an event stays a method with a verb name (open(event), requestClose())

Each hostStates() entry becomes @cssState("<state>") on the member it reads (or a small getter); the hostStates() overrides go

An effect that reads members and does one thing becomes @onChange("a", "b") onXChanged() (it may return a cleanup); conditional, per-item or object-building effects stay explicit

Event handlers and moment callbacks are on...: onKeyDown, onLoaded, onError, onMount; handlers already named on... aren't listed unless something else changes
