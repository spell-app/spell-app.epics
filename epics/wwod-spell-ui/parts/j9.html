The error kinds stayed load, cross-origin, file-protocol, save, conflict, no-saver, render, though Q1's example showed "file protocol". Why: pages read them, so they fall under AGENTS.md "Functions & types" ("values a page reads keep their published spelling").

  • they reach pages as the ui-error event's detail.kind
  • a page's saver that can't import SourceError throws { kind: "conflict" } itself
  • both are published: packages/ui/docs/ui-include.html (Events) and guides/ui-import/ui-import.html list every value; WWOD §5's own example uses kind: "file-protocol"
  • SOURCE_ERROR_KINDS is now SourceErrorKinds (const array) + SourceErrorKind (its type), same values
  • a NOTE on SourceErrorKinds (src/runtime/runtime.types.ts) says why they're kebab-case
