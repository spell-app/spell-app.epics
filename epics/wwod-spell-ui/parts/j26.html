A tag with no skeleton says skeleton: false, not null. It's the vocabulary's way of saying "deliberately none".

  • Why false, over a sentinel of our own:
    • Vocabularies are pure data that node imports, and false needs no import in 57 files.
    • It reads as English: skeleton: false.
    • It survives JSON.
  • The options:
    • false: picked.
    • A NONE sentinel of ui's own: a value import into every vocabulary. And UIT.NONE is already the CSS word "none".
    • Keep null: against Q9, since this isn't a platform boundary.
  • undefined still means "not said yet". vocabularies.test.ts still requires every tag to say which.
  • The type is skeleton?: SkeletonSpec | false, in vocabulary.types.ts.
  • 57 vocabularies changed skeleton: null to false: 56 in ui, and brand's ui-brand-check.
  • The readers:
    • the vocabularies test checks === false
    • gen-root-catalog.ts already tested truthiness, so its output came out unchanged
    • unchanged outputs:
      • ui-root.catalog.ts
      • ui's site/_data
      • brand's _data
    • status.md's root row
