Some of the gaps weren't ui breaking a rule. WWOD (written for app code) and ui's AGENTS.md (written for a library of custom elements) say different things, or WWOD's own ui examples break WWOD.

  • Each got a ruling before code moved, written once in ui's AGENTS.md (P1).

Where they disagreed:

  • Namespaces (Q4):
    • WWOD §4 wants ONE namespace, qualified at the use site (P.Match)
    • ui exports three namespaces (E, V, SSR), but no file uses them
    • ui's AGENTS.md says two things:
      • "plain named imports from components.types"
      • "UIT.<NAME>, never bare"
  • Constants (Q2):
    • WWOD §9 wants a set of values as a const array or object
    • ui is built on one loose ALL-CAPS constant per word
  • Logging (Q5): WWOD §19's Logger lives in spell-kit/util/spell. It imports chalk, which ui must never load.
  • WWOD examples that break WWOD:
    • SourceError (§5)
    • CodeLines.TOKENS and CalendarDates.MINUTE_STEP: §12 says "after the main methods", but both sit at the top
    • FormFields and CalendarDates: §12 cites them, but they take positional constructors
    • ExampleSource.format(html, live): a positional boolean
  • WWOD §17 (Solid components) and §18 (CSS naming) were written for the app's function components and sheets.
    • ui's controller classes draw their pieces as private methods
    • its shadow sheets use Fomantic's class grammar (.ui.small.button)

How each was settled:

  • Namespaces: ONE per sub-system, E from the core entry and F from forms, after a spike showed the bundles unchanged (Q4, Q19)
  • Constants: sets became const arrays plus types; single words stay (Q2); one class's constants stay module constants below it, since they minify (Q18)
  • Logging: no Logger in ui, for bundle size: one Warnings.warn() / devWarn() format (Q5)
  • WWOD's examples that broke WWOD: the code changed to match (Q15), and WWOD's citations were brought up to date (J107)
  • CSS: Fomantic's class grammar is exempt from WWOD §18's naming; the --_<tag>-* plumbing keeps its names (Q13)
  • Every other proposal became a decision (Q6-Q16).
