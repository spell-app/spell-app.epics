Chose to rename J50's ALL-CAPS UIT const objects and vocabulary tables (kept for ~150 call sites, churn only) to WWOD §9's PascalCase const objects, over leaving them. TOGGLE_COMMANDS would have become ToggleCommands, the name of the class that reads it, so the words moved INTO that class as static readonly fields: UIT.ToggleCommands.show, beside action(). TABLE_SORT_OPT_OUT stays ALL-CAPS (a frozen pair, WWOD §9's frozen singletons).

In <ui-docs-search>, isShown (the card shows, :state(open)) became isOpen, so the cell that held that name (the card is wanted: focus or typing since the last close) became isWanted. UISearch keeps isShowing: its isOpen() is the open attribute, a different thing.

Net effect:

  • no public element API changed; UIT is @spell-app/ui's exported namespace, so a page importing UIT.TOGGLE_COMMANDS etc. would need the new names (none outside ui did)
  • ui AGENTS.md 'Functions & types' now says maps are PascalCase
