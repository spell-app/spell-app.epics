UIT's maps and the vocabulary tables are PascalCase now, undoing J50, which kept them ALL-CAPS. Two names moved with them.

  • J50 kept the ALL-CAPS const objects for about 150 call sites, since renaming them was churn only. They now follow WWOD §9: PascalCase const objects.
  • TOGGLE_COMMANDS would have become ToggleCommands, the name of the class that reads it.
    • So its words moved INTO that class, as static read-only fields.
    • For example UIT.ToggleCommands.show, beside action().
  • TABLE_SORT_OPT_OUT stays ALL-CAPS: a frozen pair, one of WWOD §9's frozen singletons.
  • In the docs search, isShown became isOpen: the card shows, :state(open).
    • So the cell that held that name became isWanted: the card is wanted, after focus or typing since the last close.
    • UISearch keeps isShowing: its isOpen() is the open attribute, a different thing.
  • No public element API changed.
  • UIT is ui's exported namespace (@spell-app/ui). So a page that imports UIT.TOGGLE_COMMANDS and the like would need the new names; none outside ui did.
  • ui's AGENTS.md, "Functions & types", now says maps are PascalCase.
