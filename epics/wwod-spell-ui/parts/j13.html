In the source layer, the reads a host's script uses became getters: content, etag and isDirty. The host's own API is unchanged.

  • Why: the component reads that SourceHost hands on were methods that read like getters. WWOD §12 › "Derived reads are plain getters".
  • The host API is the same: host.content, host.etag and host.dirty.
  • SourceElement.getContent() became get content.
    • UIInclude overrides the getter, through super.content.
    • The code element's copy button reads it.
  • getEtag() became get etag.
    • The etag Cell it shadowed is GONE: nothing read it.
    • A grep found only setEtag() writing it, so that went too.
  • isDirty() became get isDirty. The tracked dirty cell stays: it drives :state(dirty).
  • SourceController, in the elements' types, declares content, etag and isDirty as read-only.
  • SourceElement.readInline(host) became inlineTextFor(host), WWOD §3's lookup form.
    • Its 2 callers: ui-code.fallback.ts and ui-markdown.fallback.ts.
    • It now tests the tag's name, not instanceof a script or template element.
  • SourceBody.veiled() and busy() became the getters isVeiled and isBusy.
    • 3 callers, in the section and the accordion.
    • Their own veiled and busy memos keep their names.
  • No change to any element's script API or events.
  • Every caller in packages/ is fixed; no doc cited the old names.
