The controller reads SourceHost delegates to were methods that read like getters (WWOD §12 › "Derived reads are plain getters"), so they became getters; the host API (host.content, host.etag, host.dirty) is unchanged.

  • SourceElement.getContent() -> get content (UIInclude overrides the getter, super.content; UICode copy button reads it)
  • getEtag() -> get etag; the etag Cell it shadowed is GONE: nothing read it (grep: only setEtag() wrote it), so setEtag() went too
  • isDirty() -> get isDirty; the tracked dirty cell stays (it drives :state(dirty))
  • SourceController (elements.types): readonly content / etag / isDirty
  • SourceElement.readInline(host) -> inlineTextFor(host) (WWOD §3 lookups): 2 callers, ui-code.fallback.ts, ui-markdown.fallback.ts; it now tests localName, not instanceof HTMLScriptElement / HTMLTemplateElement
  • SourceBody.veiled() / busy() -> get isVeiled / isBusy: 3 callers in UISection / UIAccordion (their own veiled / busy memos keep their names)

Net effect:

  • no change to any element's script API or events; every caller in packages/ fixed, no doc cited the old names
