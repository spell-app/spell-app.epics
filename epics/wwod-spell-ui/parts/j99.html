  • Its other groups keep the sheet's name plus an aspect, the way "<ui-button> keyboard" names an element's.
    • "ui-x.css examples"
    • "ui-x.css tokens"
    • "ui-x.css in shadow roots"
  • Rejected: one bare "ui-x.css" for every group. That would give a file four describes with the same name.

    "ui-x.css source"                                       -> "ui-x.css"
"ui-x static render" / "ui-x (static render)" / "ui-x, static" -> "<ui-x> static render"
