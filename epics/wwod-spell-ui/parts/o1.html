Five agents read ui against every WWOD rule (2026-10-05), one slice each: the element core and static render, the runtime and vocabulary, families ui-accordion to ui-loader, families ui-markdown to ui-visibility, and the docs components, tests, tools and scripts. Nothing was changed.

The surface style is already close. Across all ~900 files:

  • no interface (outside module augmentation), no TS enum, no #private
  • no jsdoc @param, no unicode em-dash, two spaces after every period
  • //////////////// group headers well formed; most element classes carry the /**** banner
  • no test file mixes it() and test(); every test imports from vite-plus/test
  • CSS: no rem, no live !important, no :host-context, public tokens read through private aliases
