Where ui stood when the epic started: five agents read it against every WWOD rule (2026-10-05), one slice each. Nothing was changed.

  • the element core and the static render
  • the runtime and the vocabulary
  • the families from accordion to loader
  • the families from markdown to visibility
  • the docs components, tests, tools and scripts

The surface style is already close. Across all ~900 files:

  • no interface (outside module augmentation)
  • no TS enum, no #private
  • no jsdoc @param, no unicode em-dash, two spaces after every period
  • //////////////// group headers well formed; most element classes carry the /**** banner
  • no test file mixes it() and test()
  • every test imports from vite-plus/test
  • CSS:
    • no rem, no live !important
    • no :host-context
    • public tokens read through private aliases
