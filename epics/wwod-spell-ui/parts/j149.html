Renames in the toast, progress, docs search and parts components. The toast's display duration is now @derived.

  • The toast's displayDuration computes on first read. So slotted text added before the toast shows counts toward it.
  • The progress bar's ARIA effect is @onChange("ariaValues"). Its ariaValues is protected: only the decorator reads it, by name.
  • The docs search's Cells and memos became members: query, highlighted index, grouped rows ...
  • The renames: 
    UIToast         displayTime()   -> displayDuration  (@derived)
                canClickClose() -> anyClickCloses
                isCounting      -> countdownHasStarted
UIProgress      state()         -> shownState
                barColors()     -> barHues
ProgressValues  bars            -> barCount
UIDocsSearch    Cells and memos -> query, highlightedIndex, groupedRows ...
  • The toast's test reads displayDuration; no outside caller.
