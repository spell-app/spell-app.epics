The popup's trigger words ("hover" x5, "click" x5, "focus" x2) and the search's match words were literal strings compared in code, and the vocabularies repeated the lists. Chose the UIT.Key shape (a const object, same name as its type) plus a list built from it, over a bare const array, because the code COMPARES single values: 

export const PopupTrigger = { hover: "hover", focus: "focus", click: "click", manual: "manual" } as const\nexport type PopupTrigger = (typeof PopupTrigger)[keyof typeof PopupTrigger]\nexport const PopupTriggers = [PopupTrigger.hover, PopupTrigger.focus, PopupTrigger.click, PopupTrigger.manual] as const\n\nif (trigger === UIT.PopupTrigger.click) ...      // UIPopup, PopupFallback\nvalues: UIT.PopupTriggers, default: UIT.PopupTrigger.hover   // ui-popup.vocabulary.en.ts
  • Same for UIT.SearchMatch / UIT.SearchMatches (SearchMatcher, ui-search.vocabulary.en.ts).
  • Option not taken: a const array only (PopupTriggers), which leaves every comparison a literal.
  • The type names UIT.PopupTrigger / UIT.SearchMatch are unchanged; nothing outside ui-popup / ui-search read them.
  • Published values unchanged (on="click", full-text-search="fuzzy").
