ui's server render moved to src/static/. Every file is named .server.ts, and its tests <Name>.server.ssr.test.ts.

  • That follows WWOD §10 › "Server code stays out of the browser bundle".
  • The folder was server/.
    • Its alias is now $/ui/static; the namespace is still SSR.
  • Every source file is <Name>.server.ts.
    • For example StaticRender.server.ts, and ServerHost.server.ts.
    • The types file is static.types.server.ts.
    • The barrel is still index.ts: what the alias resolves.
  • Tests: StaticRender.server.ssr.test.tsx, not the old StaticRender.ssr.test.tsx.
    • A test is named for its module (WWOD §20 › "Tests follow the logic"), and it still sorts beside it.
    • It still ends .ssr.test.ts(x). So the root config's SSR_TESTS glob keeps it in the server-render project, out of the browser one, with no config change.
  • 18 files moved with git mv, so history is kept; git mv stages the renames.
  • Every importer and mention of $/ui/server in packages/ is renamed: about 100 files.
    • Mostly the families' static-render test imports, and comments.
    • The shared docs are left as history.
  • ui's AGENTS.md, "Overview", states the naming and the import rule.
