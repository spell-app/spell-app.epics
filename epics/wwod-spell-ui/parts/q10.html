WWOD §3 says module constants go before the code that uses them, §8 says class first; ui says nothing stays loose in an element file. We extend ui's rule to src/elements/, src/server/ and src/runtime/:

  • a constant several files use: <folder>.types.ts
  • one class's constant: a private static after its methods (WWOD §12)
  • a page-wide registry (WeakMap, Set): private static readonly plus static reset() for tests (WWOD §15)
  • about 200 module-level constants and 12 module-level registries move
