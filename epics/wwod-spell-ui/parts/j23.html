ControlLabels imports its helper LabelWatch directly (import { LabelWatch } from "./LabelWatch"), not as F.LabelWatch.

Chose that over adding LabelWatch to forms.ts because it is ControlLabels' private helper, deliberately in neither the $/ui/elements barrel nor the forms entry: exporting it would make it public API of @spell-app/ui/forms (and F in the api entry) just to satisfy the namespace rule. WWOD only forbids reaching into a leaf for something its barrel exports.

Net effect:

  • the one peer import left in the forms files that is NOT a load-time exception; commented // Not in the forms entry: ControlLabels' own helper
  • LabelWatch itself uses E and import type { F } (F.ControlLabels)
