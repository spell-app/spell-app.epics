A :state() that is always on is now a getter that returns true.

  • The table said a field: @cssState("pane") readonly isPane = true.
    • But @cssState is typed for getters and accessors only.
    • On a field, it fails with TS1240.
  • So it's written as a getter: 
    @E.cssState("x") get isX() { return true }
  • On these: 
    UIPlaceholder.isPlaceholder, UICards.isCards, UITab.isPane, UISteps.isStepGroup, UIItems.isItemsView,
UIPushable / UIPusher / UISidebar, UIOr, UIDimmer, UIStatistic(s), UIForm.isRoot, UIField, UISide
  • The same states.
  • About 15 three-line getters, which a class-level form could replace later.
