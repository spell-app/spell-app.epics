Private methods and fields were renamed where an attribute now has their name. A member named like an attribute hides its getter, and clashes in the interface line.

  • Where it helps, each has a one-line note: "Not x(): x is the attribute's".
  • The renames, by group: 
    DialogElement.overlay          -> overlayEntry                    (2)
UISection.foldIcon()           -> foldChevron()                   (2)
UIDocsExample.description()    -> descriptionWithCode;  it had been hiding the attribute   (2)
UIPopup.target                 -> targetElement                   (4)
UISearch.category()            -> resultCategory()                (5)
UIRating.icon(point)           -> pointIcon(point)                (5)
UIButton.content() / icon()    -> iconAndText() / iconBox()       (7)
UITable's data columns         -> dataColumns                     (8)
UIProgress.barText(i)          -> barTextFor(i)                   (9, public)
UIEmbed.placeholder()          -> playButton()                    (10)
  • All private, except UIProgress.barTextFor(), which has no caller outside its folder.
