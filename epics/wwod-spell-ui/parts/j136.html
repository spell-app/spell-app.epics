A method or field with an attribute's name hides its getter (and clashes in the interface line), so private pieces were renamed (each with a one-line "Not x(): x is the attribute's" where it helps):

  • DialogElement.overlay -> overlayEntry; UISection.foldIcon() -> foldChevron(); UIDocsExample.description() -> descriptionWithCode (it had been hiding the attribute) (group 2)
  • UIPopup.target -> targetElement (4); UISearch.category() -> resultCategory(), UIRating.icon(point) -> pointIcon(point) (5)
  • UIButton.content() / icon() -> iconAndText() / iconBox() (7); UITable's data columns -> dataColumns (8); UIProgress.barText(i) -> barTextFor(i) (9, public); UIEmbed.placeholder() -> playButton() (10)
  • private names, except UIProgress.barTextFor() (no caller outside the folder)
