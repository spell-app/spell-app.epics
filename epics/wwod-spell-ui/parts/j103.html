In ui-r through ui-v, every kind of test file now names its describes the way element tests already did: the subject, then the aspect (<ui-x> aspect). Rejected: one bare name each.

  • Sheet tests keep ui-x.css source, examples, and tokens.
    • The file is the subject, and the word after it is the aspect, like <ui-x> keyboard.
    • Free text took that shape: "pusher tokens" became ui-sidebar.css pusher tokens.
  • Static-render tests are all <ui-x> static render.
    • They were spelled three ways: "ui-x static render", "ui-x (static render)" and "ui-x, static".
    • Where a file renders a group, it names the group's tag: <ui-steps>, <ui-tabs>.
  • Fallback tests keep the class's name (RailFallback): one class, one describe.
  • Three more:
    • "ui-root catalog" became ROOT_CATALOG.
    • <ui-transition>'s "reduced motion, commands, accessibility" was split into three.
    • <ui-shape>'s accessibility check moved out of "flipping", into its own describe.
  • Banners group every element test, and every sheet test with 3+ describes or 150+ lines.
    • The groups: Rendering; Behaviour, Keyboard, Forms ...; Tokens; Accessibility.
    • A ## Helpers banner sits over helper functions at a file's bottom.
  • Only one test was renamed: 
    move, shrink and dim the pusher  ->  moves, shrinks and dims the pusher by its private tokens
  • Every other name was already a lowercase sentence. Key names and identifiers lead some: Escape ..., UIRoot.Loading ....
