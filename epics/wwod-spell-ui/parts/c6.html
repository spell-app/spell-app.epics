ThemeSheets.pageStyles() now does import("$/ui/core") instead of import("$/ui/runtime"). In the site bundle that is a 2.4 kB core-<hash>.js facade over the shared chunks (UIElement …). ThemePreference.restore() starts it before <ui-root> is imported, where before it loaded a 0.6 kB runtime-<hash>.js. It's the same bytes, which <ui-root> needs straight after, and the site's eager size is unchanged (210.0 kB / 46.8 gz). If it ever shows on first paint, ThemePreference can pass (await UI.load()).styles to apply(), and the import goes away.
