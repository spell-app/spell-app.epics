Reactive.installAttributeGetters() now installs a setter beside each getter: this.indeterminate = false writes host[definition.attribute(name).property], so a translated tag writes its own property, and the write reflects and converts like any property write. E.AttributeValues is writable (a controller's members); UIElement.attrs (the fork's props) is Readonly<>. Generic bases' declarations lost readonly to match (SourceElement, DialogElement, checkbox / input CommonAttributes).

  • Removed what existed only for the missing setter: UITransition's @controlled("visible") private accessor visibleProperty (animateTo() writes this.visible), UICheckbox.onChosen()'s cast host write (this.indeterminate = false). Both write the same host property as before.
  • Tests: the setter reflects and reads back; on a translated stand-in (<x-reactivo etiqueta>) it writes etiqueta, never label.

Net effect:

  • behaviour unchanged; a controller can now write any of its attributes (it only should for user-driven changes like these)
