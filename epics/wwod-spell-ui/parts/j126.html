A component's attribute getters now have setters too. A write goes to the host's property, under the tag's own name when it's translated.

  • Reactive.installAttributeGetters() now installs a setter beside each getter.
    • this.indeterminate = false writes the host property that attribute maps to. That's host[definition.attribute(name).property].
    • So a translated tag writes its own property.
    • The write reflects and converts, like any property write.
  • The types:
    • E.AttributeValues is writable: they're a component's members.
    • UIElement.attrs, the element layer's props, is Readonly<>.
    • Generic bases' declarations lost readonly to match. That's SourceElement, DialogElement, and the checkbox and input common attributes.
  • Removed what existed only for the missing setter. Both write the same host property as before.
    • UITransition's visibleProperty accessor. Its animateTo() writes this.visible.
    • UICheckbox.onChosen()'s cast host write: it's now this.indeterminate = false.
  • Tests: the setter reflects, and reads back. On a translated stand-in, <x-reactivo etiqueta>, it writes etiqueta, never "label".
  • Behaviour unchanged.
  • A component can now write any of its attributes. It only should for changes the user drives, like these.
