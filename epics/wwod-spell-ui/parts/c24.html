NativeFallback should get a typed part(name) for inner boxes, as UIElement has.

  • decorate(target, name) types its part name. But it also copies the host's aria-* onto the target.
    • That's right for the fallback's root.
    • It's wrong for an inner box: a breadcrumb's <ol part="list">, or a linked image's <img part="img">.
  • P5 (Families 5) used typed module constants instead: 
    const LIST_PART: E.PartNameOf<typeof breadcrumbVocabulary> = "list"
  • A protected part(name: PartNameOf<V>): string on NativeFallback would let every fallback write { part: this.part("list") }, as an element does.
  • Not changed here: ui's src/elements/ is P3's, which is done.
