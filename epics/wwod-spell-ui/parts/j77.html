Three copies became one each, in the shared docs types file (the brief allowed adding to it), chosen over a helper per family or a new loose file.

  • HeadingLevels.levelFor(value, LEVELS): the level clamp, written 6 times (3 elements, 3 fallbacks), now one rule. Each family keeps its bounds as ONE const, LEVELS: HeadingBounds = { min, max, fallback }, replacing MIN_LEVEL / MAX_LEVEL / DEFAULT_LEVEL.
  • VocabularyTexts.english(vocabulary, key, params): the fallbacks' English text lookup with {name} filling, copied in 3 fallbacks.
  • CODE_SPAN: the backtick regex ui-docs-example and ui-docs-tokens each declared.

Net effect:

  • the fallbacks now round and clamp level like the elements: level="3.6" drew an invalid h3.6 before (it threw), now h4; level="" is h1 in both (was the default in the fallback only)
  • the file header says it holds these small pure helpers too; the other docs families (nav, toc ...) can adopt them
