Code that the api, example, tokens and themes families each copied now lives once, in the shared docs types file. That beat a helper per family, or a new loose file; the brief allowed adding to the types file.

  • HeadingLevels.levelFor(value, LEVELS) keeps a heading's level in bounds.
    • It was written 6 times: 3 elements, and their 3 fallbacks. Now it's one rule.
    • Each family keeps its bounds as ONE const, LEVELS: HeadingBounds = { min, max, fallback }.
    • That replaces three separate constants: the minimum, maximum and default level.
  • VocabularyTexts.english(vocabulary, key, params) looks up a fallback's English text.
    • It fills in {name} placeholders.
    • It was copied in 3 fallbacks.
  • CODE_SPAN is the backtick pattern that finds code spans.
    • Both ui-docs-example and ui-docs-tokens declared their own.
  • The fallbacks now round and clamp level the way the elements do.
    • level="3.6" drew an invalid h3.6 before (it threw). Now it's h4.
    • level="" is h1 in both. Before, the fallback alone gave it the default level.
  • The file's header now says it holds these small pure helpers too. The other docs families (nav, toc ...) can adopt them.
