Chose a pack file that is a bare JSON ARRAY of entries, checked strictly, over an object with a version or a looser shape. 

[
  { "tag": "x-chart",  "source": "chart.js", "skeleton": "20 x 12" },
  { "tag": "x-legend", "source": "chart.js", "load": "eager", "skeleton": "none" }
]
  • tag: any custom-element name (lowercase, a letter first, a - inside), not only ui-*
  • source: the module to import(), relative to the PACK file (made absolute as it is read)
  • load: on-demand (default: a root imports it when it meets the tag) or eager (imported as soon as the pack is read)
  • skeleton: skeleton text, default none
  • an unknown key ("lod"), a bad tag, no source, an unknown load, bad skeleton text: the pack fails as a whole, a render SourceError naming the pack, the entry number and the tag
  • the pack file is fetched through UI.sources: same origin only (as <ui-include>), cached; the modules it names may be anywhere (as a <script type="module">)
  • a pack's word on a tag WINS over the catalog's (its module and skeleton): the docs pack names <ui-docs-*> tags the catalog also lists
  • tags are added, never removed: a new source on the element reads that pack too
  • ComponentPack.load(source) is the JS way (what the element calls); ComponentPack.entries(text, url) checks a pack without a server
  • types ComponentPackEntry (as written), RootPackTag (as RootLoader takes it), ComponentLoadPolicies in ui-root.types.ts
  • element: :state(loading | loaded | error), ui-load { source, tags }, cancelable ui-error { kind, source, error } then a Warnings line
