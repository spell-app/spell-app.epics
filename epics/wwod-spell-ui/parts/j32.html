P4 (Runtime 1): the runtime calls with 3-4 positional arguments now take ONE object, destructured in the signature; every caller fixed (components: ui-tab, ui-menu, ui-nag, ui-toast, ui-transition; Overlays; the runtime tests). Nothing in app, brand or docs called them.

  • UI.keyboard.register(scope, chord, handler, options) -> register({ chord, handler, scope, ...options }); scope defaults to "page" (every page-level caller wrote it)
  • UI.transitions.animate(element, name, direction, { duration, easing }) -> animate({ element, name, direction, duration, easing })
  • UI.focus.roving(container, items, options) / RovingTabindex.attach() / its constructor -> roving({ container, items, orientation, wrap, activeIndex, onChange })
  • new Chord(key, { ctrl, ... }) -> new Chord({ key, ctrl, ... }); VisibilityWatch(element, options) -> ({ element, options }); AppStylesheet.wrap(text, layer, supports, media) + its tuple -> wrap(text, { layer, supports, media })
  • renamed on the way: Chord.parse(text, { apple }) / new Keyboard({ apple }) -> { isApple } (matches UI.browser.isApple)
