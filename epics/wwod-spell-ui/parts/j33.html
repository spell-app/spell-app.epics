names follow WWOD; the bodies are as before (one comment on syncSoon() says why); AppStylesheetProps.debounce is now syncDelay (nothing passed it).

The short answer: lodash does have one, but it is NOT cheap: about 1.4 kB gzipped, roughly 15 times what a 10-line helper costs. And neither of the two members this item is about (syncSoon(), checkSoon()) can use a plain debounce, whoever writes it.

Words used below:

  • time debounce: "run once things have been quiet for N ms". Each new call restarts the clock (clearTimeout + setTimeout(fn, ms)).
  • coalescer: "run once, soon, however many times I'm asked". No delay: it waits for the end of the current task (setTimeout(fn) with a flag) or the next frame (requestAnimationFrame). This is NOT a time debounce, and lodash's debounce() doesn't model it.

  • Three one-line entries, bundled with the repo's own tools (the worktree's esbuild, and Vite's Rolldown lib build as dist/ uses), lodash-es 4.18.1, gzip level 9:

  • Why lodash's is so big: it brings its own global sniffing (_root, _freeGlobal), toNumber (with isSymbol, baseGetTag, baseTrim), isObject and now, plus the leading / maxWait options nobody here uses.
  • Is lodash already in a ui chunk, so it would come free? No.
    • lodash-es is in packages/ui/package.json's dependencies, but no file in src/ imports it
    • the only lodash code in dist/ is inside the two pre-compiled bundles (the markdown engine and spell's highlighter, both lazy). It is their own private copy, and has no debounce in it
  • Where it would land: typeAhead() is in ui-dropdown.js, onCopy in the ui-code family chunk. Two families importing it makes Rolldown split a new shared hashed chunk: one more request, on pages with either.
  • Where B lands: $/ui/util is re-exported by core.ts, so the helper ships in core.js, on EVERY page (packages/ui/AGENTS.md: "keep it small").
  • One correction to this item: its first bullet says $/util's debounce() is on its spell side. There is NO debounce anywhere in packages/util (nor in packages/core). WWOD's rule (agents/wwod/classes-state.md:109, "Through debounce() from $/util") points at a function that doesn't exist. 
/** Call `run` once calls have stopped for `ms` ms;  `.cancel()` drops a pending call. */
export function debounce<A extends unknown[]>(run: (...args: A) => void, ms: number) {
  let timer: ReturnType<typeof setTimeout> | undefined
  const debounced = (...args: A) => {
    clearTimeout(timer)
    timer = setTimeout(() => run(...args), ms)
  }
  debounced.cancel = () => clearTimeout(timer)
  return debounced
}
