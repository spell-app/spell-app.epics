fmtConfig.ignorePatterns in the root vite.lint.ts had "**/static/**", meant for packages/app/static/ (built files). After the rename it silently skipped every file in packages/ui/src/static/: vp fmt --check reported them clean while a 123-char line sat there. Lint was unaffected (its ignores are scoped).

Chose "static/**" (a package's own top-level static/, run from that package) + "**/packages/*/static/**" (from the root) over renaming the folder again.

  • packages/app/static still skipped from both packages/app and the root (checked); ui's src/static/ formatted again (19 files)
