How to get a flag font is now documented on the flag page's Theming tab, in a new "A flag font" section. The docs site itself loads no flag font.

  • The recipe, from the card: a polyfill call, plus one CSS token.
    • The call is polyfillCountryFlagEmojis(), from the country-flag-emoji-polyfill package.
    • It adds the "Twemoji Country Flags" font only where the browser can't draw flags.
  • Why the site doesn't load it: card B says the page fetches the font, and ui ships none.
    • The site loading it would add a CDN fetch to every page, for every Windows reader.
  • Readers of the docs site in Chrome or Edge on Windows still see "FR" on the flag page, as the page now says.
  • The font's size and coverage are quoted from its package, not measured here.
    • About 77 KB, the card's number.
    • Country flags only; England, Scotland and Wales weren't checked.
  • The recipe is two code blocks, JS and CSS. A nested closing script tag can't sit inside the page's plain-text script block.
