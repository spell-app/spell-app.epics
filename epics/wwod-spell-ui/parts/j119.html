Chose to document the card's recipe (the country-flag-emoji-polyfill package's polyfillCountryFlagEmojis(), which adds the "Twemoji Country Flags" @font-face only where the browser can't draw flags) as a new "A flag font" section, over making the docs site load it, because card B says the page fetches the font and ui ships none; the site loading it would add a CDN fetch to every Windows reader of every page.

Net effect:

  • Windows Chrome / Edge readers of the docs site still see "FR" on the flag page, as the page now says
  • the font's size (about 77 KB, the card's number) and its coverage (country flags only; England / Scotland / Wales not checked) are quoted from its package, not measured here
  • the recipe is two code blocks (JS, CSS): a nested </script> can't sit inside the page's <script type="text/plain">
