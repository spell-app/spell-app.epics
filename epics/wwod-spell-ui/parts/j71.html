UIToast.readingTime() counted host.textContent, which includes slotted slot="actions" buttons, so display-time="auto" ran longer with actions. It now counts header, message and the host's text / default-slotted children only (elements in the actions slot, and comments, are skipped).

Net effect: a toast with actions closes sooner under auto; new test "auto display time counts the message, NEVER the slotted actions' labels".
