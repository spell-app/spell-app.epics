The styles barrel should export the foundation sheets by name, so the runtime stops listing them itself. Found in P4 (Runtime 1).

  • Why: UIRuntime.registerFoundation() needs each foundation sheet BY NAME, for Styles: layers, reset ...
  • But the styles barrel exports foundationCSS and pageCSS as bare text arrays. A dozen tests read them that way.
  • Now: UIRuntime.ts keeps two module tables of sheets, foundation and page (FOUNDATION_SHEETS, PAGE_SHEETS).
    • PAGE_SHEETS is built from the first, plus the utilities, typography and native sheets.
    • Each name is written once, and "utilities" once, in runtime.types.ts.
    • There's no setUtilities() call: it was Styles' default.
  • Still: the ORDER lives twice, there and in the styles index.ts.
  • The fix: the styles index exports the sheets as a record, and derives the array from it. UIRuntime imports the record. 
    export const foundationSheets = { layers: layersCSS, ... }
export const foundationCSS = Object.values(foundationSheets)
