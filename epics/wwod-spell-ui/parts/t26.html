Where a component (or a base class) already has a member named like one of its vocabulary's attributes, that attribute's getter is lost. So this.<key> is NOT the attribute there.

  • A prototype member: the getter is skipped.
  • An instance field: the getter is hidden.
  • Rename the member when converting the family: active to isActive, icon() to iconGlyph ...
  • Merging E.AttributeValues then flags any left.
