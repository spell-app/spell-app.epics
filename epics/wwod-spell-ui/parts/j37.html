Q18 moved every constant ONE class uses below that class. In three families that left the types file with nothing in it, so I deleted it rather than keep an empty ui-<name>.types.ts.

  • ui-emoji.types.ts: LOADERS, SETS, the name regexes, DIGIT_CHUNK, EmojiSetData went below EmojiData (only DEFAULT_SET stays ABOVE it: the static set reads it while the class is defined); NAME_ATTRIBUTE below UIEmoji
  • ui-image.types.ts: NATIVE became NATIVE_ATTRIBUTES below ImageFallback
  • ui-items.types.ts: ITEM_CONTEXT below UIItems, its words now UIT.LISTITEM / UIT.PAGE / UIT.IMAGE

Options: A) delete the empty file (taken: WWOD §2 › "Delete ... nothing reads", §8 › "Avoid single-concept micro-modules"); B) keep an empty types file so every family has the same five files.

Net effect:

  • the folder shape in ui's AGENTS.md ("Overview") is a maximum, not a checklist: a family with nothing shared has no types file
  • docs/report.md still lists the three files until the next yarn report
