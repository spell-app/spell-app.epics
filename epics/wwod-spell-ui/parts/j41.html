<ui-form>'s values (and every ui-valid / ui-invalid / ui-success / ui-failure detail.values) still say null for a radio group with nothing chosen, or a field with no controls. Q9 would make it undefined; I kept null.

  • it's Fomantic's get values shape, and a value pages read keeps its published spelling (ui's AGENTS.md, Functions & types)
  • undefined would DROP the key from JSON.stringify(values), the usual way a page posts a form: { plan: null } would become {}
  • options: A keep null (done); B undefined, and a note in the docs page that a JSON post loses the key

Net effect:

  • nothing changes for pages; FormFields.valueFor()'s docstring says why
  • ours that are NOT published went to undefined: CheckControl.formValue() while unchosen, UIFormHost.nativeForm / UIForm.form without a form
