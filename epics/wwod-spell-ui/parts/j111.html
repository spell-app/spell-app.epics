The root's loader, RootLoader, learns about single tags from component packs, and can wait for a pack that's on its way.

  • Chosen: a per-TAG sibling of RootLoader.add(), plus a pair to wait for packs. Rejected: stretching add(), which maps a folder to its importer, keyed by barrel path.
  • RootLoader.addTags(tags): for each tag, its module URL, load policy and skeleton. The eager ones are imported at once.
  • RootLoader.loadTag(tag) loads the pack's module, else the tag's family.
    • It gives undefined for a tag nobody knows.
    • One import per module URL, so a module that defines several tags loads once.
  • RootLoader.knows(tag) and skeletonFor(tag) ask the pack first, then the catalog.
  • RootLoader.adding(promise) and whenAdded() track a pack on its way.
    • A root that would call a tag unknown waits for it, then looks again.
    • It finds the tag's skeleton again, too, while skeletons show.
  • RootLoader.undefinedTags() now also lists undefined tags a pack added, whatever their name.
  • Folder lookup, loading a folder, and adding barrels stay as they were.
  • The root, <ui-include> and the site's router all load through loadTag(). So a pack's tags load in an include, and on a router swap, too.
  • <ui-components> asks for its pack AS IT CONNECTS, in its render(), which runs then. So even a root that comes before it in the page, or holds it, waits for the pack.
