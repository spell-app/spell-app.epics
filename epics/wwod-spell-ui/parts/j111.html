Chose a per-TAG sibling of RootLoader.add() plus a "wait for packs" pair, over stretching add() (which takes folder => importer, keyed by barrel path).

  • RootLoader.addTags(tags): tag => module URL + load policy + skeleton; eager ones import now
  • RootLoader.loadTag(tag): the pack's module, else the family; undefined for a tag nobody knows. One import per module URL, so a module defining several tags loads once
  • RootLoader.knows(tag), RootLoader.skeletonFor(tag): pack first, then the catalog
  • RootLoader.adding(promise) / RootLoader.whenAdded(): a pack on its way; a root that would call a tag unknown waits for it, then looks again (and finds its skeletons again while they show)
  • RootLoader.undefinedTags() now also lists undefined tags a pack added, whatever their name
  • folderFor(), load(folder), add(barrels) stay as they were
  • <ui-root>, <ui-include> and the site's router all load through loadTag(), so a pack's tags load in an include and on a router swap too
  • <ui-components> asks for its pack AS IT CONNECTS (its render(), which runs then), so even a root that comes before it in the page, or holds it, waits for the pack
