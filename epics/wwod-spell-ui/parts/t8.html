decorate(target, name) types its part name, but also copies the host's aria-* onto target: right for the fallback's root, wrong for an inner box (a breadcrumb's <ol part="list">, a linked image's <img part="img">). P5 (Families 5) used typed module constants instead (const LIST_PART: E.PartNameOf<typeof breadcrumbVocabulary> = "list"). A protected part(name: PartNameOf<V>): string on NativeFallback would let every fallback write { part: this.part("list") } like an element. src/elements/ is P3's, done, so not changed here.
