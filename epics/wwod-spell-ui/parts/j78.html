The four docs families (api, example, tokens, themes) were renamed and reshaped to the house style. Nothing outside them changes behaviour.

  • What kinds of change:
    • Lookups became xFor().
    • Booleans passed by position became named values, or named options.
    • Constructor arguments became one props object.
  • Every caller is inside the four folders and their tests. Nothing in ui's site source, app, docs or spell-app-dev used them.
  • ApiModel, in the api family:
    • Its lookups gained "For": sectionsFor, propertyFor and the rest.
    • A new ApiModel.labelsFor(cell) builds the range label, which the element and the fallback each built.
    • Flags gained is: on a cell, an item, and an inline piece.
    • API_SECTIONS became ApiSectionIds.
  • The example family:
    • ExampleSource.format() takes origin: "authored" | "live", not a "live" boolean. It's the shape WWOD cites, kept.
    • template() checks the tag's name, not instanceof.
    • UIDocsExample.stamped became isStamped.
    • HtmlFormatterOptions became HtmlFormatterProps. It sits beside the class with its constants, under a banner.
  • The tokens family:
    • TokenRows' lookups gained "For". Its options are now TokenViewParams, with isGlobal.
    • A new TokenRows.cssValueFor(row, { isGlobal }) gives the swatch's value, which was written 3 times.
    • TokenView's message flag became isError.
    • ColorProbe's lookups gained "For". Its canvas cache is undefined plus a "tried" flag, instead of null.
    • UIDocsTokens.apply(tokens, target) takes a target, not a page boolean.
    • renderRow(row, described) became row(row, { isDescribed }).
  • The themes family:
    • new ThemeMenu({ names, data, forTag, text }) takes a props object. The text lookup is now a field, not an argument of every call.
    • Its themes and entries became getters; its title and label lookups gained "For".
    • UIDocsThemes.matchSystem(on) became chooseScheme("system" | "shown").
    • wired became isWired.
    • The ui-change event's detail is built once, by DocsThemesChanges.detailFor(). The element and the fallback each built it before.
  • The functions that draw pieces lost their render prefix.
    • In api: item, table and cell.
    • In tokens: table and row; the data list became shownTables().
    • In themes: scheme button, palette, entry and dropdown.
  • Constants:
    • Every constant only one class uses moved below that class (Q18).
    • Types files keep only what 2 or more files read.
    • Class words in templates became constants: UIT's own where it has them (HEADER, Key.* ...).
    • "true" in an aria-* attribute became UIT's constant; "false" likewise.
  • The full renames: 
    ApiModel.sections / propertyOf / defaultOf / kindLabel / valuesOf
                                    -> sectionsFor / propertyFor / defaultFor / kindLabelFor / valuesFor
ApiModel.labelsFor(cell)            new
ApiCell swatch / range              -> isSwatch / isRange
ApiItem.grouped                     -> isGrouped
InlinePiece.code                    -> isCode
API_SECTIONS                        -> ApiSectionIds
ExampleSource.format(html, live: boolean) -> format(html, origin: "authored" | "live")
UIDocsExample.stamped               -> isStamped
HtmlFormatterOptions                -> HtmlFormatterProps
TokenRows.view / patterns           -> viewFor / patternsFor  (options: TokenViewParams, isGlobal)
TokenView message error             -> isError
TokenRows.cssValueFor(row, { isGlobal })  new
ColorProbe.toHex / hexes            -> hexFor / hexesFor
UIDocsTokens.apply(tokens, page: boolean) -> apply(tokens, target)
renderRow(row, described)           -> row(row, { isDescribed })
new ThemeMenu(names, data, forTag)  -> new ThemeMenu({ names, data, forTag, text })
ThemeMenu themes() / entries(text)  -> getters;  title / label -> titleFor / labelFor
UIDocsThemes.matchSystem(on: boolean) -> chooseScheme("system" | "shown")
wired                               -> isWired
render pieces                       -> item() / table() / cell(), table() / row(), shownTables(),
                                       schemeButton() / palette() / entry() / dropdown()
class words                         -> DESCRIPTION, HEADER, LABEL, SEPARATOR, TOP / BOTTOM, CLICK, Key.*
  • No behaviour change: the same 140 family tests pass after the renames. Tests changed only where a name did.
  • LEFT as literals: a composed widget's attribute value written once, since it reads as that widget's markup.
    • For example position="bottom right", stack-by="container".
    • Another: scope="col".
  • A value written twice became a constant, such as SMALL or TIP_POSITION.
