Owen's note on UIElement.send(), 2026-10-07:

"change events we send to on-x, e.g. on-hide"

What the rename would cost:

  • The platform names an event for what happened (hide).
  • on plus the name is its handler (onhide).
  • So an event called on-hide gets the handler onon-hide. Listening for it reads oddly, too: addEventListener("on-hide").
  • It changes every event of every component, and every listener in the app, brand, tests and docs.

The options:

  • A: keep ui-hide, as today
  • B: plain hide, as native events are named
  • C: on-hide
  • one event-name rule, applied repo-wide in its own phase
