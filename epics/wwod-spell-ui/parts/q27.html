Owen's note on UIElement.send() (2026-10-07): "change events we send to on-x, e.g. on-hide".

  • The platform names an event for what happened (hide); on + the name is its handler (onhide). An event called on-hide makes its handler onon-hide, and addEventListener("on-hide") reads oddly.
  • It changes every event of every component and every listener in the app, brand, tests and docs.

Options: A keep ui-hide (today); B plain hide, as native events; C on-hide.

Net effect:

  • one event-name rule, applied repo-wide in its own phase
