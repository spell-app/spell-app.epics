The calendar family took WWOD's shapes; where a choice was open I picked the one closest to the code's own words.

  • new CalendarDates(T, type) → new CalendarDates({ temporal, type }); the field T (a bare T, WWOD §4) is temporal, matching UICalendar.temporal and UI.i18n.temporal. Not Temporal: it would sit beside the Temporal type namespace the file imports.
  • new CalendarText(i18n, locale) → new CalendarText({ i18n, locale }); props types CalendarDatesProps / CalendarTextProps below each class.
  • CalendarDates.MINUTE_STEP (a static at the top) → MINUTE_STEP in ui-calendar.types.ts: CalendarView reads it too, so not a module const (Q18).
  • The types file's TITLE = "title link" / LINK = "link" share names with UIT.TITLE ("title") / UIT.LINK ("a") but not values: renamed, never swapped. All 14 class words got a _CLASS suffix (TITLE_CLASS, CELL_CLASS, PREVIOUS_CLASS ...) and moved below UICalendar, the one class that reads them; formats below CalendarText, ISO forms below CalendarDates, page sizes below CalendarView, NATIVE_TYPES below the fallback. FLUID / ENTER / SPACE copies → UIT.FLUID / UIT.Key.*.
  • CalendarView.move(input, key, shift) → move(input, event), taking Pick<KeyboardEvent, "key" | "shiftKey">: no positional boolean, and the caller passes its event as is. cell(input, moment, adjacent) / disabled(input, moment, adjacent) → cell(input, moment) / isDisabled(input, moment), adjacency worked out once in isAdjacent().
  • null → undefined: parse(), build(), read(), clamp(), commit(undefined) clears, focusState, typed, ViewInput.value / min / max / range, CalendarHost.value. Kept: formValue() and the fallback's setFormValue() (platform).
  • Kept on purpose: CalendarCell's booleans (active, focus, adjacent ...) keep Fomantic's class words, not isActive: they ARE the cell's classes; setOpen(open) keeps its boolean (the value set, not a mode), like the other families; popupMode() keeps its name.
  • static preload() moved from above the state to a Statics group at the end, with why it's static.
  • no behaviour change; no public API outside the family changed (the helpers aren't exported); 279 browser + the calendar SSR tests pass unchanged
