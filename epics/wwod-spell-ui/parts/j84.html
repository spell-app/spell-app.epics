ui's tools and scripts now print through one small class, Terminal. It has out() for results, and err() for the rest.

  • Every console.* call in ui's tools/ became one of those: 26 of them.
    • out(): results.
    • err(): problems, usage and progress.
  • Chosen over a copy per file, or importing cli.
  • Its shape is cli's CliSession.out() and err(): each adds the newline.
  • It uses node's built-ins only, so it sits at the bottom of the tools' import graph.
  • It's in the tools' barrel. The scripts (Tools 3) already use it, e.g. site-data.ts.
  • Which stream is decided per message.
    • On stdout: yarn measure's sizes, and the smoke test's PASS lines.
    • On stderr: a CHECK failure, and the build notes of ForkBuild and HostApp.
  • No console.* is left in my tool files.
  • yarn smoke prints only the first line of each page's errors. The stacks stay in smoke-results.json.
