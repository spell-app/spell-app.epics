Smaller choices in the runtime services (agent Runtime 2):

  • Apple platform test (was written twice, Chord.ts and Browser.ts): one static Browser.isApplePlatform(navigator = globalThis.navigator); Chord.parse()'s default and UI.browser.isApple both call it. A static, not a helper in runtime.types.ts: it reads navigator, and the types file stays pure. APPLE_PLATFORM is now a module const in Browser.ts.
  • Toasts.provider / Modals.provider stay public statics (tests set them; Q18 says a static read from outside is API). The private getter of the same name became registeredProvider.
  • Literal unions left as unions, each with a docstring saying why: OverlayKind, AnimationDirection, ApiMethod, ApiResponseType, RovingOrientation. Nothing lists or validates them. DismissReason and AnimationDirection keep their published kebab spelling (ui-close's detail.reason, data-ui-animation).
  • ANIMATION_NAMES becomes AnimationNames: UIVisibility checks names against it, so it stays a set.
  • I18n's repeated "long" | "short" | "narrow" is NameStyle, as type surgery on Intl.DateTimeFormatOptions["weekday"], not a new list.
  • No behaviour change.
