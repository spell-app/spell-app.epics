Renames in the input, root, menu, embed, emoji and message components. The order of their effects is kept.

  • The order @onChanges are declared in is the order their effects run. Each pair below has a comment.
    • onValueChanged runs before onConstraintsChanged. The control holds the new value before validity is read.
    • UIRoot's watch runs before its settings.
  • TextControl's value is the controlled accessor. Its effects: onValueChanged, onConstraintsChanged and onConnectedChanged.
  • UIMenu reads an item's type and value through its getters, not item.attrs. ItemController declares them.
  • The renames: 
    TextControl    focusValue      -> valueAtFocus
UIInput        isFile          -> isFileInput
               label()         -> labelBox()
UIMenu         parent          -> parentMenu
               top()           -> topMenu
UIRoot         isContentReady  -> contentIsReady
               display         -> displayMode
               message()       -> loadingMessage
UIComponents   status          -> loadStatus
UIEmbed        url             -> frameUrl
               label           -> accessibleName
  • Scripts that reach into these components need the new names; none was found.
