How a flag is drawn today, step by step
  1. A page writes <ui-flag country="france">, or a menu option carries flag="fr".
  2. <ui-flag> only: FlagCountry turns a Fomantic NAME into its code through FLAG_ALIASES (france => fr, england => gb-eng). Menus skip this step: they take codes.
  3. UIT.Flags.emojiFor(code) builds the emoji from the code's two letters: each letter becomes its "regional indicator" character (a Unicode letter meant only for flags). f => U+1F1EB, r => U+1F1F7; the pair is 🇫🇷. Six flags that aren't a pair (rainbow, transgender, pirate, England, Scotland, Wales) come from a small table, SPECIAL_FLAGS.
  4. The element puts that TEXT in a span: <span class="ui flag fr" role="img" aria-label="France">🇫🇷</span>. The browser's emoji font draws it. No image, no network fetch, no per-country CSS.
  5. Only if the page has applied the famfamfam theme: that sheet selects on the class word fr and paints a 16 x 11 cell of a PNG sprite behind the span, hiding the emoji. 
export class Flags {
  /** Emoji of flag `code`, in any case;  `""` when it names no flag. */
  static emojiFor(code: string): string {
    const key = code.toLowerCase()
    if (Flags.isSpecial(key)) return SPECIAL_FLAGS[key]
    if (!TWO_LETTERS.test(key)) return ""
    return String.fromCodePoint(...Array.from(key, (letter) => INDICATOR_A + letter.charCodeAt(0) - LETTER_A))
  }
  ...
}

What "emoji only" means on each platform

The emoji are drawn by the operating system's emoji font, so how a flag looks depends on where the reader is. The big caveat is Windows: Microsoft's emoji font, Segoe UI Emoji, has no country flags at all, on Windows 10 or 11.
