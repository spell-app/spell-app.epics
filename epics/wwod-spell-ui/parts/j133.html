The getters a page's script reads on a host now read the component UNTRACKED, as before P14. The docs search's query is restored to that.

  • These wrap their read in untrack(), since the component members they read became tracked:
    • UICodeHost.detectedLanguage (group 8)
    • UIMarkdownHost.headings (group 8)
    • FieldHost.errors (7)
    • brand's BrandFieldHost.errors (step 3)
  • DocsSearchHost.query: group 9 let it become tracked, as the @state query itself.
    • Step 3 made it untracked again.
    • Otherwise, a page's Solid effect reading el.query would re-run on every keystroke: a behaviour change for callers.
  • Host APIs read as they did before P14.
