A fallback class serving several tags (CardFallback for <ui-card> + <ui-cards>) now lists them in @proto static vocabularies, the FIRST being the default; NativeFallback's constructor picks the host tag's into vocabulary. Chose a list over a tag-keyed map because each vocabulary already carries its tag: a map would write every tag twice.

  • 13 fallbacks lost their constructor, not 9: breadcrumb, card, comment, feed, form, grid, image, parts, placeholder, shape, sidebar, step, tab (the plan's count missed parts, placeholder, shape, sidebar, step and tab). Form's and grid's private static VOCABULARIES became the @proto list
