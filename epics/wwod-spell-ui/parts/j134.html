I26: esbuild's transform has no "import helpers" option, so every decorated file carried its own copy of the decorator runtime (__decorateElement, __runInitializers ...: ~2.6 kB minified); core had 12 copies, and every family file one more. vite.decorators.ts now swaps a file's helper preamble for an import of ONE virtual module, virtual:esbuild-decorator-helpers (built from a probe class using every decorator kind), when each helper the file declares matches it word for word; else the file keeps its own (test files importing it, where esbuild renames a local). The swap keeps the line count, so source maps still line up.
