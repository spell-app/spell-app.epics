The static server render (no JavaScript) leaves off-value out, and says so in the vocabulary's description and on the docs page.

  • Rejected: Rails' trick, a hidden input before the box. 
    <input name="panel" value="closed">
  • Why: with it, a chosen box sends BOTH values (panel=closed&panel=open).
    • PHP and Rails take the last one.
    • But new FormData(form).get(), Flask and most first-wins readers would read "closed".
  • A static form with no script submits nothing for an unchosen box, as a native checkbox does. With JavaScript, the element or its native fallback submits the off-value.
  • The static input's value now follows the class's onValue. It's left out when it's the native "on".
