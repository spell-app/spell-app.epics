Chose to leave off-value out of the static (no-JS) render, and to say so in its vocabulary description and the docs page, over writing Rails' hidden <input name="panel" value="closed"> before the box, because the hidden input makes a chosen box send BOTH values (panel=closed&panel=open): PHP and Rails take the last, but new FormData(form).get(), Flask and most first-wins readers would read closed.

Net effect:

  • a static form with no script submits nothing for an unchosen box, as a native checkbox does; with JavaScript (the element, or its native fallback) it submits the off-value
  • the static input's value now follows the class's onValue, left out when it's the native on
