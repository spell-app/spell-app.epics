A component pack is CODE, not data: each source runs like a <script type="module"> on the page.

  • The pack FILE is same-origin only (fetched through UI.sources, like <ui-include>), so only the site's own files can name modules.
  • The modules it names may be on any origin (the browser's own CORS rules apply), as a script tag's would.
  • Tags are added page-wide and never taken back: removing a <ui-components> or changing its source leaves the tags it added.
