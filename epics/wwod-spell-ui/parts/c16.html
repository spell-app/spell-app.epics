A component pack is CODE, not data: each module it names runs like a module script on the page. Its tags are added page-wide, and never taken back.

  • The pack FILE is same-origin only: it's fetched through UI.sources, like <ui-include>. So only the site's own files can name modules.
  • The modules it names may be on any origin, as a script tag's would. The browser's own CORS rules apply.
  • Removing a <ui-components>, or changing its source, leaves the tags it added.
