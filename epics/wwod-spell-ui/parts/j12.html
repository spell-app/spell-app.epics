Where the recipe would have meant churn across many component files, or a clash, the element core kept its shape. What was kept, and the shapes picked:

  • Public booleans without is or has were kept: too many callers for P3.
    • UIElement.loaded: 28 callers
    • connected: 47
    • formDisabled: 21
    • PartContextProps.direct is kept too: a named option in an options object, which WWOD §9 allows ({ optional: true }). Its private field is isDirect.
  • Constructors keep the shape "collaborator, shorthand, then options", not one props object.
    • new HostAttribute(host, name): 21 callers
    • new PartContext(host, noun, { barrier }): 14
    • new IconGlyph(owner, name): 37
    • The host or owner is WWOD §12's context; the second argument is the one-property shorthand it allows.
  • The @proto static config on UIElement:
    • Each declare has the full docstring: what it is, and why it's static.
    • They're in a "Class config" group; each default has a one-line "Default: ...".
    • The banner lists the config and the hooks. The hooks are now one "Hooks" group, each docstring saying "Hook:". 
      render(), hostStates(), classValue(), extraClasses(), sheetNames(), isDisabled()
  • Registries became private statics, with a static reset().
    • On UIElement: sheets, texts, and cancelled hosts. reset() leaves the public definitions, which mirror the browser's custom-element registry.
    • On PartContext (6), and on RootSettings.
    • WeakMaps and WeakSets are NOT read-only: they can't be cleared, so reset() replaces them.
  • No reset() on two classes:
    • StickyWatch: it would sit beside the instance's own reset(), the clash P3 removes from PartContext. Its entries leave as watches unstick.
    • HotDefinitions: dev-only, and a reset would have to unwrap define.
  • The whitespace pattern /\\s+/ was written in ClassBuilder and Shorthand.
    • It's now WHITESPACE, in elements.types.ts.
    • So the core exports it too.
  • Deleted, since nothing but their own tests read them (WWOD §2, §20):
    • OwnerContext.ownersOf(): PartContext's registry superseded it.
    • ClassBuilder.numberToWord(). util's own numberToWord() and the ValueSets one remain.
    • 2 tests are gone.
  • Browser tests: 4688 passed, down 2 from 4690: the two deleted tests.
  • Server-render tests: 241.
