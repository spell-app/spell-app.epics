Three positional booleans, three shapes, each picked for how the call reads:

  • UIForm.check(true) / check(false) => check("show") / check("silently"): ONE mode switch, so an English sentinel (WWOD §9), type CheckMode below the class
  • UIAccordion.detail(index, true, event) => detail({ index, open: true, originalEvent }): the params mirror the AccordionToggleDetail it builds, where a NAMED boolean is fine
  • AccordionPanels.parse(text, exclusive) => parse(text, { exclusive }): a named option, after the attribute it comes from
  • KEPT: CheckControl.choose(selected, event) and setSelected(selected): the boolean is the new VALUE of selected, not a mode

Net effect:

  • all private or family-internal: no caller outside the four folders
