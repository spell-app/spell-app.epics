Public renames in the modal, section, accordion, docs api, docs example and flag components.

  • DialogElement:
    • heading is a public @state accessor; it was a read-only Cell.
    • isOpen() became an accessor that is both a CSS state and the controlled open attribute. Assigning it writes the host's open. 
      @cssState("open") @controlled("open") accessor isOpen
  • The rest: 
    UISection        collapsedState  -> isCollapsed  (@controlled)
                 isCollapsed()   -> isFolded
                 level()         -> headingLevel
                 scrolls()       -> contentScrolls
                 watch           -> stickyWatch
                 parent()        -> @derived parent   (UIPanel follows)
UIAccordion      openState       -> openText
                 isOpen(i)       -> panelIsOpen(i)
                 readPanels()    -> onChildrenChanged()
UIDocsApi        data / failure  -> siteData / loadError
UIDocsExample    source          -> sourceMarkup
                 open            -> isCodeOpen
  • UIFlag.accessibleName stays @derived, though it reads the locale (UI.i18n). The locale isn't reactive, and the old memo didn't follow it either.
  • No caller outside the folders: checked ui, brand, docs and app.
