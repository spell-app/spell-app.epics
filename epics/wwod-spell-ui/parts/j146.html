Public renames in the search, rating, item, card, include, grid and flyout components.

  • UISearch.initialValue stays undefined when the host set no value, as today.
    • The table's untrack(() => this.value) would give an empty string.
    • Then a reset would reflect value="".
  • The rating's value is now the raw controlled attribute; the clamped one is rating.
  • The card's slotted became a state, with its own sameness check.
    • That check, isSameNouns, is a module function above the class.
    • A decorator's argument can't read a static of the class being defined.
  • The renames: 
    UIRating     value()        -> rating  (clamped);  value is the raw @controlled
             max()          -> iconCount
             isPartial()    -> isPartlyFilled()
             hovered        -> hoveredPoint
UIItem       tag()          -> rootTag
             imageSrc()     -> imageUrl
             current()      -> ariaCurrent
UICard       isShowing(noun) -> rendersShorthand(noun)
             slotted        -> @state slottedNouns
UIInclude    inserted       -> markupIsInserted
  • The item's derived itemContext needs owners whose own item context reads reactive members. That's now written into UIT.ItemOwner's doc.
  • ratingController.value changes meaning: it's raw, not clamped.
