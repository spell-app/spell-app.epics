What several of ui's scripts repeated now lives in two helper files, which no yarn script runs. They're camelCase: a family of helpers, named for what they do (WWOD §8).

  • browserBundles.ts builds the browser bundles.
    • It has the esbuild call both bundle scripts made (buildBundle()), and its pieces: 
      REPO, versionFor(), REACT_DOM_STUB, buildBundle(), declarationFile(), wrapperFile()
    • gen-spell.ts went from 115 lines to 54.
    • gen-markdown.ts keeps only its three markdown-only plugins.
    • yarn gen:spell and gen:markdown, re-run: every bundle, wrapper and declaration is BYTE-IDENTICAL to the committed files (shasum).
  • generatedFiles.ts writes generated files.
    • writeOrCheck() writes what changed; with --check it lists stale files and exits 1. It was copied in 4 scripts.
    • spliceGenerated() replaces the text between two markers. It was copied in the site index and kitchen-sink scripts.
    • Also formatFiles(), and three that were copied:
      • escapeHtml(): 3 copies
      • withoutTicks(): 2
      • STATUS_TEXT: 2
  • Also, across ui's scripts/:
    • Every hand-parse of process.argv is now node's own parseArgs. That's 7 scripts: design-build, site-data, site-index, site-kitchen, site-new, site-sections, tokens-alias.
    • Every console.* call goes through Tools 1's Terminal instead.
    • Paths a person types resolve against the folder they ran the command from, as SiteCheck does. For example design:build --out, or site:sections <page>.
  • House-style fixes:
    • Constants only one class uses moved below it, as module consts, as ui's "Classes" asks. In gen-icons, gen-emoji, site-index and site-kitchen.
    • EmojiGenerator.chunkOf() became chunkFor().
    • IconStyle became a const array plus a type, IconStyles. It also gives the fomantic pack its order.
    • interface became type, in gen-emoji.
    • Errors read "Method(): problem; fix".
    • Imports through $/ui/styles/... became relative (X.ts). It's the folder rule, now in the root AGENTS.md, "Imports".
  • No generated file changes by a byte, except ui-root.catalog.ts (the next item).
