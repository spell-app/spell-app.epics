The other four families of the slice, with the calls that were mine to make.

  • UIButton: control_() → control() (the field it shadowed is innerControl); invokers() → hasNativeInvokers(); its own aria-label cell + MutationObserver → new E.HostAttribute(this.host, UIT.ARIA_LABEL) (same reads, one observer less to dispose by hand); Q3 docstrings on isDisabled() / classValue(); FORM_ATTRIBUTES, ICON_END, RIGHT_ICON_CLASS and the label / animated class words are module consts below it; RESET joins DEFAULT_TYPE in the types file (the fallback reads both).
  • Invoker.resolve() returns Element | undefined; its callers write ?? null into commandForElement (the platform's "no target"). The command words are one const object, Command, below the class.
  • EmbedSources.sourceOf() → sourceFor() (WWOD §3 lookup; 1 test, no other caller in the repo or the shared docs). ID / SAFE_PROTOCOLS below it; 6 type members documented.
  • Embed fallback: now reuses the element's ALLOW, REFERRER_POLICY and class words, and the vocabulary's English texts instead of its own literals. One visible change: its frame's allow grows from autoplay; encrypted-media; fullscreen; picture-in-picture to the element's list (+ accelerometer, clipboard-write, gyroscope), so both draw the same frame.
  • UIInclude.insert(text, select, light) → insert({ text, select, pageStyles }); "loaded" / "loading" → E.SourceStatus.*; EAGER, LOADING_CLASS, BODY_OPEN / BODY_CLOSE below the class. I8 (parentOf's instanceof) and its console.warn were already gone (P3 / P2).
  • ui-divider's VERTICAL was UIT.VERTICAL's copy: deleted.
  • Every vocabulary of the five families types itself with import type { E } from "spell-ui/core" (E.ComponentVocabulary), not a deep spell-ui/vocabulary path; "user" → "person" in three descriptions.
  • ui-button.css: the one bare @media (width < 768px) → @media (--ui-mobile), with @import "../../styles/media.css" as ui-form.css does. Same breakpoint: no pixel should move. The 0 0 #0000 shadow placeholders stay (token defaults).
