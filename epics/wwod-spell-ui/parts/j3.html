Chose to give MarkdownSanitizer a real value import from runtime.types: throw new SourceError("render", …) where DOMPurify.isSupported is false. The other option was a Rolldown option, and none exists that puts the runtime helpers in core.js: a codeSplitting group named core changed nothing.

  • It's the pattern CodeEngine, MarkdownEngine and TemporalPolyfill already use, and their headers explain why. The docs bundler already allows runtime.types into these classic scripts.
  • The import does real work: before, an unsupported browser got back markup DOMPurify never cleaned.
