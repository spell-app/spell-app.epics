The colour-emoji font stack is written once now, as a new global token, --ui-font-family-emoji. Everything that draws a flag or an emoji reads it.

  • Where it's defined: fonts.emoji in styles.vocabulary.en.ts. It's generated into tokens.css.
  • Who reads it:
    • <ui-flag>
    • the flags in dropdown and select rows
    • <ui-emoji>
  • Rejected: copying the five-font stack into the dropdown and select sheets.
    • It was already in the flag and emoji sheets.
    • Menu flags reading the flag's own font token would have made four copies.
  • And the token lets a page's recipe keep the rest of the stack: 
    --ui-flag-font-family: "Twemoji Country Flags", var(--ui-font-family-emoji), var(--ui-font-family)
  • One new public token, on :root and the shadow-root fallback. Same fonts in the same order, so flags and emoji draw as before.
  • <ui-emoji> reads it too: a drive-by, beyond card B.
  • The dropdown's flag rows are 1-2 px taller.
    • The flag's first font is now the emoji font, whose line spacing differs.
    • The dropdown's content baselines were updated: on this Mac, in 3 browsers.
  • The select's option flags measured no difference.
