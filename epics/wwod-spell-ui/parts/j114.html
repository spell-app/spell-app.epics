Chose property: "inputMode" on <ui-input> (shadowing HTMLElement.prototype.inputMode) over a non-native name like dividerHidden, because the meaning is the same: both read and write the host's inputmode attribute, and ours forwards it to the native input. hidden -> dividerHidden was renamed because Fomantic's word means something else there. The fork allows a renamed prop to shadow (upgrade.ts).

Also renamed beyond the queued 6 tags: the shared readonly spec in ui-checkbox.types.ts, so <ui-checkbox> / <ui-radio> / toggle say readOnly like a native checkbox.

  • el.inputMode on a <ui-input> is ours (reflects, forwards); same value the native getter would give
  • readOnly on 9 tags, not 6
  • attributes unchanged everywhere; no caller used the old property names
