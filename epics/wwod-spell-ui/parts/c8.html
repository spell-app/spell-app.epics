With the empty body WWOD §5 asks for, SourceError / ApiError keep Error's constructor, whose options.cause is unknown. So TypeScript checks the cause when it's READ (declare cause: SourceErrorCause | undefined), not when it's written: 

new SourceError("...", { cause: { kind: "lod" } })   // compiles;  error.kind is "lod" at run time
  • the 20 call sites were checked by hand, and the tests read kind back on each path they cover
  • a typed constructor (constructor(message: string, options: { cause: SourceErrorCause }) { super(message, options) }) would catch it, at the cost of a non-empty body: a WWOD §5 question, not taken here
