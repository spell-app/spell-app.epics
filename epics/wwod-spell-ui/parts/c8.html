TypeScript doesn't check the cause passed to new SourceError(); it checks it only where it's read.

  • Why: WWOD §5 asks for an empty class body, so SourceError and ApiError keep Error's constructor. That constructor's cause is unknown.
  • The cause is typed where it's READ: declare cause: SourceErrorCause | undefined.
  • So this compiles: 
    new SourceError("...", { cause: { kind: "lod" } })   // compiles;  error.kind is "lod" at run time
  • The 20 call sites were checked by hand. The tests read kind back on each path they cover.
  • A typed constructor would catch it, at the cost of a non-empty body. That's a WWOD §5 question, not taken here. 
    constructor(message: string, options: { cause: SourceErrorCause }) { super(message, options) }
