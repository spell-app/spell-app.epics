this.attributes takes an attribute's CANONICAL name, and a translated tag reads its own. For example, this.attributes.value reads valor on a translated tag.

  • UIElement.attributes maps a vocabulary attribute's canonical name to this tag's name. It uses ElementDefinition.localAttribute(), which is new.
  • Any other name reads as written.
    • aria-label
    • the aliases checked and active
    • a name already in the tag's language
  • Simplified: five places looked the local name up by hand.
    • UICalendar.initialValue, UISection.isCollapsible, and the form-reset hooks of UISlider, UIRating and TextControl.
    • All were: 
      this.attributes[this.definition.attribute("value").attribute]
  • Groups 3, 5 and 10 had kept that lookup, against the table's this.attributes.value, for translated tags. The table's form now works.
  • Behaviour unchanged. Every reader of a vocabulary attribute's raw text already used the local name.
