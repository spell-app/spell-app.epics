After I12's fix, yarn measure passes, but a real yarn build still writes rolldown-runtime-<hash>.js (1.2 kB min, 0.65 gz). core.js, styles.js and every family import it, so every page makes one extra request. 93abde40's dist/ had none.

  • Why: since the Themes Port (8c2c785d), the styles entry holds code, ThemeSheets. Its lazy import.meta.glob("./*.css") needs Rolldown's helpers (__exportAll for classic / dark, which are static imports too; under keepNames, __name as well). styles.js never loads core.js, so Rolldown has no single chunk that both reach, and it splits the helpers out.
  • Tried: loading classic / dark from their static imports. That drops __exportAll, but styles.js still does a bare import "./rolldown-runtime.js". Without ThemeSheets the chunk is gone, so it's the glob's loaders. Reverted.
  • yarn measure can't see it: it builds core, forms, the families and api, never styles or index.

Options:

  1. Move ThemeSheets out of @spell-app/ui/styles, into the runtime (UI.themes.apply(), where UI.styles already is). styles goes back to pure data. This changes the API: callers are <ui-docs-themes>, ThemePreference and brand-ui.ts.
  2. Export ThemeSheets from @spell-app/ui/core instead: about 1 kB more in core.js, same callers.
  3. Accept the chunk, and add styles to what yarn measure builds so the check shows it.

Measured all three (Q21). Option 1, UI.themes, is the smallest clean one, but only together with one more change that options 1 and 2 BOTH need: classicThemeCSS / darkThemeCSS leave $/ui/styles.

  • Why the extra change: the theme glob dynamic-imports classic.css and dark.css, which styles.js ALSO imported statically for the two exports. Wherever the glob lives, those two then become their own chunks that need __exportAll, and neither imports core.js: the runtime chunk comes back. Only styles.test.ts read the two exports; it now imports the sheets itself.
  • Each variant built from a clean copy of HEAD (8c5dfdac), not the live tree (other P4 agents are editing it): vp build into dist/, then yarn measure with the styles entry added to what it builds (else it can't see the chunk at all).
  • Sizes in bytes. Build columns: raw dist/ files (gzip 9). Measure columns: esbuild-minified, gzip 9.
