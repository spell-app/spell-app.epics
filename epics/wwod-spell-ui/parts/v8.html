On the boolean-names choices page, a row's File link should open VS Code at that line, from the side bar AND from Chrome.

  • The page: boolean-names.html. Click a row's File, e.g. UISection.tsx.
  • In the side bar, the page posts an open request ({ spell: "open", kind: "external" }) with a VS Code file link.
    • The link: vscode://file/<worktree>/<file>:<line>
    • DocView.open() hands it to VS Code's openExternal(), which routes VS Code's own scheme back to VS Code.
    • Not checkable headless: the extension isn't in Playwright.
  • In Chrome, it's the plain VS Code file link. Chrome asks once before opening VS Code.
  • If the side bar does nothing, the smallest fix is in DocView.open().
    • It would handle a file link with a #L<line> fragment.
    • But that needs spell dev vscode, which can't run from this branch while it's behind main.
