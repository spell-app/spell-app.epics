Public renames in the checkbox, transition, visibility, feed and select components.

  • The checkbox (CheckControl, and RadioGroup): 
    isSelected()                    -> isSelected  (get / set;  setSelected(x) is isSelected = x)
chosenValue() / unchosenValue() -> getters
@proto static onValue / offValue -> defaultChosenValue / defaultUnchosenValue
keyDown() / chosen()            -> onKeyDown() / onChosen()
now getters:                       inputType, inputTabIndex, inputRole, isIndeterminate, hasLabelText, staticControl
RadioGroup getters:                members, membersInOrder, selectedMember, isRequired, tabStop
    • For the default values, these follow: the docs page, status.md, components.types.ts, and the vocabulary descriptions.
  • The others: 
    UITransition.setVisible()       -> animateTo()
UITransition.isVisible          -> isShowing
UIVisibility.isVisible          -> isOnScreen
UIFeedEvent.glyph               -> iconGlyph
UISelect.values                 -> chosenValues;   isShowingPlaceholder -> placeholderIsShowing
  • UIRadio reads its own members untracked when it joins or finds its group. The element layer's hooks may run inside someone else's computation.
  • A subclass that sets @E.proto static onValue must rename it.
