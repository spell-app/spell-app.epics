packages/app defines its two page elements, <spell-app> and <spell-editor>, with solid-element’s customElement() directly (a function component, a base class of its own, string / boolean attributes), and its shared Solid file spell-solid.js re-exports all of solid-element (~4.9 kB gzipped). P18 as written only counts what ui uses. The whole write-up: 1.5.9.

  • P18 touches packages/app too
