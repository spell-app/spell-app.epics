Until this branch merges, other checkouts' site pages carry an undefined <ui-components>, from the shared layout.

  • The layout part, layout.html, is SHARED content: every checkout sees it at once.
  • But <ui-components> and the docs pack exist only on this branch until it merges.
  • In main, or any other checkout, every site page has an undefined <ui-components>.
    • It's harmless on screen: it sits outside the root, so no root reports it, and it draws nothing.
    • But yarn site:check there reports 1 <ui-components> never defined on every page.
    • And it waits out its settle timeout on each page.
  • The docs pages themselves still work there: site.ts's DocsFamilies.add() loads the docs families.
  • If that bites before the merge, take the one line out of the layout, and put it back after.
