Solid compiles on={...} as an event listener. So a ui-* element's "on" attribute must stay a literal string.

  • Swapping <ui-popup on="click"> for on={UIT.CLICK} in the docs themes switcher broke every render: 
    Failed to execute addEventListener ... parameter 2 is not of type Object
  • Solid treats an attribute that starts with "on" and holds an EXPRESSION as an event binding.
    • The event name is empty, and the handler is "click".
    • A string literal stays an attribute.
  • Kept the literal, with a JSX comment saying why, in UIDocsThemes.palette().
  • Any family that passes on to a COMPOSED ui-* tag must do the same: popup, dimmer ...
    • attr:on={...} may be the way to keep a constant; not tried.
