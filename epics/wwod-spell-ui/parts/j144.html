Public renames in the calendar, slider, docs tokens, sticky, comment and placeholder components.

  • Where a method's old name is now the raw controlled attribute, the computed value got a new name.
    • The calendar's isOpen and value are now the raw attributes.
    • So are the slider's value and end.
  • The calendar's Cells are now @states.
  • The slider's scale is @derived. Its synced copy of the dragged thumb is gone: the state reads fresh, so the glide is right from the first move.
  • The renames: 
    UICalendar     isOpen()      -> popupIsOpen
               value()       -> chosenMoment      (value is the ISO string)
               min() / max() -> earliest / latest
               focusMoment() -> focusedMoment
UISlider       value() / end() -> snappedValue / snappedEnd
               dragging      -> draggedThumb      (its dragThumb copy gone)
UIDocsTokens   data / failure / query / probed / view()
                             -> siteData / loadError / filterText / probedColors / tokenView
UISticky       edge          -> stuckEdge
placeholder    holdsShapes() -> canHoldShapes
  • A page that reads calendar.controller.value(), or the slider's, needs the new names. None was found.
