Section, panel, sidebar, sticky, visibility, reveal, rail, text and segment are restyled to WWOD. These are the calls Owen might have made differently.

  • Public renames (boolean names; nothing outside each family read them): UISection.folded -> isFolded, .stuck -> isStuck; UISticky.bound -> isBound; UIVisibility.visible -> isOnScreen. UISidebar.wordWidth() (a public static) is gone: UIT.WordWidthClasses.classFor() replaces it (T6), and so does the fallback's copy.
  • UISticky had no stuck field and no null at line 56 (it already used edge + undefined). The boolean was bound.
  • fold-icon's values are now a const object, FoldIconPlace = { start, end } (the UIT.Key shape), so "start" isn't written twice. FOLD_END is gone, and <ui-panel> uses FoldIconPlace.end.
  • The section's TITLE / HEADER / CONTENT were the same names and values as UIT's, so it uses UIT.TITLE / UIT.HEADER / UIT.CONTENT. UIT.TITLE is documented as the title ATTRIBUTE, and here it's a class word.
  • ui-sidebar.css: inverted's literal oklch(0.22 0.005 260) is now the default of a NEW public token, --ui-sidebar-inverted-background, through its alias --_ui-sidebar-inverted-background (test/component-tokens.test.ts wants each alias named after its token). Rejected: a shared --ui-* surface token, because none has this exact dark value, so it would move pixels.
  • ui-rail.types.ts, ui-text.types.ts and ui-segment.types.ts held only a docstring, so they're deleted (as J37). ui-panel.types.ts lost the unused PanelVocabulary. ui-sidebar.types.ts no longer value-imports its vocabularies: the fallback's VOCABULARIES and WIDTH moved into ui-sidebar.fallback.ts.
  • Left as they were: ui-panel.css's 8 --spell-* reads (each has a --ui-* fallback, and ui imports nothing from brand: only names are shared). The 0 0 #0000 empty shadows in ui-segment.css / ui-section.css are placeholders, not colours, as P5 left ui-card.css's.
  • No caller outside the families changed. Behaviour unchanged. CSS: one rule could move pixels, and only if a page sets the new token.
