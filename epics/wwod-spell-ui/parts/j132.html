Every component that opens on a user's request now has one verb for it, requestOpen(). The popup is lined up with the dropdown, search, calendar and sidebar.

  • The table's public renames, to requestOpen():
    • UIDropdown.setOpen()
    • UISearch.setOpen()
    • UICalendar.setOpen()
    • UISidebar.setVisible()
  • Step 3 renamed UIPopup.setOpen() too; its row had kept the old name.
    • The overlay's dismiss handler, the scheduler, and the command and click handlers call it.
    • No caller is outside the class. The shared docs pages' setOpen is an app's own signal setter.
  • controller.setOpen(...) and setVisible(...) are gone, on all five.
