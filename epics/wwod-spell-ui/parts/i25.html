For a checkbox with no value, form.values reports true, where Fomantic reports "on". The same box SUBMITS "on".

  • Kept unchanged on purpose, from J44's aside.
  • Fomantic's rule: 
    values[name] = isChecked ? value || true : false
    • It reads jQuery's .val(), which is "on" for a box with no value.
    • So Fomantic reports "on", and its || true never fires.
  • Ours reports true for such a box, native or ui-*.
  • Where: valueFor(), in FormFields.ts. The comment there points here.
  • A fix: drop the true branch, so form.values says what the box submits. It breaks pages that read terms === true.
