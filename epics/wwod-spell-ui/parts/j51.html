The tail of components.types.ts was four groups named for their readers (one header listed 14 families, one held a comment, one had a longer ////// line) and ~17 undocumented constants. Now seven groups named for what they hold, every constant documented:

  • ## Keys (Key, then the DEPRECATED ARROW_DOWN / ENTER / HOME / END, still read by accordion, calendar, slider, input, modal, table, rating, brand: they go once P6 ends), ## ARIA: attributes, roles and values, ## Tags and selectors, ## Attributes and their values, ## Class and part words, ## Form words, ## Patterns
  • LINK = "a" -> ANCHOR_TAG: it's the tag, not a link (callers: UIItem, UIMenu, UITitle, UIStep)
  • added, lifted from my families: ARIA_EXPANDED (item, popup), SEPARATOR (item, divider), UL / OL / ORDERED (list, feed), COLOR_CLASS_PREFIX (item, step, feed). The feed / step / popup copies are left for their own restyles
  • SHAPE_COMMANDS moved from the Calendar group to Shape; ItemContext.hostRole is string | undefined (was | null, Q9: UIMenu and the item test changed with it); the file imports import type { E } from "$/ui/core" instead of two deep paths; object-literal keys of a documented token map (PART_OWNER_TOKENS ...) aren't documented one by one

Net effect:

  • one public rename (UIT.LINK), six new shared words, no behaviour change
