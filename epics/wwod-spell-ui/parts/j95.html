Test describes that were free text are now named for their subject: a call path, or a tag plus an aspect (Q8). Where no single tag or method is the subject, I chose these names.

  • The error boundary, in isolation.test.tsx: 
    UIElement.define() error boundary
UIElement.define() error boundary cost
UIElement.define() without the error boundary
  • The files about one API:
    • fallback.test.tsx: UIElement.Fallback
    • texts.test.tsx: UIElement.text()
    • translate.test.tsx: UIElement.define(tag, dictionary)
    • harness.test.ts: split in two
      • Fixture.render()
      • A11y.check()
  • Every element at once: <ui-*>, then the aspect.
    • For example <ui-*> events, page listeners ...
    • <ui-*> form round trip (live elements)
    • Its static half: StaticRender.page() form round trip
  • Files as the subject, as for style sheets:
    • ui-*.css component tokens
    • *.vocabulary.en.ts kinds, across families
    • *.vocabulary.en.ts / *.types.ts imports
  • Every static-render test of ui-a through ui-f: <ui-x> static render. There were four spellings.
  • An attribute inside the tag moved out after it: 
    <ui-dimmer on>        -> <ui-dimmer> on
<ui-fields equal>     -> <ui-fields> equal
<ui-accordion source> -> <ui-accordion> source
  • Banners: every file of 150+ lines, or with 3+ describes, has one // ## banner per top-level describe.
    • Each is named for its aspect.
    • The new helper test files have them too.
