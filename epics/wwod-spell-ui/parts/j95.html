Free-text describes became a call path, or a tag + aspect (Q8). Where no single tag or method is the subject, I chose:

  • the error boundary (test/isolation.test.tsx): UIElement.define() error boundary / ... error boundary cost / ... without the error boundary
  • test/fallback.test.tsx: UIElement.Fallback; texts.test.tsx: UIElement.text(); translate.test.tsx: UIElement.define(tag, dictionary); harness.test.ts: split into Fixture.render() and A11y.check()
  • every element at once: <ui-*>, e.g. <ui-*> events, page listeners ..., <ui-*> form round trip (live elements); its static half StaticRender.page() form round trip
  • files as the subject (as for sheets): ui-*.css component tokens, *.vocabulary.en.ts kinds, across families, *.vocabulary.en.ts / *.types.ts imports
  • every *.ssr.test.tsx of ui-a..ui-f: <ui-x> static render (was four spellings)
  • attribute-in-tag forms split: <ui-dimmer on> => <ui-dimmer> on, <ui-fields equal> => <ui-fields> equal, <ui-accordion source> => <ui-accordion> source
  • banners: every file of 150+ lines or 3+ describes has one // ## banner per top-level describe, named for its aspect (new helper test files included)
