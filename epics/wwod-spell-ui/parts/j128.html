Components add host listeners with UIElement.listen(), which removes them with the element. It's not named on(): that's an attribute of <ui-dimmer> and <ui-form>.

  • Owen's note in UIButton.tsx asked for this.on("click", this.onHostClick): a listener removed with the element.
  • Built as listen(type, listener, { target, ...options }).
    • One AbortController per element, made by the first call.
    • It's aborted when the host is released, not on disconnect (keepAlive).
  • Why "listen": a method named on on UIElement would hide the on attribute's getter.
    • That attribute is on <ui-dimmer on="hover"> and <ui-form on="blur">.
    • Group 7 found it.
  • Converted: 
    UIElement's own slotchange, DialogElement (2), UIShape (2), UIToast (6), UIButton, UIDimmer,
UISidebar, UINag, UIPopup (5), UITransition, UIDropdown
  • Listeners an EFFECT stops keep their own controller, aborted in the effect's cleanup.
    • the markdown's hashchange
    • the tabs' history
    • the popup's target
    • the dimmer's parent
  • Two private methods already had the name:
    • UITable.listen() became watchHost(), which calls listen().
    • UIDocsTokens.listen(section) became takeInnerEvents(section).
    • NativeFallback keeps its own listen(target, type, fn): fallbacks aren't components.
  • Test: it hears the host across a move, and stops after dispose().
  • The same listeners, with the same lifetimes.
  • About 25 lines of AbortController plumbing are gone.
