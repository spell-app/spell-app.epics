Owen's note in UIButton.tsx asked for this.on("click", this.onHostClick): a listener removed with the element. Built as listen(type, listener, { target, ...options }): one AbortController per element, made by the first call, aborted when the host is released (not on disconnect: keepAlive).

  • Named listen: a method named on on UIElement would hide the on attribute's getter on <ui-dimmer on="hover"> and <ui-form on="blur"> (group 7 found it).
  • Converted: UIElement's own slotchange, DialogElement (2), UIShape (2), UIToast (6), UIButton, UIDimmer, UISidebar, UINag, UIPopup (5), UITransition, UIDropdown. Listeners an EFFECT stops (UIMarkdown's hashchange, UITabs' history, UIPopup's target, UIDimmer's parent) keep their own controller, aborted in the cleanup.
  • Two private methods already had the name: UITable.listen() became watchHost() (it uses listen()), UIDocsTokens.listen(section) became takeInnerEvents(section). NativeFallback keeps its own listen(target, type, fn) (fallbacks aren't controllers).
  • Test: hears the host across a move, stops after dispose().
