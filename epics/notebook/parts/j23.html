T2: code spell => spellx used to write a page drawing prose or examples as <spell-page "x" notebook> holding a <draw>, which since P2 no longer draws its body.

  • Chose: no <draw>; each <markdown> block loose prose, each section the twin made a ## heading, everything else as written (SpellxWriter.pageDrawing()).
  • A block stays <markdown> when, loose, it would join the run of prose before it, or a line starts with <, {, // or ## , or is indented.
  • It falls back to a <draw> when its body couldn't say the same: something after a section that isn't one (the section would take it in), a block, a comment inside a section. A drawing with the web's own tags still goes in a <spell> chunk, as before.
  • Tested: Counter there and back compiles to the same program.
