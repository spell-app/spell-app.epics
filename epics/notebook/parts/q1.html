Two things notebooks have make sense for a page without the notebook flag.

  • Its own views inside it: <spell-view "counter"> written inside the page, lifted out to just before it. Today a view inside a <spell-page> is an error.
  • locked: only whoever can write the file saves an edit. Only the editor reads it, and only its in-place page edits a file, which needs the flag.
