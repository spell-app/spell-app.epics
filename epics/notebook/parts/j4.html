Page's lock is written the way View's and List's hand-written members are: a stored member of page in the built-in types table (builtinTypes.ts), Spanish's word candado in the Spanish words' builtInMembers, and Page.lock / page.py's lock by hand.

  • That way has no list of values, so a bare locked names nothing: the twin writes the value quoted, - its lock is "locked" (Spanish - su candado es "bloqueado").
  • A plain <spell-page "x" locked> now writes the same line: every page has a lock.
  • Only the editor reads the lock, from the tag, so nothing that runs changes.
