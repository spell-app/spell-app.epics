The tokenizer works out "draws its body" by looking ahead in the page's block once. The editor's Monaco colouring reads a file a line at a time (tokenizeLine()) and can't see the block, so there the notebook flag says, as in P1. A plain page with no <draw> colours its loose text as comments in Monaco until P3+ changes the colouring; nothing compiles differently.

The look-ahead also doesn't see a - to draw it: written in a <spell> code chunk inside a page: only a <draw> tag at the page's body indent counts (not a placed slot, <draw "front" />, nor one in fenced code or a comment).
