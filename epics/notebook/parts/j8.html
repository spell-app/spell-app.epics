The editor's code colouring still uses the notebook flag to decide whether a page draws its body.

  • The tokenizer works out "draws its body" by looking ahead in the page's block once.
  • The editor's colouring reads a file a line at a time (tokenizeLine()) and can't see the block, so there the flag says, as in P1.
  • So a plain page with no <draw> colours its loose text as comments in the editor; nothing compiles differently.

The look-ahead also misses a drawing written as code inside a page.

  • A - to draw it: in a <spell> code chunk inside a page doesn't count.
  • Only a <draw> tag at the page's body indent counts: not a placed slot (<draw "front" />), nor one in fenced code or a comment.
