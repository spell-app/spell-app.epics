  • An edit in a notebook's Spell view goes back through SX.SpellxWriter.writeMarkup(), read by spell's tokenizer: NotebookCode and its regex are gone. A <markdown> block in an example's code stays a block, as before.
  • Drive-by: SourceEdits.tagAt() read a template's quoted name's words as attributes, and put a new attribute before the name; it now skips the name, so the lock lands after it.
