NotebookController.notebooksIn() no longer has its own pattern of both languages' words: it asks NotebookPageCells.holdsNotebook(), which reads the file's chunk view (SX.SpellxView) for a page with the notebook flag, kept until the file's text changes.

  • Not the parse: a project compiled from the compile cache parses nothing, so its notebooks wouldn't show.
