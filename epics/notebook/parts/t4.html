The Spell view can't tell a web tag from a component when an example mixes an HTML block with other markup.

  • The code-spell writer (SX.CodeSpellWriter.writeMarkup()) writes a top-level HTML block's markup without its <html> tags: code spell reads web tags as they are.
  • So the way back can't tell <div> from a component.
  • The old pattern did the same.
  • An example that's ONE HTML block is fine: it shows as written in both views.
