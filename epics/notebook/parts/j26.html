spell lint had no named rules of its own, so the warning takes the parser messages' kebab-case: description-before-example.

  • A lint problem carries it as rule (in --json too); a line ends (description-before-example).
  • A warning alone no longer makes spell lint exit 1: only errors do. Before, lint never listed a warning among its problems, so nothing else changes.
the fixers: spell lint --fix writes <spell-notebook> as <spell-page notebook>, a <spell-view> inside a page as <view>, and a description before an example as its description=, with a warning, description-before-example
