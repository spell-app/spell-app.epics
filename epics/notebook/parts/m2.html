1. In the browser, open the editor's notebook page (`spell server start` from the kit's root, if it isn't running): 
/edit/@spell/notebooks/Counter/Counter.spellml
2. Click an example's heading: it shows the selection's marching ants. 3. Drag it by its heading above the section before it; watch the drop line. 4. Click a paragraph of text, then drag it below an example. 5. Press ⌘Z twice. 6. Open the Inspector (its toggle in the top bar), and drag a row of its Views tree onto another. 7. Open the palette (the top bar's +): click This page › View, then Documentation › Example.

The drop line follows the pointer, between cells or round a section; each drop changes only the moved lines of the file (the code column shows it), the page redraws in about a second, and an open example's code stays open. ⌘Z puts each move back. The palette's Example appears under what's selected, with its heading, "An example", and its own code editor; View adds a new view at the page's end. A slider or button inside an example still works while the example is selected.
