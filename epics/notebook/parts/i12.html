A value like style=" followed by a line break compiles to a string holding raw line breaks. The parse reports no error, so the site's tests pass, but in Run the page shows SyntaxError: Invalid or unexpected token.

  • Seen failing in Run: Panel's Examples and Menu's Examples.
  • The same shape is in Popup's Examples and Comment's Usage; not opened in Run.
  • Kitchen Sink had two; those are joined onto one line in its own file.
  • The fix belongs in the compiler, which should escape the value's line breaks.
