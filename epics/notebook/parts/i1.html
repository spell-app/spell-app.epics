  • - su candado es "bloqueado" becomes get lock() { return "locked" }; - su dirección es abajo becomes get direction() { return "down" }.

  • Its value goes through the member's valueOutputs, quoted or not; a built-in member gets those from a new table in the language's words (candado: bloqueado, desbloqueado).
  • The property the line declares carries the same output, so a later su candado reads .lock too.
