1. In the ⎇ notebook window's terminal, print this worktree's editor address: 
    cat .spell-server.editor.json
  2. In Chrome, open that address followed by: 
    edit/@spell/notebooks/Button/Examples.spellml
  3. Turn File › AutoSave OFF if it's on.
  4. In the app area (right), click the first example's </> button (Types › Button), click in its code at the start of Follow, and type Zap.
  5. Wait about 2 seconds, then press ⌘Z while the cursor is still in that example's code.
  6. Click the lock icon in the app pane's header (right of Button ▾), type Z in the same example again, and press ⌘S.
  7. Reload the page (⌘R).
  8. Click the lock icon again to unlock it.
  • Step 4: the button draws ZapFollow about 2 seconds after the typing stops; the cursor stays after Zap, the code pane stays open, and the code column on the left shows the same text.
  • Step 5: ⌘Z takes all of Zap away in one go, and the button draws Follow again.
  • The page looks like Spell UI's docs page: sticky foldable section titles, "On this page" at the right (or its list icon, at the pane's top right, in a narrow window).
  • Step 6: the header says Locked: changes aren't saved; ⌘S saves nothing.
  • Step 7: the button is back to Follow, and the page is still locked.
  • Step 8: unlocked, the file has no locked in it (git diff shows nothing).
