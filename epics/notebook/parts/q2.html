In a notebook, loose text is drawn as markdown. In a page, loose text is a comment: the lines above a member are its docstring. 

<spell-page "about">
	# About us
	We make things.
</spell-page>
Loose text draws only in <spell-page notebook> (or <spell-notebook>); in any other page it stays a comment.A page with no <draw> draws its loose text by itself; the flag only turns on the editor's in-place page.One rule for what loose text means, set by one word; no page changes meaning when a <draw> is added or removed.
