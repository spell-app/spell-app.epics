Checks that /epic refuses plan mode, keeps your text, and writes the stub doc first.

Step 1: turn plan mode on, then type /epic tmp-z some text.

What should happen:

  • It's blocked, with "Plan mode is on".
  • Your text is quoted back and saved.

Step 2: leave plan mode, then type /epic tmp-z.

What should happen:

  1. It uses the saved prompt.
  2. It makes the worktree and the stub plan doc.
  3. It moves to the worktree's window, and ends the turn.
  4. The doc shows the "Plan hung?" notice, with the prompt and a Copy button that works.
