/isolate <name> now runs in this order:

  1. The prompt hook (prompt-gate.mjs) sees the prompt first (D1, P1).
    • it renames the session
    • or blocks it, in plan mode or inside another worktree
    • saving the text first, to ~/.spell/prompts/<name>.md
    • not on /park or /wait-for, which may name another session (D4)
  2. Then, in order:
    • the name, and any collisions
    • EnterWorktree
    • the worktree's window
    • handoff --prompt continue
  3. The turn ends at once (P2): the new tab opens with continue typed in, and the old tab closes.
  4. First turn there ("Continue"): yarn install, any saved text, carry on.
