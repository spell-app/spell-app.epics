Binding power (how tightly an operator holds its operands) changes two readings on purpose:

spell today proposed
x + y is empty x + isEmpty(y) isEmpty(x + y)
the absolute value of x + 1 absoluteValue(x + 1) absoluteValue(x) + 1
the number of cards in the deck + 1 itemCountOf(deck + 1) itemCountOf(deck) + 1
  • postfix tests (is empty, is face up) bind like comparisons: looser than +
  • every prefix rule (the first X of, the number of, the absolute value of …) takes ONE term, stopping before any operator -- the same rule for all, so nobody has to remember which

all prefix rules bind at 15: abs(x) + 1. Predictable; write the absolute value of (x + 1) for the sum.

absolute value, round bind at 12: abs(x + 1), like math notation |x+1|. Two rules to learn.

the absolute value of x + 1 => absoluteValue(x + 1) (operand bound 12: takes + - * /, stops before is); the number of cards in the deck + 1 => itemCountOf(deck) + 1 (bound 15).
