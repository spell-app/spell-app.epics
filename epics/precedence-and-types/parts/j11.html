MethodDefinition.addMethod() puts a P.ScopeMethod in its type's methods only if THIS project declares the type. A method of a built-in (Thing) or imported (Card from @library/cards) type, or of a word that isn't a type yet, goes in the project's own methods, its of saying whose; findMethod() looks there second, checking isA(of).

  • chosen: why -- root and import-layer types are shared by every project (and the import layer is outside the journal), so a record added there would outlive the edit that made it, and leak into other projects in the same process (the language server)
  • other: always on the type, as Parser Model §6.2 sketches
