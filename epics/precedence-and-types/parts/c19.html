The read-only check is a lookup at parse time, so an early set can slip past it and throw at run time.

  • a set in an earlier file, or above a pile is an exclusive list of cards, auto-declares pile (P6) before the exclusive line replaces it
  • scope ends right: reads see the exclusive member
  • but the compiled card.pile = x meets a getter-only property at run time: a TypeError
  • probe X4 pins the compiled shape
  • fix, if it matters: the type pre-scan (declaredTypes()) could note exclusive too, so every set sees it
