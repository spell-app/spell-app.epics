• a method / getter returns what all its returns return, if all agree; none or a mix => unknown. A bare return counts as nothing, so set up a deck (only bare returns) returns nothing.
  • returns inside a body with its own MethodScope (a loop, a callback) are skipped: they compile to a callback's return.
  • an inline EXPRESSION body is what it returns, e.g. the name of a card is ... => text.
  • a getter's inferred type becomes its property's datatype only if the getter declared the property and nothing gave it one (first datatype wins). So property_value_getter lost changesScope: "internal": editing a getter's line re-parses what follows (D9); an edit to its BODY does only if the type changes.
  • Declarations gain returns / datatype keys on the fixture and live examples: additions only (D37).
