From the review page (J29). Owen: "why not Deck.declareProp(...) which passes the metadata as well?"

  • today an auto-declared property compiles to three pieces:
    • a /*! SPELL: DECLARES */ comment: the metadata
    • Deck.declareProp('is_set_up', { type: 'choice' }): the schema (Schema.ts)
    • an Object.defineProperty(...) accessor
  • fold them into ONE call that also defines the accessor, and carries auto / defined
  • the catch: importers read declarations from the compiled TEXT; SpellDeclarations.read() scans the comments
  • so either the reader learns to read the call too, or the comment stays beside it
