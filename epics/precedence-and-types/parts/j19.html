Fixing I5 / J10 (D32): before any file parses, parser.stubDeclaredTypes() stubs each type the files declare, found by SpellParser.declaredTypes() -- lines STARTING a card is or create a type called hand. Its declaration then claims the stub. P.IncrementalProject compares each file's declared names on every update: changed => rewind to before the stubs and re-parse everything (~50ms on Solitaire). The scan needs only a card is, not a card is a thing, so a half-typed declaration (a card is a) keeps the editor's keep-last-good path.
