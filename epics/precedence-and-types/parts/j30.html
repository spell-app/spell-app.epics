A property's record keeps its compiled name (short_rank) as name -- scope keys, declarations and scope-pack paths stay as they were -- and its words as written, if different, as words (short rank, short-suit). Hover, completion and the Type Explorer show words; a scope pack entry gains name when it differs from its path's. So the Type Explorer and spell describe now list short-suit where they listed short_suit.

  • Option: path by words -- breaks the runner, which matches compiled code to entries by property: "short_rank".
  • Completion after the offers EVERY visible type's properties: what's typed doesn't know yet what it reads from.
