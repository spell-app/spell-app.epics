• Snippet / signature-help names come from the method's P.ScopeMethod: the receiver ({thisArg}) as its type in instance case, the rest from params. So to show (thing as a card)'s receiver is now card, not thing.
  • Signature help's parameter ranges come from where method_signature found each argument (data.argMatches), so (a card) and a card both work.
  • Highlighting: in to give a card to a pile, card / pile are parameter, a stays a keyword; the paren form is unchanged (card a type).
