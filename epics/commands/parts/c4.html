On the commands page, typing in the filter hides rows, and families with no rows left. The contents column on the right still lists every family.

  • Example: filter on worktree, and the page shows only the worktree rows, but the contents still lists every family, most of them now empty on the page.
  • Why: the page runtime's own filter (wireFilter()) only knows cheat-sheet cards.
    • the commands page has its own, in commands.js
  • The fix named here was the runtime hook in the call on how the page boots (T2), "if that's chosen".
    • that call chose commands.js booting the bundle itself instead, so the hook isn't there to use
  • nothing changes: an accepted, cosmetic limit
