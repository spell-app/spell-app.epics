Which commands move into the spell dev CLI, and which stay yarn scripts. A call to review.

  • Chose: each package's tool-native scripts STAY yarn scripts:
    • ts, lint, format, test, build, gen:*

  • Over: routing every script through the CLI, e.g. spell dev ts ui. More uniform, but it wraps tools that already have a good home, and adds about 0.5s per call (the caveat on startup, C3).
  • Instead, spell dev check runs them all (roadmap move R7 on the commands page; not built yet, checked 2026-10-04).
  • yarn ts, yarn test ... in a package stay as they are
