Settled over four rounds on the colour-scheme page (Owen, 2026-10-08):

  • red: needs you; yellow: open, still undecided (dark text); blue: do it now, or Claude is working on it (Do Now, Revisit, Send, the Underway card); green: decided or done (Approve, Make Todo, the Done card); orange: changed since you looked, and warnings; violet: Claude's voice (his replies); ivory: your voice (your notes, replies, the answer card); grey: older, inactive, not chosen
  • the fill: dashed = you pressed it, not committed; outline = recorded, not done yet or in progress; solid = done
  • buttons: Approve, Revisit, Make Todo in one group; Do Now apart, with the paper-plane icon
  • the contents and rail count: red, only what needs you; "recommended": grey text; goals items: by state, like plan docs
  • no light blue, no light green

  • one change recolours every element and doc page, and the plan-doc guide gets the colour table and the fill rule (todo T22)
