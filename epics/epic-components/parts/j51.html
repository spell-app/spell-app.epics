Chose waiting over a note on the page, because it needs no page or bundle change and works with live reload as is.

  • Options: (a) wait, up to 2 minutes (picked); (b) inject a 'Building Spell UI...' banner into pages served during a build; (c) answer 503 and let live reload fix it
  • Only a MISSING file waits: a file of the old build is served at once, and the page reloads when the new one lands (the server watches both folders)
  • A request waits for the whole build (both bundles), about 3 s from a cold start
  • A page opened right after the server starts looks blank for a few seconds, then renders; no note says why
  • A failed build: the request is answered 404 after its wait; the reason is in .spell-server.log (lines start bundles:)
