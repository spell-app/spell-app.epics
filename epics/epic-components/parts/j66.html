Built <epic-code title language open> in the epics pack: a folded code-well panel (the same fold as <epic-aside>, one EpicPanel base), the code drawn by Spell UI's own <ui-code> in its shadow root (colours, copy button). Folding and a title are a disclosure's job, not a code block's: <ui-code> stays one thing, and guides keep ui-accordion.spell-code until they want the same. Promoting later is cheap: the element is a thin fold around <ui-code>.

The code is the element's own text in ONE <pre> child (<epic-code title="x.ts" language="ts"><pre>...</pre></epic-code>), not bare text: a formatter reflows the white space of text in a custom element (the demo page's format pass kept the <pre> intact), and the page reads it before the pack loads. The <pre> isn't slotted, so the code shows once; find-in-page reaches the drawn copy, and folded bodies are hidden="until-found". open keeps the 68 accordions that start open (open="0").
