Two calls the contract left open:

  • NAME: "else by name" needs a name before the script runs, so the load takes it from the file: epics.pack.js means epics (ComponentPacks.nameFor()). The same rule lets a URL whose pack is already registered (a page own <script src>, an ES import) resolve at once, with no second script. So P2 MUST name each pack after its file (packages/<pack>/pack/<pack>.pack.js, name <pack>).
  • FAILURES: a pack that cannot load, runs without registering, or is still loading at the timeout becomes a RootFailure { tag: "ui-components", reason, source, error } (new optional source), in ui-error (cancelable) and ui-ready failed, with a console.error naming the source (Spell UI own tags keep their console.warn). An undefined tag with a registered prefix is unknown when the catalog does not list it, failed when it does (the pack defines every listed tag as it registers).
  • The root always gets ready; the page says which pack broke.
  • A second registration under a known name is ignored with a warning; define() throwing fails the load and is rethrown.
