Spell UI's element layer refuses an attribute whose property would shadow the browser's own (el.id, el.title), so the vocabularies name those properties epicId / epicTitle, as ui-divider does with hidden (dividerHidden).

  • the markup still says id="q7" and title="..."; links, getElementById, el.id and el.title work as on any element (a browser test pins it)
  • in data (Markup.read()) and in the element's own code (this.attrs) they're still id and title
  • the other option, overriding the platform's on purpose, gains nothing: the platform's already reflect the attribute

Net effect:

  • nothing visible; only code setting el.epicTitle would notice
  • P5 should check a host's title doesn't show as a browser tooltip over its whole body (T-item below)
