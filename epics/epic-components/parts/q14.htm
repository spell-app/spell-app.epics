Every Overview sub-section (o1, o2 ...) gets the same review controls the items have, so Owen can comment on the overview parts of the plan, not just on questions and items (Owen, 2026-10-07).

  • a note box under the section's heading, with drafts kept as for items
  • the same three kinds of feedback as items:
    • Make Todo: the note becomes a todo
    • Revisit soon: the note goes into the queue
    • Revisit Now / Add Details Now: done now
  • sent through the same review inbox, with the section's id (o1) where an item's id would be

Net effect:

  • Review Buttons In (P9) also draws review controls on every Overview sub-section
  • the review inbox and its routes accept section ids as well as item ids
