spell dev plan-doc convert picks the pass per doc: a doc in the old markup gets the first pass (Converter), a doc already in <epic-page> markup gets the second (Upgrader, P14's elements). A doc the second pass has nothing left to do for is skipped, nothing written, and its report line says what it kept as prose. --out and --dry-run work as before (no --out: a dry run; never into epics/).

Why: one command takes every doc as far as it goes, and --all stays clean once the docs are migrated (a second run over the output skips all 28). A flag would only add a way to run the wrong pass.
