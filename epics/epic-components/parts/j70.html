Do Now (paper plane) replaces Add Details Now and the note box's Do Now. Pressed with a note in the box (typed or a saved draft) it asks a revisit NOW with that note, as the box's Do Now did; with no note it asks for details, as Add Details Now did. The inbox's actions and data are unchanged (still details / revisit when: now); only ReviewClient.press() routes the click. To draw Do Now SOLID once done, inbox done now records review-as="now" for an immediate request (Add Details or revisit now), where a revisit now used to record revisit; a revisit talked over (clear) still records revisit. now is a new value of <epic-item review-as> (vocabulary and PLAN-DOC.md updated). Every button shows at every step (Owen's note on examples B-D): a done mark is solid in the group, the rest grey and clickable.
