Chose to make elements only of what the script writes, and keep everything hand-written as the prose it is, over converting every look-alike.

  • an option grid (ui-grid.spell-pros-cons) straight in a QUESTION's details becomes <epic-choices>; one in a judgement call, issue, reply or answer is options weighed in an explanation, often mid-text between headings (outline-spell J3, J8): it stays a ui-grid
  • only the script's UPDATE note (header="UPDATE" with data-phase) becomes <epic-update phase>; hand-written ones (DONE · option A, 2026-10-06, DEFERRED, an UPDATE with no phase) keep their header and stay ui-messages
  • an UPDATE label on an item's line goes into a slot="title" span with the title, so it still shows on the line without loading the body (shared-content, 5)
  • option titles with no letter (markdown's Choices: New package, Inside parser) get their position's letter, A, B ...

Net effect:

  • no hand-written header or note text is lost to a drawn label
  • judgement calls' grids won't get Choose pills when P8 draws them for questions
