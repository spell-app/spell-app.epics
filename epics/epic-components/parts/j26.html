The proof (ConversionProof) reads the old doc and the new, both whole (parts put back), and compares ids, link targets and visible words. Chose to compare words PER UNIT (an item, a phase, an Overview part, a section, the page) as counted sets, over one doc-wide word sequence: a sequence fails on every intended move (an answer after its question), and a doc-wide set misses text moved to the wrong item.

  • a unit whose words only changed order is listed as reordered, not a loss
  • what the elements now draw is left out of the comparison, narrowly: by WHERE it sits (a card's Choices title only on a card straight in an item's details, not on the copy of one in an Original Discussion) and by what it says (a chip only when it names its own item, D7 only when it's the answer's own id); convert --verbose prints the list
  • titles moved into attributes are read back from the attributes, as the elements will draw them; links the elements draw (chips' #q7, commits' GitHub links) count as links
  • all 26 docs: no id, link or word missing or added
  • a lost paragraph, id or link, or text moved between items, fails the run (the tests break a good conversion each way)
