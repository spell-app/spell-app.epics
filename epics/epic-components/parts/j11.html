Beyond workspaces, aliases, root vitest, lint ignores, .gitattributes and GENERATORS, pack new also:

  • adds packages/<pack>/pack to the root package.json's pageServer.watch, so pages that load the pack reload when it's rebuilt (as packages/brand is there)
  • adds the pack's yarn scripts to guides/dev/commands/commands.json (beside brand's in the check rows; pack:build / pack:check in the new rows pack-build / pack-check), then oxfmt formats it as before, so spell dev commands check passes right after
  • the prefix lives in the pack's package.json: "spellPack": { "prefix": "epic-" }, which is also how the CLI tells a pack from other packages
  • since the commands page is shared, main's spell dev commands check reports <pack> ts ... as names with no command until this branch merges (the same known gap any branch adding a command has)
