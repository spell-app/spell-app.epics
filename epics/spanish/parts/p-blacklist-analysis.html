About 105 English words couldn't be a name, and nobody knew which of them the grammar really needed.

Found what the blacklist protects, by an opt-in test that drops each word in turn and recompiles every rule test and fixture project, and kept only that.

  • The blacklist went from 105 words to 8, each with the line it protects beside it: is / if / the / in / of / with / to / no.
  • So first, empty, short and long can be names now.
  • The Spanish pack lists its own words for those 8 roles.
  • The member stop words and dangling words were kept as they are.
  • The identifier blacklist went from 105 English words to 8, each with the line it protects beside it: is / if / the / in / of / with / to / no.
    • so first / empty / short / long can now be names
  • How it was found: an opt-in analysis test drops each word in turn, and recompiles every rule test and fixture project (BLACKLIST_ANALYSIS=1, about 90 seconds).
    • only 7 mattered alone
    • dropping the rest together then broke two more spots, so two went back:
      • to, for set y to
      • no, for yes or no in outline-solitaire
  • One rule test used short to show the blacklist working; it uses if now.
  • What the Spanish pack must list: its words for these 8 roles, confirmed by the same analysis once Spanish parses. Likely es / si / el / la / los / las / en / de / con / a / no.
