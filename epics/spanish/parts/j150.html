A call of a method an imported project declares is written with that project's own words: increment the counter => increment el contador.

  • Why: the Spanish file reads an English import only by the words the import declares; incrementar el contador doesn't lint. Checked by hand on counter-app: lint clean, 2 of 2 tests.
  • So an import's names are NOT translated in the names batch (P25's plan said "otherwise translate its names in the same batch"): they're kept as declared, beneath the project's own dictionary.
  • An import with its own .es.names.json5 AND a translation recorded beside it in its group: its names are used, and the project file imports the translation instead.
  • A name the project declares itself (draw it) is still asked for, even when an import declares the same words.
