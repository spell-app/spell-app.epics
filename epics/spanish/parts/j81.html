One rule, draw_it (DrawIt.ts), replaces draw_side. It reads which drawing by what the words MEAN, a new word rule draw_method (draw / draw_each_item).

  • Quoted, - to "draw it":, its body is markup, inline or one indented line, as the sides' was: no return.
  • Unquoted, - to draw it: / - to draw each item:, its body is a method's, which returns the drawing.
  • English's unquoted to draw it: is left to to_do_something, which already made the same draw(): so no example's declarations change. Spanish's para dibujarlo: is this rule's, since the fused -lo would make a method named dibujarlo().
  • to draw each item only parses in a list type's outline; on a thing it's an error.
