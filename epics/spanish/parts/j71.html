A message's example picks its article from the pack (Language.withArticle()).

  • English uses the agreement's sound rule, so an example now says a user where the old code's first-letter rule said an user; no test or snapshot changed.
  • Spanish takes a type's gender; for a word naming no type (a property) it guesses by the ending: -a, -ión, -dad, -tad, -tud, -umbre feminine, else masculine. So una dirección, but un mano, un día would be wrong guesses.
