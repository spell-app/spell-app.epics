  • spell lang packs check [<lang>] checks each language against English:
    • every rule registered in a <module>.en.ts has an entry in its <module>.<lang>.ts, with syntax and at least one test
    • every word rule and every table has every key: booleans, ordinals, type words, built-in members, JSX words, messages
    • it prints what's missing, per file, and exits 1 when anything is
    • it runs in spell-lang's yarn test as a test too
  • spell lang packs fix [<lang>] writes the missing entries as stubs: the English syntax copied and marked TODO: translate, its tests copied with the English input, so the file lists what's owed.
  • spell lang packs fix --ai drafts the translation of each stub (the syntax string and the test inputs) by asking Claude.
    • as context: the English rule's docstring, syntax and tests, and the pack's existing translations for its vocabulary
    • each draft is marked AI draft for review
    • the check then passes, and a review list is printed
  • How the AI is reached, a decision Owen can flip:
    • the claude command already on the machine (claude -p, a subprocess): no new dependency, Owen's own account
    • not the Anthropic SDK: a runtime dependency, and an API key
  • The English side is checked too: a rule class registered in no .en.ts is reported.
