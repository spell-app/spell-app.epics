Choices a native speaker may change (all in languages/es/parserMessages.ts):

  • Di qué es / Di qué contiene "x", p. ej. "..." for Say what x is / holds, e.g.
  • No entiendo "..." for Don't understand
  • esquema for a type's outline, propiedad calculada for a getter, hueco for a blank, con sangría for indented
  • uno de unos valores fijos for a value kind's value
  • No se puede añadir ... al tipo X, No se puede guardar el tipo X dentro
  • A long form's property takes a definite article by guessed gender: el "color" de una carta es ...; long forms compile the same as the outline, as English's do.
