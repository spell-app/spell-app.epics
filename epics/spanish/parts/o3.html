The hard part is grammar, not words: gender, articles, plurals, verb forms. Each one below says what Spanish does and how the pack takes it, so the grammar work in P3 and P4 has no surprises.

  • Gender and articles. un / una, el / la / los / las, and the contractions de + el = del, a + el = al. The pack's article groups are (un|una), (el|la|los|las)?, (de|del) and (a|al). Agreement isn't checked, as English never checks a against an (question Q3).
  • Plurals. -s after a vowel, -es after a consonant, z becomes ces, accents move (corazón / corazones, joven / jóvenes), some words don't change (lunes, crisis). A Spanish inflector with those rules and an irregulars list; a type's own oddity goes in its declaration, as aka does today.
  • Adjective after the noun. carta boca arriba, pila de descarte. A declared name is a run of words looked up whole, so word order inside a name never reaches the parser. Only the built-in two-word types need Spanish words (cosa dibujable).
  • Two verbs for "is". es (what a thing is) and está (its state): both register as "is", (es|está), negated (no es|no está).
  • Conditions. si … :, then si no or de lo contrario, and the value form rojo si su palo es corazones de lo contrario negro. si no sits next to the boolean no: the choice order settles it.
  • The dropped subject. Spanish leaves it out: tiene un mazo. Outline lines without a subject already parse (subject_implied); su / sus stand for its.
  • Ordinals with gender. primer / primera / primero, última: the ordinal word table lists every form.
  • Booleans and numbers. sí / no / verdadero / falso / siempre / nunca, ok / cancelar; uno … diez. The decimal comma (1,5) stays two tokens for now: a caveat, not a blocker.
  • Methods and tests. para "mover (una carta) a (una pila)":, devolver, para probar …. Signature words are taken as written, so the phrase itself needs no rule change.
  • Question marks. ¿ and ¡ already tokenize as symbols; no rule uses them yet.
