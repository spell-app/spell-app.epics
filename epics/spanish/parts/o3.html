The hard part is grammar, not words: gender, articles, plurals, verb forms. Each one below says what Spanish does and how the pack takes it, so the grammar work in P5 and P6 has no surprises.

  • Gender and articles. un / una, el / la / los / las, and the contractions de + el = del, a + el = al. The pack's article groups are (un|una), (el|la|los|las)?, (de|del) and (a|al). Agreement is checked and WARNED, never an error, in both languages: el carta gets "la carta?" and a apple gets "an apple?" (question Q3, P7).
  • Plurals. -s after a vowel, -es after a consonant, z becomes ces, accents move (corazón / corazones, joven / jóvenes), some words don't change (lunes, crisis). An existing rule set first (Owen's M3): Python-Inflector's Spanish rules are the best documented, the npm packages only pluralize; ported into our own inflector if none fits as is. A type's own oddity goes in its declaration, as aka does today.
  • Adjective after the noun. carta boca arriba, pila de descarte. A declared name is a run of words looked up whole, so word order inside a name never reaches the parser. Only the built-in two-word types need Spanish words (cosa dibujable).
  • Two verbs for "is". es (what a thing is) and está (its state): both register as "is", (es|está), negated (no es|no está).
  • Conditions. si … :, then si no or de lo contrario, and the value form rojo si su palo es corazones de lo contrario negro. si no sits next to the boolean no: the choice order settles it.
  • The dropped subject. Spanish leaves it out: tiene un mazo. Outline lines without a subject already parse (subject_implied); su / sus stand for its.
  • Ordinals with gender. primer / primera / primero, última: the ordinal word table lists every form.
  • Booleans and numbers. sí / no / verdadero / falso / siempre / nunca, ok / cancelar; uno … diez. The decimal comma is the pack's (Owen's M4): 1,5 is a number, 1, 5 a list.
  • Methods and tests. para "mover (una carta) a (una pila)":, devolver, para probar …. Signature words are taken as written, so the phrase itself needs no rule change.
  • Question marks. ¿ and ¡ already tokenize as symbols; no rule uses them yet.
