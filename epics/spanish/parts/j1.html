P1 made every spell word Unicode, but left JSX tag names (<div>, <ui-card>) ASCII-only.

  • Why: Spell UI's localized tags drop accents (ie-boton, not ie-botón), and custom element names are safest in ASCII.
  • P9 (Spell UI in Spanish) revisits it if a Spanish drawable's tag needs an accent.
  • <juego-carta> works; <juego-corazón> doesn't read as a tag.
