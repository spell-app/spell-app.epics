A word is fixed only when both hold:

  • the parse matched it with one of the pack's own keyword rules, so a name a person chose (poner numero a 5, a method's words) stays as typed
  • the pack never lists the unaccented word on its own, only beside its accented one, so si (if) is never turned into sí (yes)

Spanish's fixes today: numero, posicion, animacion, vacio / vacia, mayusculas, minusculas, fraccion, mas, version, deberia, esta, informacion, impresion, ningun, despues, minimo, maximo, electronico. esta becomes está only where it parsed as the keyword.
