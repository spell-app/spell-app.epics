The Spanish draw_method wording: ((draw:dibujarlo|dibujarla|dibujar (eso|ello))|(draw_each_item:dibujar cada elemento)).

  • dibujarla for a feminine type (una carta), dibujar eso as Spanish's other methods say it (J37).
  • In para dibujar cada elemento, the item is el elemento, el item or its type's name, la carta; English's is the item or the card.
  • dibujar cada uno left out: uno would shadow the number word inside the body.
  • Glossary row updated; frente / dorso / reverso are gone with the sides.
