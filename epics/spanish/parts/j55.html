The editor dedents a line that starts with else, otherwise, sino or de lo contrario.

  • si no dedents only as si no: or si no si ...: on its own it may start an if, like si no hay cartas:.
  • So a bare si no followed by Enter doesn't dedent.
  • One pattern, LSP.SpellKeywords.DECREASE_INDENT, for Monaco; VS Code's settings file copies it, and a test checks they match and that every pack's else matches.
