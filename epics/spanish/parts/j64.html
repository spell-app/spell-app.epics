The editor's page, index.html, no longer says lang="en".

  • the entry calls AppTexts.namePageLanguage() before anything draws
  • it sets the document's lang to navigator.language when it has none
  • so Spell UI's <ui-root> loads its Spanish too, and screen readers agree
  • An English browser: exactly as before.
  • A Spanish browser (or <html lang="es">): the editor in Spanish, Spell UI's widgets too.
  • <spell-app> / <spell-editor> on a host page never touch the host's lang; they read it (else the browser's).
