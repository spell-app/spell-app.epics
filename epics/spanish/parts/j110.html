Owen's joker says it "is the (color) joker", and his tests ask it of a plain card (the card is the red joker), which had no such method.

Chose: a phrase declared on a SUB-type of another of the project's types compiles to a STATIC method of that type, checking the type first, and every use calls it so:

  • static isTheColorJoker(card: Card, color) { return card instanceof Joker && card.color === color }
  • the card is the red joker => Joker.isTheColorJoker(card, "red"), all three targets (Python: @staticmethod, isinstance)

Over: defining it on Card with the class check (only works when the writer knows to), or a call-site card instanceof Joker && card.isTheColorJoker(...) (evaluates the card twice). A phrase on a root type (Card, whose super-type is built-in) stays an instance method, so nothing else changed shape.
