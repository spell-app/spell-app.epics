1. In a terminal at the kit's root (~/www/spell), translate the todos test project from nothing (no glossary, no saved names), through claude -p: 
    spell translate @spell/test/todos-form-based --to es --cold --out /tmp/todos-es
  2. Wait for it to finish (about 15 s), then open /tmp/todos-es/todo.es.spell in VS Code (File › Open...) and read it.
  3. Run it: 
    spell run /tmp/todos-es
