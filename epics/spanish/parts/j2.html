A word typed as o plus a combining accent names the same member as a typed ó (NFC), but the file's own text and offsets are untouched.

  • Why: editors, error positions and the source comments in compiled code must line up with what's on disk.
  • So two spellings compile alike except for their source comments and positions; the test compares the names.
  • Two spellings of corazón are one member; error positions stay right.
