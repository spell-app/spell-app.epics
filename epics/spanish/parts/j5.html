A drawable's element tag was the project's name made singular in English, then the class's; now the project's name stays as it is.

  • e.g. project games, class Card:
    • was <game-card>, now <games-card>
  • Why: the tag is named at run time, by the core, and a running program must not load an inflector (the plan review). English singular rules would also mangle a Spanish project's name.
  • No fixture or example changes: their projects are named in the singular (Solitaire, test-project). Only tests with plural project names changed.
  • A project named in the plural gets plural tags.
