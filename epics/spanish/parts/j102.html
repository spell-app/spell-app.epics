P21 part A (J96). A number word (tres, three) is a name in two places only:

  • the target of poner / set: the assignment's syntax tries {variable} before {expression}, so poner tres a 3 declares tres (it compiled 3 = 3 before); English the same, set three to 3
  • once a variable of that name is in scope, it wins over the number: imprimir tres + 1 reads the variable

Anywhere else a number word stays a number, e.g. cuyo rango es dos. el siete already worked (an article makes it a name).
