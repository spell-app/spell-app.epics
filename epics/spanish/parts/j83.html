• to draw it on a drawable list stays DrawableList.draw(): by default just the <slot>, so the wrapper shows nothing; a wrapper that throws shows the usual stand-in, in its own error boundary.
  • to draw each item is drawEachItem(item): by default the item's own drawing (core.drawThing(), its element when it has one), or its text when it can't draw.
  • core.drawItems() draws each item with the list's drawEachItem() when it has one (any list type that writes one), in a boundary of the list's; the default adds no second boundary. A plain list without one draws as before.
  • So the runner's <game-pile> children are whatever to draw each item draws, e.g. <div class=spot><game-card>.
  • Python's spell_core twin does the same (draw_each_item).
