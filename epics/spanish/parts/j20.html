A method starts para (para mover (una carta) a (una pila):), a test para probar ... (its call probar ...), an animation (crear)? (animación|animacion) .... An argument's type is (x como (un|una)? tipo), its default (x (=|es|de|como) valor) -- English's set to has no Spanish form. Props are (con a, b y c). A quoted phrase ends (si|es)?, as English's (if|is)?. A receiver left out in an outline body is (de|del) ... after the phrase.

Risk: para is also for-each's first word (para cada carta en la pila); the two tie on length, and the earlier-registered module (statements) wins the tie. The declarations' method-line pattern (^para) also stubs every para cada ... line as a method call ahead.
