New rule unicode_offset, unicode {code:unicode_code} (plus|+) {offset:arithmetic_expression} (Spanish (más|mas|+)), priority mostSpecific: compiles to core.unicode(0x1F0A0 + n).

  • It takes a sum but stops before a comparison: unicode 1F0A0 + x * 2 is y is core.unicode(0x1F0A0 + x * 2) == y (a new line in spell-app's grammar probes).
  • Left alone: unicode code + 1 with a VARIABLE still reads as the character joined to 1, as before; write unicode (code + 1).
