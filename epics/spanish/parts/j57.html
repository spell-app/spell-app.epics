How the declaring line says a name holds a grammar word, per kind:

  • Types: the name runs up to is / aka (a card in play is a thing), or in quotes. The longest reading, since the fixed word after it is certain.
  • Properties: in quotes only (its "side of play" is a number). member_words also reads, so it can't run up to as safely.
  • Variables: with dashes (set way-to-go to 3). Which to starts the value is a guess.
  • Then every later mention reads it with spaces, whole, longest first. Only a declared name: nothing else changes.
