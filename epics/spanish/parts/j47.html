Only what a person running the program sees goes through core.message(): a test's lines (expect passed / failed, truthy, the ▶️ step line, Python's 'Error in test'), the drawing stand-in on the page (⚠ X can't draw), and confirm's printed default with no Spell UI. Everything else stays English as developer-facing: assertions, thrown errors, checkProp()'s type / one-of / rule warnings (they name compiled property names), 'draw() failed' on the console, carry-over's 'starts afresh', the CLI's own ✓/✗ summary lines. notify / alert / confirm button words come from Spell UI's own vocabularies, not the core.
