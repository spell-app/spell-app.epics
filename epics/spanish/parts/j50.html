Spanish JSX can draw <es-boton tamano="grande" color="rojo">. It compiles to h("es-boton", { tamano: "grande", color: "rojo" }), with the tag, attributes and values left as written.

  • Why: <ui-root lang="es"> already defines every component as es-* too, so the page understands these tags once Spanish is on.
  • So spell-lang needs no copy of Spell UI's dictionary (it can't import spell-ui), and nothing has to be handed in at run time.
  • Spell's own JSX words were already Spanish: <hijos/> and en=.
  • Rejected: mapping es-* to ui-* when the program compiles.
    • it needs a generated copy of the whole Spanish dictionary (tags, attributes, values) kept in step with spell-ui, or the dictionary passed in by spell-app
    • the runtime already does this job
  • Tested in the Spanish JSX rules, under the title 'Spell UI in Spanish'.
