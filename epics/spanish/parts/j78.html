New rule hex_literal, hex {digits:hex_digits}: hex 1F0A0 is 0x1F0A0 in javascript, TypeScript and Python.

  • The digits are kept as written: hex ff is 0xff, not 0xFF.
  • Spanish takes both hex 1F0A0 and hexadecimal 1F0A0; English only hex.
  • 1F0A0 as hex is NOT done: the tokenizer reads 1F0A0 as 1 then a word, and as already converts types. The class docstring says so.
  • How: a new tree node, ASTHexLiteral (a number with its digits), written once for every target by ProgramWriter. The digit reading moved into a base rule, hex_digits, which unicode_code now extends (same behaviour, capped at 10FFFF).
