<es-tarjeta discontinuo={la carta}> compiles to prop:discontinuo. The writers treat any tag with a dash this way (attributeName()), and English output can't change. But a Spell UI element's JavaScript properties stay English, so the element gets an unused discontinuo property instead of dashed.

  • Text written as is (tamano="grande") and attributes named the same in both languages (color, value) are fine.
  • A fix in Spell UI: a localized element also takes its Spanish property names. Or the writers could keep a translated name as an attribute, but only if they knew which names are translated.
