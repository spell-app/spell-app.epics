A drawable type's tag is still the project's name followed by the class's name. For example, Carta in project cartas gets <cartas-carta>.

  • English's scheme already leaves the word 'drawable' out of the project's name. Now Spanish's dibujable(s) is left out too: Solitario Dibujable + PilaDeDescarte gives solitario-pila-de-descarte.
  • Accents are dropped, the way Spell UI's Spanish tags drop them: Canción gives canciones-cancion, where it used to give canci-n.
  • Where: elementTagFor() in the kit (spell-kit/util/spell/drawable). Keeping the word list there means the compiled program, the TypeScript writer and the app all name tags the same way. A program names its tags as it runs, and it never loads a language pack.
  • Rejected: removing dibujable at compile time using the pack's typeWords. English's own drawable: "drawable" entry would also remove 'drawable' at compile time, which changes English output. Avoiding that needs a special case.
  • English output is unchanged.
