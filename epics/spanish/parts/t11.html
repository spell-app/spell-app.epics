From the kit's root, with the page server running:

spell translate @spell/test/todos-form-based --to es --review --out /tmp/todos-es
  1. The run page opens in VS Code's side bar, Review tab. Watch the status card: the names pass runs, with a bar and its calls.
  2. Once the rows show: accept one row, pick an alternative on one, tick "for every project" on one.
  3. Type over the completed row with the word the todos app row proposes (say agenda). Without pressing Send, its row should turn to say why it can't be read. Then type terminada instead.
  4. Switch the effort picker to best.
  5. Press Send.
  • Each good answer shows ✓ taken beside its box within a second or two, before Send.
  • The bad one's row says not readable: ... one word, one thing at once, and goes back to normal (and taken) once fixed.
  • After Send the card shows lines, then fix-ups at best; the run ends The command finished.
  • /tmp/todos-es's names dictionary has your answers marked reviewed, the lines use them, the ticked name is in the shared glossary as reviewed.
  • Run it again with --review-timeout 30s and answer one row without Send: the run ends as its wait ran out, and that answer is used anyway.
