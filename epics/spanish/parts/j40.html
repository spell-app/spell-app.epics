The page-wide call is UI.vocabulary.defineComponents({ prefix: "es", dictionary: es }).

  • it defines every component the dictionary names a tag for: the ones defined already at once, and each one defined later as its family loads
  • the texts are a second call, UI.i18n.registerDictionary(es), since Vocabulary is the names only
  • A page picks its language with <ui-root lang="es">, or the document's lang.
    • the root loads the Spanish chunk once, and calls both
    • it sets UI.i18n.locale to the lang
    • then loads es-* tags' families on demand (RootLoader.useLanguage())
  • The prefix is the language code (es); English pages load nothing.
  • How the runtime reaches each class, the one kit change besides the types:
    • the kit's UIComponent.register() now hands registerVocabulary() a third argument
    • a definer, E.ComponentDefiner: (tag, dictionary) => UIComponent.define.call(Class, tag, dictionary)
