Names are ASCII; values keep their accents.

  • tags, attribute, event, slot and part names: tamano / sin-anios / es-boton
  • values: tamano="pequeño", "móvil" / "página"
  • canonicalize() also finds them typed without (pequeno), so the old smoke page's spellings still work
  • ñ in a name became:
    • n where it reads fine: tamano
    • ni where n would read as another word: sin-anios, for disable-year
  • Tabs are es-solapa / es-solapas, not pestanas (eyelashes) -- a native speaker may prefer another word.
