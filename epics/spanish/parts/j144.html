The record, <Project>.es.translated.json5, holds a hash of each English line as last translated.

  • Lined up by their longest common run, so a line added above moves the rest down.
  • An unchanged line is read back from the Spanish file, which has one line per English line: a person's edit there stays.
  • A line whose context changed (a name renamed elsewhere) isn't re-translated: a full run (no --update) redoes all.
