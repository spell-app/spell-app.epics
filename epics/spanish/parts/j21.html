Chose es mayor o igual que (and a, and es mayor que o igual a) for at-least / at-most, over only the literal o igual a, because native speakers say both.

redondear X hacia arriba / hacia abajo (also para arriba / abajo); English's off has no Spanish word: bare redondear X rounds to the nearest.

Biggest / smallest: el mayor / el más grande, el menor / el más pequeño, the counted noun after (el mayor número en prices), not el número más grande.
