spell lang translate is spell-lang's command; spell-app's translateCommand only finds and parses the project (and --seed's), as every project command does through the hook.

  • The rest is spell-lang's src/cli/translateProject.ts: the dictionary, claude -p, the files.
  • The translating is spell-lang/spell/translate/: Translator, TranslationNames, NamesSeeder, on parsed files, no node.
  • Output goes beside the project by default, named as the dictionary names it (Solitario); the project description stays English unless the texts dictionary has it.
