Each tag's UI<Name>.es.ts holds:

  • its Spanish tag: name: "boton"
  • the attribute / event / slot / part names only it uses
  • its aka, and its texts

A name two or more tags use is written once, in Spanish UI's shared components.es.ts, with the shared value sets and the shared texts.

  • size is tamano
  • ui-change is es-cambio
  • it gathers the 104 tag files into one Dictionary, es
  • Why: one word per English name across all families, and a fix in one place (WWOD's DRY rule).
  • The other way: every tag file lists all its names (complete per tag, but tamano written ~60 times).
