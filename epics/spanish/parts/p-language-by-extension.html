A project named its language once, so it couldn't mix English and Spanish files, and a file didn't say what it was written in.

Made a file's name its language, Carta.es.spell, and removed the project's language setting; one project may mix them.

  • Carta.es.spell is Spanish; Card.spell and Card.en.spell are English.
  • Each file parses with its own language's parser, sharing the project's types: a Spanish file calls an English method by its English words.
  • A words file per language present; the program speaks the language of the file declaring its app, else its first file's.
  • The editor, language server, accent fixes and parser messages follow each file's language; the Written in setting is gone.
