The goal says the owner is written as a membership with the owner's role in the folder's __members/, when it has one. The people library's roles are guest, member, admin, spell-admin: no owner role. So the space's person gets __members/owen@spell.json5 with "role": "admin", written the first time the folder opens, only if the folder already has a __members/ and no membership for them. An org's folder has no one person, so nothing's written there.

  • Who may change anyone's rows: the space's person; else an admin (or spell-admin) in __members/; with no __members/, an admin of the space's org (PeopleStore.rolesOf()). Everyone else changes only their own rows.
