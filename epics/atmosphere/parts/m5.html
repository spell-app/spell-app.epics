1. In a Terminal at the kit (~/www/spell), with the page server running (spell server start), open a program whose data folder is a space's own, e.g. one with family cookbook is a data folder at "owen@spell/recipes", and add a recipe. 2. Find its id: the file name in ~/www/spell.spaces/@spell/owen@/recipes/recipes/. 3. Run: ``` spell app takedown hide owen@spell/recipes --record recipes/ --reason "testing a takedown" ``` 4. Reload the program's page. 5. Run: ``` spell app takedown restore owen@spell/recipes --record recipes/ --reason "test over" ``` 6. Reload again.

After step 4 the recipe is gone from the page, and its file is still on the disk. After step 6 it's back. The command printed each log entry, and the sign-in bar (signed out) says "To report abuse on Spell: abuse@spell.spaces".
