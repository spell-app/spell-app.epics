An org can't talk in Spell: RS's events are run in Discord.

  • Every team, project and event has an open thread in its shared space, and an organizers' thread in its private one.
  • The Board and Admins can start ad-hoc threads in the org's shared space.
  • A message shows on everyone's open page at once.
  • Everyone deletes their own messages; managers delete anyone's.

Chat is one more app in a space: a thread is a page, each message a record, live on the rooms Spell already has.

  1. Built on the rooms: a thread is a room's page; messages are records in its space, written through the room, which writes the space's own place as the person sending (P14's fix of I8), so the space's checks apply. No separate write path.
  2. Where threads sit: the guide's table, made by default with each team, project and event.
  3. Volume: a test of a busy thread against the one writer's limits; the number written into the guide.
  4. Checked by: headless runs, including a message refused from someone not on the thread's space list.
  5. Left out: voice, reactions, attachments beyond P15's files.
  • Where to see it: the built-in Chat, @spell/examples/OrgChat: a team's open thread, live; a picture in tests/org-chat.png.
  • A thread is a live room of a space's messages (J167): every team, project and event has its open thread in its shared space and its organizers' in its private one, with nothing to set up.
  • Who does what: a message is a post, so everyone deletes their own, a space's Managers anyone's, and nobody changes someone else's words; someone outside the org can't join, and only Managers reach the organizers' thread.
  • Ad-hoc threads (J168): a record in the org's threads, a new kind of thing only a Manager makes, there the Board and the Admins.
  • A room by its Spell address (J169): team chat is a room at "events_team@rs/messages", signed in by a Spell account, opening again as someone signs in or out.
  • Volume: 200 messages from one page, one after another, in about a second (about 5 ms each), now in the Spaces guide's 7.4.
