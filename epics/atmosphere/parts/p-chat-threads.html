An org can't talk in Spell: RS's events are run in Discord.

  • Every team, project and event has a public thread in its public space, and an organizers' thread in its private one.
  • The Board and Admins can start ad-hoc public threads in the org's public space.
  • A message shows on everyone's open page at once.
  • Members delete their own messages; Leads delete anyone's.

  2. Where threads sit: the guide's table, made by default with each team, project and event.
  3. Volume: a test of a busy thread against the one writer's limits; the number written into the guide.
  4. Checked by: headless runs.
