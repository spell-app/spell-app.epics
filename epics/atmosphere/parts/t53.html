The built-in Chat example (@spell/examples/OrgChat) opens ONE thread, the one its program names. Every other thread exists, but a person can't get to it from that page.

  • Today: the page opens on one thread, the Events Team's open one at events_team@rs/messages. To see another thread, you'd change the address in the program.
  • Threads that exist with nothing to set up: each team, project and event has an open thread in its shared space and an organizers' thread in its private one. Then there are the ad-hoc threads the Board and the Admins start in the org's shared space.
  • T53 adds: a list down the side of the Chat page of every thread this person can read, e.g.
    • Events Team
    • Events Team, organizers (only if you manage it)
    • Harvest Picnic
    • Board announcements (ad hoc)
    Picking one shows its messages, live.
  • Where the list comes from: the same look-up the feed uses to find every space a person can read (P33), plus the org's threads records.
