1. Start the page server (spell server start) and open a program with the line family cookbook is a data folder at "@family/cookbook".
  2. Sign in on its bar as a member of @family.
  3. Open the browser's developer tools, Network tab, and reload.

The recipes show, and the list comes from /api/reads/spaces/@family/cookbook/recipes.list.json; the Application tab shows a spell-space-read cookie, HttpOnly, for that path only.
