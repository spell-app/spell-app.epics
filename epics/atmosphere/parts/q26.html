Bluesky Sign-In (P19) has Spell's server, not the page, do the sign-in, so the server can trust who's signing in. That takes the server version of AT Protocol's sign-in library, @atproto/oauth-client-node, a new dependency.

  • The page's version, @atproto/oauth-client-browser, is already in (it writes to a person's own account).
  • WWOD asks before adding a runtime dependency.
  • The same makers as the page's library, the same version line.
  • P19 goes as planned: the server finds the account by its permanent id and starts a session.
  • The page signs in, then hands the server a token it checks.
  • Cost: the server has to check a token the page got, which is weaker and more code of our own.
  • @atproto/oauth-client-node added at the kit's root; P19 built on it
