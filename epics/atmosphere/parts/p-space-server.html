There is no server that holds a group's space, or knows who in a group may write.

  • Spell's own server, shaped like an AT Protocol Space: a group's own id owns its space, its rows sit under it, and a member list says who may read and write; that id is Spell's own org id, @family.
  • Every write goes through Spell's server, which writes the record as the group's own account, with a "written by" field naming the person. So a recipe Ana and Bo both edit is one record.
  • The member list is made from the membership records and roles in the people library, under __members, and handed to the kit's server by the app: a project data folder's own __members when it has one (optional), else its org's members; each role gives a read and a write flag.
  • Joining, leaving and admins follow the shape of AT Protocol's lists (T6): a membership added, removed, or given the admin role.
  • A refused write says why, and reaches the page, as "only the owner" already does.
