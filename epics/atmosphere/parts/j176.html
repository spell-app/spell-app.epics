Picked over taking the site over. Taking it over would have left the page server thinking it had a site, and Ctrl-C would have taken the site away until its next restart. It prints where to watch (tail the site.log) and how to run it in the terminal instead (stop the page server first). The other way round too: a page server starting while a terminal runs the site leaves it alone, and its row in spell server start all says so; a record whose process has gone counts for nothing.
