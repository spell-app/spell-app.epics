Moving a collection from one place to another is PlaceCopy's, not RoomCopy's.

  • RoomCopy holds one room's rows in memory and works out each change in the room's order: it never reads one place and writes another.
  • PlaceCopy (util's places) lists every thing of a collection in one place, whole, and applies them into another in one apply():
    • inserts for new ids
    • updates for ids already there
    • nothing removed
  • The owner field is left out, and an atmosphere id's did/ part dropped, so the place it goes into says who owns it.
  • It has no word in the language and no button yet: the recipe box's move is done by code (the headless test). See the T item.
