Owen, on J17: ATSpaces has a publicRead / publicWrite, no? That would be the default for spell?

  • Yes: a Spaces member space has two settings, publicRead (anyone may read, not only members) and publicWrite (anyone's writes count, not only members'). Both default to off in the proposal.
  • Under publicWrite, each person still writes only their own records: nobody can change another's.
  • So P1's old behaviour, where anyone could add rows of their own to a person's folder, is publicWrite on, each row editable only by whoever wrote it (by).
  • P4 has no such setting yet: today it is always members only (J17).
publicRead publicWrite Fits
Family cookbook off off the default
A club's events page on off anyone reads, members post
A sign-up sheet on on anyone adds their own row, edits only it

A space gets both settings, off unless its owner turns them on, as in Spaces; the next phase that touches spaces builds them.
