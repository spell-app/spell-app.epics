1. On the machine that will run it (Q8 B), in Terminal, in its kit checkout after yarn install and yarn build:element in app/, try it on this machine alone: 
spell app cloud serve
2. Pick how it gets a secure address from outside, and point it at http://127.0.0.1:4949: e.g. Cloudflare Tunnel (a free account, a domain you own) or Tailscale Funnel. Its address, e.g. https://spell.example.org. 3. Stop it (Ctrl-C), then print its service file, save it where its first line says, and load it: 
spell app cloud service --address https://spell.example.org
launchctl load -w ~/Library/LaunchAgents/spell.cloud.plist
4. Name a second disk for the backups (SPELL_BACKUPS_DIR in the service file, beside the arguments), then: 
spell app cloud status
5. Restart the machine, and run spell app cloud status again.

status says it is up, reached at your https address, and where the backups go; after a restart it is up again by itself; https://spell.example.org/hello answers from your phone on cellular
