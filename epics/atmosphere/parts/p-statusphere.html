No program in Spell has been built against the real AT Protocol network from end to end.

  • Bluesky's example app, Statusphere, written in Spell (T3): sign in, see profiles, post a status, see others' as they arrive.
  • It reads and writes another app's own record shape, xyz.statusphere.status, by reading that app's published schema (its Lexicon) in as a Spell type.
  • The other way too: a Spell type becomes a Lexicon, AT Protocol's schema language, so Spell is an easy way to write and publish one. Spell's declaration stays the only schema anyone writes.
  • The editor warns about a type marked for publishing that can't make the round trip, such as a decimal or a renamed field.
  • Whatever Spell can't say yet becomes a todo, or a question for another epic.

Lexicon generation added, at Owen's ask (2026-11-04): Lexicon written beside each type's JSON Schema, Statusphere's read in as a Spell type, the editor's round-trip warning, and publishing schemas from one account with a DNS record per name. Decimals are stored as strings. The real publish waits for an account and DNS records, as P2's write does.

  1. Lexicon out. spell compile writes a Lexicon for each type a library exports, beside the JSON Schema it already writes, made the same way: from the compiled class itself.
    • A recipe in Owen's recipes folder is named spaces.spell.owen.recipes.recipe: the folder's address, as a reversed domain under spell.spaces, then the type.
    • A name part Lexicon can't spell (an underscore, as in events_team) becomes a hyphen.
    • Never committed, never written by hand, like the JSON Schema.
  2. Where the two don't match, and what Spell does:
    • Decimals: Lexicon has no decimal numbers. A decimal is stored as a string, "12.50", its description saying it's a decimal, and Spell reads it back as one. Recommended over a scaled whole number (1250 meaning 12.50): exact, readable in any record viewer, and no scale to remember. Lexicon's string formats are a fixed list with no decimal in it, so the description carries it.
    • Renames and type changes: not allowed once a schema is published. A renamed field needs a new schema name, or a mapping Spell keeps on its own side from the old field name to the new one.
    • Labels and translations: Lexicon has descriptions only, so a field's label becomes its description, in the program's own language, and its translations stay Spell's.
  3. The editor's warning. On a type marked for publishing, and only those, the language server warns about what can't make the round trip: a decimal field, a renamed field. Its texts in English and Spanish. How a type is marked (a word on its declaration) is settled while building, and recorded as a judgement call.
  4. Lexicon in. Another app's record shape is read from its published Lexicon: Statusphere's xyz.statusphere.status becomes a Spell type, and the example uses it as it would its own.
  5. Statusphere in Spell. Read Bluesky's Statusphere example, and write the same app as a Spell example project: sign in, profiles, a list of statuses, post one.
    • Its statuses are an atmosphere account place with that record shape; new ones arrive through the account place's live stream.
  6. Publishing a schema. A command publishes a type's Lexicon as a schema record in ONE AT Protocol account, the one that holds every Spell schema; a DNS record for each name's domain part points it at that account (its DID).
    • That account's DID is the only one Spell needs: orgs still have none (Q10 stands).
    • The command against the fake server is Claude's; the account and the DNS records need you, so the real publish is a manual test that waits for them, as P2's does.
    • The commands page kept true.
  7. Whatever Spell can't say yet becomes a todo here, or a request to the epic that owns it.
  8. Checked by: a round trip of every kind of field through the writer and reader; the warnings; the example compiles and runs headless against the fake server; manual tests against the real one, and for the real publish.
  9. Left out: their server tool (Tap), since Spell's live stream does its job; what a translated (Spanish) program's field names are in a record, which stays an open point in the guide; making the DNS records by themselves.
