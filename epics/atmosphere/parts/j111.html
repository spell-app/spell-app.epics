The plan said no new server code. But the rules for who may name whom live in OrgRoles, on the server; a program writing the roster file straight would skip them, and a Team Manager, who doesn't manage the Admin space, couldn't add a project at all.

Built: OrgRolesPlace, the org's roles as a place, at the address a program names, @rs/__admin/roles, on the same one route every data folder uses. Each row a program adds or removes is one change through OrgRoles, so its rules hold, and it's logged.

The page is a plain Spell program, as planned; under it, one place of ~300 lines instead of none.
