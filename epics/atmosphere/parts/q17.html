Can we run Bluesky's reference host here?

You asked: Can we run Bluesky's reference host here?

Yes, on your machine, today: as a test host, not yet for real people

  • Bluesky ships a Spaces-ready version of its host, a Docker image (pds-spaces-alpha), "compatible with the reference PDS distribution", needing no new settings.
  • It says, in capitals: alpha software, do not use it in production. Breaking changes, database changes with no migration, no recovery path. Spaces is meant to launch "later this year".
  • So the hosted alpha we tested on (spaces-alpha) gets deleted at the end of the alpha; our own copy wouldn't, but would break on updates just the same.
  • The code is open: Bluesky's own (the atproto repo's Spaces branches, updated yesterday), and community hosts that run Spaces too (Cocoon, in Go; rsky, in Rust; ZDS, in Zig).

What it needs from a machine

  • Small: 1 CPU, 1 GB of memory. Bluesky's installer is for Ubuntu or Debian; on a Mac it runs in Docker.
  • Reachable from the internet on the web ports (80 and 443). At home that means a tunnel (Cloudflare Tunnel): people run hosts this way, on a Raspberry Pi say.
  • A domain, and a wildcard name under it (*.spell.spaces), for each person's handle. Through a Cloudflare tunnel, the wildcard's certificate is a paid Cloudflare add-on.
  • Mail, for verifying people's addresses: the same sending service as Q12 (Bluesky's own guide shows Resend's settings).
  • Not proven by anyone: that the network's relay keeps its live feed open through a home tunnel for days. We'd test it.

What it means for Q14 (Spell's own server answers a member's calls)

  • A member's own host must run Spaces (our trial, T35: bsky.social says "not supported"). Our own host running Spaces would answer those calls for every account on it: much of what Q14 B builds by hand.
  • But only once it's past alpha. Until then Q14 B is the part that's ours and stable; the host is a test bed beside it.

  • Keep asking eny.space (A) for the real host, at Spaces' launch, and keep Q14 B as planned.
