A data folder's address that's a name alone is the program's own folder now, as the plan says.

  • Before P1, family cookbook is a data folder at "recipes" read a folder on static hosting at that relative address.
  • Now a name alone (no slash, dot or colon) is <project>/__data/recipes.
  • Anything else stays a web folder:
    • "recipes/"
    • "https://..."
    • "/api/places/x"
  • A project with no address (a test's inline one) keeps a name as written.
  • A built-in example's shared folder is in the app's committed spaces/@spell/examples/<Project>/__data/, so running it would write there, inside git.
    • The example's own line still keeps its recipes on this device, so nothing does yet.
  • Nothing in the repo used a bare name at runtime (grep: two word tests only).
