Waits for the schema account and its DNS records (Q10 stands: one DID only). 1. Make (or pick) the account that will hold every Spell schema; in Bluesky: Settings, Privacy and security, App passwords, Add; copy it. 2. Mark a type in a library: in app/spaces/@spell/library/people/People.spell, under a note's type, add the line - it is published; then: 
cd /Users/owen/www/spell.worktrees/atmosphere
node bin/spell.mjs compile @spell/library/people
node bin/spell.mjs app lexicon publish @spell/library/people --dry-run
ATMOSPHERE_APP_PASSWORD=xxxx-xxxx-xxxx-xxxx node bin/spell.mjs app lexicon publish @spell/library/people --as yourschemas.bsky.social
3. At your DNS host, add the TXT record it prints (name _lexicon.people.library.spell.spell.spaces, value did=...). 4. Open https://pdsls.dev, paste the account, open com.atproto.lexicon.schema. 5. Take the line out of People.spell again.

The dry run prints the Lexicon, named spaces.spell.spell.library.people.note. The real run prints published at://did:.../com.atproto.lexicon.schema/spaces.spell.spell.library.people.note (new), and the DNS record. pdsls.dev shows the record, the Lexicon whole. Running it again says (updated). Once DNS has spread, dig TXT _lexicon.people.library.spell.spell.spaces prints did=...
