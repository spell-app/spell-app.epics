Spell's server for people outside is SpellCloud, started by spell app cloud serve on port 4949 (the preview has 4848), with status, invite, mail and service.

  • The page server takes anyone not signed in to be you, hands every page a write token, and serves your tools: none of that may face the internet.
  • The cloud serves only sign-in, the project data folders, /terms, and the built-in programs' pages at /apps/...; never the mail catcher's page, nor anyone's own projects.
  • It listens on this machine alone; a tunnel or proxy gives it its https address (M7). An https address marks every cookie Secure.

Names per the commands guide: the noun cloud under app, as backup and takedown are.
