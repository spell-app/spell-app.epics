For the Space Server phase (P4): a group's space is owned by the group's own id (Q1).

Which kind of id it is settles how the space moves to real Spaces later, and how T5 (handing over keys) is ever built.

  • A: Spell's own org id, @family, the way a person is owen@spell: no keys to hold now; a real AT Protocol id is made for it when it moves to Spaces.
  • B: an AT Protocol id (a DID), as the atmosphere account place already uses: ready for Spaces, but Spell holds its keys from the first day, and T5's handover is owed at once.
  • P4's records say @family; the Spaces trial (P11) makes a DID for a test org.
  • T5 stays a limit until real Spaces.
