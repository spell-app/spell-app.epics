  1. Backups: a nightly copy of every space's folder, a few kept, and a command to bring one back; on the machine you run, so the copies go to a second disk or folder you name, and a missed night is reported.
  2. Export: the space's files are already plain JSON (JsonChunks), so export is a download of the folder; changing one line to is a data folder at "./my-export" runs the program on it.
  3. Leaving with the id: the export says in plain words that an org's id is Spell's own, with no keys yet, and that the keys of the AT Protocol id it gets on moving to Spaces will be handed over; that promise goes in the server's terms page (T5, a limit until real Spaces).
  4. Delete: a space or an account deleted, and gone from backups as they age out.
  5. Limits: a space's size and a row's (about 1 MB, as AT Protocol's records); a save over is refused with the existing "over the ceiling", and the page keeps the change, saying why.
