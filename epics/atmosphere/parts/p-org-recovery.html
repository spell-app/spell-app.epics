If an org's last Admin leaves, or turns against it, nobody can step in.

  • The Board can always name new Admins, even when no Admin is left.
  • An org's recovery, held by more than one person, so whoever leaves holding it doesn't take the org with them.
  • Nothing here gives an org an AT Protocol id: if that's needed, it's Q15's answer, not this phase's choice.

An org's identity can be taken back by its Board, as the guide's "Who watches the Admins" says, on Spell's own server (Q15 A), while orgs stay Spell's own @ ids (Q10 A).

  1. Chosen: Q15 A, recovery on Spell's own server; a DID's keys come later, if orgs ever get AT Protocol ids.
  2. The Board's standing right: the Board is Manager of the Admin space whatever happens, so it can always name Admins.
  3. Recovery codes: when an org is set up, Spell makes a recovery code in parts (2 of 3, say), one for each of three Board members, shown once, kept by nobody else. Two parts together let the Board take the org back, even from a Board gone wrong.
  4. The command: spell space org recover, a verb of the one org command (beside host, setup and audit), added to the commands page in the same change.
  5. What's recorded: each recovery, in the Admin space's log (P20), in the takedown log's shape: who, why, when.
  6. Later, when an org moves to Spaces: its new AT Protocol id's rotation keys go to the same people (a todo, beside T5).
  7. Needs you: nothing.
  8. Checked by: unit tests.
  9. Left out: an AT Protocol id for any org (Q10 A).
