The hand test for Claude Tab Shortcuts: select all, copy and undo work in a Claude Code tab again, with the spell extension installed and its side-bar views open, and still work in the side-bar docs.

  1. Run spell app vscode from the branch with the fix (up to date with main), and reload the window.
  2. Open the side bar's Spell Docs and Review views, each showing a page; click into one of them once.
  3. Click into a Claude Code tab's prompt box and type a few words.
  4. Press Cmd + A: all the words in the prompt box are selected.
  5. Press Cmd + C, then click into a text editor and press Cmd + V: the words are pasted there.
  6. Back in the prompt box, type one more word and press Cmd + Z: that typing is undone.
  7. In the Review view, click into a comment box, type, then Cmd + A, Cmd + C and Cmd + Z there: each works in the box.

Each step as written: the keys act where the focus is, never in a view you aren't typing in.
