A saga page keeps its marks and comments in its own review inbox, sagas/<id>/<id>.inbox.json, the same shape as an epic one. The session that takes them runs /epic review SAGA:/<id>, as P15 says. Nobody listening: Send wakes one the P16 way, a new session in a main window with that command typed in (no session is titled for a saga).

  • Not the tooling home epic-workflow: that would mix every saga page notes into one epic.
  • Not GuideInbox and the docs-page Send: it has no section note boxes or items.
  • The short address SAGA:/<id> names the page to the tool and the skill, since a saga id may be an epic name too (output-targets). The epic skill, 7.5, says how.
  • /epic review SAGA:/epics reviews the Epic Tooling saga page; its Send reaches that session.
