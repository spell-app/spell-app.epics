liveAction() calls a changed .js the page's code when it's in the folder (or below) of a script the page loaded: a rebuilt bundle's lazy chunks get new names, so exact names can't be matched. So editing any .js in packages/epics/tools/_assets/ (the runtime's source, goals-live.js) reloads every page that loads spell-ui.js, even before the bundle is rebuilt. A harmless extra reload, kept as the 2026-10-10 source had it.

  • An edit in _assets/ reloads open docs pages once (after 500ms of quiet, never while typing).
