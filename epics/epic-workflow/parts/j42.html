For Goals Foundation (P15): how the Guides page knows which goal a guide serves, so it can list the guides in a section per goal.

  • Each guide names its goal in its own page, one meta line beside its description: <meta name="goal" content="pythonic-spell">.
    • It moves with the page, as an epic page's goal does.
    • One goal per guide: the one it serves most.
    • A guide with none, or naming a goal that isn't there, goes in Misc; the index command says which.
  • The proposed mapping goes on the goals review page: a row per guide, its goal picked, so Owen moves any before it's written.
  • The goal rename command follows the guides' goal lines too.
  • Not a map kept in one file: a guide moved or renamed would drop out of it, and two checkouts editing it would clash.
  • Guides gain a goal line; the docs index command writes the Guides page by goal, Misc last.
