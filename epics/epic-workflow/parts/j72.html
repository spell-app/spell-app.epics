For App UI Docs (P11): the set's layout loads /element/spell.pack.js, as Epic UI's loads the epics pack, so the live examples draw.

  • Every page's first load fetches the app's element bundles (about 2.3 MB, from this machine); later pages swap in place.
  • The site bundle's pack support (SitePacks) also hands packs @solidjs/h and ui-root, as the docs bundle does: the app's bundles take the page's Solid only when all their shared modules are there, else they'd load a second Solid.
  • The live examples need yarn build:element in spell-app/app, as the guides embedding a spell-app already do.
