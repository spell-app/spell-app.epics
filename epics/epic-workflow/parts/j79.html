For Epic UI Docs (P10): building on Spell UI's site turned up three things, each fixed here with its test or measurement.

  • The site's own entry modules weren't in spell-ui/package.json's sideEffects, so the build dropped what they do: Spell UI's pages had silently lost snapshot.ts's example snapshot. Now site.ts, snapshot.ts and SitePacks.ts are listed; Spell UI's eager size didn't move.
  • A root that met a pack's tag while the pack was still defining (an async define()) called it failed. It now waits (ComponentPacks.whileDefining()).
  • <ui-docs-nav> takes a site's own start and Guides links and band titles from its data (SiteDataFile.nav), and starring an element on one site no longer drops the favourites of another (they share the key).
