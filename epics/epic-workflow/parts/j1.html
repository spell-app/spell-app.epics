Chose a folder per request, epics/<epic>/requests/r3/, over one line in a shared inbox file, because screenshots need a place beside the words and the folder is shared content (every checkout sees it, the hook commits it).

  • request.md: a short header (id, epic, from, at, status, filed, images), then Owen's words verbatim, then Context (what the sender was looking at).
  • Ids count up per epic: r1, r2 ...
  • Screenshots: only images Owen pasted into his own prompts, the newest N (--images N); a tool's Read of a picture, or a subagent's, never counts.
  • Verbs: send, requests (list), file <id> "P7 · Name" (mark where it went).
  • A request survives its receiver being closed, and the phase it joins can link its folder.
