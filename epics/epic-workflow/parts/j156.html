json5-writer's own layout piles up quirks save after save (an object hugging its array's bracket, a blank line before every new key, an array's first comment pulled onto its bracket line). DataFile re-prints its output in JSON.stringify(value, null, 2)'s layout, each comment on its own line or at its line's end as it was before the save. A file with no comment is written byte for byte as before. Blank lines a person adds are dropped.

  • inboxes, answers, agents lists stay readable however often they're saved
  • a file nobody commented on diffs exactly as it did
