For App UI Docs (P11): the side column's data, and each page's tables, are built by yarn site:data in spell-app/app, not by Epic UI's builder.

  • Epic UI's (EpicUISite) reads the epics pack's definitions, so it can't read the app's components.
  • The app's builder (AppUIDataBuilder) uses Spell UI's own builder for what has a vocabulary (the two web components, the drawable thing's element), and Spell UI's search builder for search.json.
  • The Solid components have no vocabulary: it reads their source instead (TypeScript 6's parser, already a dev dependency of the app): each exported component with a banner, its props type, and every place the app draws it.
  • So a page's tables follow the code; a test fails while the data is stale.
