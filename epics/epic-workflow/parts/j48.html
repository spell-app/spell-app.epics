How the epic's window gets its new session:

  • The epic's worktree window already open: the page server asks that window's bridge for a new session, the command typed in. NOT epic window launch, which rewrites the window file and could reset a colour Owen picked.
  • Its window closed: epic window launch <epic> --prompt "/epic review <epic>", as /send already does for a request (P4).
  • An epic with no worktree (it runs in the main checkout, or a future epic): a new session in a main-checkout window: the one the page is shown in when the side bar can say, else any open one. Never window launch, which would make a worktree.
  • No window open at all: the notice gives the command to type.
  • No new spell command: the wake reuses the window bridge, as the pill's start does.
