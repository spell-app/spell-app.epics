Chose to merge a standing epic's phase by leaving the worktree (ExitWorktree, keep), running epic merge <epic> in the main checkout, and coming back (EnterWorktree with its path), over a command that moves main from inside the worktree.

  • Why: a worktree session's git is fenced to its own worktree on purpose. A tool reaching into the main checkout would step around that fence.
  • epic merge makes /isolate done's checks: the main checkout on main, nothing uncommitted, and the branch holding all of main. Then it fast-forwards only.
  • The window and the session stay. Only the session's folder hops out and back for a moment.
  • Merge-at-once (Q8) works with no question asked, using only the moves the harness allows.
