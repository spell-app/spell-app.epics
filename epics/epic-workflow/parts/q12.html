  • Example: Owen's comments on the Python target guide (The Python Target) should reach the session working epic python-target.
  • The hard case: the targets guide (Targets and Writers) was written by epic output-targets, then rewritten for Python by python-target. Two epics could claim it.
  • Today's fallback: spell dev comments gather files every guide's comments into one catch-all epic, guide-changes, one phase per page, and nobody is told.
  • An epic owns every page its See Also lists as its own: its durable doc, the guides it wrote or rewrote.
  • A page no See Also lists: the plan doc its "Status" or "Plan doc" line links to (every durable doc has one).
  • Two epics own it: the one still open wins; both open, the one updated last. So the targets guide goes to python-target while it runs, since output-targets is done.
  • No epic at all (a Solid guide, say): guide-changes, as today.
  • One place to look, kept by the tool, and the See Also is worth having anyway.
