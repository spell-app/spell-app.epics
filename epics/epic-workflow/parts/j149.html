Saga pages are small, so they are not split into parts: the Overview reads from disk too. The Epics section holds <epic-cards saga>, which asks the page server (GET /api/epics/saga) for every epic whose page names the saga, and asks again whenever an epic page changes.

  • Grouped as on the Epics page (Active, Planning, Urgent, Done) by the same state rule; Favorites is not a group there, it is Owen own list on the Epics page.
  • Each card: state mark, linked title (in that epic tab), summary, state and phases; the phase under way by its number by place, never its id (P15 stable ids).
  • A saga list of epics never goes stale; from file:// it says it needs the page server.
