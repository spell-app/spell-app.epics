Chose Spell UI's whole page shape, not only its colours:

  • Spell UI's layout and site script: the top bar, the side column, the theme switch, the contents list
  • a template for a new element page, shaped like Spell UI's page template
  • the side column reads a small data file listing the elements by group, built from the epics pack's own element definitions, so a new element shows up without hand-editing a list
  • where Spell UI's site script assumes it lives under /ui/, it learns to take another set's root

The data file needs a small build step in the epics package, like Spell UI's yarn site:data; its name and home are proposed in the phase before building, as the commands guide asks.

The two component sets read alike, and a reader moves between them without relearning the page.
