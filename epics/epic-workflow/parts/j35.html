For P14: what the goal commands are called. Claude puts them under the epic command that Split spell epic (P8) makes, as a goal noun.

  • epic goal new <goal-id> "Title": a goal and its page
  • epic goal set <epic-id> <goal-id>: an epic's goal ("" clears it)
  • epic goal rename <old-id> <new-id>: the ONE way an id changes, and every reference follows:
    • the goal's folder and page
    • each epic page's goal
    • every <epic-link goal> and GOAL:/ link in the shared pages
  • epic goal list [--json]: each goal, its epics, its page
  • An id is checked on the way in: lower case, hyphenated, one or two words (pythonic-spell).
  • If P7's review page names the nouns differently, these follow it. Before P7 merges, the same verbs run as spell dev plan-doc goal ....
  • four verbs under epic goal, on the commands page
  • a goal id changes only through rename
