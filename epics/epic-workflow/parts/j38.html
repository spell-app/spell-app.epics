The new command takes back the name migrate, which today only says "gone, use convert". The converter stays its own command: it is a different job.

  • convert: a page still in the OLD markup (from before the <epic-*> elements) into the new one. It writes copies only, with a proof that nothing was lost. Every live page was converted on 2026-10-08.
  • migrate: a page already in <epic-*> markup, brought up to date, step by step. A page in the old markup is refused, pointing at convert, as every command refuses it.
  • The tool already fixes one thing on every edit: each phase's Plan changes, moved into its phase at P6. That stays, and the same code is registered as a step, so migrate also reaches pages nobody has edited since.
  • The other steps run only on command, never on an ordinary edit: a one-line edit doesn't rewrite a whole page by surprise.
  • The epic skill's cheat sheet still lists the old migrate <name>: that line is replaced.
  • migrate means "bring an epic page up to date"; convert is unchanged.
  • Ordinary edits keep doing only what they do today.
