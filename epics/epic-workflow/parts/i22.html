json5-writer takes a null for an object and throws (Cannot convert undefined or null to object) whenever the value written holds a null and the file already has text: an inbox's listening: null, woken: null. P21 works around it in DataFile (each null written as a placeholder string, put back in the text). json5Edited() itself, which spaces' people and projects and P20's site data use, still throws. Once P20 and P21 are both merged: move the work-around into json5Edited() (withoutNulls() and NULL in DataFile.ts), with its test.
