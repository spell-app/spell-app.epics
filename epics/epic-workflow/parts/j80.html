For Epic UI Docs (P10) and App UI Docs (P11): a new page of either set starts from one shared template, beside Spell UI's.

  • templates/component-set-docs.html: Spell UI's page shape (masthead, folded sections, the set's chrome from its _parts/layout.html), an element page's sections (Example, Markup, Attributes), and its header comment says how to fill it and check it.
  • No new command for it yet: copy and fill, as the header says. Each set has its own layout and footer in _parts/; App UI's copy Epic UI's.
  • check-spell.js learnt the sets' pages: it loads them from the page server at their short address (--base to try another server).
