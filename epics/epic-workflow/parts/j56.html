BlockAnchors.js: a new block kind, update (epic-update[at]), which counts even inside another block (an item's details, a phase's field), so it gets its own bullhorn beside its item's. epic-item[id] joins the containers, so such an update's anchor is q3#update-1 (only those updates are affected: nothing else nested in an item is a block). The bullhorn moves left of the update's date (makeRoom(), MAKES_ROOM). A bare label, or an old note not yet migrated (no at), has none. spell-ui.js is rebuilt for the runtime change.
