spell/compiled takes target: "js" | "ts" | "py", short names for js/solid, ts/solid and py (SpellLanguageService.COMPILED_TARGETS). ts is ts/solid, the Solid TypeScript a person writes, not ts/lib (a library's classes alone, which refuses a project that draws). A file that can't be compiled shows // Card.spell couldn't be compiled to ts/solid, and # instead of // for Python.

  • The TypeScript button shows ts/solid. A ts/lib button would be a new command.
