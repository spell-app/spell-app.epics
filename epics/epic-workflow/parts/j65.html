The # addressing is what the help and every caller use. The old order works too, so a half-converted call never fails:

  • epic close seo J3 ~== epic close seo#J3
  • epic add seo judgement "T" ~== epic add seo#J "T"

And spell epic <verb>, the old spelling, now runs the lean epic program, so every epic verb works under it, not only the five it had (send, requests, file, home, merge).

A verb that acts on a whole epic refuses an id with a plain message (summary: takes an epic, not seo#J3), exit 2.
