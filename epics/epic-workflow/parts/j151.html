For P20: people-and-orgs' json5Edited() lived in spaces (spell-app/src/spaces/server/node/storage/json5.ts), but Spell UI's site data writers are in ui, which may import no spell-family package. It's now in the assembler, spell-kit/server/json5 (node-only, imports no package, any node-side tool may import it), opt-in by path so the epic tool doesn't load json5-writer. Spaces imports it from there and re-exports it.

  • json5-writer ships no types: the file loads it with createRequire() and types what it uses, so the root types/json5-writer.d.ts is gone. Why: ui's tsconfig doesn't include the root types/, and oxlint forbids a /// <reference path>.
