<epic-link phase="7"> means the 7th phase on the page, and draws P7 · Name with today's number. phase="epic-migrate" finds the phase whose id is p-epic-migrate, else the one whose title slugifies to that. The slug is lower case with a hyphen for each run of other characters (EpicAddress.slugOf()), which must match the stable phase ids' slug.

  • Works before and after stable phase ids merge.
  • If the stable ids slugify differently, slugOf() follows them.
