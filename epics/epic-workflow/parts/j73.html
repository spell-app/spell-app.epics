For App UI Docs (P11), what gets a page and where:

  • One page per component FILE, named for its main component (SplitPanel.html); the file's other exported components are documented on it (SplitPanel.html#SplitPane), as Spell UI's sub-tags are. chrome.tsx's menus are one page, Chrome.
  • Web components and the drawable thing's element by their tag (spell-app.html, spell-element.html).
  • Pages sit at the folder's root (/app-ui/Notice.html), beside the two web components' code folders: no sub-folder, unlike Epic UI's elements/.
  • Beyond the phase's list: ConsoleLines (what every console draws its lines with). Left out: SpellAppRunner, VSCodeRunner, the spell-editor's pane, LazyMonaco (plumbing or whole runners).
