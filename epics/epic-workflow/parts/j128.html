<epic-link> is a new element: no older page holds anything to convert, so there's no migration step. Guides don't load the epics pack today, so a guide that uses <epic-link> adds the pack's <ui-components> line. Any page can use a plain <a href="SAGA:/..."> instead: the docs runtime rewrites it.
