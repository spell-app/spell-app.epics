How the goals code came out (P6), each the least surprising way I could see:

  • spell dev goals stays as a STUB that says goals is parked and exits 1, rather than vanishing: a skill or habit that still calls it gets told why, and where it went.
  • The zip holds every file at its old path, plus unwire.patch: the exact edits that took goals out (CLI wiring, package.json, the docs configs, the buttons). Putting it back is unzip, copy, git apply -R (its README has the steps).
  • /airplane land no longer looks for goals thoughts: the Thought button only says TODO now, and the reader that found thoughts is in the zip.
  • The goals pages keep goals.css and goals-live.js, so they look as before; every button says "TODO: this will ..." with what it will do.
