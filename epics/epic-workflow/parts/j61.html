The CLI can't send a SendMessage, so migrate --all --notify prints a TELL: block: each running session's name and the exact one-line message. The session that ran it sends them (the epic skill's "Migrations").

  • Running sessions are found as epic send finds its receivers (epicSessions()): the CLI hands that finder to the tool, since epics may not import the CLI. Without it (run outside spell), --notify refuses rather than migrating a running epic.
  • The session running the command counts as idle for its own epic: it migrates its own page.
  • A running epic is told only when its page would change; it gets a dry run, never a write.
