Nothing can hand a request to another epic.A new spell epic send <epic> saves Owen's words and screenshots as a request folder in that epic. It prints the request's id, and the receiving epic's running session, or none.
  • One command saves a request into any epic: spell epic send epic-workflow --text "the comment box covers the text" --images 1.
  • The request is a folder, epics/<epic>/requests/r3/, holding:
    • request.md: Owen's words as he said them, which session sent it, and what it was looking at (page, file, item id)
    • the screenshots he pasted, as .png files, taken from the sending session's transcript
  • It prints the request's id and the receiver's running session (or "none running"), so the sender knows whether to wake it or open its window.
  • The transcript reader /wtf already uses is reused, not copied.
