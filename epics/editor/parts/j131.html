Who gets ⌘Z / ⇧⌘Z in the editor (I167), Run and Edit alike:

  • In the code: the code editor's own undo.
  • In an editor field (Inspector, palette, a dialog), or anywhere else in the editor's own panes: the editor's history, then what was typed in the code (J116).
  • In the running app, or on nothing (the page's body): the program's undo first, a move in the game. With no move to undo, the key goes on to the editor's.

Why: Owen, I167: ⌘Z in Solitaire undid the editor's change though the editor wasn't selected. This replaces P9's rule (the editor asked first in Edit: 'a program's move isn't what people mean to undo there'). The page's hook for that, core.pageUndoKey, is gone.

Edges:

  • A click on a blank part of the Inspector puts the focus on the body, so ⌘Z there now undoes a game move first, if there is one.
  • The Edit menu's Undo is unchanged: the editor's, by where the focus was last.
