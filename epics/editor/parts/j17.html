Each drawn element gets data-spell-at, and each thing a hidden symbol, only in the copy the editor runs.

  • What ships and the compiled pane stay byte for byte the same, and a test checks every fixture.
  • The source map file gains an x_spellPlaces list, which debuggers skip.
  • In the editor, a program can see that attribute on its own elements.
  • A program behaves the same, unless it reads its own data-* attributes.

It's what lets a click on something in the running app find the line that wrote it.

  • What it does: when the editor runs your program, each thing it draws carries a small hidden note: "I came from Card.spellml, line 8".
  • What it makes possible: the tooltip on the properties card today; side-bar edits writing the right line; a click on the screen, in the Views tree or in the code all following along.
  • Where it isn't: only the copy the editor runs has the notes. The output pane and anything you publish stay clean, byte for byte, and a test checks that.
  • The only catch: a program that goes looking at its own elements while in the editor could see the note, as an extra attribute. It won't when published.
