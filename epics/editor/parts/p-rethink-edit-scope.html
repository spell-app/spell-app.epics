In "atmosphere" epic, we've come up with a "versions" scheme, where you edit a "draft" in a private area, then "publish"

Drafts answer a different question from this phase: this phase is about WHERE an edit lands, drafts are about WHEN others see it. So they fit together rather than compete.

  • Edit scope (this phase): which line of the code an edit writes. "This card" writes the card's own line, "All cards" writes the template (J25).
  • Drafts and publish (atmosphere): which version of the whole project it writes into. A page being edited is a draft in the team's private space; Publish checks it, writes it to the public space, deletes the draft, and keeps a copy of each published version.
  • Every edit would be both: "All cards, in my draft".
  • AutoSave: would always be on, into the draft. Nothing reaches anyone else until Publish, so saving stops being risky.
  • Discard Changes: today it goes back to where the project was opened, with no Keep button (J51). With drafts it becomes "drop the draft, back to what's published", a real line in the sand rather than a guess.
  • The public preview: a visitor's edits already live in their browser's database, which is a draft in all but name; "Reset Example" is its Discard.
  • A new button: Publish, in the File menu, once there's somewhere to publish to.

One way, not two: the editor shouldn't grow its own starting-point-and-keep scheme while atmosphere designs drafts. J51's starting point is the piece to replace.
