In the editor (spell server url), open a project of yours in Edit, with File › AutoSave on. Change a word in its code. Then open its folder in Finder: ~/www/spell.spaces/@spell/owen@/<project>/.Its file is unchanged, and __draft/ holds <file>.owen-<today>.spell. File › Publish writes the file, a zip appears in versions/, the draft goes. File › Versions › Restore brings the old text back as a draft. Discard Changes (⌘⇧R) puts back what's published.
