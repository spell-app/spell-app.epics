An event's band shows its first word plain (when, on) and the rest as one white pill (creating solitaire, click), the way the code pane draws when [creating solitaire]. The pill doesn't bold the names inside it (solitaire is bold and underlined in the code): the row has the words only, not the parse. A one-word ability (draggable) is its pill alone. An action's name is a bold pill; an action with blanks is one plain pill, each blank underlined, its kind bold (move a card to a pile), as the code draws them; the old grey badges (ui-label) are gone, in the All Cards type card too.
