Mermaid 12.3's npm module doesn't copy ELK in: it imports elkjs/lib/elk.bundled.js lazily, elkjs 0.12 being an ordinary dependency. The loader imports the same file, so the bundler makes one chunk. <ui-diagram> uses it in T115.
