For P37 · Design Mode: Card alone shows one card, small and face down, because the card it makes starts face down. So you see only its back.

How should it show instead?
  • The card drawn big in the middle of the pane, zoomed to fit.
  • A new card starts face up, so you see its face.
  • Its rank, suit and face still change in the Inspector.
  • Several cards at once: face up and face down, one of each suit, a court card.
  • Each one is editable; a change to the drawing shows on all of them.
  • Cost: each view needs its samples named somewhere, or guessed from its properties.
  • One card at its real size, the one selected in the app, else a new one (Q46 A).
  • the card on its own is drawn large and face up
  • the one selected in the app is still the one shown, when there is one

Note that when I was trying the feature, I was trying to edit the property-editor for a card, but it was showing me the card itself. I'm thinking that this is a mode where I can pick which bit I want to edit (e.g. for a view, it would be each of its draw methods, a property editor, a page if I'm in a site). So I'd be able to pick. I like the idea of a drag and drop the thing/part to edit it, and a "storybook" mode where I can check out the different examples. Also, responsive design might play into this, so I can see the page in desktop/tablet/phone mode.
