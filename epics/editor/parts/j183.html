The standing rule says tooltips are title attributes, never Spell UI's, unless Owen says so. Owen said so for these two bars (I217: "All of these buttons should have pretty tooltips implemented with spell-ui").

  • Scope: the top bar (the mode tabs, the code, compiled code, Inspect app and Add buttons, the Draft / Publish / Discard pill, Restart, the theme button, You) and the Add View bar (the pin, each group, Clear the search). Everywhere else the editor's tooltips stay title.
  • How: barTooltip() in the editor's chrome, Spell UI's data-tooltip bubble; the theme button's is its own <ui-popup>, now small, not mini.
  • The menus (Spell, the project, File ... Help) got none: they open on a click and say what they are.
  • All wait the page's hover pause, 800ms: the theme button's waited 2s before.
