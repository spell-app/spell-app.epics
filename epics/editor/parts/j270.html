P39's plan had yarn mermaid:pretty read the Spell look from the tokens' light and dark values. Those values are OKLCH with relative colours and light-dark(), which plain node can't work out without a browser.

So the colours moved to ONE table, MermaidThemes in the kit's spell/util/diagram (the kit's README tool may not import Spell UI): SpellThemeTokens (which token fills each Mermaid variable, read live by the element) and SpellThemeColors (the same variables as fixed hex, light and dark, for GitHub's READMEs). The README tool reads the second; its output is byte for byte the same. The flowchart node kinds (repo, folder ...) stay the tool's own.
