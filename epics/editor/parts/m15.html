In VS Code's ⎇ editor window, open the editor (spell server url prints it), then Solitaire, in Edit. Turn on Inspect app (the crosshair, top right), and click a face-up card. Hover the small crossed-out save icon after a field's info icon. Then press All Cards, then This. Scroll the Code band to 'to count the points for a card on a pile'.

The switch reads This | All Cards beside the blue card chip. Each field shows the crossed-out save icon, its tip 'You can't save this because it is created automatically.', and a changed value still changes the card. The Code band shows count the points with its code (if pile is a foundation return 10).
