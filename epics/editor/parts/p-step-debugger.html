There is no way to watch a Spell method run: to see why a move went wrong, you can only guess, or print values to the console.

  • Pause inside a Spell method while the app runs, and go through it a line at a time: the debugger you loved in Q39's third answer (Q39, C), as its own phase.
  • Click in the code's left margin to put a breakpoint on a line: a dot shows there. When the running app reaches that line, it stops.
  • While it's stopped, the line it's on is highlighted in the code, and the code scrolls to follow it, into another file too.
  • Four buttons, with keys: Continue, Step Over (the next line), Step In (into a method this line calls) and Step Out (back to the line that called this method).
  • Beside the code, what it's working on, as it is right now:
    • the thing the method belongs to, and its properties: the pile, and its cards
    • the method's inputs: the card being moved
    • the values its lines have set so far
    • the methods that called it, top to bottom: click one to see its line and values
  • The editor itself keeps working while the app is stopped: you can scroll, read other files, and look at things. How the app is stopped without stopping the editor with it is Q41.

  3. The stepper in the runtime (core): it gets each step, compares it with the breakpoints and the step mode (over, in, out), and when it should stop, holds that method until the editor says go on. It keeps the stack: each method running, its thing, its inputs and its values so far.
  4. The runner: runCompiled() runs the debugging build while debugging is on, and swaps between the two builds keeping the game in progress, as a live edit does.
  5. The code editor: breakpoints in the left margin (click to add or remove), the paused line lit, and the code following it into other files, using the source map read back.
  6. The debugger's bar and values: Continue, Step Over, Step In, Step Out with their keys; beside the code, the thing and its properties, the inputs, the values, and the methods that called it, drawn as the Inspector draws a thing.
