The plan put the row height and the hairline on the menu's header look. They went on <ui-panel appearance="pane"> instead, since the hairline has to run under the chevron too, and the chevron is the panel's.

  • So the header look on the menu only sets the row's text and items.
  • A header with nothing to fold, like the file tabs, would be a pane panel without collapsible.
  • Moving the other headers means wrapping each in a pane panel, rather than only changing its toolbar's appearance.
