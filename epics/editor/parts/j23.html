A running program takes ⌘Z for its own moves whenever the focus is in the app or nowhere. So a program now asks the page first (core.pageUndoKey): in Edit, the editor's history takes the key when it has a step, and with none the program's moves still undo. In Run it's the program's alone. With the focus in the code, it's the code editor's.

  • While building in Edit, ⌘Z after a side-bar change undoes that change, not a game move.
