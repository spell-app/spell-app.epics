For P39 · Mermaid Drawings: where does Mermaid's code come from, the first time a page draws a diagram?

Spell UI's other big helpers (the code highlighter, the Markdown engine) are built into Spell UI's own files, as separate pieces loaded on first use. Mermaid could be the same, or come from a public CDN, as Mermaid's own docs show.

  • Works offline, on a plane (airplane mode) and on a page with no internet.
  • The version is fixed by the lockfile and checked by the dependency check before each push.
  • Cost: the published Spell UI package grows by Mermaid's size, though nobody downloads a piece until they draw.
  • No added size to Spell UI's package or install.
  • Cost: no drawing offline; a request to a third party on every page that draws; the version isn't checked with the rest.
  • Offline by default, a lighter page for a site that prefers the CDN.
  • Cost: two ways to load it, and two to test.
  • Mermaid loaded through a lazy engine file, as CodeEngine and MarkdownEngine are, its loader replaceable for a bundle that can't keep lazy imports
  • no request to any other site
