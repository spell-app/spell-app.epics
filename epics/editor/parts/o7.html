You can add a component by dragging it in, and move one by dragging it. Each of those is a source edit, so the code stays real and ⌘Z works.

  • The palette comes from the components' own vocabulary files, which already hold a name, search words and a description. An icon and a starting snippet are missing, and this work adds them.
  • It takes no permanent space: a + in the top bar opens it as a popup, with a search at the top. Click adds beside the selection; drag places it.
  • Dragging uses the existing drag helper, which already carries several elements, and the drop line the running program's lists draw. Both move into Spell UI, so there's one copy.
  • Overlays can sit on a layer above the app, because the app runs in the editor's own page rather than in a frame.
  • Delete and duplicate work on the selection, from the keyboard and a right-click menu.

Moving means placing in the flow. Spell apps lay out by grids and order, and nothing in the examples uses free x / y positions. So a drag shows a drop line between neighbours, and it reorders or re-parents in the source (Q6).

The coherence review found that no vocabulary holds a starting snippet, and that the drag helper doesn't draw the line.
