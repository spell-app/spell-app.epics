The public preview hides everything that makes a project or a file, because it has no server. So today a visitor can only edit the examples, which fails the goal of making an app from nothing.

  • A visitor's edits are already kept in their browser's database, per example.
  • The same place could hold whole projects.
  • New, rename and delete work, with everything kept in that browser.
  • Export and import a project as a file, so work can leave the browser.
  • No accounts and no server cost.
  • The risk: clearing site data loses the work, so the app says so.
  • Visitors remix an example; no new projects.
  • The least work, but the "from nothing" test is then only true on a local install.
  • Work follows you between machines, and it's the road to sharing.
  • A much bigger job, and it would not fit these two weeks.
  • The preview gets the project and file actions it hides today.
  • Accounts and sharing wait for a later epic.
