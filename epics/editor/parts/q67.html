For P41 · Save Back To Disk. A program needs words for two things: a place that is a file on your computer, and opening and saving it. These are NEW Spell words, so nothing is built until you pick.

Today a program can already say a file at an address, which only works with a server side:

family cookbook is a json file at "recipes.json"

Every option keeps that line, and adds a place with no address, filled by a file you pick or drop.

  • family cookbook is a json file on this computer
  • open a file into family cookbook (shows the picker); a drop on an uploader for it does the same
  • save family cookbook back to its file; save family cookbook as a new file for save-as
  • Ambiguity: "this computer" beside the existing "this device" (database on this device, keep a copy on this device): two words for nearly one idea. On a phone it reads oddly.
  • Ambiguity: "its file" is a pronoun; it reads clearly only right after the place's name.
  • Why recommended: it says what you'd say out loud, and "back to its file" is exactly the new thing.
  • family cookbook is a json file you pick
  • pick a file for family cookbook; plain save family cookbook goes back to the picked file
  • Ambiguity: "you" is the person using the app, but in a program it can read as the programmer.
  • Ambiguity: plain save already means "send the pending changes" for every place; here it also means "write the file", which is the same thing, but hides the download fallback.
  • family cookbook is a json file on this device, reusing "this device"
  • No open or save words: the place shows its own "Open a file" line when it has none, and saves as every place does
  • Fewest new words. Ambiguity: "on this device" already means the browser's own copy, not a file you can see in Finder.
  • Cost: an app can't put "Open" in its own menu or button.
  • a new place kind, json file on this computer (and the same for csv and excel files), with no address
  • two new actions, open a file into and save ... back to its file / as a new file, English and Spanish
