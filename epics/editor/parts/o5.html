Editing one thing and editing what all such things are is a single switch in the properties card, and each field shows where its value comes from.

The switch: This card | All cards, in the row that already names the picked thing (Card · ace of spades), so it costs no height.

  • This card: the edit goes on this one's tag.
  • All cards: the edit goes on the template, and every card follows on screen.
  • A thing whose own tag is in the source starts on "This". A thing made in a loop starts on "All". "This" stays editable to play around, with a note that its changes can't be saved.

Each field says where its value is from, with no extra rows:

  • Set here: a dot beside its label, and a Reset.
  • Inherited: quieter, and its tooltip names the type that set it ("from Card").
  • Worked out: read only, as today's "What it is" group is.

What's missing today: the side bar knows whether a value differs from the default, not who set it. The new source places (above) and the type's chain supply that.

A template's own <property-editor>, from the debut epic, still decides how its fields are laid out: this adds to it.
