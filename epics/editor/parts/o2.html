The editor looks good already, but it can only be looked at: nothing done in the side bar reaches the program's code. That is the biggest gap, and most of what's asked for stands on closing it.

Solitaire in Glass, every panel open, on a short laptop window (1280 by 680):

What it costs in height, measured in that browser:

Piece Height
Top bar, with its gaps above and below 74px (46 + 14 + 14)
Gap under the panes 14px
File tabs 49px
Each Inspector card's header 40px
Program panel's header 40px
Code visible at 1280 by 680, Program panel off 543px
Code visible, Program panel on 327px

Width costs as much: with the Inspector open, the code and the app get 422px each at 1280. The game's own toolbar is clipped at that width.

What's missing or thin:

  • Edits in the side bar change the running app only. They don't touch the code, have no undo, and are lost when the program restarts.
  • A drawn element doesn't know where it came from: the Inspector finds its source by a best guess over the text.
  • One thing can be picked at a time.
  • The Views tree is hand-built: no filter, placeholder icons, and rows that read as raw markup (<ui-item "Moves: 0" />).
  • There is no way to add a component or move one.
  • The public preview hides everything that makes a project or a file, because it has no server (Q2).

What's already there to build on:

  • Exact character positions for everything in a .spellml file, and a notebook that already rewrites one span and keeps the rest byte for byte.
  • A drag helper that carries several elements, from Solitaire's own drags, and a drop line that the running program's lists draw.
  • A click, command-click and shift-click selection rule, in the running program's lists.
  • Source maps from output to code, used only by the debugger so far.
  • Each component's description in its vocabulary file: its name, topics and words people might search for.

The coherence review found two claims here untrue: no vocabulary holds a starting snippet, and the drag helper carries while the running program's list element draws the line.
