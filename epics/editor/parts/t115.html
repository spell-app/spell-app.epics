What it is: <ui-diagram> places its boxes today with its own small layout, in spell/util/diagram. This todo lets it use ELK, the layout engine Mermaid uses for flowcharts, for tidier lines and fewer crossings on bigger diagrams.

  • It loads ELK through the ONE loader P37 builds, so a page with both a Mermaid drawing and a <ui-diagram> loads ELK once.
  • Its own layout stays the default for small diagrams, and for pages that never load ELK; which one wins when is part of this todo.
  • The boxes a person dragged (kept under remember) still win over either layout.
  • ELK is about 1.6 MB (470 KB zipped), so it loads only when a diagram asks for it.
