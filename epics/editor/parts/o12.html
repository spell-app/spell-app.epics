The order puts what you can see first, then the foundation everything else needs. Each step merges as it finishes.

  1. The look: the one header row, the top bar, quiet popups, Glass and Fruity. It needs nothing else, and you'd see it at once.
  2. Source places and source edits: starting with the count of what has a home, then every side-bar field writes the code, with undo.
  3. This one or all of them.
  4. The one selection and the tree: many selected, filter, icons, Things and Templates folded in.
  5. Adding and moving: the palette, drag and drop, delete and duplicate.
  6. A preview you can build in: new projects in the browser (Q2), then a first-run path that's fun.
  7. Code mode that follows along.
  8. "Change this" and the first turtle.

If time runs short, the last two are what wait: the preview's test is steps 1 to 6.
