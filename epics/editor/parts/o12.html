The order puts what you can see first, then the foundation everything else needs. Each step merges as it finishes.

  1. The look: steady mouse cursors first, then the one header row, the top bar, quiet popups, Glass and Fruity. It needs nothing else, and you'd see it at once.
  2. The layout in Spell, stage 1: proved on one pane, then the rest. It comes early so later work on the panes isn't done twice.
  3. Source places and source edits: starting with the count of what has a home, then every side-bar field writes the code, with undo.
  4. This one or all of them.
  5. The one selection and the tree: many selected, filter, icons, Things and Templates folded in.
  6. Adding and moving: the palette, drag and drop, delete and duplicate.
  7. A preview you can build in: projects kept in the browser, with export and import, then a first-run path that's fun.
  8. Code mode that follows along.
  9. "Change this", on your own machine.
  10. Things and Templates reimagined.
  11. The backing in Spell, then the full editor: stages 2 and 3, piece by piece.

If time runs short, the last four wait: the preview's test is steps 1 to 7. Stage 1 is the one item in those seven that the preview doesn't strictly need, so it's what to pull if it runs long.
