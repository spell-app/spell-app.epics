A tag or an attribute chosen from the suggestion list is written whole, the caret where you type next. The shapes live in ONE table in the language service, so VS Code gets them too.

  • Spell's own tags
    • <action "|"/>: the caret between the quotes, and the program's actions listed at once
    • <divider/>|, <children/>|
    • <context-menu>, then a line a level in for the caret, then </>
  • Spell UI's tags, by what Spell UI says each one holds
    • holds nothing (no default slot), e.g. <icon | />: the caret where its attributes go, and their list opens
    • holds a few words (button, header, label ...): <button>|</> on one line
    • named by a quoted word (tab, panel, example, tree-node): <tab "|">, a line in, </>
    • anything else holds things: <content>, a line a level in for the caret, </>
    • Spanish names in a Spanish file: <acción "|"/>, <contenido>
  • Attributes (Owen on I55): color="|", its words listed at once; one that takes no value (fluid, disabled) just its name.
  • Nothing doubled: when the tag already goes on after the caret (>, />, its attributes), or = follows an attribute, only the name is written.
  • Closing tags are </>, as the examples write them.
 `<act` + Tab gives `<action "|"/>`, the program's actions listed at once; `<divider/>`, `<children/>`; `<context-menu>` and Spell UI's tags that hold things a line in then `</>`; `<button>|</>` for a tag of a few words; `<tab "|">` for one a quoted word names; `<icon |/>` for one that holds nothing (Spell UI's help table says which: no default slot); `color="|"` with its words listed at once, `fluid` by its name alone (Owen, on I55); nothing doubled when the tag or its `=` is already written after the caret.
