For P41 · Save Back To Disk. You save in the app, but since you opened the file someone else changed it: another program, the app in another tab, or a sync like Dropbox or iCloud.

The browser doesn't stop a save over their change. So before each save the app reads the file's modified time and size again (the spike checks whether those are enough, or whether it must compare the contents), and if they differ from when it last read or wrote, that's a conflict. 

const now = await handle.getFile()
if (now.lastModified !== lastSeen.lastModified || now.size !== lastSeen.size) conflict()
const writer = await handle.createWritable()
await writer.write(text)
await writer.close()
