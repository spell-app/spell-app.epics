The Files button now always shows, so I looked at letting every tab close, always. I kept T77's rule instead:

  • With every file a tab, the row shows them all; closing one would need the toolbar to remember a list of CLOSED files (per project, across reloads) beside the list of open ones it keeps today -- a new mechanism, not a tweak.
  • A project of 1-8 files fits in the bar, so closing buys little room there.

So hovering a tab in a small project shows its file icon, no ✕. Say if you want closing always: it's that closed-files list in UIToolbar.

Also: the ✕ shows on hover only, not on keyboard focus. A tab focused by the keyboard is focused inside its shadow, where the bar's CSS can't tell keyboard from mouse focus (:focus-visible doesn't reach the tab's element); no key closes a tab anyway (⌘W is the browser's).
