The selection follows the cursor by click and arrows, never while typing (I51, I69); a paste counts as typing, and nothing follows once the edit is drawn.

  • The code editor notes an edit typed or pasted in it (while it has the keyboard).
  • Once the running app has taken that edit and drawn it, the editor follows the cursor's line once, as a click there would:
    • a line that draws something selects it;
    • a line that draws nothing leaves the selection as it was (not let go, as a click there would).
  • Still typing (another compile on the way), a range selected, or the run failed: no follow yet; the next drawn run follows instead.
  • Edits from the Inspector or the palette never follow the cursor: they select what they made, as now.
  • Test: in Solitaire, cut <action "cheat"/> and paste it above <action "auto play"/>; once it's redrawn, the Inspector has that action selected.
