For I197, replacing J137 (Add Action only for a thing). Add Action now shows beside Add Event for every part selected.

  • A drawn thing (a card): the action goes in its own type, as before.
  • A Spell UI element (a toolbar, a button in a drawing): the action goes in the type of the nearest view whose drawing holds it (Inspector.actionHomeOf(), through its shadow root); that's where the element's event handlers can call it.
  • That view is then selected, so its Code card shows the new action, to "new action", with the cursor in it: the element's own card lists only its events.
  • Not chosen: listing the drawing view's actions on every element's card (long for the app's drawing), or keeping the element selected and the new action out of sight.
