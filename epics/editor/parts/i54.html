Found: the language service DOES know action for <act, but the code pane is set to show suggestions only when you press Ctrl+Space.

  • That's the default you chose in Quiet Code Popups (P4): "by default nothing shows by itself as you type". The code pane's ⋯ › Settings… can turn on "as you type".
  • Headless in Tic-Tac-Toe, typing <act on a new line in the drawing:
    • default settings: no list
    • then Ctrl+Space: action, "a button for one of the program's actions"
    • with "as you type" on: the same list, by itself
  • The language service alone, in node, gives children, action, context-menu, divider at every place tried. 
export const CODE_POPUP_DEFAULTS: CodePopupChoices = {
  hover: "withAlt",
  suggest: "onCtrlSpace",
  suggestDetails: false,
  parameterHints: false,
  ...
}
// and so:  quickSuggestions false, suggestOnTriggerCharacters false

Where suggestions should show by themselves is a choice for you: it's in the phase's Choices.

  • Typing <act offers action by itself, with no keys to press.
