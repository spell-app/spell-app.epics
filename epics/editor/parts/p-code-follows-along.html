Spell and its output sit side by side. A click anywhere shows the same thing everywhere else.
  1. Side by side, only when you ask. The output pane is off by default, and nothing makes you look at compiled code. You open it from the code pane's ... menu, which also chooses the language, and it's remembered. Everything else follows along without it. It uses the existing split panel and OutputEditor, whose tab today shows one target for its life. On a narrow window the pane gives way rather than squeezing both.
  2. Reading the maps back. New: a small decoder beside SourceMarks, answering "which Spell statement is this output line?" and the reverse. No second map.
  3. One place in focus. A click on a Spell line, an output line, a tree row or a thing on screen sets one "current place", on P11's selection and P7's marks. The other three reveal and highlight it.
  4. Quiet following. Following scrolls only when the thing is out of view, and never takes the keyboard focus, so typing is undisturbed.
  5. Python. Its map is last, as its own step. If its writer doesn't report statements to the marks, that's new work, and the other three follow without it until then.
  6. Checked by: tests for the decoder; a headless script clicks each of the four in Solitaire and checks the other three, for JavaScript and TypeScript, then Python.
  7. Left out: following by word (Owen: statements are fine); editing the output.
