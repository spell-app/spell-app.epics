The accepted plan said a thing made in a loop starts on "All cards", whose suit edit goes to the template. That can't happen in Solitaire:

  • A card's rank and suit come from add a new card with rank = the rank, suit = the suit, so the template has no suit to change, and a default there would be overridden by that line.
  • A card's Face (direction) belongs to the built-in two sided view, with no starting value in the code.

So on "All cards" every field of a card is read only, and opening on that would look broken. What I built instead:

  • A thing made in a loop starts on All only if something there can change. Otherwise it starts on This, with your note, "Changes to this card can't be saved."
  • On All, the note says "Each card gets these from the code that makes it.", and rank and suit each have a button to that line.
  • This differs from the plan's words and its Verify line. Rethink Edit Scope can revisit what "All cards" should offer here.
