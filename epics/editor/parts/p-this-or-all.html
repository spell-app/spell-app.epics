A "This card | All cards" switch in the row that names the thing. Each field shows where its value comes from.
  1. The switch. A small This card | All cards beside the name in the properties card's first row, worded from the thing's type. It's a segmented <ui-menu>, the same widget as every other choice; it collapses when the card is narrow, and adds no row.
  2. Which side it starts on: "This" for a thing with its own tag, otherwise "All". The count from Source Places may move this default.
  3. All cards edits the type's default through the source edit, and every card follows on screen.
  4. A thing made in a loop offers only "All cards". Beside it, a "Just while it runs" try-out changes this one running thing and writes nothing. It's labelled, and it goes when the program restarts.
  5. Where each value comes from. <ui-property-editor> learns this, so any property editor can use it, and the editor adds no CSS of its own:
    • set here: a dot, and a Reset that removes it from the source
    • inherited: quieter, its tooltip naming the type
    • worked out: read only
    Today it compares a value with the default only, so the Inspector tells it the home.
  6. A template's own <property-editor> works the same way, since these are its fields.
