Every header in the editor becomes the same widget, so the views header, the file tabs, Run | Edit and the Program panel stop looking like four different ideas.

Today's tangle:

  • The file tabs are folder tabs, 49px high, 14px text.
  • The views tabs are pills inside a card title, 40px high, 13px text, tuned by hand in the editor's CSS.
  • Run | Edit has a recipe of its own.
  • So the code's top edge doesn't line up with the Inspector's first row.

The proposal: <ui-toolbar> becomes the one header (Q3). It has most of this already:

  • the pill look, with its sliding thumb
  • one or many chosen (choose="many")
  • collapsing into a dropdown when narrow (shrinkable, which the editor doesn't use yet)
  • slots for a title and for actions on the right

It would grow three things:

  1. A header size: the row's height, its hairline, 13px text. The pill tuning moves out of the editor's CSS into the widget and the theme.
  2. A way to say "these are tabs", for screen readers.
  3. A middle stage for many files: today's collapse is all or nothing, so a 12-file project would become a dropdown too early. It would scroll with its ‹ › arrows first. 
<ui-toolbar appearance="segmented link" shrinkable size="header" label="Views">
  <ui-item selected><ui-icon name="sitemap"/>Views</ui-item>
  <ui-item><ui-icon name="cube"/>Things</ui-item>
  <ui-icon slot="right" name="search" link label="Filter"/>
  <ui-icon slot="right" name="angle double up" link label="Collapse all"/>
</ui-toolbar>

<ui-toolbar appearance="segmented link" shrinkable size="header" label="Files">
  <ui-item selected>Card.spellml<span class="NotSaved"/></ui-item>
  <ui-item>Solitaire.spellml</ui-item>
</ui-toolbar>

What it deletes: the pill tuning and most of the file tabs' CSS, the file tabs' hand-made narrow version, the Program panel's own header, and <ui-buttons> used as a chooser.

The top bar joins the top of the window, with no gap around it, and gets shorter: about 38px instead of 74. It has no panel look of its own, so the page reads as one app. The Inspector's fold caret and hide-eye go into the same row's slots.
