The palette's topic headings come straight from each component's English topics. Spell UI's Spanish dictionary already words every topic (values.topics: forms is "formularios"), so the palette will look each one up there.

  • Spell UI's ComponentDefinitions gets topicIn(topic, language), which reads that language's dictionary, the way snippetIn() already does for snippets. It falls back to the English when the dictionary doesn't word a topic.
  • The palette's heading, its tree's label and the "N more" tooltip read it in the editor's language (appTexts.lang), so they change when the Spanish texts arrive.
// Palette.tsx <h4>{upperFirst(topicName(group.topic))}</h4> /** `topic` as the editor's language words it: `forms` => `formularios`. */ function topicName(topic: string): string { return definitions?.topicIn(topic, appTexts.lang) ?? topic }
  • on a Spanish page the palette's topics read Formularios, Botones, Texto ...
  • component names under them stay English for now
