Make sure cut, copy and paste work too

  • A + in the top bar opens the palette as a popup, with a search at the top, so it takes no permanent space.
  • Click adds beside the selection; drag places it.
  • The palette reads each component's vocabulary file, which gets an icon.
  • Moving happens in the flow: a drop line between neighbours, changing the order or the parent in the source.
  • Delete and duplicate work on the selection, from the keyboard and a right-click menu.
  • Each of these is a source edit, and ⌘Z takes it back.
A palette from the components' own descriptions. Dragging places and moves things, and each move is a source edit.
  1. The palette. A + in the top bar opens a popup with a search at the top, listing components by topic from ComponentDefinitions, which already reads each vocabulary's name, search words and description, plus the icon from P12. Internal components are left out, through a new vocabulary field or list.
  2. Adding. Click adds beside the selection. This phase adds a starting snippet to each vocabulary, since none has one. It goes into the source through P9's source edit, the app redraws, and the new thing is selected.
  3. Dragging, one copy. Dragging and the drop line, which SpellElement draws today, are lifted into Spell UI's runtime, as P11 does with the selection rule. The running program's lists use them from there.
    • A drag from the palette, or of a selected thing, uses them.
    • Rows in the Views tree drag the same way, and a drop there moves the same tag.
    • Over the app, the drop line sits on a layer above it.
  4. Moving and deleting use the one source edit's moves and deletes (P9), which came from the notebook. A drop changes the order or the parent in the source, keeping each tag's text and comments whole. P7's source places say which tag.
  5. Delete and duplicate. From the keyboard and a right-click menu, on the whole selection.
  6. Things with no tag. A loop-made thing can't be moved alone: the app says so, and offers its template, as in P10.
  7. Undo. One gesture is one step, whatever it wrote, through P9's history.
  8. Checked by: tests of each source edit on real files, byte for byte elsewhere; Solitaire's drags still working from the lifted copy; a headless run from an empty project: drag in a button and a card, reorder, save, reload, and read the code; undo each step.
  9. Left out: free x / y placement (a todo, per Q6); resize handles; drops into .spell files with no markup.
  10. Cut, copy and paste: ⌘X, ⌘C and ⌘V work on the selection, in the app and in the tree, and in the Edit menu. Each is one source edit and one undo step. Paste lands beside the selection, or inside it when it's a container. They go through the same keys list as the rest, so in the code editor ⌘C still copies text.
  11. Pin the palette: it stays a popup by default, and a pin in its header keeps it open as a side pane, for a big monitor. The pane is remembered, and it's the panes' own widget, not a new one.
