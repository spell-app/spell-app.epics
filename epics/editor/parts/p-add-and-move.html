There is no way to add a component to a page or move one.
  • A + in the top bar opens the palette as a popup, with a search at the top, so it takes no permanent space.
  • Click adds beside the selection; drag places it.
  • The palette reads each component's vocabulary file, which gets an icon.
  • Moving happens in the flow: a drop line between neighbours, changing the order or the parent in the source.
  • Delete and duplicate work on the selection, from the keyboard and a right-click menu.
  • Each of these is a source edit, and ⌘Z takes it back.
A palette from the components' own descriptions. Dragging places and moves things, and each move is a source edit.
  1. The palette. A + in the top bar opens a popup with a search at the top, listing components from their vocabulary files by topic: name, icon (P11), description. Internal components are left out, through a new vocabulary field or list.
  2. Adding. Click adds beside the selection. The vocabulary's starting snippet goes into the source through P8's source edit, the app redraws, and the new thing is selected.
  3. Dragging. A drag from the palette, or of a selected thing, uses Dragging, which already carries several and draws a drop line. Its tie to the runner is loosened where needed. The drop line sits on a layer above the app.
  4. Moving. A drop changes the order or the parent in the source, keeping each tag's text and comments whole. P7's source places say which tag.
  5. Delete and duplicate. From the keyboard and a right-click menu, on the whole selection.
  6. Things with no tag. A loop-made thing can't be moved alone: the app says so, and offers its template, as in P9.
  7. Undo. One gesture is one step, whatever it wrote, through P8's history.
  8. Checked by: tests of each source edit on real files, byte for byte elsewhere; a headless run from an empty project: drag in a button and a card, reorder, save, reload, and read the code; undo each step.
  9. Left out: free x / y placement (a todo, per Q6); resize handles; drops into .spell files with no markup.
