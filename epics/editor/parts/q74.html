For P41 · Save Back To Disk. How soon the app notices that its file changed on disk while it's open.

Chrome has tried a change observer (FileSystemObserver) that tells a page at once when a file changes, moves or disappears; it's still marked experimental and not standard, and the spike checks whether today's Chrome has it.

  • No change is ever missed at save time (Q72).
  • Coming back to the tab, the app checks the file once, and offers to read it again if it changed.
  • Where the observer exists, the same offer comes at once.
  • Simplest; you may work for a while on a stale copy, and only find out on saving.
  • Like an editor that reloads a file changed on disk, when you have no changes of your own.
  • Can be added to A; surprising if the file is half-written by a slow program.
  • a check on save and on the tab coming back, plus the observer when present
  • a "This file changed. Read it again?" line
