Short answer: today this touches almost nobody, so I'd leave it and note it. Of the three parts, only one shows on a built-in program.

  • A program that imports another project: no built-in example or guide does. The only one is a frozen test project, counter-app, which imports the counter library. (Solitaire's files, and Star Wars' API file, are the project's own files, not another project.)
  • A program with no app: e.g. FizzBuzz, which only prints. It draws nothing, so running again loses nothing on screen, and printing again is what you'd want after an edit. That's right as it is.
  • A new property's attribute: its value works at once, but the attribute only appears on the element after Restart. An element's list of attributes is set once, when its tag is defined on the page, and the browser can't change it after that.
