How add and move work today: a drop edits the source, then compiles and runs the whole program again.

  • The run first unmounts the app, so every element on the page goes away.
  • The top-level things are kept by name, and what they hold comes over as new things of the new classes, so all 52 cards are new objects drawn afresh.

    Edit Goes
    An attribute or words on a tag in a drawing Live: that view draws again
    A tag added, moved or removed in a drawing Live: that view draws again

    A property's default Live: things still holding the old value follow, as the side bar already does
    The project's CSS Live: the styles swap, nothing draws
    A new property Live on running things, with its starting value, if that holds in step 2; else as the row below
