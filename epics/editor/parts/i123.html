Three layers, so a rename in the editor's own Spell is never silent again.

  • One list of the names the editor needs, EDITOR_NAMES: every type and member the editor's TypeScript reads or fills by name, and what each is for (code is showing: ticks View › Code). Every reader and writer takes its names from it, through its types, so a name the TypeScript writes that isn't on the list doesn't compile.
  • Warn while editing. The editor hands the language service the list for @spell/editor/spell-editor. A name on it the Spell no longer declares is an error squiggle under the type it's missing from, in short lines: “The editor fills code is showing itself. / Renaming it stops the editor from working. / Keep this name, or ask Claude to rename it in the editor's code too.”
  • Never fail silently. As the editor loads its Spell it checks the list against what loaded, and shows ONE notice naming every name missing, a line each. A missing view or menu falls back: the plain panes and bar, an empty menu, no tabs, rather than a crash.
  • A test renames members in a copy of the Spell's text, and checks the squiggle and the load's notice.

No parser change: the check reads the outline the language service already builds.
