Owen's I177 note asked for a square checkbox or a toggle; the Inspector's yes/no fields are now toggles, a size smaller than a default one (2.5em lane, 1.25em knob), the label right beside them, its centre on the toggle's, light and dark.

  • Where: Spell UI's <ui-property> draws a yes/no as the toggle kind in any compact editor (only the editor's forms are compact: the Inspector, the site editor's page form). Without compact it stays a checkbox.
  • The round look came from the Spell theme (and Glass), which rounded every checkbox on purpose, the brand's to-do circle. Now 4px corners, so no checkbox anywhere reads as a radio. The brand's done to-do is still filled purple with a white check, only square-ish.
  • A toggle's knob is white in dark too: the theme's surface colour sank into the dark lane.
  • Not changed: the Inspector's read-only computed yes/no (a <ui-checkbox readonly> drawn in Inspector.tsx) is now square, not a toggle; making it a toggle is a one-word change there (appearance="toggle" padding="none"), in a file another agent held.
