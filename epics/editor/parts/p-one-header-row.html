The first stage is on main: the header look on the Views card. The other headers wait for Owen's answer on the details page, The Header Look.

  1. A header look, on <ui-menu>: one height, a hairline and 13px text. It's a new appearance word, header, because size is a scale and this isn't a size. It goes on the menu, which the toolbar is built on, so the top bar can use it too. Its height comes from the control-height setting that Glass And Fruity adds, starting from the existing menu height value. The pill tuning moves from the editor's CSS into the widget and the theme.
  2. It can say "these are tabs", for screen readers.
  3. Many items scroll first: the ‹ › scrolling it already has is switched off when it's shrinkable today. It becomes the stage before the dropdown, so no new scroller is written.
  4. A collapsible header over a pane reads as ONE thing, not a caret, a track and loose icons side by side. This is the point of the phase. Inspector cards become <ui-panel>, which already folds: its caret, the tabs and the actions sit in one bar, on one baseline and with one spacing, as the bar of the pane below. Closed, the pane leaves only that bar, which still shows what's chosen. The header row is the panel's title, with the hide-eye in its actions slot and the caret from its fold-icon, so no new slots. The hand-built fold goes, and each card still remembers whether it's open.
  5. Show it before moving the rest: the look is built on the Inspector's Views card first, open and closed, in Glass and Fruity. Pictures go to Owen on a details page, and the other headers follow once he's happy with it.
  6. Every header moves over: the views tabs, file tabs as pills, Run | Edit, the Program panel, the output view switch, and the Things tab's hand-toggled icons.
  7. What goes: the pill tuning, most of the file tabs' CSS, their hand-made narrow version, the Program panel's own header, and <ui-buttons> as a chooser.
  8. Docs: the toolbar's and panel's pages, examples, and English and Spanish vocabularies.
