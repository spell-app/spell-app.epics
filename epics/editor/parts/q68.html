For P41 · Save Back To Disk. Where the file's handle lives in the code decides what an app gets for free.

A handle is the browser's key to one file on disk (Chrome and Edge only): it can read and write the file, and can be stored in the browser's database, which DatabasePlace already does.

  • A small place in spell/places that reads and writes through the handle, using the formats already there: JSON, CsvFile, Workbook.
  • It gets what every place has: pending changes, the side bar's origin, undo before sending, a copy on this device.
  • The browser's file kinds, refused today without a server side, get this place instead.
  • A handler reads the file (as from-jarvis's File Upload already lets it) and keeps the handle in a variable; a save writes the text back.
  • Less to build, but every app writes its own reading and saving, with no pending changes and nothing in the side bar.
  • a new place class in spell/places, taken by file, so only an app using it pays for it
  • placeKinds' file, json file, csv file and excel file with no server side make it, instead of throwing
