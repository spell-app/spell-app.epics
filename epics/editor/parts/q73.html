For P41 · Save Back To Disk. The file was moved, renamed or deleted (in Finder, say) after the app opened it.

A handle to a file on disk names its path, so after any of these the app can't reach it: reading or saving fails with "not found". The browser can't tell which of the three happened, nor where the file went. And if a different file now has the old name, the handle reaches THAT one: the conflict check (Q72) catches it, as a change by someone else.

  • A short line: "Can't find recipes.json. It may have been moved, renamed or deleted."
  • Two buttons: "Find it" (the file picker, starting near where it was) and "Save as new file".
  • Your data stays from the copy on this device, and unsaved changes are kept meanwhile.
  • The next save asks where to save, with the old name filled in.
  • Fewer words, but a moved file ends up as two copies.
  • a "can't find it" line with two buttons, shown on read or save
  • the remembered handle is replaced by the one picked
