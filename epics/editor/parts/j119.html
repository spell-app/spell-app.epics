Restore's link under a refused name puts the old name back and closes the field, so the action reads as it did before.

  • Kept open, the field would only hold the name it already has: nothing left to do there.
  • To try another name, click the name again.
  • Restore shows under every refused name (empty, not words, taken), not only a taken one: the old name is always there to go back to.
