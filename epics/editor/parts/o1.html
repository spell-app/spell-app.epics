Someone who has never seen Spell code should be able to make a real app in the editor, and enjoy it. That's the bar for a public preview on the web, in the next couple of weeks.

  • The test: start from nothing, draw an app with drag and drop, tweak it in the side bar, and save. No code read at any point, yet real Spell code comes out.
  • The feel: "All Magic, No Fuss". It feels like an app, not like a web page holding panels.
  • Where it runs first: Mac and Windows desktops, on a laptop screen with a menu bar and browser chrome above it. Tablets next. Phones and Linux are out for now.
  • Later: select something and say "change this", then eventually "I want an app where...".

Four rules hold for all of it:

  1. Height is precious. A new feature doesn't get a new row: it goes in a ... menu, or a toolbar that compresses.
  2. The widgets learn it. What the editor needs becomes a capability of a <ui-*> widget, not editor CSS. Before a new widget or CSS, ask whether a close widget could grow, and ask Owen.
  3. Sparse code. The opposite of an AI-made screen with its one-off components and piles of classes.
  4. Glass and Fruity first. Other themes get no tuning for now, but nothing here makes theming harder.

This epic is standing: major editor work from other epics comes here, and each phase merges into main as it finishes.
