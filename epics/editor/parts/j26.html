Thing's constructor assigns what a line gives, then runs to create it. So in Counter, a new counter with count = 5 still starts at 0, because set its count to 0 runs after it. Sidebar Writes Source assumed the line wins: it doesn't.

  • A value the type sets, in to create it or as its "layout" is stacked, can only change through All.
  • On This, such a field writes nothing and says "All counters start with this, so change it on All counters."
  • Counter starts on This, as it has its own line, and its count edit goes through All. Rethink Edit Scope may ask the language to let a line win.
