Two long aims shape the work now: the first gets started on your own machine, and the second starts right after the look.

"Change this": select things on the screen, say what you want, and it happens. The epics' comments are the model: a place you can find again, a note, and a send.

  1. The selection supplies the place: project, source position, a short excerpt.
  2. A small box on the selection takes the words. It's a popup, not a panel.
  3. It reaches a Claude session, which edits the files.
  4. The program compiles again, keeps its state, and shows the result.
  • The app has no agent plumbing today.
  • It runs on your own machine first, and is hidden in the public preview, which has no server.

Turtles all the way down: the editor edited in the editor. We go for it, in three stages:

  1. The layout in Spell: the editor's layout pieces are written in .spellml, with custom TypeScript behind them where Spell would make it too hard.
  2. The backing in Spell: that TypeScript is rewritten in Spell, piece by piece.
  3. The full editor: all of it in Spell, and editable in itself.

What stands in the way of stage 1: the first step proves it on one pane before going further.

  • The editor is one bundled Solid program today, with a single editor object per page.
  • The Inspector's picker and its parts assume a program running inside the editor, not the editor itself.
  • Compiled Spell runs on its own copy of the runtime, while the page must hold one Solid.

Every widget the editor grows in this epic is also one a Spell app can use.
