Found: the marching ants sit on top of the loading screen, because both are at the same height on the page.

  • The loading screen (the Spell hat that covers the page while it starts) and the boxes that draw the ants are both z-index: 2147483000.
  • The ants' box is added to the page after the loading screen, so with the same height it wins and draws on top.
  • Nothing waits for the loading screen to go: anything selected while it's up, like what was selected last time being put back, shows its ants straight away.

Seen headless: selecting the New game button while the loading screen was up drew its ants over the hat.

/* app/app/index.html */
#PageLoading {
  z-index: 2147483000;
}
/* app/src/app/solid/Inspector.css:  the ants' boxes, on <body> */
.InspectorBox {
  position: fixed;
  z-index: 2147483000;
}
  • The loading screen goes above everything, the ants and the hover box included.
  • The ants also wait until it has gone before they start, so they never flash during its fade.
