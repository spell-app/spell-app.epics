• Showing a page in the side bar: node scripts/window.mjs show <file> -> the extension's DocPreview -> the "Spell Docs" view (DocView, an iframe of the page server's URL). Live reload included. No extension change needed.
  • Pages talking back: the page server's ROUTE MODULES (root package.json "pageServer".routes) add POST routes; goals' buttons already do it (packages/docs/tools/goals/goalsRoutes.ts). Writes carry the per-run token (window.SPELL_SERVER.token) and pass guard.writeCheck.
  • Worktrees: the main checkout's server serves every worktree under /worktrees/<w>/, so a page in a worktree works from one port.
  • Waking a session: a background Bash command re-invokes Claude when it exits. So a script that waits for the answer file, then exits, IS the wake-up.
