What already worked before this epic, and what it could build on.

  • Showing a page in the side bar, live reload included. No extension change needed. 
    node scripts/window.mjs show <file>  ->  the extension's DocPreview  ->  the "Spell Docs" view
    • the view, DocView, is an iframe of the page server's URL
  • Pages talking back: the page server's ROUTE MODULES add POST routes.
    • they're listed in the root package.json, under "pageServer".routes
    • the goals pages' buttons already do it (goalsRoutes.ts)
    • writes carry the token for the server's run (window.SPELL_SERVER.token)
    • and pass guard.writeCheck
  • Worktrees: the main checkout's server serves every worktree under /worktrees/<w>/, so a page in a worktree works from one port.
  • Waking a session: a background Bash command calls Claude again when it exits. So a script that waits for the answer file, then exits, IS the wake-up.
