A details page that was open while the page server restarted can't send until you reload it.

  • Why: every send carries the server's write token (x-server-token), and the token changes each time the server starts.
  • What you see, from the page's script (details.js): "The page server restarted since this page loaded: reload the page, then Send again."
  • Not checked: whether your picks survive the reload.
  • nothing changes: the error says what to do
