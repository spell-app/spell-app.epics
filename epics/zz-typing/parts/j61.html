Two calls made while giving App UI's and Brand's pages the comments and toolbar.

  • The epics pack in their layouts. The comments draw each thread and the comment pane with the epics pack's elements (<epic-thread>, <epic-comment-pane>). Epic UI's layout loads that pack; App UI's and Brand's didn't, so a comment typed there never saved. Both layouts now carry <ui-components source="/_epic/pack/epics.pack.js"> beside their own pack. The other way: have spell-comments.js load the pack itself, which Spell UI's site bundle gives it no way to do.
  • Pages in tabs. Brand's element pages hold their sections in tabs (Examples, Usage, API, Theming). The toolbar used to sit in the first tab, with a button for every tab's sections, hidden ones too (T C S V U K A T). Now it lists the shown tab's sections and follows the tabs; the API tab, which has no sections, has no toolbar. The other way: no toolbar at all on a tabbed page.
  • Not done: Spell UI's own pages (/components/ui/). They load Spell UI's own site bundle, which can't load a component pack, so the one line wouldn't be enough for them.
