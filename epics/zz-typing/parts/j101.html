The prompt hook asks Haiku (claude -p --model haiku, hooks off) for one sentence only when the session was busy for 3s before the message came, the message is 40 characters or more, and it isn't a slash command.

  • Why: the hook holds the prompt until it finishes, and Haiku takes 2-5s. An idle session replies at once anyway, so a summary there would only slow every reply.
  • Every prompt is logged to epic-prompts.log in the checkout's git folder: when the hook ran, the session's state and for how long. That shows whether the hook runs when a mid-turn message is sent, or only when it's taken up.
  • promptAck: false in .epic/config.json5 turns it off.
