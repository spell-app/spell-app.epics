When spell-app's page server is running but its editor isn't (vite crashed, or SPELL_NO_EDITOR), the App tab runs spell dev server ensure. That finds the page server up, so it starts nothing. The 'Starting…' page then gives up after 2 minutes and names the log.

  • Fix by hand: yarn server stop, then click App again.
  • The epic server never stops or restarts a page server itself (Owen's rule).
