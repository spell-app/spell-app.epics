What each piece of the Epics page is drawn with, inside the new elements:

  • Each card: Spell UI's <ui-card>, <ui-header>, <ui-description>, <ui-meta>, drawn in <epic-card>'s shadow root, its title link the card's own child. Measured against the old page at 1200px: the same card boxes (341 x 136), gaps (12px) and heading spacing, to a pixel or two.
  • The star: a <ui-button tertiary> with the star icon, centred by the component (was a raw <button>).
  • The sort: <epic-sort> draws the same <ui-buttons circular basic size="tiny"> pair the runtime built.
  • The saga chips: plain <button>s in <epic-list>'s shadow root, as <epic-section>'s state chips are: no Spell UI element is a pill that toggles and counts, and their ivory look is the toolbar's.

The alternative for the chips: <ui-button basic circular toggle>, restyled through ::part() to get the ivory back; more CSS for the same look.
