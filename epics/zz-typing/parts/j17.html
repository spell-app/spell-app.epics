Owen, 2026-10-19: "in epic outline-spell, J9 was decided in conversation in the item, but J9 is not green and the selected choice is not selected." The CLI had no way to record a pick on anything but a question (epic decide ... --option).

  • New verb: epic choose <epic>#<id> <letter> ["outcome"] [--set N], e.g. epic choose outline-spell#J9 A "Owen, 2026-10-06: 'require the parens'; built".
  • It runs the page pick's own code (PlanDoc.choose() calls pickOption(), which applyMark() uses): the set's chosen; a question answered with the option's title; a judgement call closed (accepted); reviewed as approved; the same Noted card, the outcome in place of "waiting for the next phase"; one log line ending "settled in conversation: <outcome>".
  • The set: the item's LATEST (often Claude's last reply's); --set N counts from 1, as the error messages do.
  • An issue, caveat or todo is only reviewed, not closed, as the page pick does: choosing how to fix an issue isn't fixing it.
  • Not chosen: stretching decide to any item. decide takes free answer text and is about questions; a pick on any item is the page's pick, so a verb of its own reads plainer.

The /epic skill says to run it at once whenever Owen settles options in words (section 5 step 2, section 7.3, the cheat sheet). outline-spell J9 fixed with it.
