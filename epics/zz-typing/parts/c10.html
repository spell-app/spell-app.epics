• The browser keeps a page's storage per address (host and port). A choice or details page reopened from the same server gets its typing back; one reopened from a server on another port doesn't.
  • That is exactly the case I69 makes (the epic server on a random port). There, Copy my answers in the still-open page is the way out.
  • Each token refresh loads the page once in a hidden frame with its scripts off. The browser's console then shows a few "Blocked script execution" lines. They are harmless.
Until I69 is fixed, a page stranded on a dead port still needs Copy my answers, not a reload, to rescue what was typed.
