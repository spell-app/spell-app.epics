Backfill now finds an epic's commits in every child repo, but the list of files those commits changed, which /docs-check reads (EpicDocs.commitFiles()), still reads only the kit's git history.

  • So for an epic whose work is in spell-lang, spell-ui or spell-app, /docs-check may miss docs those commits touched.
  • The fix: read each commit's files from the repo it came from (the repo its <epic-commit> names).
