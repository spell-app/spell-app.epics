The fix for links one folder too deep (I34) is a rule in the engine-links step (I27), not a sibling step. Both mend dead links to files with evidence, and a too-deep link can also point at a moved file: epic-workflow's link to the docs package's old check-spell.js needed both fixes at once. Like the rest of the step, it changes a link only when the file is there one folder up, never more than one. The alternative was a separate dated step, which would have to run before engine-links and repeat its table.
