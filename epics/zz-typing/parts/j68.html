commentsRoutes.ts took comments on the pages of the sets in spell-app's COMPONENT_SETS. Now it takes them on any page under /components/<set>/ (COMPONENTS_PREFIX), still never a set's __parts/.

  • Why: that address is the sets' alone, and a page is only found where the server serves a set (commentsPage() resolves it through the mounts), so spell-app's settings' sets and the epic server's Epic UI both work without the route module reading any settings.
  • Example: /api/docs/comments?page=/components/ui/ui-button.html on the epic server answers takesComments: true; /components/ui/__parts/layout.html answers false.
  • The alternative: build the list from the server's checkout's settings, plus Epic UI.
