EpicConfig.main and EpicConfig.mainOf() now give the main checkout's REAL path, whatever spelling found it; a config folder found beside an OLD spelling (the compat link) is returned as ITS real path.

  • Why: git and process.cwd() give real paths, so every value now matches them; epic config contentFolder after the move prints ~/www/spell/spell.epics, the path to write into the config, and window files get the real folder.
  • Seen today only where a temp folder is a link (/var -> /private/var): seven test files now take their temp folders' real paths. Owen's checkouts aren't links, so nothing he sees changes before the move.
  • RepoList.add() finds an entry by any spelling and rewrites it to the real path, so epic repo add after the move tidies repos.json5.
  • The alternative: keep main as found and compare by real path only; then a worktree and the main checkout could report two spellings of one repo.
