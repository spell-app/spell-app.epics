The epic server finds a repo's app from an app key in its .epic/config.json5: where it answers (url, or a record file such as spell-app's .spell-server.editor.json) and what starts it (start). It doesn't import spell-app's appRoutes.ts.

  • Why: that module loads spaces' server code, which spell-epic has no alias for. The engine also serves other repos, whose apps are nothing like spell-app's.
  • Kept from appRoutes.ts: the same rule. The record's URL counts only if it answers within a second.
  • spell-app's start command is its page server, node bin/spell.mjs dev server ensure, because the editor is a child of the page server.
  • The other way: the brief's alternative, redirecting /editor/ to 4747's own /editor. It needs 4747 running, and can't start it.

spell-app's app key is written in spell-app's epic-engine worktree and isn't committed yet. It counts once that is merged into spell-app's main.
