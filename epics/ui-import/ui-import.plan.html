UI Import: include, code, markdown Spell UI gets three new elements, for HTML, code and markdown: each shows text from a file on the same server, or written inline, and saves it back through one shared loader, UI.sources. Their engines (highlight.js, marked and a pre-compiled spell highlighter) load only when a page uses them, and the page server learns to save files that aren't HTML, so docs pages can edit what the elements show.
