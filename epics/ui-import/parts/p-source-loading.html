Built the loading and saving all three elements share.

  • UI.sources, one runtime service: it loads text and caches it per URL, same origin only, with ETags, and saves through a saver the page plugs in
  • SourceElement and SourceHost, the base component and element:
    • inline text, from a template or a script, dedented
    • its states, save(), reload() and events
  • all three elements draw into a shadow root
