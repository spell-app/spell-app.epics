An element that puts part of another page, from the same server, into this one.

<ui-include source="/docs/part.html" select="main" load="visible"></ui-include>
  • Where the content goes (D14):
    • by default, into its shadow root: page CSS stays out, but Spell UI's tokens (inherited custom properties) still apply
    • with page-styles, into its LIGHT DOM: page CSS applies, and so does <ui-root>
  • Either way, the include loads the Spell UI families its content uses itself, through RootLoader.undefinedTags(root).
    • why: <ui-root> can't see into a shadow root, and a page may have no <ui-root>
  • A whole page fetched: it takes the children of its <body>, or only what select matches.
    • the page's <head> is ignored
    • relative links and image sources are rewritten against the source URL
  • Scripts in it don't run (D7).
  • Nested includes load themselves; a cycle shows an error.
  • Saving:
    • with select: saves only that fragment, found by its id
    • how: a byte-exact splice of the file, through PATCH /_server/page
    • a fragment with no id: an error
    • without select: a PUT of the whole file
Kind Name Type / default What
attribute select CSS selector include only its first match
attribute page-styles boolean render into light DOM, so page CSS applies
property contentRoot ShadowRoot, read-only where included markup lives (for editors)
property content HTML string get serializes the live markup (DOM edits get saved); set replaces it
slot default placeholder until loaded (server-rendered fallback)
part content wrapper around included markup
