Three new element families in Spell UI, and the code they share.

  • The families sit with the others, in components/: ui-include/, ui-code/, ui-markdown/.
    • Each has the usual files: the component, its index, vocabulary, types, CSS and fallback.
    • Also its tests, its examples and its docs site page.
  • Shared by all three:
    • Sources.ts: the UI.sources service, which loads and saves text
    • SourceElement and SourceHost: the base component and element for "content from inline text or a source file"
    • what they give each element: content, save() and reload()
  • The engines load lazily, each in a chunk of its own, behind a small wrapper module.
    • CodeHighlighter loads highlight.js's core and the languages it guesses from.
    • MarkdownRenderer loads marked and DOMPurify.
    • Why a wrapper: so Rolldown splits off no shared runtime chunk, as with TemporalPolyfill.
  • Each family is registered in the same places as every other:
    • the package's package.json (its exports and sideEffects)
    • the build's family list (COMPONENTS)
    • the package's entry, index.ts
    • the fallback tests' fallback.cases.ts
    • the demo's index.ts
    • yarn gen:root
    • the status list, status.md
    • the inventory in plan.md
    • the CHANGELOG.md
