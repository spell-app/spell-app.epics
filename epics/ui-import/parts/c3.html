On a page opened from disk (file://), none of the three elements can load a source file: the browser blocks the fetch. They say so, instead of failing quietly.

  • The message: "Can't load {source}: this page was opened from disk. Open it from a web server to see it."
  • Its error kind is file-protocol, in the ui-error event.
  • Inline content still works.

  • Its error kind is file-protocol (the ui-error event's kind).
