• host.save(text = host.content):
    1. dispatches cancelable ui-save; a listener that calls preventDefault() does the saving itself (an editor posting elsewhere)
    2. else UI.sources.save(url, text, etag) -> the registered saver (UI.sources.saver = fn). None: ui-error kind: "no-saver". Inline content with no source: updates content only
    3. success: new etag, ui-saved; 409 (file changed underneath): ui-error kind: "conflict", edits kept
  • ui ships no saver (it stands alone). The page-server saver: SPELL_SERVER.saveFile in the server's liveClient.ts, registered by packages/docs/tools/_assets/spell-ui-sources.js; a saver that can't import SourceError throws { kind, message, status } (D28).
  • Server (D3): PageEditor's PUT /_server/page widened from .html to text files (.md, .ts, .tsx, .js, .css, .spell, .txt, .yaml, .svg; NOT .json, D25): same token, same-origin, ETag and FileLock rules. PATCH (one element by id) stays pages-only.
  • A script's fetch() (Sec-Fetch-Dest: empty) gets files AS IS, without the injected live-reload tags (D24): what an include shows and saves is the file.

Shared API (all three elements)

Kind Name Type / default What
attribute source URL, reflected same-origin URL; change -> re-fetch
attribute load eager | visible | idle; eager when to fetch: now, scrolled into view, idle (islands)
property content string current text; set -> re-render, dirty
property etag read-only version of the last load / save, sent as If-Match
property dirty boolean, read-only changed since load / save
property loaded Promise<string> content once loaded
method save(text?) Promise<boolean> true once saved here; false when a listener took over (cancelled ui-save) or it failed (ui-error)
method reload() Promise<string> re-fetch past the cache; drops edits
event ui-load { source, content } content arrived
event ui-change { content } content set
event ui-save { source, content, etag }, cancelable before saving
event ui-saved { source, etag } saved
event ui-error { kind, source, error }, cancelable load | cross-origin | file-protocol | save | conflict | no-saver | render; cancel = no message
state loading, error, saving, dirty :state() for CSS
part loader, error the loader / message
text loading, loadError, crossOrigin, fileProtocol, saveError, conflict, noSaver translatable strings
