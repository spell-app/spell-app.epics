How an element saves its text, and the API all three share.

  • host.save(text = host.content) saves in three steps:
    1. It sends a cancelable ui-save event. A listener that calls preventDefault() does the saving itself: an editor posting elsewhere.
    2. Else UI.sources.save(url, text, etag) hands it to the saver the page registered.
      • how a page registers one: UI.sources.saver = fn
      • no saver: a ui-error of kind "no-saver"
      • inline content with no source: only the content is updated
    3. On success: a new etag, and a ui-saved event.
      • a 409 (the file changed underneath): a ui-error of kind "conflict", the edits kept
  • Spell UI ships no saver, since it stands alone. The page server has one:
    • SPELL_SERVER.saveFile, in the server's liveClient.ts
    • registered by the docs pages' spell-ui-sources.js
    • a saver that can't import SourceError throws a plain { kind, message, status } (D28)
  • The page server can now save text files, not only pages (D3):
    • PageEditor's PUT /_server/page takes them
    • which files: Markdown, TypeScript, JavaScript, CSS, spell, plain text, YAML and SVG (the list below)
    • NOT JSON (D25)
    • the same rules as for pages: token, same origin, ETag and the file lock
    • PATCH, which saves one element by its id, still takes pages only
    .md .ts .tsx .js .css .spell .txt .yaml .svg      (not .json)
  • A script's fetch() gets a file AS IS, without the live-reload tags the server adds to pages (D24).
    • how the server tells: the request's Sec-Fetch-Dest: empty
    • so what an include shows and saves is the file itself

Shared API (all three elements)

Kind Name Type / default What
attribute source URL, reflected same-origin URL; change -> re-fetch
attribute load eager | visible | idle; eager when to fetch: now, scrolled into view, idle (islands)
property content string current text; set -> re-render, dirty
property etag read-only version of the last load / save, sent as If-Match
property dirty boolean, read-only changed since load / save
property loaded Promise<string> content once loaded
method save(text?) Promise<boolean> true once saved here; false when a listener took over (cancelled ui-save) or it failed (ui-error)
method reload() Promise<string> re-fetch past the cache; drops edits
event ui-load { source, content } content arrived
event ui-change { content } content set
event ui-save { source, content, etag }, cancelable before saving
event ui-saved { source, etag } saved
event ui-error { kind, source, error }, cancelable load | cross-origin | file-protocol | save | conflict | no-saver | render; cancel = no message
state loading, error, saving, dirty :state() for CSS
part loader, error the loader / message
text loading, loadError, crossOrigin, fileProtocol, saveError, conflict, noSaver translatable strings
