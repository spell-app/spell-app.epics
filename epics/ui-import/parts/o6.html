An element that renders GitHub-flavoured markdown, from a file or written inline.

<ui-markdown source="readme.md"></ui-markdown>
  • Inline, the text is best in a <script type="text/markdown">.
  • The engine is marked 18, about 14 kB, with GitHub's extensions on:
    • tables, task lists, strikethrough, autolinks
    • footnotes later (T1)
  • Every render is sanitized by DOMPurify 3.4, in every browser (D20).
    • not the browser's setHTML(): its defaults drop task checkboxes, images, heading ids and code classes
    • DOMPurify's SANITIZE_DOM is off, so ids survive (D21)
    • trusted skips sanitizing
  • marked and DOMPurify load together, in one lazy chunk, MarkdownEngine (28 kB gzipped).
  • Code fences become <ui-code language="x"> (D9); a fence with no language is guessed.
  • How it draws:
    • in its shadow root, with a GitHub-like style sheet on Spell UI's tokens
    • heading ids are GitHub's slugs, so #anchor links work
    • #id links scroll inside the shadow root
    • relative links and images resolve against the source URL
    • task-list checkboxes are labelled by their item's text (D22)
  • The heading-offset attribute's PROPERTY is headingLevelOffset (D23).
    • why: WebKit already has a native headingOffset
  • The engine sits behind MarkdownRenderer, which turns text into a DocumentFragment (D10).
