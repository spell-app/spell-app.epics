A # heading inside <ui-markdown> becomes a real heading, part of the page's outline. That can put it at the wrong level under the page's own headings.

  • heading-offset shifts them to fit: with 1, a # heading is an h2.
  • Without it, axe's heading-order check can fail.
  • The property is headingLevelOffset, because WebKit already has a native headingOffset (D23). 
<h1>Page</h1>
<ui-markdown source="readme.md" heading-offset="1"></ui-markdown>
