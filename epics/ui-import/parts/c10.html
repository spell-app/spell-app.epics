Vite's dev server rewrites some files when they're fetched. So under yarn dev, or in the tests, a <ui-code source> can show Vite's version of a file instead of the file itself.

  • What changes:
    • .ts and .css files come back as JS modules
    • .html files come back with Vite's client script added
  • The page server serves files raw, so docs pages show the real file.
