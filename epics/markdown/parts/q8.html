Markdown needs counts: a heading is 1-6 #s; a thematic break 3 or more. Repeat already has minCount / maxCount: rulex just can't set them.

meaning regex A. braces (recommended) B. plus-number
exactly 7 x{7} x{7} x+7
1 to 6 x{1,6} \#{1,6} \#+1-6
3 or more x{3,} \-{3,} \-+3-
  • A: exactly regex. { is also a subrule, but a subrule name starts with a letter, so { + digit is unambiguous. Cost: rulex's repeatFlag grows a second form.
  • B: Owen's first idea. Quirk: the tokenizer reads -6 as a negative number and 1..6 as 1, .6; parseable, but the parser fights the tokenizer.
