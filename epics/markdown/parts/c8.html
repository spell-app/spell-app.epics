Since D30, an element without sanitized keeps whatever HTML its text holds: script tags and on* handlers included.

  • Fine for text the page author wrote: every <ui-markdown> in the repo today shows Spell UI's own docs text.
  • NOT fine for user input, or a source file from somewhere you don't control: those need <ui-markdown sanitized>.
  • Example: a README from another site would run an <img onerror> in that file; with sanitized, it's dropped. 
    <ui-markdown source="https://example.com/README.md"></ui-markdown>            <!-- runs it -->
<ui-markdown sanitized source="https://example.com/README.md"></ui-markdown>  <!-- drops it -->
  • The vocabulary and the site page say so; nothing enforces it.
