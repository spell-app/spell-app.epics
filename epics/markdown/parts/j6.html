The full ui-* mapping (D3), as decided, with these choices where the elements didn't fit (from a survey of Spell UI).

  • Ordered lists: ui-list has no start.
    • each item gets its marker as its value instead (value="N.")
    • so 3. a still reads 3
  • A bullet list inside an ordered list stays a plain <ul>.
    • a nested ui-list is ordered if any outer one is
    • so it would number the bullets 1.1
  • Quotes are a secondary ui-segment: no quote look exists.
  • Alerts are a ui-message, with icons:
    • NOTE info, TIP positive, IMPORTANT purple
    • WARNING warning, CAUTION negative
  • Code is <ui-code language copy> with escaped text, as <ui-markdown> made it before (upgradeCode()).
    • NOTE: ui-code dedents, so code whose every line shares an indent loses it, as today
  • Task items: <ui-checkbox readonly>
  • Headings: <ui-header level id>
  • Tables: <ui-table celled> around a <table>
  • Breaks: <ui-divider>
  • Options:
    • a plain <ol start> for every ordered list: less ui-*
    • or numbering nested bullets: wrong for markdown

D3 (full ui-*) as decided, with these choices where the elements didn't fit (survey of packages/ui):

  • ordered lists: ui-list has no start; each item gets value="N." (its marker) instead, so 3. a still reads 3.
  • a bullet list inside an ordered ui-list stays a plain <ul>: a nested ui-list is ordered if any outer one is, and would number the bullets 1.1.
  • quotes are ui-segment secondary (no quote look exists); alerts ui-message: NOTE info, TIP positive, IMPORTANT purple, WARNING warning, CAUTION negative, with icons.
  • code is <ui-code language copy> with escaped text, as <ui-markdown>'s upgradeCode() made it. NOTE: ui-code dedents, so code whose every line shares an indent loses it (as today).
  • task items <ui-checkbox readonly>; headings <ui-header level id>; tables <ui-table celled><table>; breaks <ui-divider>.

Options: plain <ol start> for every ordered list (less ui-*), or numbering nested bullets (wrong for markdown).
