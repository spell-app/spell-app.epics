Found designing P2.3. The rulex doc said a repeat's copies follow the spacing written after the repeated part (-{3,} = only ---). Applied to everything, that breaks 2 spell syntaxes whose repeats are written touching: {rhsChain:expression_suffix}+ (expressions.ts:432) and ({method_keyword}|\({method_arg}\))+ (methods.ts:842: to move (a card) to (a pile)).

Markdown needs both: #{1,6} and `{3,} touching, - - - spaced.

option rule spell markdown
A. Symbols run (recommended) A repeated SYMBOL is a run, like **: copies touch, unless a space before the flag (- {3,}). Any other repeat (subrule, group, keyword) spaces freely, as today unchanged #{1,6}\s{text}, `{3,}, (- {3,}|\* {3,}|_ {3,})
B. As written, everywhere Copies touch unless a space before the flag, whatever is repeated 2 syntaxes get a space: {rhsChain:expression_suffix} + same as A
C. Repeats always free Spacing as written applies between parts only unchanged # # would read as level 2; touching runs need a custom rule
D24 · A: a repeated SYMBOL's copies touch unless a space before the flag; other repeats space freely. {space} / {spaces} replace \s

Owen: "A, but have {space} rule which means single space character, and {spaces} which means any amount of spaces rather than \s".

  • {space}: exactly one space between the tokens either side
  • {spaces}: one or more spaces / tabs (read "any amount" as at least one: {spaces}? = allowed, which a written space already says)
  • both own their boundary: the syntax's spacing around them doesn't apply
  • examples: #{1,6}{spaces}{text}, (-|\*|\+){spaces}{text}, \[{space}\] (unchecked task box)
