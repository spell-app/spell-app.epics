Which markdown constructs draw as ui-* elements vs plain tags styled by ui-markdown.css.

Markdown Minimal Medium (recommended) Full
```ts fence <ui-code> <ui-code> <ui-code>
> [!NOTE] GFM alert blockquote <ui-message state="info"> same
- [x] done input checkbox <ui-checkbox> read-only same
table <table> <ui-table celled> around it same
--- <hr> <hr> <ui-divider>
headings <hN id> <hN id> <ui-header>
lists, quotes plain plain <ui-list>, <ui-segment>

Medium: ui where it adds behaviour (copy, alert icons, checkbox look); plain where CSS already does the job and text selection / copy-paste stays clean.

Heading ids, the headings outline and in-page # links must still work on ui-header; see C5.
