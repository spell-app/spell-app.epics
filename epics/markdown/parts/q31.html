Owen, 2026-10-04, answering I6: "Make sanitized opt-in and DOMPurify lazy load".

  • <ui-markdown> no longer sanitizes by default: raw HTML in the text is kept as written, <ui-*> elements included. The old trusted attribute is gone, since that is now the default.
  • A new sanitized attribute sanitizes with DOMPurify, which is now its own lazy chunk (MarkdownSanitizer.ts), loaded alongside the engine only when sanitized is set.
  • Both engines (marked, and spell's for editable) now return plain markup; the element sanitizes it when asked.
  • The docs bundle loads the sanitizer as its own classic script, _assets/lazy/markdown-sanitizer.js.
  • marked's chunk: 26.2 kB gz before (marked + DOMPurify), 14.2 kB gz now.
  • DOMPurify: 12.4 kB gz, paid only by a sanitized element.
  • Text you did not write needs sanitized (see the caveat).
