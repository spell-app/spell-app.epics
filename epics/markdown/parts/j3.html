Chose to leave two items of P3's goal to later phases:

  • link reference definitions ([ref]: /url "title") need the same destination / title parsing as inline links, so they go with P4's link rules; the scanner hands paragraphs over untouched (spec "Link reference definitions" 6/28 until then).
  • GFM alerts (> [!NOTE]) are a blockquote that DRAWS differently (ui-message), so P5's renderer does them; the spec has no alert examples.
  • Options: do both in P3 (ref defs would duplicate P4's link parsing), or this split.
