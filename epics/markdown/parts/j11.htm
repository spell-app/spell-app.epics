• Opens on Write, as GitHub's comment box does. The preview renders when its tab is shown (and on every edit while it is), so a page with an editable that nobody previews never loads the 230 kB MDEngine chunk.
  • MDEngine is its own lazy chunk (MarkdownRenderer.loadMD()), beside marked's; it defines the families MD draws with (ui-list, ui-parts, ui-table, ui-checkbox, ui-segment, ui-divider).
  • Sanitizing: DOMPurify, as marked's output, but ui-* tags are kept with every attribute except on* handlers.
  • The preview's <article> now sits in a <section> (the tabpanel: axe refuses that role on an article), for plain <ui-markdown> too; it has no name, so no landmark.
