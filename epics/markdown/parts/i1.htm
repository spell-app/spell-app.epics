rulex.compile() (via P.Rule.compileSyntax()) never checks that every token was consumed. It throws only when NOTHING matched; otherwise the rule is quietly truncated.

syntax compiles to
a -- b Keyword("a")
a // b Keyword("a")
a "b c" d Keyword("a")
a \-- b Sequence[Keyword("a") Symbol("\")]

Evidence: guides/rulex/experiments/rulex-probe.mts. Simplest fix: throw when match.length < tokens.length. Parser change: review gate (D7).
