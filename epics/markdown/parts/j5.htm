Chose, to match GitHub and pass the spec:

  • MD.toHTML(md, { autolinks, tagfilter }), both on by default. CommonMark core examples say bare URLs AREN'T links and <script> IS raw HTML, so the spec test turns each extension on only for its own examples, as cmark-gfm's runner does. <ui-markdown> sanitizes with DOMPurify anyway.
  • Nested strong draws no inner tag (****foo**** is one bold), as cmark-gfm's renderer does; the spec expects it.
  • HTML comments follow CommonMark 0.31's rule (<!-->, -- inside), which GFM's examples expect over 0.29's.
