A new package, packages/markdown, that turns markdown into Spell UI markup in four steps (the package decision: Q1).

  • named @spell-app/markdown, imported as $/markdown, its namespace MD
  • it depends on the parser and util packages only
  • Dependency direction: app / lsp / spell -> markdown -> parser -> util.
  • ui NEVER imports it: gets a committed precompiled bundle, like spell's highlighter (yarn gen:spell, packages/ui/scripts/gen-spell.ts).
