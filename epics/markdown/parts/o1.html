A new package, spell-lang/src/markdown, that turns markdown into Spell UI markup in four steps (the package decision: Q1).

  • named @spell-app/markdown, imported as spell-lang/markdown
  • its namespace: MD
  • it depends on the parser and util packages only
  • Which packages may import it: app, the language server and spell. 
    app / lsp / spell  ->  markdown  ->  parser  ->  util
  • Spell UI NEVER imports it: it gets a committed, pre-compiled bundle instead, as with spell's highlighter (yarn gen:spell).
