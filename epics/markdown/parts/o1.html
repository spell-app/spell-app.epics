A package of its own, spell-lang/src/markdown, that turns markdown into Spell UI markup in four steps (the package decision: Q1).

  • imported as spell-parser/markdown since epic repo-split, its folder spell-parser/src/markdown
  • its namespace: MD
  • it depends on the parser and util packages only
  • Who imports it: the app (its docstrings, and <spell-markdown>) and the language server. 
    app / lsp / spell  ->  markdown  ->  parser  ->  util
  • Spell UI NEVER imports it. Its <ui-markdown> keeps marked, editable or not; only spell-app's <spell-markdown> loads MD, since Spell UI holds nothing of spell (epic repo-split P2).
