In a spell file, a comment with markdown in it shows each kind in its own style.

# a **b** *c* `d` [e](f)
  • **b** bold
  • *c* italic
  • `d` in the string colour
  • [e](f) underlined
  • the rest in the comment colour

In a .spell file, a comment like # a **b** *c* `d` [e](f): **b** bold, *c* italic, `d` in the string colour, [e](f) underlined, the rest in the comment colour.
