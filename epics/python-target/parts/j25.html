Beyond the helpers the brief listed, I ported the rest of the JavaScript core's P10 names, so the method list (spellCore.declarations.json) has them: keys_of, values_of, set_items_of, add_at_position, merge_lists_into, remove, remove_items_at, remove_where, remove_item_at, clear, get_iterator_for, is_truthy, is_defined, is_array_like, check_prop, new_thing_like, new_scratch, things and base_types. I left forEachSequential for P11, since it waits. Two small changes from JavaScript: duplicate_list() of a value that isn't a list gives None rather than false, and so does merge_lists_into(). The stand-in h() leaves out only event handlers (an on... key). It calls any other function for its value, so a class or a child passed as a function, as the JavaScript writer emits them, still shows. It also writes className as class.
