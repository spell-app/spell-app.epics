When a page sends an event, a detail whose key is just its thing's type name is left out of the details: the event's target already names that thing.

  • Solitaire's card click is written sendTrigger("card-click", { card: this }).
  • With the card as the target too, it would name the card twice; it sends {"trigger": "card-click", "target": "Card#ace-of-hearts", "details": {}}.
  • The handler still reads event.card: Python hands it the target under its type's name (J84).
  • A thing under any other key, like { from: pile }, stays in the details (by reference) and is also a target.
  • The type name is matched in snake case, so discardPile matches a DiscardPile.
