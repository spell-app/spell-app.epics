Compiled code tells the core where counting starts on every call, deck.position_of(ace, start_at=0), and Owen hates it.

Both cores count from 0, as javascript and Python do; no position method takes a start any more.

Spell code that counts from 1 compiles each position through a helper, deck[position(n)], and a plain number is worked out as it compiles: item 2 is deck[1].

The javascript core's list methods change too: one break, with every compiled program and pinned output written again.
