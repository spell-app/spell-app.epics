In the messages a test sends, a thing is named by its @id, because references like Card#12 are the parked phase P27.

  • The phase planned this: "before it, the helper names things by @id".
  • A test writes game.ref(card), and the click it sends names the card as {"@id": ...}.
  • The Quart app's browser test checks that the click its page sends names the card the same way.
  • Once P27 lands, ref() writes a reference instead; tests that call it don't change.
  • Nothing to do now.
  • P27 changes ref() and the browser test's check of the click.

Since P27, a test's messages name things by reference, not by @id.

  • A test names a card by reference through the player's new reference(), like Card#queen-of-spades, and hands it to trigger() as the target.
  • ref() was kept as it was: it still writes {"@id": ...}, for a message that wants an id.
  • A thing with no reference (no name, no place) still goes by its id, {"@id": "3"}.
  • The Quart app's browser test and the contract test check the click by reference.
