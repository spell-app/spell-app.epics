Once Python is in the contract, every machine that runs the tests needs Python 3.12 or later and uv, its package runner.

  • This laptop has both: Python 3.13 and uv 0.12.
  • A CI job, or another checkout on a fresh machine, has to install them first, or the Python half of the contract and of core's tests fails.
  • uv fetches the pinned Python by itself, so one install of uv is enough.
  • the setup steps (AGENTS.md, and any CI config) name Python and uv
