A reference by place, like Tableau#1, counts things in the order they were made; Python's core now keeps that list per core, the way drawable-thing's javascript core does.

  • Each core holds the things its program made, in the order made: things_made().
  • It holds them weakly, so a thing nobody uses any more can still be freed.
  • Left out of the count:
    • a plain List, which is never one of the program's things
    • things a test makes while it runs
    • a collection helper's scratch result, made inside quietly()
  • So thing_named(), thing_at_place() and reference_for() answer the same in Python as in javascript.
  • The page session still counts the things a page was sent, in order (J85): the same order, seen from the page.
