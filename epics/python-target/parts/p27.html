A page's event names the thing it happened to inside its details, by an id only Python's state knows: {"card": {"@id": "3"}}.

An event names its target in the reference words the drawable-thing epic brings: a string, or a list of them.

  • "target": "Card#3"
  • other references: Tableau#T1, UIButton#4

Its details are kept for the event's other details.

It waits for drawable-thing to merge into main; while it hasn't, the phase is parked.
