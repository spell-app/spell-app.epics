Python's pieces are spread over two packages: spell_core and spell-quart sit inside core, and the TypeScript that writes Python sits in parser, beside the javascript writers.

A new package, packages/py, holds everything Python: spell_core in its core folder, spell-quart in its quart folder, and the TypeScript that writes Python.

It is a yarn workspace like the others, @spell-app/py: it imports parser, and spell imports it for its Python target.

Every path naming the old places follows. Nothing a program compiles to or prints changes.
