In py/asyncio, a function that pauses is async def, and every call to it needs await. The writer can't always tell which method a call reaches (card.turn_over() could be any type's), so it goes by name: if one method called turn_over waits, every turn_over is async def.

A plain method may become async def because another of its name waits. Never an await on a plain value.Exact where spell knows the type, but a call it doesn't know would be left unawaited: Python then does nothing at all, silently.
  • Every call that waits is awaited.
  • Some methods are async that needn't be.
  • A function inside a method (a click's handler) counts as its own, but a loop's callback (for card in cards) counts as the method's.
