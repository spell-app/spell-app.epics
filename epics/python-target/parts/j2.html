Chose a new tree node, ASTOrdinalLiteral, a number said with an ordinal word, over a flag on each position rule.

  • The problem: "the first card" stays the first in a project counting from 0, while "card 1 of the deck" follows the setting. Both reached the writer as the same number, 1.
  • One place makes the new node, the ordinal rule.
  • Each writer counts it as its project does: javascript writes "first" as 0, counting from 0.
  • the ordinal rule builds an ASTOrdinalLiteral; every writer writes it as a plain number unless it says otherwise
  • no output changes counting from 1
