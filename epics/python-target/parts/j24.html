Chose one base class, SpellObject in things.py, for what a thing and a spell list share: declared properties, keyword set-up, create(), type, is_of_type(), JSON, and reading an undeclared name as None. In JavaScript a List isn't a Thing either; both extend Observable. List is SpellObject plus MutableSequence. to_json() returns plain dicts and lists all the way down, ready for json.dumps(), rather than nesting things, because Python's json has no toJSON hook.
