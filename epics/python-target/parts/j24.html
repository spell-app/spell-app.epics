Chose one base class, SpellObject, for what a thing and a spell list share.

  • What they share:
    • declared properties, and set-up by keyword
    • create()
    • their type, and is_of_type()
    • JSON
    • reading an undeclared name as None
  • In JavaScript a List isn't a Thing either: both extend Observable.
  • Python's List is a SpellObject, and a MutableSequence.
  • to_json() returns plain dicts and lists all the way down, ready for json.dumps(), rather than nesting things.
    • Why: Python's json module has no toJSON hook.
  • core.types_of(deck) also names Python's sequence bases (mutablesequence, sequence ...), as JavaScript's names observable
