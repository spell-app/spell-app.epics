position(0) gives a value that reads nothing, as spell's "item 0" does: spell counts from 1. It can't give -1, which is the last item.

  • javascript: position(0) is NaN. And deck.getItem(NaN) gives nothing.
  • Python: position(0) is None. And deck[None] gives None.
  • A 0 written out goes through position(0) too, not folded, so it reads nothing the same way.
  • Other numbers: position(2) is 1. And position(-1) stays -1.
  • Each platform's own "not a position", and the lists already read nothing for it.
  • Simplest sum, but "item 0" would read the last item.
  • "item 0 of the deck" reads nothing on every target, as before P23
