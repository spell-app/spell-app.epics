Chose to copy what the javascript run actually prints, checked with real Solid and linkedom on tricky drawings (pinned in tests/test_drawing.py), over HTML as a browser or Python's html module would write it, because the core contract compares the two line for line.

  • True / False as a child show true / false (the old stand-in showed nothing)
  • a class is split on spaces, each name once: " a a b " is a b
  • attributes sorted as written; only " escaped in a value; empty id / class / style left out; hidden bare, other True props name=""
  • text escapes & < > and a no-break space; style, script, textarea, title keep their text as it is; an empty SVG element closes itself
  • className is an attribute of that name, as Solid's h() treats it (the stand-in made it class)
  • NOT copied: form state Solid sets as a property (checked on an input), which linkedom never prints; Python prints it. No spell program draws one yet.
