Chose to copy what the javascript run actually prints, over HTML as a browser or Python's html module would write it, because the core contract compares the two line for line.

  • It was checked with real Solid and linkedom on tricky drawings, pinned in spell_core's test_drawing.py.
  • True and False, as a child, show true and false (the old stand-in showed nothing).
  • A class is split on spaces, each name once: " a a b " is a b.
  • Attributes:
    • sorted as written
    • only a double quote escaped in a value
    • an empty id, class or style left out
    • hidden bare; any other prop that's True written name=""
  • Text:
    • escapes & < >, and a no-break space
    • style, script, textarea and title keep their text as it is
    • an empty SVG element closes itself
  • className is an attribute of that name, as Solid's h() treats it.
    • The stand-in made it class.
  • NOT copied: form state Solid sets as a property (checked on an input).
    • linkedom never prints it; Python does.
    • No spell program draws one yet.
