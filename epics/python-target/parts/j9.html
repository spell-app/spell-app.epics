Chose JavaScript's answers over Python's in spell's tests, so the same expect passes or fails in both, and prints the same line.

  • An expect with nothing to compare counts yes as JavaScript does: an empty list is yes, where Python's own test says no. No: nothing, false, 0, empty text, not-a-number.
  • Equal is the JavaScript core's (lodash's): 3 equals 3.0, but true never equals 1; not-a-number equals not-a-number; a list equals a tuple with the same items.
  • A value in a line is written as JavaScript writes it: [1, None, True] shows as 1,,true.
  • One change from JavaScript: an error inside a test is written to stderr, where JavaScript drops it without a word. The test ends there, and prints its lines as usual, so stdout is the same.
  • the ✅ / ❌ lines match JavaScript's for the same program
  • a broken test says why on stderr, in Python only
