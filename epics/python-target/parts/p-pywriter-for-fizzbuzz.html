There is no Python writer, so --target py is refused.

A Python writer on the shared base, with Python's own text kit.

py joins the targets table, and FizzBuzz compiles and prints its 100 lines.

  • spell compile FizzBuzz --target py writes Python, and python3 runs it.
  • Python's text kit:
    • indented blocks, with pass in an empty one
    • Python's quoting
    • Python's own yes, no and nothing: True, False and None
  • py in the targets table:
    • its files end .compiled.py
    • it draws HTML text (Q2)
    • the contract's list of target files gains it
  • What FizzBuzz needs:
    • statements
    • if / elif
    • native for loops
    • a block passed along, as a one-line lambda or a def lifted above the call
    • functions, and the file's header
  • Python fixture snapshots (.snapshot.py); the rule tests keep checking JavaScript and TypeScript only.
  • Spell compiles to Python: spell compile @test/FizzBuzz --target py --stdout.
    • The output is in FizzBuzz.snapshot.py, beside the test program.
  • python3 runs it, and it prints the same 100 lines as the javascript.
  • It's the Python a person would write (Overview 1.2 has it whole):
    • def play_fizzbuzz():, with its docstring inside
    • for number in range(1, 101):
    • if (number / 15).is_integer():, then elif
    • print(number, "fizz")
    • it imports only what it uses: FizzBuzz imports nothing
  • A value prints through Python's own print() where Python prints it as spell does, else through the core:
    • print(): text, whole numbers
    • core.console.log(): the rest, e.g. yes / no
  • Not yet: things and lists, pauses, drawing.
    • The writer's test lists the 20 kinds of tree node still to write, for P10-P12.
