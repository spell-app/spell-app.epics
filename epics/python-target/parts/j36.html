Python can't await outside a function. So a top-level line that waits is:

  • a call alone: asyncio.run(reset_the_game())
  • set from one: card = asyncio.run(deal())
  • anything else (a loop): its own async def _step_1():, then asyncio.run(_step_1())
Reads like the spell, line for line.The textbook shape, but it moves every top-level line into a function, so the module's names stop being globals.
  • Each top-level step runs in its own event loop, one after another.
