Chose prop(init=Deck), called with no arguments as dataclasses' default_factory is, over JavaScript's init, which is called with the thing as this. It is what a Python programmer writes. A list, dict or set default raises TypeError saying to pass init=list, because every instance would share that one object. JavaScript's rule says the same (primitives only), but does not enforce it.
