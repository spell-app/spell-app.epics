Chose prop(init=Deck), called with no arguments, over JavaScript's way, where init is called with the thing as this.

  • It's what a Python programmer writes: dataclasses' default_factory works the same way.
  • A list, dict or set as a default raises a TypeError, saying to pass init=list.
    • Why: every instance would share that one object.
    • JavaScript's rule says the same (plain values only), but doesn't enforce it.
  • the writer emits init=Deck or init=list, never a list default
