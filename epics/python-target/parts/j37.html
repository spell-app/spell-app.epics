Type hints come from what spell already knows of each value (kindOf()): text is str, a choice bool, a thing its class, and a method that never returns a value -> None. Where spell can't tell, there's no hint at all, rather than Any.

  • A number is float: PEP 484 lets an int stand for a float, and spell has one kind of number.
  • | None when a return may give nothing: a method that may end without return, or returns the pile a card is in (Pile | None).
  • Every module with hints starts from __future__ import annotations, so a class can name one defined below it.
Reads clean; pyright infers the rest.Noisier, and Any turns pyright's checking off for that value anyway.
