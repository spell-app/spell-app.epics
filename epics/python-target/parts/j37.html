Chose type hints only where spell knows the kind of a value, and no hint at all where it can't tell, rather than Any.

  • What spell knows of each value (kindOf()):
    • text is str
    • yes or no is bool
    • a thing is its class
    • a method that never returns a value is -> None
  • A number is float, since spell has one kind of number.
    • PEP 484 lets an int stand for a float.
  • A return that may give nothing adds | None:
    • a method that may end without a return
    • one that returns the pile a card is in: Pile | None
  • Every module with hints starts from __future__ import annotations, so a class can name one defined below it.
Reads clean; pyright infers the rest.Noisier, and Any turns pyright's checking off for that value anyway.
