After the compile above, run the Python through spell_core's runner, from the repo root. spell run doesn't run Python yet (T4). 

uv run --project packages/py/core python -m spell_core.run /tmp/Solitaire/Solitaire.compiled.py --seed 1 --page --no-pauses
  • spell's test lines, ✅ each, ending with "it is the ace of clubs"
  • then a blank line, and the page's HTML on one long line: <div id="spell-app-root">, the board, "Klondike Solitaire", "Score: 0"
  • the same seed deals the same cards as the javascript run: spell run /tmp/Solitaire --seed 1 --no-browser prints the same test lines

Where the two runs differ, on purpose: printing a thing (a card, the game) shows each language's own dump, Python's Card(rank='queen', ...) against node's, on stderr (Q17). Every other line is the same.
