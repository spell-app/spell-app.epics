Owen chose a generated app file (Q25, B): compiling a program to py/asyncio writes a short Quart app beside it, every route spelled out. Chose its name, and what compiling again does to it.

  • Name: Solitaire.app.py, beside Solitaire.compiled.py, as the option in Q25 showed it.
    • One folder can hold several programs, so a bare app.py would clash.
    • It runs as a script, uv run python Solitaire.app.py; nothing imports it.
  • Compiling again (the cost Q25 named: a generated file a person edits):
    • its first line says it was generated, with a hash of what was generated
    • while the file still matches that hash, compiling rewrites it
    • once a person has edited it, compiling leaves it alone, and says so in one line
    • deleting it gets a fresh one at the next compile
  • The routes stay short: the work is in spell-quart (J44), so an edited app keeps working when spell-quart improves. 
# generated by spell compile Solitaire --target py/asyncio (sha 3f9c1e):  edit freely;  once edited, it is kept
from pathlib import Path

from quart import Quart, websocket
from spell_quart import Sessions, page_html, play

PROGRAM = Path(__file__).with_name("Solitaire.compiled.py")

app = Quart(__name__)
sessions = Sessions(PROGRAM)  # a game per visitor, each with its own core


@app.get("/")
async def page():
    return page_html(await sessions.current(), title="Solitaire")


@app.websocket("/ws")
async def events():
    await play(await sessions.current(), websocket)  # clicks in, drawings out

if __name__ == "__main__":
    app.run(port=5000)
