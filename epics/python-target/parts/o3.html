A project can say its lists count from 0, the way Python and JavaScript do: Owen's "let's try the first item is 0 here". Built in P2 · Lists Start At 0.

  • It's a setting in the project's project.json: "listsStartAt": 0. Without it, lists count from 1, as today.
  • It works for every target, the JavaScript ones too.
  • The core's methods respect it (Owen: "core methods in JS should respect listStartAt"):
    • each method that takes or returns a position takes a startAt too, 1 when left out
    • compiled code passes its own project's setting on every call
    • per call, not one switch for the whole program: a library counting from 1 and a program counting from 0 can share one core, and neither reads the wrong item
  • Ordinal words don't change: "the first card" and "the last card" mean the same either way.
  • Only NUMBERS change: "item 3 of the deck", "the position of the queen", a loop's position.
    • "position of queen in card ranks" is 12 counting from 1, 11 counting from 0.
    • "position of joker in card ranks" is still nothing, never -1 or 0.
  • Negative positions don't change: -1 is the last item, -2 the one before, whatever lists start at. It's Python's own deck[-1].
  • The hover text and the Type Explorer say "counts from 0" in a project set so.
  • In Python, the writer writes native indexes: deck[0], deck[-1], deck[2:5]. Spell's ranges include their end, so a slice's end gets 1 added: "items 3 to 5" counting from 0 is deck[3:6].
  • Where it reaches: 11 places in spell's rules write one of the core's position methods (get an item, find a position, two kinds of range, two kinds of remove), plus a loop's position.

These are fixed first in P2, each with a test, before counting from 0 is added on top.

  • On a spell list, "item 0" reads the SECOND item.
    • A spell list turns spell's position into JavaScript's index with a small helper. For 0 it returns 1, and index 1 is the second item.

  • On a plain list (not a spell list), "item -1" reads nothing, and "remove item -1" removes the second-to-last item.
  • "the last two cards of the deck" returns ONE card: it asks for 2 cards starting at the last one.
