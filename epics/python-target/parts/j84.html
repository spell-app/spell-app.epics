A page's event can now name the thing it happened to, and the handler gets that thing two ways: event.target, and under its type's Python name (event.card for a Card).

  • Solitaire's handlers are written with the card, and read event.card in Python.
  • Keeping that name means every program already written runs unchanged.
  • A list of targets reaches the handler only as event.target: no single type name fits it.
Handlers written for with the card work unchanged, and new ones can read the target.Every handler that reads event.card would need rewriting.The page would have to know the handler's words; more to send, for no gain.
  • Solitaire's card click works with a target by reference, its handler untouched.
  • A thing whose type's name clashes with another of the event's details: the target wins.
