Chose the way JSON-LD points at a thing already written, over the {"@ref": 17} the phase goal sketched.

  • The first mention of a thing is whole, with its "@id" after its "@type".
  • Each later mention is an object holding the id alone: a card held by a pile and by the game is one card, read back.
  • Why: the JSON already follows JSON-LD for "@type", so "@id" keeps one convention, not two.
  • Ids are text, "1", "2" and on, not numbers, as JSON-LD has them; each writer counts its own (the next call).

  ],
  "top": { "@id": "3" } }
