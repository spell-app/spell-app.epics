Chose to tidy spell_core with core's own scripts over a separate command, so yarn review in core keeps the Python as tidy as the TypeScript.

  • Core's test script runs pytest after vitest; its lint and format scripts run ruff after oxlint and oxfmt.
  • So core's scripts now need uv on the machine, as this laptop has.
  • uv runs Python 3.13, the one installed, written in a .python-version file.
    • The package still says 3.12 or later, and ruff holds the code to 3.12.
  • The package can be installed (it has a build backend, uv's own), so a compiled program can install it rather than borrow its path.
  • pytest 9.1.1 and ruff 0.17.0, pinned, in the dev group: spell_core itself needs nothing but Python.
  • From the repo root: uv run --directory packages/core/py pytest. The brief's form, with --project, works too, but searches the whole repo for tests first.
  • Since P21, all of this is py's, not core's:
    • spell_core sits in py's core folder
    • py's scripts run pytest and ruff, and core's run its javascript only
    • from the repo root: uv run --directory packages/py/core pytest
  • yarn test and yarn review in core cover the Python
  • a machine without uv can't run core's scripts
