For P23, Positions From 0. Owen's design (cm5, cm9, cm10): compiled javascript and Python always count from 0, and spell code counting from 1 goes through a position() helper. That leaves one choice: whether the javascript core's own list methods, which count from 1 today, simply change, or stay beside new ones.

  • Today, in the javascript core, list.getItem(1) is the FIRST item, and every position method takes a last startAt, 1 when left out.
  • Python's spell_core mirrors it: deck.get_item(column) counts from 1, start_at=0 to count from 0.
  • Who calls them: compiled programs (all of them), the 12 compiled examples committed in spell's system projects, and a little hand-written javascript in core and app. 
# today:  a variable position goes through the 1-based core method
tableaus.get_item(column).append(stock.last_item)
foundations[1]                        # foundation 2:  already worked out as it compiles
# after:  the core counts from 0;  the compiled code converts
tableaus[position(column)].append(stock.last_item)
foundations[1]                        # unchanged
  • getItem(), positionOf(), between() and the rest count from 0 in both cores, with no startAt.
  • One way of counting in the core, so a port can't get it wrong, and Python's list reads as any Python list.
  • Breaks: any program compiled before this reads the wrong item until it's compiled again. The 12 committed examples are compiled again in the phase, and it checks how the editor's runners load a program, so none runs stale javascript.
  • Every pinned output is blessed again; what programs PRINT must not change.
  • getItem(1) stays the first item; new methods count from 0, e.g. itemAt(0), and compiled code uses those.
  • Nothing already compiled breaks.
  • Two ways to count in one core, forever: twice the methods to port and test, and the old ones only for old code.
  • the cores count from 0; startAt / start_at gone from every method
  • listsStartAt stays a project setting, read only by the compiler
  • every compiled program and fixture snapshot written again, in the one phase
