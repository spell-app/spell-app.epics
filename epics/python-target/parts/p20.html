A compiled Python program can't be used as an app: nothing serves its page, and nothing carries a click back to Python.

A Quart app (Flask's asyncio twin, Q23) serves a program compiled to py/asyncio: its page, drawn with P19's web components, and one WebSocket per page (Q22).

Up the WebSocket go events; down it go the whole state when the page opens (P17), then only the changes (P18) after each event and at each pause.

Each visitor's session plays its own game (Q24). Compiling writes an app file beside the program (Q25), on a new package, spell-quart (Q26); spell_core stays standard library only.
