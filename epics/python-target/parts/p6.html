Python has no runtime: nothing for compiled Python to import.

A Python package, spell_core, beside the JavaScript core, tested by core's own yarn test.

The basics first: the console, spell's tests, ranges, types, equality, and the same random as the JavaScript core.

  • spell_core lives inside the core package, beside the JavaScript it ports (Q6):
    • a pyproject.toml and a spell_core folder, the standard Python layout
    • pytest for its tests and ruff to keep it tidy, both through uv run
    • core's yarn test runs them, so yarn review does too
  • The console prints what JavaScript prints:
    • groups indented the same
    • 3.0 prints as 3
    • true and false, not Python's True and False
  • Spell's tests: expect, and the ✅ / ❌ lines.
  • Ranges, types and equality.
  • The same generator and shuffle as the JavaScript core: one seed deals the same cards in both.
  • A test checks spell_core against the core's method list, in snake_case; a missing method fails it, unless it's listed as not ported.
