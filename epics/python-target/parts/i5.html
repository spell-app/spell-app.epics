Thing and List now read any undeclared public name as None, so a compiled self.name or 'pile' works as spell's does. Python's own idioms lose their footing, though. hasattr(card, 'anything') is always True, and getattr(card, 'x', 0) gives None, not 0. A misspelt method call fails as 'NoneType' object is not callable rather than naming the attribute. Dunders and _private names still raise AttributeError.

  • the writer reads an undeclared property only where spell does; hand-written Python should use x or default, not getattr(x, name, default)
