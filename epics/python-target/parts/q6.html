Where does spell_core live in the repo, and how do its own tests run?
  • A folder of its own, core-py, in the standard Python package layout:
    • its code in src/spell_core/
    • a pyproject.toml
  • A small package.json makes it a workspace, so yarn test runs its tests.
    • So does yarn review.
    • Both with uv run pytest.
  • Python's own formatter and linter (ruff) keep it tidy, run the same way.
  • A compiled program finds it on PYTHONPATH; later it could be published as a pip package.
  • In a py folder inside core, spell_core, beside the JavaScript core it ports.
  • One package, two languages; core's yarn test runs both.
  • a new package, core-py, in the packages table of the root AGENTS.md
  • Python tooling, pinned in its pyproject.toml:
    • uv
    • pytest
    • ruff
