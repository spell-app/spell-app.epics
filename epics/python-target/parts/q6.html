Where does spell_core live in the repo, and how do its own tests run?
  • packages/core-py/, with src/spell_core/ and a pyproject.toml: the standard Python package layout.
  • A small package.json makes it a workspace, so yarn test and yarn review run its tests with uv run pytest.
  • Python's own formatter and linter (ruff) keep it tidy, run the same way.
  • A compiled program finds it on PYTHONPATH; later it could be published as a pip package.
  • packages/core/py/spell_core/, beside the JavaScript core it ports.
  • One package, two languages; core's yarn test runs both.
  • a new package, packages/core-py, in the packages table of the root AGENTS.md
  • Python tooling: uv, pytest, ruff, pinned in its pyproject.toml
