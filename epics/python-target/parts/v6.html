Solitaire, compiled to Python and served by Quart, plays in the browser like the javascript version, each click running in Python. A second browser gets a game of its own.

  1. In app, build the page side once: yarn build:page.
  2. Copy Solitaire to a scratch folder: cp -R packages/spell/projects/test/Solitaire /tmp/.
  3. Compile it: spell compile /tmp/Solitaire --target py/asyncio.
  4. Serve it: uv run --project packages/core/py-quart python /tmp/Solitaire/Solitaire.app.py.
    • Port 5000 taken (AirPlay, on a Mac): put PORT=5050 in front, and use that port below.
  5. Open http://localhost:5000.
  6. Click the stock, press AutoPlay, click a playable card.
  7. Open the same address in a second browser, or a private window.
  • The page shows a dealt Solitaire board.
  • Clicking the stock turns a card over onto the discards.
  • AutoPlay moves cards one at a time, the board changing at each step, not all at once.
  • A playable card moves where it goes.
  • The second browser is dealt a different game, and clicks there leave the first one alone.
  • A second tab in the SAME browser shows the same game, and follows the first tab's clicks.
