A drawable type's element is defined by the page's javascript, not by Python, so the compiled Python leaves that line out.

  • A drawable type in spell compiles to a javascript line like static elementTag = spellCore.defineElement(this, "test-project").
  • That line is browser code: it registers <solitaire-card> with the browser.
  • Python has no browser; the page's elements file, which keeps the line, defines the element there.
  • Written into the Python, it was raw javascript that pyright flagged: leaving it out fixed 12 errors.
Python keeps only what Python runs; the page defines its elements.A Python element_tag nothing reads, kept only so the two outputs line up.
  • DrawableSolitaire and CardTable compile to Python with no pyright errors.
  • Python code that wants a type's tag name has none to read; nothing needs one today.
