Compiling a program to py writes its app file, but not the files of the projects it imports. An app for such a program won't start until they are copied in by hand.

  • Missing beside the app, for each imported project:
    • its Python module, e.g. cards.py for from cards import Card
    • its drawing half, its .elements.js file, which the page loads
  • Solitaire imports nothing, so it works as compiled.
  • Klondike imports the cards project, so it would need both copied by hand.
  • The fix is the todo to copy them when compiling (T5).
  • for now, only programs that import no project run as Python web apps unaided
