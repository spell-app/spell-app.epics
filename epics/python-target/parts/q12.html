Each of spell's rules has tests that say what it compiles to in JavaScript and TypeScript. Python doesn't get a third slot in each of them.

  • Python is checked two ways instead:
    • fixture snapshots: each test program's whole .compiled.py, compared to a saved copy
    • the contract: each program run, its output compared line for line with JavaScript's
  • Why: hundreds of rule tests would each need a Python line written by hand, for little more than the snapshots catch.
  • The cost: a rule that compiles wrong in Python, and isn't used by any test program, slips through. The rule's own test can gain a Python line when that happens.
  • rule tests keep their JavaScript and TypeScript lines only
  • Python snapshots (.snapshot.py) from P8, the contract from P9
