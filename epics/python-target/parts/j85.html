A reference by place, like Tableau#1, counts the things the page was sent, in the order they were sent.

  • The page makes its copies of the things in that order, so "the first tableau" means the same thing on both sides.
  • Python's core keeps no list of the things a program made, so it has no creation order of its own to count.
  • The state writer now lists the things a page was sent, in order (things_given_ids()).
A place means the same thing in Python and on the page.Python's core keeps no list of things made; and the page's copies are made in state order anyway.
