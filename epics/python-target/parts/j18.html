Chose to register each Thing and List class as Python defines it (__init_subclass__), over JavaScript's way.

  • JavaScript's things.classNamed() learns a class once one of its things is made, or once the runner hands it the program's modules.
  • Python has no runner step that hands over the modules.
  • And a class defined in the program is one it can read back.
  • core.from_json() finds any class the program defined, made or not
  • a class defined again under the same name replaces the one before
