Python draws only HTML text, so a Python program can't show its widgets anywhere by itself.

Study the terminal libraries: Textual and Rich for Python, against Ink for JavaScript.

Prototype Solitaire's board in the terminal, then write up the findings and a recommendation.

  • Owen: "Check out Ink for a possible solution here -- python programs could translate widgets/etc into CLI programs. Explore what is possible before doc review".
  • What's looked at:
    • Textual, for Python: widgets, CSS and events in the terminal
    • Rich, for Python: styled text, tables and layout in the terminal
    • Ink, for JavaScript: React for command-line apps, which the spell CLI already draws with
  • A prototype: Solitaire's board drawn in the terminal from the same to draw methods.
  • The findings go into a new Overview section, with a recommendation: a py/terminal target, as a future epic, or not (a todo waits on its answer).
  • The same to draw methods can draw a terminal.
    • A prototype draws Solitaire's board three ways from one element tree: HTML, a still Rich picture, and a live Textual board.
    • Clicking a card on the Textual board fires spell's card-click.
