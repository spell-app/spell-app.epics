The generated app file starts its server on port 5000 unless $PORT says otherwise, and $SPELL_SEED fixes the random numbers so every visitor is dealt the same game.

  • 5000 is Flask's and Quart's usual port.
  • macOS often holds port 5000 (AirPlay Receiver), so PORT=5050 is the way round it.
  • $SPELL_SEED left unset: each visitor gets a different game.
if __name__ == "__main__":
    # $PORT, if set:  5000 is often taken on a Mac (AirPlay)
    app.run(port=int(os.environ.get("PORT", "5000")))
  • The framework's usual port, and a way round it.
  • Avoids AirPlay, but not what Quart's docs show.
  • the app serves at http://localhost:5000, or the port in $PORT
