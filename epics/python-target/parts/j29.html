Chose to have h() build an Element, a tag with attributes and children, which str() writes as HTML, over returning HTML text at once.

  • Tests, and later targets such as the terminal study's Textual board (P15), can read a tree.
  • The page needs one live spot, the mounted app, that a finished string can't hold.
  • h() works out what the page would hold as it's called: handlers left out, functions called, classes tidied.
  • The second argument is props only when it's a dict or None: h("thead", h("tr", ...)) works.
