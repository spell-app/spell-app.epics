spellCore.console.log() and info() print plain data as before. A line holding anything else, e.g. a thing or a spell list, goes through spellCore.console.printDump().

Chose a hook over deciding the stream inside the core, because a browser's console has no streams:

  • by default the hook is console.log, so the app and the page's console show the line as before
  • the node runner (runProject.ts) points it at console.error, so it lands on stderr

Plain is what Python's core counts as plain: text, numbers, yes / no, nothing, and plain lists and objects, whatever is in them. A group heading that is a dump goes through the hook too, then an unnamed group opens, as Python's core does it.

The page's own console (spellCore.console.lines) keeps every line, dump or not.
