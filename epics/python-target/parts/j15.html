Besides spellCore.seedRandom(seed), the core gains two names Python's core already has:

  • spellCore.random(): the next number, the core's own Math.random()
  • spellCore.shuffled(items): lodash's shuffle, step for step (J8), on that random; randomItemsOf() and randomize() call it

Chose public names over a hidden helper, because Python's core has random() and shuffled(), and a test can stand in for them (the tests that stubbed lodash's shuffle now stub shuffled()).

The generator itself is a module variable, not a name on spellCore, so it isn't in the method list. Unseeded, it starts from a seed picked with Math.random(), as the brief asked.

seedRandom() doesn't check its seed, as Python's doesn't. spell run and spell test do: --seed takes a whole number from 1 to 2147483646, and anything else stops with a message, since 0 would give only zeros.

  • spell run --seed 0 says: --seed takes a whole number from 1 to 2147483646, not 0
  • lodash is no longer used for any random
