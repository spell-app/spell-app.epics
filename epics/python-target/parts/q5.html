  • Modern idiomatic Python has hints: editors use them for completion and errors.
  • The writer already knows most kinds (the TypeScript writer writes them).
  • pyright, the checker VS Code's Python extension uses, is an npm package: it runs from the repo with no Python install.
  • Hints wherever the kind is known; pyright as the target's checker, like tsc.
  • A wrong hint fails the fixture tests, as a wrong TypeScript type does.
