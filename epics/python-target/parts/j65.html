P22 made the asyncio writer the only Python writer. It did that by renaming, not by rewriting:

  • PyAsyncWriter became PY.PyWriter, the Python target's writer.
    • It still decides which functions wait, and writes them so:
      • those become async def
      • their callers await them
      • the top level runs through asyncio.run()
  • The old plain PyWriter became PY.PyBaseWriter, which writes everything but waiting.
    • Nothing uses it on its own any more: it is only what PyWriter builds on.
  • A program that never waits comes out as plain Python: FizzBuzz's snapshot is unchanged.
  • Every program's Python is exactly what the asyncio target wrote before, which the snapshots prove.
  • Two classes stay where one would do.
  • One class, no base nobody else uses.
  • A big hand edit of about 1,400 lines in the same phase that changes every snapshot, so a slip is harder to see.
  • the py package's ts folder has two writers:
    • PyWriter.ts
    • PyBaseWriter.ts
  • PyAsyncWriter.ts is gone
  • a later tidy may fold PyBaseWriter into PyWriter, with the snapshots as its check
