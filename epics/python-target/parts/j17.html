test_core_declarations.py (I1) checks spell_core has each name in the method list, snake_cased: getItemAt is core.get_item_at, isANumber is is_a_number, ACTIVE_TEST is active_test. A class keeps its name, on the package: spell_core.Thing.

NOT_PORTED_YET holds the 109 names Python lacks today, grouped by the phase I expect to port them:

  • P10: things, lists and JSON
  • P11: pauses and events
  • P12: drawing
  • not yet decided: names where Python may use its own word (absoluteValue is abs()), or that only a browser needs (alert, prompt)

Chose to also fail when a listed name IS ported, or isn't in the method list at all, so the list can't go stale.

  • porting a name means taking it out of NOT_PORTED_YET in the same change
  • a name the JavaScript core gains fails in Python until it's ported or listed
