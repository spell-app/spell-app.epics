A compiled Python program can't be used as an app: nothing serves its page, and nothing carries a click back to Python.

A Quart app (Flask's asyncio twin, Q23) serves a program compiled to py/asyncio: its page, and one WebSocket per page carrying clicks up and new drawings down (Q22).

Each visitor's session plays its own game, with its own core and its own run of the program, in one process (Q24).

Compiling writes an app file beside the program (Q25), on a new package, spell-quart (Q26); spell_core stays standard library only.
