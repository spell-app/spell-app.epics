Chose ids that belong to the writer, not to the things: a writer numbers each thing the first time it writes it, and keeps that number.

  • A page gets a writer of its own, so its ids count from "1", in the order that writer first wrote things.
  • One writer names a thing the same in every state and patch it writes after.
  • Two writers may name the same thing differently: an id means something only to the page it was sent to.
  • Why: an id stored on the thing would be shared by every page and session that reads it.
    • A page could name a thing it was never sent.
    • Every thing made would use up an id, written or not.
