From the repo root, copy the frozen test project first: compiling writes beside it, and the test projects must never change. 

cp -R packages/spell/projects/test/Solitaire /tmp/Solitaire
spell compile /tmp/Solitaire --target py
  • a green tick, and a line saying which files it wrote, with no pyright errors: every test program's Python has been pyright-clean since P25 (C3)
  • beside the project:
    • the Python, Solitaire.compiled.py
    • its words file, Solitaire.py.en.json
    • its drawing half, Solitaire.elements.js (P19)
    • its web app, Solitaire.app.py (P20)
  • there is no --check flag: pyright runs on every Python compile by itself
