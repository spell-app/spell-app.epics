A compiled Python program has no page: its drawing exists only as HTML text printed when it ends, nothing a browser can show live, or click.

Compiling to py also writes the program's drawing half as JavaScript, with the javascript target's writer (Q20, A, revised): web components, custom elements like <solitaire-card>.

Their things are mirrors of Python's, read from P17's state by id and patched with P18's changes. Python keeps the logic.

A click goes back as a message naming its thing by id; nothing the page runs changes the game.
