The page knows Python's things only as attributes on their elements: flat values, nothing a thing holds (a pile's cards, the game's score), and a card drawn in two places is two strangers.

With each drawing, Python also sends the whole state as JSON: every thing once, with an "@id", and each later mention a reference to that id (Q21, A).

The page keeps a stand-in ("mirror") for each thing, updated in place by id, and each element with that spell-id can read its whole thing.
