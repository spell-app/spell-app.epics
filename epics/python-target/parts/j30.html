Chose to mount the app as a LIVE drawing, drawn each time the page is written, over drawing it once at start the game.

  • core.mount_app() keeps a function that draws it.
  • Why: cards move after the game starts, and the javascript run's page, which redraws itself, shows the final state when it ends.
  • App.start() puts the app's root element on the page, <div id="spell-app-root">; the app inside it is drawn later
  • python -m spell_core.run --page writes the page at the end of main()
