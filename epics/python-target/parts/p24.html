  • The answer to his question: yes, math.floor(x + 0.5), which is exactly javascript's Math.round(). spell_core already uses it, to measure text as javascript does.
    • Python's built-in round() is "banker's rounding": a half goes to the even neighbour.
    • decimal's ROUND_HALF_UP takes a half away from zero, so -2.5 becomes -3, where javascript gives -2.
  • Rounding a half, compared: 
    #  x      javascript Math.round   Python round()   math.floor(x + 0.5)   decimal ROUND_HALF_UP
#  2.5    3                       2                3                     3
#  3.5    4                       4                4                     4
# -2.5   -2                      -2               -2                    -3
  • Both cores get three methods: round (a half up), round up, round down. Their names are Q29 (recommended: as the javascript core's, core.round_up(x) in Python).
  • Round up and down are Math.ceil() / Math.floor() and math.ceil() / math.floor().
  • Rounding to a number of places ("to the nearest tenth") stays out: the spell rule has no words for it yet.
