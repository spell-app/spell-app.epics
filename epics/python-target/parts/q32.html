For P28, Drawable Elements: what a drawable type's tag is named.

  • On the card's drawing in Solitaire's elements file, h("div", { class: ... }), Owen asked (cm13): "wouldn't this be `<game-card>`?"
  • Yes, a card should be an element of its own; the question is what he meant by its name.
  • Today the core names a drawable type's tag from its PROJECT and its type: elementTagFor("Solitaire", "Card") is solitaire-card.
  • The drawable-thing epic writes the same names, and drops the word "drawable" from a project's name: Drawable Solitaire's tableau is <solitaire-tableau>.
  • A project named "games" would give <game-card>, since the project's name is made singular. None of the test projects is named that. 
elementTagFor("Solitaire", "Card")           // "solitaire-card"
elementTagFor("games", "BankAccount")        // "game-bank-account"
elementTagFor("Todos - Form Based", "Task")  // "todos-form-based-task"
elementTagFor("", "Card")                    // "spell-card"
