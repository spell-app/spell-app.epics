Owen chose, on Q31 (D), "spell's knowledge, else assert". This is the first half: where the program itself has just checked, compiled code trusts the check.

  • After a guard that a list is empty (if the pile is empty return 0), its first and last items are there for the rest of the method. The writer remembers the guard (ProgramWriter.noteGuard()).
  • Cards' Pile.value, before: 
    @property
def value(self) -> float | None:
    if not self:
        return 0
    return getattr(self.last_item, "value", None)
  • After: 
    @property
def value(self) -> float:
    if not self:
        return 0
    return self.last_item.value
  • javascript reads it the same way: this.lastItem.value, not this.lastItem?.value.
  • A getter's hint is now worked out after its body is written, so it sees the guard: Pile.value is -> float, no longer float | None.
  • This took out the "None" errors on a pile's last item (Klondike 161 and 163, OutlineSolitaire 531 and 533, Solitaire 509).
  • Reads as a person would write it, in both languages; no extra line.
