The same Solitaire copy, run with its pauses, from the repo root. Since P22 the one Python target, py, is on asyncio, so its pauses wait; there's no second target to compile any more. 

uv run --project packages/py/core python -m spell_core.run /tmp/Solitaire/Solitaire.compiled.py --seed 1
  • open Solitaire.compiled.py first: a card's "turn face up" is an async def that ends in await core.pause_for(50, "msec")
  • the run prints the same lines as the --no-pauses run in V2, but slowly: about 7 seconds in all, the lines coming in bursts as each pause waits
  • run again with --no-pauses: the same lines, at once

The same Solitaire copy, on the second Python target, from the repo root:

spell compile /tmp/Solitaire --target py/asyncio
uv run --project packages/core/py python -m spell_core.run /tmp/Solitaire/Solitaire.compiled.asyncio.py --seed 1
  • the compile writes Solitaire.compiled.asyncio.py: open it, and a card's "turn face up" is an async def that ends in await core.sleep(50, "msec")
  • the run prints the same lines as the plain py run, but slowly: about 7 seconds in all, the lines coming in bursts as each pause waits
  • run again with --no-pauses: the same lines, at once
