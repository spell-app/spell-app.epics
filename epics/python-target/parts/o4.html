spell_core is the Python twin of the core: what compiled Python imports to do what Python has no word for.

  • What it ports (about 3,000 of the core's 4,450 lines are plain logic):
    • things, with declared properties (a plain dictionary, no reactivity)
    • spell lists: owners ("a card belongs to one pile"), guards, moving between lists
    • types and equality
    • spell's tests: expect, the ✅ / ❌ lines, the indented groups
    • events (on, trigger) and processes
    • pauses
    • JSON with "@type" and "@items"
    • the seeded random the contract uses, and lodash's shuffle, so Solitaire deals the same cards
  • What it doesn't: drawing with Solid, the page, the Thing Explorer's registry, and the old names marked deprecated.
  • A machine-readable list of the core's methods (the core contract's, about 119) is written first, and a test checks spell_core against it, so the port can't miss one.
    • Already found by looking: spell writes absoluteValue, which the core doesn't have.
  • Python 3.13 and uv are on this machine; no Python is in the repo yet.
