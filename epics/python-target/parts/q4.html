When a program prints a thing (print the card), JavaScript prints node's own dump of the object. Python can't print the same, and the contract compares the lines. What should printing a thing show? 

Card {
  Symbol(props): Map(3) { 'rank' => 'queen', 'suit' => 'spades', 'direction' => 'up' },
  Symbol(state): null,
  Symbol(propCells): null,
  ...
  • It shows node's insides (symbols, maps), not what the card is.
  • Cards, Solitaire, Klondike and OutlineSolitaire all print one.
  • Each core prints a thing as its type and its properties, the same way: Card(rank: queen, suit: spades, direction: up).
  • JavaScript's output changes too: the contract snapshots are updated once.
  • In Python it's the thing's __repr__, so the REPL shows it too.
  • JavaScript stays as it is; Python's core prints Symbol(props): Map(3) {...} by hand.
  • Odd Python, and it breaks whenever node changes its format.
  • Each target prints its own way; the contract ignores lines that print a thing.
  • printing a thing shows Card(rank: queen, ...) on every target, in the editor's console too
  • the four contract snapshots that print a thing are updated, in the phase that adds it
