A repeatable random becomes part of the core itself. Owen: "add runtime seed mechanism to JS/spellcore".

  • Today the contract gets the same deal every run by replacing JavaScript's Math.random from outside, before the program loads.
  • Python can't share that trick, and the shuffle goes through lodash, which Python doesn't have.
  • So the core gets:
    • spellCore.seedRandom(n), after which every random is repeatable
    • its own number generator and its own shuffle, written so Python's core can copy them exactly
  • The same seed deals the same cards in JavaScript and Python, so Solitaire prints the same game.
  • Built in P5 · Core List And Seed; Python's twin in P6.
  • the Math.random patch goes from the contract's runner
  • a run takes a --seed option
