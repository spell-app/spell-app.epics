Chose to write the page's classes as the javascript writer writes them, methods and getters included, and to send Python only what changes the program.

  • The elements file is the javascript writer's output, with the program's top-level steps left out: dealing, tests, starting the game. Python ran those.
  • What goes to Python:
    • a call of a thing's method inside a drawing's click handler
    • an event, wherever it is triggered
    • a top-level function, through a stand-in that sends the call
  • A class's methods stay as local copies on the page: drawing reads its getters, so they must answer on the page, at once.
  • A getter that called a top-level function would send Python a message while drawing.
    • None of the test projects do. It is a gap to watch, not a bug today.
