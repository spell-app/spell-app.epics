The goal is Python a Python programmer would write by hand and happily edit: Owen's "as idiomatic as Python can possibly be".

  • Names follow PEP 8, Python's style guide (Q9):
    • functions, methods, variables and properties in snake_case: play_fizzbuzz, turn_face_up
    • classes in PascalCase: Card, BankAccount
    • constants in SCREAMING_SNAKE_CASE, capitals joined by underscores: Card.RANKS
    • a name that clashes with a Python keyword gets a trailing underscore, PEP 8's own rule: class_ (Q14)
  • Native loops, not callbacks: for number in range(1, 101):, not core.map(..., each_number).
  • Native operators where the kinds are known: a == b, f"{rank}-of-{suit}", x in ("diamonds", "hearts").
  • Getters are @property; stored properties are declared in the class body, the way dataclasses and Django do it.
  • A spell list is a real Python sequence: deck[0], len(deck), for card in deck, if not deck.
  • The core is called only where Python has no word of its own (spell's test lines, a seeded shuffle, a pause).

def play_fizzbuzz() -> None:
    for number in range(1, 101):
        if (number / 15).is_integer():
            print(number, "fizzbuzz")
        elif (number / 3).is_integer():
            print(number, "fizz")
        elif (number / 5).is_integer():
            print(number, "buzz")
        else:
            print(number)

# a card is a thing
# cards have a rank as one of ace, 2, 3, ..., jack, queen or king
# the color of a card is red if its suit is either diamonds or hearts otherwise it is black
# the value of a card is the position of its rank in card ranks
# a card "is face up" if its direction is up
# a card "is a (suit)" for its suits
# the name of a card is: its rank + "-of-" + its suit

class Card(Thing):
    """Definition of a card, with nice English aliases for working with it."""

    RANKS = ["ace", 2, 3, 4, 5, 6, 7, 8, 9, 10, "jack", "queen", "king"]
    SUITS = ["clubs", "diamonds", "hearts", "spades"]

    rank = prop(one_of=RANKS)
    suit = prop(one_of=SUITS)
    direction = prop(one_of=["up", "down"])

    @property
    def color(self) -> str:
        return "red" if self.suit in ("diamonds", "hearts") else "black"

    @property
    def value(self) -> int | None:
        return core.position_of(Card.RANKS, self.rank)

    @property
    def is_face_up(self) -> bool:
        return self.direction == "up"

    def is_a_suit(self, suit: str) -> bool:
        return self.suit == suit

    @property
    def name(self) -> str:
        return f"{self.rank}-of-{self.suit}"

    def turn_face_up(self) -> None:
        self.direction = "up"
        core.pause_for(50, "msec")
 
export class Card extends Thing {
  static Ranks = ['ace', 2, 3, 4, 5, 6, 7, 8, 9, 10, 'jack', 'queen', 'king']
  static { this.declareProp('rank', { oneOf: Card.Ranks }) }
  get rank() { return this.getProp('rank') }
  set rank(value) { this.setProp('rank', value) }
  get value() {
    return positionOf(Card.Ranks, this.rank)
  }
  isASuit(suit) {
    return this.suit === suit
  }
  get name() {
    return `${this.rank}-of-${this.suit}`
  }
