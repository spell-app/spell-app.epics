  2. Skim a few files' sections, and the "Not in Python yet" section.
  3. Hover a "not yet" cell, and a section title's code icon.
  4. Narrow the window to phone width.

  • Each row: the name, its parameters, a line of description, its Python name.
  • A "not yet" cell's tooltip says why; the code icon's tooltip is the file's path, and a click opens it.
