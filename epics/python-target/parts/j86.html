A reference's type, the Card in Card#3, is looked up among the things themselves, not in spell_core's class registry.

  • The Python server runs the program once per visitor, and each run defines its own classes.
  • The registry keeps only the last run's classes.
  • So a lookup by name in the registry would miss an earlier visitor's things.
  • The things carry their own classes, so looking among them always finds the right one.
Right with any number of visitors.Wrong as soon as a second visitor starts a game.
  • References work for every visitor on the same server.
  • The registry's own trouble with several visitors is a suspected issue of its own.
