The page client is the one script every Python app's page loads: it sends clicks to Python and swaps in what Python draws. Chose where it lives and how it swaps.

  • Where: core's TypeScript, a folder of its own, web/, built to one file.
    • It is the page half of spell_core's web mode (J42), so it sits beside the core it talks to.
    • It imports nothing of the spell runtime or Solid: Python draws, the client only swaps.
    • P20's package, spell-quart, carries a copy of the built file.
  • How it swaps: idiomorph, htmx's morphing library (about 3 KB), keyed by spell-id.
    • Morphing: the new HTML is compared with the page, and only what differs is changed.
    • So a card that moves between piles stays the same element, and focus and scroll stay put.
    • Over writing a morph of our own: it is small, tested, and made for exactly this.
  • How messages travel is the host's: P19's test records them; P20 sends them over a WebSocket.
  • a new entry in core, the page client, with a browser test on headless Playwright
  • one npm dependency for core, idiomorph, pinned
