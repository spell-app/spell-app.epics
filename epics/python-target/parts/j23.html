Chose to read each callback's signature, with inspect.signature, and pass it only as many of value, position and list as it takes.

  • So these work:
    • deck.filter(lambda card: card.rank == 'queen')
    • deck.map(str.upper)
  • The other choice: always pass three, as JavaScript can, so every Python lambda spells out card, _position, _list.
  • A function whose signature Python can't read, a builtin like str, gets the value alone.
  • A condition's answer is read as JavaScript reads it (is_js_truthy()).
    • So filter() with no condition keeps empty-list items, as JavaScript does.
  • the writer can emit one-argument lambdas
