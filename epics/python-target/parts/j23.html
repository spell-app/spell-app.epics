Chose to read each callback's signature (inspect.signature) and pass it only as many of (value, position, list) as it takes. That lets deck.filter(lambda card: card.rank == 'queen') and deck.map(str.upper) work. The alternative was always passing three, as JavaScript can, which makes every Python lambda spell out card, _position, _list. A function whose signature Python can't read, a builtin like str, gets the value alone. A condition's answer is read as JavaScript reads it (is_js_truthy()), so filter() with no condition keeps [] items, as JavaScript does.
