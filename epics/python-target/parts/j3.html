Q15 said javascript counting from 0 uses its own words, deck.at(n) and deck.slice(2, 5). I used at() for an item, but kept ranges on the list's own between(start, end, 0). Why: spell's ranges include their end and take negative ends, so "cards 2 to -1" is everything from the third card on. slice(2, -1 + 1) would be empty.

  • right for every range spell can say
  • more javascript-like; wrong for a negative end
  • cards 0 to 3 of the deck => deck.between(0, 3, 0)
  • Python can still write native slices where both ends are known numbers (P10)
