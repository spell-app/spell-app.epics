Chose to have a project's declarations say which of its methods wait, so a project importing it awaits them.

  • The problem: Klondike imports Cards, whose turn_face_up() pauses.
    • Klondike's own source can't show that.
    • So the asyncio Klondike called it without an await, and its cards never turned.
  • Each method in a project's declarations file now carries "waits": true when it pauses, read from its tree.
  • The importing project reads it back (P.ScopeMethod.waits).
