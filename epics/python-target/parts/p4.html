What every writer needs to know about a program (an expression's kind, its locals, whether a value may be nothing) lives in the JavaScript writer, so Python would have to copy it.

A new ProgramWriter, between the base writer and the JavaScript writer, takes those over.

Writing a file's header and joining the files move from the project into the writer.

  • One home for what isn't JavaScript:
    • an expression's kind
    • a function's locals
    • whether a value may be nothing
    • the facts about the whole project
    • writing a match
  • The JavaScript writer extends it; the Python writer (P8 · PyWriter For FizzBuzz) will too.
  • Each writer writes its own file header and joins its own files, so Python writes its imports its own way.
  • Nothing compiled changes.
