Compiled Python should read like Python a Python programmer wrote by hand and would happily edit: Owen's "as idiomatic as python can possibly be".

  • That rules out the easy way: a thin layer of core calls that only imitates JavaScript.
  • Native Python wherever Python has a word for it:
    • for card in deck:, not a callback handed to the core
    • deck[0]
    • len(deck)
    • card in pile
    • @property getters, f-strings, if not deck:
  • The core is called only where Python has no word of its own: spell's test lines, a seeded shuffle, a pause.
  • The cost: the writer leans on kinds much harder than the JavaScript writer does, and the lists and things in spell_core act like Python's own (P7, P10).
  • What it looks like: the Overview's "What idiomatic Python looks like" (1.2).
  • every Python phase is judged by "would a Python programmer write this?", not only "does it run?"
