What got better, and what didn't.

  • vp run runs the root's per-package scripts, in parallel: the biggest real win.
    • it replaced yarn workspaces foreach -A run, for ts, test and review (P3)
    • the type check went from 6.0s to 3.1s; packages aren't taken from the cache yet (I1)
  • vp check: lint, the format check and type-aware lint in one pass.
    • no root script runs it yet: files already unformatted on main fail it (C18)
  • vp staged: checks before a commit, on the staged files (we have none).
  • One dependency, vite-plus, instead of five, in 11 package.json files: vite, vitest, oxlint, oxfmt and tsgolint.
    • their versions move together
    • the lint and format settings live in one module every vite.config.ts spreads, not in .oxlintrc.json / .oxfmtrc.json (D8)
  • NOT faster dev, build or test: the same engines are underneath (C5).
  • Since the repo split, the kit holds the one install: vite-plus and its tools are bumped together in its yarn catalog, and the lint and format settings are the toolchain's spell/toolchain/lint.
