One command, vp, around tools we already use one by one.

  • Vite 8 and Rolldown: vp dev, vp build
  • Vitest: vp test
  • Oxlint, Oxfmt and tsgolint: vp check, vp fmt
  • tsdown, for library builds
  • Vite Task: vp run, the monorepo's tasks, with a cache
  • git hooks on staged files: vp hooks, vp staged
  • managing Node and the package manager (we opt out: C4)
