P4 gives a test item fields (Step, Should, Example, If not), but an older test, written as prose, is still a valid page: the run shows its prose as the Step.

  • The rule (src/AGENTS.md, "Rules") asks for a migration step with every change to epic page markup. Here nothing on an old page has to change: the fields are new content a test MAY have, and the one new attribute, failed, is written only by epic inbox apply.
  • So no step in Migrations.all. The open tests are being rewritten into the fields by hand in P4 (the content agent), where it's worth it.
  • The alternative: a step that wraps every old test's prose in a Step field. It would say nothing new, and its Should would be empty.
