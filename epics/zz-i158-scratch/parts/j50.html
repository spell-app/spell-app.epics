For I43 the top bar's four icon buttons keep their plain <a> / <button> with a title, and their icons get pointer-events: none, so the pointer lands on the titled element.

  • Why: <spell-site-header> is self-contained by design (its own shadow DOM and CSS, no UI elements), so it looks the same on every site, including pages that load no Spell UI. A <ui-button> would need Spell UI on every page that shows the bar.
  • The alternative: make each a <ui-button title>, as spell-epic's own pages do.
