The rest of the page's chrome the runtime draws, as elements:

  • The Cmd / Ctrl + K dialog stays a <ui-modal>; its list of threads waiting on Owen is a <ui-menu vertical secondary link>, its title a header item, each line a <ui-item> button (focus and Enter for free). Its id box stays the native input Spell UI styles (ui-native): the dialog focuses and selects it itself, and the checks fill it.
  • The one-line head's / is the breadcrumb's own divider: the copy keeps the page's own crumb, emptied, instead of a <span> of ours.
  • The stuck titles' one-row trail (wireStuckTrail()) draws no markup: an attribute and a CSS variable on <ui-section>, unchanged.
  • Everything is made with a helper, el(tag, attributes, ...children) (spell-doc-helpers.js), never an HTML string. Left as they were: the page notes' cards and the comments' threads, which the comments work owns.
