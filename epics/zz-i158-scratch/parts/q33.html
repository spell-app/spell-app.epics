When the titles are gone, a page may want to style the row (the docs make each button 34px square). This decides what the menu offers for that.

  • ui-toolbar:state(icons-only) ui-item { ... }: the page styles it as it likes.
  • Nothing moves unless a page asks.
  • The menu adds icon to its class while icons only, which re-pads and centres every item.
  • Cost: items jump in size the moment the titles go, on every page, wanted or not.
  • :state(icons-only) on the menu; no class word changes
