This decides whether <ui-toolbar> shrinks without being asked.
  • A toolbar scrolls by default, as its components page says; shrinkable turns the shrinking on.
  • No toolbar on any page changes until it asks.
  • Cost: every toolbar in Spell UI's, App UI's and Brand UI's pages changes, and the visual baselines with them.
  • only toolbars that write shrinkable shrink: the docs toolbars, through the docs runtime
