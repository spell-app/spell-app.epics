Every session gets one monitor process, epic session listen, declared in spell-epic's monitors/monitors.json.

  • Claude Code starts it with the session and stops it with the session. Each line it prints reaches the session as a notification and wakes it when idle (plugin components docs, "Monitors").
  • It prints nothing until Owen sends, so it costs no tokens while idle. Each Send costs one turn, as today.
  • Not a Haiku agent: an agent can't write in the chat, and would have to wake the main session anyway.
  • Not asyncRewake on the session-start hook: the docs don't say the event honours it, and a hook can't re-arm itself after a wake.
