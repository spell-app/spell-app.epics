Leaving a test run (Done testing, Esc, or the summary's Next epic) now sends the answers given in it that aren't sent yet, through the page's Send, as the summary's Send results does (I52). The answers are NOT sent one by one as he gives them.

  • Why: each send wakes a waiting session once (the inbox's handedOver takes each send once), so a run of 17 tests would wake the session 17 times and have it act on half a run while he goes on.
  • What he sees: the notice line at the window's foot says "3 results sent to Claude" (with nobody listening, Send's own notice: saved, and how the epic was woken). Nothing answered: it just leaves. The send failing (page server gone, not served): the notice says so and the answers wait, Send blue in the header.
  • The summary's Send results stays a button: reaching the summary doesn't send by itself, so Back to change an answer doesn't wake the session first.
  • The alternative: send each answer as it's given -- the session hears at once, but is woken per answer.
