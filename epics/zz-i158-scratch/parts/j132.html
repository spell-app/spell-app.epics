The server renders the page as a navigation would get it, and sends it to every socket. A page that isn't showing that file ignores it. There is no per-page subscription, because the socket has no message from the page saying what it shows. The limit is 4 MB a page; a bigger page, or one at an address the server can't render (a worktree's file under the main server's ../ path), goes alone, and the page fetches it as before.
