Owen's request said <ui-example> should work "for guides and READMEs too". GitHub shows a README's Markdown and runs no custom elements, so there an <ui-example> shows as plain text. This decides what "READMEs too" means.

  • <ui-example> works on every page the page server serves, the guides included.
  • READMEs keep what they have: a command in a code block, and what it prints in an Output fold, tested.
  • Cost: none; a README on GitHub never shows a live example.
  • A tool screenshots each <ui-example> and the README shows the picture.
  • Cost: a new tool, images in every repo, kept in step by hand or by CI; its own phase.
  • <ui-example> draws in the components pages, App UI's and Brand UI's pages, and the guides
  • no README changes
