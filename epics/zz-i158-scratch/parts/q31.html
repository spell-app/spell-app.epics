A segmented menu is one choice among a few (like List / Grid). This decides what shrinkable does on one.

  • A segmented menu keeps scrolling, every label whole.
  • A single choice whose labels vanish is a different control; the docs runtime never asks for it there.
  • Titles cut, then icons, then the overflow menu.
  • Cost: the sliding thumb must follow the shrinking items, and a choice hidden in a menu reads oddly.
  • <ui-menu segmented shrinkable> draws as plain segmented, and warns once in development
