Owen asked (I40) for a <ui-table> property, unstacked or stack=no. Spell UI already has both halves of it, so I added the missing word to what is there rather than a new name:

  • One table: unstackable, Fomantic's word, already there.
  • A whole page or region: stack-by="none" and its token --ui-table-stack-by: none. stack-by says what stackable measures (viewport, container); none means it measures nothing, so the table never stacks. "none" is Spell UI's usual word for "off" in an enum (closedby="none", animation="none").
  • Example: spell-epic's pages now set ui-table { --ui-table-stack-by: none }, a public token, instead of the private --_table-stack: 0.

Why not stack="no" or unstacked: Spell UI's vocabulary rules give each meaning one name, and those would be second names for unstackable. An attribute also can't reach every table on a page; the token can. The alternative was stack-by="never" (the issue's first idea): it reads as well, but no other Spell UI enum says never.
