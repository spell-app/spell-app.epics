• The browser's copy is written at every change. The page server's copy follows half a second after the last change: choice pages waited 5s before, details pages 2s.
  • One save at a time: a change made while a save is on its way goes in the next one, so an older save never lands after a newer one.
  • A failed save tries again every 3s, until one goes through: no keystroke needed, and a restarted server's new token is picked up. A steady 3s, no backing off: the server is on this machine, and Owen wants it saved the moment it's back.
  • A details page's failed save was orange (a warning), muted beside Send, where the side bar cut it short. Now it is red and bold, on its own line under Send, like the choice bar's.
Everything typed reaches the server within a second while it answers, and gets there by itself once it answers again.
