  • Where it runs: the main checkout, spell-app on main (its epic page says so), no worktree. Its phases change content pages, which the turn-end hook commits; a comment that needs code is sent on to the epic that owns the code (today epic-engine), not built in feedback. The alternative: a spell-epic worktree feedback, worth it only if code work there became routine.

  • No feedback epic yet (another repo): a page no epic owns keeps the old "no epic owns this page", its Send wakes nobody, and /airplane land's gather makes the epic (standing). The alternative, a Send that makes the epic, would have a page route write an epic page.
