After a reload for new code (I23), the page reopens everything that was open as it went: sections, phases, items, and whatever a link had opened. It keeps that list in the tab's session storage, and reads it only when the reload was the live client's. A reload you start yourself (Cmd+R) still opens only what you opened or closed by hand, as before, with items folded.

  • Why: a reload for new code shouldn't change what you see; a reload you ask for is a fresh start, and links' unfolds were never remembered.
  • The other way: remember every item you open, for good, as sections are. Not done: an epic page has hundreds of items, and it would change how a fresh visit opens.
