The sticky-title check in src/tools/check-spell.js (stuckAndActive()) also passes an h2 whose <ui-sticky> reports :state(bound). That state means a short section's end has pushed its title out.

While checking I33, I turned the goal pages' sticky titles off on a scratch copy (ui-sticky.spell-h2::part(sticky) { position: static }). motivation.html's Ideas title then scrolled away with the page, but ui-sticky still said bound, so the check passed. A real break of the sticky titles on section.s2 pages could go unnoticed in the same way.

A possible fix: count bound only when the title's bottom is near its section's bottom, so it really was pushed out.
