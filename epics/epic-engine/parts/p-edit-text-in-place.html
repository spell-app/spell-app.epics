  1. Which text each drawn piece came from (Spell UI, plain code, tested first): a new MarkdownSource, from marked's own tokens.
    • Each editable piece's place in the block's markdown: a table cell's text inside its row's line, a paragraph, a list item's own text (a nested list is its own items), a heading's text after its #s.

  2. The drawn block carries those places: the markdown engine marks each cell, paragraph, list item and heading it draws with its place in the text (counting a title skip-title leaves out).
    • An engine of its own (the app's <spell-markdown>) marks none, so it simply isn't editable in place.
  3. The box: <ui-markdown edit-in-place>, a new attribute of Spell UI's markdown element.
    • A plain click on a marked piece (not a link, not the end of a drag) makes it editable where it is, holding its markdown, with the cursor where he clicked.
    • Enter or a click away commits; Shift+Enter is a new line in a paragraph; Tab and Shift+Tab commit and move to the next and previous cell; Escape puts the text back.
    • A commit is an edit as the Write tab's are: the content changes (ui-changed, dirty), then save(). A second without typing commits too, and the box stays open.
    • Hover: a faint outline and a text cursor on what a click would edit.
    • Its words in English and Spanish, an example on its components page, the site's data (yarn site:data), Spell UI's status checklist.
  4. Saving a block written in the page (most guide blocks: no source file).
    • save() hands an inline block's text to the page's saver, when the saver says it takes inline text; otherwise it does what it does today. So dirty, saved and the conflict error work as they do for a file.

    • Reading and writing one element go through the live client: a new readElement() beside editPage(); the section editor (<spell-section-editor>) moves onto both, dropping its own requests.
    • Refused because the file changed: read it again, and put the edit in once more if the old text is still there; otherwise the conflict error, and the box keeps what he typed.
    • A block with a source file already saves to it: unchanged.
