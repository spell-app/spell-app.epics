Yes, it's part of <ui-table>, and half of it was there already: unstackable keeps one table from stacking. What it lacked was a way to say "never" for a whole page, which is what our pages need. So I added that in Spell UI's own words, rather than a new unstacked / stack name (J57 says why):

  • stack-by="none" on a table, or the token --ui-table-stack-by: none on any ancestor or the page: the table never stacks. stack-by already took viewport and container; the attribute still wins over the token.
  • Done in spell-app's branch epic-engine-stack (one commit): UITable.css, its vocabulary, the ui-table docs page, a new test (it fails on the old sheet, and passes in Chromium, Firefox and WebKit), and the whole packages/ui suite passing.
  • Our spell-doc.css now sets the public token, ui-table { --ui-table-stack-by: none }. The private-flag rule stays below it as a fallback, with a comment, because main's Spell UI doesn't know none yet.
  • I checked it on a scratch build of spell-ui.js from that branch, at 300px in Chromium and WebKit, with the token alone (no fallback): a plain table stays a table, and the component guide's stack-by="container" demo still stacks. With today's main build, the token alone doesn't hold, so the fallback is still needed for now.
