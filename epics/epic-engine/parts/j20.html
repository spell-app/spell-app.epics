Three calls in the engine-links step (I27), made without you:

  • A spell-app CLI file that was FOLDED into the epic classes, rather than moved whole, goes back to plain text. For example packages/cli/src/commands/notesCommand.ts became a line in EpicTools's table, not a file of its own. Eight such files, 35 links in all with the other gone ones. The alternative: link each to the class it went into, under a name that no longer matches the words.
  • A file renamed as it moved keeps its link, under its new name. For example packages/cli/src/dev/mergeMain.ts leads to spell-epic/src/command/MainMerge.ts, where git and its test's rename say it went.
  • Epic UI's pages are linked at their served address, components/epics/..., as the linker writes them, not at spell-epic/src/docs/.... A link to the old package as a whole, packages/epics/, leads to spell-epic's root, which is that package now.
