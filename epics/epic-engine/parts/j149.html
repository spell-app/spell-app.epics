For P52 · Commit Log: a phase chip is stored by the phase's lasting id (p-commit-log), and drawn with its number today (P52).

  • Phases renumber when one is added or moved; a chip stored as P52 would point at the wrong phase afterwards.
  • An item chip is its id (i151), which doesn't change.
  • A ref the page doesn't have (a phase since removed) shows as plain text, no link.
  • chips stay right after phases are added or moved
