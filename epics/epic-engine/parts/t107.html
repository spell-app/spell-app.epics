owenoak: “When I do a comment in the middle of an HTML block, e.g. claude's todo notes in a phase or in a table, it somtimes shows at the very bottom of the item. I'd prefer it if it appeared closer to the selected text, but e.g. not in the middle of a table.”

Fixed (commit 3404305, on main):

  • A quote running out of a code span (<ui-input>'s action) was never found, so its thread fell to the end of the field. It's found now.
  • A quote in a table: its thread goes after the whole table, never in a cell.
  • Else after the nearest paragraph, list item or code block; else after the nearest box of text (a div of notes); the item's end only when nothing nearer works.
  • A list item's thread stays at the end of that item, so the list stays a list.
  • Worked out as the page draws, so old comments move too.
