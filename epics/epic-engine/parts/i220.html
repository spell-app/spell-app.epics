Owen, 2026-11-04: "Still seeing this message fairly frequently": "Saved. 🚧 data's tab is open, and VS Code types only into a session it opens: nothing typed. Paste /epic review data there."

  • Cause: the page wakes a session through its inbox poller only while one RUNS. The poller is the end-of-turn hook: it ends once it wakes the session, and the next starts only when that turn ends. So a Send during a turn found no poller, tried to type, and VS Code refused (its tab open).
  • And a process started again (a window reloaded: 🚧 data's was 3 minutes old, idle, no poller) had none until its first turn ended.
  • Fix: a mid-turn session is told through its inbox ("it wakes once its turn ends, nothing typed"), and the plugin starts the poller at each session's start too.
