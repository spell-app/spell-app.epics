  • Why: the thread is already where the comment is closed. Claude answers it as ever, naming the phase ("worked into P66"), and the person closes it ("that's good" / "skip it"). A second "handled" state on threads would be one more thing to keep in step.
  • And no Reopen on a comment's mark: to disagree, the person replies on the thread, which the mark's popup now links ("Open C2's thread").
  • Rejected: stamping the comment taken into the phase as the mark is stamped: it would mean the plan tool writing the review inbox on every edit, for what Claude's answer already says.
