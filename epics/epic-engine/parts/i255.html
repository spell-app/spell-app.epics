Building P71, its agent ran epic window launch test-epic from a scratch repo NOT set up for epics. EpicCheckout.nearest() falls back to the engine's own checkout, so the launch worked on the kit: it made ~/www/spell.worktrees/test-epic (branch test-epic, from main, installed) and its window file spell.epics/windows/ongoing/test-epic.code-workspace, and may have tried to open that window.

The agent may not delete outside its worktree, so they're left for you:

epic worktree remove test-epic\ngit -C ~/www/spell branch -D test-epic\nepic window close test-epic

Worth a look too: should epic window launch from a repo not set up for epics refuse, rather than fall back to the engine's checkout?
