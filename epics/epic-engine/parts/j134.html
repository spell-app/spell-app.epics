How the page sends a choices question's answer, for the choices questions phase (epic-engine's P50 · Choices Questions).

  • The pick mark keeps its one key per item: pick becomes a list of letters when the set is multiple ({ action: "pick", pick: ["A", "C"] }), a single letter as today otherwise.
  • Owen's added options ride in the same mark: added: [{ title, note, shot? }], so one Send carries the whole answer.
  • Apply writes each added option into the set with the next free letter, marked by="owen", and counts it as picked.
  • Why: the inbox, the fill rule (dashed, sent, applied) and takenPickOf() all key on the one pick mark; a second mark kind would copy them.
  • PickFields.pick: a letter or a list of letters
  • A new added list on the pick mark
