For P52 · Commit Log: a change entry is the Log's own line, <epic-event>, with a commit on it, not a second element.

  • It gains sha, repo (that repo's GitHub page, for a peer's commit) and refs (the phases and items it names).
  • It draws: time, short sha as a link, the summary, then the chips.
  • The sha link is made the way <epic-commit> makes its own, one shared helper.
  • A line with no sha is a review line (Q56 decides how those show).
  • one log element, two kinds of line; no new tag to learn

  • one commit element in both places; the log line element keeps only the review lines
