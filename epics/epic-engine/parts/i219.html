Owen, 2026-11-04: "So why aren't you restarting the page server when you merge to main?" I218's Hold was refused by the running server ("No such action: hold") till a restart by hand.

  • The server restarts when its code is newer than it, but only when something calls PageServer.ensure() (an opener), and it watched only its route modules' own folders, not the rest of epic/src they import.
  • Now: it watches the whole src/ each route module is in, and epic merge calls it right after main moves, so a running server restarts with the merged code (a stopped one stays stopped).
