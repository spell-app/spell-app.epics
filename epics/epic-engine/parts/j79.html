Where spell-epic learns that ~/www/spell is a multi-repo top (P10, repo-split's Q9 A): a new key, "repos", in the TOP repo's .epic/config.json5, naming its list of child repos ("repos.json5", the file yarn clone already reads) or the names themselves.

  • A child repo (~/www/spell/spell-epic) finds its top as the folder above its main checkout, when that folder's config lists it (EpicConfig.top). No key: a single repo, exactly as before, so other people's setups don't change.
  • Why there: the top already holds the list, so nothing is written twice, and no child has to know where it lives.
  • The other ways: spot repos.json5 beside a child with no setting at all (too magic: a stray file would switch modes), or a "top" key in every child's config (eight files to keep in step).
