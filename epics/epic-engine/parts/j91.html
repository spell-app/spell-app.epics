P14's goal says the chip shows on guides, the docs index and epic pages alike. That came from epic even-martin-demo's J1, which was never reviewed. P14 puts it on every page with the docs head, but not on epic pages.

  • J1's reason was that the same head draws them, so leaving epic pages out would take extra code. It doesn't: <epic-page> draws its own head. A chip there would mean changing the element.
  • And the count would be wrong. An epic page's item bodies are in part files, which load only as you open them. This page has about 410 words on it when it loads, and about 63,000 in its parts.
  • So it would say 2 min read at first, and grow as you open items. Counting every part instead means fetching each of them (this page has over 200), for a figure of about 4.5 hours that tells nobody much.
  • Guides, the index pages, details and choice pages get the chip. Epic and saga pages don't.
  • If you want it on epic pages, say what it should count: the whole page with its parts, or only what's open.
