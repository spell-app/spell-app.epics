Owen, 2026-10-22: "after reloading this or another window, vscode extension is hanging".

  • Cause: EpicConfig worked out its voices folder as it loaded, from import.meta.dirname, which the extension's bundle doesn't have. The class threw while loading, so the extension never started. The build silences esbuild's warning about it on purpose, so nothing flagged it.
  • Fix: the folder is worked out only when read. And the extension's build now loads the bundle once, with VS Code stubbed: a crash as it loads fails the build. Checked against the broken bundle: it catches it.
