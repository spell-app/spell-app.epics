For I25, the spell syntax guide and the core reference page read their data from spell-app's checkout, and the epic server (the side bar's) served only the content folder. So EpicServer now serves each repo's MAIN checkout after its content, at / and /r/<repo>/, as spell-app's page server lays the two. The content wins where both have a path, and dot files are refused.

  • It fixes more than those two pages: every epic page's links to code (../../../packages/..., ../../../spell-epic/src/...) now open from the side bar too, where all of them used to 404.
  • The alternative: leave the epic server serving content only, and have check-spell.js use spell-app's page server for those pages. The checker would pass, but the side bar would still draw no tables and every code link would still 404.
  • It's only the main checkout, as spell-app's page server serves it at /. A worktree's code shows from /worktrees/<w>/ on spell-app's server only.
