## What Claude Code does (from the repo-split session's research)

- Claude Code always asks before `EnterWorktree` enters a path outside the repo's `.claude/worktrees/`. - https://code.claude.com/docs/en/worktrees: "An `EnterWorktree` permission rule or choosing 'don't ask again' doesn't suppress this prompt; only `bypassPermissions` mode skips it." Since v2.1.206. - No setting, `EnterWorktree(<path>)` rule, `additionalDirectories` or PreToolUse "allow" skips it (https://code.claude.com/docs/en/permissions; user report anthropics/claude-code#94265). - Open feature request for a path rule / trusted roots: anthropics/claude-code#77069. - Our worktrees are at `~/www/spell.worktrees/<epic>`, so every enter prompts.
