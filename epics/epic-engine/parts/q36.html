This decides what the overflow button shows, and how a page changes it.

  • Spell UI's icons are named, as the toolbar's own scroll keys are (chevron left).
  • Default icon ellipsis horizontal: it reads as "more of these", and sits in a row.
  • A page puts its own in slot="overflow", e.g. a hamburger, or a word.
  • Its title, and so its tooltip and accessible name: "More" (Spanish "Más"), from the vocabulary.
  • Icon bars, the same slot to change it.
  • Cost: a hamburger reads as "the site's menu", not "the rest of this row".
  • <ui-toolbar shrinkable overflow-icon="bars">
  • Cost: an icon name only, never markup; one more attribute.
 
<ui-toolbar shrinkable>
  <ui-icon slot="overflow" name="bars"></ui-icon>
  ...
</ui-toolbar>
  • the overflow button shows "…", titled "More"; an overflow slot replaces its icon
