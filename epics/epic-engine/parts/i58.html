App UI's layout loads /element/spell.pack.js, which only spell-app's own app route module (appRoutes.ts, in spaces) serves. The epic server doesn't load that module, so it answers 404 and check-spell.js --base on packages/app/docs/index.html fails with two console errors. The same on Owen's running 4848 server, so it predates P8.

  • Example: curl http://127.0.0.1:4848/element/spell.pack.js gives 404; on 4747 it gives 200.
  • The demo check stubs it (check-comments-epic-ui.mjs --set app).
  • A fix: a page-server setting for such a mount, or the epic server loading the repo's app routes.
