How editing a guide's text in place starts (P60 · Edit Text in Place, request r53): Owen picked ⌥-click, from three shown on the details page Edit Text in Place: how it starts (2026-11-02).

  • A · a plain click: any click on text edits it. Gets in the way of selecting text for a comment; the hardest to build.
  • B · a pencil button beside expand / collapse and the bullhorn: turns editing on for the page. One more click, and a mode to turn off.
  • C · ⌥-click, chosen: a plain click reads as now; holding ⌥ outlines what can be edited, and ⌥-click opens the box there. Nothing to switch, nothing remembered; the easiest to build.
  • Reading and commenting work exactly as today: links, selecting text, folding.
  • Holding ⌥ outlines every editable piece of a <ui-markdown>; ⌥-click edits one.
  • No pencil, no edit mode: one can be added on top later (T66).
  • The bullhorn's tooltip and the docs guide's help say ⌥-click edits.
 on a guide the page server can save, ⌥-click a paragraph, heading, list item or table cell inside a <ui-markdown>: a box holding its markdown, Enter / a click away keeps it, Tab moves on, Escape puts it back, 5 seconds without typing keeps it too; each keep written into the page's file at once, only that text changed, the page never moving (r53)
