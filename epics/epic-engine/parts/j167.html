Owen picked both ways to clear Update marks; how Seen reaches the page was my call.

  • Chosen: a review mark, { action: "seen" } under the block's id (up3), as a change mark's Reopen. The block folds to one grey line at once on Owen's page (the mark is in the inbox); Send carries it; epic inbox apply stamps seen="<time>", so everyone sees it seen.
  • Why: the review routes never write the epic page (only the tool does, under its lock, after the dry run), and Reopen, the other button that changes how a mark looks, already goes this way. Writing at once would need a new route that edits the page, racing the session's own edits.
  • Also: the tool now gives each update block an id (up1 ...) and each host a to-see list (id and date of each new one), so a folded phase's pen counts only new ones without its body loaded; that replaces the phase's changes count, dropped on the next write. No migration step: seen is optional, old blocks go quiet by age.
