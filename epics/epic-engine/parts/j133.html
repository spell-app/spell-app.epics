Before this, a set page's SPELL_SERVER.file was its path in the checkout (/spell-ui/docs/ui-button.html), but the server reported its changes at /components/ui/ui-button.html. So the page never heard about its own edits: no patch and no reload. The live client now also counts the file at the page's own address (a folder's as its index.html) as the page's (liveAction()'s address).
