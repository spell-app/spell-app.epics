P10 taught the worktree hook, epic worktree remove / repos / status / merge-main, epic merge, the session guard and epic window about every repo. These still look at ONE repo's git, the top's (or the repo they run in):

  • epic stock and /worktrees' clean-up offers (merge, discard) read the top's branches: a child repo's <epic> branch with commits isn't offered.
  • epic commits <epic> --backfill finds a phase's commits in the repo it runs in.
  • epic worktree status's merged looks at the top's branch history (its ahead counts every repo).

For example, after /isolate done merges spell-ui and spell-app, /worktrees still describes the epic from the top repo's branch alone. Old one-repo worktrees (spell-epic.worktrees/epic-engine) keep working as before until they end.
