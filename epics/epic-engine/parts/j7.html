Comments on Epic UI's pages (/components/epics/...) belong to NO epic, so they follow the rule every unowned page follows: Send says no epic owns this page, and /airplane land (epic comments gather) takes them into guide-changes, a phase per page. epic comments list shows them, named by their served path, components/epics/epic-item.html#M1.

  • Why: SeeAlso.ownerOf() only gives a page an owner when an epic's phases link it as a guide, and no open epic links an element's page. Hard-wiring epic-engine would send comments to an epic that will close; Send would then wake a finished epic.
  • The alternative: let an epic's phase links claim Epic UI's pages, as they claim guides (SeeAlso reading components/epics/... links), so the epic that last worked on an element gets its page's comments. A small change to SeeAlso if you want it.
