Comments on Epic UI's pages (/components/epics/...) belong to NO epic, so they follow the rule every unowned page follows: Send says no epic owns this page, and /airplane land (epic comments gather) takes them into guide-changes, a phase per page. epic comments list shows them, named by their served path, components/epics/epic-item.html#M1.

  • Why: SeeAlso.ownerOf() only gives a page an owner when an epic's phases link it as a guide, and no open epic links an element's page. Hard-wiring epic-engine would send comments to an epic that will close; Send would then wake a finished epic.
  • The alternative: let an epic's phase links claim Epic UI's pages, as they claim guides (SeeAlso reading components/epics/... links), so the epic that last worked on an element gets its page's comments. A small change to SeeAlso if you want it.

Yes: "guide-changes" is a guide-only name for what is really the inbox for every page no epic owns.

How it works today:

  • A comment on a page no epic owns waits in that page's own inbox file. Its Send says "no epic owns this page", and wakes nobody.
  • Only /airplane land (or epic comments gather by hand) sweeps them into an epic called guide-changes, one phase per page.
  • That epic doesn't exist yet: it's made on the first gather. So today an unowned page's comments can sit unseen for days.
  • Pages with no owner: most guides, Epic UI's pages (now), the list pages, the changelog, the Templates page.
  • guide-changes becomes feedback: a STANDING epic, made once, never done.
  • An unowned page's Send goes to it and wakes its session, like an owned page's Send does today. So nothing waits for /airplane land.
  • Each page with comments gets a phase, as now; done ones merge on their own (standing).
  • epic comments gather stays, for the sweep; guide-changes is read as an old name.
  • Cost: 1-2h (the name in ~11 files, SeeAlso's fallback, Send's wording, the airplane skill).
  • guide-changes is called feedback; nothing else changes. Unowned comments still wait for a sweep.
  • Cost: 30m.
  • Epic UI's pages, the templates and the list pages belong to epic-engine; other unowned guides keep the sweep.
  • Smaller, but two places to look.
  • Every page's Send reaches a session at once: its epic's, or Feedback's.
  • "guide-changes" disappears from what you read.
