The Epics page's saga chips are drawn by <epic-list> now, from its cards: each card says its saga's id, title and purpose, and the list's sagas attribute gives Owen's order.

  • So a saga that no epic names has no title to show, and gets no chip. Before: a chip counting 0, which shows nothing when clicked.
  • No saga's chip shows only when some epic names none (always the case today).
  • Example: the 10 sagas today all have epics, so the page shows the same 11 chips.

The alternative: write each saga's title and purpose on the list too (child elements or a JSON attribute), to keep the 0 chips.
