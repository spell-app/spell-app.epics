Owen asked for "updated" to mean a phase with news for him. The page has no "seen" record for a phase, so the chip counts what the phase itself already shows:

  • its build plan waits for his Accept (plan="waiting", the Accept plan buttons; never the Doc Review phase, as those buttons skip it)
  • or its plan changed (changes, the orange pen on its title)

Both only while it is not done: a done phase never draws the pen, so its old changes are no news. The same rule lives in one place, PhaseState.of().
