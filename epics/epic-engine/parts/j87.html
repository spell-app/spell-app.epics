P12's fix for r11. Before, the guard told a session that started in its worktree's folder to run EnterWorktree on that same folder, so that Claude Code would record it. That was the prompt Owen kept getting: Claude Code asks before entering any worktree outside .claude/worktrees/, whatever the permission rules say.

  • Now the guard writes its own record of the session's worktree, ~/.spell-epic/session-worktrees/<session id>.json, and says nothing.
  • When that session is reopened outside its worktree, the record works like Claude Code's own note: the guard tells Claude to enter, and that one enter asks Owen once.
  • Claude Code's own note still wins when there is one. A session that left on purpose (ExitWorktree) stays out.
  • A new tab in an epic's window starts working at once, with no permission prompt.
