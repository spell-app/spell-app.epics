The monitor is a node process under tsx beside every Claude Code session: about 170MB each (measured 2026-10-22), polling a file every 2s while its session has an epic, every 30s while it has none.

  • Ten open sessions: about 1.7GB.
  • Making it plain node (no tsx) would cut that, but the inbox code it reads loads the epic tool, which needs tsx.
  • Monitors are an experimental plugin feature (experimental.monitors).
