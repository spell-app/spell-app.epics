Owen asked (comment C3 on P60) for the attribute to be editable, not a new edit-in-place. <ui-markdown> already has editable: the Write / Preview tabs and their text box.

  • Chose: bare editable is the new edit in place (⌥-click), and editable="tabs" keeps today's Write / Preview editor: one attribute, its mode a word (WWOD §9, "String sentinels over booleans for modes").
  • Over keeping bare editable as the tabs and adding a value for edit in place: every docs page would then write editable="in-place", the long form for the common case.
  • Today's users are few: its components page and example, and its test. They move to "tabs" in P60, with the attribute's words in English and Spanish and the site's data.
  • <ui-markdown editable>: ⌥-click text to edit it where it is.
  • <ui-markdown editable="tabs">: the Write / Preview editor, as editable is today.
