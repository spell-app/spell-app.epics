1. In a worktree's VS Code window, press ⇧⌘P › Developer: Reload Window (once is enough, after M68).
  2. In the Review tab (checklist icon, right side bar), hover each title-bar button: the tooltips read Back, Forward, Reload, Open in Browser, Epics Home, This Epic's Page, Restart Page Server. No Inspect button.
  3. Click This Epic's Page: the epic page shows. Click a link in it to a guide, then Back, then Forward, then Reload, then Open in Browser.
  4. Click Epics Home: the docs' home page. Click Epics in its top bar for the Epics list, then a saga from Sagas; on each, click This Epic's Page.
  5. Do steps 2-4 again in the Epic Docs tab (the hat icon): This Epic's Page opens the epic page in the Review tab.
  6. In the Details tab (speech bubble), hover the buttons: Back, Forward, Reload, Open in Browser, This Epic's Questions, Restart Page Server. Click This Epic's Questions for the list, pick a page, click This Epic's Questions again, then Reload: the list stays.
  7. ⇧⌘P, type Epics Home: listed as Epic Docs: Epics Home and Review: Epics Home.

Every button does what its tooltip says on every page; each tooltip is a short name, no Review: prefix, nothing in brackets; right-click in a page still offers Inspect
