Open the spell syntax guide (guides/spell-syntax/spell-syntax.html) in VS Code's side bar. Hover a class name's pencil, a purpose's wand, and Expand all / Collapse all in the toolbar. Then type in a box and hover the round reset that appears beside it. Each should show its tooltip ("Suggest another name for ...", "Provide more details here ...", "Expand all", "Back to ..."). On the core reference (guides/targets/core-reference.html), open a file's section and hover the round code button in its title: it should show the file's path, and clicking it should open the source. All of these are now <ui-button>s; headless Playwright can't show a native tooltip.
