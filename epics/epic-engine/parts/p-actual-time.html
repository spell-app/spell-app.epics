An epic page's estimates are never checked against how long the work really took, not counting time waiting on Owen.

  • Each phase records the time Claude actually spent on it, next to its estimate: est 3-4h · took 21m.
  • The epic page's total shows estimated against actual.
  • Owen, 2026-10-25: "for the time estimates in the epic doc -- do you have easy access how long work took in wall clock time, not including waiting on me?" ... "yes, new phase".
  • Actual time is Claude's working time only: a background agent's own running time, and the session's turns while working on the phase, never the gaps waiting for Owen.
  • Shown beside the estimate on the phase's title row, and summed for the epic; over time it shows how good the estimates are.
  1. Where the time comes from: the session transcript of whoever worked the phase (the epic session and the agents it started, each a transcript with a timestamp on every message), from the phase going active to done. A turn counts from its first message to its last; the gap until Owen next types (or a notice arrives) does not, nor do gaps longer than a few minutes inside a turn spent waiting on a background agent that is counted on its own.
  2. Agents: a named agent (epic agents) records its own running time as it ends (epic agents done), from its transcript; agents that run side by side count once (wall clock, not summed).
  3. Recorded: epic phase … done writes it on the phase, <epic-phase took="21m">, and the log line says it; epic phase … took works it out again for a phase done before.
  4. Shown: the phase title row reads est 3-4h · took 21m; the Overview total shows estimated and actual for the done phases; a markup change, so its migration step (leaves pages without it as they are).
  5. Checks: tests on a made-up transcript (a turn, a long wait for Owen, an agent running in parallel) giving the right time; the real numbers for P37-P40 against what their agents reported; headless screenshot of a phase row.
  6. Left out: time before this phase (older phases get a time only when asked, with took); other people's sessions.
spell-epic: epic phase (PlanDoc's phase status), the session transcripts' timestamps (TranscriptIndex / Sessions), epic-phase's title row (EpicPhase, its estimate), the Overview's total

A phase built by an agent and one built in the session each show a measured time; a phase that waited on Owen for an hour doesn't count that hour.
