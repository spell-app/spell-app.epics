Why

  • Today an epic starts in Claude's plan mode: a plan file in an editor tab, approved in one go, then copied into the page. The back and forth that works (the page, its bullhorns) only starts after.
  • Once building starts, the Overview and phases still say what was PLANNED. What was really done is scattered across Done lists, Update blocks and dozens of items.
  • So looking back means wading through questions, issues and caveats that a phase settled long ago; and the epic's guide repeats what the READMEs should say.

Stage 1: the Overview

Claude writes the Overview and its questions; your answers rewrite the Overview.

  • The page shows only the Overview, Questions and Todos. Phases, judgement calls, To test and the log stay hidden (the file still has them; it's a view).
  • Each answer rewrites the Overview's text where it applies. The changed words get an orange background, with the question and answer folded beside them in a line or two.
    • Beside each change: Accept (the change stands) and Reopen (talk it over again).

  • A todo raised meanwhile can be promoted (a plan of its own: a phase, or a new epic) or deferred.
