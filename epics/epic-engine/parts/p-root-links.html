  2. The Linker writes and reads root paths (Linker, in spell/server):
    • link() writes a code span's link as its served address from the root, /spell-ui/x.ts, and turns any existing relative href in a shared page into one, so every write through the tools mends a page.
    • fileFor() and check() read /x as the checkout's root, through the served folders (/components/ui/, /templates/, the content folder's).
    • check() refuses a relative link in a shared page: relative: ../x -- write /spell-ui/x. That's the lint rule: epic lint and doc-links.js --check both run it.
    • Root paths are the same text in every checkout, which is what lets one shared page serve them all.
