A fix to a checkout's setup (the .ignore that lets Open File see .spell files) reaches a worktree only once its branch merges main.
  • Each repo lists its checkout patches in .epic/config.json5 on main.
  • epic worktree patch [--all] applies the ones a checkout lacks: a file copied in and git-excluded, or a command run.
  • The SessionStart and worktree-create hooks run it, so new and reopened sessions catch up by themselves.
  • Owen does nothing: a fix made once on main reaches main and every worktree, running sessions included.
  • A copied file is git-excluded, so the worktree's status stays clean and a later merge of the tracked file replaces it.
  • Each checkout remembers what it has had (inside its .git folder), so nothing runs twice.
  • A patch is a no-op once its file is tracked there: it retires by itself.
  • The .ignore patch is the first, applied by hand on 2026-10-22.
