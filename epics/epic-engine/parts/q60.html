For P54 (r45). Two ways for the page server to learn a catalog is stale:

  • A. The page tells it: <ui-root> hits the stale catalog and sends one request (what Owen asked for). Fixes it only once a page breaks.
  • B. The server watches the components' vocabularies itself, as it already watches a bundle's sources, and regenerates the catalog before any page breaks.
  • C. Both: B normally, A as the backstop for what B misses (a component pack).
