The Review tab had no way to open a page with a query: the extension's show-doc took a file, an id to land on and a tab. P4 adds query to it (DocPreview.show(), WindowBridge), and to the openers that call it (open.js --query=, pages.js, window.mjs).

  • Until the extension is rebuilt and the window reloaded, epic test opens the page WITHOUT test mode (the old bridge ignores query); "Start testing" on the To test section works either way.
  • Chrome (a session outside VS Code) gets the query in its URL at once.
  • The alternative: test mode from the hash (#test), which the extension passes already; but the contract names ?test=1, and a hash on the page already shown only scrolls, never reloads it into the run.
