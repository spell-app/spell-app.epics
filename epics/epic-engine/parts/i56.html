Most of Spell UI's docs pages write their prose in <ui-markdown>, which draws it in its shadow root. Selecting a sentence there and pressing ⌘ I does nothing, and the floating bullhorn doesn't show: the comments' selected() (spell-doc-comments.js) takes a selection only when its start is in the page's main, and a node in a shadow root isn't.

  • What works there: the page's bullhorn, every section's, the toolbar, Send, and text in a live example's light DOM (the check comments on utilities.html's ui-heading).
  • A fix: take the selection's shadow host as its place (its section), keep the quote; the highlight wouldn't draw (the quote is looked for in light DOM), the thread would sit under the section. It changes spell-doc-comments.js, so spell-ui.js is rebuilt with it.
  • Same on any page that writes prose in <ui-markdown>.
