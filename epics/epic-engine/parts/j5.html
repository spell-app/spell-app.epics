For I11, the checks run on src/demo/DemoServer.ts. It is spell-epic's EpicServer over src/demo/shots/, with ReviewStart.wake() and start() replaced in that process only. The real shared folders (guides/ ...) are mounted beside the copies, read only.

  • Why: production code stays as it is (no test-only flag in ReviewStart), and a check can assert that a wake was asked for.
  • Second guard: the window registries point at an empty folder, so even a missed stub finds no window to type into.
  • The alternative: a no-wake env var that ReviewStart honours. It would also protect a hand-run server, at the cost of a test hook in real code.
