Which package should someone install to get the whole product, once spell itself installs only what epic needs?

  • Why it comes up: the split phase moves Monaco, Ink, the language server, atproto and the other app-only packages out of what spell installs by itself. Anyone who wants the editor app still needs a way to get them all.
  • Import names don't change in any of these: code still says spell/app/....
  • spell-app is recommended because the name is already ours and says what it's for. It does reverse repo-split's Q65, which held that name and said it wouldn't be published again.
  • spell-app: npm install spell-app brings spell and everything the app needs. spell publish goes from three packages to four.
  • spell-full: the same thing under a brand new public name; Q65 stands.
  • No package: still three packages. A command that needs a missing piece prints the npm install line to run.
