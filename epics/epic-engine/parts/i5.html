For P12: each option's round tick box is a native radio in the option's own shadow root, so the browser doesn't group them: Tab reaches each, arrow keys don't move the pick, and the question keeps them exclusive itself. The old page's <ui-radio>s had the same limit. A role="radiogroup" with roving focus on <epic-ask> would fix it.

Fixed in P1: a pick-one question's round tick boxes now behave as one radio group to the keyboard.

  • Tab stops on ONE of them: the option picked, else the first one shown (a roving tabindex: EpicAsk.tabStop, drawn by EpicOption.tickTabIndex).
  • Down / Right moves the pick and the focus to the next option shown, Up / Left to the one before, round the ends; options hidden by Open are skipped (EpicAsk.onArrowKey()). An arrow in a comment box or Other moves nothing.
  • <epic-choices> under a pick-one question is a role="radiogroup", named by the question's section title (Q1 · Which layout?). Pick several is unchanged: every tick box a stop, no group.
