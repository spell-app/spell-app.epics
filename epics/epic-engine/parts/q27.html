The renames make old tags draw nothing: no page may keep <ui-docs-toc> or <ui-docs-example>. A branch cut before this phase still has pages that write them. This decides who rewrites those when that branch merges main.

  • epic worktree merge-main runs spell ui rename --write on the files the merge brought in, and lists what it changed.
  • So a branch cut before this phase never shows an empty box where an example was.
  • Cost: one step in the merge, and its test.
  • Each branch's session runs spell ui rename --write itself.
  • Cost: easy to forget; the page then draws nothing where the old tag was, with no error.
