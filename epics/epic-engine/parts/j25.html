On the Epics page, a group's heading counts the cards that show, and a group with none showing is hidden.

  • Before: only the saga chips counted. A group whose cards the section's state chips hid (click the green chip: done only) kept its heading and its count, over no cards.
  • Now both filters count (data-spell-hidden, which the docs runtime's state chips set, is one of the attributes <epic-list> watches).
