I156's guard against a format run rewriting more than N files nobody edited: not built. The root cause is fixed instead -- every format script names only its own files and reads its own ignore list (kit:format its own paths; app's ignores app/docs) -- so a guard would only catch each folder's real drift, which is what yarn review is for (the kit's 12 and epic's 6 unformatted files today). Building it means a wrapper bin in every folder's format script that asks git which files were edited, and a threshold that blocks review on legitimate drift. Recommend: one plain yarn format commit on main for the 28 drifted files (kit 12, epic 12, ui 4) instead.
