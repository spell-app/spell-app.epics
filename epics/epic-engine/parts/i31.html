On the commands page (guides/dev/commands/commands.html), commands.js fills the [data-commands-families] placeholder <div> with the family sections. The div already takes the reading column's indent, and each nested <ui-section> takes it again inside. At 1200px a family's table starts at 352px and is 496px wide, so it scrolls sideways where it should fill the column.

The core reference had the same problem. P3 fixed it there by putting the sections in the placeholder's place (holder.replaceWith(...), as spell-syntax.js does), so they are their section's children, as a page writes nested sections. The filter then finds them by a data-* mark. commands.js needs the same fix.
