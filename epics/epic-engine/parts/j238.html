Claude Code keeps a picture pasted into the chat only in the session's transcript (~/.claude/projects/<slug>/<session>.jsonl, as base64); no image cache on disk. So --picture <file> alone couldn't carry it: --pasted <n> takes the n pasted last, read the way epic send --images reads them (Requests.pastedImages()). Checked on a real transcript: a 57KB PNG came back whole.
