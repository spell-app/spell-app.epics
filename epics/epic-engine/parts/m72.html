In VS Code (any window), open a new terminal: Terminal > New Terminal (⌃`). If it asks which folder, pick spell. Then type: 

spell runbook start netbox-demo

Follow each step it shows: press o to open NetBox's page, Enter once a step is done, and paste the token when it asks. It runs the last three steps by itself (about 3 minutes). Then type: 

spell runbook status netbox-demo

The token doesn't show as you paste it. It runs the ingest and both verifies itself, showing their output, and ends with ✓ All 5 steps are done. The token never appears on screen: where a command printed it, it says [the secret NETBOX_TOKEN]. status shows five ticks.
