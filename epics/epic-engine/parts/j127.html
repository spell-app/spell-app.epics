With a section per kind, a family's tags (<ui-button>, <ui-buttons>, <ui-or>) are headed in every section they appear in.

  • Their one-line summaries would repeat in each of up to seven sections, so they're the header's tooltip instead.
  • So a sub-tag's summary is no longer visible text on the API tab. The other choice: a first 'Tags' section listing each tag and its summary.
