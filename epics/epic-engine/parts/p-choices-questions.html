An option may show a small picture (a screenshot, a diagram) inline, which opens full size on a click.

  1. The set says how it is answered. <epic-choices> takes multiple (pick one or many) and addable (Owen may add options); chosen may hold several letters (chosen="A C").   2. The cards on the epic page. In a multiple set, each EpicOption draws a tick box in place of the Choose pill, reusing the tick-box mode it already draws for details pages; the fill rule as today (dashed once ticked, outlined once sent, solid once applied). Answered: the folded Choices heading names every chosen one.
  3. Add choice. Under an addable set, an Add choice button adds a new card Owen fills in: a title, a note (an <epic-text-box>), and an optional pasted or dropped picture, saved as the test run saves its screenshots. As many as he likes; each removable until sent; kept as a draft across reloads.
