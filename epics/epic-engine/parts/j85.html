spell-epic can't depend on @spell-app/page-server: it is spell-app's, and spell-app is above spell-epic (it runs it). So EpicServer.buildBundles() now loads BundleBuild at run time from the DEFAULT repo's checkout, through that checkout's own install (resolvedFile('@spell-app/page-server', checkout)); a default repo without it builds nothing. Epic UI's site bundle likewise comes from the default repo's settings, else Spell UI's own site/_assets.

  • Alternative: spawn spell-app's CLI by path (cli/bin/spell.mjs dev bundles build --stale) and drop the wait-for-missing-file handler.
