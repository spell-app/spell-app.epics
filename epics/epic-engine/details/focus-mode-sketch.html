  • Which items: the open ones drawn red (needs you), orange (changed since you looked), blue (Claude is on it) and yellow (open), by the same colour rule the page uses. Done and grey ones never show.
  • Tabs: one per kind that has any: Phases, Questions, Todos, Calls (judgement calls), Issues, Tests. Each tab's count follows its chips.
  • Chips: the section's own state chips, so a click hides the yellows (say) in that tab, and remembers it.
  • The buttons: exactly the item's buttons on the page (a question's Approve / Revisit / Details, a test's Approve / Revisit / skip, a waiting plan's Accept plan ...): the same mark, the same Send.
  • Back / Next: the arrow keys too. Pressing a button keeps you on the item (so you see it marked); Next moves on. The last item of a tab goes on to the next tab.
  • Keeps its place: the tab, the item and the chips, across reloads. An item Claude closes while you're on it stays until you move on.
  • Send: the header's Send and its countdown stay where they are, above the overlay.
