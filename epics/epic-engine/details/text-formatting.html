Formatting while you edit: what and how it looks

The phase after Edit Text in Place adds formatting to its edit box. Pick what you can format, what the box shows while you type, and where the formatting buttons sit and how they look.

session 🚧 epic-engine, planning the phase after P60 2026-11-02
epic-engine -- the epic pages, guides and their tools. P60 · Edit Text in Place (being built now) lets you ⌥-click a guide's text and edit its markdown right there. You asked for a phase after it for bold, italic, headings and the like: "Present options both what makes sense to edit as well as visual styling for the toolbar". What the next phase builds, and its size: between about 2 and 9 hours, mostly set by Q2.
  • The box P60 builds holds one piece of a <ui-markdown> block: a paragraph, a list item, a heading or a table cell. Formatting applies inside that piece.
  • Every format here is markdown, so the file stays markdown: bold is **bold**, a heading is a line starting ##.
  • Keys inside an open box mean formatting, as in any editor.
    • ⌘ I is italic there; outside a box it's still "comment on the selection".
    • ⌘ B hides VS Code's side bar, and ⌘ K starts VS Code's two-key shortcuts: the box keeps them from reaching VS Code while it's open.
  • Nothing in Spell UI formats text today: the buttons are <ui-button>s in a <ui-toolbar>, and the bold / italic / heading icons are added from the icon pack Spell UI already ships.

Which formats get a button and a key? Pick any; the recommended ones are what guides use most.

⌘ B, ⌘ I: wraps the selection in ** or *, or unwraps it.

A paragraph becomes a heading, or a heading changes level or back to a paragraph: a small menu of Paragraph, H2, H3, H4.

No H1: that's the page's own title. A heading inside a section is drawn one level lower already (heading-offset), so the menu names them as you'd see them.

⌘ K: asks for an address, and the selection becomes [text](address); on a link, it edits or removes it.

⌘ E: wraps the selection in backticks, for names like epic inbox.

Bulleted and numbered, and indenting a list item. Each list item is its own box in P60, so this means turning a paragraph into a list, or a list item back. About +1h.

~~text~~, for crossing out without deleting.

Removes every mark from the selection.

Where do the formatting buttons show while a box is open?

A small bar appears just above the box when it opens (below it near the top of the window), and goes when it closes. Close to the text; never moves the page.
