The generated JSX types are their own small TypeScript program (beside Spell UI's browser and node programs), and their test is another.

  • Why: in Spell UI's main program they'd clash with the docs elements' loose DocsJSXTags declaration (TS2430), and turn every docs element's JSX strict at once.
  • Its declarations are still built for other repos (spell-types lists the new program), so import type {} from "spell-ui/jsx" works everywhere.
  • Measured: with the types in Spell UI's main program, 11 errors (10 in the docs elements' JSX, 1 the clash). P2 folds them in and drops the separate program.
