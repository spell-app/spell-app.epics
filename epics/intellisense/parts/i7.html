The element core types an attribute's getter (this.size) from its vocabulary, but only an INLINE value list narrows it.

  • A shared set, like the sizes or the hues, reads as plain text (string).
  • So does a free-text attribute meant as a hue.
  • Both are still checked against the set as they're read.
  • So handing it on to a <ui-*> tag, now typed exactly, needs a typed cast, marked HACK::
    • spell-ui:
      • UIDocsThemes: its size, to its <ui-dropdown>
      • UIDocsToc.menuSize: to its two <ui-menu>s
    • spell-epic: EpicOption's badge color (a plain-text attribute), to its <ui-label color>
  • The fix: the kit's SpecValue reads a shared set's VALUES from a registry Spell UI fills.
    • As Spell UI fills ValueSetNames with the sets' names today.
    • Then this.size is the sizes.
    • badge-color takes values: "hues".
    • And the casts go.
