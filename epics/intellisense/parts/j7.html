Chose to point the kit's VS Code settings at TypeScript 6 (installed as @typescript/old, beside the TypeScript 6 package the repos already have) and to turn off the TypeScript 7 native preview there, over pointing at node_modules/typescript as planned.

  • Why: node_modules/typescript is TypeScript 7, which has no editor server that loads plugins (its folder has no tsserver at all). The native preview loads none either.
  • What you'd notice: your user settings turn the native preview ON; in a window opened on the kit's folder, the editor now uses TypeScript 6 instead, the same as spell-app's own settings already do. tsc and yarn ts still run TypeScript 7.
  • The settings use VS Code's new names (js/ts.tsdk.path, js/ts.tsdk.promptToUseWorkspaceVersion, js/ts.experimental.useTsgo); the old typescript.tsdk names are deprecated in this VS Code.
