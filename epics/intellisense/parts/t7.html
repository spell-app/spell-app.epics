epic window init writes the three TypeScript settings (windows.settings) into every window file that exists.

  • This epic's included: intellisense.code-workspace.
  • A new window file gets them as it's made.
  • Only after the merge: epic window reads the MAIN checkout's epic settings (config.json5), and the key is on this branch.
  • Not run here: it rewrites other epics' window files too.
  • To try it in this window before then: "TypeScript: Select TypeScript Version", then the workspace version (folder 1's).
  • The HTML and CSS data need nothing: they work in this window now, from the worktree's own settings.
