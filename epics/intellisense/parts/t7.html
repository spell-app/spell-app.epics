epic window init writes windows.settings (the three TypeScript settings) into every window file that exists, this epic's included (spell.epics/windows/ongoing/intellisense.code-workspace); a new window file gets them as it's made.

  • Only after the merge: epic window reads the MAIN checkout's .epic/config.json5, and the key is on this branch.
  • Not run here: it rewrites other epics' window files too.
  • To try it in this window before then: "TypeScript: Select TypeScript Version", then the workspace version (folder 1's).
  • The HTML and CSS data need nothing: they work in this window now, from the worktree's own settings.
