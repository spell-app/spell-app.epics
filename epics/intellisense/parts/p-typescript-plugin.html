Types can't say which slots a parent tag has, or which parts a component exposes.

A TypeScript language-service plugin in the kit, reading the same vocabularies, adds what types can't.

  • Each repo's tsconfig loads it, through VS Code's workspace TypeScript.
  • What it does exactly is a question first (Q6).
  • Typing slot=" in a child completes the parent tag's slot names, with their descriptions.
  • An unknown slot name shows a warning.
  • Inside a component's own JSX, part=" completes its parts (if Q6 says so).
  • Where to see it: any .tsx file.
    • slot=" on a child of a custom tag lists the parent's slots.
    • part=" in a component's own JSX lists its parts.
    • A misspelt slot, part or dashed attribute gets a warning, with "did you mean".
    • Hand check: V1.
  • It needs VS Code to run the repo's TypeScript 6 server: accept "Use Workspace Version" once. In kit windows that turns off the TypeScript 7 preview (J7, red: it overrides your useTsgo setting).
  • Children are not checked: no vocabulary says which children a tag takes (J8, T5).
  • It reads each package's Custom Elements Manifest, so Spell Brand's tags work too.
