  • Why: the shared value sets (hues, sizes ...) are Spell UI's, and the kit may never import Spell UI. The kit generator would have typed every color as plain string.
  • ElementManifests already reads every vocabulary with the sets resolved (the site data), and already has typeText(), the type of each attribute.
  • Spell Brand writes its files with the same class, so its JSX types (T1) come almost free later.
