TypeScript never checks a JSX attribute whose name has a dash in it: <ui-button text-alin="x"> passes, where sise="large" is an error.

  • That's how data-* stays allowed, so it can't be turned off for one tag.
  • A dashed name the vocabulary DOES name is still typed: a wrong value is caught.
  • Only a language-service plugin could flag the name itself.

Since P5: the TypeScript plugin warns on a misspelt dashed attribute in the editor, with a "did you mean" (J9).

  • Still open for tsc and yarn ts: they run no plugins, so the misspelling passes there.
