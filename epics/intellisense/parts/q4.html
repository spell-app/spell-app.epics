Our events are hyphenated (ui-change, ui-toggle). Solid's onUiChange listens for uichange, so it can't bind them; today we attach them in a ref.

  • each set's events join TypeScript's event map, with their detail type
  • ref={on("ui-change", (event) => event.detail.value)}: the name completes, event.detail is typed
  • also types addEventListener("ui-change", ...) anywhere
  • attributes only; events stay as they are, untyped
  • one shared on() helper in the kit's element folder, typed by every set's event map
