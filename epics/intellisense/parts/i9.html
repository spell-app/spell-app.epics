Why it happens: an epic window has the kit open TWICE, once as the epic's worktree and once as the main checkout.

  • VS Code's HTML support collects the data files named by EVERY folder in the window into one list.
  • Both kit folders name their own copy of Spell UI's HTML data, so each tag is offered twice.
  • CSS is the same. A window opened on the kit alone (one folder) is fine.
  • Pairs with J7's option A: an extension can hand VS Code the HTML and CSS data itself, once per window.
  • The kit's folder settings stop naming the data, so nothing is doubled.
