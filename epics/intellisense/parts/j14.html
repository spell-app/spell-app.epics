Each repo's yarn site:data now also writes css-custom-data.json, VS Code's CSS data, beside the HTML data.

  • Custom properties: each family's tokens, with its default and its tag in the hover docs. Spell UI: 1,326; the brand: 62.
  • Parts and custom states: VS Code's CSS data names them as whole names, ::part(icon) and :state(open), so they're in. Spell UI: 136 parts, 103 states; the brand: 38 and 18.
  • What it can't do: tie a name to a tag. So they're offered after ANY selector, and each one's docs list the tags that have it, and what it is on each.
  • Inside var(--, VS Code completes only the variables the file itself declares: the data completes a custom property where you SET it, as a property name.
