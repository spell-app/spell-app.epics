Eleven Spell UI type names appear in event details (close reasons, form changes, field values, search results, the visibility calculations ...). The generator now writes each as the real type, through the core entry's namespaces, rather than mapping them to unknown.

  • The DOM's and TypeScript's own names stay as written.
  • Any other name makes yarn site:data throw, naming the table to add it to.
  • Fixed in the vocabulary: the property group's ui-invalid and ui-success said only 'as the form's', which isn't a type and showed so in the docs; they now spell the form's shapes out.
