A flag attribute's JSX type is boolean | "", not just boolean.

  • Why: Spell UI's own code writes flags as primary="" (the attribute's own text), and Solid 2 sets true as "", removes on false. With boolean only, 46 more errors.
  • Not "true" / "yes" / "false", which the elements also read: tighter, and no code writes them.
  • Numbers take number or its text. A value set that also takes free text (width) keeps offering the set.
