A flag attribute's JSX type is boolean | "", not just boolean.

  • Why: Spell UI's own code writes flags as empty text, and Solid 2 does the same.
    • Spell UI writes primary="", the attribute's own text.
    • Solid 2 sets true as "", and removes the attribute on false.
    • With boolean only, 46 more errors.
  • Not the other words the elements also read as flags: tighter, and no code writes them. 
    "true"  "yes"  "false"
  • Numbers take number or its text. A value set that also takes free text (width) keeps offering the set.
