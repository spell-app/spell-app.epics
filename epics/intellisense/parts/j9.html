A dashed attribute a custom tag doesn't have is a warning with a 'did you mean' (the kit's own suggest(), at most two letters off). Allowed besides the tag's attributes: data-*, aria-*, and on- plus each event the tag dispatches (on-ui-change).

  • Namespaced names (on:click, prop:value) and undashed ones are left to TypeScript.
  • The manifests don't list attribute aliases; today the only alias (a tab's active) has no dash, so nothing is missed.
  • Run over every .tsx file of Spell UI, the app, Spell Epic and Spell Brand: no warnings, so no false alarms today.
