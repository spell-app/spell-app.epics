Wherever a ui-* event is heard, event.detail is untyped.

Each event is a typed on-ui-change prop in JSX, the shape solid-17 settled and built, and joins the event map, so addEventListener and refs are typed too.

  • event.detail is typed per tag in JSX; the prop list is closed, so a typo errors.
  • In plain code, querySelector("ui-input") gives an element whose listeners are typed; on the document every event name completes, its detail unknown (J12).
  • Detail types name real types, checked by yarn site:data (J13).
