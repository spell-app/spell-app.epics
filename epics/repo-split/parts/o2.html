Owen checked every top-level folder of every repo on 2026-10-20, and decided where each one goes. Two tables, as he decided them:

  • the spell command-line tool, which was two tools in one package then
  • every repo's folders: what stays, and what moves or goes

What changed after:

  • CLI to the Kit (P13) put the program's base in the kit's cli folder (Q42).
    • spell dev is gone: the kit's own commands are top-level, e.g. spell server
    • Its docs commands were deleted, and its pack command became spell pack create (Q46).
  • One Import Name (P14) moved every repo's code folders under ONE src/ (Q47), and the assembler into the server (Q43).
    • So spell-lang's parser/ is src/parser/ now, and the same in every repo.

The spell command-line tool

It was one package, spell-app's cli/, holding two tools that need very different things.

  • The program itself and the repo tooling go to the kit, in a later phase of their own, CLI to the Kit (P13).
  • Each repo adds its own commands to it, and a command goes under its repo's name only when two repos want the same word (the decision on the CLI, Q33).
