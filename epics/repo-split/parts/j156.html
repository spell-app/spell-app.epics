spell-brand's Vite config imports spell-ui/vite.config.ts. Vite leaves a file under node_modules external, so node loads it, and node adds no extension: spell-kit/element-tools/elementConfig failed with ERR_MODULE_NOT_FOUND.

So it imports spell-kit/element-tools/elementConfig.ts, HotElements.ts and spell-ui/tools/environment.ts (the "./*.ts" keys). Likewise createRequire().resolve("spell-kit/util/index.ts"), since require can't resolve a folder through "./*".
