spell-brand's Vite config imports Spell UI's vite.config.ts. Vite leaves a file under node_modules external, so node loads it, and node adds no extension:

  • spell-kit/element-tools/elementConfig failed with ERR_MODULE_NOT_FOUND.

So it imports these with the extension written, by the "./*.ts" keys:

  • spell-kit/element-tools/elementConfig.ts
  • HotElements.ts
  • environment.ts
  • Likewise createRequire().resolve("spell-kit/util/index.ts"), since require can't resolve a folder through "./*".
