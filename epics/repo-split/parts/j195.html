With the repo named spell-parser, the word its commands go under is parser.

  • spell lang packs check|fix and spell lang translate are now spell parser packs ... and spell parser translate.
  • Why: the clash rule puts a repo's clashing commands under its short name, the repo's name less spell-; keeping lang would need a second name for the repo, and Owen didn't like the lang bit.
  • The kit's short name stays kit (its package is spell now).
  • Type spell parser translate ..., not spell lang translate ....
