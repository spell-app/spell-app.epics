spell icon and spell ssr used chalk in spell-app. Spell UI doesn't list chalk as a dependency, so rather than add one, they now dim and colour their lines with node's own styleText() (no colour into a pipe, or with NO_COLOR, as chalk did).

Also, Spell UI's site tools start the page server differently:

  • the tools: yarn site:dev, yarn site:check
  • they started it with spell-app's spell dev server ensure
  • they now run the kit's spell server start, found by package (spell-kit), in spell-app's folder as before
