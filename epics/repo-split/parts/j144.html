Chose to move ALL of the toolchain into src/toolchain/, over leaving the config files in a toolchain/ folder at the root:

  • its modules
  • tsconfig.base.json
  • its types' index.d.ts
  • and its two bins, into the kit's bin/

How the names still work:

  • Every name other repos use stays.
    • Two names are exact exports keys, pointing into src/toolchain/:
      • spell-kit/toolchain/tsconfig.base.json
      • spell-kit/toolchain/types
    • The rest, ./toolchain/*, point at its TypeScript files, with the extension (*.ts).
    • So plain node and import.meta.resolve() find spell-kit/toolchain/aliases.
  • The bins import the toolchain by PATH (declarations.ts), not by package name: node runs them as they are, in any repo, before anything is linked.
