The root package.json's "pageServer" gets "pageScripts": module scripts added before </body> of every HTML page served (after the docs bundle's classic script, which a module runs after).

  • src: the URL (/element/spell-language.js); file: the file it is, so a checkout that hasn't built it serves pages without it, never a 404; skip: URL prefixes, matched without /worktrees/<w>.
  • Skips /components/: Spell UI's docs show no spell, and App UI loads <spell-code> from its pack.
  • The server's code names no app path.
