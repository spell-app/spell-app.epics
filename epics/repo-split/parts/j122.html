  • spell dev plan-doc phase <name> <N> done became epic phase <epic>#P<N> done

    • estimate
    • phase-body
    • rename
  • original became epic restore; the rest kept their verb.
  • Notes about the past keep the old name ("once spell dev details"), and test fixtures and generated files were left as they are.
