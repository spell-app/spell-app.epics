Epic UI's component pages (spell-epic/src/docs/epic-*.html) named about sixty spell dev plan-doc ... commands, in the tool's own order. They're now written the way epic takes them:

  • spell dev plan-doc phase <name> <N> done became epic phase <epic>#P<N> done
  • estimate, phase-body and rename, which epic folds into one verb, became epic update <epic>#P<N> --estimate ... / --goal ... / --title ...
  • original became epic restore; the rest kept their verb.
  • Notes about the past keep the old name ("once spell dev details"), and test fixtures and generated files were left as they are.
