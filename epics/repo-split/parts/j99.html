Chose a bin in the kit's toolchain, spell-folders <check> [folder ...] (FolderChecks).

  • A "spellFolders" list drives it, in each several-folder package's package.json: name, lint, fmt, tests, node, python.
  • Over copying the kit's kit.ts into spell-lang and spell-app, or 35 per-folder root scripts.
  • Because the three packages have the same shape, and one copy keeps them in step.

How it runs:

  • The kit's kit.ts is gone (J80's runner). yarn kit:ts ... run spell-folders.
  • Folders run one after another; the old yarn workspaces foreach -p -j 4 ran them in parallel.
  • Every folder runs, failed or not.
  • At spell-lang's and spell-app's root, yarn ts | test | lint | lint:fix | format | format:check run spell-folders.
    • So do py's and spaces' ruff and pytest.
  • yarn spell-folders test parser core: only those folders
  • a folder has no scripts of its own: yarn test inside one runs the repo's
