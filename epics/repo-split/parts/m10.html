1. Push main to GitHub (the workflow has to be there).

2. On npmjs.com, for each of spell, spell-ui, spell-epic: Settings › Trusted Publisher › GitHub Actions: organization spell-app, repository spell, workflow publish.yml, environment empty.

3. Within 2 days, on GitHub: spell-app/spell › Actions › Publish › Run workflow, tag next, dry run on; then again with dry run off.

4. Then each package's Publishing access: Require two-factor authentication and disallow tokens; revoke the 30-day token and delete its line from ~/.npmrc.

All three packages publish under next from the Actions run, each showing provenance on npmjs.com.
