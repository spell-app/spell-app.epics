Once T72 is pushed, in Terminal on the work computer:

cd ~/www/spell && git pull && yarn install
cd <your app project>
spell local on
spell local

Then type /reload-plugins in Claude Code, and reload the VS Code window (Cmd+Shift+P, Developer: Reload Window).

spell local lists every row as [your checkout]: spell, epic, yarn spell, yarn epic, skills, the epic@spell plugin, the VS Code extension, the page server, and the project's worktrees. Only the app's own Spell imports stay on npm, and the old checkout's servers are listed with the command to stop them.
