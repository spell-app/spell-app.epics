Chose one short workflow per repo (checks.yml), over a reusable workflow kept in spell-kit. Each one:

  • checks out spell-kit at the same-named branch if it has one, else main
  • puts the commit under test inside it
  • runs yarn clone <repo> --branch <branch> --https --shallow

Why:

  • A reusable workflow's ref is fixed in the YAML (@main), so it couldn't follow the branch under test.
  • The cloning logic lives in the kit's repos.ts, so it does follow the branch.
  • yarn clone takes --branch, --https, --shallow and --no-install
  • the five child workflows are the same apart from the repo's name, uv (spell-lang, spell-app) and the extension's install (spell-epic)
  • the kit's own workflow runs kit:ts, kit:lint, kit:test
