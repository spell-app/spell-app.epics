The task preferred folding into on / status. status lists the epic page server and each page or vite server not running your checkout (pid, port); on lists them and says to type spell local on --stop, which stops them (SIGTERM) and starts the epic page server again from the checkout (epic hub start). A page server is not restarted: the output says spell server start. A vite server counts only when it runs from a Spell checkout, never a project's own. spell server prune now also knows npm's built page server and the epic server (prune.ts' kinds), so an orphan one goes with its removed worktree.
