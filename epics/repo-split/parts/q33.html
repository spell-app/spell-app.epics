The spell program itself moves into spell-kit, and each repo adds its own commands to it.

  • The program itself: reading its arguments, its help, finding its commands.
  • Owen would notice nothing when he types a command: spell compile, spell run and the rest keep their names. So does spell dev pack build.
  • Owen, 2026-10-20, after the folder audit (Where every folder goes): "seems like the base for the tooling (spell ....) should live in the kit, then hand off to spell-app for app-specific stuff".
  • Today the CLI is two tools in one package, spell-app's cli/:
    • spell dev, the repo tooling, which needs only the server, the assembler and Spell UI
    • the language and app commands, which need spell, the language server, spaces and the app's runner
  • How a repo adds its commands: its package.json names its list of commands, and the kit's spell reads the list of every repo that's installed.
  • Where a command's name goes:
    • at the top level by default, so every command keeps the name it has today
    • under its repo's name ONLY when two repos want the same word: then both go under their repo's names, and the bare word is neither's
  • Owen picked "namespace only for clashes" over two other ways:
    • a namespace per repo for every command (spell lang compile), which renames everything
    • refusing a clash outright, which makes one repo pick another word
{
  "name": "@spell-app/app",
  "spell": {
    "commands": "./cli/commands.ts"
  }
}
