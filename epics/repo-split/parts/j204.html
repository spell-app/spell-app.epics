spell/no-upward-import (the toolchain's lint.imports.ts), on everywhere, stands in for the clone that kept each repo to the ones below it.

  • The order: the kit's own src/, then its workspaces in order: parser, ui, epic, app. A folder may import the kit and the folders before it.
  • So it's a little looser than the repos were: ui may import parser, epic may import parser (neither does today). A per-folder needs list could make it exact; not worth a second list yet.
  • A file outside the kit (spell-brand) may import anything, as any project of spell may.
  • importNameFor() names a folder's file spell/ui/..., never its own package.json's name.
