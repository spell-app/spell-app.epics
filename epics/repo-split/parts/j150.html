Per the spell-lang agent's contract, spell-types reads two kinds of "spellTypes" entry:

  • An entry ending .json is a TypeScript program.
    • It's built with rootDir the package root, into the one dist-types/.
    • No paths, and no $/ rewrite.
  • A folder entry (spell-app, spell-brand) keeps the old alias re-pointing and rewrite.
  • --below finds a repo's root without an alias table by its package.json.
  • The alias hook, the alias lint rules and the rewrite code stay until the last step.
  • The lint rules know the kit's src/<folder>/.
