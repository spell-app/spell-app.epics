The repos are held together by a new top repo, spell, checked out at ~/www/spell. It holds nothing anyone imports: only what makes the child repos one install.

  • Owen's comments on the layout page, 2026-10-19: "the top project is just spell"; every package moves into another repo; "rethink this with the minimal set in the root repo".
  • The child repos are cloned inside it, git-ignored, each still its own git repo with its own history.
  • It replaces Q11, where spell-app itself was the meta repo.
