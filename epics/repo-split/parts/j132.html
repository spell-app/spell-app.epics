The bundles and the editor are named by spell-app's page server settings: "pageServer" in its package.json. Run from the kit's root, there are none there.

So these commands look for them:

  • spell bundle
  • spell server start all
  • spell server stop all

They use:

  1. the nearest folder up from where you are whose package.json has page server settings
  2. else the installed repo that has them (spell-app)
  3. else the nearest git checkout

start all waits for the editor and checks Spell UI's site only when those settings run the app's routes and name Spell UI's set. It was spell-app's serve.mjs, which still named the monorepo's paths.
