Setting up the whole thing is two yarn commands in the top repo: yarn install, then yarn clone. No node scripts/... step.

  • Owen's comment on the layout page, 2026-10-19: "I don't like the node scripts/... ... OK if it's a second command after or before yarn install".
  • The first yarn install is quick: there are no child repos yet, so nothing to link.
  • yarn clone reads repos.json5, clones every child repo that isn't there yet, then installs again: one install for all of them.
  • yarn clone spell-ui clones Spell UI and only the repos it needs.
  • yarn pull and yarn status run git over every child repo.
git clone <spell's URL> ~/www/spell && cd ~/www/spell
yarn install          # quick:  no child repos yet
yarn clone            # every child repo, then one install for all of them
yarn clone spell-ui   # or:  spell-ui, spell-element, spell-server, spell-util
  • the three scripts, clone, pull and status, built in P7
  • P7 first checks that yarn install works with no child repos
