spell-app keeps six packages: app, spaces, lsp, cli, vscode and the new page-server. Together they are the editor and its servers.

  • Chose one repo for them over more repos, because they are one product and change together.
  • The editor app runs on spaces' models, the language server reads spaces' projects, and the CLI and VS Code extension drive both.
  • page-server, the page server's Spell layer (component sets, engine routes, bundles), lives here because only spell-app runs it.
  • spell-app is the highest code repo: it needs spell-lang, spell-brand, spell-ui, spell-server, spell-util; spell-epic by the page server's settings only
  • the spell language's VS Code extension stays its own yarn project inside it, as today
