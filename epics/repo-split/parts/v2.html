1. In this window (⎇ repo-split), open spell-app/spaces/@spell/library/cards/Card.spell.
  2. Open VS Code's Output panel: menu View › Output, or ⇧⌘U. It opens along the bottom of the window.
  3. In the drop-down at the right end of that panel's top bar, pick Spell.
  4. Find the line that starts Language server from.
  5. Back in Card.spell, hover over a word, then start typing a new line.
  6. Do steps 1-5 again in the main spell window, with the same file from ~/www/spell.

In ⎇ repo-split the line reads Language server from ~/www/spell.worktrees/repo-split/spell-app...; in the main window, Language server from ~/www/spell/spell-app.... In both, hovering shows a tooltip and typing shows suggestions.
