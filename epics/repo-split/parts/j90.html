Chose the name spell-pack build | check [<folder>] over keeping spell-ui-pack, because the tool isn't Spell UI's any more.

  • It's the kit's spell-pack.mjs, beside spell-types.
  • It runs the kit's ComponentPack.ts from source through tsx, with the pack's own tsconfig (else the tools').
  • The packs' generated files still say spell dev pack build <pack>, so the brand's and the epics' packs rebuilt byte for byte.
  • The bin and the build settings need three packages at run time, so they're the kit's dependencies now:
    • tsx
    • @solidjs/vite-plugin
    • lightningcss
  • yarn pack:build / pack:check in spell-brand and spell-epic run spell-pack. So does the CLI's pack template.
