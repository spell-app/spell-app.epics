Q44 left what epic summarize <epic>#J3 --file summary.html writes to be checked with you. An item has no summary of its own in the page markup: the only per-item summary is the one under Claude's status card (epic status seo#J3 done "<summary>"). So it writes that, from a file, as epic details writes details:

  • an underway card turns done with it, and the spinner goes off
  • a done or noted card has its summary replaced, or added to with --append
  • no status card: refused, saying to start one

Not picked: the Overview's own summary (the page's lede, which no verb writes yet), or a new summary slot on every item (a markup and element change).
