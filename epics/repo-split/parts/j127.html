Owen named spell server stop [local|all] beside spell server start all and spell server local. Read as:

  • stop or stop local: this checkout's page server, as spell dev server stop did (the editor, its child, stops with it).
  • stop all: every web server start all starts: the page server, then the app's editor from its record (.spell-server.editor.json) when it is still running, e.g. after the page server was killed without stopping it.
  • Not read as "every checkout's servers on this machine": spell server prune already covers servers whose checkout is gone.
  • spell server local runs the page server in the foreground (was serve); the page server's own command line keeps serve hidden, because a background server runs it and prune finds servers by it.
