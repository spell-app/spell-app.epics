Owen named spell server stop [local|all], beside the two commands that start servers:

  • spell server start all
  • spell server local

Read as:

  • stop or stop local: this checkout's page server. The editor, its child, stops with it: the same as spell dev server stop.
  • stop all: every web server that start all starts.
    • the page server
    • then the app's editor, from its record (.spell-server.editor.json), when it is still running: e.g. after the page server was killed without stopping it
  • Not read as "every checkout's servers on this machine": spell server prune already covers servers whose checkout is gone.
  • spell server local runs the page server in the foreground (was serve).
    • The page server's own command line keeps serve, hidden.
    • Why: a background server runs it, and prune finds servers by it.
