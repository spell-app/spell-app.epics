Chose to keep the kit's four $/ names, in one table, over renaming element's to $/element.

  • The names: $/util and the rest, in the kit's tsconfig.base.json.
  • Why: Q35 said the kit's $/ names can stay, and $/spell-element is also the run-time pack key (J72).

Where one folder imports another (element and assembler use util and the toolchain), the import says spell-kit/util/..., the package naming itself, not $/util.

  • Other repos' Vite, esbuild and tsx builds read element's source.
  • A $/ there would need the kit's alias table in every one of them.
  • import { camelCase } from "spell-kit/util/string" in element/src
  • the import lint treats each kit folder as a package (KIT_FOLDERS), so a ../ from one into another still fails
