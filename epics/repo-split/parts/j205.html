The kit command spell rename imports [--dry-run] [--json] [repos...] (ImportRenamer), grown beside tools/rename-packages.ts, which stays for P17's rename.

  • It renames: import names (spell-ui/x to spell/ui/x, a barrel from "spell-ui" to spell/ui, a published short name spell-ui/ui-button to spell/ui/ui-button), each <repo>-source condition to spell-source, paths naming the old folder (../spell-ui/site/_assets, [x](spell-ui/README.md), /spell-ui/src/x.ts) and GitHub links into a file on a branch.
  • Import or path: the context first (../, a Markdown link, from "), then what's on disk (the folder's src/<rest> resolves, or its tracked root has the first segment), quotes or backticks breaking a tie toward an import.
  • It leaves: bare repo names, longer names (spell-ui-site:), lint rule families (spell-ui/*), the GitHub org, links to commits and issues, saga addresses (SAGA:/spell-ui/seo), installed packages' paths (node_modules/spell-ui/, a CDN's npm/spell-ui/), a quoted prefix alone ("spell-ui/", an import map's), a template's slot (spell-ui/${name}), the rename's own description, changelogs, docs/drafts/, and the files that mend old paths (the Linker, RootLinks, tools/content-links.ts).
  • A second run changes nothing.
  • Counts: the old layout, dry run, 9,194 names in 2,770 files over 6 repos; the merged repo, 9,021 names in 2,805 files; spell-brand, 85 in 32 (then 3 more after merging its main).
  • What it can't know, fixed by hand (a dozen): bare names used as module specifiers (sourceOf("spell-ui"), a Map key), regexes over paths (/\\/spell-ui\\/src\\//), made-up test layouts.
