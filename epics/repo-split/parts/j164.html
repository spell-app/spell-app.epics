Every import in spell-epic is spell-epic/<path under src> now, with two kinds. That replaced 785 $/epics imports and every ../ climb.

  • Files plain node loads keep the extension they had:
    • the hooks
    • window.mjs
    • the docs tools' JS scripts, and the TypeScript files they reach
    • e.g. spell-epic/config/EpicConfig.ts, by the "./*.ts" key
    • e.g. spell-epic/tools/pages.js, by "./*"
  • Everything else: no extension, as the rule says.
  • Checked by walking the import graph from every plain-node entry, and by running each hook.
  • The one file code imports from outside src/ is the extension's docUrls.ts, for its test. It has an explicit exports key.
