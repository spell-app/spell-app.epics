Spell UI's templates/pack/ still write a new pack the old way:

  • a tsconfig.base.json alias table
  • components/ outside src/
  • a test that imports $/<pack>/components/<tag>

So spell pack add brand brand-x now puts the family in the right folder, but writes a test that imports $/brand/..., which no longer resolves. The templates need the P14 shape: one src/, imports by package name, and "spellPack": { "components" }.
