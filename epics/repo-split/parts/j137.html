spell-lang's code is under one src/, a folder per part. Each folder has its own AGENTS.md and CLAUDE.md:

  • parser
  • markdown
  • core
  • py
  • spell
  • cli

Where the rest went:

  • py's TypeScript (was py's ts folder) is the py folder itself.
    • spell_core, the uv project, is the core folder inside it.
    • So Python stays in one place with its writers, and spell-app's runCommand still finds it as the py folder's core.
  • Generated data files go with their folder:
    • core.declarations.json5 in core
    • spellSyntax.json in spell
    • and PARSING.md moves to spell too
  • Outside src/:
    • markdown's spec tools, in spell-lang's scripts
    • spell's old notes, in spell-lang's docs:
      • thoughts
      • CODEBASE_INDEX.md
      • graphify-out
  • Tests drop their inner src/. Each test sits at its code's path: Rule.test.ts tests Rule.ts.
