spell-lang's code is under one src/: src/parser, src/markdown, src/core, src/py, src/spell, src/cli (each folder's AGENTS.md and CLAUDE.md with it).

  • py's TypeScript (was py/ts/) is src/py/ itself; spell_core, the uv project, is src/py/core/: Python stays in one place with its writers, and spell-app's runCommand still finds it as the py folder's core/.
  • Generated data files go with their folder: src/core/core.declarations.json5, src/spell/spellSyntax.json; PARSING.md to src/spell/.
  • Outside src/: markdown's spec tools in scripts/markdown/; spell's old notes (thoughts/, CODEBASE_INDEX.md, graphify-out/) in docs/spell/.
  • Tests drop their inner src/: tests/parser/rules/Rule.test.ts tests src/parser/rules/Rule.ts.
