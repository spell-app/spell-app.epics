Decided over 'use the built ones': a repo's root yarn ts (and a flat repo's) first builds the lower repos it depends on.

  • It runs spell-types --below, which builds every package of the LOWER repos its packages depend on, lowest first.
  • It finds them by their @spell-app/* dependencies, through node_modules.
  • Incremental, so an up-to-date one costs about a second, and what a repo checks against is never stale.
  • A single package's yarn ts uses what's built (cd spell-lang/core).

spell-types --below still builds the lower repos first. It finds them by their workspace: dependencies (spell-kit, spell-ui ...), no longer by @spell-app/* names: the kit, and spell-ui for the repos above it (J79).
