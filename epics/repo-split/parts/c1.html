util moves into spell-app, the TOP repo (Q11), but the repos below it need util. No package imports one that imports it back, so there's no package cycle. But the REPOS loop: spell-app needs spell-ui, and spell-ui needs a package that lives in spell-app.

  • Who needs util: spell-parser (its five helpers), spell-element, and through it spell-ui.
  • Inside the meta checkout this is invisible: one install links spell-app's util/ to every child repo.
  • A lower repo cloned ALONE doesn't build, until util is published to npm (Q4's later step).
  • This narrows Q1's "no cycles": true of packages, not of repos.
