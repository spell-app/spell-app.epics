Inside each child repo, every package is a folder right at the repo's root, and a repo that is ONE package is that package, with no folder in between. There is no packages/ folder anywhere.

  • Owen's comment on the layout page, 2026-10-20: single-package repos "should just be embedded in their root, not in a nested folder".
  • Flat, one package (spell-ui, spell-brand, spell-element, and spell-epic as today): the repo's own package.json is the package's. Spell UI's components/, src/ and docs/ sit right in spell-ui/.
  • Several packages (spell-util, spell-server, spell-lang, spell-app): a folder each at the root, named as workspaces in the repo's package.json: spell-lang/core/, not spell-lang/packages/core/.
  • Tests, in a repo with several packages: tests/<name>/ at the repo's root, as today one level up.
  • Tests, in a flat repo: tests/ at the root, mirroring the code, with no package folder.
