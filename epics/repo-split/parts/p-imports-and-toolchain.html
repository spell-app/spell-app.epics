Every package names every other through one alias table in spell-app, and spell-epic copies the toolchain by hand.
  • Imports that will cross a repo use package names (@spell-app/ui/...); $/ stays inside a repo (Q8), and each package gets an exports map.
  • The shared toolchain becomes a package in a top-level toolchain/ folder, which every repo's configs import.
  • Reading an import says which repo it comes from.
  • Each package says what it exports, the shape npm needs at release.
  • One toolchain package holds the lint config, the lint patterns, the decorators plugin, the base tsconfig and the global types, in its own top-level folder (Owen's comment).
  • spell-epic stops copying any of it.
  • tsconfig.base.json, vite.lint.ts, vite.lint.patterns.ts, vite.decorators.ts, types/ move to toolchain/
  • each package's package.json and vite.config.ts
  • the crossing imports (a codemod; ~3,100 sites in 970 files before filtering)
  • yarn review passes at the root.
  • spell-epic's checks pass with its copied toolchain removed.
