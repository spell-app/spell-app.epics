The tabs live in spell-app's root package.json, "pageServer" "siteTabs", in the bar's order. The page server tells every page (SPELL_SERVER.siteTabs), and so does spell-epic's epic server, from its default repo's settings.

  • Not built from componentSets: the tab labels differ from the sets' names (Epic/UI, not Epic UI), the sets sit between other tabs (Epics, App), and the brand's set lights Brand instead of a tab of its own.
  • Each tab says what lights it: component sets by id (sets), path patterns (paths), docs area folders (areas). spell-server's litTab() checks sets and paths first, then areas.
  • The server's list wins. defineSite({ tabs }) is only the fallback for a page whose server names none, never merged in.
  • The page-by-page lighting table moved from spell-server's tests to spell-app's (tests/page-server/src/siteTabs.test.ts), beside the data it pins. spell-server keeps generic tests on a made-up site.
