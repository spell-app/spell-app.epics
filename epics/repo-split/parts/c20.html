The published packages have to ship built JavaScript: node won't run TypeScript from inside node_modules, and today every package exports its TypeScript source.

  • Node strips types only outside node_modules, on purpose, so packages don't ship TypeScript.
  • The code uses standard (TC39) decorators, which the build has to turn into plain JavaScript.
  • So Publish Prep builds each package to JavaScript plus declarations, and points the published exports at them, as Spell UI's built package already does; developing in the checkout keeps reading source.
