Spell UI's built package bundles the kit's element code inside it (only Solid is left out), so a project that installs both @spell/ui and @spell/element could load the element base classes twice.

  • Twice means two DOMElement classes: one's components fail the other's instanceof.
  • Publish Prep decides: leave @spell/* out of Spell UI's bundle and depend on it, or keep it inside and say so.
