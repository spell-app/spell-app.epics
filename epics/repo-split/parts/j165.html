spell-epic's packageDir() finds a package by its package.json entry. A sub-path is that folder under the package's src/, where the name points.

  • epic server / epic server start --all run tools from package spell-kit. Its tools list, EpicTools.TOOLS, names:
    • the page server's cli.ts, under tsconfig.node.json
    • spell.mjs
  • The rest find the kit the same way:
    • pages.js' ensurePageServer()
    • EpicServer.SOURCES watches the kit's server folder
    • pack.test.ts runs the kit's spell-pack.mjs
  • No --import spell-kit/toolchain/aliases anywhere in spell-epic:
    • its epic bin
    • the yarn scripts
