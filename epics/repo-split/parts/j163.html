sourceNames(), in spell-epic's packageDir.ts, is an esbuild plugin. It finds spell-* names as their source files, as spell-lang's library test does:

  • .ts
  • .tsx
  • a folder's index.ts
  • Used by the extension's build (build.mjs), replacing the alias hook's aliasedFile().
  • And by the docs bundle (bundle-spell-ui.js):
    • the docs runtime's spell-epic/links
    • the lazy engines' spell-ui/runtime/runtime.types
  • spell-lang's test and spell-brand's design bundle have their own few lines: a candidate for the kit's tools once every repo is in.
