@spell already means two things besides the new npm scope, and Owen wants to keep both: the built-in projects' space (@spell/examples/Solitaire, @spell/test, @spell/library), and the names compiled spell imports at run time. The second can collide with npm: a bundler or node that meets import ... from "@spell/core" looks for that package on npm. 

export const SPELL_CORE_MODULE = "@spell/core"
export const SPELL_ELEMENTS_MODULE = "@spell/elements"
