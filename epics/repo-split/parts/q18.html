The assembler's JSON5 writer moves into util, as a node-only entry of its own, @spell-app/util/json5. It writes JSON5 files with their comments kept.

  • Owen asked on the layout page, 2026-10-20: "Should assembler/json5 move into spell-util/util?". The page recommended yes.
  • For Spell UI, the app, brand and spaces, json5 is the ONLY thing they take from the assembler. With it in util, none of the four needs the assembler, or the HTML parser and formatter it carries.
  • util stays safe in a browser: only code that names util/json5 gets the node part.
  • Who uses it: 12 source files outside the assembler and 7 test files (counted 2026-10-20), so about 20 imports change.
  • spell-server now uses spell-util too (the assembler's data files read util's json5): one more arrow, still pointing down. 
// before:  packages/ui/tools/SiteDataBuilder.ts
import { json5Edited } from "$/assembler/json5"
// after:  spell-ui/tools/SiteDataBuilder.ts
import { json5Edited } from "@spell-app/util/json5"
  • done in P1, with util's trim, before the cutover
  • util takes json5-writer as a dependency
  • the assembler keeps its link resolver, its formatter, the bundles, its data files and the content folder lookup
