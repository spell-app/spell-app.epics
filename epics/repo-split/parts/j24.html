The catalog imports the pack's vocabularies, which import $/<pack>/... values (spell-epic's import $/epics/components/.../Fold.types).

  • So the bin registers tsx with the pack folder's tsconfig.json, else Spell UI's.
  • Spell UI's own tool files import only relative paths and type-only aliases, so any tsconfig runs them.
  • A side gain: spell-epic's vocabularies now resolve $/epics to spell-epic itself; through spell-app's CLI they went through the checkout's spell-epic link (the real repo, even from a clone).
