An npm package can only point at files inside its own folder, so once each kit folder is its own package (the shape decision, below), its declarations have to live inside that folder too, not in the kit's one dist-types/.

  • Node refuses an exports target that climbs out of the package (../).
  • Today @spell/util's declarations would be at the kit's dist-types/src/util/: outside src/util/.
  • So the declarations build writes each folder's into the folder itself (say src/util/dist-types/, git-ignored), and the lint, format and test globs skip it.
