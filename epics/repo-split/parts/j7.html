  • Now packageVersion(import.meta.dirname): each config passes its own folder, and the stamp reads that package.json.

  • Different in their own test runs:

  • No test depended on it but util's own, now reading util's file.
  • each repo can stamp its own version once split

The stamp still reaches into no other repo, but a folder rarely has a package.json of its own now.

  • Each config still passes its own folder; the stamp reads the nearest package.json at or above it, which is the repo's ONE package: the kit's 0.0.0 (J78), 0.8.0 for spell-lang and spell-app (J101).
