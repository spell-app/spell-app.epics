Linker, format, Bundle, DataFile and contentFolder sit in src/server/ and in the server's barrel:

  • SRV.Linker
  • SRV.formatHTML()
  • SRV.Bundle
  • SRV.DataFile
  • SRV.contentFolderOf()
  • their types and BUNDLES moved into server.types.ts
  • So the barrel now loads json5 and linkedom. formatHTML() imports vite-plus/fmt (oxfmt) when first called, so every server needn't load it.
  • spell-kit/server/DataFile and /contentFolder stay as names of their own, for code that wants them without linkedom.
  • The Bundle sources list names three folders, so every bundle's hash changes once, and each rebuilds once:
    • spell-kit/src/element
    • spell-kit/src/server/site
    • spell-ui/src (its components inside)
