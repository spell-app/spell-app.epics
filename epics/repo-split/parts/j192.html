The editor's page, index.html, now loads the app with import "spell-app/app" inside its script tag, instead of pointing the tag at a file path.

  • Why: the editor's dev server serves only what's inside spell-app's app/ folder, and since P14 the app's code is beside it, in src/app/. A path can't reach above that folder.
  • The package name reaches it the same way every other import in the repo does.
  • The production build bundles an inline script just as it did the old one: the build test still passes.

The other ways, and why not:

  • A one-line entry file inside app/: one more file to explain, doing what the inline line does.
  • A server rule mapping /src/ to the folder above: hidden, and only for the dev server.
  • Making spell-app's root the dev server's root: every URL and build path in app/ would change.
