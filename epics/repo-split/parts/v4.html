1. In VS Code, in the ⎇ repo-split window, open a terminal: menu Terminal › New Terminal. It opens along the bottom of the window, in the worktree's folder. 2. Type this, then press Enter: node bin/spell.mjs app serve @spell/examples/Solitaire 3. Look at your web browser. 4. Back in that terminal, press Ctrl-C.

Your web browser opens the Spell editor on Solitaire (the page server starts first, if it wasn't running). Ctrl-C stops what it started, and the terminal's prompt comes back.
