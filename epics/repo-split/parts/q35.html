Owen would notice one version number to bump, one set of scripts, and new import names everywhere the five are used.

What it costs, as the reply counted it:

  • 641 import lines in 582 files renamed, 622 of them outside the kit, in every repo.
  • 47 dependency entries, 31 TypeScript settings lines and about 200 mentions in docs.
  • Spell UI's users install everything the kit needs (Vite+, esbuild, parse5, linkedom): Owen accepts that, "disk space is cheap".
  • The browser-or-node check still needs one TypeScript setting per folder inside the one package: server and assembler are node only, element and util run in the browser.
  • The names every page's packs share at run time ($/spell-element ...) stay as they are, through packModuleKey() (the run-time keys call, J36): a judgement call of its own.
