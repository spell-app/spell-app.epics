  • Both bundles built the same: brand 247 files / 2824.0 KB, the site 187 files / 3085.8 KB.
  • ui's dev plugin finds HotDefinitions through spell-element's exports. It asks node (createRequire), not a path into spell-element's source.

ui's declaration build (declarations()) gets its own paths, mapping the npm names to source.

  • Without them TypeScript treats util and spell-element as a library reached through node_modules, and writes no declarations for them.
