Spell UI has two TypeScript programs, and spellTypes lists both.

  • tsconfig.json covers the browser code:
    • src/, except its tools and cli folders (below)
    • plus site/_src
  • tsconfig.node.json covers the node code:
    • src/tools
    • src/cli
    • scripts/
    • the Vite configs
    • with the DOM, Vite's client types and JSX, because the tools reach the browser source

The browser program used to get two things from the tools by accident:

  • node's types, which ServerRuntime.ssr.ts now declares itself (/// <reference types="node" />)
  • the <ui-dropdown> JSX type from the Solid host app.
    • It is now DocsJSXTags' (docs-components.types.ts), one declaration per program.
