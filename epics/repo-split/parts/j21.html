The generic engineRoutePath() applies every route under /worktrees/<w>/ too. Before, only /templates/ did.

  • So /worktrees/w/_epic/assets/x.js now serves the main checkout's engine file, where it answered 404 before.
  • A worktree has no _epic/ folder of its own, so nothing it served is shadowed.
  • It saves a per-route setting nobody needs.
