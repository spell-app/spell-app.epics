The kit's six per-folder tsconfig / vite / vitest configs (and the tests' seven tsconfigs) became:

  • tsconfig.json, browser-safe: util, element, the test helpers
    • no node types; util's node/ is the node program's
  • tsconfig.node.json, node plus the DOM: server, cli, element-tools, toolchain, util's node folder, bin, scripts, tools, the configs
    • It is ALSO the tsx settings every repo's code runs under (jsx react-jsx, target ES2020), for:
      • spell.mjs
      • the background page server
      • spell-pack
    • It was cli's tsconfig and server's
  • the tests' tsconfig.json: the node program's settings with Solid's JSX
  • ONE vitest.config.ts of projects: util, util:node, element, server, element-tools, cli, toolchain, tools
  • ONE lint config, the root vite.config.ts
  • kit:* are plain scripts, no spellFolders

The browser program's target is ES2020 (util's), so element went from ES2022 to ES2020. Under ES2022, tsc 7 reports Logger.WARN used before its initialization (TS2729) in util's Logger, which element never reached before.
