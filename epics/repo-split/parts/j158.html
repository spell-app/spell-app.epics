Read from Owen on J141 ("(re-)condense the text/conversations in that section after a lot of back and forth"):

  • epic summarize <epic>#<id> --file condensed.html: the file replaces what the item shows.
  • Everything that was there moves into the item's Original Discussion as ONE version, folded: its text, every reply (Owen's and Claude's), More Details, option cards nobody picked, asides, code. Nothing is lost.
  • Stays: the question as asked, the answer, option cards Owen picked from (a picked set inside a moved reply is copied out, so the pick still shows), Claude's status cards, commits, and his marks (reviewed, calm, queued ...).
  • Logged; the item is stamped but not flagged UPDATE: it says the same thing, shorter.
  • Items only: an Overview sub-section or a phase has no Original Discussion to fold into, so it's refused there. Giving them one would change those elements, so that waits until it's asked for.
  • No markup change, so no migration step.
  • The epic skill's new step 13 covers it: read the whole item and its thread, then write the condensed text (plain words, bullets, every decision and number kept, open options as fresh option cards, open questions at the end), then epic summarize.
