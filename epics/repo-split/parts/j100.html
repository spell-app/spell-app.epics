Chose to prefix each folder's own scripts with its folder, but to keep the app's unprefixed at spell-app's root.

  • each folder's own, prefixed:
    • spell:gen:syntax
    • core:gen:declarations
    • markdown:spec:update
    • spell:test:fixtures ...
  • the app's, unprefixed, each cd app && ...:
    • build
    • build:runner
    • build:element
    • build:page
    • start
    • site:data ...

Why the app's stay as they are:

  • the CLI and the VS Code extension run yarn build:page / build:runner in app
  • the generators list runs yarn site:data there

Renamed and dropped:

  • lsp's start:lsp became lsp:start (the commands page's own target, R8).
  • lsp's scopes became lsp:scopes.
  • Dropped each folder's test:watch: run yarn vp test in the folder.
  • Dropped spell's dev, which ran the old CLI's spell.mjs, gone since P8.
  • spell-lang's generators list runs yarn spell:gen:syntax
  • yarn cli:install and the spell bin are spell-app's root's
