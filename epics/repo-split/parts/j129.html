spell --version used to print the parser's version (spell-app's CLI ran spell's source). The program is the kit's now, and every repo adds to it, so it prints one line per installed repo:

  • spell-kit 0.0.0
  • spell-lang 0.8.0
  • spell-ui 0.0.1
  • spell-app 0.8.0

Also kept from before: --all and --verbose are still flags every command takes, now the kit's.
