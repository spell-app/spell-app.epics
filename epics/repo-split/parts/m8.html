1. On the work computer, in Terminal, check Node is 24.11 or later, and yarn is there: 
    node --version
yarn --version
  2. Clone both repos side by side (your SSH key on GitLab): 
    mkdir -p ~/www/psiquantum && cd ~/www/psiquantum
git clone git@gitlab.psiquantum.com:software/quantum-os/epics.git
git clone git@gitlab.psiquantum.com:software/quantum-os/jarvis-spell.git
  3. Install (Spell 0.9.0 from npm, and what its editor needs): 
    cd ~/www/psiquantum/jarvis-spell
yarn install
  4. Set up the epic plugin and the VS Code extension; answer its name and colour questions: 
    yarn epic init --no-commit
  5. Start Spell, and leave it running: 
    yarn start
  6. In a browser, open http://localhost:3000/ (the port yarn start printed for the editor, if not 3000).
  7. It asks Your name, @psiquantum on the right of the field: keep the name it suggests from your git email, or type your own, and press Start.
  8. On the home page, click New Jarvis Console under Jarvis; go back, then Jarvis Current.
  9. In jarvis-new, change a word in home.spell, wait a second, then press Publish.
  10. Reload the page.
  11. In a second Terminal: 
    cd ~/www/psiquantum/epics && git status --short
cd ~/www/psiquantum/jarvis-spell && epic list
  • yarn install ends with no error
  • yarn epic init says it installed the plugin, links epics, sagas, guides and pages, and makes nothing on GitLab
  • the first page is Welcome to Spell, one field, Your name, prefilled from your git email (kim.lee@psiquantum.com as kim-lee), @psiquantum joined on its right
  • after Start, the home page lists Apps (yours, empty) and Jarvis, with New Jarvis Console and Jarvis Current
  • the editor shows New Jarvis Console: JarvisNew.site.spell on the left, the console with its side bar on the right; Jarvis Current shows the screens' snapshots
  • the reload goes straight to the editor: no name asked
  • after Publish, git status in epics lists spaces/@psiquantum/jarvis/jarvis-new/home.spell as changed, and your new space, spaces/@psiquantum/<you>@/
  • epic list runs, listing the epics in epics (none yet: an empty list, no error)
