When spell local on finds spell on the PATH already linked to a DIFFERENT checkout, it points the link at this project's checkout and says so. It records the old target in ~/.spell/path-link.json, and the last spell local off puts that link back instead of removing it.

A link to the SAME checkout that you made by hand is left alone and not recorded, so off never removes it. yarn cli:install forgets the record, which makes the link yours again.
