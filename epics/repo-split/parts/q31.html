The top repo, checked out at ~/www/spell, stops being only the install: it becomes spell-kit, holding the layer every other repo stands on. Owen would notice it as six repos instead of nine, and one commit where a change to util, the server and the element base took three.

  • Owen, 2026-10-20, after asking why spell-util isn't in the top repo: "What if we moved spell-server and spell-element into the hub also and called it spell-kit?"
  • Then, on where they go: "kit + generic. DO NOT put things into packages".

What the kit holds:

  • Five packages, each a folder right at the kit's root, with no packages/ folder (Owen's words, and Q16's rule):
    • util/ and toolchain/, from spell-util
    • server/ and assembler/, from spell-server
    • element/, from spell-element (a flat repo today)
  • The house style, WWOD, tracked in the kit.
  • What the top repo already holds: the one install, the list of repos, and the clone, pull and status commands.
  • NOT the three logs (papercuts, suspected bugs, code debt): they stay in the content repo, spell.epics.

Why it's safe now:

  • No child repo builds alone today anyway: every setup clones the top repo first.
  • The CI planned in Multi-repo Tooling (P12) clones the top repo first too.
  • The toolchain already reads the top repo's list of repos, to know which repo a package is in.

What it replaces:

  • The top repo decision (Q15) said the top repo "holds nothing anyone imports". Now it holds what everything imports.
  • The repo loop caveat (C1) worried that a lower repo cloned alone needs the top repo. It was already closed, on 2026-10-20, because the top repo held no package then. The worry comes back in name only: every clone starts from the top repo.
  • The package names stay (@spell-app/util, @spell-app/server ...): no import changes.
  • the GitHub repo spell-app/spell-hub is renamed spell-kit (Owen's step); the checkout stays at ~/www/spell
  • spell-util, spell-server and spell-element merged into it, histories kept, and archived on GitHub
  • six repos: spell-kit, spell-lang, spell-ui, spell-brand, spell-epic, spell-app
  • built in The Kit (P9), before Multi-repo Tooling (P12)
