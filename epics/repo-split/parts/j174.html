The two old import rules are gone: spell/no-cross-repo-alias and spell/no-cross-package-import. Both depended on each repo's layout and alias table.

One rule replaces them, spell/no-parent-import:

  • A ../ import that lands in any package's src/ fails.
  • Its message names the import to write: the nearest package.json's name plus the path under src/.
  • Still allowed: same-folder ./Peer, a climb to a file outside src/ (a config, a glue tool), and globs (import.meta.glob).

The kit's bin spell-types.ts now imports spell-kit/toolchain/declarations by name.
