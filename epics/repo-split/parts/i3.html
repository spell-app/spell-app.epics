Once P1 is on main, every spell-epic docs tool that reads a data file fails: plain node can't resolve the $/ alias P1 added.

  • P1 changed DataFile.ts to import its json5 helper, json5Edited, through an alias, $/util/node/json5.
  • Plain node loads DataFile.ts by path, through spell-epic's own DataFile.ts.
  • The error: ERR_MODULE_NOT_FOUND: Cannot find package '$'.
  • spell-epic's MigrateCommands test caught it: epic migrate brand exited 1.

Fixed: it imports @spell-app/util/src/node/json5.ts by package path, which works under plain node and under tsc (assembler depends on util). json5.ts imports only node built-ins and json5.
