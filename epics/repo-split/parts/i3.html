P1 changed packages/assembler/src/DataFile.ts to import json5Edited from $/util/node/json5. Plain node loads DataFile.ts by path, through spell-epic's src/data/DataFile.ts (@spell-app/assembler/src/DataFile.ts), and it can't resolve a $/ alias: ERR_MODULE_NOT_FOUND: Cannot find package '$'. So once P1 is on main, every spell-epic docs tool that reads a data file fails. spell-epic's MigrateCommands test caught it (epic migrate brand exited 1).

Fixed: it imports @spell-app/util/src/node/json5.ts by package path, which works under plain node and under tsc (assembler depends on util). util/src/node/json5.ts imports only node built-ins and json5.
