Chose to leave six run-time keys as they are, over renaming them:

  • Symbol.for("@spell-app/ui:runtime")
  • "@spell-app/cells"
  • "@spell-app/ui-docs:example-sources"
  • "@spell-app/element-tag"
  • "@spell-app/element-class"
  • "@spell-app/spell-elements"

For J72's reason:

  • Two copies of Spell UI on one page find each other by these keys: spell-epic's docs bundle and the app's spell-language.js, built at different times.
  • The docs bundle isn't rebuilt from this branch.

What only shows text was renamed:

  • the console prefix [spell-ui]
  • page titles
  • the property editor's module, spell-ui/ui-property-editor
  • the search for @spell-app/ finds these six keys
  • easy to rename later: one pass and every bundle rebuilt
