Chose, in order: the spell.parserRoot setting (a bad value is an error, never a fallback); then the window's folders from the SECOND on, then the first; a folder counts if it is spell-app, holds spell-app/, or is inside one; last, the checkout it was built in, only while it still exists. That beats reading the folders in order because an epic window's folder 1 is ~/www/spell (for the Claude panel), and read in order a worktree window would run main's language server. It also beats using the open file's checkout because spell.spaces and spell.epics live inside main's kit.

  • the server decides once at start; restart it after changing the window's folders
