Chose, in order, which checkout's language server to run:

  1. the spell.parserRoot setting: a bad value is an error, never a fallback
  2. then the window's folders from the SECOND on, then the first
    • a folder counts if it is spell-app, holds spell-app/, or is inside one
  3. last, the checkout it was built in, only while it still exists

Why:

  • It beats reading the folders in order: an epic window's folder 1 is ~/www/spell (for the Claude panel). Read in order, a worktree window would run main's language server.
  • It beats using the open file's checkout: spell.spaces and spell.epics live inside main's kit.
  • no rebuild needed after moving a checkout
  • the server decides once at start; restart it after changing the window's folders
  • Run Project uses the chosen checkout's runner bundle (app/dist-runner)
