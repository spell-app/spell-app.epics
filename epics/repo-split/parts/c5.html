Once the split is done there are ten repos to keep in step: the top repo spell, eight code repos and the content repo. A change that spans repos costs one round of git work per repo.

  • A change across three repos is three commits, three pushes, three pull requests and three CI runs.
  • They merge in order, the lowest repo first, so a higher repo never points at code that isn't merged yet.
  • An epic's worktree holds a worktree of each child repo: merging main and /isolate done go repo by repo, and can stop with one merged and another not.
  • Day to day, yarn status and yarn pull cover every repo, and VS Code's Source Control lists them together. 
cd ~/www/spell/spell-ui  && git commit -am "ui:  ui-button takes size=tiny"
cd ../spell-app          && git commit -am "app:  the toolbar's buttons are tiny"
git -C ../spell-ui push  && git push      # two pull requests;  spell-ui's merges first
  • the worktree tooling (P9) loops over the repos an epic changed
  • accepted: the price of each repo having its own history, CI and releases
