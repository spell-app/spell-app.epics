Once the packages live in several repos, something must say where $/ui is.

  • Today every package names every other with the $/ alias:
    • $/ui
    • $/server/page
  • The alias comes from ONE table, in spell-app's tsconfig.base.json.
  • About 3,100 import lines use it, in 970 files.
 
import { E } from "$/spell-solid"                 // today
import { E } from "@spell-app/spell-element"      // A:  its package name, outside its own repo
  • A repo's own packages keep $/; another repo's are imported by package name.
  • The shape npm needs at release (Q4): nothing to change then.
  • Cost: a codemod of the crossing imports, and an exports map in each package.
  • The meta repo's alias table (tsconfig.base.json) maps $/ui into the spell-ui folder; no import changes.
  • But a repo can't be type-checked outside the meta folder, and npm needs A anyway.
  • reading an import says which repo it comes from
  • one mechanical pass now, nothing at release
