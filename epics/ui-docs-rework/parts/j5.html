The editor app (served by vite) has its own copy of the favicon, in favicon/. You'd see it in the browser tab of /editor/.

  • The app's page links /static/favicon/{favicon.svg,favicon-32.png,apple-touch-icon.png}: copies that yarn favicon writes.
  • Chose that folder over vite's usual public/ folder:
    • vite bundles the static/ files into dist/assets/ (checked: the files get hashed names, and the links are rewritten to them)
    • a public/ folder would also be copied into every library build: the element's and the runner's
  • The page server can't add the icon here: /editor redirects to vite's own port, so the page server never serves the app's page.
  • The old /vite.svg link was dead: that file never existed.

<link rel="apple-touch-icon" href="/static/favicon/apple-touch-icon.png" />

The options:

  1. favicon/, bundled by vite (chosen).
  2. public/: simpler, but copied into every library build too.
  • the app's tab shows Spell's icon, in development and in its built output (the app's dist/)
  • the library builds carry no icon files
  • yarn favicon keeps the server's and the app's copies in step
