The sun / moon swap's transition is marked !important, the one documented exception, so the Spell theme's "no transitions while the scheme switches" rule doesn't kill it.

  • The Spell theme turns every transition off (transition: none !important) for the frame a scheme switch lands in. That's exactly the frame the icon swap starts in.
  • The swap's transition is !important in the component's layer. Between cascade layers, an !important in an EARLIER layer wins, so the swap keeps its transition.
  • Reduced motion (reset.css, an earlier layer still) still turns it off.
  • Also: the light icon is Font Awesome's outline sun, because the solid one reads as a cog at 14px (see I5).
@media (prefers-reduced-motion: no-preference) {
  .scheme .glyph {
    transition:
      opacity var(--_ui-docs-themes-swap-duration) var(--ui-ease-out, ease-out),
      scale var(--_ui-docs-themes-swap-duration) var(--ui-ease-out, ease-out),
      filter var(--_ui-docs-themes-swap-duration) var(--ui-ease-out, ease-out) !important;

The options:

  1. One !important, documented in the CSS (chosen).
  2. A keyframe animation: the brief asked for transitions.
  3. Exempt the icons in spell.css: ties the theme to one component.
  • the sun / moon cross-fade plays on every flip, in every theme
  • reduced motion still switches it off
