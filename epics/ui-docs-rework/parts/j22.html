The nav's rows are plain links styled like the brand's nav, not ui widgets. Only the 8 hand-written pages get an icon; component rows are text.

  • Each row is <li><a class=item>, drawn as the brand's .sp-nav. That avoids about 100 <ui-item> widgets plus a <ui-menu>.
  • The favourite stars stay <ui-button toggle>. They show on row hover or focus, or when starred; on touch screens they show at 0.4 opacity.
  • Icons only on the 8 hand-written pages, all solid Font Awesome (the free pack has few outline icons):
    • house, rocket, spell check, cubes
    • palette, screwdriver wrench, icons, sink
  • The 96 component rows stay text.
