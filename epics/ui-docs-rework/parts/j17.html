The repo-wide site header (<spell-site-header>) got a compact docked mode for the Spell UI site, instead of a second bar made only for Spell UI.

  • Chose one element with a docked mode, over a second, Spell-UI-only bar.
  • The docs, plan docs and goals keep the fixed bar, unchanged.
  • Docked means:
    • no fixed position
    • no breadcrumbs (the page shows its own title)
    • no light / dark button (the page's own control has it)
    • no room reserved (--spell-site-header-height is 0)
  • The layout has two copies, one shown per width:
    • 1200px and wider: in the right column
    • narrower: in the top bar
  • It re-draws on spell-site:page, which the router fires after a swap, so its title and VS Code link follow the page.

The options:

  1. One element with a docked attribute (chosen).
  2. A second bar, only for Spell UI.
  • Spell UI keeps the branch, VS Code and edit-mode links, without a top bar on wide screens
  • every other site's header is unchanged
