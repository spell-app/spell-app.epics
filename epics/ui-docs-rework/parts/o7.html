Each tab's content is nested <ui-section>s, every one sticky collapsible dividing, as the docs pages already are.

  • Ids nest: tab value, then each section, then the example: #examples-types-emphasis = Examples tab › Types › Emphasis. Written INTO the markup by a converter, yarn site:sections, 1,749 sections in all, so they're stable and grep-able; site:check fails on a new one that doesn't follow the pattern.
  • A link to any id: picks its tab (its first word IS the tab), unfolds the sections around it, lands below the stuck titles.
  • The Examples | Usage | API | Theming tabs stick at the top; section titles stick below them.
  • <ui-docs-toc> reads <ui-section>s.
  • Old links like #types still land: old hashes are forwarded to the new ids.
