A spell theme sheet for @spell-app/ui, from the brand's tokens (packages/brand/spell-design-system/tokens/), the default on EVERY doc site: Spell UI docs, docs pages, plan docs, goals (D6).

  • Colours: the brand's light / dark meanings (theme.css) mapped onto --ui-* tokens, as Theme Creator.dc.html already sketches. Accent Spell Purple (violet-600 light, violet-300 dark); dark mode is aubergine (violet-950), not black.
  • Type: the brand's own fonts (tokens/fonts.css, D7): Palatino-family serif headings, installed faces first, the brand's P052 .otf as fallback; system sans body; mono only for code and eyebrows.
  • Shape: pill actions, 12px inputs, 16px cards, 22px dialogs; layered soft shadows instead of borders.
  • From the interfaces.dev cheat sheet, what a THEME can do:
    • semantic tokens only (--ui-accent-*, never --violet-500 in components)
    • press scale: 0.97, transition naming exact properties, hover only inside @media (hover: hover)
    • no transitions while the scheme switches; motion inside prefers-reduced-motion: no-preference
    • :focus-visible ring (3px accent), tabular-nums in tables, text-wrap: balance headings / pretty ledes
    • font smoothing on the root, text-underline-position: from-font, 1px -1px-offset image outline
    • concentric radii (outer = inner + padding), scroll-margin-top for landings
  • Skipped: swoops and blobs (spell-flourish.js).
