Your light / dark choice is stored under one key, spell-site:scheme, which the Spell UI site and the docs, plan docs and goals all share. Flip it on one site and the others follow.

  • The new key serves both ThemePreference (Spell UI) and <spell-site-header> (the other sites).
  • Chose a NEW key over reusing the header's spell-site:theme: that name says "theme", and the Spell UI site already has a separate theme key.
  • The old keys are copied once, while the new one is absent, then removed:
    1. spell-site:theme
    2. spell-ui-site:scheme
    The first one with a valid value wins.
  • Both sites apply the choice the same two ways:
    • a ui-light / ui-dark class on <html>: for the UI tokens and --ui-scheme, which ui-invert reads
    • an inline color-scheme: for goals pages, which have no UI sheets, and for the header's own light-dark() colours

The options:

  1. The class AND color-scheme (chosen).
  2. The class only: goals pages wouldn't switch.
  3. color-scheme only: --ui-scheme would stay on the OS's value.

Net effect:

  • one light / dark choice for every doc site
  • a choice made before this change carries over once
