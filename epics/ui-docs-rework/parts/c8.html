Moving between Spell UI pages swaps only the <main>. So styles and scripts a page puts in its own <head> don't come along, and inline scripts inside <main> run again on every visit.

  • Written down in the template, README.md and PAGES.md.
  • Today no page has head styles beyond the shared ones.
  • Example: a <style> added to one page's head would apply when that page is loaded directly, but not when you click to it from another page.
