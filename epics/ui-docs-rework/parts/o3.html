The chrome (nav panel, right sidebar, narrow top bar) is written ONCE, and stays on screen while you move between pages; only the page's content is swapped in, by <ui-include>. How the URLs work is Q1.

  • A small router:
    • it catches link clicks, and the nav's cancelable ui-navigate
    • it points the content include at the new page (select="main")
    • it pushes the real URL to the history, sets the title, and scrolls to the hash
    • back and forward work through popstate
  • The old content stays until the new one is ready, then swaps (a View Transition where supported): no blank flash between pages.
  • Gotcha: <ui-docs-example> reads its source from a snapshot taken once, at load (snapshot.ts). Included pages need their own snapshot BEFORE they upgrade, so the router takes it from the fetched HTML.
  • Live reload (page server) reloads just the content when only a page changed.
