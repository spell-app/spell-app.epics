Two causes, two fixes; the options for the first are Q2.

  1. Unstyled markup paints before the elements upgrade: every page turns hiding OFF (display="immediately").
  2. The page jumps 44px when the site header adds its padding late: reserve that space in the page's own CSS, before any script.

With one layout (1.3), this matters only on the FIRST page; later pages swap in already upgraded.
