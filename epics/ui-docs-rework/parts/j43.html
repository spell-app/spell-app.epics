The nav's old filter field is gone: the search field replaces it, and still filters the nav list as you type. There's ONE field.

  • The results card is a top-layer popover, 28em wide, anchored under the pill-shaped field. It covers the nav list while it shows.
  • Every keystroke still fires ui-input, so the list underneath filters as before. It shows filtered once the card closes (Escape or Tab).
  • Enter always goes through the card (the best match is pre-highlighted), never the list.
  • The / shortcut moved from the nav into the field, plus Cmd / Ctrl+K. The nav's focusSearch() now summons it.

The options:

  1. One field, both behaviours (done).
  2. Separate filter and search fields.
  3. Drop the list filter.
  • one place to type, for finding a page and for narrowing the nav
  • / and Cmd / Ctrl+K both focus it
