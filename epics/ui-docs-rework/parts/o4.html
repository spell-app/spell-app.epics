There were two causes of the flash, and each has its fix:

  1. Unstyled markup painted before the elements upgraded: now <ui-root> waits until they're ready.
  2. The page jumped 44px when the site header added its padding late: the page's own CSS reserves that space, before any script.

With one layout (1.3), this matters only on the FIRST page; later pages swap in already upgraded.
