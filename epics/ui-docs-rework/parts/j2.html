The white hat fills 74% of the icon's width, the brand's own proportion, rather than being enlarged to read better at tiny sizes. You'd see it in a browser tab, where the icon is drawn at 16px.

  • The brand says "about three-quarters"; its CSS uses 72%.
  • Tried 82%. At 16px on a 1x (non-retina) screen the bigger hat gains about one pixel, and it reads as a hat silhouette either way.
  • At 16px on a retina screen (32 device pixels) and above, 74% is crisp, and the bigger hat crowds the corners.
  • One SVG serves every size, so it's one number for all of them.

Example: to try a bigger hat, run yarn favicon --hat 0.8 in src/server. It rewrites the icon files and prints a summary line ending in hat 0.8.

The options:

  1. 74%, the brand's proportion (chosen).
  2. 82%, a bigger hat for small sizes: one pixel gained at 16px, crowded corners at larger sizes.
  • the tab icon keeps the brand's proportions at every size
  • changing it later is one flag: yarn favicon --hat 0.8
