A spell theme sheet for Spell UI, made from the brand's tokens (D6). It's the default on EVERY doc site: Spell UI docs, docs pages, plan docs, goals.

  • Colours: the brand's light / dark meanings, mapped onto the --ui-* tokens.
    • the meanings are in the brand's theme.css; the Theme Creator page already sketches the mapping
    • the accent is Spell Purple: violet-600 light, violet-300 dark
    • dark mode is aubergine (violet-950), not black
  • Type: no font files ship with the theme.
    • serif headings in the installed Palatino family, else the system serif
    • a system sans body
    • mono only for code and eyebrows
  • Shape: pill actions, 12px inputs, 16px cards, 22px dialogs; layered soft shadows instead of borders.
  • From the interfaces.dev cheat sheet, what a THEME can do:
    • semantic tokens only (--ui-accent-*, never --violet-500 in components)
    • a press shrinks to scale: 0.97
    • a transition names its exact properties
    • hover only inside @media (hover: hover)
    • no transitions while the scheme switches; motion inside prefers-reduced-motion: no-preference
    • a :focus-visible ring (3px accent)
    • tabular-nums in tables
    • text-wrap: balance on headings, pretty on ledes
    • font smoothing on the root, text-underline-position: from-font, 1px -1px-offset image outline
    • concentric radii (outer = inner + padding), scroll-margin-top for landings
  • Skipped: swoops and blobs (spell-flourish.js).
