Escape in the search field works in steps, and picking a result empties the field. You'd notice it using search from the keyboard.

  1. The first Escape closes the results card. The text stays; Down reopens it.
  2. The second clears the text, and the nav list stops filtering.
  3. The third returns focus to where a shortcut summoned the field from. If no shortcut did, it does nothing, so a flyout's own Escape can close the flyout.
  • After a pick (Enter or a click), the card closes and the field EMPTIES, so the nav list isn't left filtered on the new page.

The options:

  1. A staged Escape, and an empty field after a pick (chosen).
  2. One Escape that closes AND clears.
  3. Keep the text after a pick, as Fomantic does (it puts the result's title in the field).

Net effect:

  • Escape never throws away typing by surprise
  • a new page opens with the full nav list
