A parts page (e.g. Meta) shows the part inside each component that styles it, then its variations. Its Usage tab is Using it, Owners, and Accessibility.

  • "Owner": a component that styles the part inside itself, e.g. a card styling its header.
  • Examples tab: one example section per owner (borrowed from the owners' pages and ui-parts/examples/elements/), then Variations / Content: the part's attributes.
  • Owners that only appear in overlays (toast, flyout, popup, search) are listed under Usage / Owners, not demoed. The modal is demoed, behind a Show button.
  • No Keyboard section: it's folded into Accessibility.
  • The link to Fomantic's page:

    • textarea: collections/form
    • parts: none
  • The kitchen sink: the family's example links each split page; its examples stay per family.
