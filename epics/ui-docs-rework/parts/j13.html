The first page you open isn't inside a <ui-include>: the router wraps it in one on your first click to another page. You won't see a difference; it matters to anyone reading the layout or the router.

  • An include with no source empties itself when it connects to the page.
  • Giving it the current page's URL at load would fetch and re-render the page that's already shown.
  • So the first page's <main> sits bare in .site-content.
  • The first swap wraps it in <ui-include select="main#main" page-styles>, with the new source set before the include connects.

The options:

  1. The router makes the include on the first swap (chosen).
  2. An include in the layout from the start: it would empty the page, or fetch it twice.
  • a first load renders the page once
  • layout.html holds no include; the router adds it
