On the avatar page, an avatar inside an item draws at its image's size, about 3em, while a card's avatar is 2em.

  • Seen on ui-avatar.html, under Owners / Item.
  • :state(in-item) > .avatar sets no size, so the avatar is about 3em, with the name on its baseline.
  • Logged in SUSPECTED-BUGS.md, in the ui section (still there, checked 2026-10-04).
  • The page describes it neutrally.
