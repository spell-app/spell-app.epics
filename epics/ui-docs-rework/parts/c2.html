A Spell UI page opened with JavaScript turned off shows its content, but no nav panel, right column or top bar.

  • This follows from the layout decision (D1, option B of Q1): each page's file holds only its <head> and its <main>, and the script wraps it in the one layout.
  • Without the script, nothing adds the layout.
  • The content itself still shows: the no-flash decision (D2) hides the page only while scripting is enabled.
