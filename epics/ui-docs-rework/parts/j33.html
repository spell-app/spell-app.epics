The Examples / Usage / API / Theming tabs stick at the top on a band of page background, and section titles stick just below them. The titles' position is measured in JavaScript.

  • The tabs' menu sticks at the top, above the section titles. 
    .site-tabs::part(menu) {
  position: sticky;
  top: var(--site-top);
  z-index: calc(var(--ui-z-sticky) + 1);
}
  • An 8px band of page background (a box-shadow, --site-tabs-band) hides what scrolls under the bar's rounded corners.
  • Top-level sections' offset (in px) is set by SiteSections.ts; it also feeds their StickyWatch:
    • the bar's measured height, plus the band, plus --site-top
    • --site-top is read through a hidden fixed probe, so a calc() in it still resolves
    • measured again when the bar or the window resizes
  • Stuck titles take the page's background (--ui-section-sticky-background: var(--ui-background)), not the surface's, which showed as white bands on the tinted Spell page.

The options:

  1. Measure in JavaScript (chosen).
  2. A CSS variable for the offset: <ui-section> can't take one (its offset is a number).
  • tabs and titles stack without overlapping, at any window size
  • stuck titles blend with the page's tint
