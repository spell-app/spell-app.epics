The 180px apple-touch-icon.png is the full aubergine square, NOT the rounded icon. You'd only see it by adding a page to an iPhone or iPad home screen.

  • iOS cuts every home-screen icon to its own rounded shape.
  • If our icon had transparent rounded corners, iOS would fill them with black.
  • The 32px PNG and the SVG keep the brand's 22.5% corners: browsers show those as they are.

The options:

  1. A square icon for iOS, which rounds it itself (chosen).
  2. The same rounded icon as everywhere else: black corners on the home screen.

Net effect:

  • the home-screen icon gets iOS's own rounding, with no black corners
  • browser tabs keep the brand's rounded square
