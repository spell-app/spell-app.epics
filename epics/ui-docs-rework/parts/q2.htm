FOUC ("flash of unstyled content"): raw <ui-*> markup paints before its element's code loads, then jumps into shape. Every page today asks for it: <ui-root display="immediately">. The 44px jump from the site header is fixed in every option (its space reserved in CSS).

ChoicesA · ui-root when-ready (recommended)
  • <ui-root display="when-ready">: already built
  • CSS hides it before upgrade (native.css:510); then it waits for every element's ready, 5s cap, and shows all at once (120ms fade)
  • No JS: CSS hides only while scripting: enabled
B · <ui-root hidden>
  • Your idea; needs a :host([hidden]) rule (ui-root.css has none) and code to drop hidden on ui-ready
  • Same result as A, by hand; a failed script leaves the page blank forever
C · Skeleton
  • display="skeleton" (ui-root's default): grey placeholder shapes until ready
  • Feels like an app loading; noisy for mostly-static docs
D · .ui-cloak
  • Class on each piece: opacity 0 for up to 2s by a CSS animation
  • Crude: a fixed timer, not "ready"
D2 · A: ui-root when-ready, header space reserved in CSS
