In dark mode, the nav row for the page you're on is lilac with dark ink, not the brand's solid violet with white text.

  • The brand's dark current row: solid violet-600, white text.
  • The Spell theme's dark primary colour: lilac violet-300, aubergine ink.
  • So the row's token defaults to the theme's primary. That matches Spell's dark buttons and tabs, and works in every theme.
  • To get the brand's violet back: set --ui-docs-nav-current-background to #6550ca.
ui-docs-nav.css · the current row's fill · 4 lines 
--_ui-docs-nav-current-background: var(
  --ui-docs-nav-current-background,
  light-dark(var(--ui-primary-background), var(--ui-primary))
);

The options:

  1. Lilac, the theme's primary (chosen).
  2. The brand's solid violet-600.

Net effect:

  • the dark current row matches dark buttons and tabs
  • it differs from the brand's dark mockup; one token changes it
