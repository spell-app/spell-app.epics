The favicon's image data is kept as text inside a TypeScript file, not as image files next to the server. You'd only notice it when changing the icon: you regenerate that file instead of swapping a PNG.

  • Chose favicon.ts: the SVG and both PNGs, as base64 strings.
  • The file is GENERATED by yarn favicon, in the server package; nobody edits it by hand. The script is favicon.ts.
  • Over: an assets folder, read from disk at run time.
  • Why: the VS Code extension bundles WebServer with esbuild. A file sitting beside the source code isn't there once the extension is installed.
  • The site header's bundles drop the PNG strings (tree-shaking: the bundler leaves out code nothing uses). The header only uses the SVG.

 */
