<epic-question>

A question's text, as first asked. It draws a small grey QUESTION label over the text, and sits first in its item, before the options and the answer.

Written for: anyone reading or writing a plan doc's markup, or changing this element Status: built in packages/epics/components/epic-question/ Its vocabulary (every table below comes from it): packages/epics/components/epic-question/EpicQuestion.en.ts; the markup rules: packages/epics/src/tool/PLAN-DOC.md

Live: the real element, drawn by the epics pack this page loads. Click a line to unfold it. The review buttons don't show here: they show only on a plan doc being reviewed.

Q21 of the wwod epic, shown open (as it stood before it was answered), and unfolded.

§12 says behaviour switches are ALL-CAPS statics at the top (Match.DEBUG_MATCH_INITIALIZATION), and also "prefer @proto static for any per-class constant behaviour switch" (@proto static inlineInitialType = false).

ALL-CAPS static: a developer / debug switch, set by hand for the whole class tree. @proto static: a behaviour a subclass or instance overrides.

Drop the ALL-CAPS switch form.

Its parents:

  • <epic-item>: first among its details, one at most. The tool finds the question by this tag, not by its place.
  • <epic-version>: in an item's Original Discussion, when a rewrite of the question moved the old one there

None: it draws the same wherever it is.

A slot is a place in the drawing that a child goes to: a child with slot="name" goes to that name's place, every other child to the default one (shown as default).

Slot What goes there
default The question, as asked.

A part is a piece of what the element draws in its shadow root (its own hidden markup), named so a stylesheet can reach it: epic-question::part(header).

Part What it is
base The label over the text.
label Question, a small grey eyebrow (as an item's Original question).
  • Neutral: no colour of its own. The label is small, grey, bold capitals, the same look as an item's Original question label.
  • The text is the page's own children, spaced as an item's details are.
  • It doesn't fold by itself: it folds with its item.
  • plan-doc add <name> question "title" --details html: the lead of the HTML (the prose up to its first element or bold label line, such as <p><b>The options:</b></p>) goes into an <epic-question>, unless the HTML has one
  • plan-doc details <name> <Q id> --file html, a rewrite of a question's text: the new lead goes into a new one; the old one moves into the Original Discussion with the rest of the old text
  • --append never makes one
  • older docs: the converter (plan-doc convert), from a question's leading text
