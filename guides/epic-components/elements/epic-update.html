Its parents:

  • as a label: an item's title (the <span slot="title"> of an <epic-item>), or inline in any prose
  • as a note: anywhere prose goes. It's a prose element:
    • <epic-item>: among an item's own text, before its cards
    • <epic-answer>, <epic-more>, <epic-reply>: the cards under an item
    • <epic-option>: an option card's pros and cons
    • <epic-field>: a phase's field, or a labelled block
    • <epic-updated>: a change to a phase's plan
    • <epic-section>: an Overview sub-section's prose, or a report's
    • <epic-version>: an earlier version, kept as it was
    • another prose element (a note inside an aside), or plain HTML around it (a <li>, a <div>)

Its children:

  • none: a label
  • prose: a note of what changed

A note that should STAY once the phase is done (an item partly fixed elsewhere, a decision done) is an <epic-note> instead. A change to a phase's own plan is its <epic-updated> line.

Name Values Meaning Required
phase a phase number (2) The phase it belongs to. Its tooltip names it (Changed during P2); that phase's done removes it. yes

A slot is where the element's own children show.

Slot Holds
(default) What changed; none for a bare label.

A part is a piece of the drawing a page's CSS can reach.

Part Is
base The label or note.
toggle A note's fold chevron, a <button>, before its label.
label The orange UPDATE label: alone when empty, the note's heading otherwise.
body A note's text; hidden (until-found) while folded.

A state is set by the element on itself; none is ever written in the doc.

State When
note It has children: drawn as a note, not a bare label.
open A note, unfolded. It starts so.
  • Orange: changed since you looked (orange means only that, and warnings, on every doc page: templates/epics/plan-doc.md, "Colours").
  • The label: solid orange, small bold capitals, centred on the text's middle.
  • A note: a block with an orange hairline and a faint orange tint, headed by the chevron and the label.
  • A note folds by its heading and starts open. Folded, its text is hidden="until-found", so find-in-page reveals it.
  • No fill lifecycle: it's a marker, not a button.
  • The tool adds a label to an item's title when add, decide, close / reopen / cancel or details (with or without --more) change it while a phase is active: once per item (PlanDoc.markUpdate()).
