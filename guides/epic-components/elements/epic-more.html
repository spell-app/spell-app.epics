<epic-more>

More Details: a plain white card under an item's text and answer, holding what the text left out. The item's own text above it gets the label Original reply.

For anyone reading or writing a plan doc's markup, or changing this element. built in packages/epics/components/epic-answer/. Its vocabulary (every table below comes from it): packages/epics/components/epic-answer/EpicMore.en.ts; the markup rules: packages/epics/src/tool/PLAN-DOC.md.

Live: the real element, drawn by the epics pack this page loads. Click a line to unfold it. The review buttons don't show here: they show only on a plan doc being reviewed.

A slot is a place in the drawing that a child goes to: a child with slot="name" goes to that name's place, every other child to the default one (shown as default).

SlotWhat goes there
defaultWhat the item's text left out.

A part is a piece of what the element draws in its shadow root (its own hidden markup), named so a stylesheet can reach it: epic-more::part(header).

PartWhat it is
baseThe card.
toggleIts More Details <button>, which folds it.
bodyWhat the item's text left out; hidden while folded.

A state is a word the element sets on itself while something is true, for styling: epic-more:state(open). Never written in the file.

StateWhen
openUnfolded: it starts so.
  • A plain card (the page's own surface, a thin rule round it): no colour meaning.
  • Its heading is a small grey eyebrow, MORE DETAILS, the chevron first; a click on it folds the card. It starts open.
  • Its item labels the text above it Original reply, so the reader can tell the two apart.
  • plan-doc details <name> <id> --file html --more (Add Details): the item's text stays on top, the file's HTML goes in the card. An agent writes it when Owen asks for more on an item (Do Now on an item with no note).
  • A second --more replaces the card; the old card's text moves into the Original Discussion, as a rewrite's does
  • older docs: the converter, from the old More Details block
