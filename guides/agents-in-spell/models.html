Spell Epic Agents in Spell Frontier models and what they cost

Frontier models and what they cost

Which models Spell's agent could run on in November 2026, what each costs, and what a real Spell task would cost on them: so we can pick a default, a cheap tier and a best tier before planning.

Written for: Owen, reviewing epic agents-in-spell before any planning; anyone choosing which model a Spell feature calls Status: draft (discussion) Researched on: branch agents-in-spell, 2026-11-20. Prices from each provider's own page where it could be read, else OpenRouter's live model list, fetched that day (see Sources). Benchmarks are the labs' own, unless said otherwise.
  • The model Owen heard about is MAI Code 2, Microsoft's coding model, launched at Ignite on 2026-11-17.
    • $0.50 in, $2.50 out, per million tokens, until 2027-05-17; then double, $1 / $5.
    • Microsoft says it scores 98% of GPT-6.1 Sol at 40% of the price, and 96% of Opus 5.5 at 5% of the cost per task (its own four benchmarks, at the promo price).
    • Today it runs only inside GitHub Copilot. No API, no OpenRouter yet; its small sibling, MAI Code 2 Flash, is in a limited Foundry preview. Weights are not open.
  • Prices have fallen into three bands, and the cheap band is now good enough for small edits:
    • best: Claude Fable 5.2, GPT-6.2 Astra -- $8 in, $40 out
    • workhorse: Opus 5.5 ($4 / $20), Sonnet 5.5, GPT-6.2 Sol, Gemini 4 Argon / Carbon (all $2 / $10)
    • cheap: Haiku 5.5 and GPT-6 Luna ($0.10 / $0.50), DeepSeek V4.1 Flash, GLM-5.3, MiMo, MAI Code 2 Flash -- a few cents per thousand edits' worth of input
  • Cached input is where agent costs go, and it's now 2-5% of the input price on most frontier models:
    • an agent re-sends its whole conversation every step, so 80-90% of what it sends can be a cache hit
    • so keeping Spell's system prompt and tool list stable, in front, matters as much as picking a model
  • A small edit ("make this button red") costs about 0.1-1 cents on cheap models, 5-11 cents on the workhorses; a small new app about 2 cents to $1.40. Assumptions in What a Spell task costs: they're estimates, not measurements.
  • Every provider speaks one of two shapes (OpenAI's or Anthropic's), and gateways put all of them behind one key: OpenRouter (with sign-in for people, see byo-agent.html), Vercel AI Gateway, Cloudflare AI Gateway, LiteLLM (self hosted). None marks up tokens; they charge on top-ups or plans.
  • Routing (a cheap model for edits, a frontier one for creating) is ordinary now: GitHub Copilot's auto mode, OpenRouter's Auto Code router, Microsoft's Decision router. Spell's own code already has the shape for it: the parser's EffortTier, fast | balanced | best.
  • Pick models by TIER, never by name, through the tiers Spell already has (fast, balanced, best): each provider maps them to its own models.
  • Start with Claude (Haiku 5.5 / Sonnet 5.5 / Opus 5.5) as the reference, plus one OpenAI-shaped provider through OpenRouter, so every other model comes for free.
  • Add MAI Code 2 when it reaches an API (OpenRouter, Foundry): it's the strongest price per task.

Seven MAI models came out at Ignite, 2026-11-17; two are for coding.

  • MAI Code 2: for everyday coding and front-end work, by Microsoft's own description. Not tuned for research or very long agent runs.
    • $0.50 in, $0.025 cached, $2.50 out until 2027-05-17; $1 / $0.05 / $5 after (GitHub's pricing page).
    • Microsoft's four benchmarks: DeepSWE 73.2%, Terminal-Bench 2.1 84.6%, SWE-Atlas 43.1%, FrontierCode 52%: an average of 63.2%, against GPT-6.1 Sol's 64.1% and Opus 5.5's 65.3%.
    • Cost per task on that run: $0.31, against $0.76 for GPT-6.1 Sol and $6.31 for Opus 5.5. That's the "radically cheaper": 20× under Opus per task, partly because it writes fewer tokens.
    • Context: about 1.05M tokens, by its model card as others quote it; Microsoft's pages didn't say.
  • MAI Code 2 Flash: for routine edits and fixes. $0.05 / $0.005 / $0.25 until 2027-05-17, then double. Microsoft's average 61%, above GPT-6 Luna (55.1%) and Haiku 5.5 (53.9%), at $0.05 a task.
  • Where it runs:
    • GitHub Copilot only, today: Code 2 on Pro and above, Flash on every plan including Free.
    • Flash is in a limited-access preview in Microsoft Foundry, with no price published there.
    • Microsoft says OpenRouter, Vercel, OpenCode and Kilo are coming "soon"; OpenRouter's list on 2026-11-20 had no MAI coding model yet.
  • Weights: closed. "MAI Licensed Weights" is a program for trusted enterprises to tune a MAI model and run it in their own Azure; it's not open weights, and no use to Spell.
  • Also new: Microsoft-Decision-1.1, a router model that sends a request to a bigger model only when needed ($0.042 per million in). See Routing.
  • Verified on Anthropic's pricing page: Fable 5.2, Opus 5.5, Sonnet 5.5, Haiku 5.5 are current.
  • Cached input is unusually cheap: 2.5% of input on Fable 5.2, 5% on Opus 5.5 and Sonnet 5.5, 10% on Haiku 5.5. Writing the cache costs 1.25× input (5 minutes) or 2× (an hour).
  • 1M context on all, at one price; Haiku 5.5 alone charges 5× above 100K tokens of prompt.
  • Batch: half price. Fast mode: double price, up to 2.5× faster output (Fable 5.2, Opus 5.5).
  • Claude Mythos 5.2 (same price as Fable) is limited to verified organisations: not something Spell can offer.
  • Spell already calls Claude two ways (the parser's ClaudeRunner): the API straight with a key, or the person's own claude -p.
  • Three sizes, named Astra (best), Sol (workhorse), Terra (between Sol and Luna) and Luna (cheap). GPT-6.2 Sol and Astra came out 2026-11-17; Sol's price didn't change.
  • GPT-6.1 / 6.2 Sol: $2 / $0.10 / $10 up to 272K tokens of input, then $4 / $0.20 / $15 (GitHub's page; OpenAI's own page refused the fetch).
  • GPT-6.1 Terra $1 / $5; GPT-6 Luna $0.10 / $0.50.
  • OpenAI's open-weight gpt-oss models are from 2025 and well behind now.
  • OpenAI also lets people spend their ChatGPT plan in other apps ("Sign in with ChatGPT"): byo-agent.html covers it.
  • Four Gemini 4 models, all with 1M context (Google's pricing page):
    • Argon and Carbon: $2 / $0.10 / $10, doubling on 2026-12-01 to $4 / $20
    • Neon $3 / $15; Hydrogen $1.50 / $7.50, with a free tier, GA 2026-11-12
  • Gemini 3.8 Flash: $0.75 / $3.75, doubling 2027-01-01.
  • The free tier of the Gemini API is the only free tier among the big three for these models.
  • No Gemini 4 coding benchmarks were found published yet.
  • xAI: Grok 4.7 ($2 / $6, 500K) for everything, grok-build-0.1 ($1 / $2) for coding; both double above 200K tokens of prompt (xAI's model page).
  • DeepSeek: V4.1 Flash and V4 Pro, open weights, 1M context; off-peak hours (most of the day outside China's morning) are half price, and cache hits nearly free ($0.003-0.006).
  • Alibaba's Qwen3.8 (Max is closed and 2.4 trillion parameters; 27B is open), Moonshot's Kimi K3.1 Pro, Z.ai's GLM-5.3, Xiaomi's MiMo-V2.6, MiniMax M3: all open weights or mostly so, all under $1 in, and all claim near-frontier coding scores.
  • Mistral: Large 4 (Oct 2026) and Devstral 2 for coding: European hosting is their draw, not price.
  • Also seen on the leaderboards: Cognition's SWE-2 (leads Terminal-Bench 2.1, only inside Devin) and Meta's Muse family (Muse Spark Open is open weights).
  • Running any of the open ones on a Mac or a phone: local-models.html.

A small edit

"Make this button red, and say Save".

  • 3 model calls: read the component, edit it, say what changed.
  • Instructions and tools: about 6K tokens, cached after the first call.
  • What Spell sends of the thing: its source and where it sits, about 3K.
  • In all: 12K input not cached, 18K cached, 3K out (with thinking).
 A small new app

"A recipe box with three pages and a search".

  • About 25 model calls, the conversation growing to about 60K tokens.
  • In all: 800K input, 85% of it cached (680K), and 40K out: 15K of code, 25K of thinking.

A gateway takes one kind of request and sends it to any provider. What each buys Spell, checked 2026-11-20:

gateway what it buys BYOK what it charges
OpenRouter ~480 models behind one OpenAI-shaped API; fallbacks between hosts; sign-in for PEOPLE (OAuth PKCE), so they pay; auto routers yes token prices passed through; 5.5% on credit top-ups; BYOK free up to $25K a month, then 5%
Vercel AI Gateway one API and the AI SDK's own provider; fallbacks; spend reports yes, paid plans no markup on tokens, nor on BYOK
Cloudflare AI Gateway caching, rate limits, logs and fallbacks in front of any provider; one bill ("Unified Billing") yes free gateway; 5% on Unified Billing credits; Workers billing at volume
LiteLLM an open-source proxy we'd run ourselves: one API, keys per person, budgets, logs it IS bring your own free; our server
Azure AI Foundry Claude, GPT, MAI and open models on one Azure bill; enterprise data terms no the providers' prices; US-only +10% on Claude
Bedrock, Vertex the same on AWS and Google Cloud; Claude on both no their prices; regional endpoints +10%
  • For a small project the clouds (Foundry, Bedrock, Vertex) buy nothing but paperwork; they matter if a company wants Spell on its own cloud bill.
  • OpenRouter is the one that serves both Spell paying (one key on the server) and people paying (their sign-in): see byo-agent.html.
  • How the gateways' API shapes relate to the agent protocols (MCP, AG-UI, ACP): standards.html.

Who does it today, and what it would mean for Spell.

  • GitHub Copilot: an Auto choice, and since June 2026 bills every model per token in AI credits (1 credit = 1 cent): the same per-token shape Spell would have.
  • OpenRouter Auto and Auto Code (2026-11-06): a small model rates each request (task, difficulty, need for speed), then picks a model and how hard it thinks, from live prices.
    • No fee of its own; the reply says which model answered.
    • It avoids switching model mid-conversation, since a switch throws away the cache: it stayed on one model for about 9 turns in 10.
    • OpenRouter's claim: Auto Code scores like Opus 5.5 for 74% less per task. Its own caveat: no router beats the best single model at every point of cost against quality.
  • Microsoft-Decision-1.1: a router model sold on its own, $0.042 per million in.
  • Spell's own shape: the parser asks by EffortTier (fast, balanced, best) and each runner maps a tier to its models (Claude's table, CLAUDE_TIERS). Routing for the editor is that, picked per task:
    • fast: an edit to one thing on the page, explain this, name this
    • balanced: a change across a few files, a new component
    • best: a new app, site or page from a sentence
  • Picking the tier from what was asked, before the model runs, is cheap and plain. Letting a router decide (OpenRouter Auto) is one setting later, for people on OpenRouter.

The code words ("model" or "runner") and where the one model client lives are the epic page's and : not asked again here.

  1. Which provider first? It sets the API shape Spell's first runner speaks. A. Claude API recommended Spell already calls it; the cheapest cache; Haiku 5.5 for the free tier. Then OpenRouter as the second, for every other model. B. OpenRouter only Every model through one shape from day one; but its OpenAI shape loses some Claude features (cache control, thinking) unless passed through. C. Wait for MAI Code 2's API Cheapest per task; but no date, and Copilot only today.

    Why it matters: the first runner's shape is the one every later one is bent to fit.

  2. How does a task pick its model? A. By tier, from the kind of task recommended Edit = fast, create = best, the person can turn it up. Plain, and the tiers exist. B. A router decides OpenRouter Auto Code; less to build, but a black box, and OpenRouter only. C. The person picks a model A model menu, as Cursor and Copilot have: power users want it; novices don't.

    Why it matters: it's the biggest lever on cost, 30-80× between tiers.

  3. Do we measure real token counts before promising any price? A. Yes, an experiment first recommended Run ten edits and three new apps through the change flow on 3-4 models, logging usage. B. Use this page's estimates Faster; but they could be off by several times, either way.

    Why it matters: a free tier priced on a guess can cost Spell real money.

  4. Do open-weight Chinese models (DeepSeek, GLM, Kimi, Qwen) get offered, hosted? A. Yes, through OpenRouter, US / EU hosts only recommended OpenRouter can pin the provider; the weights are open, so others host them. B. Only locally No data leaves the machine; see local-models.html. C. Not at all Simplest story for companies; gives up the cheapest strong models.

    Why it matters: they're the cheapest models near the frontier, and where data goes matters.
