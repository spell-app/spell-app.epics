Events

A card dropped on a pile sends ui-dropped, and a page script can listen for it: board.addEventListener("ui-dropped", ...). Inside the program, the pile's when a card is dropped on it: hears the same moment. Every event like it is below.

One row per event: its name for addEventListener(), and on a Spanish page; who sends it; what its detail holds; and, where Spell has one, the line a program writes to hear it, in English and Spanish.

Epic page: epic language, P67 · Drag Events Written for: anyone writing a page around a Spell program, or looking up which line hears an event Status: built in epic language P67, 2026-11-20 Data: events.json5, beside this page, written by spell events write from the code; never edited by hand
  • Spell UI's events come from each component's vocabulary, and their Spanish from Spell UI's dictionary.
  • A view's own events (a drag's, a file's) come from its element's vocabulary, named in each language by the core's messages.
  • The program's own come from the core's messages.
  • Each Spell line is compiled, in its language, by the data's test:
    • it fails unless the line makes the handler the page calls
    • it fails too while the data is stale, so an event added or renamed can't ship without its row
  • Run spell events write after changing an event; spell events check only says if it's stale.

A list's element sends these as a thing is dragged over it, and a view with a file line as files come from the desktop. None can be cancelled. While something moves, a dragged-over comes at most every 100ms.

Every component's events, by tag. A Spell line hears the uploader's: the page carries them to the view holding the uploader, then the lists holding it, then the app.
