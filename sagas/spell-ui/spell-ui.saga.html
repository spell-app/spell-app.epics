Beautiful, themeable, accessible components that load themselves on demand, for plain HTML or any framework: <ui-*> elements on Solid 2, and its docs site.

Spell UI, the <ui-*> elements on Solid 2, is the most finished part of spell, with its own docs site.

  • UI Component Creation, built 2026-10-01: Spell UI green in the monorepo, folders named by tag, <ui-root> loading components on demand, and every test passing in Chromium, Firefox and WebKit.
  • UI Import, merged: three elements that show HTML, code and markdown from a file or inline, and save it back through one loader.
  • Solid Migration, merged: the editor app, its web components and the VS Code runner moved from React to Solid 2 on Spell UI's elements.
  • Spell Element: Spell UI makes its own custom elements now, with one attribute store, new decorators, a lint guard, and four attributes every element shares.
  • WWOD Spell UI: the whole package, about 120,000 lines, brought in line with the house style, folder by folder.
  • Spell UI Pages: 66 hand-written docs pages in Fomantic's style, with 1608 live examples, and 24 of Fomantic's 25 themes ported.
  • Spell UI Docs Rework, merged: the docs site in the Spell brand look, one steady layout, foldable sections, sticky tabs and a site-wide search.
  • SEO · Static Server Render, merged: spell ssr renders every family to plain HTML in node, so dialogs, accordions and forms work with JavaScript off.

What's left is mostly shipping it, and the gaps the docs pages found.

  • The 100 widget gaps still open, grouped in Spell UI Pages' gap report.
  • The Linux visual baselines, still waiting (UI Component Creation's C1).
  • From the parked goals, spell/ui: a release on npm, with a fresh README, a repository field, the last WebKit failures fixed and families back under their size budget.
  • Spell UI written in spell itself is the Drawable Spell saga's Spell UI In Spell.
