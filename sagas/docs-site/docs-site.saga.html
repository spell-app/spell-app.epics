The docs pages, the shared folders they live in, and the one page server that shows them.

The docs became pages on Spell UI in shared folders every checkout sees, served by one page server.

  • Docs workspace + /plan-doc: every doc moved into hand-written HTML pages on Spell UI, with templates and a docs index, and each planning session got a live epic page.
  • Unified Server, merged: one leaf package of page-serving helpers replaced six hand-rolled copies, and ONE page server per checkout serves docs, epics, Spell UI's docs and the editor, with live reload.
  • Shared Content: every docs page, epic page, template and log moved out of git branches into one shared repo, linked into every checkout, committed after every turn.
    • So every worktree sees every edit at once, and those files never conflict on merge again.
  • Reading time chip, epic-engine P14: a "48 min read" chip after every docs page's title, its tooltip the word count. Started as the small demo epic even-martin-demo, folded into epic-engine and removed (2026-10-21).
